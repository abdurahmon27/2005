does it go?** So every skill note ends up in one of three buckets.

| Depth | What it means |
|---|---|

| **Working** | I can build with it without hand-holding, but I've not carried it through production pain yet. |
| **Learning** | I'm actively reading and breaking things. Ask me again in a month. |
