**Depth: shipping — on my own machine, every day.** My laptop runs **NixOS with
Hyprland**, defined as a flake I can rebuild from scratch. When something breaks,
it breaks in a file I can read.

## What that actually buys me

- The machine is reproducible. A new laptop is a `nixos-rebuild`, not a weekend.
- Rollbacks are real. A bad change is one generation back.
- Per-project shells: `shell.nix` per repo, no global tool soup. (This portfolio
  has one.)

## The hardest thing I've done with it

Getting **iOS development working without a Mac**: `xtool` inside Docker,
`usbmuxd` on the host, a free Apple ID for signing, and GitHub's macOS runners
for the parts that genuinely need Apple's toolchain. NixOS made it harder in its
own special ways — no FHS, no casual `curl | sh` — and that's exactly why the
final setup is something I can hand to someone else:
[ios-on-nixos](https://github.com/abdurahmon27/ios-on-nixos).

Related: [React Native](/lab/skills/react-native), [FilterCam](/lab/ideas/filter-cam).

## Comfortable with

- Flakes, modules, `home-manager`, overlays for the packages that need patching.
- Hyprland + Wayland config, and the specific pain of screen sharing on it.
- Docker on NixOS, systemd units written as Nix attributes.
- Linux fundamentals: udev rules, journald, networking, permissions.

## Still learning

- Writing derivations that aren't just `mkShell` wrappers.
- `nixos-anywhere` / declarative remote deploys for servers, not just my laptop.
- Keeping closure sizes sane instead of letting `/nix/store` grow forever.
