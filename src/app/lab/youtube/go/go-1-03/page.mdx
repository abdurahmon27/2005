## Nimani oʻrganasiz

Sinf jurnalida baholar ism bilan emas, tartib raqami bilan yozilgan: «3-oʻquvchiga 5». Roʻyxat oʻrtasiga yangi
oʻquvchi qoʻshilsa, oʻsha 5 baho endi kimniki boʻladi?

```text
Kecha:  1 Ali    2 Bobur   3 Dilnoza    ← 3-raqamga ⭐ 5
Bugun:  1 Ali    2 Bobur   3 Botir      4 Dilnoza
                           ⭐ 5 endi kimniki?
```

Go dasturlarida ham xuddi shunday jim xato bor. Bu darsda uni topamiz va tuzatamiz.

**Bitta gʻoya:** konstanta oʻzgarmaydi, lekin uning maʼnosi qayerda turganiga bogʻliq. Turini tushgan katagidan
oladi, `iota` qiymatini esa roʻyxatdagi qator oʻrnidan oladi.

Dars oxirida siz:

- `const` bilan oʻzgarmaydigan son yoza olasiz va unga yangi qiymat berilsa nima boʻlishini bilasiz;
- nega `time.Sleep(2)` ikki soniya emas, ikki nanosekund soʻrashini tushuntira olasiz va `2 * time.Second` deb
  tuzata olasiz;
- `iota` bilan holatlar roʻyxatini yoza olasiz;
- faylga saqlanadigan raqamlarni roʻyxat oʻrtasiga qator qoʻshib buzmaslikni bilasiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| konstanta (`const`) | kodda tayyor yozilgan, oʻzgarmaydigan son: toshga oʻyilgan yozuv | constant |
| turi yoʻq konstanta | turi yozilmagan konstanta: suv kabi, qaysi katakka tushsa, oʻsha katakning turini oladi | untyped constant |
| `iota` | `const ( … )` qavsi ichidagi qator raqami, 0 dan boshlanadi | iota |

Yoʻl-yoʻlakay ikkita yordamchi soʻz ham uchraydi: **`time.Sleep`** (dasturni kutdiradigan buyruq) va
**nanosekund** (soniyaning milliarddan biri). Ikkalasini kerak boʻlgan joyda tushuntiramiz.

## Konstanta: toshga oʻyilgan son (`const`)

[GO-0.02](/lab/youtube/go/go-0-02) da oʻzgaruvchini stadion tablosiga oʻxshatdik: undagi son almashib turadi. Ammo baʼzi sonlar
hech qachon oʻzgarmaydi. Masalan, bir daqiqada doim 60 soniya bor. Bunday sonni toshga oʻyilgan yozuv deb tasavvur
qiling: uni oʻchirib, boshqasini yozib boʻlmaydi.

```text
oʻzgaruvchi = tablo          konstanta = tosh 🪨
PAXTAKOR  3 → 4              ┌──────────────┐
son almashadi                │ soniyalar 60 │  oʻzgarmaydi
                             └──────────────┘
```

Kodda tayyor yozilgan, oʻzgarmaydigan son oʻzbekcha **konstanta**, inglizcha **constant** deyiladi. Go'da
konstantaga nom berish uchun **`const`** soʻzi yoziladi:

```go
const soniyalar = 60
soniyalar = 61
fmt.Println(soniyalar)
```

Birinchi qatorni shunday oʻqing: «konstanta `soniyalar`, qiymati 60». `soniyalar` — «seconds», bir daqiqadagi
soniyalar soni. Ikkinchi qatorda esa unga «`soniyalar` endi 61 boʻlsin» deb yangi qiymat bermoqchimiz.

Go'ning odatini eslang: kodda xato boʻlsa, u jim oʻtkazib yubormaydi. Ekranga nima chiqadi?
**A)** `61` · **B)** `60` · **C)** tarjima xatosi

<details>
<summary>Javob</summary>

**C: tarjima xatosi.** Konstantaga yangi qiymat berib boʻlmaydi, Go buni dastur ishga tushmasdan oldin koʻradi.
**A** ni tanlagan boʻlsangiz, `soniyalar` ni oddiy oʻzgaruvchi deb oʻylagansiz. **B** ni tanlagan boʻlsangiz, Go 61 ni
jimgina eʼtiborsiz qoldiradi deb oʻylagansiz. Go esa xatoni jim oʻtkazmaydi, toʻxtatib aytadi.

</details>

Toʻliq dastur, kurs papkasidagi `ozgarmas/main.go`:

```go filename="ozgarmas/main.go" showLineNumbers
package main

import "fmt"

func main() {
	const soniyalar = 60 // bir daqiqadagi soniyalar soni (vaqt emas, oddiy son)
	soniyalar = 61       // ataylab xato: konstantani oʻzgartirib boʻlmaydi
	fmt.Println(soniyalar)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1–5 | `package main` … `func main() {` | tanish qolip: ishga tushadigan dastur, `fmt` ni ulaymiz, dastur `main` dan boshlanadi |
| 6 | `const soniyalar = 60` | **konstanta** `soniyalar`, qiymati 60. `//` dan keyingi matn izoh, Go uni oʻqimaydi |
| 7 | `soniyalar = 61` | konstantaga yangi qiymat bermoqchi: ataylab yozilgan xato |
| 8 | `fmt.Println(soniyalar)` | `soniyalar` ni ekranga chiqarishi kerak edi |
| 9 | `}` | `main` tugadi |

```console
$ go run ozgarmas/main.go
# command-line-arguments
ozgarmas/main.go:7:2: cannot assign to soniyalar (neither addressable nor a map index expression)
```

Xabarni har doimgidek fayl va qatordan boshlab oʻqiymiz: `ozgarmas/main.go` fayli, **7-qator**, 2-belgi. Yuqoridagi
3 qatorli parchada bu ikkinchi qator edi, toʻliq faylda esa tepada tanish qolip turgani uchun 7-qator. Keyin
`cannot assign to soniyalar`, yaʼni «`soniyalar` ga qiymat berib boʻlmaydi». Qavs ichidagi qolgan soʻzlar «bu nom
qiymat qoʻyiladigan joy emas» degan maʼnoni beradi. `go run` dasturni ishga tushirmadi.

| Qator | `soniyalar` | Ekranda |
|---|---|---|
| 6 `const soniyalar = 60` | `60` 🪨 | |
| 7 `soniyalar = 61` | tarjima xatosi: dastur ishga tushmaydi | |

Qisqasi: toshdagi yozuv kabi, konstanta ham oʻzgarmaydi.

## Turi yoʻq konstanta: suv idish shaklini oladi

[GO-0.03](/lab/youtube/go/go-0-03) da `int` va `float64` oʻzgaruvchilarni aralashtirib boʻlmasligini koʻrdik: turlar mos emas.
Eslash uchun `suv-xato/main.go` (ataylab xato):

```go filename="suv-xato/main.go" showLineNumbers
package main

import "fmt"

func main() {
	n := 100          // oʻzgaruvchi: turi int
	var b float64 = n // ataylab xato: int oʻzgaruvchi float64 katakka tushmaydi
	fmt.Println(b)
}
```

6-qatorda `n := 100` turi `int` boʻlgan oʻzgaruvchi yaratadi. 7-qatordagi `var b float64` esa [GO-1.02](/lab/youtube/go/go-1-02)
dagidek yangi yorliq yaratadi, faqat katak turini oʻzimiz yozamiz: `float64`. Unga `n` ni qoʻymoqchimiz.

```console
$ go run suv-xato/main.go
# command-line-arguments
suv-xato/main.go:7:18: cannot use n (variable of type int) as float64 value in variable declaration
```

7-qator, 18-belgi (aynan `n`): «`n` ni (`int` turidagi oʻzgaruvchi) `float64` qiymat sifatida ishlatib boʻlmaydi».

Konstanta bilan esa boshqacha. Turi yozilmagan konstantaning turi u katakka tushganda aniqlanadi. Konstantani suv deb
tasavvur qiling: qaysi idishga quyilsa, oʻsha idishning shaklini oladi. Bunday konstanta oʻzbekcha **turi yoʻq
konstanta**, inglizcha **untyped constant** deyiladi. Bu «konstantada umuman tur boʻlmaydi» degani emas: turini u
tushgan katak beradi.

```go filename="suv/main.go" showLineNumbers
package main

import "fmt"

func main() {
	const yuz = 100       // turi yoʻq (untyped) konstanta
	var a int8 = yuz      // int8 katakka tushdi
	var b float64 = yuz   // float64 katakka tushdi
	fmt.Println(a/8, b/8) // int8: kasr tashlanadi, float64: qoladi
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 6 | `const yuz = 100` | turi yoʻq konstanta `yuz` («yuz» = 100) |
| 7 | `var a int8 = yuz` | `int8` katak `a`, unga `yuz` tushdi: endi bu 100 `int8` |
| 8 | `var b float64 = yuz` | `float64` katak `b`, unga ham `yuz` tushdi: endi bu 100 `float64` |
| 9 | `fmt.Println(a/8, b/8)` | ikkalasini 8 ga boʻlib chiqaradi: turlar farqini koʻrish uchun |

Bitta konstanta, ikki xil katak:

| Nom | Turi | Qiymati |
|---|---|---|
| `yuz` | turi yoʻq 💧 | `100` |
| `a` | `int8` | `100` |
| `b` | `float64` | `100` |

Taxmin qiling: ekranga nima chiqadi? **A)** `12 12` · **B)** `12 12.5` · **C)** tarjima xatosi

<details>
<summary>Javob</summary>

**B: `12 12.5`.** `yuz` ikkala katakka ham xatosiz tushdi, chunki uning turi yoʻq edi. `a` butun son, butun sonni
boʻlganda kasr tashlanadi: `100 / 8` → `12`. `b` kasrli son, unda kasr qoladi: `12.5`. **C** ni tanlagan
boʻlsangiz, `yuz` ni `suv-xato` dagi `n` kabi `int` deb oʻylagansiz. **A** ni tanlagan boʻlsangiz, ikkala katak bir xil
turni oldi deb oʻylagansiz.

</details>

```console
$ go run suv/main.go
12 12.5
```

Bu dasturning toʻliq misoli videoda yoʻq: videoda faqat 6–8-qatorlar koʻrsatilgan.

## `time.Sleep(2)`: ikki soniya emas

Bu qoida vaqt bilan ishlaganda juda muhim. **`time`** — `fmt` kabi Go'ning tayyor asboblar qutisi (paket). Unda
dasturni biroz kutdiradigan buyruq bor: **`time.Sleep`**. U qavsi ichidagi sonni vaqt katagiga qoʻyadi. Bu katak
turining nomi **`time.Duration`**. Bu katak vaqtni **nanosekund**da sanaydi, nanosekund esa soniyaning milliarddan
biri:

| | |
|---|---|
| 1 soniya | 1 000 000 000 nanosekund |
| 1 nanosekund | 0,000 000 001 soniya |

Endi savol. `var` bilan `kutish` yorligʻini yaratamiz, katak turi `time.Duration`, qiymati 2:

```go
var kutish time.Duration = 2
fmt.Println(kutish)
```

Ekranda nima boʻladi? **A)** `2s` · ikki soniya · **B)** `2ns` · ikki nanosekund · **C)** tarjima xatosi

<details>
<summary>Javob</summary>

**B: ikki nanosekund.** Go xato bermadi, chunki 2 turi yoʻq son edi. U vaqt katagiga jimgina tushdi, katakdagi 2 esa
nanosekund deb oʻqiladi. `Println` vaqtni birligi bilan yozadi: `ns` = nanosekund. **A** ni tanlagan boʻlsangiz, odamlar
kabi «vaqt odatda soniyada» deb oʻylagansiz, Go esa nanosekundda sanaydi. **C** ni tanlagan boʻlsangiz, `suv-xato` ni
esladingiz, lekin u yerda oʻzgaruvchi edi; bu yerda turi yoʻq konstanta.

</details>

```text
   2              →   time.Duration katagi    →   2 nanosekund
turi yoʻq 💧          nanosekundlarni sanaydi       xato yoʻq, jim
```

Demak, `time.Sleep(2)` deb yozsangiz, dastur ikki soniya emas, atigi ikki nanosekund kutishni soʻraydi. Yaʼni deyarli
umuman kutmaydi, xato ham chiqmaydi. (`Sleep` kamida soʻralgan vaqtcha kutadi: bu kursda 1000 marta oʻlchaganda
0,4 dan 27 mikrosekundgacha chiqdi. Baribir soniyadan juda-juda kam.)

Ikki soniya uchun Go'ning tayyor konstantasi bor: **`time.Second`**, u bir soniyaga teng. Yulduzcha `*` koʻpaytiradi,
shuning uchun `2 * time.Second` = ikki soniya. Hammasi bitta dasturda, `kutish/main.go`:

```go filename="kutish/main.go" showLineNumbers
package main

import (
	"fmt"
	"time"
)

func main() {
	var kutish time.Duration = 2 // vaqt turi: nanosekundlarni sanaydi
	fmt.Println(kutish)          // Println birlik qoʻshadi: ns = nanosekund
	time.Sleep(kutish)           // = time.Sleep(2): deyarli kutmaydi
	kutish = 2 * time.Second     // time.Second = 1 soniya = 1 000 000 000 nanosekund
	fmt.Println(kutish)          // s = soniya
	time.Sleep(kutish)           // 2 soniya kutadi
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 3–6 | `import ( "fmt" "time" )` | ikkita paketni birga ulaydi: qavs ichida har biri alohida qatorda |
| 9 | `var kutish time.Duration = 2` | `kutish` yorligʻi («kutish» = wait), katak turi `time.Duration`, unga 2 tushdi: 2 nanosekund |
| 10 | `fmt.Println(kutish)` | `2ns` chiqaradi |
| 11 | `time.Sleep(kutish)` | `time.Sleep(2)` bilan bir xil: 2 nanosekund soʻraydi, deyarli kutmaydi |
| 12 | `kutish = 2 * time.Second` | `kutish` endi 2 soniya boʻlsin: katakda 2 000 000 000 nanosekund |
| 13 | `fmt.Println(kutish)` | yangi qiymatni chiqaradi |
| 14 | `time.Sleep(kutish)` | endi haqiqatan 2 soniya kutadi |

13-qator ekranga nima chiqaradi? **A)** `2000000000` · **B)** `2s` · **C)** `2ns`

<details>
<summary>Javob</summary>

**B: `2s`.** Katakda 2 000 000 000 nanosekund turibdi, lekin `Println` vaqtni qulay birlikda yozadi: `s` = soniya.
**A** ni tanlagan boʻlsangiz, katakdagi sonni koʻrdingiz, lekin `Println` uni vaqt sifatida birligi bilan yozadi.
**C** — eski qiymat; 12-qatordan keyin u yoʻqoldi.

</details>

```console
$ go run kutish/main.go
2ns
2s
```

`2s` chiqqandan keyin dastur 2 soniya kutib, keyin tugaydi.

| Qator | `kutish` katagida | Ekranda |
|---|---|---|
| 9 | `2` (nanosekund) | |
| 10 | `2` | `2ns` |
| 11 | `2` | deyarli kutmaydi |
| 12 | `2000000000` (nanosekund) | |
| 13 | `2000000000` | `2s` |
| 14 | `2000000000` | 2 soniya kutadi ✅ |

## Kichik sinov: `const narx = 300`

Endi oʻzingizni tekshiring. `narx` («narx» = price) konstantasini `int` katakka ham, `int8` katakka ham qoʻyamiz:

```go
const narx = 300
var a int = narx
var b int8 = narx
fmt.Println(a, b)
```

Ekranga nima chiqadi? **A)** `300 300` · **B)** `300 44` · **C)** tarjima xatosi

<details>
<summary>Javob</summary>

**C: tarjima xatosi.** `int` katagiga 300 sigʻdi, `int8` katagiga esa sigʻmadi (unga eng koʻpi 127 sigʻadi).
**A** ni tanlagan boʻlsangiz, suv har qanday idishga sigʻadi deb oʻylagansiz. **B** — jim aylanish: 300 − 256 = 44.
Bu [GO-1.02](/lab/youtube/go/go-1-02) dagi `x++` kabi, dastur ishlayotganda oʻzgaruvchi bilan boʻladi. Konstantani esa Go
oldindan tekshiradi.

</details>

```go filename="sinov/main.go" showLineNumbers
package main

import "fmt"

func main() {
	const narx = 300
	var a int = narx
	var b int8 = narx // ataylab xato: 300 int8 ga sigʻmaydi
	fmt.Println(a, b)
}
```

```console
$ go run sinov/main.go
# command-line-arguments
sinov/main.go:8:15: cannot use narx (untyped int constant 300) as int8 value in variable declaration (overflows)
```

`go run` `int8` qatorini koʻrsatdi: **8-qator**, 15-belgi (aynan `narx`). Xabar: «`narx` ni (turi yoʻq butun
konstanta 300) `int8` qiymat sifatida ishlatib boʻlmaydi … (toʻlib ketadi)». Xabarda **untyped** soʻzi ham bor: bu
bizning «turi yoʻq». 7-qatorda xato yoʻq: `int` katagiga 300 bemalol sigʻadi.

Qisqasi: turi yoʻq konstanta qaysi katakka tushsa, oʻsha katak turini oladi. Idish kichik boʻlsa, Go suvni toʻkmaydi,
tarjima xatosi beradi.

## `iota`: jurnaldagi tartib raqami

Endi doʻkondagi buyurtma holatlari: nomaʼlum, yangi, toʻlangan. Dasturlar ularni koʻpincha jurnaldagi kabi tartib
raqami bilan saqlaydi: 0, 1, 2. Bir nechta konstantani birga yozish uchun `const ( … )` qavsi bor. Raqamlarni qoʻlda
yozmaslik uchun qavs ichiga **`iota`** yozamiz:

```go
const (
	Nomalum = iota
	Yangi
	Tolangan
)
fmt.Println(Yangi, Tolangan)
```

Qoidalar:

- **`iota`** — `const ( … )` qavsi ichidagi qator raqami, u **0 dan** boshlanadi va har qatorda bittaga oshadi.
- Faqat nom yozilgan qatorda Go oldingi yozuvni, yaʼni `= iota` ni takrorlaydi.

Nomlar: `Nomalum` (nomaʼlum, «unknown»), `Yangi` («new»), `Tolangan` (toʻlangan, «paid»). Kodda ular apostrofsiz
yozilgan.

Oxirgi qatorda `Println` `Yangi` va `Tolangan` ni chiqaradi. Ekranda qaysi ikki son boʻladi?
**A)** `0 1` · **B)** `1 2` · **C)** `2 3`

<details>
<summary>Javob</summary>

**B: `1 2`**, chunki sanash noldan boshlandi: `Nomalum` 0, `Yangi` 1, `Tolangan` 2. **C** ni tanlagan boʻlsangiz,
sanashni 1 dan boshlagansiz. **A** ni tanlagan boʻlsangiz, `Yangi` ni birinchi qator deb hisoblagansiz, lekin birinchi
qator `Nomalum`.

</details>

```go filename="holat/main.go" showLineNumbers
package main

import "fmt"

func main() {
	const (
		Nomalum  = iota // 0: qiymat berilmagan (nol qiymat) holat
		Yangi           // 1
		Tolangan        // 2
	)
	fmt.Println(Yangi, Tolangan)
}
```

| Qator | Kod | `iota` | Konstanta qiymati |
|---|---|---|---|
| 6 | `const (` | | bir nechta konstanta birga boshlanadi |
| 7 | `Nomalum = iota` | `0` | `Nomalum` = 0 |
| 8 | `Yangi` | `1` | faqat nom → `= iota` takrorlanadi → `Yangi` = 1 |
| 9 | `Tolangan` | `2` | `Tolangan` = 2 |
| 10 | `)` | | guruh tugadi |
| 11 | `fmt.Println(Yangi, Tolangan)` | | ekranda: `1 2` |

```console
$ go run holat/main.go
1 2
```

Nega 0 «nomaʼlum»? [GO-1.02](/lab/youtube/go/go-1-02) dagi nol qiymatni eslang: qiymat berilmagan katakda 0 turadi. Demak,
buyurtmaga holat berilmasa ham, katakda 0 turadi. 0 `Nomalum` boʻlsa, bunday buyurtma «yangi» emas, «nomaʼlum» boʻlib
koʻrinadi. Bu toʻgʻri: biz unga hech qanday holat bermaganmiz.

## Jim xato: roʻyxat oʻrtasiga qoʻshilgan qator

Endi boshidagi jurnal savoli. Kecha doʻkon toʻlangan buyurtmani, jurnalga yozgandek, faylga **2** raqami bilan yozdi
(oʻshanda `Tolangan` = 2 edi). Bugun dasturchi yangi holat qoʻshdi: `Bekor` (bekor qilingan, «cancelled»). U uni
`Yangi` dan keyin yozdi. Keyin saqlangan 2 ni `Tolangan` va `Bekor` bilan solishtiradi:

```go filename="xato/main.go" showLineNumbers
package main

import "fmt"

func main() {
	const (
		Nomalum = iota
		Yangi
		Bekor // yangi holat oʻrtaga qoʻshildi
		Tolangan
	)
	saqlangan := 2 // kecha faylga yozilgan: oʻshanda 2 = Tolangan edi
	fmt.Println(saqlangan == Tolangan, saqlangan == Bekor)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 9 | `Bekor` | yangi holat, roʻyxat oʻrtasiga qoʻshildi |
| 12 | `saqlangan := 2` | kecha faylga yozilgan raqam («saqlangan» = saved) |
| 13 | `saqlangan == Tolangan, saqlangan == Bekor` | `==` ikki sonni taqqoslaydi: javob `true` yoki `false`. `Println` ikkala javobni chiqaradi |

Ekranda nima chiqadi? **A)** `true false` · **B)** `false true` · **C)** tarjima xatosi. Qatorlarni oʻzingiz
sanab koʻring.

<details>
<summary>Javob</summary>

**B: `false true`.** Qatorlarni sanaymiz: `Nomalum` 0, `Yangi` 1, `Bekor` 2, `Tolangan` 3. Endi 2 `Bekor` degani,
`Tolangan` esa 3 boʻldi. **A** ni tanlagan boʻlsangiz, `Tolangan` hali ham 2 deb oʻylagansiz: lekin `iota` raqamni
qatorning oʻrnidan oladi. **C** ni tanlagan boʻlsangiz, Go buni xato deb biladi deb oʻylagansiz: Go uchun bu toʻgʻri
dastur.

</details>

```console
$ go run xato/main.go
false true
```

`go run` xatosiz ishladi. Raqamlar qanday surildi:

| Holat | Kecha (`Bekor` yoʻq) | Bugun (`Bekor` oʻrtada) |
|---|---|---|
| `Nomalum` | 0 | 0 |
| `Yangi` | 1 | 1 |
| `Bekor` | — | **2** |
| `Tolangan` | **2** | 3 |

Faylda esa kechagi 2 joyida qoldi. Kechagi toʻlangan buyurtmalar endi bekor qilingan boʻlib koʻrinadi. Jurnaldagi
kabi: raqam joyida qoldi, maʼnosi oʻzgardi.

### Tuzatish

Xulosa: faylga yozilgan raqamning maʼnosi hech qachon oʻzgarmasligi kerak. Shuning uchun saqlanadigan holatlarga
raqamni qoʻlda yozing:

```go filename="tuzatish/main.go" showLineNumbers
package main

import "fmt"

func main() {
	const ( // faylga saqlanadigan raqamlar qoʻlda yoziladi va hech qachon oʻzgarmaydi
		Nomalum  = 0
		Yangi    = 1
		Tolangan = 2
		Bekor    = 3 // yangi holat roʻyxat oxiriga
	)
	saqlangan := 2
	fmt.Println(saqlangan == Tolangan, saqlangan == Bekor)
}
```

Oʻzgargan qatorlar: 7–10-qatorlarda raqam qoʻlda yozilgan (`iota` yoʻq), yangi `Bekor` esa oxirida va 3 ni oldi.
`Tolangan` yana 2. Endi nima chiqadi? **A)** `true false` · **B)** `false true`

<details>
<summary>Javob</summary>

**A: `true false`.** Saqlangan 2 yana `Tolangan`. Raqam qoʻlda yozilgan, shuning uchun uni hech bir yangi qator
sura olmaydi.

</details>

```console
$ go run tuzatish/main.go
true false
```

`iota` ni qoldirmoqchi boʻlsangiz ham boʻladi, lekin ikki shart bilan: yangi holatni **faqat roʻyxat oxiriga**
qoʻshing va **hech birini oʻchirmang** (oʻchirilsa, keyingilari yana bittaga suriladi). Uy vazifasining birinchi
topshirigʻi aynan shu. Katta tizimlar ham shunday qiladi: masalan, Protocol Buffers (Google'ning dasturlar oʻrtasida maʼlumot
almashish formati) qoʻllanmasi oʻchirilgan raqamlarni qayta ishlatmaslikni qatʼiy tavsiya qiladi.

## Chuqurroq (ixtiyoriy): `1 << 100` va `0.1 + 0.2`

Agar endi boshlayotgan boʻlsangiz, bu boʻlimni keyinroq oʻqing: darsning qolgan qismi usiz ham tushunarli.

**Juda katta konstanta.** Go qoidasiga koʻra, butun konstanta juda katta aniqlikda saqlanadi: kamida 256 bit. **Bit** — bitta 0 yoki 1, yoqilgan yoki oʻchgan chiroq kabi
([GO-1.02](/lab/youtube/go/go-1-02) ning «Chuqurroq» qismida batafsil). `big/main.go`:

```go filename="big/main.go" showLineNumbers
package main

import "fmt"

const big = 1 << 100

func main() {
	fmt.Println(big >> 98)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 5 | `const big = 1 << 100` | konstanta `main` dan tashqarida ham yozilishi mumkin. `<<` — chapga surish: 1 ni 2 ga 100 marta koʻpaytiradi, yaʼni 2¹⁰⁰ |
| 8 | `fmt.Println(big >> 98)` | `>>` — oʻngga surish: `big` ni 2⁹⁸ ga boʻladi |

2¹⁰⁰ = 1 267 650 600 228 229 401 496 703 205 376, bu 101 bitlik son. Go'dagi eng katta butun son katagi 64 bit,
shuning uchun bu son hech bir butun son katagiga sigʻmaydi. Konstanta sifatida esa bemalol yashaydi. Dastur ishlaydimi?
**A)** ishlaydi · **B)** tarjima xatosi

<details>
<summary>Javob</summary>

**A: ishlaydi va `4` chiqaradi.** 2¹⁰⁰ / 2⁹⁸ = 2² = 4. Katta son faqat konstanta boʻlib, tarjima paytida hisoblandi.
Katakka esa faqat natija, 4 tushdi, u `int` ga bemalol sigʻadi. Bu misol Go'ning rasmiy qoidalarida ham bor.

</details>

```console
$ go run big/main.go
4
```

**Konstanta aniq hisoblanadi.** 0,1 va 0,2 ning yigʻindisi 0,3 ga tengmi? `float/main.go`:

```go filename="float/main.go" showLineNumbers
package main

import "fmt"

const a, b = 0.1, 0.2

func main() {
	fmt.Println(a+b == 0.3)

	x, y := 0.1, 0.2
	fmt.Println(x+y == 0.3)
	fmt.Println(x + y)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 5 | `const a, b = 0.1, 0.2` | ikkita konstanta bitta qatorda: `a` = 0.1, `b` = 0.2 |
| 8 | `fmt.Println(a+b == 0.3)` | konstantalar yigʻindisini 0.3 bilan taqqoslaydi |
| 10 | `x, y := 0.1, 0.2` | ikkita `float64` oʻzgaruvchi bitta qatorda |
| 11 | `fmt.Println(x+y == 0.3)` | oʻzgaruvchilar yigʻindisini 0.3 bilan taqqoslaydi |
| 12 | `fmt.Println(x + y)` | yigʻindining oʻzini chiqaradi |

Taxmin qiling: **A)** `true` va `true` · **B)** `true` va `false` · **C)** `false` va `false`

<details>
<summary>Javob</summary>

**B.** Konstantalar bilan `true`: Go ularni aniq hisoblaydi. `float64` oʻzgaruvchilar bilan `false`, chunki `float64`
katagi 0.1 va 0.2 ni aniq saqlay olmaydi, yaxlitlab saqlaydi. Yigʻindi biroz katta chiqadi:
`0.30000000000000004`.

</details>

```console
$ go run float/main.go
true
false
0.30000000000000004
```

## Koʻp uchraydigan xatolar

**1. `iota` roʻyxati oʻrtasiga yangi holat qoʻshish.** Eng klassik xato, chunki «bitta qator qoʻshdim, xolos» deb
oʻylash oson. Go xato bermaydi, faylda saqlangan raqamlar esa jim maʼnosini oʻzgartiradi: kechagi toʻlangan
buyurtma bekor qilingan boʻlib koʻrinadi. Toʻliq misol yuqoridagi «Jim xato: roʻyxat oʻrtasiga qoʻshilgan qator»
boʻlimida (`xato/main.go` → `false true`). **Tuzatish:** saqlanadigan holatlarga raqamni qoʻlda yozing
(`tuzatish/main.go` → `true false`) yoki yangi holatni faqat oxiriga qoʻshing va hech birini oʻchirmang.

**2. `time.Sleep(2)` ni ikki soniya deb oʻylash.** Bu ham jim xato: dastur xatosiz ishlaydi, lekin kutmaydi.
Turi yoʻq 2 `time.Duration` katagiga tushib, 2 nanosekund boʻladi. Batafsil: yuqoridagi «`time.Sleep(2)`: ikki
soniya emas» boʻlimi. **Tuzatish:** `time.Sleep(2 * time.Second)`. Go'ning oʻzi ham, `go vet` ham bu haqda jim;
alohida tekshiruvchi dastur [staticcheck](https://staticcheck.dev/docs/checks/#SA1004) (SA1004) buni ushlaydi.

**3. Soniyalar oʻzgaruvchida boʻlsa: `n * time.Second`.** `2 * time.Second` ishlaydi, chunki 2 turi yoʻq son. Son
oʻzgaruvchida boʻlsa-chi? Bu misol videoda yoʻq, u kurs papkasida (`duration/main.go`):

```go filename="duration/main.go" showLineNumbers
package main

import (
	"fmt"
	"time"
)

func main() {
	fmt.Println(2 * time.Second)

	n := 2
	fmt.Println(n * time.Second)
}
```

```console
$ go run duration/main.go
# command-line-arguments
duration/main.go:12:14: invalid operation: n * time.Second (mismatched types int and time.Duration)
```

12-qator, 14-belgi: «notoʻgʻri amal: `n * time.Second` (turlar mos emas: `int` va `time.Duration`)». `n` turi yoʻq
konstanta emas, u `int` oʻzgaruvchi. Go esa turlarni oʻzi jimgina aralashtirmaydi, xuddi `suv-xato` dagidek.
**Tuzatish:** `n` ni vaqt turiga aylantiring, [GO-0.03](/lab/youtube/go/go-0-03) dagi `float64(olma)` kabi (`durfix/main.go`):

```go filename="durfix/main.go" showLineNumbers
package main

import (
	"fmt"
	"time"
)

func main() {
	n := 2
	fmt.Println(time.Duration(n) * time.Second)
}
```

```console
$ go run durfix/main.go
2s
```

**4. Konstantaga yangi qiymat berish.** `const soniyalar = 60`, keyin `soniyalar = 61` → `cannot assign to
soniyalar` (yuqoridagi «Konstanta: toshga oʻyilgan son» boʻlimi). **Tuzatish:** qiymat oʻzgarishi kerak boʻlsa,
konstanta emas, oʻzgaruvchi yarating: `soniyalar := 60`.

**5. Konstanta katakka sigʻmaydi.** `const narx = 300`, keyin `var b int8 = narx` → `(overflows)` (yuqoridagi
«Kichik sinov» boʻlimi). **Tuzatish:** kattaroq katak tanlang, masalan `int`.

## Oʻzingizni tekshiring

Avval oʻzingiz javob bering, keyin oching.

**1.** `const soniyalar = 60` dan keyin `soniyalar = 61` deb yozsak, nima boʻladi?

<details>
<summary>Javob</summary>

Tarjima xatosi (`cannot assign to soniyalar`), chunki konstanta oʻzgarmaydi. Dastur umuman ishga tushmaydi.

</details>

**2.** `time.Sleep` qavsida `2` boʻlsa, dastur qancha vaqt kutishni soʻraydi?

<details>
<summary>Javob</summary>

Ikki nanosekund, yaʼni deyarli umuman kutmaydi. Turi yoʻq 2 `time.Duration` katagiga tushadi, bu katak esa
nanosekundlarni sanaydi. Ikki soniya uchun `2 * time.Second` yozing.

</details>

**3.** `iota` roʻyxati oʻrtasiga yangi holat qoʻshsak, faylda saqlangan raqamlar bilan nima boʻladi?

<details>
<summary>Javob</summary>

Undan keyingi raqamlar bittaga suriladi va saqlangan sonlarning maʼnosi jim oʻzgaradi, xato chiqmaydi. Saqlanadigan
holatlarga raqamni qoʻlda yozing yoki yangi holatni faqat oxiriga qoʻshing.

</details>

**4.** Bu kod nimani chiqaradi?

```go
const (
	Qizil = iota
	Sariq
	Yashil
)
fmt.Println(Qizil, Yashil)
```

<details>
<summary>Javob</summary>

`0 2`. `Qizil` (qizil, «red») birinchi qator: `iota` = 0. `Sariq` («yellow») 1, `Yashil` («green») 2.

</details>

**5.** Oldingi darsdan: `var x int8 = 127`, keyin `x++` va `fmt.Println(x)`. Ekranga nima chiqadi? Nega bu safar
tarjima xatosi boʻlmaydi?

<details>
<summary>Javob</summary>

`-128`. Bu yerda 128 kodda tayyor yozilmagan: u dastur ishlayotganda oʻzgaruvchi bilan hisoblanadi, shuning uchun
`int8` katagi jim aylanadi (overflow). Konstanta esa kodda tayyor turadi va Go uni oldindan tekshiradi.

</details>
