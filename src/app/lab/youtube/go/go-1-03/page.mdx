## Nimani oʻrganasiz

Bazada toʻlangan buyurtmalar `status = 2` bilan saqlangan. Kimdir Go kodidagi holatlar roʻyxatining oʻrtasiga
bitta yangi holat qoʻshdi. Kompilyator jim. Ertasi kuni oʻsha buyurtmalar qanday koʻrinadi? Javob
darsning ikkinchi yarmida, va u Go'dagi konstantalarning bitta qoidasidan kelib chiqadi.

**Bitta gʻoya:** Go'da `const` — kompilyatsiya paytida maʼlum qiymat, va tur yozilmagan konstanta (**untyped
constant**) turini ishlatilgan joydan oladi: `time.Sleep(2)` shuning uchun ikki nanosekund soʻraydi. `iota` esa
qiymatini `const` blokidagi eʼlon oʻrnidan oladi, shuning uchun roʻyxat oʻrtasiga qoʻshilgan holat bazadagi
raqamlarning maʼnosini jim oʻzgartiradi.

Dars oxirida siz:

- Go `const` ni JavaScript `const` dan ajrata olasiz: qaysi ifoda konstanta boʻla oladi, qaysi biri `is not
  constant` beradi;
- `time.Sleep(2)` nega 2 soniya ham, 2 ms ham emas, 2 nanosekund ekanini tushuntirib, toʻgʻri vaqtni
  `2 * time.Second` va `time.Duration(n) * time.Second` bilan yoza olasiz;
- `iota` bilan holatlar roʻyxatini yozib, bazadagi raqamlarni buzmasdan yangi holat qoʻsha olasiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| `const` | qiymati kompilyatsiya paytida maʼlum nom: faqat son, string yoki bool | constant |
| untyped constant | tur yozilmagan konstanta: turini ishlatilgan joydan oladi | untyped constant |
| `iota` | `const` blokidagi eʼlonning tartib raqami, 0 dan | iota |

Ikkita yordamchi soʻz ham uchraydi: **`time.Duration`** (vaqt oraligʻi, nanosekundlar soni) va **yangi tur**
(`type Duration int64`: asosi `int64`, lekin alohida tur). Bundan tashqari **default type** va **typed constant**
degan ikki ibora bor, ular untyped constant boʻlimida tushuntiriladi.

## `const`: JavaScript'dagi `const` emas

Bugun uchta Go tushunchasi, har biri siz bilgan narsa yonida: `const` ↔ JS `const`, untyped constant ↔
`time.Sleep(2)`, `iota` ↔ TypeScript `enum`. Birinchisidan boshlaymiz.

JavaScript'da `const` faqat **nomni** qotiradi: uni boshqa qiymatga qayta bogʻlab boʻlmaydi. Qiymatning oʻzi esa
ishlash paytida hisoblanadi, masalan `Date.now()` dan. Obyekt ichi ham oʻzgaraveradi:

```js filename="anchors/const.js"
// JS const faqat nomni qayta bogʻlashni taqiqlaydi
const cfg = { port: 80 };
cfg.port = 81;            // ✅ obyekt ichi oʻzgaradi
console.log(cfg.port);    // 81
const start = Date.now(); // ✅ qiymat ishlash paytida olinadi
console.log(typeof start); // number
```

```console
$ node anchors/const.js
81
number
```

Python'da esa konstanta umuman yoʻq. Katta harfli nom shunchaki kelishuv (PEP 8), qayta yozish ham ishlaydi:

```python filename="anchors/const.py"
# Python'da konstanta faqat kelishuv (katta harfli nom)
MAX_RETRIES = 3
MAX_RETRIES = 4  # ✅ ishlaydi
print(MAX_RETRIES)  # 4
```

```console
$ python3 anchors/const.py
4
```

Go'da `const` boshqa narsa. Uning qiymati **kompilyatsiya paytida** maʼlum boʻlishi shart, va u faqat son (rune ham),
string yoki bool boʻla oladi. Konstanta ifodada faqat konstantalar va operatorlar qatnashadi, oddiy funksiya
chaqiruvi emas. (`len("abc")`, `min` va `max` kabi baʼzi oʻrnatilgan funksiyalar konstantalar bilan istisno.)

Foydasi: oʻtgan darsdagi `var x int8 = 128` kabi xatolar dastur ishga tushishidan oldin ushlanadi.

| Til | `const` nimani qotiradi | Qiymat qachon maʼlum | Kim tekshiradi |
|---|---|---|---|
| JavaScript | nomni (qayta bogʻlab boʻlmaydi) | ishlash paytida (`Date.now()`) | runtime |
| Python | hech narsani: katta harfli nom — kelishuv | ishlash paytida | hech kim |
| PHP | nom va qiymatni | kompilyatsiya paytida | PHP fayl ishga tushishidan oldin |
| Go | nom va qiymatni | kompilyatsiya paytida | kompilyator |

Endi uchta qator. Oʻn megabayt baytlarda, ikkining kvadrat ildizi va joriy vaqt (JS'dagi `Date.now()` kabi):

```go
const maxSize = 10 * 1024 * 1024
const root2 = math.Sqrt(2)
const start = time.Now()
```

Ulardan qaysilari kompilyatsiya boʻladi? **A)** uchalasi · **B)** `maxSize` va `root2` · **C)** faqat `maxSize` ·
**D)** hech biri

<details>
<summary>Javob</summary>

**C: faqat `maxSize`.** `10 * 1024 * 1024` da faqat konstantalar va `*` operatori bor, kompilyator uni oʻzi
hisoblaydi. `math.Sqrt(2)` natijasi hech qachon oʻzgarmasa ham, u funksiya chaqiruvi: Go uni ishlash paytida
hisoblaydi. `time.Now()` esa har safar boshqa qiymat qaytaradi. «Uchalasi» ni tanlagan boʻlsangiz, Go `const` ni JS
`const` kabi deb oʻylagansiz. «`maxSize` va `root2`» ni tanlagan boʻlsangiz, «natija oʻzgarmasa, konstanta» deb
oʻylagansiz: Go natijaga emas, ifodaning oʻziga qaraydi.

</details>

Toʻliq dastur, `notconst/main.go`:

```go filename="notconst/main.go" showLineNumbers
package main

import (
	"fmt"
	"math"
	"time"
)

func main() {
	const maxSize = 10 * 1024 * 1024 // faqat konstantalar va operatorlar: kompilyator hisoblaydi
	const root2 = math.Sqrt(2)       // ataylab xato: funksiya chaqiruvi — natija ishlash paytida
	const start = time.Now()         // ataylab xato: time.Now() faqat ishlash paytida maʼlum
	fmt.Println(maxSize, root2, start)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 3–7 | `import ( "fmt" "math" "time" )` | `fmt` (chiqarish), `math` (matematik funksiyalar) va `time` (vaqt) paketlarini ulaydi |
| 10 | `const maxSize = 10 * 1024 * 1024` | konstanta ifoda: 10 485 760, kompilyator hisoblaydi ✅ |
| 11 | `const root2 = math.Sqrt(2)` | funksiya chaqiruvi: natija ishlash paytida ❌ |
| 12 | `const start = time.Now()` | joriy vaqt: faqat ishlash paytida maʼlum ❌ |
| 13 | `fmt.Println(maxSize, root2, start)` | uchalasini chiqarishi kerak edi |

```console
$ go run notconst/main.go
# command-line-arguments
notconst/main.go:11:16: math.Sqrt(2) (value of type float64) is not constant
notconst/main.go:12:16: time.Now() (value of struct type time.Time) is not constant
```

Ikki qator, ikkalasida *is not constant* — «konstanta emas». `notconst/main.go:11:16` — 11-qator, 16-ustun, yaʼni
`math.Sqrt(2)` turgan joy. Qavs ichida Go uning turini aytadi: *value of type float64* — «`float64` turidagi
qiymat». `time.Now()` esa `time.Time` struct'ini qaytaradi. 10-qatorda xato yoʻq.

PHP'dagi `const` ham shunday: `time()` funksiyasini yozsangiz, fayl umuman ishga tushmaydi.

```php filename="anchors/const.php"
<?php
// PHP const: Go kabi, faqat kompilyatsiya paytida maʼlum ifoda
const MAX_SIZE = 10 * 1024 * 1024; // ✅
echo MAX_SIZE, "\n";
const START = time(); // ❌ Fatal error: Constant expression contains invalid operations
```

```console
$ php anchors/const.php

Fatal error: Constant expression contains invalid operations in …/anchors/const.php on line 5
```

(Chiqishdagi toʻliq yoʻl `…` bilan qisqartirildi: u sizning kompyuteringizdagi papkaga bogʻliq.) 4-qatordagi `echo`
ham ishlamadi: PHP butun faylni ishga tushirishdan oldin tekshiradi. Go'da ham, PHP'da ham ishlash paytidagi qiymat
uchun oddiy oʻzgaruvchi ishlatiladi: Go'da `start := time.Now()`.

## Untyped constant: tur ishlatilgan joydan

Turlar darsidan bilasiz: `int` oʻzgaruvchini `float64` ga qoʻyib boʻlmaydi, Go'da yashirin konversiya yoʻq.
`untyped-xato/main.go`:

```go filename="untyped-xato/main.go" showLineNumbers
package main

import "fmt"

func main() {
	n := 100          // oʻzgaruvchi: turi int
	var b float64 = n // ataylab xato: int oʻzgaruvchini float64 ga yashirin konversiya yoʻq
	fmt.Println(b)
}
```

```console
$ go run untyped-xato/main.go
# command-line-arguments
untyped-xato/main.go:7:18: cannot use n (variable of type int) as float64 value in variable declaration
```

*cannot use n (variable of type int) as float64 value* — «`int` turidagi `n` oʻzgaruvchini `float64` qiymat
sifatida ishlatib boʻlmaydi». 6-qatordagi `:=` `n` ga `int` turini bergan, va u oʻzgarmaydi.

Tur yozilmagan konstantaning esa **hali turi yoʻq**. Bu **untyped constant** deyiladi. U turini ishlatilgan joydan
oladi: bir qatorda `int8`, boshqasida `float64`. `untyped/main.go`:

```go filename="untyped/main.go" showLineNumbers
package main

import "fmt"

func main() {
	const yuz = 100       // untyped constant: turi hali yoʻq
	var a int8 = yuz      // bu yerda int8 boʻldi
	var b float64 = yuz   // bu yerda float64 boʻldi
	m := yuz              // tur aytilmagan joy → default type: int (butun son konstantasi uchun)
	fmt.Println(a/8, b/8) // int8: kasr tashlanadi, float64: qoladi
	fmt.Printf("%T\n", m) // int
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 6 | `const yuz = 100` | `yuz` («yuz», 100) — untyped constant: tur yozilmagan |
| 7 | `var a int8 = yuz` | shu yerda `yuz` `int8` boʻladi |
| 8 | `var b float64 = yuz` | shu yerda `float64` boʻladi: `untyped-xato` dagi xato yoʻq |
| 9 | `m := yuz` | `:=` tur aytmaydi: butun son konstantasi **default type** oladi, yaʼni `int` |
| 10 | `fmt.Println(a/8, b/8)` | `int8` boʻlishda kasr tashlanadi (12), `float64` da qoladi (12.5) |
| 11 | `fmt.Printf("%T\n", m)` | `%T` — qiymatning turini chiqaradi; `\n` — yangi qator |

```console
$ go run untyped/main.go
12 12.5
int
```

Bitta `yuz`, uch xil tur:

| Qayerda ishlatildi | `yuz` ning shu yerdagi turi | Nega |
|---|---|---|
| `var a int8 = yuz` | `int8` | oʻzgaruvchining turi yozilgan |
| `var b float64 = yuz` | `float64` | oʻzgaruvchining turi yozilgan |
| `m := yuz` | `int` | tur aytilmagan → default type |

**Default type** — tur aytilmagan joyda (`:=`, `fmt.Println`) Go tanlaydigan tur: butun son uchun `int`, kasrli son
uchun `float64`, `'a'` uchun `rune`. Untyped constant'ning teskarisi — **typed constant**: tur yozilgan konstanta
(`const b int = 3`). U oʻzgaruvchidek qatʼiy, buni «Tekshiruv» boʻlimida koʻramiz.

TypeScript'da bunga yaqin narsa bor. `const a = 3` ning turi `number` emas, `3` (literal type). Uni `let` ga
bersangiz, tur `number` ga kengayadi:

```ts filename="anchors/literal.ts"
// TS: const a = 3 → literal type 3; let b = a → number ga kengayadi ("widening")
const a = 3
let b = a
const ok: 3 = a
const bad: 3 = b // TS2322: Type 'number' is not assignable to type '3'.
```

```console
$ tsc --strict anchors/literal.ts
anchors/literal.ts(5,7): error TS2322: Type 'number' is not assignable to type '3'.
```

4-qator oʻtdi: `a` ning turi hali `3`. 5-qatorda `b` allaqachon `number`. Go'dagi untyped constant va default type —
xuddi shu gʻoya. Farqi: TypeScript turlari kompilyatsiyadan keyin oʻchadi, Go'da esa tanlangan tur ishlash paytida
ham saqlanadi.

## `time.Sleep(2)`: soniya, millisekund yoki nanosekund?

Bu qoida eng koʻp vaqt bilan ishlaganda seziladi. Python'da `time.sleep(2)` ikki **soniya** kutadi:

```python filename="anchors/sleep.py"
import time

t = time.monotonic()
time.sleep(2)  # soniya
print(round(time.monotonic() - t, 1))  # 2.0
```

```console
$ python3 anchors/sleep.py
2.0
```

Node'dagi `setTimeout` da esa `2` — ikki **millisekund**:

```js filename="anchors/sleep.js"
const t = Date.now();
setTimeout(() => console.log(Date.now() - t), 2); // millisekund → 2
```

```console
$ node anchors/sleep.js
2
```

Go'da `time.Sleep` ning parametri `time.Duration`: `func Sleep(d Duration)`. **`time.Duration`** vaqt oraligʻini
**nanosekund** bilan sanaydi (soniyaning milliarddan biri).

### `type Duration int64`: yangi tur, taxallus emas

`time` paketida u `type Duration int64` deb eʼlon qilingan. TypeScript'dagi `type Ms = number` faqat taxallus
(alias): unga istalgan `number` oʻtadi.

```ts filename="anchors/alias.ts"
// TS: type Ms = number — faqat taxallus (alias): istalgan number oʻtadi
type Ms = number
function sleep(ms: Ms) {}
const n: number = 2
sleep(n) // ✅ xato yoʻq. Go'da type Duration int64 esa alohida tur: int oʻtmaydi
```

```console
$ tsc --strict anchors/alias.ts
```

`tsc` hech narsa chiqarmadi: xato yoʻq. Go'dagi `type` esa **yangi tur** yaratadi. `Duration` ning asosi `int64`,
lekin `int` oʻzgaruvchini `Duration` ga qoʻyib boʻlmaydi. `duration-type/main.go`:

```go filename="duration-type/main.go" showLineNumbers
package main

import (
	"fmt"
	"time"
)

func main() {
	// time paketida: type Duration int64 — asosi int64, lekin alohida tur
	var n int = 2
	var d time.Duration = n // ataylab xato: int → time.Duration yashirin oʻtmaydi
	fmt.Println(d)
}
```

```console
$ go run duration-type/main.go
# command-line-arguments
duration-type/main.go:11:24: cannot use n (variable of type int) as time.Duration value in variable declaration
```

11-qator, 24-ustun: `n`. Xabar `untyped-xato` dagi bilan bir xil, faqat `float64` oʻrnida `time.Duration`.

| | TypeScript `type Ms = number` | Go `type Duration int64` |
|---|---|---|
| Nima | taxallus (alias) | yangi tur |
| Oddiy sonni berish | `sleep(n)` ✅ | `var d time.Duration = n` ❌ |
| Ishlash paytida | tur yoʻq | tur bor |

### Bashorat

Endi Go'da `time.Sleep` qavsida `2` turibdi:

```go
time.Sleep(2) // func Sleep(d Duration)
```

Dastur qancha vaqt kutishni soʻraydi? **A)** 2 soniya · **B)** 2 millisekund · **C)** 2 nanosekund ·
**D)** tur mos emas, kompilyatsiya xatosi

<details>
<summary>Javob</summary>

**C: 2 nanosekund, xatosiz.** `2` — untyped constant. U `Sleep` parametrining turini, yaʼni `time.Duration` ni
oladi, `Duration` esa nanosekund sanaydi. «2 soniya» ni tanlagan boʻlsangiz, Python qoidasini koʻchirgansiz.
«2 millisekund» — `setTimeout` qoidasi. «Kompilyatsiya xatosi» ni tanlagan boʻlsangiz, `duration-type` dagi xatoni
eslagansiz: u yerda `n` turi bor oʻzgaruvchi edi, bu yerda `2` turi yoʻq konstanta.

</details>

`sleep2/main.go`:

```go filename="sleep2/main.go" showLineNumbers
package main

import (
	"fmt"
	"time"
)

func main() {
	start := time.Now()
	time.Sleep(2) // 2 soniya? 2 millisekund?
	fmt.Println(time.Duration(2), time.Since(start) < time.Millisecond)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 9 | `start := time.Now()` | boshlanish vaqtini eslab qoladi |
| 10 | `time.Sleep(2)` | `2` → `time.Duration`: 2 nanosekund soʻraydi |
| 11 | `time.Duration(2)` | `2` ni `Duration` sifatida chiqaradi: `Println` uni birligi bilan yozadi |
| 11 | `time.Since(start) < time.Millisecond` | oʻtgan vaqt 1 millisekunddan kammi? `true` yoki `false` |

```console
$ go run sleep2/main.go
2ns true
```

`2ns` — soʻralgan vaqt. `true` — `Sleep` bir millisekunddan ham tez qaytdi. `Sleep` kamida `d` kutadi, aniq vaqt OS'ga
bogʻliq: dars tayyorlanayotganda 1000 ta `time.Sleep(2)` 0,3–14 mikrosekundda qaytgan. Kompilyator ham, `go vet` ham
jim. [staticcheck SA1004](https://staticcheck.dev/docs/checks/#SA1004) esa `time.Sleep` dagi bunday kichik
konstantani ushlaydi.

### Tuzatish: `2 * time.Second`

Ikki soniya uchun `2 * time.Second` yozing. `kutish/main.go`:

```go filename="kutish/main.go" showLineNumbers
package main

import (
	"fmt"
	"time"
)

func main() {
	time.Sleep(2) // untyped 2 → time.Duration: 2 nanosekund soʻraydi
	var d time.Duration = 2
	fmt.Println(d)      // Duration birligi bilan chiqadi: 2ns
	d = 2 * time.Second // time.Second: typed constant, turi Duration (1 000 000 000 ns)
	fmt.Println(d)      // 2s
	time.Sleep(d)       // 2 soniya kutadi
}
```

| Qatordan keyin | `d` (`time.Duration`) | Ekranda | Izoh |
|---|---|---|---|
| 9 | — | | untyped `2` → `Duration`: 2 ns soʻraydi |
| 10 | 2 | | `d` = 2 nanosekund |
| 11 | 2 | `2ns` | `Println` `Duration` ni birligi bilan chiqaradi |
| 12 | 2 000 000 000 | | `time.Second` = 1 000 000 000 ns |
| 13 | 2 000 000 000 | `2s` | |
| 14 | 2 000 000 000 | | 2 soniya kutadi ✅ |

```console
$ go run kutish/main.go
2ns
2s
```

(`2s` dan keyin dastur yana 2 soniya kutib, keyin tugaydi.) **`time.Second`** — **typed constant**: turi
`Duration`, qiymati bir milliard nanosekund. `time` paketida shunday yozilgan:
`Nanosecond Duration = 1`, `Microsecond = 1000 * Nanosecond`, …, `Second = 1000 * Millisecond`. `2 * time.Second`
da `2` untyped, u `Duration` ga moslashadi va natija ham `Duration`.

## Config'dan kelgan soniyalar: `n * time.Second`

Endi ishdagi holat: kutish soniyalari config'dan yoki env'dan keladi. Hozirgina `2 * time.Second` ishladi.

```go
n := 2
time.Sleep(n * time.Second)
```

Bu safar nima boʻladi? **A)** 2 soniya kutadi · **B)** 2 nanosekund kutadi · **C)** kompilyatsiya xatosi

<details>
<summary>Javob</summary>

**C: kompilyatsiya xatosi.** `:=` `n` ga default type'ni, yaʼni `int` ni berdi. Endi `n` — turi `int` boʻlgan
oʻzgaruvchi, Go esa `int` ni `Duration` ga jim aylantirmaydi. Literal `2` esa untyped edi va `Duration` ga moslashdi.
«2 soniya» ni tanlagan boʻlsangiz, `n` ham `2` kabi moslashadi deb oʻylagansiz. «2 nanosekund» ni tanlagan
boʻlsangiz, `time.Sleep(2)` dagi tuzoqni bu yerga koʻchirgansiz.

</details>

```go filename="config/main.go" showLineNumbers
package main

import (
	"fmt"
	"time"
)

func main() {
	n := 2                      // masalan, config yoki env'dan oʻqilgan soniyalar soni: tur = int
	time.Sleep(n * time.Second) // ataylab xato: int × time.Duration
	fmt.Println("tayyor")
}
```

```console
$ go run config/main.go
# command-line-arguments
config/main.go:10:13: invalid operation: n * time.Second (mismatched types int and time.Duration)
```

10-qator, 13-ustun. *invalid operation: n * time.Second (mismatched types int and time.Duration)* — «notoʻgʻri amal:
turlar mos emas, `int` va `time.Duration`».

**Tuzatish:** `time.Duration(n)` — `n` ni `Duration` ga aniq aylantirish (**konversiya**, `int8(big)` kabi,
[GO-1.02](/lab/youtube/go/go-1-02)), keyin `* time.Second`. `time` paketining oʻz hujjatida ham aynan shu shakl bor.
`config-fix/main.go`:

```go filename="config-fix/main.go" showLineNumbers
package main

import (
	"fmt"
	"time"
)

func main() {
	n := 2
	d := time.Duration(n) * time.Second // konversiya: int → time.Duration
	fmt.Println(d)
	time.Sleep(d) // 2 soniya kutadi
}
```

```console
$ go run config-fix/main.go
2s
```

(Bu dastur ham `2s` dan keyin 2 soniya kutadi.) Ehtiyot boʻling: faqat konversiyani yozib, koʻpaytirishni
unutsangiz, yana 2 nanosekund boʻladi. `wrongfix/main.go`:

```go filename="wrongfix/main.go" showLineNumbers
package main

import (
	"fmt"
	"time"
)

func main() {
	n := 2
	fmt.Println(time.Duration(n) * time.Second) // 2s — toʻgʻri
	fmt.Println(time.Duration(n))               // 2ns — notoʻgʻri tuzatish: birlik yoʻq
}
```

```console
$ go run wrongfix/main.go
2s
2ns
```

| Kod | `n` = 2 | Natija |
|---|---|---|
| `n * time.Second` | `int` × `Duration` | kompilyatsiya xatosi |
| `time.Duration(n)` | 2 ns | xatosiz, lekin notoʻgʻri ❌ |
| `time.Duration(n) * time.Second` | 2 × 1 000 000 000 ns | `2s` ✅ |

staticcheck SA1004 `time.Sleep(time.Duration(n))` ni ushlamaydi: u faqat konstantaga qaraydi. Config'da `"2s"` kabi
matn boʻlsa, `time.ParseDuration("2s")` ishlating (npm'dagi `ms('2s')` ga oʻxshash).

Nega Go shunday qatʼiy? Go yashirin sonli konversiyani ataylab qoʻymagan (Go FAQ). Untyped constant esa literal
sonlarni shu qatʼiylikda ham qulay qoldiradi: `2 * time.Second` yoki `var b float64 = 100` uchun konversiya yozish
shart emas (Rob Pike, *Constants*).

## Tekshiruv: untyped `a` va typed `b`

Ikki konstanta: `a` ga tur yozmadik, `b` ga esa `int` deb yozdik. Keyin ikkalasini `time.Second` ga koʻpaytiramiz:

```go
const a = 3
const b int = 3
x := a * time.Second
y := b * time.Second
```

Qaysi qator kompilyatsiya boʻlmaydi? **A)** hech biri · **B)** `x` · **C)** `y` · **D)** ikkalasi

<details>
<summary>Javob</summary>

**C: `y` qatori.** Typed constant oʻzgaruvchidek qatʼiy: `b` endi `int`, va `int` ni `Duration` ga koʻpaytirib
boʻlmaydi. Untyped `a` esa `Duration` ga moslashdi. «Hech biri» ni tanlagan boʻlsangiz, har qanday konstanta
moslashadi deb oʻylagansiz. «`x`» yoki «ikkalasi» ni tanlagan boʻlsangiz, konstanta ham `n` kabi `int` boʻladi deb
oʻylagansiz: untyped constant default type'ni faqat tur aytilmagan joyda oladi.

</details>

```go filename="sinov/main.go" showLineNumbers
package main

import (
	"fmt"
	"time"
)

func main() {
	const a = 3     // untyped
	const b int = 3 // typed: turi int
	x := a * time.Second
	y := b * time.Second // ataylab xato: int × time.Duration
	fmt.Println(x, y)
}
```

```console
$ go run sinov/main.go
# command-line-arguments
sinov/main.go:12:7: invalid operation: b * time.Second (mismatched types int and time.Duration)
```

Faqat 12-qator. Qoida bitta: **untyped constant turini ishlatilgan joydan oladi**, typed constant esa oʻz turini
hamma joyga olib yuradi. Shuning uchun [GO-1.02](/lab/youtube/go/go-1-02) dagi `int8(127) + 1` ham rad etilgan edi:
`int8(127)` — typed constant, va Go spec boʻyicha typed constant qiymati doim oʻz turiga sigʻishi shart. 128 esa
`int8` ga sigʻmaydi.

## TypeScript `enum` va Go'dagi `iota`

Endi boshidagi savolga qaytamiz. TypeScript'da `enum` raqamlarni oʻzi qoʻyadi: `Unknown` 0, `New` 1, `Paid` 2.

```ts filename="anchors/enum1.ts"
enum Status { Unknown, New, Paid }
console.log(Status.New, Status.Paid) // 1 2
```

```console
$ tsc anchors/enum1.ts && node anchors/enum1.js
1 2
```

Go'da `enum` kalit soʻzi yoʻq. Uning oʻrnida oʻz turimiz va `const` blokidagi **`iota`** ishlatiladi.
`holat/main.go` («holat» — status):

```go filename="holat/main.go" showLineNumbers
package main

import "fmt"

type Holat int // time.Duration kabi: asosi int boʻlgan alohida tur

const (
	Nomalum  Holat = iota // 0: zero value — holat berilmagan
	Yangi                 // 1: faqat nom → oldingi ifoda "Holat = iota" takrorlanadi
	Tolangan              // 2
)

func main() {
	var h Holat // zero value
	fmt.Println(Yangi, Tolangan, h == Nomalum)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 5 | `type Holat int` | `time.Duration` kabi oʻz turimiz: asosi `int`, lekin alohida tur |
| 7 | `const (` | `const` bloki: bir nechta konstanta bitta qavs ichida |
| 8 | `Nomalum Holat = iota` | `Nomalum` («nomaʼlum», unknown). `iota` — blokdagi eʼlonning tartib raqami, 0 dan. `Nomalum` = 0 |
| 9 | `Yangi` | («yangi», new) faqat nom: Go oldingi ifodani, `Holat = iota` ni takrorlaydi, `iota` = 1 |
| 10 | `Tolangan` | («toʻlangan», paid) yana takror, `iota` = 2 |
| 14 | `var h Holat` | qiymat berilmagan: zero value, 0 |
| 15 | `fmt.Println(Yangi, Tolangan, h == Nomalum)` | ikki raqam va taqqoslash |

```console
$ go run holat/main.go
1 2 true
```

Natija TypeScript bilan bir xil: `1 2`. Kompilyator blokni shunday oʻqiydi:

| Qator | Yozilgan | Go koʻradigan | `iota` | Qiymat |
|---|---|---|---|---|
| 8 | `Nomalum Holat = iota` | `Nomalum Holat = iota` | 0 | 0 |
| 9 | `Yangi` | `Yangi Holat = iota` | 1 | 1 |
| 10 | `Tolangan` | `Tolangan Holat = iota` | 2 | 2 |

Izoh va boʻsh qatorlar sanalmaydi: `iota` faqat eʼlonlarni sanaydi. Har bir yangi `const` blokida u yana 0 dan
boshlanadi.

Bu tur yopiq emas: `Holat(42)` ham kompilyatsiya boʻladi. Go faqat turni tekshiradi, qiymat roʻyxatda bormi — yoʻq
(hamma holat tekshirilganini `exhaustive` linter ushlaydi).

**Nega 0 aynan `Nomalum`?** Holat berilmagan oʻzgaruvchida zero value, yaʼni 0 turadi (14-qator). 0 `Yangi`
boʻlsa, holati unutilgan buyurtma yangi boʻlib koʻrinardi. Shuning uchun 0 ni `Nomalum` ga qoldiramiz. Protobuf
(gRPC'ning sxema formati) qoʻllanmasi ham shuni talab qiladi: birinchi qiymat `…_UNSPECIFIED = 0`.

## Roʻyxat oʻrtasiga qoʻshilgan holat

Endi boshidagi oʻzgarishni yozamiz. Kecha toʻlangan buyurtma bazaga `2` raqami bilan yozildi. Bugun kimdir yangi
holat `Bekor` («bekor qilingan», cancelled) ni qoʻshdi va uni `Yangi` dan keyin yozdi. Saqlangan `2` ni `Tolangan`
va `Bekor` bilan solishtiramiz. `xato/main.go`:

```go filename="xato/main.go" showLineNumbers
package main

import "fmt"

type Holat int

const (
	Nomalum Holat = iota
	Yangi
	Bekor // yangi holat oʻrtaga qoʻshildi
	Tolangan
)

func main() {
	var saqlangan Holat = 2 // kecha bazaga yozilgan: oʻshanda 2 = Tolangan edi
	fmt.Println(saqlangan == Tolangan, saqlangan == Bekor)
}
```

10-qatorda yangi holat. 15-qatorda kechagi `2`, 16-qatorda ikki taqqoslash.

Ekranda nima chiqadi? **A)** `true false` · **B)** `false true` · **C)** kompilyatsiya xatosi. Eʼlonlarni oʻzingiz
sanab koʻring.

<details>
<summary>Javob</summary>

**B: `false true`.** `Bekor` 2-oʻrinda turibdi, shuning uchun endi `Bekor` = 2, `Tolangan` esa 3. «`true false`»
ni tanlagan boʻlsangiz, `Tolangan` raqamini oʻzgarmas deb oʻylagansiz: `iota` raqamni joyidan oladi.
«Kompilyatsiya xatosi» ni tanlagan boʻlsangiz, Go raqamlar oʻzgarganini sezadi deb oʻylagansiz: u bazani bilmaydi.

</details>

```console
$ go run xato/main.go

```

Kompilyatsiya ham, ishlash ham xatosiz. Lekin endi `2` — `Bekor`:

| Nom | Kecha | Bugun |
|---|---|---|
| `Nomalum` | 0 | 0 |
| `Yangi` | 1 | 1 |
| `Bekor` | — | **2** |
| `Tolangan` | **2** | 3 |
| bazadagi `status = 2` | toʻlangan ✅ | bekor qilingan 💥 |

### Tuzatish

Qoida: bazaga yoki JSON'ga ketadigan raqamning maʼnosi hech qachon oʻzgarmasligi kerak. Uchta yoʻl bor:

1. **Raqamni qoʻlda yozing.** Har bir holat oʻz raqamini oʻzi aytadi, yangisi oxiriga.
2. **`iota` qoldirsangiz, yangi holatni faqat oxiriga qoʻshing** va hech birini oʻchirmang (oʻchirilgan holat
   oʻrniga `_` qoldirish mumkin, «Oʻzingizni tekshiring» 3-savol).
3. **Raqam emas, nom saqlang:** bazaga `"paid"` yozing, TypeScript'dagi string `enum` kabi. Buni 🟡 uy vazifasida
   qilasiz.

Birinchi yoʻl, `tuzatish/main.go`:

```go filename="tuzatish/main.go" showLineNumbers

	Yangi    Holat = 1
	Tolangan Holat = 2
	Bekor    Holat = 3 // yangi holat roʻyxat oxiriga

```

Qoʻlda yozilgan raqamlar bilan saqlangan `2` yana `Tolangan`. Protobuf ham har bir qiymatga raqamni qoʻlda
yozdiradi, va oʻchirilgan raqamni `reserved` qilib, qayta ishlatishni taqiqlaydi.

## Chuqurroq (ixtiyoriy): `0.1 + 0.2 == 0.3`

JavaScript'dagi mashhur savol:

```console
$ node -p '0.1 + 0.2 === 0.3'
false
```

(Bu buyruq kurs papkasida fayl sifatida yoʻq, kod buyruqning oʻzida.) Go'da tur yozilmagan konstantalar bilan nima
chiqadi?

```go
const a, b = 0.1, 0.2
fmt.Println(a+b == 0.3)
```

**A)** `true` · **B)** `false`

<details>
<summary>Javob</summary>

**A: `true`.** Untyped konstanta ifodalar aniq hisoblanadi (Go spec: «evaluated exactly»): yigʻindi aynan 0.3,
hech narsa yaxlitlanmaydi. «`false`» ni tanlagan boʻlsangiz, JS qoidasini koʻchirgansiz: u `float64` uchun toʻgʻri.

</details>

```go filename="float/main.go" showLineNumbers
package main

import "fmt"

func main() {
	const a, b = 0.1, 0.2 // untyped: aniq hisoblanadi
	fmt.Println(a+b == 0.3)

	const c, d float64 = 0.1, 0.2 // typed: float64 ga yaxlitlangan
	fmt.Println(c+d == 0.3)

	x, y := 0.1, 0.2 // float64 oʻzgaruvchilar
	fmt.Println(x+y == 0.3, x+y)
}
```

```console
$ go run float/main.go
true
false
false 0.30000000000000004
```

| Qator | Nima | Natija |
|---|---|---|
| 6–7 | untyped konstantalar: aniq hisob | `true` |
| 9–10 | `float64` deb tur yozilgan: har biri `float64` ga yaxlitlanadi | `false` |
| 12–13 | `float64` oʻzgaruvchilar: JavaScript kabi | `false 0.30000000000000004` |

## Koʻp uchraydigan xatolar

**1. `iota` roʻyxatining oʻrtasiga holat qoʻshish.** Bu mavzudagi eng klassik xato. Xato ham, ogohlantirish ham
yoʻq: undan keyingi hamma raqam bittaga suriladi, bazadagi `2` endi boshqa holat. Toʻliq misol «Roʻyxat oʻrtasiga
qoʻshilgan holat» boʻlimida. **Tuzatish:** bazaga yoki JSON'ga ketadigan raqamlarni qoʻlda yozing, yoki yangi
holatni faqat oxiriga qoʻshing, yoki nom saqlang.

**2. `time.Sleep(2)` ni ikki soniya deb oʻylash.** Kompilyator jim: `2` untyped, u `Duration` boʻladi va
2 nanosekund soʻraydi. Misol «`time.Sleep(2)`» boʻlimida. **Tuzatish:** birlikni doim yozing: `2 * time.Second`,
`500 * time.Millisecond`. staticcheck SA1004 buni ushlaydi.

**3. `int` oʻzgaruvchini `time.Second` ga koʻpaytirish.** `n * time.Second` →
`mismatched types int and time.Duration` (`config/main.go`). **Tuzatish:** `time.Duration(n) * time.Second`.
Faqat `time.Duration(n)` emas: u 2 nanosekund (`wrongfix/main.go`).

**4. Ishlash paytidagi qiymatni `const` qilish.** `const start = time.Now()` →
`time.Now() (value of struct type time.Time) is not constant` (`notconst/main.go`). **Tuzatish:** oddiy
oʻzgaruvchi: `start := time.Now()`. `const` faqat kompilyatsiya paytida maʼlum son, string va bool uchun.

**5. Konstantaning manzilini olish.** Bu xato videoda yoʻq, lekin kurs papkasida bor, `addr/main.go`:

```go filename="addr/main.go" showLineNumbers
package main

import "fmt"

const Port = 8080

func main() {
	fmt.Println(&Port) // ataylab xato: konstantaning xotirada manzili yoʻq
}
```

```console
$ go run addr/main.go
# command-line-arguments
addr/main.go:8:15: invalid operation: cannot take address of Port (untyped int constant 8080)
```

`cannot take address of Port` — «`Port` ning manzilini olib boʻlmaydi» (`Port` — server porti, 8080). `&` — qiymatning xotiradagi manzili
(pointer'lar keyingi darslarda). Go qoidasi boʻyicha `&` faqat oʻzgaruvchi kabi xotirada joyi bor qiymatga
qoʻyiladi (addressable), konstanta esa bunday emas. **Tuzatish:** avval
oʻzgaruvchiga qoʻying (`p := Port`, keyin `&p`). Go 1.26 dan `new(Port)` ham ishlaydi: u qiymat nusxasi bilan yangi
oʻzgaruvchi yaratadi.

## Oʻzingizni tekshiring

Avval oʻzingiz javob bering, keyin oching.

**1.** JavaScript `const` bilan Go `const` ning asosiy farqi nima?

<details>
<summary>Javob</summary>

Go `const` ning qiymati kompilyatsiya paytida maʼlum boʻlishi kerak (faqat son, string yoki bool; funksiya
chaqiruvi emas). JavaScript `const` esa faqat nomni qotiradi, qiymat ishlash paytida hisoblanadi.

</details>

**2.** `n := 2` boʻlsa, `time.Sleep(time.Duration(n))` qancha vaqt soʻraydi?

<details>
<summary>Javob</summary>

2 nanosekund. `time.Duration(n)` faqat turni oʻzgartiradi, birlik qoʻshmaydi. Ikki soniya uchun
`time.Duration(n) * time.Second` kerak.

</details>

**3.** `Nomalum, Yangi, Tolangan, Bekor` `iota` roʻyxatidan `Yangi` ni oʻchirsak, bazadagi `2` nimani bildiradi?
`ochirish/main.go` nima chiqaradi?

```go filename="ochirish/main.go" showLineNumbers
package main

import "fmt"

type Holat int

const (
	Nomalum Holat = iota
	// Yangi oʻchirildi → keyingilarning raqami bittaga kamaydi
	Tolangan // endi 1
	Bekor    // endi 2
)

const (
	Nomalum2  Holat = iota
	_               // Yangi oʻchirildi, lekin raqami band qoldi
	Tolangan2       // 2
	Bekor2          // 3
)

func main() {
	var saqlangan Holat = 2 // kecha: 2 = Tolangan
	fmt.Println(saqlangan == Tolangan, saqlangan == Bekor)
	fmt.Println(saqlangan == Tolangan2, saqlangan == Bekor2)
}
```

<details>
<summary>Javob</summary>

Birinchi blokda `2` endi `Bekor`, chunki keyingi raqamlar bittaga suriladi: `Tolangan` = 1, `Bekor` = 2. Ikkinchi
blokda oʻchirilgan `Yangi` oʻrnida `_` (boʻsh nom) turibdi: u raqamni band qiladi, shuning uchun `Tolangan2` yana 2.

```console
$ go run ochirish/main.go
false true
true false
```

</details>

**4.** [GO-1.02](/lab/youtube/go/go-1-02) dan: `var x int8 = 128` xato xabarida *(untyped int constant)* degan soʻz bor edi.
`x++` esa 127 dan −128 ga jim aylangan edi. Endi farqni bugungi soʻzlar bilan tushuntiring.

<details>
<summary>Javob</summary>

`128` — untyped constant: u `int8` turini ishlatilgan joydan, yaʼni oʻzgaruvchi eʼlonidan oladi. Go buni
kompilyatsiya paytida qiladi va 128 `int8` ga sigʻmasligini koʻradi. `x++` esa oʻzgaruvchidagi amal, u ishlash
paytida boʻladi va jim aylanadi.

</details>

🟡 `HolatNomi` har bir holatga nom beradi, `HolatNomdan` hamma holatni aylanib chiqib, nomi mosini qaytaradi:

```go filename="uyga/javob/orta/main.go" showLineNumbers
// 🟡 Javob: nom ↔ Holat. Bazada "paid" saqlansa, const blokidagi tartib oʻzgarsa ham maʼno buzilmaydi.
package main

import "fmt"

type Holat int

const (
	Nomalum Holat = iota
	Yangi
	Tolangan
	Bekor
)

func HolatNomi(h Holat) string {
	if h == Yangi {
		return "new"
	}
	if h == Tolangan {
		return "paid"
	}
	if h == Bekor {
		return "cancelled"
	}
	return "unknown"
}

func HolatNomdan(s string) (Holat, error) {
	for _, h := range []Holat{Nomalum, Yangi, Tolangan, Bekor} {
		if HolatNomi(h) == s {
			return h, nil
		}
	}
	return Nomalum, fmt.Errorf("nomaʼlum holat: %q", s)
}

func main() {
	h, err := HolatNomdan(HolatNomi(Tolangan))
	fmt.Println(HolatNomi(h), h, err)

	h, err = HolatNomdan("refund")
	fmt.Println(h, err)
}
```

```console
$ go run uyga/javob/orta/main.go
paid 2 <nil>
0 nomaʼlum holat: "refund"
```

`for _, h := range []Holat{…}` — roʻyxatdagi har bir holat ustida sikl (JS'dagi `for (const h of [...])` kabi;
`range` keyingi darslarda batafsil). `fmt.Errorf` — matnli `error` yasaydi, `%q` qiymatni qoʻshtirnoq ichida
yozadi. Bazada `"paid"` saqlansa, `const` blokidagi tartib oʻzgarsa ham maʼno buzilmaydi.

Qiyinroq vazifalar (`homework/README.md` da batafsil):

- 🟢 `Monday Weekday = iota + 1` bilan dushanba 1 dan boshlanadi, `0` esa «kun tanlanmagan» boʻlib qoladi:
  `homework/easy` → `1 5 7` va `0`. Standart `time.Weekday` da esa `Sunday Weekday = iota`, yakshanba 0.
- 🟡 `Read Perm = 1 << iota` → `001`, `010`, `100`: har bir flag alohida bit, `|` bilan birlashadi, `&` bilan
  tekshiriladi. `io/fs.FileMode` ham shunday qurilgan.
- 🟠 `1.5 * time.Second` → `1.5 (untyped float constant) truncated to int64`: untyped `1.5` `Duration` ga, yaʼni
  butun songa aniq aylanmaydi, konstanta esa yaxlitlanmaydi. Toʻgʻri yoʻllar: `1500 * time.Millisecond` yoki
  `time.Second * 3 / 2`, ikkalasi ham `1.5s`.
- 🔴 `January Month = 1 + iota`: oylar odamlar yozganidek 1 dan 12 gacha. Qiymat berilmagan `time.Month` 0, lekin
  0-oy yoʻq: `fmt` uni `%!Month(0)` deb chiqaradi. Go jamoasi bu yerda «raqam odamlar ishlatadigan raqamga teng
  boʻlsin» ni tanlagan.
