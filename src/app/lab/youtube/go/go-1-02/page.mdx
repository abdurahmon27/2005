## Nimani oʻrganasiz

Mashinaning kilometr hisoblagichida hamma raqamlar 9: **999 999**. Mashina yana bir kilometr yursa, hisoblagich nima
koʻrsatadi? Hamma gʻildirakcha birdan aylanadi va **000 000** chiqadi, hech qanday ogohlantirishsiz. Go'dagi baʼzi
sonlar ham xuddi shunday aylanadi, faqat ular minusga qaytadi. Bu darsda nega shunday ekanini koʻramiz.

**Bitta gʻoya:** son turi katakning kattaligini ham aytadi: `int8` katagiga faqat −128 dan 127 gacha son sigʻadi.
Sigʻmaydigan son dastur ishlayotganda hisoblansa, mashina hisoblagichi kabi jimgina aylanib, eng kichik songa
qaytadi. Oʻzgaruvchisiz, faqat sonlardan yozilgan boʻlsa esa Go uni tarjima paytida rad etadi.

Dars oxirida siz:

- `var x int8 = 127` qatorini oddiy soʻz bilan oʻqiy olasiz va `int8` katagiga qaysi sonlar sigʻishini bilasiz;
- `int8` dagi hisob qachon jim aylanishini, qachon esa Go dasturni umuman tarjima qilmasligini oldindan aytib bera
  olasiz;
- qiymat berilmagan oʻzgaruvchida nima turishini bilasiz;
- layk hisoblagichidagi yashirin xatoni topib, uni `int` bilan tuzata olasiz.

Bugun uchta yangi soʻz bor:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| `int8` | kichik katakli son turi: faqat −128 … 127 | int8 |
| toʻlib ketish | katakka sigʻmagan son aylanib, doiraning narigi tomoniga oʻtadi | overflow |
| nol qiymat | qiymat berilmagan katakda turadigan boshlangʻich qiymat: `0`, `false`, boʻsh matn | zero value |

Ikkita yordamchi soʻz ham uchraydi: **katak** (qiymat turadigan joy) va **`var`** (katak turini oʻzimiz yozadigan
yorliq).

Avval Go 0 ni eslaymiz. Bu kod ekranga qanday son chiqaradi? **A)** `127` · **B)** `128` · **C)** xato

```go
ochko := 127
ochko++
fmt.Println(ochko)
```

<details>
<summary>Javob</summary>

**B: `128`.** `ochko++` bu `ochko = ochko + 1` bilan bir xil: `ochko` ni bittaga oshiradi.

| Qator | `ochko` ostida | Ekranda |
|---|---|---|
| 1 `ochko := 127` | `127` | |
| 2 `ochko++` | `128` | |
| 3 `fmt.Println(ochko)` | `128` | `128` |

`:=` bu yerda oddiy `int` turini tanladi. `int` esa juda katta son sigʻdira oladi. Bugun esa kichik turni koʻramiz.

</details>

## Katak va uning kattaligi: `int8`

Go 0 dagi xotira rasmlarida yorliq ostida doim bir toʻrtburchak chizilgan edi: qiymat aynan unda turadi. Shu
toʻrtburchakni bundan buyon **katak** deymiz. Katak — qiymat turadigan joy. Yorliq esa katakka yopishtirilgan nom.

| Yorliq | Katak (qiymat) |
|---|---|
| `ochko` | `127` |

Endi hisoblagichni soddalashtiramiz. Unda faqat uchta gʻildirakcha bor, deylik. U 999 gacha sanay oladi, 1000 ga esa
joyi yoʻq. Shuning uchun oxirgi sondan keyin u eng kichik songa qaytadi:

```text
 [9][9][8]   →   [9][9][9]    →   [0][0][0]
                eng kattasi       eng kichigiga qaytdi
```

Kompyuter xotirasida ham katak cheksiz emas. Son turi faqat «bu butun son» demaydi, **katakning kattaligini ham
aytadi**. Go'da joyni tejash uchun kichik son turlari bor. Eng kichigining nomi **`int8`**:

| Tur | Katak | Eng kichik son | Eng katta son |
|---|---|---|---|
| `int8` | kichik | −128 | 127 |
| `int` | juda katta | −9 223 372 036 854 775 808 | 9 223 372 036 854 775 807 |

`int8` katagiga roppa-rosa 256 ta son sigʻadi: yarmi manfiy (−128 dan −1 gacha), yarmi 0 va musbat (0 dan 127
gacha). Bu chegaralar Go'ning rasmiy qoidasida (Go spec) yozilgan: *"int8 the set of all signed 8-bit integers (-128
to 127)"*, yaʼni «−128 dan 127 gacha boʻlgan hamma 8 bitli butun sonlar». Bit nima ekanini «Chuqurroq»
boʻlimida koʻramiz. Oddiy `int` esa juda katta katak. Jadvaldagi chegaralar shu kompyuterniki: baʼzi kompyuterlarda `int`
kichikroq boʻladi, lekin baribir `int8` dan juda katta.

## `var`: katak turini oʻzimiz yozamiz

`int8` katak yaratish uchun yangi soʻz kerak. `:=` turni oʻzi tanlaydi, butun son uchun esa doim oddiy `int` ni
oladi. Shuning uchun **`var`** soʻzini yozamiz:

```go
var x int8 = 127
```

Bu qatorni shunday oʻqing: **«`var`, `x`, `int8`, qiymati 127»**.

| Qism | Nima qiladi |
|---|---|
| `var` | yangi yorliq yaratadi (xuddi `:=` kabi) |
| `x` | yorliqning nomi |
| `int8` | katakning turi: biz uni oʻzimiz yozdik |
| `= 127` | katakka qoʻyiladigan boshlangʻich qiymat |

Bu yerdagi `=` yangi yorliq bilan birga yozilgan. Uni «qiymati» deb oʻqing, xuddi GO-0.02 da `ochko := 3` ni «qiymati
uch» deb oʻqiganimizdek.

| Qatordan keyin | Yorliq | Tur | Katakda |
|---|---|---|---|
| `var x int8 = 127` | `x` | `int8` | `127` |

## 127 ga bir qoʻshsak nima boʻladi?

Endi `x` ni bittaga oshirib, ekranga chiqaramiz. Bu kurs papkasidagi `aylanish/main.go`:

```go filename="aylanish/main.go" showLineNumbers
package main

import "fmt"

func main() {
	var x int8 = 127
	x++
	fmt.Println(x)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1–5 | `package main` … `func main() {` | birinchi darsdagi tanish qolip |
| 6 | `var x int8 = 127` | yangi `x` yorligʻi, turi `int8`, qiymati 127: katakdagi eng katta son |
| 7 | `x++` | `x` ni bittaga oshiradi: `x = x + 1` |
| 8 | `fmt.Println(x)` | `x` ostidagi qiymatni ekranga chiqaradi |
| 9 | `}` | `main` va dastur tugadi |

Yaʼni katakdagi eng katta songa bir qoʻshib, natijani koʻrmoqchimiz. Lekin 128 ga `int8` katagida joy yoʻq.
Hisoblagich oxirgi sondan keyin eng kichik songa qaytganini eslang. Ekranga nima chiqadi? **A)** `128` · **B)** xato ·
**C)** `-128`

<details>
<summary>Javob</summary>

**C: `-128`.** 127 — `int8` dagi eng katta son. Undan keyin, hisoblagichdagi kabi, eng kichik son keladi, yaʼni −128.
«`128`» ni tanlagan boʻlsangiz, `int8` katagi ham `int` kabi katta deb oʻylagansiz: 128 unga sigʻmaydi. «Xato» ni
tanlagan boʻlsangiz, Go buni xato deb toʻxtatadi deb kutgansiz. Lekin dastur ishlayotganda Go hech narsa demaydi.

</details>

`go run` dasturni tarjima qilib, darhol ishga tushiradi:

```console
$ go run aylanish/main.go
-128
```

`go run` xato ham, ogohlantirish ham bermadi. Dastur shunchaki boshqa son chiqardi.

## Sonlar doirasi: toʻlib ketish (overflow)

`int8` ga faqat −128 dan 127 gacha son sigʻadi. Bu sonlarni soat siferblati, yaʼni soat yuzi kabi doira boʻylab
tasavvur qiling. 127 dan keyin doira yopiladi va eng kichik son keladi:

```text
  … → 125 → 126 → 127 ──┐
                        │ +1: 128 ga joy yoʻq
  ┌─────────────────────┘
  └─► -128 → -127 → -126 → … → -1 → 0 → 1 → … → 126 → 127 ─┐
                                                            └─► yana -128 …
```

Shuning uchun 127 ga bir qoʻshsak, −128 chiqadi. Katakka sigʻmagan sonning shunday aylanib ketishi oʻzbekcha
**toʻlib ketish**, inglizcha **overflow** deyiladi.

Xotirada nima boʻldi:

| Qator | `x` (`int8`) | Ekranda |
|---|---|---|
| 6 `var x int8 = 127` | `127` | |
| 7 `x++` | `-128` (127 + 1 → doira: −128) | |
| 8 `fmt.Println(x)` | `-128` | `-128` |

Go'ning rasmiy qoidasi boʻyicha bu **xato emas**. Spec'da shunday yozilgan: bunday hisob natijasi *"exists and is
deterministically defined"* (aniq belgilangan) va *"Overflow does not cause a run-time panic"* (dastur
toʻxtamaydi). Qisqasi: son jim aylanadi, buni sezish dasturchining vazifasi.

## Qachon Go rad etadi

Endi oʻzgaruvchisiz, toʻgʻridan-toʻgʻri son yozamiz. Bu `sigmaydi/main.go`:

```go filename="sigmaydi/main.go" showLineNumbers
package main

import "fmt"

func main() {
	var x int8 = 128
	fmt.Println(x)
}
```

6-qatorda: `var`, `x`, `int8`, qiymati 128. Bu son kodning oʻzida turibdi, Go uni dastur ishga tushmasdan oldin koʻra
oladi. [GO-0.03](/lab/youtube/go/go-0-03) da Go turlar mos kelmasa, xatoni tarjima paytida koʻrsatganini eslang. Bu dastur
ishga tushadimi? **A)** `128` chiqadi · **B)** `-128` chiqadi · **C)** tarjima xatosi

<details>
<summary>Javob</summary>

**C: tarjima xatosi**, dastur ishga tushmadi. 128 `int8` ga sigʻmaydi va Go buni oldindan koʻrdi. «`-128`» ni
tanlagan boʻlsangiz, aylanish qoidasini bu yerga ham qoʻllagansiz. Lekin son jim aylanadigan holatda hisobda
oʻzgaruvchi bor edi (`x++`). Bu yerda esa hech qanday hisob yoʻq: faqat yozilgan son.

</details>

```console
$ go run sigmaydi/main.go
# command-line-arguments
sigmaydi/main.go:6:15: cannot use 128 (untyped int constant) as int8 value in variable declaration (overflows)
```

Birinchi qator — `go run` yozadigan sarlavha, bizga kerak emas. Ikkinchi qatorni oldingi darslardagidek oʻqiymiz:

- `sigmaydi/main.go:6:15` — fayl, **6-qator**, 15-belgi (qator boshidagi Tab ham sanaladi): bu `128` turgan joy.
- `cannot use 128` — «128 ni ishlatib boʻlmaydi».
- `(untyped int constant)` — «turi hali belgilanmagan butun son». Bu soʻzlar haqida [GO-1.03](/lab/youtube/go/go-1-03) da.
- `as int8 value in variable declaration` — «oʻzgaruvchi eʼlon qilinayotgan joyda `int8` qiymati sifatida».
- `(overflows)` — «toʻlib ketadi».

Go'ning rasmiy qoidasida ham shunday: son turga sigʻmasa, bu xato (*"It is an error if the constant value cannot be
represented as a value of the respective type"*). **Tuzatish:** `int8` ga sigʻadigan son yozing (127 yoki undan
kichik) yoki kattaroq tur tanlang, masalan `int`.

Xulosa: bir xil sigʻmaydigan son ikki xil natija beradi.

| Sigʻmaydigan son qayerdan chiqdi | Misol | Nima boʻladi |
|---|---|---|
| oʻzgaruvchisiz, faqat sonlardan | `var x int8 = 128` | Go uni **tarjima paytida rad etadi** 🛑 |
| hisobda oʻzgaruvchi qatnashdi | `x++` (`x` ostida 127) | natija **dastur ishlayotganda** chiqadi va son **jim aylanadi** 🔄 |

## Kichik sinov: `a = a + 50`

Oʻzingizni tekshiring. Bu `sinov/main.go`:

```go filename="sinov/main.go" showLineNumbers
package main

import "fmt"

func main() {
	var a int8 = 100
	a = a + 50
	fmt.Println(a)
}
```

- **6-qator:** `var`, `a`, `int8`, qiymati 100.
- **7-qator:** `a` endi `a + 50` boʻlsin.

Ekranga nima chiqadi? **A)** `150` · **B)** tarjima xatosi · **C)** manfiy son

<details>
<summary>Javob</summary>

**C: manfiy son, aniqrogʻi −106.** Hisobda `a` oʻzgaruvchisi qatnashdi, shuning uchun Go xato bermadi. 150 esa
`int8` ga sigʻmaydi. «`150`» ni tanlagan boʻlsangiz, katak kattaligini unutgansiz. «Tarjima xatosi» ni tanlagan
boʻlsangiz: 50 ham kodda yozilgan, lekin hisobda oʻzgaruvchi `a` bor. Bunday natija faqat dastur ishlayotganda
chiqadi.

Doira boʻylab sanaymiz. 100 dan 127 gacha 27 qadam. 50 dan yana 23 qadam qoldi: −128, −127, …, −106.

| Qadam | Son |
|---|---|
| boshida | `100` |
| 27-qadam | `127` (eng katta) |
| 28-qadam | `-128` (doira yopildi) |
| 50-qadam | `-106` |

</details>

```console
$ go run sinov/main.go
-106
```

## Nol qiymat (zero value): katak boʻsh qolmaydi

Yangi mashinaning hisoblagichi zavoddan nollar bilan chiqadi: **000 000**. Endi Go'da `var`, `y`, `int8` deymiz va
**qiymat bermaymiz**:

```go
var y int8
```

Katakda nima turadi? Ishora uchun yangi mashinani eslang. **A)** `0` · **B)** tasodifiy son · **C)** tarjima xatosi

<details>
<summary>Javob</summary>

**A: katakda `0` turadi.** Go qiymat berilmagan katakni hech qachon boʻsh yoki tasodifiy son bilan qoldirmaydi.
«Tasodifiy son» ni tanlagan boʻlsangiz: Go'da bunday boʻlmaydi, bu Go'ning rasmiy qoidasida yozilgan. «Tarjima
xatosi» ni tanlagan boʻlsangiz: `var` bilan qiymatsiz yorliq yaratish mumkin, faqat turini yozish kerak.

</details>

Endi uchta yorliqqa qiymat bermaymiz. Bu `nol/main.go`:

```go filename="nol/main.go" showLineNumbers
package main

import "fmt"

func main() {
	var y int8
	var tayyor bool
	var ism string
	fmt.Println(y, tayyor, "["+ism+"]")
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 6 | `var y int8` | yangi `y` yorligʻi, turi `int8`, qiymat berilmagan |
| 7 | `var tayyor bool` | yangi `tayyor` («tayyor») yorligʻi, turi `bool` (`true` yoki `false`), qiymat berilmagan |
| 8 | `var ism string` | yangi `ism` («ism») yorligʻi, turi `string` (matn), qiymat berilmagan |
| 9 | `fmt.Println(y, tayyor, "["+ism+"]")` | uchta qiymatni vergul bilan, bitta qatorda chiqaradi |

9-qatordagi `"["+ism+"]"` ga eʼtibor bering. Boʻsh matn ekranda koʻrinmaydi. Uni koʻrish uchun `ism` ni ikki kvadrat
qavs orasiga plyus bilan yopishtirdik ([GO-0.03](/lab/youtube/go/go-0-03) dagi matnlarni yopishtirish). `"["` va `"]"` —
qoʻshtirnoq ichidagi oddiy matn.

```console
$ go run nol/main.go
0 false []
```

| Yorliq | Tur | Katakda | Ekranda |
|---|---|---|---|
| `y` | `int8` | `0` | `0` |
| `tayyor` | `bool` | `false` | `false` |
| `ism` | `string` | `""` (boʻsh matn) | `[]` (qavslar orasida hech narsa yoʻq) |

Qiymat berilmagan katakda turadigan bunday qiymat oʻzbekcha **nol qiymat**, inglizcha **zero value** deyiladi.
Son uchun `0`, `bool` uchun `false`, matn uchun boʻsh matn. Go'ning rasmiy qoidasi: qiymat berilmagan oʻzgaruvchi
*"is given a default value"*, yaʼni oʻz turining nol qiymatini oladi.

## Layk hisoblagichidagi yashirin xato

Endi koʻp uchraydigan xato. Dasturchi rasmga bosilgan layklarni sanaydi va «joyni tejash» uchun `int8` tanlaydi.
Bu `layk/main.go`:

```go filename="layk/main.go" showLineNumbers
package main

import "fmt"

func main() {
	var layk int8
	for i := 1; i <= 200; i++ {
		layk++
	}
	fmt.Println(layk)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 6 | `var layk int8` | yangi `layk` yorligʻi, turi `int8`, qiymati yoʻq, demak nol qiymat: `0` |
| 7 | `for i := 1; i <= 200; i++ {` | [GO-0.05](/lab/youtube/go/go-0-05) dagi sikl: `i` 1 dan 200 gacha, yaʼni 200 marta aylanadi |
| 8 | `layk++` | har aylanada bitta layk qoʻshiladi |
| 9 | `}` | sikl guruhining oxiri |
| 10 | `fmt.Println(layk)` | sikl tugagach, `layk` ni bir marta chiqaradi |

Rasmga 200 marta layk bosildi. Ekranga nima chiqadi? **A)** `200` · **B)** tarjima xatosi · **C)** manfiy son

<details>
<summary>Javob</summary>

**C: manfiy son, aniqrogʻi −56.** 200 `int8` ga sigʻmaydi, hisobda esa `layk` oʻzgaruvchisi bor. Demak Go xato
bermaydi va son jim aylanadi. «`200`» ni tanlagan boʻlsangiz, katak kattaligini unutgansiz. «Tarjima xatosi» ni
tanlagan boʻlsangiz: kodda 200 dan katta hech qanday son yozilmagan, `layk` ga faqat birma-bir qoʻshilyapti.

</details>

```console
$ go run layk/main.go
-56
```

Xotirada nima boʻldi:

| Aylana (`i`) | `layk` (`int8`) |
|---|---|
| sikldan oldin | `0` |
| 1 | `1` |
| … | … |
| 127 | `127` (eng katta) |
| 128 | `-128` (doira yopildi) |
| … | … |
| 200 | `-56` |

128-laykda son manfiy tomonga oʻtdi. Qolgan 72 ta layk uni −128 dan −56 gacha olib keldi. Xato chiqmadi. Shuning
uchun bunday bug'ni, yaʼni yashirin xatoni, sezmay qolish oson: dastur ishlaydi, faqat notoʻgʻri son koʻrsatadi.

**Tuzatish oson:** `int8` oʻrniga oddiy `int` yozamiz. Bu `layk-int/main.go`, faqat 6-qator oʻzgardi:

```go filename="layk-int/main.go" showLineNumbers
package main

import "fmt"

func main() {
	var layk int
	for i := 1; i <= 200; i++ {
		layk++
	}
	fmt.Println(layk)
}
```

Endi ekranga nima chiqadi? 200, chunki `int` katagida joy yetarli:

```console
$ go run layk-int/main.go
200
```

Go'ning rasmiy qoʻllanmasi (*A Tour of Go*) ham shuni maslahat beradi: *"use int unless you have a specific reason to
use a sized or unsigned integer type"*, yaʼni alohida sabab boʻlmasa, `int` ishlating.

## Hayotda: Boeing 787

Bu faqat oʻquv misoli emas. 2015-yilda AQSh Federal aviatsiya boshqarmasi (FAA) Boeing 787 samolyotlari uchun majburiy
koʻrsatma chiqargan (AD 2015-09-07). Unda shunday yozilgan:

- generatorlarni boshqaradigan bloklar dasturidagi hisoblagich **248 kun** uzluksiz tok ostida ishlasa, toʻlib qoladi;
- shunda samolyot generator quvvatini butunlay yoʻqotishi va *"loss of control of the airplane"*, yaʼni
  boshqaruvdan chiqishi mumkin edi;
- yechim topilguncha samolyotni muntazam oʻchirib-yoqish buyurildi: oraliq **120 kundan oshmasin**.

Keyinroq, 2018-yilda, FAA yangi koʻrsatma bilan bloklarga yangi dastur oʻrnatishni talab qildi (AD 2018-20-15).
Koʻrsatmada hisoblagichning turi aytilmagan, shuning uchun biz ham uni taxmin qilmaymiz.

## Chuqurroq (ixtiyoriy): bitlar va two's complement

Agar endi boshlayotgan boʻlsangiz, bu boʻlimni keyinroq oʻqing. Darsning qolgan qismi unga bogʻliq emas.

**Nega aynan −128?** Kompyuter sonni chiroqchalarda saqlaydi: yoniq chiroqcha — 1, oʻchiq — 0. Bitta chiroqcha
**bit** deyiladi. `int8` da sakkizta bit bor (nomidagi 8 shu). Har bir bitning oʻz vazni (qiymati) bor. Yoniq
bitlarning vaznlari qoʻshiladi:

| Bit vazni | −128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 | Son |
|---|---|---|---|---|---|---|---|---|---|
| 127 | 0 | 1 | 1 | 1 | 1 | 1 | 1 | 1 | 64 + 32 + 16 + 8 + 4 + 2 + 1 = **127** |
| 127 + 1 | 1 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | **−128** |
| −1 | 1 | 1 | 1 | 1 | 1 | 1 | 1 | 1 | −128 + 127 = **−1** |

127 bu bitta 0 va yettita 1. Bir qoʻshsak, oʻngdagi birlar nolga aylanib, 1 chapga oʻtadi (oddiy qoʻshishdagi
«eslab qolish» kabi): 1 va yettita 0. Go eng chapdagi bitni plyus emas, **minus 128** deb hisoblaydi. Shuning uchun
`1000 0000` = −128. Eng chapdagi bitni manfiy vaznli deb hisoblaydigan bu usul **two's complement** deyiladi. Go'ning
rasmiy qoidasida butun sonlar aynan shunday saqlanishi yozilgan.

Buni oʻzingiz koʻrmoqchi boʻlsangiz, papkada `binary/main.go` bor:

```go filename="binary/main.go" showLineNumbers
package main

import "fmt"

func main() {
	var x int8 = 127
	fmt.Printf("%4d = %08b\n", x, uint8(x))
	x++
	fmt.Printf("%4d = %08b\n", x, uint8(x))
	x = -1
	fmt.Printf("%4d = %08b\n", x, uint8(x))
}
```

Bu yerda uchta yangi belgi bor, ular faqat chiqarish uchun kerak. `fmt.Printf` qolipga qarab chiqaradi: `%4d` sonni
4 ta joyga, `%08b` esa 8 ta bit qilib yozadi, `\n` qatorni tugatadi. `uint8(x)` — bitlarni minus belgisiz koʻrsatish
uchun; bunday yozuv (aylantirish) keyingi darslarda.

```console
$ go run binary/main.go
 127 = 01111111
-128 = 10000000
  -1 = 11111111
```

**Faqat sonlar: `int8(127) + 1`.** Yana bir misol, `constover/main.go`:

```go filename="constover/main.go" showLineNumbers
package main

import "fmt"

func main() {
	fmt.Println(int8(127) + 1)
}
```

`int8(127)` — «127, turi `int8`». Bu yerda ham oʻzgaruvchi yoʻq, faqat sonlar. Shuning uchun Go uni tarjima paytida
rad etadi:

```console
$ go run constover/main.go
# command-line-arguments
constover/main.go:6:14: int8(127) + 1 (constant 128 of type int8) overflows int8
```

`overflows int8` — «`int8` dan toʻlib ketadi». Kodga oʻzgaruvchisiz yozilgan bunday sonlar **konstanta** deyiladi
(*constant 128 of type int8* — «`int8` turidagi konstanta 128»). Nega Go ularni bunchalik qattiq tekshirishini keyingi
darsda koʻramiz: [GO-1.03 · Konstantalar va iota](/lab/youtube/go/go-1-03).

## Koʻp uchraydigan xatolar

**1. «Go overflow'ni xato deb toʻxtatadi» deb oʻylash.** Bu mavzudagi eng klassik xato tushuncha. Dastur ishlayotganda
Go hech narsa demaydi: `int8` dagi 127 ga bir qoʻshsangiz, jimgina −128 chiqadi. Toʻliq misol yuqoridagi «Layk
hisoblagichidagi yashirin xato» boʻlimida: 200 ta layk `-56` boʻlib chiqdi. Belgisi: xato xabari yoʻq, lekin son
notoʻgʻri (koʻpincha kutilmaganda manfiy). **Tuzatish:** alohida sabab boʻlmasa, `int` ishlating.

**2. «Joyni tejash» uchun kichik tur tanlash.** `int8` sanagich yoki hisoblagich uchun juda kichik: 128-qadamdayoq
aylanadi. Bu ham yuqoridagi layk misoli. **Tuzatish:** oddiy `int`. Kichik tur faqat qiymat chegarasi aniq
maʼlum boʻlganda kerak.

**3. Sigʻmaydigan sonni toʻgʻridan-toʻgʻri yozish.** `var x int8 = 128`:

```console
$ go run sigmaydi/main.go
# command-line-arguments
sigmaydi/main.go:6:15: cannot use 128 (untyped int constant) as int8 value in variable declaration (overflows)
```

Xabarni oʻqiymiz: `sigmaydi/main.go` fayli, **6-qator**, 15-belgi; `cannot use 128` — «128 ni ishlatib boʻlmaydi»;
`(overflows)` — «toʻlib ketadi». Batafsil tahlil «Qachon Go rad etadi» boʻlimida. **Tuzatish:** sonni `int8`
chegarasiga keltiring (−128 … 127) yoki `int` tanlang.

## Oʻzingizni tekshiring

Avval oʻzingiz javob bering, keyin oching.

**1.** `int8` dagi 127 ga bir qoʻshsak (`x++`), nima chiqadi?

<details>
<summary>Javob</summary>

`-128`. Son jim aylanadi: bu overflow (toʻlib ketish). Go xato ham, ogohlantirish ham bermaydi.

</details>

**2.** `var x int8 = 128` nega ishga tushmaydi?

<details>
<summary>Javob</summary>

Bu yerda faqat son bor, oʻzgaruvchi qatnashgan hisob yoʻq. Go 128 ni oldindan koʻradi va u `int8` ga sigʻmagani uchun
dasturni tarjima paytida rad etadi (`cannot use 128 … (overflows)`).

</details>

**3.** Qiymat berilmagan `bool` yorligʻida (`var tayyor bool`) nima turadi?

<details>
<summary>Javob</summary>

`false`: bu `bool` turining nol qiymati (zero value). `int8` da `0`, matnda boʻsh matn turadi.

</details>

**4.** Bu kod nimani chiqaradi? **A)** `130` · **B)** tarjima xatosi · **C)** `-126`

```go
var c int8 = 120
c = c + 10
fmt.Println(c)
```

<details>
<summary>Javob</summary>

**C: `-126`.** Hisobda `c` oʻzgaruvchisi bor, shuning uchun xato yoʻq va son jim aylanadi. 120 dan 127 gacha 7 qadam,
qolgan 3 qadam: −128, −127, −126. Bu misol kurs papkasida yoʻq, uni alohida ishga tushirdik:

```go
package main

import "fmt"

func main() {
	var c int8 = 120
	c = c + 10
	fmt.Println(c)
}
```

```console
$ go run takror/main.go
-126
```

</details>

**5.** [GO-0.05](/lab/youtube/go/go-0-05) dan: `for i := 1; i <= 200; i++ { … }` sikli necha marta aylanadi?

<details>
<summary>Javob</summary>

200 marta. `i` 1 dan boshlanadi, `i` 200 boʻlganda ham `200 <= 200` → `true`, 201 da esa `false`. Shuning uchun layk
dasturida `layk++` roppa-rosa 200 marta bajarildi.

</details>

<details>
<summary>Javob</summary>

🟢 `i <= 127` boʻlsa, `127` chiqadi: son hali sigʻadi. `i <= 128` boʻlsa, `-128` chiqadi: 128-laykda son doiraning

```go filename="uyga/javob/orta/main.go" showLineNumbers
package main

import "fmt"

func main() {
	var son int16
	for i := 1; i <= 100000; i++ {
		son++
		if son < 0 {
			fmt.Println(i, son)
			break
		}
	}
}
```

```console
$ go run uyga/javob/orta/main.go
32768 -32768
```

32768-qadamda `int16` 32767 dan −32768 ga aylanadi. Qoida `int8` dagi bilan bir xil, faqat doira kattaroq.

🟡 `int32` ning eng katta qiymati 2 147 483 647 sekund, bu 2038-yil 19-yanvar, 03:14:07 (UTC). Bir sekunddan keyin

🟠 Overflow faqat bir xil ishorali ikki son qoʻshilganda boʻladi va bunda natijaning ishorasi oʻzgaradi. Ikki musbat
sonning yigʻindisi manfiy chiqsa (yoki aksincha), overflow boʻlgan.

```console
$ go run homework/guru/main.go

5 128
```

🔴 `int8` doirasi nosimmetrik: −128 bor, +128 yoʻq. Shuning uchun `-(-128)` ham toʻlib ketadi va yana `-128` chiqadi.
Yechim: natijani kattaroq turda (`int16`) qaytarish.

</details>
