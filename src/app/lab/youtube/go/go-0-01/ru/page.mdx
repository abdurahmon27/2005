## Что вы узнаете

Откуда калькулятор в вашем телефоне знает, что два плюс два — четыре? Кто-то шаг за шагом написал ему, что делать.
В этом уроке вы тоже впервые сами дадите компьютеру письменную команду.

**Одна идея:** программа — это список команд, который компьютер выполняет сверху вниз. Компилятор переводит её на
язык компьютера; если неверна хотя бы одна буква, он останавливается и говорит, в каком файле и в какой строке
ошибка.

К концу урока вы сможете:

- прочитать простыми словами семь строк первой программы на Go;
- запустить её в браузере ([go.dev/play](https://go.dev/play)) и на своём компьютере (`go run main.go`);
- разобрать по частям сообщение об ошибке вроде `./main.go:6:6`: какой файл, какая строка, какой символ, что
  случилось.

Сегодня всего три новых слова:

| Слово | Простой смысл | По-английски |
|---|---|---|
| программа | список команд для компьютера, как рецепт | program |
| компилятор | переводчик: переводит код на язык компьютера | compiler |
| терминал | окно, в котором вы пишете компьютеру команды, как в переписке | terminal |

## Программа — рецепт для компьютера

Компьютер сам ничего не знает: ему нужно сказать каждый шаг. Представьте рецепт плова:

1. нарежьте лук;
2. обжарьте морковь;
3. засыпьте рис.

Повар выполняет список сверху вниз, шаг за шагом. Компьютер тоже выполняет список команд сверху вниз, строка за
строкой. Список команд, написанный для компьютера, называется **программой**, по-английски **program**.

| На кухне | В компьютере |
|---|---|
| рецепт (список шагов) | программа |
| написать рецепт | написать **код**, то есть текст программы |
| приготовить плов | **запустить** программу |

Языков для написания программ много. Наш язык называется **Go**.

## Компилятор — переводчик

Мы пишем код словами, которые может прочитать человек. А компьютер понимает только свой язык из нулей и единиц.
Значит, между нами нужен переводчик. Программа, которая переводит код на язык компьютера, называется **компилятором**,
по-английски **compiler**.

```text
 код (текст, который мы написали)
        │
        ▼
 компилятор (переводчик) ──► если есть ошибка: останавливается и говорит где
        │
        ▼
 0101… (язык компьютера)
```

Компилятор очень строгий. Если в команде неверна хотя бы одна буква, он не переводит и говорит, где ошибка. Вы
увидите это своими глазами в конце урока.

## Первая программа строка за строкой

Вот наша первая программа. Она выводит на экран `Salom, dunyo!` («Привет, мир!» по-узбекски). Это файл `main.go` из
папки курса:

```go filename="main.go" showLineNumbers
package main

import "fmt"

func main() {
	fmt.Println("Salom, dunyo!")
}
```

Имя файла — `main.go`. `.go` в конце («точка go») означает, что это код на Go. Теперь прочитаем каждую строку:

| Строка | Код | Что делает |
|---|---|---|
| 1 | `package main` | `package` — «набор». `package main` значит «это программа, которую можно запустить»; `main` по-английски «главный» |
| 2 | (пусто) | ничего: оставлена пустой, чтобы было легче читать |
| 3 | `import "fmt"` | `import` — «привезти, подключить». `fmt` (сокращение от «format») — готовый ящик с инструментами, который идёт вместе с Go |
| 4 | (пусто) | ничего |
| 5 | `func main() {` | `func` создаёт группу команд, у этой группы имя `main`. `{` — начало группы |
| 6 | `fmt.Println("Salom, dunyo!")` | выводит на экран одну строку: `Salom, dunyo!` |
| 7 | `}` | конец группы |

Теперь о каждой части подробнее.

**Строка 1: `package main`.** Первое слово в этом файле — `package`, то есть «набор». `package main` говорит Go:
«этот файл — программа, которую можно запустить».

**Строка 3: `import "fmt"`.** `import` значит «подключить». `fmt` — готовый ящик с инструментами, который идёт
вместе с Go. В нём есть инструменты для вывода на экран. Программисты называют такой ящик **пакетом**. Имя ящика
написано в кавычках, потому что **кавычки** (`"`) отмечают начало и конец текста.

**Строка 5: `func main() {`.** Слово `func` создаёт группу команд, у этой группы имя `main`. Программисты называют
такую именованную группу **функцией**; это слово вы будете часто слышать в следующих уроках. Строки выше
представляют файл, а наши команды начинаются именно в этой группе. Фигурные скобки `{` и `}` отмечают начало и
конец группы. Круглые скобки `()` после `main` разберём позже: пока в этой строке они всегда пишутся так.

**Строка 6: `fmt.Println("Salom, dunyo!")`.** Это самая важная строка. `fmt.Println` — «инструмент `Println` из ящика
`fmt`»: точка посередине значит «внутри ящика». `Println` — по-английски *print line*, то есть «выведи одну
строку». В скобках, между кавычками, стоит текст, который появится на экране. Отступ в начале строки ставится
клавишей **Tab** (в коде на Go отступ всегда делают табом). Этот Tab понадобится нам в конце урока.

Коротко, в программе четыре части:

| # | Часть | Простыми словами |
|---|---|---|
| 1 | `package main` | это программа |
| 2 | `import "fmt"` | ящик с инструментами |
| 3 | `func main() { … }` | место, откуда всё начинается |
| 4 | `fmt.Println(…)` | команда, которая пишет на экран |

## Запускаем в браузере: go.dev/play

Самый простой путь — браузер. Откройте страницу [go.dev/play](https://go.dev/play) на официальном сайте Go; ничего
устанавливать не нужно. Это **Go Playground**, то есть «игровая площадка Go».

1. В большом окне на странице стоит готовый пример. Удалите его.
2. Напишите наши семь строк (или скопируйте их сверху).
3. Нажмите кнопку **Run** («запустить») вверху.
4. Результат появится внизу.

Прежде чем нажать, предположите: что появится внизу?

**A)** `Salom, dunyo!` (без кавычек) · **B)** `"Salom, dunyo!"` (с кавычками) · **C)** вся строка 6:
`fmt.Println("Salom, dunyo!")`

<details>
<summary>Ответ</summary>

**A.** На экране появится только `Salom, dunyo!`, без кавычек. Кавычки — не часть текста, они только отмечали его
границы. Если вы выбрали **B**, вы считали кавычки частью текста. Если вы выбрали **C**, вы думали, что компьютер
копирует код на экран: на самом деле он **выполняет** команду, а на экран попадает только текст, который она
выводит.

</details>

В нижней части Playground появится вот что:

```text
Salom, dunyo!

Program exited.
```

`Program exited.` написала не ваша программа. Это добавляет сам Playground: «программа завершила работу».

## На своём компьютере: терминал

Теперь запустим программу на своём компьютере. Для этого нужно окно, в котором компьютеру пишут команды. Это похоже
на переписку: вы пишете одну строку и нажимаете **Enter**, а компьютер пишет ответ ниже. Такое окно называется
**терминалом**.

```text
 ┌─ терминал ─────────────────────────────────┐
 │ $ go version                  ← пишете вы   │
 │ go version go1.26.8 linux/amd64  ← ответ    │
 │ $ █                           ← пишите ещё  │
 └─────────────────────────────────────────────┘
```

Знак в начале строки (на этой странице `$`, в Windows `C:\Users\…>`) — это знак терминала «пишите здесь». Его вы
**не пишете**, пишете только команду после него.

Например, команда `go version` сообщает версию Go:

```console
$ go version
go version go1.26.8 linux/amd64
```

`go1.26.8` — номер версии; у вас может быть новее, это нормально. Последнее слово — тип вашего компьютера: у вас
может быть `windows/amd64` или `darwin/arm64` (Mac).

### Установка Go: 4 шага

Чтобы эта команда работала, сначала установим Go.

1. Скачайте файл со страницы [go.dev/dl](https://go.dev/dl): для Windows `.msi`, для Mac `.pkg`.
2. Откройте файл и следуйте подсказкам (в Windows вы нажимаете **Next**; если спросит разрешение, нажмите **Да**).
3. Откройте терминал. В Windows найдите `cmd` в меню «Пуск». На Mac нажмите Command + Пробел и напишите `Terminal`.
   В Linux (Ubuntu) нажмите Ctrl + Alt + T.
4. Напишите `go version` и нажмите Enter. Если появился ответ, как выше, Go установлен.

Если вместо этого появилось `command not found` или `'go' is not recognized`, откройте терминал заново (или
перезагрузите компьютер). Установщик передаёт новую настройку только новым окнам. Подробный путь для Mac и Linux
есть в файле README (файл с пояснениями) в папке курса и в официальной [инструкции](https://go.dev/doc/install).

### Сохраняем файл и открываем терминал в папке

1. Создайте на компьютере новую папку, например `salom`.
2. Напишите семь строк в «Блокноте» (Notepad) или в бесплатном [VS Code](https://code.visualstudio.com).
3. Сохраните файл в эту папку под именем `main.go`. В «Блокноте» выберите «Тип файла» **Все файлы**, иначе файл
   станет `main.go.txt`.
4. Откройте терминал в этой папке. В Windows откройте папку, напишите `cmd` в адресной строке наверху и нажмите
   Enter: терминал откроется именно в этой папке. В VS Code выберите в меню **Terminal → New Terminal**.

## `go run main.go`: перевести и запустить

Теперь пишем в терминале `go run main.go`. Это значит «запусти `main.go`»:

```console
$ go run main.go
Salom, dunyo!
```

Результат такой же, как в браузере: `Salom, dunyo!`. Строки `Program exited.` на этот раз нет, потому что её
добавляет только Playground. Если появилась ошибка «файл не найден», терминал открыт в другой папке (см. ниже,
«Частые ошибки», пункт 2).

Быстрый вопрос. Компьютер ведь не понимает наш код. Что же тогда произошло внутри `go run`?

**A)** код сработал сам · **B)** сначала перевод, потом запуск · **C)** код отправили в интернет

<details>
<summary>Ответ</summary>

**B.** `go run` сначала переводит код на язык компьютера с помощью компилятора, а потом сразу запускает перевод.
Коротко: компьютер выполняет не наш текст, а его перевод. **A** невозможно: компьютер понимает только свой язык.
**C** тоже неверно: `go run` делает всё на вашем компьютере, без интернета.

</details>

```text
 main.go (наш код)
     │  go run
     ▼
 компилятор: переводит
     │
     ▼
 язык компьютера ──► запускается ──► на экране: Salom, dunyo!
```

## Ошибка нарочно: маленькая `p`

Теперь нарочно сделаем ошибку. В строке 6 заменим заглавную `P` в слове `Println` на маленькую `p`. Для человека это
почти то же слово. В папке курса эта ошибка уже готова в файле `xato/main.go` (`xato` — «ошибка»):

```go filename="xato/main.go" showLineNumbers
package main

import "fmt"

func main() {
	fmt.println("Salom, dunyo!")
}
```

Что теперь сделает `go run main.go`?

**A)** всё равно выведет `Salom, dunyo!` · **B)** Go выдаст сообщение об ошибке · **C)** Go сам исправит ошибку и
запустит программу

<details>
<summary>Ответ</summary>

**B.** Компилятор не узнал слово с маленькой `p` и не стал переводить. Программа вообще не запустилась: на экране
нет `Salom, dunyo!`, только сообщение об ошибке. Если вы выбрали **A** или **C**, вы думали, что компьютер понимает
«примерно», как человек. Компилятор не угадывает и ничего не исправляет сам: он только говорит, где ошибка.

</details>

В терминале заходим в папку `xato` (`cd` — команда «зайти в папку») и запускаем:

```console
$ cd xato && go run main.go
# command-line-arguments
./main.go:6:6: undefined: fmt.println (but have Println)
```

Первая строка, `# command-line-arguments`, — заголовок: «я переводил файлы, указанные в команде». Нужное нам —
во второй строке.

### Читаем сообщение об ошибке

Сообщение об ошибке выглядит страшно, но в нём точный адрес ошибки. Разберём его по частям:

| Часть | Смысл |
|---|---|
| `./main.go` | файл: `./` значит «в этой папке», то есть `main.go` в этой папке |
| `6` (первое число) | **строка**: 6-я строка |
| `6` (второе число) | **символ**: 6-й символ в строке (программисты называют это столбцом, *column*) |
| `undefined: fmt.println` | «не определено»: Go не знает имени `println` в ящике `fmt` |
| `(but have Println)` | подсказка: «но есть `Println`», то есть с заглавной `P` |

Почему 6-й символ — это именно маленькая `p`? Потому что Tab в начале строки тоже считается одним символом:

| Номер символа | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| В строке 6 | Tab | `f` | `m` | `t` | `.` | `p` |

### Исправляем

Снова делаем букву заглавной (`fmt.Println`) и запускаем ещё раз. В папке с исходным `main.go`:

```console
$ go run main.go
Salom, dunyo!
```

`Salom, dunyo!` вернулось. Отсюда два правила:

- **Go различает заглавные и маленькие буквы:** `Println` и `println` — два разных имени.
- **Если появилась ошибка:** сначала найдите файл и строку, потом прочитайте сообщение. Если ошибок несколько,
  начинайте с первой.

Сегодня вы прочитали свою первую программу, запустили её и прочитали её ошибку. В следующем уроке
([GO-0.02 · Переменная — ярлык, приклеенный к значению](/lab/youtube/go/go-0-02/ru)) посмотрим, как программа запоминает
информацию.

## Частые ошибки

**1. Мысль «компьютер понимает примерно».** Это самое частое неверное представление в этой теме. Человек прочитает
`println` как `Println`, а компилятор — нет. Мы видели это выше, в разделе «Ошибка нарочно»:
`undefined: fmt.println (but have Println)`. **Исправление:** пишите буквы так, как подсказывает сообщение.

**2. Терминал открыт в другой папке или имя файла неверное.** Если написать `go run main.go` в папке, где нет
`main.go` (вывод получен в Linux):

```console
$ go run main.go
stat main.go: no such file or directory
```

`no such file or directory` — «нет такого файла или папки». В Windows сообщение другое, но смысл тот же: файл не
найден. **Исправление:** откройте терминал в папке, где лежит `main.go`. Проверьте, что имя файла не стало
`main.go.txt`: в Проводнике (окно папок Windows) включите **Вид → Расширения имён файлов**, и полное имя файла
станет видно.

**3. Отступ сделан четырьмя пробелами, а не табом.** Программа всё равно работает, только номер символа в сообщении
об ошибке будет другим. Например, если в `xato/main.go` поставить вместо таба четыре пробела:

```go
package main

import "fmt"

func main() {
    fmt.println("Salom, dunyo!")
}
```

```console
$ go run main.go
# command-line-arguments
./main.go:6:9: undefined: fmt.println (but have Println)
```

Теперь `6:9`: четыре пробела — символы 1–4, `fmt.` — 5–8, а `p` — 9-й символ. Ошибка та же, только счёт другой.
**Исправление:** делайте отступ табом (VS Code делает это сам).

**4. Кавычки стали «фигурными».** Некоторые текстовые редакторы (программы для набора текста), например TextEdit на
Mac, превращают `"` в `“ ”`. Go их не узнаёт:

```go
package main

import "fmt"

func main() {
	fmt.Println(“Salom, dunyo!”)
}
```

```console
$ go run main.go
# command-line-arguments
./main.go:6:14: invalid character U+201C '“' in identifier
./main.go:6:29: syntax error: unexpected ! in argument list; possibly missing comma or )
./main.go:6:30: invalid character U+201D '”' in identifier
```

`invalid character U+201C '“'` — «недопустимый символ: `“`». Читаем первое сообщение: строка 6, символ 14 — именно
открывающая кавычка. Остальные две строки — продолжение той же ошибки. **Исправление:** пользуйтесь VS Code или в
TextEdit выберите Format → **Make Plain Text** и выключите Edit → Substitutions → **Smart Quotes**.

(Примеров 2, 3 и 4 нет в папке курса: они запускались в отдельной папке. Программы в примерах 3 и 4 — изменённые
копии `xato/main.go` и `main.go`.)
