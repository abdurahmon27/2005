## Dastur — kompyuter uchun retsept

Kompyuter oʻzi hech narsa bilmaydi: unga har bir qadamni aytish kerak. Osh retseptini tasavvur qiling:

1. piyozni toʻgʻrang;
2. sabzini qovuring;
3. guruchni soling.

Oshpaz roʻyxatni tepadan pastga, qadamma-qadam bajaradi. Kompyuter ham buyruqlar roʻyxatini tepadan pastga,
qatorma-qator bajaradi. Kompyuter uchun yozilgan buyruqlar roʻyxati **dastur** deyiladi, inglizcha **program**.

| Oshxonada | Kompyuterda |
|---|---|
| retsept (qadamlar roʻyxati) | dastur |
| retseptni yozish | **kod** yozish, yaʼni dastur matnini yozish |
| oshni pishirish | dasturni **ishga tushirish** |

Dastur yoziladigan tillar koʻp. Bizning tilimiz **Go** deb ataladi.

## Kompilyator — tarjimon

Biz kodni odam oʻqiy oladigan soʻzlar bilan yozamiz. Kompyuter esa faqat nol va birlardan iborat oʻz tilini
tushunadi. Demak, oʻrtada tarjimon kerak. Kodni kompyuter tiliga tarjima qiladigan dastur **kompilyator** deyiladi,
inglizcha **compiler**.

```text
 kod (biz yozgan matn)
        │
        ▼
 kompilyator (tarjimon) ──► xato boʻlsa: toʻxtaydi va joyini aytadi
        │
        ▼
 0101… (kompyuter tili)
```

Kompilyator juda talabchan. Buyruqdagi bitta harf notoʻgʻri boʻlsa ham, u tarjima qilmaydi va xato qayerda ekanini
aytadi. Buni dars oxirida oʻz koʻzingiz bilan koʻrasiz.

## Birinchi dastur qatorma-qator

Mana birinchi dasturimiz. U ekranga `Salom, dunyo!` deb yozadi (oʻzbekcha «Hello, world!»). Bu kurs papkasidagi
`main.go` fayli:

```go filename="main.go" showLineNumbers
package main

import "fmt"

func main() {
	fmt.Println("Salom, dunyo!")
}
```

Fayl nomi `main.go`. Oxiridagi `.go` («nuqta go») bu fayl Go kodi ekanini bildiradi. Endi har bir qatorni oʻqiymiz:

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1 | `package main` | `package` — «toʻplam». `package main` «bu ishga tushadigan dastur» degani; `main` inglizcha «asosiy» |
| 2 | (boʻsh) | hech narsa: oʻqish oson boʻlishi uchun qoldirilgan |
| 3 | `import "fmt"` | `import` — «olib kelish». `fmt` (format soʻzining qisqasi) — Go bilan birga keladigan tayyor asboblar qutisi |
| 4 | (boʻsh) | hech narsa |
| 5 | `func main() {` | `func` buyruqlar guruhini yaratadi, bu guruhning nomi `main`. `{` guruhning boshi |
| 6 | `fmt.Println("Salom, dunyo!")` | ekranga bitta qator chiqaradi: `Salom, dunyo!` |
| 7 | `}` | guruhning oxiri |

Endi har bir qism haqida batafsilroq.

**1-qator: `package main`.** Bu fayldagi birinchi soʻz `package`, yaʼni «toʻplam». `package main` Go'ga «bu fayl
ishga tushadigan dastur» deb aytadi.

**3-qator: `import "fmt"`.** `import` «olib kelish» degani. `fmt` — Go bilan birga keladigan tayyor asboblar qutisi.
Unda ekranga yozish asboblari bor. Dasturchilar bunday qutini **paket** deyishadi. Qutining nomi qoʻshtirnoq ichida
yozilgan, chunki **qoʻshtirnoq** (`"`) matnning boshi va oxirini belgilaydi.

**5-qator: `func main() {`.** `func` soʻzi buyruqlar guruhini yaratadi, bu guruhning nomi `main`. Dasturchilar nomi
bor bunday guruhni **funksiya** deyishadi; bu soʻzni keyingi darslarda koʻp eshitasiz. Tepadagi qatorlar faylni
tanishtiradi, bizning buyruqlarimiz esa aynan shu guruhdan boshlanadi. Jingalak qavslar `{` va `}` guruhning boshi
va oxirini belgilaydi. `main` dan keyingi oddiy qavslar `()` ni keyinroq koʻramiz: hozircha ular shu qatorda doim
shunday yoziladi.

**6-qator: `fmt.Println("Salom, dunyo!")`.** Bu eng muhim qator. `fmt.Println` — «`fmt` qutisidagi `Println`
asbobi»: oʻrtadagi nuqta «qutining ichidagi» degani. `Println` inglizcha *print line*, yaʼni «bitta qator chiqar».
Qavs ichida, qoʻshtirnoqlar orasida ekranga chiqadigan matn turibdi. Qator boshidagi surilish klaviaturadagi **Tab**
tugmasi bilan qoʻyiladi (Go kodida surilish doim Tab bilan yoziladi). Bu Tab dars oxirida bizga kerak boʻladi.

Qisqasi, dasturda toʻrt qism bor:

| # | Qism | Oddiy soʻz bilan |
|---|---|---|
| 1 | `package main` | bu dastur |
| 2 | `import "fmt"` | asboblar qutisi |
| 3 | `func main() { … }` | boshlanish joyi |
| 4 | `fmt.Println(…)` | ekranga yozadigan buyruq |

## Brauzerda ishga tushiramiz: go.dev/play

Eng oson yoʻl — brauzer. Go'ning rasmiy saytidagi [go.dev/play](https://go.dev/play) sahifasini oching, hech narsa
oʻrnatmaysiz. Bu **Go Playground**, yaʼni «Go oʻyin maydonchasi».

1. Sahifada katta oynada tayyor misol turadi. Uni oʻchiring.
2. Bizning yetti qatorimizni yozing (yoki yuqoridan koʻchirib qoʻying).
3. Tepadagi **Run** («ishga tushir») tugmasini bosing.
4. Natija pastda chiqadi.

Bosishdan oldin taxmin qiling: pastda nima chiqadi?

**A)** `Salom, dunyo!` (qoʻshtirnoqsiz) · **B)** `"Salom, dunyo!"` (qoʻshtirnoqlari bilan) · **C)** butun 6-qator:
`fmt.Println("Salom, dunyo!")`

<details>
<summary>Javob</summary>

**A.** Ekranda faqat `Salom, dunyo!` chiqadi, qoʻshtirnoqsiz. Qoʻshtirnoq matnning bir qismi emas, faqat uning
chegarasi edi. **B** ni tanlagan boʻlsangiz, qoʻshtirnoqni matnning oʻzi deb oʻylagansiz. **C** ni tanlagan boʻlsangiz,
kompyuter kodni ekranga koʻchiradi deb oʻylagansiz: aslida u buyruqni **bajaradi**, ekranga esa faqat buyruq
chiqargan matn tushadi.

</details>

Playground'ning pastki qismida shunday chiqadi:

```text
Salom, dunyo!

Program exited.
```

`Program exited.` sizning dasturingiz yozgan narsa emas. Uni Playground'ning oʻzi qoʻshadi: «dastur ishini tugatdi»
degani.

## Oʻz kompyuteringizda: terminal

Endi dasturni oʻz kompyuterimizda ishga tushiramiz. Buning uchun kompyuterga yozib buyruq beradigan oyna kerak.
Bu xuddi yozishmaga oʻxshaydi: siz bir qator yozib **Enter** bosasiz, kompyuter javobni pastga yozadi. Bu oyna
**terminal** deyiladi.

```text
 ┌─ terminal ─────────────────────────────────┐
 │ $ go version                  ← siz yozasiz │
 │ go version go1.26.8 linux/amd64  ← javob    │
 │ $ █                           ← yana yozing │
 └─────────────────────────────────────────────┘
```

Qator boshidagi belgi (bu sahifada `$`, Windows'da `C:\Users\…>`) — terminalning «yozing» degan belgisi. Uni
**yozmaysiz**, faqat undan keyingi buyruqni yozasiz.

Masalan, `go version` buyrugʻi Go'ning versiyasini aytadi:

```console
$ go version
go version go1.26.8 linux/amd64
```

`go1.26.8` — versiya raqami; sizda yangiroq boʻlishi normal. Oxirgi soʻz — kompyuteringiz turi: sizda
`windows/amd64` yoki `darwin/arm64` (Mac) boʻlishi mumkin.

### Go'ni oʻrnatish: 4 qadam

Bu buyruq ishlashi uchun avval Go'ni oʻrnatamiz.

1. [go.dev/dl](https://go.dev/dl) sahifasidan faylni yuklab oling: Windows uchun `.msi`, Mac uchun `.pkg`.
2. Faylni oching va koʻrsatmalarga amal qiling (Windows'da **Next** bosib borasiz; ruxsat soʻrasa, **Ha** bosing).
3. Terminalni oching. Windows'da Start menyusida `cmd` deb qidiring. Mac'da Command + Probel bosib, `Terminal` deb
   yozing. Linux'da (Ubuntu) Ctrl + Alt + T.
4. `go version` deb yozing va Enter bosing. Yuqoridagi kabi javob chiqsa, Go oʻrnatildi.

`go version` oʻrniga `command not found` yoki `'go' is not recognized` chiqsa, terminalni (yoki kompyuterni) qayta
oching. Oʻrnatuvchi yangi sozlamani faqat yangi ochilgan oynalarga beradi. Mac va Linux uchun batafsil yoʻl kurs
papkasidagi README faylida (yaʼni tushuntirish faylida) va rasmiy [yoʻriqnomada](https://go.dev/doc/install).

### Faylni saqlash va terminalni papkada ochish

1. Kompyuterda yangi papka oching, masalan `salom`.
2. Yetti qatorni Bloknot (Notepad) yoki bepul [VS Code](https://code.visualstudio.com) dasturida yozing.
3. Faylni shu papkaga `main.go` nomi bilan saqlang. Bloknot'da «Fayl turi»ni **Barcha fayllar** qiling, aks holda
   fayl `main.go.txt` boʻlib qoladi.
4. Terminalni shu papkada oching. Windows'da papkani oching, tepadagi manzil qatoriga `cmd` deb yozing va Enter
   bosing: terminal aynan shu papkada ochiladi. VS Code'da menyudan **Terminal → New Terminal** ni tanlang.

## `go run main.go`: tarjima qilib, ishga tushirish

Endi terminalga `go run main.go` deb yozamiz. Bu «`main.go` ni ishga tushir» degani:

```console
$ go run main.go
Salom, dunyo!
```

Natija brauzerdagidek: `Salom, dunyo!`. Bu safar `Program exited.` qatori yoʻq, chunki uni faqat Playground qoʻshadi.
«Fayl topilmadi» degan xato chiqsa, terminal boshqa papkada ochilgan (pastda, «Koʻp uchraydigan xatolar», 2-band).

Tezkor savol. Kompyuter bizning kodimizni tushunmaydi-ku. Unda `go run` ichida nima boʻldi?

**A)** kod oʻzi ishladi · **B)** avval tarjima, keyin ishga tushirish · **C)** kod internetga yuborildi

<details>
<summary>Javob</summary>

**B.** `go run` avval kompilyator bilan kodni kompyuter tiliga tarjima qiladi, keyin tarjimani darhol ishga
tushiradi. Qisqasi, kompyuter bizning matnimizni emas, uning tarjimasini bajaradi. **A** boʻlishi mumkin emas:
kompyuter faqat oʻz tilini tushunadi. **C** ham emas: `go run` hammasini oʻz kompyuteringizda, internetsiz qiladi.

</details>

```text
 main.go (bizning kod)
     │  go run
     ▼
 kompilyator: tarjima qiladi
     │
     ▼
 kompyuter tili ──► ishga tushadi ──► ekranda: Salom, dunyo!
```

## Ataylab xato: kichik `p`

Endi ataylab xato qilamiz. 6-qatordagi `Println` soʻzining katta `P` harfini kichik `p` qilamiz. Odam uchun bu
deyarli bir xil soʻz. Kurs papkasida bu xato tayyor holda `xato/main.go` faylida turibdi:

```go filename="xato/main.go" showLineNumbers
package main

import "fmt"

func main() {
	fmt.println("Salom, dunyo!")
}
```

Endi `go run main.go` nima qiladi?

**A)** baribir `Salom, dunyo!` chiqadi · **B)** Go xato xabarini beradi · **C)** Go xatoni oʻzi tuzatib, ishga
tushiradi

<details>
<summary>Javob</summary>

**B.** Kompilyator kichik `p` bilan yozilgan soʻzni tanimadi va tarjima qilmadi. Dastur umuman ishga tushmadi:
ekranda `Salom, dunyo!` yoʻq, faqat xato xabari bor. **A** yoki **C** ni tanlagan boʻlsangiz, kompyuter odamdek
«taxminan» tushunadi deb oʻylagansiz. Kompilyator taxmin qilmaydi va oʻzi tuzatmaydi: u faqat xato qayerdaligini aytadi.

</details>

Terminalda `xato` papkasiga kiramiz (`cd` — «papkaga kirish» buyrugʻi) va ishga tushiramiz:

```console
$ cd xato && go run main.go
# command-line-arguments
./main.go:6:6: undefined: fmt.println (but have Println)
```

Birinchi qator `# command-line-arguments` — sarlavha: «buyruqda koʻrsatilgan fayllarni tarjima qildim». Bizga
kerakli gap ikkinchi qatorda.

### Xato xabarini oʻqish

Xato xabari qoʻrqinchli koʻrinadi, lekin u xatoning aniq manzilini aytadi. Uni boʻlaklab oʻqiymiz:

| Boʻlak | Maʼnosi |
|---|---|
| `./main.go` | fayl: `./` «shu papkadagi» degani, yaʼni shu papkadagi `main.go` |
| `6` (birinchi son) | **qator**: 6-qator |
| `6` (ikkinchi son) | **belgi**: qatordagi 6-belgi (dasturchilar buni ustun, *column* deyishadi) |
| `undefined: fmt.println` | «aniqlanmagan»: Go `fmt` qutisida `println` degan nomni bilmaydi |
| `(but have Println)` | maslahat: «lekin `Println` bor», yaʼni katta `P` bilan |

Nega 6-belgi aynan kichik `p`? Chunki qator boshidagi Tab ham bitta belgi boʻlib sanaladi:

| Belgi raqami | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 6-qatorda | Tab | `f` | `m` | `t` | `.` | `p` |

### Tuzatish

Harfni yana katta qilamiz (`fmt.Println`) va qayta ishga tushiramiz. Asl `main.go` turgan papkada:

```console
$ go run main.go
Salom, dunyo!
```

`Salom, dunyo!` qaytib keldi. Bundan ikki qoida chiqadi:

- **Go katta va kichik harfni farqlaydi:** `Println` va `println` — ikki boshqa nom.
- **Xato chiqsa:** avval fayl va qatorni toping, keyin xabarni oʻqing. Xato bir nechta boʻlsa, birinchisidan
  boshlang.

Bugun birinchi dasturingizni oʻqidingiz, ishga tushirdingiz va xatosini oʻqidingiz. Keyingi darsda
([GO-0.02 · Oʻzgaruvchi — qiymatga yopishtirilgan yorliq](/lab/youtube/go/go-0-02)) dastur maʼlumotni qanday eslab qolishini
koʻramiz.

## Koʻp uchraydigan xatolar

**1. «Kompyuter taxminan tushunadi» degan fikr.** Bu mavzudagi eng koʻp uchraydigan notoʻgʻri tasavvur. Odam
`println` ni `Println` deb tushunib oladi, kompilyator esa yoʻq. Buni yuqoridagi «Ataylab xato» boʻlimida
koʻrdik: `undefined: fmt.println (but have Println)`. **Tuzatish:** harfni xabardagi maslahatdagidek yozing.

**2. Terminal boshqa papkada ochilgan yoki fayl nomi notoʻgʻri.** `main.go` yoʻq papkada `go run main.go` yozilsa
(Linux'da olingan natija):

```console
$ go run main.go
stat main.go: no such file or directory
```

`no such file or directory` — «bunday fayl yoki papka yoʻq». Windows'da xabar boshqacha, lekin maʼnosi shu: fayl
topilmadi. **Tuzatish:** terminalni `main.go` turgan papkada oching. Fayl nomi `main.go.txt` boʻlib qolmaganini
tekshiring: Explorer'da (Windows'ning papkalar oynasi) **Koʻrinish (View) → Fayl nomi kengaytmalari** belgisini qoʻysangiz, faylning toʻliq nomi
koʻrinadi.

**3. Surilish Tab emas, toʻrtta boʻsh joy bilan yozilgan.** Dastur baribir ishlaydi, faqat xato xabaridagi belgi
raqami boshqacha chiqadi. Masalan, `xato/main.go` dagi Tab oʻrniga toʻrtta boʻsh joy qoʻysak:

```go
package main

import "fmt"

func main() {
    fmt.println("Salom, dunyo!")
}
```

```console
$ go run main.go
# command-line-arguments
./main.go:6:9: undefined: fmt.println (but have Println)
```

Endi `6:9`: toʻrtta boʻsh joy 1–4 belgilar, `fmt.` 5–8, `p` esa 9-belgi. Xato oʻsha, faqat sanash boshqacha.
**Tuzatish:** surilishni Tab bilan qoʻying (VS Code buni oʻzi qiladi).

**4. Qoʻshtirnoq «jingalak» boʻlib qolgan.** Mac'dagi TextEdit kabi baʼzi matn muharrirlari (matn yoziladigan dasturlar) `"` ni `“ ”` ga
aylantiradi.
Go buni tanimaydi:

```go
package main

import "fmt"

func main() {
	fmt.Println(“Salom, dunyo!”)
}
```

```console
$ go run main.go
# command-line-arguments
./main.go:6:14: invalid character U+201C '“' in identifier
./main.go:6:29: syntax error: unexpected ! in argument list; possibly missing comma or )
./main.go:6:30: invalid character U+201D '”' in identifier
```

`invalid character U+201C '“'` — «notoʻgʻri belgi: `“`». Birinchi xabarni oʻqiymiz: 6-qator, 14-belgi, aynan ochuvchi
qoʻshtirnoq. Qolgan ikki qator shu xatoning davomi. **Tuzatish:** VS Code'dan foydalaning yoki TextEdit'da
Format → **Make Plain Text** ni tanlang va Edit → Substitutions → **Smart Quotes** ni oʻchiring.

(2-, 3- va 4-misollar kurs papkasida yoʻq: ular alohida papkada ishga tushirildi. 3- va 4-misollardagi dasturlar
`xato/main.go` va `main.go` ning oʻzgartirilgan nusxalari.)

🔍 Oxirgi qoʻshtirnoqsiz dastur (bu fayl kurs papkasida yoʻq, alohida ishga tushirildi):

```go
package main

import "fmt"

func main() {
	fmt.Println("Salom, dunyo!)
}
```

```console
$ go run main.go
# command-line-arguments
./main.go:6:29: newline in string
./main.go:6:29: syntax error: unexpected newline in argument list; possibly missing comma or )
```

`main.go`, 6-qator, 29-belgi — qatorning oxiri. `newline in string` — «matn ichida qator tugadi»: matn yopilmay turib
qator tugadi. Ikkinchi xabar shu bitta xatoning davomi: avval birinchisini tuzating.

➕ `PRINTLN` bilan (bu ham kurs papkasida yoʻq):

```console
$ go run main.go
# command-line-arguments
./main.go:6:6: undefined: fmt.PRINTLN (but have Println)
```

Yana 6-belgi, lekin bu safar u `P`, yaʼni toʻgʻri harf. Go notoʻgʻri harfni emas, notanish nomning **boshini**
koʻrsatadi. Darsdagi misolda nomning boshi va xato harf bir joyga tushgan edi.
