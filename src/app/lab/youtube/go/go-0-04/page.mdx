## Nimani oʻrganasiz

Doʻkonda xaridingiz 100 000 soʻmga yetsa, kassa chegirmani oʻzi beradi. Kassir hech narsani hisoblamaydi. Qarorni
kim qabul qildi? Dastur. Bu darsda xuddi shunday oʻzi qaror qabul qiladigan birinchi dasturingizni yozasiz.

**Bitta gʻoya:** dastur ikki sonni solishtirib savol beradi. Javob faqat ha (`true`) yoki yoʻq (`false`) boʻladi,
`if` esa shu javobga qarab ikki yoʻldan faqat bittasini tanlaydi.

Dars oxirida siz:

- `xarid >= 100000` kabi savolni oddiy soʻz bilan oʻqiy olasiz va uning javobini (`true` yoki `false`) aytasiz;
- `if` / `else` bilan chegirma dasturini, `else if` bilan baho dasturini yoza olasiz;
- dastur ekranga nima chiqarishini uni ishga tushirmasdan oldin aytib bera olasiz;
- eng koʻp uchraydigan ikki xatoni taniysiz: `if` ichida bitta `=` va `else if` savollarining notoʻgʻri tartibi.

Bugun uchta yangi soʻz bor:

| Belgi yoki soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| taqqoslash (`>`, `<`, `>=`, `<=`, `==`, `!=`) | ikki sonni solishtirib savol berish | comparison |
| `true` / `false` | savolning javobi: ha (rost) / yoʻq (yolgʻon) | true / false |
| `if` / `else` | «agar … boʻlsa» / «aks holda» | if / else |

Ikkita yordamchi soʻz ham uchraydi: `bool` (ha-yoʻq turi) va `else if` («aks holda, agar»).

## Kassaning savoli: taqqoslash

Kassa har bir xaridga bitta savol beradi: **«xarid 100 000 soʻmdan katta yoki tengmi?»** Javob faqat ikki xil
boʻladi: ha boʻlsa chegirma beriladi, yoʻq boʻlsa toʻliq narx olinadi.

```text
            xarid ≥ 100 000 ?
             /            \
           ha             yoʻq
            |               |
   chegirma beriladi    toʻliq narx
```

Bunday savolda ikki son solishtiriladi. Buni oʻzbekcha **taqqoslash**, inglizcha **comparison** deyiladi. Go'da
maktabdagi katta va kichik belgilari ishlatiladi. Klaviaturada `≥` va `≤` belgilari yoʻq, shuning uchun ularni ikki
belgi bilan yozamiz: avval katta (yoki kichik), keyin teng.

| Belgi | Oʻqilishi | Misol | Javob |
|---|---|---|---|
| `>` | katta | `5 > 3` | ha |
| `<` | kichik | `3 < 5` | ha |
| `>=` | katta yoki teng (≥) | `5 >= 5` | ha: teng boʻlsa ham |
| `<=` | kichik yoki teng (≤) | `4 <= 5` | ha |

`>=` va `<=` — bitta belgi: `>` bilan `=` orasiga boʻsh joy qoʻyilmaydi. Yana ikkita belgi (`==` va `!=`) bor, ularni
xatolar oldidan koʻramiz.

## Javob ham qiymat: `true` va `false`

Taqqoslashning javobi ham **qiymat**, xuddi son yoki matn kabi. Lekin Go uni inglizcha soʻz bilan aytadi:

| Kassaning javobi | Go'da | Oʻzbekcha |
|---|---|---|
| ha | `true` | rost |
| yoʻq | `false` | yolgʻon |

Har bir taqqoslash shu ikkisidan birini beradi, uchinchisi yoʻq.

Javob qiymat boʻlgani uchun uni yorliqqa yopishtirsa boʻladi. Bu uch qatorga qarang (dasturning ichki qismi):

```go
xarid := 120000
katta := xarid >= 100000
fmt.Println(katta)
```

- **1-qator:** yangi `xarid` yorligʻi, qiymati 120 000.
- **2-qator:** oʻng tomonda savol bor. Oldingi darsdagidek, Go **avval oʻng tomonni hisoblaydi**: `120000 >= 100000`?
  Ha, javob `true`. Keyin yangi `katta` yorligʻi shu javobga yopishadi.
- **3-qator:** `katta` ostidagi qiymatni ekranga chiqaradi: `true`.

Xotira rasmi:

| Qatordan keyin | `xarid` | `katta` | Ekranda |
|---|---|---|---|
| 1 `xarid := 120000` | `120000` (int) | — (hali yoʻq) | |
| 2 `katta := xarid >= 100000` | `120000` (int) | `true` (bool) | |
| 3 `fmt.Println(katta)` | `120000` | `true` | `true` |

`katta` ostidagi qiymatning ham turi bor. Uning turi **bool**, yaʼni ha-yoʻq turi: bu turda faqat ikki qiymat bor,
`true` va `false`. Oldingi darsdagi `int` (son) va `string` (matn) yoniga uchinchi tur qoʻshildi.

Endi birinchi qatorni oʻzgartiramiz: xarid 50 000. Bu kurs papkasidagi `taqqos/main.go`:

```go filename="taqqos/main.go" showLineNumbers
package main

import "fmt"

func main() {
	xarid := 50000
	katta := xarid >= 100000
	fmt.Println(katta)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1–5 | `package main` … `func main() {` | birinchi darsdagi tanish qolip |
| 6 | `xarid := 50000` | yangi `xarid` yorligʻi, qiymati 50 000 |
| 7 | `katta := xarid >= 100000` | savol: `50000 >= 100000`? Javob yangi `katta` yorligʻi ostiga tushadi |
| 8 | `fmt.Println(katta)` | `katta` ostidagi javobni ekranga chiqaradi |
| 9 | `}` | `main` va dastur tugadi |

Ishga tushirishdan oldin taxmin qiling: ekranga nima chiqadi? **A)** `false` · **B)** `true` · **C)** `50000`

<details>
<summary>Javob</summary>

**A: `false`.** 50 000 soni 100 000 dan kichik, demak «katta yoki tengmi?» savoliga javob — yoʻq, yaʼni `false`.
«`true`» ni tanlagan boʻlsangiz, eski 120 000 ni eslagansiz: endi 6-qatorda 50 000 turibdi. «`50000`» ni tanlagan
boʻlsangiz: `katta` yorligʻi xaridning oʻziga emas, savolning javobiga yopishgan.

</details>

`go run` dasturni tarjima qilib, darhol ishga tushiradi:

```console
$ go run taqqos/main.go
false
```

Qisqasi: taqqoslash savol beradi, uning javobi esa `true` yoki `false`.

## `if` va `else`: ikki yoʻldan bittasi

Javobni bilish yetmaydi, dastur unga qarab ish qilishi kerak. Kassaning qoidasini gap bilan yozamiz:
**agar** xarid 100 000 dan katta yoki teng boʻlsa, chegirma ber, **aks holda** toʻliq narx ol.

Go'da **`if`** soʻzi «agar» degani, **`else`** esa «aks holda» degani.

Avval `if` qismi. Xarid aynan 100 000:

```go
xarid := 100000
if xarid >= 100000 {
	fmt.Println("chegirma bor")
}
```

- **1-qator:** yangi `xarid` yorligʻi, qiymati 100 000.
- **2-qator:** `if`, keyin savol (`xarid >= 100000`), keyin jingalak qavs `{`. Birinchi darsdagidek, `{` — guruhning
  boshi.
- **3-qator:** guruh ichidagi qator. U ekranga `chegirma bor` deb yozadi, lekin **faqat savolning javobi `true`
  boʻlsa** bajariladi. Qator boshidagi boʻsh joy (tab) uning guruh ichida ekanini koʻrsatadi.
- **4-qator:** `}` — guruhning oxiri.

Endi ikkinchi guruhni qoʻshamiz. Guruh oxiridagi `}` dan keyin, **xuddi shu qatorda**, `else` va yangi guruh keladi:

```go
xarid := 100000
if xarid >= 100000 {
	fmt.Println("chegirma bor")
} else {
	fmt.Println("chegirma yoʻq")
}
```

- **4-qator:** `} else {` — birinchi guruh tugadi, «aks holda» guruhi boshlandi.
- **5-qator:** ekranga `chegirma yoʻq` deb yozadi, lekin **faqat javob `false` boʻlsa** bajariladi.
- **6-qator:** `}` — ikkinchi guruhning oxiri.

Toʻliq dastur — kurs papkasidagi `chegirma/main.go`:

```go filename="chegirma/main.go" showLineNumbers
package main

import "fmt"

func main() {
	xarid := 100000
	if xarid >= 100000 {
		fmt.Println("chegirma bor")
	} else {
		fmt.Println("chegirma yoʻq")
	}
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 6 | `xarid := 100000` | yangi `xarid` yorligʻi, qiymati 100 000 |
| 7 | `if xarid >= 100000 {` | savol beradi; javob `true` boʻlsa 8-qatorga kiradi |
| 8 | `fmt.Println("chegirma bor")` | faqat javob `true` boʻlsa bajariladi |
| 9 | `} else {` | javob `false` boʻlsa, dastur shu yerdan 10-qatorga kiradi |
| 10 | `fmt.Println("chegirma yoʻq")` | faqat javob `false` boʻlsa bajariladi |
| 11 | `}` | `else` guruhining oxiri |
| 12 | `}` | `main` tugadi |

Xarid aynan 100 000. Ekranga nima chiqadi? **A)** `chegirma bor` · **B)** `chegirma yoʻq` · **C)** ikkalasi

<details>
<summary>Javob</summary>

**A: `chegirma bor`.** 100 000 soni 100 000 ga teng, `>=` belgisi esa teng boʻlganda ham `true` beradi. Shuning
uchun `if` guruhi bajarildi. «Yoʻq» ni tanlagan boʻlsangiz, `>=` ni oddiy «katta» deb oʻqigansiz. «Ikkalasi» ni
tanlagan boʻlsangiz: ikki guruhdan doim faqat bittasi bajariladi.

</details>

```console
$ go run chegirma/main.go
chegirma bor
```

Dastur qanday yurdi:

| Qator | Nima boʻldi | Ekranda |
|---|---|---|
| 6 `xarid := 100000` | `xarid` ostida `100000` | |
| 7 `if xarid >= 100000 {` | `100000 >= 100000` → `true` | |
| 8 `fmt.Println("chegirma bor")` | bajarildi | `chegirma bor` |
| 9–11 `} else { … }` | **oʻtkazib yuborildi** | |

```text
              xarid >= 100000 ?   →  true
               /              \
       if guruhi ✔          else guruhi ✘
     "chegirma bor"       (oʻtkazib yuborildi)
```

Qisqasi: ikki guruhdan doim faqat bittasi bajariladi. Javob `true` boʻlsa `if` guruhi, `false` boʻlsa `else` guruhi.

## Kichik sinov: `>` va `>=`

Endi 7-qatordagi `>=` oʻrniga faqat `>` (katta) belgisini qoʻyamiz. Xarid yana 100 000. Bu `sinov/main.go`:

```go filename="sinov/main.go" showLineNumbers
package main

import "fmt"

func main() {
	xarid := 100000
	if xarid > 100000 {
		fmt.Println("chegirma bor")
	} else {
		fmt.Println("chegirma yoʻq")
	}
}
```

`chegirma/main.go` dan farqi faqat 7-qatorda: `xarid >= 100000` emas, `xarid > 100000`.

Ekranga endi nima chiqadi? **A)** `chegirma bor` · **B)** `chegirma yoʻq` · **C)** xato

<details>
<summary>Javob</summary>

**B: `chegirma yoʻq`.** 100 000 soni 100 000 dan **katta emas**, u unga teng. Javob `false`, shuning uchun `else`
guruhi bajarildi. «Xato» ni tanlagan boʻlsangiz: `>` ham toʻgʻri taqqoslash belgisi, dastur bemalol ishlaydi.

</details>

```console
$ go run sinov/main.go
chegirma yoʻq
```

| Savol | Javob | Qaysi guruh |
|---|---|---|
| `100000 >= 100000` | `true` | `if`: chegirma bor |
| `100000 > 100000` | `false` | `else`: chegirma yoʻq |

Bitta belgi chegaradagi xaridning taqdirini hal qiladi. Qoida «100 000 ga **yetsa**» deydimi yoki «100 000 dan
**oshsa**» deydimi — shunga qarab `>=` yoki `>` ni tanlang.

## `else if`: savollar ketma-ket

Baʼzan javob ikki xil emas, uch xil boʻladi. Masalan, test bali (bu bizning misol, rasmiy shkala emas):

- 90 va undan yuqori boʻlsa — `aʼlo`;
- 70 va undan yuqori boʻlsa — `yaxshi`;
- qolgan hollarda — `qayta topshiring`.

Savollarni ketma-ket qoʻyamiz: **`else if`**, yaʼni «aks holda, agar». Oxirgi `else` hech bir javob `true`
boʻlmasa bajariladi. Bu `baho/main.go`:

```go filename="baho/main.go" showLineNumbers
package main

import "fmt"

func main() {
	ball := 75
	if ball >= 90 {
		fmt.Println("aʼlo")
	} else if ball >= 70 {
		fmt.Println("yaxshi")
	} else {
		fmt.Println("qayta topshiring")
	}
}
```

Yangi qatorlar:

| Qator | Kod | Nima qiladi |
|---|---|---|
| 6 | `ball := 75` | yangi `ball` yorligʻi, qiymati 75 |
| 7–8 | `if ball >= 90 {` … `"aʼlo"` | 1-savol: javob `true` boʻlsa `aʼlo` deb yozadi |
| 9–10 | `} else if ball >= 70 {` … `"yaxshi"` | 2-savol: faqat 1-javob `false` boʻlsa soʻraladi |
| 11–12 | `} else {` … `"qayta topshiring"` | ikkala javob ham `false` boʻlsa bajariladi |
| 13 | `}` | oxirgi guruhning oxiri |

Ball 75 boʻlsa, ekranga nima chiqadi? **A)** `yaxshi` · **B)** `aʼlo` · **C)** `qayta topshiring`

<details>
<summary>Javob</summary>

**A: `yaxshi`.** 75 soni 90 dan kichik, lekin 70 dan katta. «Aʼlo» ni tanlagan boʻlsangiz, 1-savolni qayta
tekshiring: `75 >= 90` — `false`. «Qayta topshiring» faqat ikkala savolga ham javob `false` boʻlganda chiqadi.

</details>

```console
$ go run baho/main.go
yaxshi
```

Go savollarni **tepadan pastga, bittalab** tekshiradi:

| Qadam | Qator | Savol | Javob | Nima boʻladi |
|---|---|---|---|---|
| 1 | 7 | `75 >= 90` | `false` | keyingi savolga oʻtadi |
| 2 | 9 | `75 >= 70` | `true` | 10-qator: ekranga `yaxshi` |
| 3 | 11 | `else` | — | **tekshirilmaydi** |

Qisqasi: birinchi `true` topilgach, qolgani umuman tekshirilmaydi.

## Tengmi? `==` va `!=`

Oldingi darsda bitta `=` «boʻlsin» degani edi: u yorliq ostiga qiymat qoʻyadi, **savol bermaydi**. Ikki son tengmi deb
soʻrash uchun Go'da **ikkita teng** yoziladi: `==`. Teskari savol ham bor: undov belgisi va teng, `!=`, yaʼni «teng
emasmi?».

| Yozuv | Oʻqilishi | Nima qiladi |
|---|---|---|
| `a = 4` | `a` boʻlsin 4 | qiymat berish: `a` ostiga 4 qoʻyadi |
| `a == 4` | `a` 4 ga tengmi? | savol: javob `true` yoki `false` |
| `a != 4` | `a` 4 ga teng emasmi? | savol: javob `true` yoki `false` |

Bu kichik dastur kurs papkasida yoʻq, uni shu sahifa uchun alohida ishga tushirdik:

```go
package main

import "fmt"

func main() {
	a := 4
	fmt.Println(a == 4, a != 4)
	a = 5
	fmt.Println(a == 4, a != 4)
}
```

- **6-qator:** yangi `a` yorligʻi, qiymati 4.
- **7-qator:** ikki savol: `a == 4`? va `a != 4`? `Println` ikkala javobni bitta qatorda, orasiga boʻsh joy qoʻyib
  chiqaradi.
- **8-qator:** bitta `=`: `a` endi 5 boʻlsin.
- **9-qator:** xuddi oʻsha ikki savol, lekin endi `a` ostida 5.

Taxmin qiling: **A)** `true false`, keyin `false true` · **B)** `true true`, keyin `false false` ·
**C)** `true false`, keyin `true false`

<details>
<summary>Javob</summary>

**A.** Avval `a` ostida 4: «4 ga tengmi?» — `true`, «teng emasmi?» — `false`. 8-qatordan keyin `a` ostida 5:
endi «tengmi?» — `false`, «teng emasmi?» — `true`. `==` va `!=` har doim bir-biriga teskari javob beradi.
«B» boʻlmaydi: ikki savol bir vaqtda `true` boʻla olmaydi. «C» ni tanlagan
boʻlsangiz, 8-qatordagi `a = 5` ni unutgansiz.

</details>

```console
$ go run teng/main.go
true false
false true
```

## Chuqurroq (ixtiyoriy): `if` haqida yana toʻrt gap

Bu qism videoda yoʻq, kurs papkasidagi README'dan olingan.

- **Savol atrofida oddiy qavs kerak emas, jingalak qavslar esa majburiy:** `if xarid >= 100000 {`
  ([A Tour of Go](https://go.dev/tour/flowcontrol/5)).
- **`else` majburiy emas.** Keyingi boʻlimdagi `tuzat/main.go` da faqat `if` bor: javob `false` boʻlsa, dastur hech
  narsa yozmaydi.
- **`else if ball >= 70` ga «`ball` 90 dan kichik» degan savolni qoʻshish kerak emas.** Bu savolga faqat oldingi
  `ball >= 90` javobi `false` boʻlganda navbat keladi. Harvard CS50 ham xuddi shu savolni beradi: *"not all these
  lines of code are required"*.
- **Dasturchilar `if` dan keyingi savolni shart (condition) deb ham atashadi.** Bu darsda biz bitta soʻz bilan,
  «savol» deb aytdik.

## Koʻp uchraydigan xatolar

**1. `if` ichida bitta `=` (eng koʻp uchraydigan xato).** Bu dasturda oʻquvchining javobi 4. Javob 4 boʻlsa, ekranga
`toʻgʻri` chiqishi kerak. Eslang: `if` dan keyin savol turadi. Lekin 7-qatorda adashib bitta `=` yozilgan, u esa
savol emas. Bu `xato/main.go`, ataylab xato yozilgan:

```go filename="xato/main.go" showLineNumbers
package main

import "fmt"

func main() {
	javob := 4
	if javob = 4 {
		fmt.Println("toʻgʻri")
	}
}
```

Bu dastur nima qiladi? **A)** `toʻgʻri` deb yozadi · **B)** jim qoladi · **C)** xato beradi

<details>
<summary>Javob</summary>

**C: xato.** Kompilyator dasturni tarjima qilmaydi, dastur umuman ishga tushmaydi. `if` dan keyin savol kerak,
bitta `=` esa savol emas, u qiymat qoʻyadi. «Toʻgʻri» ni tanlagan boʻlsangiz, `=` ni matematikadagi «teng» deb
oʻqigansiz.

</details>

```console
$ go run xato/main.go
# command-line-arguments
xato/main.go:7:11: syntax error: cannot use assignment javob = 4 as value
```

Xabarni birinchi darsdagidek, boʻlakma-boʻlak oʻqiymiz:

| Boʻlak | Maʼnosi |
|---|---|
| `xato/main.go` | fayl |
| `7` | **7-qator** |
| `11` | qatordagi **11-belgi**: aynan bitta `=` (tab 1-belgi, `if` 2–3, boʻsh joy 4, `javob` 5–9, boʻsh joy 10, `=` 11) |
| `syntax error` | yozilish xatosi: kompilyator kodni oʻqiy olmadi |
| `cannot use assignment javob = 4 as value` | «`javob = 4` qiymat berishini (assignment) javob oʻrnida ishlatib boʻlmaydi» |

Bu xato shunchalik koʻp uchraydiki, Go kompilyatorining oʻzida unga alohida xabar yozilgan. Kompilyator kodida
shunday izoh bor: *"A common syntax error is to write '=' instead of '=='"* («koʻp uchraydigan xato — `==` oʻrniga `=`
yozish»).

**Tuzatish:** ikkita teng yozamiz. Bu `tuzat/main.go`:

```go filename="tuzat/main.go" showLineNumbers
package main

import "fmt"

func main() {
	javob := 4
	if javob == 4 {
		fmt.Println("toʻgʻri")
	}
}
```

Faqat 7-qator oʻzgardi: `javob == 4` — «javob 4 ga tengmi?». Bu dasturda `else` yoʻq: javob `false` boʻlganida dastur
hech narsa yozmasdi.

```console
$ go run tuzat/main.go
toʻgʻri
```

**2. `else if` savollarining notoʻgʻri tartibi.** Bu xatoda kompilyator jim turadi, dastur esa notoʻgʻri javob
beradi. Bu xuddi baho dasturi, faqat ikki savol oʻrin almashgan: avval 70, keyin 90 soʻraladi. Ball esa 95.
Bu `tartib/main.go`:

```go filename="tartib/main.go" showLineNumbers
package main

import "fmt"

func main() {
	ball := 95
	if ball >= 70 {
		fmt.Println("yaxshi")
	} else if ball >= 90 {
		fmt.Println("aʼlo")
	} else {
		fmt.Println("qayta topshiring")
	}
}
```

95 ball uchun ekranga nima chiqadi? **A)** `aʼlo` · **B)** `yaxshi` · **C)** ikkalasi

<details>
<summary>Javob</summary>

**B: `yaxshi`.** Go savollarni tepadan pastga tekshiradi va birinchi `true` da toʻxtaydi. `95 >= 70` — `true`,
shuning uchun ekranga `yaxshi` chiqadi va `aʼlo` savoliga navbat kelmaydi. «Aʼlo» ni tanlagan boʻlsangiz, Go hamma
savolni koʻrib, eng mosini tanlaydi deb oʻylagansiz. «Ikkalasi» boʻlmaydi: bu savollardan keyin faqat bitta guruh bajariladi.

</details>

```console
$ go run tartib/main.go
yaxshi
```

| Qadam | Qator | Savol | Javob | Nima boʻladi |
|---|---|---|---|---|
| 1 | 7 | `95 >= 70` | `true` | 8-qator: ekranga `yaxshi` |
| 2 | 9 | `95 >= 90` | — | **tekshirilmaydi** (aslida `true` boʻlardi) |
| 3 | 11 | `else` | — | tekshirilmaydi |

**Tuzatish:** eng qattiq savolni, yaʼni `>= 90` ni, birinchi qoʻying. Bu aynan `baho/main.go` dagi tartib
(yuqoridagi «`else if`: savollar ketma-ket» boʻlimi).

**3. Chegarada `>` va `>=` ni adashtirish.** Bu ham jim xato: qoida «100 000 ga yetsa» deydi, kodda esa `>` yozilgan.
Natijada aynan 100 000 lik xarid chegirmasiz qoladi. Batafsil: yuqoridagi «Kichik sinov» boʻlimi.
**Tuzatish:** «yetsa», «va undan yuqori» degan qoida uchun `>=` yozing.

**4. `else` ni yangi qatorga yozish.** Bu dastur kurs papkasida yoʻq, uni shu sahifa uchun alohida ishga tushirdik:

```go
package main

import "fmt"

func main() {
	xarid := 100000
	if xarid >= 100000 {
		fmt.Println("chegirma bor")
	}
	else {
		fmt.Println("chegirma yoʻq")
	}
}
```

```console
$ go run elsequr/main.go
# command-line-arguments
elsequr/main.go:10:2: syntax error: unexpected keyword else, expected }
```

10-qator, 2-belgi: aynan `else` soʻzi. `unexpected keyword else` — «kutilmagan soʻz: `else`», `expected }` — «bu yerda
`}` kutilgan edi». Go qator oxiridagi `}` dan keyin buyruq tugadi deb hisoblaydi, shuning uchun keyingi qatordagi
`else` yetim qoladi. **Tuzatish:** `else` ni oldingi `}` bilan bitta qatorga yozing: `} else {`.

**5. Matnni son bilan taqqoslash.** Bu ham kurs papkasida yoʻq, alohida ishga tushirildi:

```go
package main

import "fmt"

func main() {
	yosh := "15"
	fmt.Println(yosh == 15)
}
```

```console
$ go run matn/main.go
# command-line-arguments
matn/main.go:7:22: invalid operation: yosh == 15 (mismatched types string and untyped int)
```

Bu oldingi darsdagi xatoning qarindoshi: `invalid operation` — «notoʻgʻri amal», qavs ichida sabab: «turlar mos
emas, biri `string`, biri son». `yosh` ostida qoʻshtirnoqli `"15"`, yaʼni matn turibdi, `15` esa son. Taqqoslash ham,
plyus kabi, faqat bir xil turdagi qiymatlar bilan ishlaydi. **Tuzatish:** sonni qoʻshtirnoqsiz yozing: `yosh := 15`.

## Oʻzingizni tekshiring

Avval oʻzingiz javob bering, keyin oching.

**1.** `5 < 3` ning javobi nima?

<details>
<summary>Javob</summary>

`false`, chunki 5 soni 3 dan kichik emas.

</details>

**2.** Bitta `=` va ikkita `==` ning farqi nima?

<details>
<summary>Javob</summary>

Bitta `=` yorliq ostiga qiymat qoʻyadi (qiymat berish). Ikkita `==` savol beradi: «tengmi?», javobi `true` yoki
`false`.

</details>

**3.** `else` guruhi qachon bajariladi?

<details>
<summary>Javob</summary>

Faqat savolning javobi `false` boʻlganda. `else if` savollari ketma-ket kelsa — tepadagi hamma savolga javob `false` boʻlganda.

</details>

**4.** Bu kod ekranga nima chiqaradi?

```go
xarid := 99999
if xarid >= 100000 {
	fmt.Println("chegirma bor")
} else {
	fmt.Println("chegirma yoʻq")
}
```

<details>
<summary>Javob</summary>

`chegirma yoʻq`. `99999 >= 100000` — `false`: 99 999 soni 100 000 ga yetmadi, shuning uchun `else` guruhi bajariladi.

</details>

**5.** Birinchi darsdan: `xato/main.go:7:11` xabaridagi birinchi son (`7`) nimani bildiradi?

<details>
<summary>Javob</summary>

Qator raqamini: xato 7-qatorda. Ikkinchi son (`11`) — shu qatordagi belgi oʻrni.

</details>

<details>
<summary>Javob</summary>

🟢 Hozirgi fayl `chegirma yoʻq` deb yozadi, chunki `xarid` ostida 70 000, u 100 000 dan kichik:

`if xarid >= 50000 {` qilsangiz, `70000 >= 50000` — `true`, dastur `chegirma bor` deb yozadi.

🟡 Yangi `else if` ni `>= 70` dan keyin, `else` dan oldin qoʻyamiz (eng qattiq savol birinchi):

```go
	if ball >= 90 {
		fmt.Println("aʼlo")
	} else if ball >= 70 {
		fmt.Println("yaxshi")
	} else if ball >= 55 {
		fmt.Println("qoniqarli")
	} else {
		fmt.Println("qayta topshiring")
	}
```

`ball := 60` bilan: `60 >= 90` — `false`, `60 >= 70` — `false`, `60 >= 55` — `true` → `qoniqarli`. Agar `>= 55` ni eng
tepaga qoʻysangiz, 95 ball ham `qoniqarli` boʻlib qoladi: bu darsdagi tartib xatosi.

🔴 `fmt.Println(pin, kiritilgan)` qatori oʻrniga:

```go
	pin := 2580
	kiritilgan := 1111
	if kiritilgan != pin {
		fmt.Println("notoʻgʻri kod")
	} else {
		fmt.Println("xush kelibsiz")
	}
```

`1111 != 2580` — `true`, demak `notoʻgʻri kod`. `kiritilgan := 2580` qilsangiz, `2580 != 2580` — `false`, `else`
guruhi `xush kelibsiz` deb yozadi.

</details>
