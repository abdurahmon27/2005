## Что вы узнаете

В математике `x = x + 1` — ошибка: ни одно число не может быть на единицу больше самого себя. А в Go такая строка
спокойно работает. В этом уроке вы поймёте почему.

**Главная идея:** переменная — это ярлык с именем, приклеенный к значению в памяти. `:=` создаёт новый ярлык, а `=`
заменяет значение под ярлыком на новое, и старое значение пропадает.

К концу урока вы сможете:

- прочитать строки `ochko := 3` и `ochko = ochko + 1` простыми словами;
- сказать, что программа выведет на экран, ещё до того, как её запустить;
- прочитать и исправить две самые частые ошибки компиляции (`undefined` и `no new variables`).

Новых слов сегодня всего три:

| Знак или слово | Простой смысл | По-английски |
|---|---|---|
| переменная | ярлык с именем, приклеенный к значению | variable |
| `:=` («двоеточие-равно») | создаёт новый ярлык | short variable declaration |
| `=` («пусть будет») | кладёт под ярлык новое значение: присваивание | assignment |

## Программе нужно что-то запоминать

Программе часто нужно запомнить число, например очки в игре. Представьте табло на стадионе: на нём название команды,
например **PAXTAKOR**, а рядом цифра **3**. Когда забивают гол, название остаётся на месте, 3 стирается, и вместо
неё пишется 4.

```text
PAXTAKOR   3      ⚽ гол!      PAXTAKOR   4
```

В программе всё так же. Пока программа работает, числа лежат в **памяти** компьютера, то есть в месте, где он
хранит то, что нужно помнить (как память телефона). Число, лежащее в памяти, называется **значением**. Мы
приклеиваем к значению ярлык с именем. Ярлык, приклеенный к значению, по-русски называется **переменная**,
по-английски **variable**.

| Ярлык (имя переменной) | Значение (в памяти) |
|---|---|
| `ochko` | `3` |

Главное правило: **под одним ярлыком всегда лежит только одно значение.** Когда кладут новое значение, старое
пропадает.

Почему «ярлык», а не «коробка»? Переменную часто объясняют как «коробку, в которую что-то кладут». Фелиенне
Херманс с коллегами сравнили эти две метафоры на 496 новичках: те, кому объясняли через «коробку», чаще ошибались,
думая, что переменная хранит сразу несколько значений (как будто в коробке осталось и старое значение). Поэтому мы
говорим «ярлык»: как название на табло, он приклеен к одному месту, и там лежит одно число.

## `:=` — создаём новый ярлык

Теперь напишем это на Go (`ochko` по-узбекски значит «очки», «счёт»):

```go
ochko := 3
```

Знак `:=` («двоеточие-равно») создаёт **новый** ярлык и приклеивает его к значению справа. Читайте эту строку так:
**«новый ярлык `ochko`, значение 3»**.

| После строки | Под `ochko` |
|---|---|
| `ochko := 3` | `3` |

В следующей строке выводим значение на экран:

```go
fmt.Println(ochko)
```

На этот раз слово `ochko` написано без кавычек. Поэтому `Println` выводит не слово «ochko», а **значение** под этим
ярлыком, то есть `3`. Если написать с кавычками (`fmt.Println("ochko")`), на экран выйдет само слово `ochko`.
Разницу между числом и текстом подробно разберём в следующем уроке.

Ещё одно маленькое правило: `:=` работает только внутри функции, то есть между фигурными скобками
`func main() { … }`. Весь наш код пишется именно там.

## `=` — присваивание: `ochko = ochko + 1`

Теперь сама загадка урока, только вместо `x` — `ochko`:

```go
ochko = ochko + 1
```

Один знак `=` здесь — **не** «равно» из математики. Он кладёт новое значение под уже созданный ярлык. Это
называется **присваивание**, по-английски **assignment**. Читайте его как «пусть будет»: **«пусть `ochko` теперь
будет `ochko + 1`»**.

Это не уравнение, а команда. Go выполняет её в два шага (так написано и в официальных правилах Go:
*"The assignment proceeds in two phases"*):

| Шаг | Что происходит | Под `ochko` |
|---|---|---|
| до | — | `3` |
| шаг 1 | **сначала вычисляется правая часть**: Go смотрит на ярлык `ochko`, находит `3`, прибавляет 1: `3 + 1 = 4` | пока `3` |
| шаг 2 | **результат кладётся под ярлык слева**: `3` пропадает | `4` |

Коротко: один `=` кладёт результат правой части под ярлык слева. Чтобы **проверить**, равны ли две вещи, в Go
есть другой знак, `==` (мы разберём его в [GO-0.04](/lab/youtube/go#go-0-04)).

## Полная программа: создаём, выводим, изменяем

Соберём всё в одну программу. Это файл `hisob/main.go` из папки курса (`hisob` значит «счёт», «подсчёт»):

```go filename="hisob/main.go" showLineNumbers
package main

import "fmt"

func main() {
	ochko := 3
	fmt.Println(ochko)
	ochko = ochko + 1
	fmt.Println(ochko)
}
```

Что делает каждая строка:

| Строка | Код | Что делает |
|---|---|---|
| 1 | `package main` | знакомый шаблон из прошлого урока: это программа, которую можно запустить |
| 3 | `import "fmt"` | подключает пакет с командами вывода на экран (`fmt.Println`) |
| 5 | `func main() {` | отсюда программа начинается |
| 6 | `ochko := 3` | **1 · создаём**: новый ярлык `ochko`, значение 3 |
| 7 | `fmt.Println(ochko)` | **2 · выводим**: пишет на экран значение под ярлыком |
| 8 | `ochko = ochko + 1` | **3 · изменяем**: пусть `ochko` теперь будет `3 + 1` |
| 9 | `fmt.Println(ochko)` | **4 · снова выводим** |
| 10 | `}` | `main` закончилась, программа закончилась |

Прежде чем запускать, угадайте: что появится на экране? **A)** 3 и 3 · **B)** 3 и 4 · **C)** 4 и 4 ·
**D)** ошибка

<details>
<summary>Ответ</summary>

**B: сначала 3, потом 4.** Первый `Println` вывел 3, потому что в тот момент под ярлыком лежало 3. Потом строка 8
заменила значение на 4, и второй `Println` вывел 4. Если вы выбрали «4 и 4»: программа выполняет строки сверху вниз,
по одной; когда работала строка 7, строка 8 ещё не выполнилась.

</details>

Проверим в терминале (`go run` переводит программу и сразу её запускает):

```console
$ go run hisob/main.go
3
4
```

Что происходило в памяти, строка за строкой:

| Строка | Под `ochko` | На экране |
|---|---|---|
| 6 `ochko := 3` | `3` | |
| 7 `fmt.Println(ochko)` | `3` | `3` |
| 8 `ochko = ochko + 1` | `4` (3 пропало) | |
| 9 `fmt.Println(ochko)` | `4` | `4` |

## Один ярлык — одно значение

Проверьте себя. Это программа `savol/main.go` (`savol` — «вопрос», `yosh` — «возраст»):

```go filename="savol/main.go" showLineNumbers
package main

import "fmt"

func main() {
	yosh := 15
	yosh = 16
	fmt.Println(yosh)
}
```

Что выведет `fmt.Println(yosh)`? **A)** 15 · **B)** 16 · **C)** 15 и 16

<details>
<summary>Ответ</summary>

**B: 16.** Строка 7 положила под ярлык `yosh` число 16, а 15 пропало. Тот, кто представляет переменную как коробку,
в которой копятся вещи, может ответить «оба», как будто старое значение осталось в коробке. Но под ярлыком всегда
лежит одно значение.

</details>

```console
$ go run savol/main.go
16
```

## Копия: `rekord := ochko`

Теперь добавим второй ярлык (`rekord` — «рекорд»). Это `nusxa/main.go` (`nusxa` — «копия»):

```go filename="nusxa/main.go" showLineNumbers
package main

import "fmt"

func main() {
	ochko := 3
	rekord := ochko
	ochko = 0
	fmt.Println(ochko, rekord)
}
```

- **Строка 6:** новый ярлык `ochko`, значение 3.
- **Строка 7:** `rekord := ochko`. Go делает **копию** значения `ochko`, то есть создаёт второе такое же число, и
  новый ярлык `rekord` приклеивается к этой копии. Теперь в памяти лежат две отдельные тройки.
- **Строка 8:** `ochko = 0`, потому что началась новая игра.
- **Строка 9:** `Println` получает через запятую два значения и выводит оба в одной строке, через пробел.

Угадайте: **A)** `0 0` · **B)** `0 3` · **C)** `3 3`

<details>
<summary>Ответ</summary>

**B: `0 3`.** `ochko = 0` заменило только значение под ярлыком `ochko`. `rekord` приклеен к своей копии, её никто не
трогал. Если вы выбрали «0 0», вы думали, что два ярлыка приклеены к одному значению. С числами `:=` всегда делает
отдельную копию.

</details>

```console
$ go run nusxa/main.go
0 3
```

Картина памяти:

| После строки | `ochko` | `rekord` |
|---|---|---|
| 6 `ochko := 3` | `3` | — (ещё нет) |
| 7 `rekord := ochko` | `3` | `3` (копия) |
| 8 `ochko = 0` | `0` | `3` (не тронуто) |
| 9 `fmt.Println(ochko, rekord)` | на экране: `0 3` | |

```text
 ochko  ──►  [ 0 ]     3 стёрто, вместо него 0
rekord  ──►  [ 3 ]     своя копия: её никто не трогал
```

Это правило для чисел. Позже, когда будем работать со списками (slice) и словарями (map), увидим, что копия там
работает иначе ([GO-1.08](/lab/youtube/go#go-1-08), [GO-1.09](/lab/youtube/go#go-1-09)).

## Частые ошибки

**1. Ярлыка ещё нет, а написано `=`.** Файл `xato/main.go` написан с ошибкой нарочно (`xato` — «ошибка»):

```go filename="xato/main.go" showLineNumbers
package main

import "fmt"

func main() {
	ochko = 0
	fmt.Println(ochko)
}
```

```console
$ go run xato/main.go
# command-line-arguments
xato/main.go:6:2: undefined: ochko
xato/main.go:7:14: undefined: ochko
```

Читаем сообщение, как в прошлом уроке: файл `xato/main.go`, **строка 6**, символ 2, затем `undefined: ochko`, то
есть «имя `ochko` не найдено». Go не знает такого имени, потому что ярлык `ochko` ещё не создан: `=` только кладёт
значение под **существующий** ярлык. Вторая строка сообщения по той же причине (в строке 7 снова используется
`ochko`). **Исправление:** в первый раз пишем `:=`: `ochko := 0`.

**2. Ярлык уже есть, а снова написано `:=`.** `xato2/main.go`:

```go filename="xato2/main.go" showLineNumbers
package main

import "fmt"

func main() {
	ochko := 0
	ochko := 1
	fmt.Println(ochko)
}
```

```console
$ go run xato2/main.go
# command-line-arguments
xato2/main.go:7:8: no new variables on left side of :=
```

`no new variables on left side of :=` — «слева от `:=` нет ни одной новой переменной». `ochko` создана в строке 6,
создать её второй раз нельзя. **Исправление:** в строке 7 пишем один `=`: `ochko = 1`.

Запомните обе ошибки одним правилом:

| Ситуация | Какой знак |
|---|---|
| ярлыка ещё нет, создаём его впервые | `:=` |
| ярлык есть, меняем его значение | `=` |

**3. Переменная создана, но не используется.** В Go это тоже ошибка (вы можете встретить её в домашнем задании).
Например, если написать `ochko := 3` и больше нигде не использовать `ochko`:

```go
func main() {
	ochko := 3
	fmt.Println("salom")
}
```

```console
$ go run unused/main.go
# command-line-arguments
unused/main.go:6:2: declared and not used: ochko
```

«объявлена, но не используется». **Исправление:** используйте её (например, `fmt.Println(ochko)`) или удалите
строку.

**4. Путаница с кавычками.** `fmt.Println("ochko")` выводит не значение, а само слово `ochko`, а
`fmt.Println(ochko)` выводит значение:

```console
$ go run quote/main.go
ochko
3
```

(Этих двух примеров нет в папке курса: их запускали отдельно, только чтобы показать ошибку.)

## Проверьте себя

Сначала ответьте сами, потом откройте ответ.

**1.** Чем `:=` отличается от `=`?

<details>
<summary>Ответ</summary>

`:=` создаёт новый ярлык и приклеивает его к значению. `=` кладёт новое значение под существующий ярлык (старое
пропадает).

</details>

**2.** Как выполняется `ochko = ochko + 1`?

<details>
<summary>Ответ</summary>

В два шага: сначала вычисляется правая часть (`3 + 1 = 4`), затем результат кладётся под ярлык `ochko` слева, и 3
пропадает.

</details>

**3.** Если после `rekord := ochko` изменить `ochko`, изменится ли `rekord`?

<details>
<summary>Ответ</summary>

Нет. `rekord` приклеен к своей копии; `ochko = 0` меняет только значение под `ochko`.

</details>

**4.** Что выведет этот код?

```go
a := 5
b := a
a = a + 2
fmt.Println(a, b)
```

<details>
<summary>Ответ</summary>

`7 5`. `b` получила копию числа 5. Потом `a` стала `5 + 2`, а `b` никто не трогал.

</details>

**5.** Из прошлого урока: чем отличаются `fmt.Println("salom")` и `fmt.Println(salom)`?

<details>
<summary>Ответ</summary>

Первая выводит слово `salom` из кавычек. Вторая выводит **значение переменной** с именем `salom`. Если такая
переменная не создана, компилятор скажет `undefined: salom`.

</details>
