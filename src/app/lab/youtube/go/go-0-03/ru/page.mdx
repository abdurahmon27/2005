## Что вы узнаете

На калькуляторе `2 + 2` всегда равно `4`. А в программе на Go что-то очень похожее на `2 + 2` может вывести `22`.
Разница прячется в одном маленьком символе. В этом уроке вы его найдёте.

**Одна идея:** у каждого значения есть тип. Значение в кавычках — это текст, а целое число без кавычек — число. Плюс
работает только с двумя значениями одного типа: числа он складывает, тексты склеивает. Если их смешать, Go не
переведёт программу.

К концу урока вы сможете:

- сказать, какого типа `15` и `"15"`;
- заранее сказать, что делает `+` с двумя числами и с двумя текстами;
- прочитать ошибку `mismatched types` и исправить её с помощью `strconv.Itoa`;
- объяснить, почему `7 / 2` в Go даёт `3` и как получить `3.5`.

Новые слова сегодня:

| Слово | Простой смысл | По-английски |
|---|---|---|
| тип | вид значения: считаем ли мы с ним или только записываем его | type |
| `int` | целое число: `15`, `7`, `2` | int (integer) |
| `string` | строка, то есть текст; в коде пишется в кавычках: `"15"`, `"Salom"` | string |

Есть ещё два вспомогательных слова: `float64` (число с точкой, дробное) и `strconv.Itoa` (делает текст из целого
числа). Каждое объясняется в своём разделе.

## У каждого значения есть тип

Представьте анкету с двумя полями: ваш возраст и номер телефона. Оба состоят из цифр.

```text
Возраст:  15             → +1 → 16   (ваш возраст в следующем году)
Телефон:  90 123 45 67   → +1 → ?    (с номером телефона не считают)
```

Прибавьте к возрасту единицу — получите возраст в следующем году. С номером телефона никто не считает: его только
записывают. Значит, даже если два значения состоят из одинаковых цифр, это значения разного вида.

Компьютер тоже должен знать вид каждого значения: складывать его или только записывать? В программировании вид
значения называется **типом** (по-английски **type**). В Go у каждого значения есть тип.

Сегодня знакомимся с двумя основными типами:

- Основной тип целых чисел в Go называется **`int`**. `15` в `yosh := 15` («возраст») записано без кавычек, это
  `int`.
- Текст называется **`string`** (строка). Как `"Salom, dunyo!"` («Привет, мир!») в первом уроке, текст в коде мы
  пишем в кавычках. `"15"` в `yozuv := "15"` стоит в кавычках, это `string`, совсем как номер телефона.

```go
yosh := 15
yozuv := "15"
```

(`yozuv` — «запись, текст».) Картинка памяти:

| Ярлык | Значение (в памяти) | Тип | Почему |
|---|---|---|---|
| `yosh` | `15` | `int` | целое число, кавычек нет |
| `yozuv` | `"15"` | `string` | есть кавычки: это два символа, `1` и `5` |

В обоих есть 15, но это два разных значения. Go узнаёт тип по тому, как записано значение: с кавычками — `string`,
целое число без кавычек — `int`.

## Плюс сначала смотрит на тип

Теперь проверим плюс на обоих типах. Это файл `qoshish/main.go` («сложение») из папки курса:

```go filename="qoshish/main.go" showLineNumbers
package main

import "fmt"

func main() {
	fmt.Println(2 + 2)
	fmt.Println("2" + "2")
}
```

| Строка | Код | Что делает |
|---|---|---|
| 1 | `package main` | шаблон из первого урока: это программа, которую можно запустить |
| 3 | `import "fmt"` | подключает «коробку» (пакет) `fmt` с инструментами для вывода на экран |
| 5 | `func main() {` | отсюда начинается программа |
| 6 | `fmt.Println(2 + 2)` | два плюс два без кавычек: два значения `int` |
| 7 | `fmt.Println("2" + "2")` | два в кавычках плюс два в кавычках: два значения `string` |
| 8 | `}` | `main` закончилась, программа закончилась |

`fmt.Println` выводит на экран то, что стоит в скобках. Эта программа выведет две строки. Угадайте до запуска:
**A)** 4 и 4 · **B)** 4 и 22 · **C)** ошибка

<details>
<summary>Ответ</summary>

**B: 4 и 22.** Тот маленький символ из начала урока — это кавычки. В строке 6 оба значения `int`, их сложили. В
строке 7 оба значения `string`, их склеили рядом. Если вы выбрали «4 и 4», вы не заметили кавычки. Если выбрали
«ошибка», вы думали, что тексты нельзя соединять плюсом: можно, только результат — склеенный текст, а не сумма.

</details>

Проверим в терминале. Команда `go run` переводит файл `main.go` из папки `qoshish` и сразу его запускает:

```console
$ go run qoshish/main.go
4
22
```

Почему так? Значение в кавычках — это текст. А плюс сначала смотрит на тип с каждой стороны:

| Код | Слева | Справа | Что делает `+` | Результат |
|---|---|---|---|---|
| `2 + 2` | `int` | `int` | складывает | `4` (число) |
| `"2" + "2"` | `string` | `string` | склеивает рядом | `"22"` (текст) |

`Println` выводит текст без кавычек, поэтому `22` на экране похоже на число. На самом деле это не число двадцать два,
а два символа `2`, стоящих рядом:

```text
"2"  +  "2"   →   "22"
[2]     [2]       [2][2]     два символа, а не число
```

Коротко: плюс работает только с двумя значениями одного типа. Если оба `int` — складывает. Если оба `string` —
склеивает. Такое склеивание текстов по-английски называется **string concatenation** (конкатенация строк).

## Маленькая проверка: часы + минуты

Теперь проверим, что правило работает и с переменными. `sinov/main.go` («проверка»):

```go filename="sinov/main.go" showLineNumbers
package main

import "fmt"

func main() {
	soat := "10"
	daqiqa := "5"
	fmt.Println(soat + daqiqa)
}
```

- **Строка 6:** новый ярлык `soat` («часы»), значение — `"10"` в кавычках.
- **Строка 7:** новый ярлык `daqiqa` («минута»), значение — `"5"` в кавычках.
- **Строка 8:** соединяет значения под двумя ярлыками плюсом и выводит результат.

В этой строке кавычек не видно. Но плюс смотрит на тип значений, а не на то, как записана строка. Угадайте:
**A)** 15 · **B)** 105 · **C)** ошибка

<details>
<summary>Ответ</summary>

**B: 105.** Под `soat` и `daqiqa` лежат значения в кавычках, то есть `string`. Плюс их склеил: `"10"` и `"5"` →
`"105"`. Это не число сто пять, а три символа рядом: `1`, `0`, `5`. Если вы выбрали «15», вы посмотрели на то, что в
строке 8 нет кавычек. Но тип путешествует вместе со значением: под ярлыком лежит `"10"`.

</details>

```console
$ go run sinov/main.go
105
```

| После строки | `soat` | `daqiqa` | На экране |
|---|---|---|---|
| 6 `soat := "10"` | `"10"` (string) | — | |
| 7 `daqiqa := "5"` | `"10"` | `"5"` (string) | |
| 8 `fmt.Println(soat + daqiqa)` | `"10"` | `"5"` | `105` |

## Смешиваем типы: ошибка

Теперь смешаем два типа. `aralash/main.go` («смешанное»):

```go filename="aralash/main.go" showLineNumbers
package main

import "fmt"

func main() {
	gap := "Yosh: "
	yosh := 15
	fmt.Println(gap + yosh)
}
```

- **Строка 6:** под `gap` («фраза») в кавычках слово `Yosh` («Возраст»), двоеточие и один пробел в конце. Это
  `string`.
- **Строка 7:** под `yosh` — `15` без кавычек, то есть `int`.
- **Строка 8:** хотим соединить их плюсом.

Запустится ли эта программа? Помните: плюс работает только со значениями одного типа, а здесь `string` и `int`.
Угадайте: **A)** `Yosh: 15` · **B)** `15` · **C)** ошибка

<details>
<summary>Ответ</summary>

**C: ошибка.** Типы по двум сторонам плюса разные: слева `string`, справа `int`. Go не знает, что делать: складывать
или склеивать. Если вы выбрали «Yosh: 15», вы думали, что Go сам превратит число в текст. Некоторые языки так делают,
а Go — нет (ниже увидим почему).

</details>

```console
$ go run aralash/main.go
# command-line-arguments
aralash/main.go:8:14: invalid operation: gap + yosh (mismatched types string and int)
```

**Компилятор** (наш переводчик) не перевёл программу, поэтому она не запустилась. На экране нет ни одного результата
программы, только сообщение об ошибке.

### Читаем сообщение об ошибке по частям

| Часть | Значение |
|---|---|
| `# command-line-arguments` | так Go называет программу, когда `go run` получает имя файла; эту строку можно пропустить |
| `aralash/main.go` | ошибка в этом файле |
| `8` | **номер строки**: строка 8 |
| `14` | **позиция символа** в строке: ровно здесь начинается слово `gap` |
| `invalid operation` | «недопустимая операция» |
| `gap + yosh` | какая операция недопустима |
| `(mismatched types string and int)` | причина в скобках: «типы не совпадают: один `string`, другой `int`» |

Как считается 14: один таб в начале строки — это тоже один символ. Дальше `fmt.Println(` — 12 символов (2–13).
Значит, `gap` начинается с 14-го символа.

### Почему Go этого не разрешает?

Некоторые другие языки молча превращают число в текст. Например, в одном из них `"2" + 2` — не ошибка, а `"22"`.
Тогда в программе магазина `"2000" + 2000` может дать не четыре тысячи, а текст `"20002000"`. Такую ошибку можно не
заметить.

А Go проверяет типы во время перевода. Он показывает ошибку ещё до запуска программы. В официальных правилах Go
(Go spec) написано: *"the operand types must be identical"*, то есть типы с двух сторон операции должны совпадать.
(У этого правила есть небольшое исключение, мы рассмотрим его в разделе «Глубже».)

## Исправление: `strconv.Itoa` превращает число в текст

Чтобы исправить, превратим число в текст. Для этого в Go есть ещё одна готовая «коробка с инструментами» (пакет) —
**`strconv`**. Её тоже подключаем через `import`, как `fmt`. `aylantir/main.go` («преобразовать»):

```go filename="aylantir/main.go" showLineNumbers
package main

import "fmt"
import "strconv"

func main() {
	gap := "Yosh: "
	yosh := 15
	fmt.Println(gap + strconv.Itoa(yosh))
}
```

От `aralash/main.go` отличаются только две строки:

| Строка | Код | Что делает |
|---|---|---|
| 4 | `import "strconv"` | **новая:** подключает коробку `strconv` |
| 7–8 | `gap := "Yosh: "`, `yosh := 15` | как раньше: `string` и `int` |
| 9 | `fmt.Println(gap + strconv.Itoa(yosh))` | **изменилась:** `strconv.Itoa(yosh)` создаёт новый текст из целого числа в скобках |

Читайте `strconv.Itoa` изнутри наружу. Сначала берётся `15` из-под `yosh`. `strconv.Itoa` делает из него новый текст
`"15"`. А `yosh` остаётся `int`: его никто не трогал. Потом плюс склеивает два текста.

| Код | Что происходит | Тип |
|---|---|---|
| `gap` | `"Yosh: "` | `string` |
| `yosh` | `15` (не меняется) | `int` |
| `strconv.Itoa(yosh)` | `"15"` (новый текст) | `string` |
| `gap + strconv.Itoa(yosh)` | `"Yosh: "` + `"15"` → `"Yosh: 15"` | `string` |

Что выведет программа? Угадайте: **A)** `Yosh: 15` · **B)** `Yosh:15` · **C)** ошибка

<details>
<summary>Ответ</summary>

**A: `Yosh: 15`.** Теперь с обеих сторон плюса `string`, поэтому Go переводит программу. Пробел между двоеточием и 15
стоял в конце текста `gap`. Если вы выбрали «Yosh:15», вы не заметили этот пробел.

</details>

```console
$ go run aylantir/main.go
Yosh: 15
```

Коротко: если типы не совпадают, Go выдаёт ошибку. А `strconv.Itoa` превращает целое число в текст.

## Деление: почему `7 / 2` даёт три

Теперь деление. Делим семь яблок поровну между двумя детьми, но яблоки не режем: каждый ребёнок получает только целые
яблоки. `bolish/main.go` («деление»):

```go filename="bolish/main.go" showLineNumbers
package main

import "fmt"

func main() {
	olma := 7
	bola := 2
	fmt.Println(olma / bola)
}
```

- **Строки 6–7:** под `olma` («яблоко») 7, под `bola` («ребёнок») 2. Оба `int`.
- **Строка 8:** в коде `/` (косая черта) означает деление: `olma / bola` — «яблоки разделить на детей».

Что выведет программа? Подсказка: `int` хранит только целые числа, а яблоки не режут. **A)** 3,5 · **B)** 3 · **C)** 4

<details>
<summary>Ответ</summary>

**B: 3.** Оба значения `int`, значит, и результат — целое число. Go просто отбрасывает дробную часть, не округляет. Как
в жизни: каждому ребёнку достаётся по три яблока, а одно остаётся. Если вы выбрали «3,5», вы ждали обычного школьного
деления. Если выбрали «4», вы думали, что Go округлит 3,5: он не округляет, он отбрасывает дробь.

</details>

```console
$ go run bolish/main.go
3
```

В официальных правилах Go это называется *"truncated division"*: при делении целых чисел дробная часть отсекается.

## Дробное число: `float64`

А если нам нужно три с половиной? Разливаем семь литров воды в две бутылки: воду можно разделить поровну.

В коде дробь пишется через **точку**, а не через запятую: не `3,5`, а `3.5`. `7` — целое число, `7.0` — число с
точкой. Число с точкой в Go называется **`float64`** (число с плавающей точкой, *floating-point number*).
`suv/main.go`:

```go filename="suv/main.go" showLineNumbers
package main

import "fmt"

func main() {
	suv := 7.0
	shisha := 2.0
	fmt.Println(suv / shisha)
}
```

- **Строки 6–7:** под `suv` («вода») `7.0`, под `shisha` («бутылка») `2.0`. Есть точка, значит, оба `float64`.
- **Строка 8:** такое же деление, как в `bolish`, только теперь значения `float64`.

Что выведет программа? Угадайте: **A)** 3 · **B)** 3.5 · **C)** ошибка

<details>
<summary>Ответ</summary>

**B: 3.5.** Тип — `float64`, поэтому дробная часть сохранилась. Если вы выбрали «3», вы применили правило `int` и к
`float64`. Тип результата зависит от типа значений.

</details>

```console
$ go run suv/main.go
3.5
```

Два числа рядом:

| Код | Тип | Значение | Дробная часть |
|---|---|---|---|
| `olma := 7 / 2` | `int` | `3` | отброшена |
| `suv := 7.0 / 2.0` | `float64` | `3.5` | сохранилась |

`int` и `float64` — тоже два разных типа. Поэтому если смешать **переменные** `int` и `float64`, будет та же ошибка
«типы не совпадают». Вы увидите её сами в задаче 🔴 домашнего задания.

## Глубже (необязательно): число, записанное прямо в коде

Этого раздела нет в видео, он взят из README курса. Выше мы говорили о «**переменных** двух разных типов». Число или
текст, записанные прямо в коде (`2.0`, `15`, `"Yosh: "`), называются **константой**. Её тип ещё не закреплён, поэтому
она немного гибкая. Правило из Go spec: типы должны совпадать, *"unless the operation involves shifts or untyped
constants"*, то есть если участвует константа без типа, есть исключение.

Три примера (их нет в папке курса, мы запустили их отдельно). Первый, `konst/main.go`:

```go
package main

import "fmt"

func main() {
	olma := 7
	fmt.Println(olma / 2.0)
}
```

```console
$ go run konst/main.go
3
```

Ошибки нет: `2.0` использовано как целое число `2`, потому что `olma` — `int`. Дробь всё равно отброшена.

Второй, `konst2/main.go`: та же программа, только `2.5` вместо `2.0`:

```go
package main

import "fmt"

func main() {
	olma := 7
	fmt.Println(olma / 2.5)
}
```

```console
$ go run konst2/main.go
# command-line-arguments
konst2/main.go:7:21: 2.5 (untyped float constant) truncated to int
```

«2.5 (дробная константа без типа) при превращении в `int` была бы обрезана». `2.5` нельзя сделать целым числом без
потери дроби, поэтому Go отказывается.

Третий, `konst3/main.go`: обе — константы, но одна текст, другая число:

```go
package main

import "fmt"

func main() {
	fmt.Println("Yosh: " + 15)
}
```

```console
$ go run konst3/main.go
# command-line-arguments
konst3/main.go:6:14: invalid operation: "Yosh: " + 15 (mismatched types untyped string and untyped int)
```

`untyped string` — текст без закреплённого типа, `untyped int` — целое число без закреплённого типа. Гибкость работает
только между числами: текст и число всё равно не смешиваются. Подробнее о типах:
[GO-1.02 · Типы и overflow](/lab/youtube/go/go-1-02/ru).

## Частые ошибки

**1. Прибавить число к тексту плюсом (самая известная ошибка).** `string + int`, например `"Yosh: " + yosh`. Это
ошибка `mismatched types string and int` из раздела «Смешиваем типы: ошибка». **Исправление:** превратите число в
текст через `strconv.Itoa(yosh)` и добавьте `import "strconv"`.

**2. Число осталось в кавычках.** Хотим прибавить 1 к `yosh`, но записали 15 в кавычках (`matnson/main.go`
(«текст-число»), его нет в папке курса):

```go
package main

import "fmt"

func main() {
	yosh := "15"
	fmt.Println(yosh + 1)
}
```

```console
$ go run matnson/main.go
# command-line-arguments
matnson/main.go:7:14: invalid operation: yosh + 1 (mismatched types string and untyped int)
```

Строка 7, символ 14 (`yosh`): «недопустимая операция: типы не совпадают, `string` и целое число без типа». `"15"` —
это текст, как номер телефона: с ним не считают. **Исправление:** уберите кавычки: `yosh := 15`.

**3. Дробь через запятую.** В узбекской школе пишут `7,5`, а в Go так нельзя (`vergul/main.go` («запятая»), его нет
в папке курса):

```go
package main

import "fmt"

func main() {
	suv := 7,5
	fmt.Println(suv)
}
```

```console
$ go run vergul/main.go
# command-line-arguments
vergul/main.go:6:9: assignment mismatch: 1 variable but 2 values
```

«Несоответствие при присваивании: 1 переменная, но 2 значения». Go прочитал запятую как разделитель двух значений:
`7` и `5`. (В прошлом уроке запятая в `fmt.Println(ochko, rekord)` тоже разделяла два значения.)
**Исправление:** поставьте точку: `suv := 7.5`.

**4. Забыть `import "strconv"`.** Если удалить строку 4 из `aylantir/main.go` (`importsiz/main.go` («без import»),
его нет в папке курса):

```go
package main

import "fmt"

func main() {
	gap := "Yosh: "
	yosh := 15
	fmt.Println(gap + strconv.Itoa(yosh))
}
```

```console
$ go run importsiz/main.go
# command-line-arguments
importsiz/main.go:8:20: undefined: strconv
```

Строка 8, символ 20 (`strconv`): «имя `strconv` не найдено». Коробка не подключена, поэтому Go её не знает.
**Исправление:** добавьте строку `import "strconv"`.

**5. Ждать 3.5 от `7 / 2` (тихая ошибка).** Сообщения об ошибке нет, но результат — `3`. Мы видели это в разделе
«Деление: почему `7 / 2` даёт три»: если оба значения `int`, дробь отбрасывается. **Исправление:** если нужна дробь,
пишите числа с точкой: `7.0 / 2.0` (`float64`).

**6. Забыть пробел (тихая ошибка).** `"Mening yoshim" + strconv.Itoa(yosh)` работает без ошибок, но слово и число
слипаются (`boshjoy/main.go` («пробел»), его нет в папке курса; `Mening yoshim` — «Мой возраст»):

```go
package main

import "fmt"
import "strconv"

func main() {
	yosh := 15
	fmt.Println("Mening yoshim" + strconv.Itoa(yosh))
}
```

```console
$ go run boshjoy/main.go
Mening yoshim15
```

Плюс склеивает тексты, ничего не добавляя между ними. **Исправление:** поставьте пробел в конце текста:
`"Mening yoshim "`, как в `"Yosh: "`.

## Проверьте себя

Сначала ответьте сами, потом откройте ответ.

**1.** Какого типа `"15"` в кавычках?

<details>
<summary>Ответ</summary>

`string`, потому что есть кавычки. Это не число, а два символа: `1` и `5`.

</details>

**2.** Что будет, если соединить плюсом `string` и `int`?

<details>
<summary>Ответ</summary>

Компилятор не переведёт программу: будет ошибка `mismatched types string and int` («типы не совпадают»). Чтобы её
исправить, превращаем число в текст через `strconv.Itoa`.

</details>

**3.** Если оба `int`, сколько будет `7 / 2`?

<details>
<summary>Ответ</summary>

`3`, потому что дробная часть отбрасывается (а не округляется). Чтобы получить `3.5`, пишем `7.0 / 2.0`: это
`float64`.

</details>

**4.** Что выведет эта программа? (`ikkiming/main.go` («две тысячи»), его нет в папке курса.)

```go
package main

import "fmt"

func main() {
	fmt.Println("2000" + "2000")
	fmt.Println(2000 + 2000)
}
```

**A)** 4000 и 4000 · **B)** 20002000 и 4000 · **C)** ошибка

<details>
<summary>Ответ</summary>

**B.** В первой строке склеили два значения `string`, во второй сложили два значения `int`. Ошибки нет, потому что у
каждого плюса с обеих сторон один и тот же тип.

```console
$ go run ikkiming/main.go
20002000
4000
```

</details>

**5.** Из прошлого урока: что выведет эта программа? И что будет, если в строке 7 написать `:=` вместо `=`?
(`narx/main.go`, его нет в папке курса; `narx` — «цена».)

```go
package main

import "fmt"

func main() {
	narx := "10"
	narx = narx + "0"
	fmt.Println(narx)
}
```

<details>
<summary>Ответ</summary>

Выведет `100`: пусть `narx` теперь будет склейкой `"10"` и `"0"`, то есть текстом `"100"` (а не числом сто).

```console
$ go run narx/main.go
100
```

С `:=` будет ошибка `no new variables on left side of :=`: ярлык `narx` создан в строке 6, второй раз создать его
нельзя ([GO-0.02](/lab/youtube/go/go-0-02/ru)).

</details>

🔴 Сначала ошибка:

```console

uyga/qiyin/main.go:8:14: invalid operation: olma / shisha (mismatched types int and float64)
```

Строка 8, символ 14 (`olma`): «типы не совпадают: один `int`, другой `float64`». `int` и `float64` — тоже разные
типы. Есть два исправления:

- поставить точку, как в видео: `olma := 7.0` → `3.5`;

}

3.5
