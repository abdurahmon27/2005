## Nimani oʻrganasiz

Kalkulyatorda `2 + 2` har doim `4` boʻladi. Go dasturida esa xuddi shunga oʻxshash `2 + 2` ekranga `22` chiqarishi
mumkin. Farq bitta kichik belgida yashiringan. Bu darsda oʻsha belgini topasiz.

**Bitta gʻoya:** har bir qiymatning turi bor. Qoʻshtirnoq bilan yozilgan qiymat matn, qoʻshtirnoqsiz butun son esa
son. Plyus faqat bir xil turdagi ikki qiymat bilan ishlaydi: sonlarni qoʻshadi, matnlarni yopishtiradi.
Aralashtirsangiz, Go dasturni tarjima qilmaydi.

Dars oxirida siz:

- `15` va `"15"` qaysi turda ekanini ayta olasiz;
- `+` ikki son bilan va ikki matn bilan nima qilishini oldindan aytib bera olasiz;
- `mismatched types` xatosini oʻqib, uni `strconv.Itoa` bilan tuzata olasiz;
- nega `7 / 2` Go'da `3` chiqishini va `3.5` ni qanday olishni tushuntira olasiz.

Bugungi yangi soʻzlar:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| tur | qiymatning xili: u bilan hisob qilinadimi yoki u faqat yoziladimi | type |
| `int` | butun son: `15`, `7`, `2` | int (integer) |
| `string` | matn, kodda qoʻshtirnoq ichida yoziladi: `"15"`, `"Salom"` | string |

Yana ikkita yordamchi soʻz bor: `float64` (nuqtali, kasrli son) va `strconv.Itoa` (butun sondan matn yasaydi). Ular
oʻz boʻlimida tushuntiriladi.

## Har bir qiymatning turi bor

Anketani tasavvur qiling. Unda ikki qator bor: yoshingiz va telefon raqamingiz. Ikkalasi ham raqamlardan iborat.

```text
Yosh:     15             → +1 → 16   (keyingi yilgi yoshingiz)
Telefon:  90 123 45 67   → +1 → ?    (telefon bilan hisob qilinmaydi)
```

Yoshga bir qoʻshsangiz, keyingi yilgi yoshingiz chiqadi. Telefon raqami bilan esa hisob qilinmaydi, u faqat
yoziladi. Demak, ikki qiymat bir xil raqamlardan tuzilgan boʻlsa ham, ular ikki xil.

Kompyuter ham har bir qiymatning xilini bilishi kerak: uni qoʻshadimi yoki faqat yozadimi. Qiymatning xili
dasturlashda **tur**, inglizcha **type** deyiladi. Go'da har bir qiymatning turi bor.

Bugun ikki asosiy turni koʻramiz:

- Go'da butun sonning asosiy turi **`int`** deyiladi. `yosh := 15` dagi `15` qoʻshtirnoqsiz yozilgan, bu `int`.
- Matn **`string`** deyiladi. Birinchi darsdagi `"Salom, dunyo!"` kabi, kodda matnni qoʻshtirnoq ichida yozamiz.
  `yozuv := "15"` dagi `"15"` qoʻshtirnoq ichida, bu `string`, xuddi telefon raqami kabi.

```go
yosh := 15
yozuv := "15"
```

(`yozuv` — «yozuv», inglizcha "text, writing".) Xotira rasmi:

| Yorliq | Qiymat (xotirada) | Turi | Nima uchun |
|---|---|---|---|
| `yosh` | `15` | `int` | butun son, qoʻshtirnoq yoʻq |
| `yozuv` | `"15"` | `string` | qoʻshtirnoq bor: bu ikki belgi, `1` va `5` |

Ikkalasida ham 15 bor, lekin bu ikki xil qiymat. Turni Go qiymatning yozilishidan biladi: qoʻshtirnoq bor boʻlsa
`string`, qoʻshtirnoqsiz butun son boʻlsa `int`.

## Plyus avval turga qaraydi

Endi plyusni ikkala turda sinaymiz. Bu kurs papkasidagi `qoshish/main.go` fayli:

```go filename="qoshish/main.go" showLineNumbers
package main

import "fmt"

func main() {
	fmt.Println(2 + 2)
	fmt.Println("2" + "2")
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1 | `package main` | birinchi darsdagi qolip: bu ishga tushadigan dastur |
| 3 | `import "fmt"` | ekranga chiqarish asboblari turgan `fmt` qutisini (paketini) ulaydi |
| 5 | `func main() {` | dastur shu yerdan boshlanadi |
| 6 | `fmt.Println(2 + 2)` | qoʻshtirnoqsiz ikki plyus ikki: ikkita `int` |
| 7 | `fmt.Println("2" + "2")` | qoʻshtirnoqdagi ikki plyus qoʻshtirnoqdagi ikki: ikkita `string` |
| 8 | `}` | `main` tugadi, dastur tugadi |

`fmt.Println` qavs ichidagi narsani ekranga chiqaradi. Bu dastur ekranga ikki qator chiqaradi. Ishga tushirishdan
oldin taxmin qiling: **A)** 4 va 4 · **B)** 4 va 22 · **C)** xato

<details>
<summary>Javob</summary>

**B: 4 va 22.** Boshidagi oʻsha kichik belgi mana shu qoʻshtirnoq edi. 6-qatorda ikkala qiymat `int`, ular
qoʻshildi. 7-qatorda ikkala qiymat `string`, ular yonma-yon yopishtirildi. «4 va 4» ni tanlagan boʻlsangiz,
qoʻshtirnoqqa eʼtibor bermagansiz. «xato» ni tanlagan boʻlsangiz, matnlarni plyus bilan birlashtirib boʻlmaydi deb
oʻylagansiz: boʻladi, faqat natija yigʻindi emas, yopishtirilgan matn.

</details>

Terminalda tekshiramiz. `go run` buyrugʻi `qoshish` papkasidagi `main.go` faylini tarjima qilib, darhol ishga
tushiradi:

```console
$ go run qoshish/main.go
4
22
```

Nega shunday? Qoʻshtirnoq bilan yozilgan qiymat matn boʻladi. Plyus esa avval ikki tomonning turiga qaraydi:

| Kod | Chap tomon | Oʻng tomon | `+` nima qiladi | Natija |
|---|---|---|---|---|
| `2 + 2` | `int` | `int` | qoʻshadi | `4` (son) |
| `"2" + "2"` | `string` | `string` | yonma-yon yopishtiradi | `"22"` (matn) |

`Println` matnni qoʻshtirnoqsiz chiqaradi, shuning uchun ekrandagi `22` son kabi koʻrinadi. Aslida bu yigirma ikki
soni emas, yonma-yon turgan ikkita `2` belgisi:

```text
"2"  +  "2"   →   "22"
[2]     [2]       [2][2]     ikkita belgi, son emas
```

Qisqasi, plyus faqat bir xil turdagi ikki qiymat bilan ishlaydi. Ikkalasi `int` boʻlsa, qoʻshadi. Ikkalasi `string`
boʻlsa, yopishtiradi. Matnlarni bunday yopishtirish inglizcha **string concatenation** deyiladi.

## Kichik sinov: soat + daqiqa

Endi qoida oʻzgaruvchilar bilan ham ishlashini tekshiramiz. `sinov/main.go`:

```go filename="sinov/main.go" showLineNumbers
package main

import "fmt"

func main() {
	soat := "10"
	daqiqa := "5"
	fmt.Println(soat + daqiqa)
}
```

- **6-qator:** yangi `soat` yorligʻi («soat», "hour"), qiymati qoʻshtirnoqdagi `"10"`.
- **7-qator:** yangi `daqiqa` yorligʻi («daqiqa», "minute"), qiymati qoʻshtirnoqdagi `"5"`.
- **8-qator:** ikki yorliq ostidagi qiymatlarni plyus bilan birlashtirib, ekranga chiqaradi.

Bu qatorda qoʻshtirnoq koʻrinmaydi. Lekin plyus qiymatlarning turiga qaraydi, yozuvga emas. Taxmin qiling:
**A)** 15 · **B)** 105 · **C)** xato

<details>
<summary>Javob</summary>

**B: 105.** `soat` va `daqiqa` ostida qoʻshtirnoqli qiymat, yaʼni `string` bor. Plyus ularni yopishtirdi: `"10"` va
`"5"` → `"105"`. Bu yuz besh soni emas, yonma-yon turgan uchta belgi: `1`, `0`, `5`. «15» ni tanlagan boʻlsangiz,
8-qatorda qoʻshtirnoq yoʻqligiga qaragansiz. Lekin tur qiymat bilan birga yuradi: yorliq ostida `"10"` turibdi.

</details>

```console
$ go run sinov/main.go
105
```

| Qatordan keyin | `soat` | `daqiqa` | Ekranda |
|---|---|---|---|
| 6 `soat := "10"` | `"10"` (string) | — | |
| 7 `daqiqa := "5"` | `"10"` | `"5"` (string) | |
| 8 `fmt.Println(soat + daqiqa)` | `"10"` | `"5"` | `105` |

## Turlarni aralashtirsak: xato

Endi ikki turni aralashtiramiz. `aralash/main.go`:

```go filename="aralash/main.go" showLineNumbers
package main

import "fmt"

func main() {
	gap := "Yosh: "
	yosh := 15
	fmt.Println(gap + yosh)
}
```

- **6-qator:** `gap` («gap», "sentence") ostida qoʻshtirnoq ichida `Yosh` soʻzi, ikki nuqta va oxirida bitta boʻsh
  joy bor. Bu `string`.
- **7-qator:** `yosh` ostida qoʻshtirnoqsiz `15`, yaʼni `int`.
- **8-qator:** ularni plyus bilan birlashtirmoqchimiz.

Bu dastur ishga tushadimi? Esingizda boʻlsin: plyus faqat bir xil turdagi qiymatlar bilan ishlaydi, bu yerda esa
`string` va `int`. Taxmin qiling: **A)** `Yosh: 15` · **B)** `15` · **C)** xato

<details>
<summary>Javob</summary>

**C: xato.** Plyusning ikki tomonidagi turlar har xil: chapda `string`, oʻngda `int`. Go ulardan qaysi birini
qilishni bilmaydi: qoʻshishnimi yoki yopishtirishnimi. «Yosh: 15» ni tanlagan boʻlsangiz, Go sonni oʻzi matnga
aylantiradi deb oʻylagansiz. Ayrim tillar shunday qiladi, Go esa yoʻq (pastda nega ekanini koʻramiz).

</details>

```console
$ go run aralash/main.go
# command-line-arguments
aralash/main.go:8:14: invalid operation: gap + yosh (mismatched types string and int)
```

**Kompilyator** (tarjimonimiz) dasturni tarjima qilmadi, shuning uchun u ishga tushmadi. Ekranda dasturning birorta
ham natijasi yoʻq, faqat xato xabari bor.

### Xato xabarini qismlarga boʻlib oʻqiymiz

| Qism | Maʼnosi |
|---|---|
| `# command-line-arguments` | `go run` ga fayl nomi berilganda Go dasturni shunday ataydi; bu qatorni oʻtkazib yuborsa boʻladi |
| `aralash/main.go` | xato shu faylda |
| `8` | **qator raqami**: 8-qator |
| `14` | qatordagi **belgi oʻrni**: aynan `gap` soʻzi shu yerdan boshlanadi |
| `invalid operation` | «notoʻgʻri amal» |
| `gap + yosh` | qaysi amal notoʻgʻri |
| `(mismatched types string and int)` | qavs ichida sabab: «turlar mos emas: biri `string`, biri `int`» |

14 qanday sanaladi: qator boshidagi bitta tab ham bitta belgi. Keyin `fmt.Println(` 12 ta belgi (2–13). Demak,
`gap` 14-belgidan boshlanadi.

### Nega Go bunga ruxsat bermaydi?

Ayrim boshqa tillar sonni jimgina matnga aylantiradi. Masalan, ulardan birida `"2" + 2` xato emas, `"22"`
beradi. Unda doʻkon dasturida `"2000" + 2000` toʻrt ming emas, `"20002000"` degan matn boʻlib qolishi mumkin.
Bunday xato koʻzga tashlanmay qolishi mumkin.

Go esa turlarni tarjima paytida tekshiradi. Xatoni dastur ishga tushmasdan oldin koʻrsatadi. Go'ning rasmiy
qoidasida (Go spec) shunday yozilgan: *"the operand types must be identical"*, yaʼni amalning ikki tomonidagi turlar
bir xil boʻlishi kerak. (Bu qoidaning kichik istisnosi bor, uni «Chuqurroq» boʻlimida koʻramiz.)

## Tuzatish: `strconv.Itoa` sonni matnga aylantiradi

Tuzatish uchun sonni matnga aylantiramiz. Go'da buning uchun **`strconv`** degan yana bir tayyor asboblar qutisi
(paket) bor. Uni ham `fmt` kabi `import` qilamiz. `aylantir/main.go`:

```go filename="aylantir/main.go" showLineNumbers
package main

import "fmt"
import "strconv"

func main() {
	gap := "Yosh: "
	yosh := 15
	fmt.Println(gap + strconv.Itoa(yosh))
}
```

`aralash/main.go` dan faqat ikki qator farq qiladi:

| Qator | Kod | Nima qiladi |
|---|---|---|
| 4 | `import "strconv"` | **yangi:** `strconv` qutisini ulaydi |
| 7–8 | `gap := "Yosh: "`, `yosh := 15` | avvalgidek: `string` va `int` |
| 9 | `fmt.Println(gap + strconv.Itoa(yosh))` | **oʻzgardi:** `strconv.Itoa(yosh)` qavs ichidagi butun sondan yangi matn yaratadi |

`strconv.Itoa` ni ichkaridan tashqariga qarab oʻqing. Avval `yosh` ostidagi `15` olinadi. `strconv.Itoa` undan yangi
`"15"` matnini yasaydi. `yosh` esa `int` boʻlib qoladi, unga hech kim tegmadi. Keyin plyus ikki matnni yopishtiradi.

| Kod | Nima boʻladi | Turi |
|---|---|---|
| `gap` | `"Yosh: "` | `string` |
| `yosh` | `15` (oʻzgarmaydi) | `int` |
| `strconv.Itoa(yosh)` | `"15"` (yangi matn) | `string` |
| `gap + strconv.Itoa(yosh)` | `"Yosh: "` + `"15"` → `"Yosh: 15"` | `string` |

Nima chiqadi, taxmin qiling: **A)** `Yosh: 15` · **B)** `Yosh:15` · **C)** xato

<details>
<summary>Javob</summary>

**A: `Yosh: 15`.** Endi plyusning ikki tomonida ham `string` bor, shuning uchun Go dasturni tarjima qiladi. Ikki
nuqta bilan 15 orasidagi boʻsh joy `gap` matnining oxirida turgan edi. «Yosh:15» ni tanlagan boʻlsangiz, oʻsha boʻsh
joyni koʻrmagansiz.

</details>

```console
$ go run aylantir/main.go
Yosh: 15
```

Qisqasi: turlar mos kelmasa, Go xato beradi. `strconv.Itoa` esa butun sonni matnga aylantiradi.

## Boʻlish: nega `7 / 2` uch chiqadi

Endi boʻlishga oʻtamiz. Yetti olmani ikki bolaga teng boʻlamiz, lekin olmani kesmaymiz: har bola faqat butun olma
oladi. `bolish/main.go`:

```go filename="bolish/main.go" showLineNumbers
package main

import "fmt"

func main() {
	olma := 7
	bola := 2
	fmt.Println(olma / bola)
}
```

- **6–7-qatorlar:** `olma` («olma», "apple") ostida 7, `bola` («bola», "child") ostida 2. Ikkalasi ham `int`.
- **8-qator:** kodda `/` (qiya chiziq) boʻlishni anglatadi: `olma / bola` — «olma boʻlinsin bolaga».

Ekranga nima chiqadi? Ishora: `int` faqat butun son saqlaydi, olma esa kesilmaydi. **A)** 3,5 · **B)** 3 · **C)** 4

<details>
<summary>Javob</summary>

**B: 3.** Ikkala qiymat ham `int`, demak natija ham butun son. Go kasr qismini shunchaki tashlab yuboradi,
yaxlitlamaydi. Hayotdagidek: har bir bolaga uchtadan olma tegadi, bittasi esa ortib qoladi. «3,5» ni tanlagan
boʻlsangiz, maktabdagi oddiy boʻlishni kutgansiz. «4» ni tanlagan boʻlsangiz, Go 3,5 ni yaxlitlaydi deb oʻylagansiz:
yaxlitlamaydi, kasrni tashlaydi.

</details>

```console
$ go run bolish/main.go
3
```

Go'ning rasmiy qoidasida bu *"truncated division"* deyiladi: butun sonlarni boʻlganda kasr qismi kesib tashlanadi.

## Kasrli son: `float64`

Agar bizga uch yarim kerak boʻlsa-chi? Yetti litr suvni ikki shishaga quyamiz: suvni teng boʻlish mumkin.

Kodda kasr son vergul bilan emas, **nuqta** bilan yoziladi: `3,5` emas, `3.5`. `7` butun son boʻlsa, `7.0` nuqtali
son. Nuqtali son Go'da **`float64`** deyiladi (kasrli son, inglizcha *floating-point number*). `suv/main.go`:

```go filename="suv/main.go" showLineNumbers
package main

import "fmt"

func main() {
	suv := 7.0
	shisha := 2.0
	fmt.Println(suv / shisha)
}
```

- **6–7-qatorlar:** `suv` («suv», "water") ostida `7.0`, `shisha` («shisha», "bottle") ostida `2.0`. Nuqta bor,
  demak ikkalasi `float64`.
- **8-qator:** xuddi `bolish` dagidek boʻlish, faqat endi `float64` lar.

Nima chiqadi, taxmin qiling: **A)** 3 · **B)** 3.5 · **C)** xato

<details>
<summary>Javob</summary>

**B: 3.5.** Turi `float64` boʻlgani uchun kasr qismi saqlanib qoldi. «3» ni tanlagan boʻlsangiz, `int` qoidasini
`float64` ga ham qoʻllagansiz. Natija turi qiymatlarning turiga bogʻliq.

</details>

```console
$ go run suv/main.go
3.5
```

Ikkala son yonma-yon:

| Kod | Turi | Qiymat | Kasr qismi |
|---|---|---|---|
| `olma := 7 / 2` | `int` | `3` | tashlandi |
| `suv := 7.0 / 2.0` | `float64` | `3.5` | qoldi |

`int` va `float64` ham ikki xil tur. Shuning uchun `int` va `float64` **oʻzgaruvchilarni** aralashtirsangiz, xuddi
shu «turlar mos emas» xatosi chiqadi. Buni uy vazifasining 🔴 topshirigʻida oʻzingiz koʻrasiz.

## Chuqurroq (ixtiyoriy): kodga toʻgʻridan-toʻgʻri yozilgan son

Bu boʻlim videoda yoʻq, u kurs README'sidan olingan. Yuqorida «ikki xil turdagi **oʻzgaruvchilar**» dedik. Kodga
toʻgʻridan-toʻgʻri yozilgan son yoki matn (`2.0`, `15`, `"Yosh: "`) **konstanta** deyiladi. Uning turi hali qatʼiy
belgilanmagan, shuning uchun u biroz moslashuvchan. Go spec qoidasi: turlar bir xil boʻlishi kerak, *"unless the
operation involves shifts or untyped constants"* — yaʼni turi belgilanmagan konstanta qatnashsa, istisno bor.

Uchta misol (ular kurs papkasida yoʻq, biz alohida ishga tushirdik). Birinchisi, `konst/main.go`:

```go
package main

import "fmt"

func main() {
	olma := 7
	fmt.Println(olma / 2.0)
}
```

```console
$ go run konst/main.go
3
```

Xato yoʻq: `2.0` butun son `2` sifatida ishlatildi, chunki `olma` — `int`. Kasr baribir tashlandi.

Ikkinchisi, `konst2/main.go`: xuddi shu dastur, faqat `2.0` oʻrnida `2.5`:

```go
package main

import "fmt"

func main() {
	olma := 7
	fmt.Println(olma / 2.5)
}
```

```console
$ go run konst2/main.go
# command-line-arguments
konst2/main.go:7:21: 2.5 (untyped float constant) truncated to int
```

«2.5 (turi belgilanmagan kasrli konstanta) `int` ga aylantirilganda kesilib qoladi». `2.5` ni butun songa
aylantirib boʻlmaydi, kasr yoʻqolar edi, shuning uchun Go rad etadi.

Uchinchisi, `konst3/main.go`: ikkalasi ham konstanta, lekin biri matn, biri son:

```go
package main

import "fmt"

func main() {
	fmt.Println("Yosh: " + 15)
}
```

```console
$ go run konst3/main.go
# command-line-arguments
konst3/main.go:6:14: invalid operation: "Yosh: " + 15 (mismatched types untyped string and untyped int)
```

`untyped string` — turi belgilanmagan matn, `untyped int` — turi belgilanmagan butun son. Moslashuvchanlik faqat
sonlar orasida: matn va son baribir aralashmaydi. Turlar haqida batafsil:
[GO-1.02 · Turlar va overflow](/lab/youtube/go#go-1-02).

## Koʻp uchraydigan xatolar

**1. Matnga sonni plyus bilan qoʻshish (eng mashhur xato).** `"Yosh: " + yosh` kabi `string + int`. Bu
«Turlarni aralashtirsak: xato» boʻlimida koʻrgan `mismatched types string and int` xatosi. **Tuzatish:** sonni
`strconv.Itoa(yosh)` bilan matnga aylantiring va `import "strconv"` qoʻshing.

**2. Son qoʻshtirnoq ichida qolib ketgan.** `yosh` ga 1 qoʻshmoqchimiz, lekin 15 ni qoʻshtirnoq ichida yozib
qoʻyganmiz (`matnson/main.go`, kurs papkasida yoʻq):

```go
package main

import "fmt"

func main() {
	yosh := "15"
	fmt.Println(yosh + 1)
}
```

```console
$ go run matnson/main.go
# command-line-arguments
matnson/main.go:7:14: invalid operation: yosh + 1 (mismatched types string and untyped int)
```

7-qator, 14-belgi (`yosh`): «notoʻgʻri amal: turlar mos emas, `string` va turi belgilanmagan butun son». `"15"` —
telefon raqami kabi matn, u bilan hisob qilinmaydi. **Tuzatish:** qoʻshtirnoqni olib tashlang: `yosh := 15`.

**3. Kasr sonni vergul bilan yozish.** Maktabda `7,5` deb yozamiz, Go'da esa bunday boʻlmaydi
(`vergul/main.go`, kurs papkasida yoʻq):

```go
package main

import "fmt"

func main() {
	suv := 7,5
	fmt.Println(suv)
}
```

```console
$ go run vergul/main.go
# command-line-arguments
vergul/main.go:6:9: assignment mismatch: 1 variable but 2 values
```

«Qiymat berishda nomuvofiqlik: 1 ta oʻzgaruvchi, lekin 2 ta qiymat». Go vergulni ikki qiymat orasidagi ajratuvchi
deb oʻqidi: `7` va `5`. (Oldingi darsdagi `fmt.Println(ochko, rekord)` da ham vergul ikki qiymatni ajratgan edi.)
**Tuzatish:** nuqta qoʻying: `suv := 7.5`.

**4. `import "strconv"` ni unutish.** `aylantir/main.go` ning 4-qatorini oʻchirsak (`importsiz/main.go`, kurs
papkasida yoʻq):

```go
package main

import "fmt"

func main() {
	gap := "Yosh: "
	yosh := 15
	fmt.Println(gap + strconv.Itoa(yosh))
}
```

```console
$ go run importsiz/main.go
# command-line-arguments
importsiz/main.go:8:20: undefined: strconv
```

8-qator, 20-belgi (`strconv`): «`strconv` degan nom topilmadi». Quti ulanmagan, shuning uchun Go uni tanimaydi. **Tuzatish:** `import "strconv"`
qatorini qoʻshing.

**5. `7 / 2` dan 3.5 kutish (jim xato).** Xato xabari chiqmaydi, lekin natija `3`. Buni «Boʻlish: nega `7 / 2` uch
chiqadi» boʻlimida koʻrdik: ikkala qiymat `int` boʻlsa, kasr tashlanadi. **Tuzatish:** kasr kerak boʻlsa, nuqtali
son yozing: `7.0 / 2.0` (`float64`).

**6. Boʻsh joyni unutish (jim xato).** `"Mening yoshim" + strconv.Itoa(yosh)` xatosiz ishlaydi, lekin soʻz bilan
son yopishib qoladi (`boshjoy/main.go`, kurs papkasida yoʻq):

```go
package main

import "fmt"
import "strconv"

func main() {
	yosh := 15
	fmt.Println("Mening yoshim" + strconv.Itoa(yosh))
}
```

```console
$ go run boshjoy/main.go
Mening yoshim15
```

Plyus matnlarni hech narsa qoʻshmasdan yopishtiradi. **Tuzatish:** boʻsh joyni matnning oxiriga yozing:
`"Mening yoshim "`, xuddi `"Yosh: "` dagidek.

## Oʻzingizni tekshiring

Avval oʻzingiz javob bering, keyin oching.

**1.** Qoʻshtirnoq ichidagi `"15"` qaysi turda?

<details>
<summary>Javob</summary>

`string`, chunki qoʻshtirnoq bor. Bu son emas, ikki belgi: `1` va `5`.

</details>

**2.** `string` bilan `int` ni plyus bilan birlashtirsak nima boʻladi?

<details>
<summary>Javob</summary>

Kompilyator dasturni tarjima qilmaydi: `mismatched types string and int` («turlar mos emas») xatosi chiqadi.
Tuzatish uchun sonni `strconv.Itoa` bilan matnga aylantiramiz.

</details>

**3.** Ikkalasi `int` boʻlsa, `7 / 2` nechchi?

<details>
<summary>Javob</summary>

`3`, chunki kasr qismi tashlanadi (yaxlitlanmaydi). `3.5` olish uchun `7.0 / 2.0` yozamiz, ular `float64`.

</details>

**4.** Bu dastur nimani chiqaradi? (`ikkiming/main.go`, kurs papkasida yoʻq.)

```go
package main

import "fmt"

func main() {
	fmt.Println("2000" + "2000")
	fmt.Println(2000 + 2000)
}
```

**A)** 4000 va 4000 · **B)** 20002000 va 4000 · **C)** xato

<details>
<summary>Javob</summary>

**B.** Birinchi qatorda ikki `string` yopishtirildi, ikkinchisida ikki `int` qoʻshildi. Xato yoʻq, chunki har bir
plyusning ikki tomonida bir xil tur turibdi.

```console
$ go run ikkiming/main.go
20002000
4000
```

</details>

**5.** Oldingi darsdan: bu dastur nimani chiqaradi? Va 7-qatorda `=` oʻrniga `:=` yozsak nima boʻladi?
(`narx/main.go`, kurs papkasida yoʻq; `narx` — «narx», "price".)

```go
package main

import "fmt"

func main() {
	narx := "10"
	narx = narx + "0"
	fmt.Println(narx)
}
```

<details>
<summary>Javob</summary>

`100` chiqadi: `narx` endi `"10"` va `"0"` ning yopishtirilgani boʻlsin, yaʼni `"100"` matni (yuz soni emas).

```console
$ go run narx/main.go
100
```

`:=` yozsak, `no new variables on left side of :=` xatosi chiqadi: `narx` yorligʻi 6-qatorda yaratilgan, uni
ikkinchi marta yaratib boʻlmaydi ([GO-0.02](/lab/youtube/go/go-0-02)).

</details>

Avval oʻzingiz urinib koʻring.

🟢 **Oson** (`uyga/oson/main.go`): dastur `7 / 2` ni `3` deb chiqaradi. Faqat ikki qatorni oʻzgartirib, `3.5`
chiqaradigan qiling.

```go filename="uyga/oson/main.go" showLineNumbers
package main

import "fmt"

func main() {
	olma := 7
	bola := 2
	fmt.Println(olma / bola)
}
```

🟡 **Oʻrta** (`uyga/orta/main.go`): dastur ikki qator chiqaradi: `Mening yoshim` va `15`. Uni bitta qatorga,
`Mening yoshim 15` qilib chiqaring.

```go filename="uyga/orta/main.go" showLineNumbers
package main

import "fmt"

func main() {
	yosh := 15
	fmt.Println("Mening yoshim")
	fmt.Println(yosh)
}
```

🔴 **Qiyin** (`uyga/qiyin/main.go`): `olma := 7` va `shisha := 2.0` ni boʻlib koʻring. Xatoni oʻqing va tuzating.

```go filename="uyga/qiyin/main.go" showLineNumbers
package main

import "fmt"

func main() {
	olma := 7
	shisha := 2.0
	fmt.Println(olma / shisha)
}
```

<details>
<summary>Javob</summary>

🟢 6–7-qatorlarga nuqta qoʻying: `olma := 7.0` va `bola := 2.0`. Endi ikkalasi `float64`. (Javob fayli kurs
papkasida yoʻq, biz uni `javob-oson/main.go` sifatida ishga tushirdik.)

```go
package main

import "fmt"

func main() {
	olma := 7.0
	bola := 2.0
	fmt.Println(olma / bola)
}
```

```console
$ go run javob-oson/main.go
3.5
```

Diqqat: butun chiqadigan `float64` nuqtasiz koʻrinadi. `fmt.Println(6.0 / 2.0)` `3.0` emas, `3` chiqaradi.

🟡 `strconv` ni ulang va sonni matnga aylantiring. Matn oxiridagi boʻsh joy soʻz bilan sonni ajratadi:

```go
package main

import "fmt"
import "strconv"

func main() {
	yosh := 15
	fmt.Println("Mening yoshim " + strconv.Itoa(yosh))
}
```

```console
$ go run javob-orta/main.go
Mening yoshim 15
```

🔴 Avval xato:

```console
$ go run uyga/qiyin/main.go
# command-line-arguments
uyga/qiyin/main.go:8:14: invalid operation: olma / shisha (mismatched types int and float64)
```

8-qator, 14-belgi (`olma`): «turlar mos emas: biri `int`, biri `float64`». `int` bilan `float64` ham har xil tur.
Ikki tuzatish bor:

- videodagidek nuqta qoʻyish: `olma := 7.0` → `3.5`;
- yoki aniq aylantirish: `fmt.Println(float64(olma) / shisha)`. `float64(...)` qavs ichidagi butun sonni kasrli
  songa aylantiradi. Go buni oʻzi jimgina qilmaydi, uni siz yozasiz.

```go
package main

import "fmt"

func main() {
	olma := 7
	shisha := 2.0
	fmt.Println(float64(olma) / shisha)
}
```

```console
$ go run javob-qiyin/main.go
3.5
```

</details>
