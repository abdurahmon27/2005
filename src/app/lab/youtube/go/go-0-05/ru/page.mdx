## Что вы узнаете

Представьте наказание: написать на доске одну фразу сто раз. Рука быстро устанет. А компьютер не устанет, даже если
напишет фразу миллион раз. Как ему это поручить? Этому и посвящён урок.

**Главная идея:** цикл выполняет одно и то же действие снова и снова. Счётчик задаётся один раз в начале, перед
каждым кругом задаётся вопрос, а после каждого круга шаг увеличивает счётчик. Если забыть шаг, цикл не закончится, и
программу придётся остановить клавишами **Ctrl+C**. А выйти из цикла изнутри можно с помощью `break`.

К концу урока вы сможете:

- прочитать строку `for i := 1; i <= 3; i++` простыми словами: начало, вопрос, шаг;
- сказать, сколько раз повторится цикл и что появится на экране, ещё до запуска программы;
- посчитать с помощью цикла сумму (1 + 2 + 3 + 4 + 5);
- узнать бесконечный цикл, остановить его через Ctrl+C, исправить его и выйти из цикла с помощью `break`.

Новых слов сегодня три:

| Слово | Простой смысл | По-английски |
|---|---|---|
| цикл (`for`) | выполнять одно действие снова и снова | loop |
| счётчик (`i`) | переменная, которая считает круги | counter |
| `break` | выйти из цикла изнутри, сразу | break |

Встретятся и два вспомогательных слова: `++` («плюс плюс», увеличить на единицу) и **бесконечный цикл** (цикл,
который никогда не заканчивается).

## Одно действие снова и снова: цикл

Допустим, нужно вывести на экран числа от 1 до 5. С тем, что мы уже знаем, пишем отдельный `Println` для каждого
числа:

```go
fmt.Println(1)
fmt.Println(2)
fmt.Println(3)
fmt.Println(4)
fmt.Println(5)
```

Пять чисел — пять строк. А если нужен миллион чисел? Миллион строк вручную никто писать не будет.

Пример из жизни. На стадионе тренер говорит: «Пробегите три круга». Перед каждым кругом вы спрашиваете себя: «номер
круга меньше или равен 3?» Если да, бежите ещё один круг и прибавляете к счёту единицу. Если нет, останавливаетесь.

```text
  начинаем с 1-го круга              (начало)
           │
           ▼
  ┌─► номер круга ≤ 3? ── нет ──► останавливаемся
  │        │ да                    (вопрос)
  │        ▼
  │   🏃 бежим один круг           (повторяемое действие)
  │        │
  │        ▼
  └── к счёту +1                   (шаг)
```

Такое повторение одного действия снова и снова по-русски называется **цикл**, по-английски **loop**. На картинке
три части: **начало** (откуда считаем), **вопрос** (бежим ещё круг?) и **шаг** (прибавить к счёту единицу). В коде
на Go они точно такие же.

## Счётчик: ярлык, который считает круги

Когда бегаете, вы считаете круги, загибая пальцы. В программе это делает отдельная переменная. Она по-русски
называется **счётчик**, по-английски **counter**, а имя у неё обычно `i`.

Счётчик — такой же обычный ярлык, как в [GO-0.02](/lab/youtube/go/go-0-02/ru). На каждом круге значение под ним увеличивается
на единицу:

```go
i := 1
i = i + 1
i = i + 1
```

| После строки | Под `i` |
|---|---|
| 1 `i := 1` | `1` |
| 2 `i = i + 1` | `2` (1 пропала) |
| 3 `i = i + 1` | `3` (2 пропала) |

Здесь цикла ещё нет: значение мы увеличили вручную. Теперь это будет делать цикл.

## Строка `for`: начало, вопрос, шаг

В Go цикл начинается со слова **`for`**. За ним идут три части, разделённые **точкой с запятой** (`;`). Сначала
посмотрим на две (третья пока скрыта за `…`):

```go
for i := 1; i <= 3; … {
	fmt.Println(i)
}
fmt.Println("tamom")
```

- **Первая часть — начало:** `i := 1`. Новый ярлык `i`, значение 1.
- **Вторая часть — вопрос:** `i <= 3`, то есть «`i` меньше или равно 3?». Программисты называют эту часть
  **условием**. Если ответ `true`, цикл продолжается.

**Третья часть — шаг:** `i++`. Читайте его «i плюс плюс». Он увеличивает `i` на единицу: `i++` — то же самое, что
`i = i + 1`. Как `ochko = ochko + 1` из [GO-0.02](/lab/youtube/go/go-0-02/ru), только короче.

```go
for i := 1; i <= 3; i++ {
	fmt.Println(i)
}
fmt.Println("tamom")
```

Строки между `{` в конце строки `for` и следующей `}` — это группа цикла. Они выполняются **на каждом круге**. А
`fmt.Println("tamom")` после `}` срабатывает **один раз**, когда цикл закончился.

Полная программа — файл `sanash/main.go` из папки курса (`sanash` — «считать»):

```go filename="sanash/main.go" showLineNumbers
package main

import "fmt"

func main() {
	for i := 1; i <= 3; i++ {
		fmt.Println(i)
	}
	fmt.Println("tamom")
}
```

| Строка | Код | Что делает |
|---|---|---|
| 1–5 | `package main` … `func main() {` | знакомый шаблон из первого урока |
| 6 | `for i := 1; i <= 3; i++ {` | цикл: начало `i := 1`, вопрос `i <= 3`, шаг `i++`; `{` — начало группы цикла |
| 7 | `fmt.Println(i)` | на каждом круге выводит значение под `i` |
| 8 | `}` | конец группы цикла: программа снова идёт к шагу и вопросу в строке 6 |
| 9 | `fmt.Println("tamom")` | после цикла один раз выводит `tamom` («конец») |
| 10 | `}` | конец `main` и программы |

Прежде чем запускать, угадайте: что появится на экране? **A)** `1 2 3 tamom` · **B)** `1 2 tamom` ·
**C)** `0 1 2 3 tamom`

<details>
<summary>Ответ</summary>

**A: `1`, `2`, `3` и `tamom`.** Когда `i` равно 1, 2 и 3, ответ на вопрос `true`, поэтому выводятся три числа. Когда
`i` равно 4, ответ `false`, цикл заканчивается и выводится `tamom`. Если вы выбрали «`1 2 tamom`», вы прочитали `<=`
как «меньше»: `3 <= 3` тоже `true`, потому что числа равны. Если выбрали «`0 1 2 3`»: счётчик начинается со значения,
записанного в начале, то есть с 1.

</details>

Запускаем программу из папки `sanash` командой `go run`:

```console
$ go run sanash/main.go
1
2
3
tamom
```

Каждое число вывелось на отдельной строке: `Println` каждый раз заканчивает строку.

## Цикл в памяти

Теперь проследим шаг за шагом, что происходило в памяти:

| Что сработало | Под `i` | Вопрос | На экране |
|---|---|---|---|
| начало `i := 1` | `1` | `1 <= 3` → `true` | `1` |
| шаг `i++` | `2` | `2 <= 3` → `true` | `2` |
| шаг `i++` | `3` | `3 <= 3` → `true` | `3` |
| шаг `i++` | `4` | `4 <= 3` → `false` | цикл закончился |
| строка 9 | `4` | — | `tamom` |

Обратите внимание на последний вопрос: `4 <= 3` → `false`. Именно этот ответ закончил цикл.

Коротко:

| Часть | В коде | Когда срабатывает |
|---|---|---|
| начало | `i := 1` | **один раз**, в самом начале |
| вопрос | `i <= 3` | **перед каждым кругом**; если `true`, группа выполняется, если `false`, цикл заканчивается |
| шаг | `i++` | **после каждого круга** |

Так написано и в официальных правилах Go: начало выполняется один раз перед первым вопросом, а шаг — после каждого
выполнения группы (*"the init statement is executed once before evaluating the condition for the first iteration;
the post statement is executed after each execution of the block"*).

## Маленькая проверка: сколько раз `Salom`?

Проверьте себя. Вот `salom/main.go` (`Salom` — «привет»):

```go filename="salom/main.go" showLineNumbers
package main

import "fmt"

func main() {
	for i := 1; i <= 4; i++ {
		fmt.Println("Salom")
	}
}
```

`i` начинается с 1, а вопрос — `i <= 4`. В группе цикла выводится слово `Salom`. Сколько раз `Salom` появится на
экране? **A)** 3 · **B)** 4 · **C)** 5

<details>
<summary>Ответ</summary>

**B: 4 раза.** Когда `i` равно 1, 2, 3 и 4, ответ `true`, а при 5 — `false`. Если вы выбрали «3», вы решили, что
`4 <= 4` — это `false`. Если выбрали «5», вы посчитали кругом и последний вопрос при `i`, равном 5: вопрос был задан,
но ответ `false`, и группа не выполнилась.

</details>

`go run` показывает то же самое:

```console
$ go run salom/main.go
Salom
Salom
Salom
Salom
```

## Считаем с циклом: сумма

Теперь посчитаем что-нибудь с помощью цикла: найдём сумму всех чисел от 1 до 5, то есть 1 + 2 + 3 + 4 + 5. Вот
`yigindi/main.go` (`yigindi` — «сумма»):

```go filename="yigindi/main.go" showLineNumbers
package main

import "fmt"

func main() {
	jami := 0
	for i := 1; i <= 5; i++ {
		jami = jami + i
	}
	fmt.Println(jami)
}
```

| Строка | Код | Что делает |
|---|---|---|
| 6 | `jami := 0` | **до цикла**: новый ярлык `jami` («итого»), значение 0 |
| 7 | `for i := 1; i <= 5; i++ {` | счётчик `i` считает от 1 до 5 |
| 8 | `jami = jami + i` | на каждом круге: пусть `jami` теперь будет `jami + i`, то есть прибавляется очередное число |
| 9 | `}` | конец группы цикла |
| 10 | `fmt.Println(jami)` | после цикла выводит `jami` |

Что выведет программа? Подсказка: `Println` стоит внутри фигурных скобок или снаружи? **A)** `5` · **B)** `15` ·
**C)** `1 3 6 10 15` (`jami` на каждом круге)

<details>
<summary>Ответ</summary>

**B: `15`, всего одна строка.** `fmt.Println(jami)` стоит после `}` в строке 9, то есть вне группы цикла. Поэтому он
срабатывает один раз, когда цикл закончился. Если вы выбрали «`1 3 6 10 15`», вы решили, что `Println` внутри группы.
Если выбрали «`5`», вы решили, что `jami` получает только последнее `i`: но на каждом круге значение прибавляется к
**предыдущему** `jami`.

</details>

```console
$ go run yigindi/main.go
15
```

Как компьютер сложил числа от 1 до 5? Здесь два ярлыка: `jami` и счётчик `i`. Строка 8 каждый раз работает по
правилу из [GO-0.02](/lab/youtube/go/go-0-02/ru): сначала вычисляется правая часть, потом результат кладётся под `jami`.

| Круг | `i` | Вопрос | Строка 8: `jami + i` | Под `jami` |
|---|---|---|---|---|
| до цикла | — | — | — | `0` |
| 1 | `1` | `1 <= 5` → `true` | `0 + 1` | `1` |
| 2 | `2` | `2 <= 5` → `true` | `1 + 2` | `3` |
| 3 | `3` | `3 <= 5` → `true` | `3 + 3` | `6` |
| 4 | `4` | `4 <= 5` → `true` | `6 + 4` | `10` |
| 5 | `5` | `5 <= 5` → `true` | `10 + 5` | `15` |
| — | `6` | `6 <= 5` → `false` | цикл закончился | `15` → на экране `15` |

Коротко: ярлык `jami` остался на месте, менялось только значение под ним: 0, 1, 3, 6, 10, 15.

## Если забыть шаг: бесконечный цикл

Теперь самая частая ошибка в циклах. Вот `cheksiz/main.go` (`cheksiz` — «бесконечный»). Это та же программа
`sanash`, только в строке `for` забыт шаг: нет `i++`.

```go filename="cheksiz/main.go" showLineNumbers
package main

import "fmt"

func main() {
	for i := 1; i <= 3; {
		fmt.Println(i)
	}
	fmt.Println("tamom")
}
```

В строке 6 вторая точка с запятой на месте, а после неё ничего нет. Go принимает такой код: ошибки компиляции (ошибки
перевода) не будет. По официальным правилам Go любая часть строки `for` может быть пустой, только точки с запятой
должны остаться.

Что выведет эта программа? Подсказка: когда увеличивается `i`? **A)** `1 2 3 tamom` · **B)** выводит `1` без
остановки · **C)** ничего не выведет

<details>
<summary>Ответ</summary>

**B: выводит `1` без остановки.** `i` увеличивал бы только шаг, а шага нет. Под `i` всегда лежит 1, поэтому ответ на
вопрос `1 <= 3` всегда `true`. Такой цикл, который никогда не заканчивается, называется **бесконечным циклом**. Если
вы выбрали «`1 2 3 tamom`», вы думали, что `i` растёт сам: его увеличивает только шаг. Если выбрали «ничего»: ответ на
вопрос `true`, значит группа выполняется и выводится `1`.

</details>

Если запустить программу через `go run`, экран заполнится единицами. На этом компьютере за секунду вывелись сотни
тысяч `1` (в замере больше 890 000), а `tamom` так и не появился. Чтобы остановить программу, зажмите на клавиатуре
**Ctrl** и нажмите **C** (на Mac тоже Ctrl, а не Cmd):

```console
$ go run cheksiz/main.go
1
1
1
…
1
1
^Csignal: interrupt
```

Здесь `…` — сокращённое место: на самом деле там сотни тысяч строк `1`. Читаем последнюю строку:

- `^C` — так терминал показывает нажатую клавишу: символ `^` означает Ctrl.
- `signal: interrupt` — «сигнал: прервано». Ctrl+C через терминал посылает программе сигнал «стоп», и программа
  завершилась по этому сигналу. Эту строку написал `go run`.

В Windows последняя строка может выглядеть иначе (там не проверялось). А на [go.dev/play](https://go.dev/play)
Ctrl+C не нужен: сервер сам останавливает программу через несколько секунд и пишет `timeout running program`
(«программа работала слишком долго»).

Что происходило в памяти:

| Что сработало | Под `i` | Вопрос | На экране |
|---|---|---|---|
| начало `i := 1` | `1` | `1 <= 3` → `true` | `1` |
| шага нет | `1` | `1 <= 3` → `true` (снова) | `1` |
| шага нет | `1` | `1 <= 3` → `true` (снова) | `1` |
| … | `1` | всегда `true` | `1` `1` `1` … |

**Исправить** легко: вернуть шаг. Строка 6 снова становится `for i := 1; i <= 3; i++ {`, и программа выводит `1`,
`2`, `3`, `tamom` и сама останавливается. Это и есть `sanash/main.go`.

## Проект: за сколько месяцев накопить на телефон

Теперь соберём всё, что мы узнали на уроках Go 0, в один проект. Телефон стоит 900 тысяч сумов. Вы каждый месяц
откладываете 200 тысяч сумов. За сколько месяцев наберётся нужная сумма?

Цикл пишем на год, то есть на 12 месяцев. Но в тот месяц, когда денег хватит, он должен остановиться: проходить все
12 месяцев не нужно. Для этого нужно правило выхода из цикла.

Снова вспомним стадион. Перед пробежкой вы ставите себе правило: «если кончится вода, я сойду с дорожки, даже если
круги не закончились». Этот выход вы делаете сами, **изнутри**. А Ctrl+C — другое дело: его снаружи, принудительно
нажимает кто-то другой.

```text
  🏃 круг (цикл)
       │
       ▼
  💧 вода кончилась? (if) ── да ──► 🚪 сойти с дорожки
       │ нет                        (break · изнутри)
       ▼
  следующий круг

  Ctrl+C ── снаружи, принудительно
```

Такой выход из цикла изнутри, сразу, называется **`break`** (по-английски «прервать»).

Код похож на программу суммы. Деньги записаны в тысячах: `200` — это 200 тысяч сумов. Вот `loyiha/main.go`
(`loyiha` — «проект»):

```go filename="loyiha/main.go" showLineNumbers
package main

import "fmt"

func main() {
	jami := 0
	for oy := 1; oy <= 12; oy++ {
		jami = jami + 200
		fmt.Println(oy, "oy:", jami)
		if jami >= 900 {
			break
		}
	}
}
```

| Строка | Код | Что делает |
|---|---|---|
| 6 | `jami := 0` | до цикла: накоплено 0 |
| 7 | `for oy := 1; oy <= 12; oy++ {` | счётчик `oy` («месяц») считает от 1 до 12, то есть до года |
| 8 | `jami = jami + 200` | на каждом круге (каждый месяц) к `jami` прибавляется 200 |
| 9 | `fmt.Println(oy, "oy:", jami)` | выводит в одну строку номер месяца, текст `oy:` («месяц:») и `jami` |
| 10 | `if jami >= 900 {` | вопрос: `jami` больше или равно 900? |
| 11 | `break` | если ответ `true`: весь цикл сразу заканчивается |
| 12 | `}` | конец группы `if` |
| 13 | `}` | конец группы цикла |
| 14 | `}` | конец `main` и программы |

В строке 9 число и текст стоят рядом. Это не ошибка из [GO-0.03](/lab/youtube/go/go-0-03/ru): здесь нет плюса, значения
разделены запятыми. `Println` выводит их по очереди и сам ставит между ними пробел.

`break` в строке 11 стоит внутри группы `if`. И всё же он заканчивает не только группу `if`, а **весь цикл**.
Официальное правило Go: `break` заканчивает ближайший `for`, внутри которого стоит (`if` его не останавливает).

Какой будет последняя строка на экране? **A)** `4 oy: 800` · **B)** `5 oy: 1000` · **C)** `12 oy: 2400`

<details>
<summary>Ответ</summary>

**B: `5 oy: 1000`.** На 4-м месяце `jami` равно 800: `800 >= 900` → `false`, денег пока не хватает. На 5-м месяце
`jami` равно 1000, то есть миллиону сумов: `1000 >= 900` → `true`, и `break` остановил цикл. Если вы выбрали
«`4 oy: 800`»: 800 ещё не дотягивает до 900. Если выбрали «`12 oy: 2400`», вы забыли про `break`. `1000` тоже
вывелось, потому что `Println` (строка 9) стоит перед `if` (строка 10).

</details>

```console
$ go run loyiha/main.go
1 oy: 200
2 oy: 400
3 oy: 600
4 oy: 800
5 oy: 1000
```

В памяти:

| `oy` | `jami` после строки 8 | На экране | `jami >= 900` |
|---|---|---|---|
| `1` | `200` | `1 oy: 200` | `false` |
| `2` | `400` | `2 oy: 400` | `false` |
| `3` | `600` | `3 oy: 600` | `false` |
| `4` | `800` | `4 oy: 800` | `false` |
| `5` | `1000` | `5 oy: 1000` | `true` → `break`, цикл закончился |
| `6` … `12` | — | — | эти месяцы так и не выполнились |

В этих восьми строках вместе сработало всё из Go 0: переменная, число и текст, `if` и `for`. Поздравляем, сезон Go 0
закончен! Следующий шаг: [GO-1.01 · Зачем нужен Go? Что внутри `go build`](/lab/youtube/go/go-1-01/ru).

## Глубже (необязательно): счёт с нуля и `for {`

Этого раздела нет в видео, его можно пропустить.

**Счёт с нуля.** Опытные программисты обычно считают с 0: `for i := 0; i < 3; i++` тоже делает три круга. Этого
примера нет в папке курса, мы запустили его отдельно:

```go
package main

import "fmt"

func main() {
	for i := 0; i < 3; i++ {
		fmt.Println(i)
	}
}
```

```console
$ go run noldan/main.go
0
1
2
```

Счёт с нуля нужен при работе со списками (слайсами, slice), их мы разберём в [GO-1.08](/lab/youtube/go/go-1-08/ru).

**`for {`.** В строке `for` можно вообще не писать ни одной части: `for {`. По официальным правилам Go, если вопрос
не написан, он всегда считается `true` (*"If the condition is absent, it is equivalent to the boolean value true"*).
Значит, это бесконечный цикл, написанный нарочно, и выйти из него можно только через `break`.

**Картинка упрощена.** В таблицах мы рисовали, как значение одного `i` растёт: 1 → 2 → 3. На самом деле начиная с
Go 1.22 на каждом круге создаётся новая `i`, и в неё переносится предыдущее значение. Для программ этого урока
результат тот же. Когда разница становится видна, разберём в [GO-1.05](/lab/youtube/go/go-1-05/ru).

## Частые ошибки

**1. Забыт шаг: бесконечный цикл.** Самая классическая ошибка в циклах. Go не выдаёт ошибку, а программа не
останавливается: ответ на вопрос всегда `true`. Полный пример — выше, в разделе «Если забыть шаг: бесконечный цикл».
Признак: экран заполняется одинаковыми строками, и программа сама не заканчивается. **Исправление:** остановите её
через Ctrl+C, потом верните шаг (`i++`) в строку `for`.

**2. Убрали шаг вместе с точкой с запятой.** Шаг может быть пустым, но точка с запятой должна остаться. Этого примера
нет в папке курса:

```go
package main

import "fmt"

func main() {
	for i := 1; i <= 3 {
		fmt.Println(i)
	}
}
```

```console
$ go run nuqtali/main.go
# command-line-arguments
nuqtali/main.go:6:21: syntax error: unexpected {, expected semicolon or newline
nuqtali/main.go:7:17: syntax error: unexpected newline, expected { after for clause
```

Читаем первую строку: файл `nuqtali/main.go`, **строка 6**, символ 21 (Tab в начале строки тоже считается) — это
место, где стоит `{`. `syntax error: unexpected {, expected semicolon or newline` — «синтаксическая ошибка: не ожидалась
`{`, ожидалась точка с запятой или новая строка». После вопроса Go ждал вторую `;`. Вторая строка — продолжение той же
ошибки. **Исправление:** напишите шаг (`i <= 3; i++ {`). Оба сообщения исчезнут.

**3. `<` вместо `<=`: на один круг меньше.** При `i < 3` получается `3 < 3` → `false`, поэтому 3 не выводится. Этого
примера нет в папке курса:

```go
package main

import "fmt"

func main() {
	for i := 1; i < 3; i++ {
		fmt.Println(i)
	}
	fmt.Println("tamom")
}
```

```console
$ go run kichik/main.go
1
2
tamom
```

Go не выдаёт ошибку, просто результат неправильный. **Исправление:** если последнее число тоже нужно, пишите `<=`
(`i <= 3`). Написав цикл, спросите себя: чему равно `i` на первом круге, а на последнем?

**4. `Println` остался внутри группы цикла.** Если в программе `yigindi` перенести `fmt.Println(jami)` перед `}`,
внутрь группы, он будет срабатывать на каждом круге. Этого примера тоже нет в папке курса:

```go
package main

import "fmt"

func main() {
	jami := 0
	for i := 1; i <= 5; i++ {
		jami = jami + i
		fmt.Println(jami)
	}
}
```

```console
$ go run ichkarida/main.go
1
3
6
10
15
```

Это тоже не ошибка Go, но нам нужно было только `15`. **Исправление:** то, что нужно один раз, пишите после `}`.
Правило: строка внутри группы работает на каждом круге, строка после группы — один раз.

## Проверьте себя

Сначала ответьте сами, потом откройте ответ.

**1.** Какие три части в строке `for` и когда срабатывает каждая?

<details>
<summary>Ответ</summary>

Начало (`i := 1`) — один раз, в самом начале. Вопрос (`i <= 3`) — перед каждым кругом. Шаг (`i++`) — после каждого
круга.

</details>

**2.** Что будет, если забыть шаг, и как это исправить?

<details>
<summary>Ответ</summary>

Счётчик не растёт, ответ на вопрос всегда `true`, и цикл становится бесконечным. Программу останавливает Ctrl+C.
Исправление: вернуть шаг (`i++`).

</details>

**3.** Из второго урока: как выполняется `jami = jami + i`?

<details>
<summary>Ответ</summary>

Это присваивание. Сначала вычисляется правая часть (значение под `jami` складывается с `i`), потом результат кладётся
под ярлык `jami`, а старое значение пропадает.

</details>

**4.** Что выведет этот код?

```go
jami := 0
for i := 1; i <= 4; i++ {
	jami = jami + i
}
fmt.Println(jami)
```

<details>
<summary>Ответ</summary>

`10`. Под `jami`: 0 → 1 → 3 → 6 → 10. Когда `i` равно 5, `5 <= 4` → `false`, цикл заканчивается, и `Println` один раз
выводит `10`.

</details>

**5.** Чем `break` отличается от Ctrl+C?

<details>
<summary>Ответ</summary>

`break` — правило внутри программы: цикл заканчивается сам, изнутри, и программа переходит к строке после цикла. А
Ctrl+C действует снаружи, принудительно: останавливается вся программа.

</details>

**6.** Из прошлого урока: чем `if` отличается от `for`?

<details>
<summary>Ответ</summary>

`if` задаёт вопрос один раз и выполняет группу один раз (или не выполняет). А `for` задаёт вопрос снова и снова,
перед каждым кругом, и повторяет группу, пока ответ `true`.

</details>
