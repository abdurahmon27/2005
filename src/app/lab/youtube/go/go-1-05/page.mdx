## Bitta for, toʻrt shakl

Dasturga bir ishni koʻp marta qildirish kerak boʻlsa, **sikl** yozamiz: soat mili kabi, u aylanib, bir xil
qadamlarni takrorlaydi. Koʻp tillarda buning uchun bir nechta soʻz bor: `for`, `while`, `do … while`.

Go'da esa **25 ta kalit soʻz** bor. Kalit soʻz — Go oʻziga olib qoʻygan soʻz (`for`, `if`, `func`…), uni nom
sifatida ishlatib boʻlmaydi. `while` ular orasida **yoʻq**. Go'da hamma sikl bitta `for` bilan yoziladi.

Ikki qoida:

- shart atrofida qavs `( )` **kerak emas** (Go'ning formatlovchi dasturi `gofmt` uni olib tashlaydi);
- jingalak qavs `{ }` esa **majburiy**, hatto ichida bitta qator boʻlsa ham.

Toʻrt shaklning hammasi bitta dasturda. Bu kurs papkasidagi `shakllar/main.go`:

```go filename="shakllar/main.go" showLineNumbers
package main

import "fmt"

func main() {
	for i := 0; i < 3; i++ { // 1. uch qismli
		fmt.Print(i, " ")
	}
	n := 1
	for n < 100 { // 2. faqat shart (while)
		n *= 2
	}
	fmt.Println("|", n)
	for { // 3. cheksiz
		n -= 50
		if n < 0 {
			break
		}
	}
	fmt.Println(n)
	for i := range 3 { // 4. son ustida (Go 1.22+)
		fmt.Print(i, " ")
	}
	fmt.Println()
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1–5 | `package main` … `func main() {` | tanish qolip: dastur `main` dan boshlanadi |
| 6 | `for i := 0; i < 3; i++ {` | **1-shakl, uch qismli:** boshlanish `i := 0`; shart `i < 3`; qadam `i++` (`i` ni 1 ga oshiradi). `//` dan keyingisi izoh, Go uni oʻqimaydi |
| 7 | `fmt.Print(i, " ")` | `i` ni va bitta boʻsh joyni chiqaradi. `Print` yangi qatorga **oʻtmaydi** (`Println` dan farqi shu) |
| 9 | `n := 1` | yangi `n` yorligʻi, qiymati 1 |
| 10 | `for n < 100 {` | **2-shakl, faqat shart:** shart `true` ekan, takrorlaydi. Bu boshqa tillardagi `while` |
| 11 | `n *= 2` | `n = n * 2` ning qisqa yozuvi: `n` ikki barobar boʻlsin |
| 13 | `fmt.Println("\|", n)` | `\|` belgisini va `n` ni chiqaradi, keyin yangi qatorga oʻtadi |
| 14 | `for {` | **3-shakl, cheksiz:** shart yoʻq, sikl oʻzi toʻxtamaydi |
| 15 | `n -= 50` | `n = n - 50` ning qisqa yozuvi |
| 16–18 | `if n < 0 { break }` | `n` manfiy boʻlsa, `break` sikldan chiqaradi |
| 20 | `fmt.Println(n)` | sikldan keyingi `n` ni chiqaradi |
| 21 | `for i := range 3 {` | **4-shakl, `range`:** `i` ga navbat bilan 0, 1, 2 ni beradi (3 ning oʻzi kirmaydi) |
| 24 | `fmt.Println()` | hech narsa yozmay, faqat yangi qatorga oʻtadi |

6-qatordagi `i` va 21-qatordagi `i` ni `for` ning oʻzi yaratdi (`:=` aynan `for` qatorida turibdi). Bu
[GO-0.05](/lab/youtube/go/go-0-05) dagi sanagichning oʻzi: har aylanada yorliq joyida qoladi, ostidagi qiymat almashadi.
Sikl oʻzi yaratgan bunday yorliq **sikl oʻzgaruvchisi** (inglizcha **loop variable**) deyiladi: har qadamda
(iteratsiyada) unga yangi qiymat yoziladi. 9-qatordagi `n` esa sikl oʻzgaruvchisi emas: u sikldan oldin, alohida yaratilgan.

`range` Go'da boshidan bor. **Go 1.22** dan beri u butun son ustida ham yuradi: `range 3` 0, 1, 2 ni beradi.

Ishga tushirishdan oldin oʻylab koʻring: ikkinchi qatorda nima chiqadi? **A)** `100` · **B)** `128` · **C)** `-22`

<details>
<summary>Javob</summary>

**C: `-22`** (birinchi qator esa `0 1 2 | 128` bilan tugaydi). 2-shakl `n` ni 100 dan oshguncha ikki barobar qiladi:
1, 2, 4, 8, 16, 32, 64, 128. 128 &lt; 100 emas, shuning uchun sikl toʻxtaydi. Keyin cheksiz sikl undan har safar
50 ni ayiradi: 78, 28, −22. −22 manfiy, `break` ishlaydi. «100» ni tanlagan boʻlsangiz: `n` hech qachon aynan
100 boʻlmaydi, u ikki barobar oshib, 100 dan sakrab oʻtadi. «128» esa birinchi qatorning oxirida turibdi.

</details>

Birinchi qator ikki sikldan yigʻildi: `Print` yangi qatorga oʻtmagani uchun `0 1 2 ` dan keyin `| 128` yonma-yon

| Qayerda | `n` ning qiymatlari | Ekranga |
|---|---|---|
| 9-qator | 1 | |

| 3-shakl (14–19) | 78 → 28 → −22 (`break`) | `-22` |

## range nima ustida yuradi

`range` bilan yurish uchun avval bir nechta qiymatni bitta nom ostida saqlash kerak. Masalan, uchta narxni.
Raqamlangan javonni tasavvur qiling: har bir kataginda bitta narx, kataklar esa **0 dan** boshlab raqamlangan.

```text
narxlar:   [ 100 ][ 200 ][ 300 ]
indeks:       0      1      2
```

Bunday roʻyxat Go'da **slice** deyiladi: `[]int{100, 200, 300}` — «`int` lardan iborat roʻyxat, ichida 100, 200,
300». Roʻyxatdagi har bir qiymat **element**, uning oʻrin raqami esa **indeks** deyiladi. `narxlar[0]` — 0-oʻrindagi
element, yaʼni 100. Slice'larni [GO-1.08](/lab/youtube/go#go-1-08) da batafsil oʻrganamiz.

`range` faqat sonlar ustida emas, bir nechta narsa ustida yuradi. Har qadamda u bitta yoki ikkita qiymat beradi:

| Nima ustida | 1-qiymat | 2-qiymat | Qayerda batafsil |
|---|---|---|---|
| slice | indeks | element (nusxasi!) | shu dars, [GO-1.08](/lab/youtube/go#go-1-08) |
| matn (`string`) | rune boshlangan baytning oʻrni | rune | [GO-1.04](/lab/youtube/go#go-1-04) |
| map (kalit → qiymat lugʻati) | kalit | qiymat; tartib kafolatlanmagan | [GO-1.09](/lab/youtube/go#go-1-09) |
| butun son `n` (Go 1.22+) | 0, 1, …, n−1 | — | shu dars |
| channel (goroutine'lar orasidagi quvur) | qiymatlar | — | [GO-1.21](/lab/youtube/go#go-1-21) |
| funksiya (Go 1.23+) | iterator | | [GO-1.18](/lab/youtube/go#go-1-18) |

Keraksiz qiymat oʻrniga `_` (pastki chiziq) yoziladi: `for _, n := range narxlar` — «indeks kerak emas, faqat
element». Faqat birinchi qiymat kerak boʻlsa, ikkinchisi umuman yozilmaydi: `for i := range narxlar`.

## Tuzoq: range nusxa beradi

Narxlar roʻyxati bor, va biz har bir narxni ikki barobar qilmoqchimiz. Mana `nusxa/main.go` ning birinchi qismi
(qolganini javobdan keyin ochamiz):

```go
	narxlar := []int{100, 200, 300}
	for _, n := range narxlar {
		n *= 2
	}
	fmt.Println(narxlar)
```

- **6-qator:** `narxlar` slice'i, ichida 100, 200, 300.
- **7-qator:** har qadamda `range` navbatdagi elementni `n` ga yozadi; indeks `_` bilan tashlab yuborildi.
- **8-qator:** `n` ikki barobar boʻlsin.
- **10-qator:** butun slice'ni chiqaradi. `Println` slice'ni kvadrat qavsda chiqaradi: `[1 2 3]`.

`Println` nima chiqaradi? **A)** `[100 200 300]` · **B)** `[200 400 600]` · **C)** kompilyatsiya xatosi

<details>
<summary>Javob</summary>

**A: `[100 200 300]`, slice oʻzgarmadi.** `range` har qadamda elementning **nusxasini** `n` ga yozadi (xuddi
[GO-0.02](/lab/youtube/go/go-0-02) dagi `rekord := ochko` kabi). Biz nusxani ikki barobar qildik, slice'dagi asl qiymatga
hech kim tegmadi. «B» ni tanlagan boʻlsangiz, `n` ni elementning oʻzi deb oʻylagansiz. «C» emas: kod toʻgʻri
yozilgan, u shunchaki kutgan ishimizni qilmaydi.

</details>

Xotirada har qadam:

| Qadam | `n` (nusxa) | `n *= 2` dan keyin | `narxlar` |
|---|---|---|---|
| 1 | 100 | 200 | `[100 200 300]` |
| 2 | 200 | 400 | `[100 200 300]` |
| 3 | 300 | 600 | `[100 200 300]` |

Endi toʻliq faylni ishga tushiramiz (ikkinchi qatori ham bor, uni pastda koʻramiz):

```console
$ go run ./nusxa
[100 200 300]
[200 400 600]
```

Kodni ishga tushirmasdan oʻqib, shubhali joylarni topadigan tekshiruvchi dasturlar bor. `go vet` Go bilan birga
keladi. `staticcheck` alohida oʻrnatiladi (`go install honnef.co/go/tools/cmd/staticcheck@2026.2.1`) va
`$(go env GOPATH)/bin/` papkasiga tushadi; quyidagi buyruq uni oʻsha papkadan ishga tushiradi.

```console
$ go vet ./nusxa
```

```console
$ $(go env GOPATH)/bin/staticcheck ./nusxa
nusxa/main.go:8:3: this value of n is never used (SA4006)
```

`go vet` jim: u hech narsa topmadi. `staticcheck` esa 8-qator, 3-belgini koʻrsatadi: *this value of n is never
used* — «`n` ning bu qiymati hech qachon ishlatilmaydi». Yaʼni ikki barobar qilingan nusxa hech qayerga
bormaydi.

Ikkinchi qatordagi toʻgʻri natija qayerdan chiqdi? Mana toʻliq fayl:

```go filename="nusxa/main.go" showLineNumbers
package main

import "fmt"

func main() {
	narxlar := []int{100, 200, 300}
	for _, n := range narxlar {
		n *= 2
	}
	fmt.Println(narxlar)

	for i := range narxlar {
		narxlar[i] *= 2
	}
	fmt.Println(narxlar)
}
```

- **12-qator:** `for i := range narxlar` — faqat indeks olamiz: 0, 1, 2.
- **13-qator:** `narxlar[i] *= 2` — nusxani emas, slice'ning `i`-katagidagi elementning oʻzini ikki barobar qiladi.
- **15-qator:** endi `[200 400 600]`.

Qoida: slice elementini oʻzgartirmoqchi boʻlsangiz, **indeks orqali** yozing: `narxlar[i]`.

## switch: koʻp yoʻldan bittasi

Telefon menyusini eslang: «balans uchun 1 ni, tarif uchun 2 ni bosing». Bitta raqamga qarab, koʻp yoʻldan
bittasi tanlanadi. Buni `if … else if … else if` zanjiri bilan ham yozish mumkin, lekin Go'da buning uchun
alohida **tanlov** buyrugʻi bor: inglizcha **switch**. Har bir yoʻl **case** («holat») deyiladi.

Bu `tanlov/main.go`. `kun` hafta kunining raqamini oladi va soʻzini qaytaradi:

```go filename="tanlov/main.go" showLineNumbers
package main

import "fmt"

func kun(d int) string {
	s := ""
	switch d {
	case 6, 7: // bir nechta qiymat
		s = "dam olish"
	case 1:
		s = "hafta boshi, "
		fallthrough // keyingi case ham bajariladi
	case 2, 3, 4, 5:
		s += "ish kuni"
	default:
		s = "bunday kun yoʻq"
	}
	return s
}

func main() {
	for _, d := range []int{1, 3, 7, 9} {
		fmt.Println(d, kun(d))
	}
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 5 | `func kun(d int) string {` | oʻz funksiyamiz: `int` turidagi `d` ni oladi, `string` qaytaradi (funksiyalar: [GO-1.06](/lab/youtube/go#go-1-06)) |
| 6 | `s := ""` | boʻsh matn bilan yangi `s` yorligʻi |
| 7 | `switch d {` | `d` ning qiymatiga qarab bitta `case` tanlanadi |
| 8–9 | `case 6, 7:` | bitta `case` da bir nechta qiymat: 6 **yoki** 7 boʻlsa, `s` = «dam olish» |
| 10–11 | `case 1:` | 1 boʻlsa, `s` = «hafta boshi, » |
| 12 | `fallthrough` | «pastga tush»: keyingi `case` ning ichi ham bajarilsin |
| 13–14 | `case 2, 3, 4, 5:` | ish kunlari; `s += "ish kuni"` — `s` ning oxiriga «ish kuni» qoʻshiladi |
| 15–16 | `default:` | hech bir `case` mos kelmasa, shu ishlaydi |
| 18 | `return s` | `s` ni funksiyani chaqirgan joyga qaytaradi |
| 22 | `for _, d := range []int{1, 3, 7, 9} {` | toʻrtta son ustida yuradi |
| 23 | `fmt.Println(d, kun(d))` | sonni va `kun` qaytargan soʻzni chiqaradi |

Muhim farq: C'da va Java'ning klassik `switch` ida har bir `case` dan keyin `break` yozish kerak, aks holda dastur
keyingi `case` ga oʻtib ketadi. Go'da **har bir `case` oʻzi tugaydi**, `break` yozish shart emas. Pastga tushishni
xohlasangiz, buni `fallthrough` deb ochiq yozasiz.

Taxmin qiling: `1` uchun nima chiqadi? **A)** `1 hafta boshi, ` · **B)** `1 hafta boshi, ish kuni` · **C)** `1 ish kuni`

<details>
<summary>Javob</summary>

**B: `1 hafta boshi, ish kuni`.** `case 1` «hafta boshi, » ni yozdi, keyin `fallthrough` keyingi `case` ning ichiga
tushdi va «ish kuni» ni qoʻshdi. Diqqat: 1 soni `2, 3, 4, 5` roʻyxatida yoʻq, lekin `fallthrough` keyingi `case`
ning shartini **tekshirmaydi**, shunchaki uning ichiga oʻtadi. «A» ni tanlagan boʻlsangiz, `fallthrough` ni
unutgansiz; «C» ni tanlagan boʻlsangiz, `case 1` ham ishlaganini unutgansiz.

</details>

```console
$ go run ./tanlov
1 hafta boshi, ish kuni
3 ish kuni
7 dam olish
9 bunday kun yoʻq
```

| `d` | Qaysi `case` | `s` |
|---|---|---|
| 1 | `case 1` → `fallthrough` → `case 2, 3, 4, 5` | «hafta boshi, » + «ish kuni» |
| 3 | `case 2, 3, 4, 5` | «ish kuni» |
| 7 | `case 6, 7` | «dam olish» |
| 9 | hech biri → `default` | «bunday kun yoʻq» |

Amalda `fallthrough` kam ishlatiladi.

## switch ichidagi break sikldan chiqarmaydi

Endi `switch` ni `for` ichiga qoʻyamiz. Sonlar ichidan birinchi manfiy sonni topib, toʻxtamoqchimiz. Bu
`break/main.go`:

```go filename="break/main.go" showLineNumbers
package main

import "fmt"

func main() {
	sonlar := []int{4, 7, -1, 8, -5}
	for _, s := range sonlar {
		switch {
		case s < 0:
			fmt.Println("manfiy:", s, "→ toʻxtaymiz")
			break // faqat switch'dan chiqadi
		case s%2 == 0:
			fmt.Println("juft:", s)
		}
	}
	fmt.Println("tugadi")
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 6 | `sonlar := []int{4, 7, -1, 8, -5}` | beshta sondan iborat slice |
| 7 | `for _, s := range sonlar {` | har qadamda navbatdagi son `s` ga yoziladi |
| 8 | `switch {` | **ifodasiz `switch`**: `switch` dan keyin hech narsa yoʻq. Shunda **birinchi `true` boʻlgan `case`** ishlaydi |
| 9–11 | `case s < 0:` | `s` manfiy boʻlsa, xabar chiqaradi va `break` yozilgan |
| 12–13 | `case s%2 == 0:` | `%` boʻlishdagi qoldiq: `s % 2` 0 boʻlsa, son juft |
| 16 | `fmt.Println("tugadi")` | sikldan keyin |

7 soni na manfiy, na juft: hech bir `case` mos kelmaydi, `default` ham yoʻq, shuning uchun 7 uchun hech narsa
chiqmaydi.

Manfiy son topilganda `break` yozdik. Sikl toʻxtaydimi? **A)** ha: `juft: 4`, `manfiy: -1 → toʻxtaymiz`, `tugadi` ·
**B)** yoʻq: −1 dan keyin 8 va −5 ham chiqadi · **C)** kompilyatsiya xatosi

<details>
<summary>Javob</summary>

**B: sikl toʻxtamaydi.** Go'ning rasmiy qoidasi: *"A "break" statement terminates execution of the innermost
"for", "switch", or "select" statement within the same function"* — «`break` eng ichki `for`, `switch` yoki
`select` ni tugatadi». Bu yerda `break` ga eng yaqin, eng ichki quti — `switch`. `break` faqat `switch` dan
chiqdi, `for` esa keyingi songa oʻtdi. «A» ni tanlagan boʻlsangiz, `break` ni doim siklga tegishli deb
oʻylagansiz.

</details>

```console
$ go run ./break
juft: 4
manfiy: -1 → toʻxtaymiz
juft: 8
manfiy: -5 → toʻxtaymiz
tugadi
```

Qutilar rasmi: `break` faqat oʻzi turgan eng ichki qutidan chiqadi.

```text
┌ for ─────────────────────────────┐
│  ┌ switch ───────────────────┐   │
│  │  case s < 0:              │   │
│  │      break ──► switch'dan │   │
│  │               chiqadi     │   │
│  └───────────────────────────┘   │
│  for davom etadi: keyingi s      │
└──────────────────────────────────┘
```

Tekshiruvchilar nima deydi?

```console
$ go vet ./break
```

```console
$ $(go env GOPATH)/bin/staticcheck ./break
break/main.go:11:4: ineffective break statement. Did you mean to break out of the outer loop? (SA4011)
break/main.go:11:4: redundant break statement (S1023)
```

`go vet` yana jim. `staticcheck` esa aynan shu xatoni topadi, 11-qator: *ineffective break statement. Did you
mean to break out of the outer loop?* — «samarasiz `break`. Tashqi sikldan chiqmoqchimidingiz?» Ikkinchi qator,
*redundant break statement* — «ortiqcha `break`»: Go'da `case` oʻzi tugaydi, bu `break` hech narsa qilmaydi.

Xuddi shu tuzoq `for` ichidagi `select` bilan ham bor; `select` va bu tuzoqqa goroutine darslarida
([GO-1.21](/lab/youtube/go#go-1-21)) qaytamiz.

Bu tuzoq yangi emas. 1990-yil 15-yanvarda AT&T telefon tarmogʻi qariyb toʻqqiz soat nosoz ishladi. RISKS
Digest'da tarqalgan bir xatga koʻra (AT&T'ning rasmiy bayonoti emas), sabab C kodidagi `break` edi: u `if` uchun
yozilgan, lekin `switch` dan chiqib ketgan. U yerda ham, bizda ham dars bitta: `break` `if` ga ham, `case` ga ham
tegishli emas.

## Yechim: label

Sikldan chiqish uchun `for` ga nom qoʻyamiz. Uyda bir nechta eshik boʻlsa, «chiqib ket» emas, «**koʻcha eshigidan**
chiqib ket» deymiz. Siklga qoʻyilgan nom inglizcha **label** deyiladi. Bu `label/main.go`, `break/main.go` dan faqat
ikki qatori farq qiladi:

```go filename="label/main.go" showLineNumbers
package main

import "fmt"

func main() {
	sonlar := []int{4, 7, -1, 8, -5}
qidiruv:
	for _, s := range sonlar {
		switch {
		case s < 0:
			fmt.Println("manfiy:", s, "→ toʻxtaymiz")
			break qidiruv // for'dan chiqadi
		case s%2 == 0:
			fmt.Println("juft:", s)
		}
	}
	fmt.Println("tugadi")
}
```

- **7-qator:** `qidiruv:` — nom va ikki nuqta, `for` dan oldin. Endi bu sikl `qidiruv` deb ataladi.
- **12-qator:** `break qidiruv` — «`qidiruv` deb atalgan sikldan chiq». Endi `break` aynan shu `for` ni tugatadi.

Taxmin qiling: **A)** `juft: 4`, `manfiy: -1 → toʻxtaymiz`, `tugadi` · **B)** oldingi natija bilan bir xil ·
**C)** `juft: 4`, `tugadi`

<details>
<summary>Javob</summary>

**A.** Avval 4 chiqadi (u juft), 7 uchun hech narsa chiqmaydi. Keyin −1 topiladi, xabar chiqadi va
`break qidiruv` butun sikldan chiqaradi: 8 va −5 ga navbat kelmaydi. «C» ni tanlagan boʻlsangiz: xabar `break`
dan **oldin** chiqariladi.

</details>

```console
$ go run ./label
juft: 4
manfiy: -1 → toʻxtaymiz
tugadi
```

Label haqida yana uch narsa:

- `continue` ham label bilan ishlaydi. Ichma-ich sikllarda `continue qidiruv` ichki siklni tashlab, tashqi
  siklning keyingi qadamiga oʻtadi.
- Ishlatilmagan label kompilyatsiya xatosi (pastda, «Koʻp uchraydigan xatolar» da koʻramiz).
- Yana bir yoʻl: siklni alohida funksiyaga chiqarib, `return` qilish. `return` funksiyani darhol tugatadi.

Qoida: `switch` ichida turib sikldan chiqmoqchi boʻlsangiz, **label** ishlating.

## Bitta kod, ikki natija: Go 1.22 va sikl oʻzgaruvchisi

Endi boshidagi xatoga qaytamiz. Domen — saytning nomi, masalan `a.uz`. Domenlar roʻyxatini keyinroq tekshirish
uchun navbatga qoʻyamiz. Navbatga domenning
oʻzini emas, sikl oʻzgaruvchisi `d` ning **manzilini** yozamiz.

Manzil nima? Xotiradagi har bir oʻzgaruvchi biror joyda turadi, xuddi uy biror koʻchada turgani kabi. Uyning
oʻzini emas, manzilini qogʻozga yozib qoʻyish mumkin. Keyin manzilga borib, uyda hozir kim yashayotganini
koʻramiz. Go'da `&d` — «`d` ning manzili», `*p` esa «`p` manzilidagi qiymat». Manzilni saqlaydigan qiymat
**pointer** deyiladi; ularni [GO-1.11](/lab/youtube/go#go-1-11) da batafsil ochamiz.

Bu `manzil/main.go`:

```go filename="manzil/main.go" showLineNumbers
package main

import "fmt"

func main() {
	domenlar := []string{"a.uz", "b.uz", "c.uz"}
	var navbat []*string
	for _, d := range domenlar {
		navbat = append(navbat, &d) // d'ning manzili
	}
	for _, p := range navbat {
		fmt.Print(*p, " ")
	}
	fmt.Println()
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 6 | `domenlar := []string{…}` | uchta domen nomidan iborat slice |
| 7 | `var navbat []*string` | `var` qiymat bermasdan oʻzgaruvchi eʼlon qiladi; `navbat` — «matn manzillari roʻyxati» (`*string` = matnning manzili), hozircha boʻsh |
| 8 | `for _, d := range domenlar {` | `d` — sikl oʻzgaruvchisi: har qadamda unga navbatdagi domen yoziladi |
| 9 | `navbat = append(navbat, &d)` | `append` roʻyxatning oxiriga `d` ning manzilini qoʻshadi; natija yana `navbat` ga yoziladi |
| 11 | `for _, p := range navbat {` | saqlangan manzillar ustida yuradi |
| 12 | `fmt.Print(*p, " ")` | `p` manzilida **hozir** turgan qiymatni chiqaradi |

Bu dastur nima chiqaradi? **A)** `a.uz b.uz c.uz` · **B)** `0x…` bilan boshlanadigan manzil raqamlari · **C)** xato

<details>
<summary>Javob</summary>

**A: `a.uz b.uz c.uz`** (bizning modulda). `*p` manzilning oʻzini emas, oʻsha manzildagi **qiymatni** beradi,
shuning uchun raqamlar emas, domenlar chiqadi. Manzil raqamlarini `fmt.Print(p)` chiqarar edi.

</details>

```console
$ go run ./manzil
a.uz b.uz c.uz 
```

Endi `eski/` papkasi. Unda `main.go` harfma-harf xuddi shu kod, lekin papkaning oʻz `go.mod` fayli bor.
`go.mod` — papkaning sozlama fayli. Shu fayl turgan papka **modul** deyiladi. Undagi `go` qatori modul Go
tilining qaysi versiyasi qoidalari bilan yozilganini aytadi. `grep '^go ' fayl` buyrugʻi fayldan `go ` bilan
boshlanadigan qatorni topib chiqaradi:

```console
$ grep '^go ' ../../go.mod
go 1.26
```

```console
$ grep '^go ' eski/go.mod
go 1.21
```

Kurs modulida `go 1.26`, `eski/` da `go 1.21`. Endi `eski/` ga kirib (`cd eski`), dasturni ishga tushiramiz:

```console
$ cd eski && go run .
c.uz c.uz c.uz 
```

Nega uchala manzilda `c.uz`? **A)** eski Go `range` ni teskari yuradi · **B)** uchala manzil bitta oʻzgaruvchiga
qaraydi · **C)** `append` oxirgi elementni uch marta qoʻshgan

<details>
<summary>Javob</summary>

**B.** `go` qatori 1.22 dan past boʻlsa, butun sikl uchun **bitta** `d` boʻladi. Har qadam oʻsha bitta `d` ning
ustidan yozadi: avval `a.uz`, keyin `b.uz`, keyin `c.uz`. `&d` esa har safar bir xil manzil. Uchala manzil bitta
oʻzgaruvchiga qaraydi, unda esa oxirgi qiymat qoldi. «A» emas: `range` doim 0-elementdan boshlaydi. «C» emas:
`append` har safar `&d` ni qoʻshdi, faqat `&d` har safar bir xil edi.

</details>

Xotira rasmi (`go 1.21`, bitta `d`):

| Qadam | `d` (bitta katak) | `navbat` |
|---|---|---|
| 1 | `a.uz` | `[&d]` |
| 2 | `b.uz` (a.uz yoʻqoldi) | `[&d &d]` |
| 3 | `c.uz` (b.uz yoʻqoldi) | `[&d &d &d]` |
| chiqarish | `c.uz` | ekranda: `c.uz c.uz c.uz` |

Go 1.22 dan beri (`go 1.22` va yuqori): har qadamning oʻz `d` si bor:

| Qadam | Yangi `d` | `navbat` |
|---|---|---|
| 1 | `d₁ = a.uz` | `[&d₁]` |
| 2 | `d₂ = b.uz` | `[&d₁ &d₂]` |
| 3 | `d₃ = c.uz` | `[&d₁ &d₂ &d₃]` |
| chiqarish | | ekranda: `a.uz b.uz c.uz` |

```text
go 1.21:   navbat[0] ─┐
           navbat[1] ─┼──►  d [ c.uz ]        bitta katak, har qadam ustidan yozildi
           navbat[2] ─┘

go 1.22+:  navbat[0] ──►  d₁ [ a.uz ]
           navbat[1] ──►  d₂ [ b.uz ]         har qadamda yangi katak
           navbat[2] ──►  d₃ [ c.uz ]
```

Tekshiruvchilar bu xatoni topadimi?

```console
$ cd eski && go vet . && $(go env GOPATH)/bin/staticcheck .
```

Yoʻq: `go vet` ham, `staticcheck` ham jim. (`&&` — «oldingi buyruq muvaffaqiyatli boʻlsa, keyingisini bajar».)

## Let's Encrypt, 2020 va Go jamoasining qarori

Let's Encrypt saytlarga HTTPS (saytga xavfsiz, shifrlangan ulanish) uchun bepul sertifikat beradi. Sertifikat —
brauzerdagi qulf belgisi ortidagi elektron hujjat: u «bu haqiqatan shu sayt» deb tasdiqlaydi. DNS — internetning
«telefon kitobi», unda har bir domen haqida yozuvlar turadi. CAA ana shunday yozuv: unda domen egasi qaysi
tashkilot unga sertifikat bera olishini yozadi.

Sertifikat berishdan oldin Let's Encrypt serveri (uning nomi Boulder) har bir domenning CAA yozuvini qayta
tekshirishi kerak edi. Kod sikl oʻzgaruvchisining manzilini saqlagan, xuddi bizning `manzil` dasturidagidek.
Natijada bir nechta domenli soʻrovda bitta domen bir necha marta tekshirilgan, qolganlari esa qayta
tekshirilmagan. Eng qizigʻi: kodda `k` uchun izoh bilan nusxa olingan, `v` esa unutilgan. Soddalashtirilgan rasm:

```text
for k, v := range m {
    // Make a copy of k because it will be reassigned with each loop.
    kCopy := k          ← k uchun nusxa bor ✓
    ... &v ...          ← v uchun nusxa yoʻq ✗
}
```

| Sana (UTC) | Nima boʻldi |
|---|---|
| 2019-yil 24-aprel | xatoli kod qoʻshildi (hali oʻchirilgan sozlama ortida) |
| 2019-yil 23-avgust | sozlama ishchi serverlarda (production) yoqildi |
| 2020-yil 29-fevral, 03:08 | xato tasdiqlandi |
| 2020-yil 29-fevral, 05:22 | tuzatish ishga tushdi: ikki soatdan sal koʻproq vaqtda |

Xato yarim yildan ortiq production'da ishlagan. U 3 048 289 ta sertifikatga taʼsir qilgan edi, va Let's Encrypt
ulardan 1 711 396 tasini bekor qildi. Hodisa hisobotining birinchi gapi: *"The proximate cause of the bug was a
common mistake in Go: taking a reference to a loop iterator variable"* — «xatoning bevosita sababi Go'dagi keng
tarqalgan xato: sikl oʻzgaruvchisiga havola (manzil) olish».

Go jamoasi qoidani oʻzgartirishdan oldin uni Google ichida sinab koʻrdi. Taxminan 100 000 testdan 58 tasi
oʻtmadi. Faqat 2 tasida kod eski xulqqa haqiqatan tayangan, qolganlarining deyarli hammasi yashirin xatolar
edi. Ikkinchi eng koʻp uchragan sabab esa aynan biz koʻrgan holat: sikl oʻzgaruvchisining manzilini slice'ga
qoʻshish.

Shundan keyin, **Go 1.22 dan boshlab**:

- sikl oʻzi eʼlon qilgan oʻzgaruvchi har iteratsiyada yangi;
- `d := d` kabi qoʻlda nusxa olish endi kerak emas;
- lekin faqat `go.mod` dagi `go` qatori **1.22 yoki undan yuqori** boʻlgan modullarda. Eski qatorli modulga
  koʻchirilgan kod xatoni qaytaradi (`eski/` dagidek).

Bu qator dastur xulqini qanday boshqarishini [GO-1.16](/lab/youtube/go#go-1-16) da koʻramiz.

## Koʻp uchraydigan xatolar

**1. `switch` ichidagi `break` siklni toʻxtatadi deb oʻylash.** Bu darsning asosiy tuzogʻi, yuqorida
`break/main.go` da koʻrdik: dastur xato bermaydi, lekin −1 dan keyin ham ishlayveradi. `break` eng ichki `for`,
`switch` yoki `select` dan chiqadi. **Tuzatish:** siklga label qoʻyib, `break qidiruv` yozing, yoki siklni
funksiyaga chiqarib, `return` qiling.

**2. `range` qiymatini oʻzgartirib, slice oʻzgardi deb oʻylash.** `for _, n := range narxlar { n *= 2 }` slice'ga
tegmaydi: `n` — nusxa. `staticcheck` buni `SA4006` deb koʻrsatadi. **Tuzatish:** `narxlar[i] *= 2`.

**3. `while` yozish.** Boshqa tildan kelganlar koʻpincha shunday yozadi (bu misol kurs papkasida yoʻq, alohida
ishga tushirildi):

```go
package main

import "fmt"

func main() {
	n := 1
	while n < 100 {
		n *= 2
	}
	fmt.Println(n)
}
```

```console
$ go run while/main.go
# command-line-arguments
while/main.go:7:8: syntax error: unexpected name n at end of statement
while/main.go:10:2: syntax error: non-declaration statement outside function body
```

`while/main.go`, 7-qator, 8-belgi: *syntax error: unexpected name n at end of statement* — «sintaksis xatosi:
buyruq oxirida kutilmagan `n` nomi». Go `while` ni kalit soʻz deb bilmaydi, uni oddiy nom deb oʻqiydi, va
undan keyin `n` turishini tushunmaydi. Ikkinchi qator shu birinchi xatoning oqibati: Go adashib, qolgan kodni
funksiyadan tashqarida deb oʻyladi. Birinchi xatoni tuzatsangiz, ikkinchisi ham yoʻqoladi. **Tuzatish:**
`while` oʻrniga `for`: `for n < 100 {`.

**4. Uch qismli siklni qavsga olish.** (Bu misol ham kurs papkasida yoʻq.)

```go
package main

import "fmt"

func main() {
	for (i := 0; i < 3; i++) {
		fmt.Println(i)
	}
}
```

```console
$ go run qavs/main.go
# command-line-arguments
qavs/main.go:6:9: syntax error: unexpected :=, expected )
```

6-qator, 9-belgi: *unexpected :=, expected )* — «kutilmagan `:=`, `)` kutilgan edi». Go qavs ichida oddiy shartni
kutgan, `:=` ni emas. **Tuzatish:** qavslarni olib tashlang: `for i := 0; i < 3; i++ {`. Faqat shartli siklda
qavs xato emas: `for (n < 100) {` ishlaydi, lekin `gofmt` uni baribir `for n < 100 {` ga aylantiradi.

**5. Ishlatilmagan label.** (Kurs papkasida yoʻq.) Bu yerda `break` label'siz yozilgan, `qidiruv` esa hech
qayerda ishlatilmagan:

```go
package main

import "fmt"

func main() {
	sonlar := []int{4, 7, -1}
qidiruv:
	for _, s := range sonlar {
		if s < 0 {
			break
		}
		fmt.Println(s)
	}
}
```

```console
$ go run ortiqcha/main.go
# command-line-arguments
ortiqcha/main.go:7:1: label qidiruv defined and not used
```

*label qidiruv defined and not used* — «`qidiruv` label'i eʼlon qilingan, lekin ishlatilmagan». Ishlatilmagan
oʻzgaruvchi kabi, Go buni ham xato deb hisoblaydi. **Tuzatish:** label'ni oʻchiring (bu yerda `break` `switch`
ichida emas, shuning uchun label kerak emas) yoki uni ishlating: `break qidiruv`.

**6. `range 3` ni eski modulda yozish.** (Kurs papkasida yoʻq; `go.mod` da `go 1.21` boʻlgan alohida modul.)

```go
package main

import "fmt"

func main() {
	for i := range 3 {
		fmt.Print(i, " ")
	}
	fmt.Println()
}
```

```console
$ cd eskirange && go run .
# eskirange
./main.go:6:17: cannot range over 3 (untyped int constant): requires go1.22 or later (-lang was set to go1.21; check go.mod)
```

*cannot range over 3 … requires go1.22 or later (-lang was set to go1.21; check go.mod)* — «3 ustida `range` qilib
boʻlmaydi … Go 1.22 yoki yuqori kerak (til versiyasi go1.21 qilib belgilangan; `go.mod` ni tekshiring)». Xabar
hatto qayerga qarashni ham aytadi. **Tuzatish:** `go.mod` dagi `go` qatorini 1.22 yoki yuqoriga koʻtaring yoki
uch qismli sikl yozing.

**7. Sikldan oldin yaratilgan oʻzgaruvchi har qadamda yangi deb oʻylash.** Go 1.22 qoidasi faqat **sikl oʻzi
eʼlon qilgan** oʻzgaruvchiga tegishli. Bu yerda `j` sikldan oldin `var j int` bilan yaratilgan, `for` unga faqat
`=` bilan qiymat beradi. Bu misol kurs papkasida yoʻq, u `go 1.26` modulda ishga tushirildi:

```go
package main

import "fmt"

func main() {
	var navbat []*int
	var j int
	for j = 0; j < 3; j++ {
		navbat = append(navbat, &j)
	}
	for _, p := range navbat {
		fmt.Print(*p, " ")
	}
	fmt.Println()
}
```

```console
$ go run tashqi/main.go
3 3 3 
```

Bitta `j`, uchala manzil unga qaraydi. Sikl `j` 3 boʻlganda toʻxtadi, shuning uchun `3 3 3`. **Tuzatish:** `j` ni
`for` ning oʻzida yarating: `for j := 0; j < 3; j++`. Shunda u sikl oʻzgaruvchisi boʻladi va natija `0 1 2`.

<summary>Javob</summary>

`homework/guru/` — alohida modul, `go.mod` da `go 1.21` (eski qoida).

1. `d := d`: sikl ichida yangi oʻzgaruvchi yaratiladi, har manzil oʻz nusxasiga qaraydi. Go 1.22 gacha shunday
   yozilardi; `go 1.22+` modulda bu qator ortiqcha va `go fix` (eski kodni yangilaydigan Go buyrugʻi) uni
   oʻchiradi.
2. `&domenlar[i]`: sikl oʻzgaruvchisi emas, slice elementining oʻzining manzili. Bu yerda nusxa umuman yoʻq.
3. Fayl boshidagi `//go:build go1.22` qatori **shu fayl** uchun til versiyasini koʻtaradi: modul `go 1.21` da
