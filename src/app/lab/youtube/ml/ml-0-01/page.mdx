## Nimani oʻrganasiz

Oʻnta talabada nol xato qilgan model eng yomon holda yangi talabaga 79 oʻrniga 233 ball berdi. Bu natijani
koʻrishdan oldin besh bashorat yozib, git'ga commit qilgan edik. Ulardan ikkitasi xato chiqdi. Bu ML trekining
birinchi darsi, va biz modeldan emas, odatdan boshlaymiz: avval bashorat, keyin natija, keyin halol solishtirish.

**Bitta gʻoya:** oʻrgatilgan maʼlumotdagi kichik xato hech narsani isbotlamaydi. Modelni faqat u koʻrmagan
maʼlumotda tekshiramiz, natijani esa ishga tushirishdan oldin yozib qoʻyilgan bashorat bilan solishtiramiz.

Dars oxirida siz:

- ML trekining xaritasini (ML-0 … ML-6) va C1–C12 checkpoint'lari nima ekanini bilasiz;
- har bir faktni *tekshirdim*, *oʻqidim* yoki *taxminim* belgisi bilan ajratasiz;
- tajribadan oldin raqamli bashorat yozib, uni commit qilib, keyin natija bilan solishtirasiz;
- train xatosi kichik, test xatosi katta boʻlgan modelni koʻrib, buni overfitting deb taniysiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| train va test | model oʻrganadigan maʼlumot va model koʻrmagan, faqat tekshirish uchun olingan maʼlumot | training set, test set |
| overfitting | model train'ni yodlab oladi: train xatosi kichik, test xatosi katta | overfitting |
| seed | tasodifiy sonlar generatorining boshlangʻich qiymati: bir xil seed — bir xil «tasodif» | seed |

Ikkita yordamchi soʻz ham bor. **Checkpoint** — bosqich oxiridagi raqamli oʻtdi/oʻtmadi mezoni. **Errata** — ilgari
fakt deb aytilgan, keyin xato chiqqan gaplar roʻyxati.

## Tajriba: toʻgʻri chiziq va 9-darajali koʻphad

Maʼlumotni oʻzimiz yasaymiz, shuning uchun haqiqiy qonuniyatni bilamiz:

```text
ball = 40 + 5 × soat + shovqin        shovqin ~ Normal(0, 5)
```

`soat` — talaba necha soat oʻqigani (0 dan 10 gacha), `ball` — imtihon bali. Shovqin — har talabaga qoʻshiladigan
tasodifiy farq: oʻrtachasi 0, standart ogʻishi 5 ball.

- **train**: 10 ta talaba. Model faqat shularni koʻrib oʻrganadi.
- **test**: yana 10 ta yangi talaba. Model ularni hech qachon koʻrmagan, ular faqat tekshirish uchun.

Ikki model solishtiriladi:

| Model | Parametrlar | Nima qiladi |
|---|---|---|
| `chiziq` | 2 (`a + b·soat`) | 10 nuqtaga eng yaqin toʻgʻri chiziq |
| `daraja 9` | 10 | 9-darajali **koʻphad** (polynomial, `a₀ + a₁x + … + a₉x⁹`): 10 nuqtaga 10 parametr, shuning uchun u **har bir nuqtadan oʻtadi** |

**Xato** — oʻrtacha mutlaq xato: model har talabada necha ballga adashganining oʻrtachasi (mean absolute error).

Toʻliq dastur (kurs papkasidan, oʻzgarishsiz):

```python filename="tajriba.py" showLineNumbers
# /// script
# requires-python = ">=3.10"
# dependencies = ["numpy==2.5.5"]
# ///
"""Toʻgʻri chiziq yoki har nuqtadan oʻtadigan egri chiziq: qaysi biri YANGI talabalarda yaxshiroq?

Maʼlumot sintetik (oʻzimiz yasaymiz, shuning uchun haqiqiy qonuniyatni bilamiz):
    ball = 40 + 5 × soat + shovqin,   shovqin ~ Normal(0, 5)
10 ta talaba bilan oʻqitamiz (train), modellar koʻrmagan 10 ta yangi talabada tekshiramiz (test).
Xato = oʻrtacha mutlaq xato: model oʻrtacha necha ballga adashdi.

Faqat CPU va numpy. Bashorat bashorat.md faylida, u shu skript birinchi marta ishga tushishidan
OLDIN commit qilingan (git log bilan tekshiring).

    uv run tajriba.py          # seed 1: jadval va eng katta xato
    uv run tajriba.py seeds    # 1..5 seed: tasodifmi yoki qonuniyatmi?
    uv run tajriba.py seeds 100  # xuddi shu, lekin 100 ta train talaba (bashorat2.md)
    uv run tajriba.py ming     # 1000 seed: bashoratlar nega xato chiqdi (natijadan keyin qoʻshilgan)
    uv run tajriba.py ming 100   # xuddi shu, 100 ta train talaba bilan
"""
import sys

import numpy as np
from numpy.polynomial import Polynomial

N_TRAIN = 10
N_TEST = 10
MODELLAR = [("chiziq", 1), ("daraja 9", 9)]  # 10 nuqta, 10 parametr: daraja 9 har nuqtadan oʻtadi

def talabalar(rng, n):
    soat = rng.uniform(0, 10, n)
    ball = 40 + 5 * soat + rng.normal(0, 5, n)
    return soat, ball

def xato(p, x, y):
    return float(np.mean(np.abs(p(x) - y)))  # oʻrtacha necha ballga adashdi

def tajriba(seed, n_train=N_TRAIN):
    rng = np.random.default_rng(seed)
    xs, ys = talabalar(rng, n_train)  # train: ball = 40 + 5·soat + shovqin
    xt, yt = talabalar(rng, N_TEST)  # test: modellar bularni koʻrmagan
    natija = {}
    for nom, daraja in MODELLAR:  # chiziq (1) va daraja 9
        p = Polynomial.fit(xs, ys, daraja)  # least squares; daraja 9 = 10 parametr
        natija[nom] = {"train": xato(p, xs, ys), "test": xato(p, xt, yt), "p": p}
    return natija, (xs, ys), (xt, yt)

def bitta():
    natija, (xs, _), (xt, yt) = tajriba(1)
    print(f"seed 1 · train: {N_TRAIN} talaba · test: {N_TEST} yangi talaba")
    print(f"{'model':<10}{'train xato':>12}{'test xato':>11}")
    for nom, _ in MODELLAR:
        r = natija[nom]
        print(f"{nom:<10}{r['train']:>12.1f}{r['test']:>11.1f}")
    p = natija["daraja 9"]["p"]
    i = int(np.argmax(np.abs(p(xt) - yt)))
    print(f"eng katta xato: {xt[i]:.1f} soat, haqiqiy {yt[i]:.0f}, model {p(xt[i]):.0f}")
    print(f"train soatlari: {xs.min():.1f} … {xs.max():.1f}")

def seeds(n_train=N_TRAIN):
    test = {nom: [] for nom, _ in MODELLAR}
    for s in range(1, 6):
        natija, _, _ = tajriba(s, n_train)
        for nom, _ in MODELLAR:
            test[nom].append(natija[nom]["test"])
    print(f"train: {n_train} talaba · test xato, seed 1…5")
    for nom, _ in MODELLAR:
        print(f"{nom:<9}" + "".join(f"{v:>9.1f}" for v in test[nom]))
    yomon = sum(d > c for c, d in zip(test["chiziq"], test["daraja 9"]))
    print(f"daraja 9 testda yomonroq: {yomon} / 5")

def ming(n_train=N_TRAIN):
    """Bashoratlar nega xato chiqdi? Bitta seed emas, 1000 ta seed (natijadan keyin qoʻshilgan tahlil)."""
    R = [tajriba(s, n_train) for s in range(1, 1001)]
    tr = np.array([n["chiziq"]["train"] for n, _, _ in R])
    te = np.array([n["chiziq"]["test"] for n, _, _ in R])
    d9 = np.array([n["daraja 9"]["test"] for n, _, _ in R])
    ichida = 0
    for n, (xs, _), (xt, yt) in R:
        p = n["daraja 9"]["p"]
        i = int(np.argmax(np.abs(p(xt) - yt)))
        ichida += xs.min() <= xt[i] <= xs.max()
    print(f"1000 seed · train: {n_train} talaba")
    print(f"chiziq train xato, oʻrtacha: {tr.mean():.1f}")
    m = float(np.median(d9))
    print(f"daraja 9 test xato, mediana: {m:.0f}" if m >= 100 else f"daraja 9 test xato, mediana: {m:.1f}")
    print(f"daraja 9 test 10…100 oraligʻida: {np.sum((d9 >= 10) & (d9 <= 100))} / 1000")
    print(f"eng katta xato train oraligʻi ichida: {ichida} / 1000")
    print(f"daraja 9 testda yomonroq: {np.sum(d9 > te)} / 1000")

if __name__ == "__main__":
    rejim = sys.argv[1] if len(sys.argv) > 1 else ""
    if rejim == "seeds":
        seeds(int(sys.argv[2]) if len(sys.argv) > 2 else N_TRAIN)
    elif rejim == "ming":
        ming(int(sys.argv[2]) if len(sys.argv) > 2 else N_TRAIN)
    else:
        bitta()
```

## Natija: train'da 0, testda 52

## Koʻp uchraydigan xatolar

**1. «Train xatosi 0 — demak model zoʻr».** Bu mavzuning klassik xatosi. Xato xabari yoʻq, raqam chiroyli: seed
1'da koʻphad train'da 0.0, testda esa 52.1 («Natija: train'da 0, testda 52» boʻlimi). Tuzatish: modelni doim u
koʻrmagan maʼlumotda (test) baholang va ikkala raqamni yonma-yon koʻrsating.

**2. Bitta ishga tushirishdan xulosa.** Seed 1'da 3-bashorat toʻgʻri chiqdi, lekin 1000 seed'ning faqat 175 tasida
shunday boʻladi («Nega adashdik: 1000 seed» boʻlimi). Tuzatish: bir necha seed'da qaytaring, oraliq va medianani
koʻrsating.

**3. Natijani koʻrib, bashoratni keyin «eslash».** Xato xabari ham, iz ham qolmaydi: har bir natija «kutilgan»
boʻlib qoladi. Tuzatish: bashoratni **raqam va oraliq** bilan yozing («≈ 30, 10 dan 100 gacha», «yomonroq» emas) va
ishga tushirishdan oldin commit qiling.

**4. Float'larni `>` bilan solishtirish.** Shovqinni nolga tushirsak, ikkala model ham ideal boʻlishi kerak. Bu kurs
papkasida yoʻq: `tajriba.py` nusxasi `shovqin0.py`, unda faqat 33-qator oʻzgargan:

```python
    ball = 40 + 5 * soat + rng.normal(0, 0, n)
```

Ekranda hamma xato `0.0`, lekin oxirgi qator «5 / 5 yomonroq» deydi. Sabab: `.1f` formati yaxlitlaydi, `d > c` esa

```python
        d9.append(n["daraja 9"]["test"])
print(f"hamma test nuqtasi train oraligʻi ichida: {len(d9)} / 1000")
print(f"ularda daraja 9 test xato, mediana: {np.median(d9):.0f}")
```

🔴 Javob kurs papkasida: `homework/nuqtalar.py` seed 1'ning train nuqtalarini `homework/nuqtalar.csv` ga yozadi va
numpy chizigʻini chiqaradi; `homework/guru/main.go` shu faylni oʻqib, chiziqni noldan hisoblaydi. Formula — eng kichik
kvadratlarning bir oʻzgaruvchili holati: `b = Σ(x−x̄)(y−ȳ) / Σ(x−x̄)²`, `a = ȳ − b·x̄`.

```go filename="homework/guru/main.go" showLineNumbers
// Guru vazifasi javobi: toʻgʻri chiziqni (least squares) noldan, faqat standart kutubxona bilan.
//
//	uv run homework/nuqtalar.py && go run ./homework/guru homework/nuqtalar.csv
//
// Formula (CS229 konspekti, 1.2 «The normal equations» ning bir oʻzgaruvchili holati):
//
//	b = Σ(x-x̄)(y-ȳ) / Σ(x-x̄)²,   a = ȳ - b·x̄
package main

import (
	"encoding/csv"
	"fmt"
	"os"
	"strconv"
)

func main() {
	if len(os.Args) != 2 {
		fmt.Fprintln(os.Stderr, "ishlatish: go run ./homework/guru nuqtalar.csv")
		os.Exit(2)
	}
	f, err := os.Open(os.Args[1])
	if err != nil {
		fmt.Fprintln(os.Stderr, err)
		os.Exit(1)
	}
	defer f.Close()
	qatorlar, err := csv.NewReader(f).ReadAll()
	if err != nil {
		fmt.Fprintln(os.Stderr, err)
		os.Exit(1)
	}
	var xs, ys []float64
	for _, q := range qatorlar {
		x, err1 := strconv.ParseFloat(q[0], 64)
		y, err2 := strconv.ParseFloat(q[1], 64)
		if err1 != nil || err2 != nil {
			fmt.Fprintln(os.Stderr, "notoʻgʻri qator:", q)
			os.Exit(1)
		}
		xs, ys = append(xs, x), append(ys, y)
	}
	a, b := chiziq(xs, ys)
	fmt.Printf("go:    ball = %.12f + %.12f × soat\n", a, b)
}

func chiziq(xs, ys []float64) (a, b float64) {
	n := float64(len(xs))
	var mx, my float64
	for i := range xs {
		mx += xs[i]
		my += ys[i]
	}
	mx, my = mx/n, my/n
	var sxy, sxx float64
	for i := range xs {
		sxy += (xs[i] - mx) * (ys[i] - my)
		sxx += (xs[i] - mx) * (xs[i] - mx)
	}
	b = sxy / sxx
	return my - b*mx, b
}
```

`chiziq` funksiyasi ikki marta aylanadi: avval oʻrtachalar (`mx`, `my`), keyin ikki yigʻindi (`sxy`, `sxx`).
`(a, b float64)` — nomli qaytariladigan qiymatlar. Buyruq `lessons/ml-01-map` dan beriladi, chunki `go run` papka
yoʻli bilan ishlaydi (bizda `CGO_ENABLED=0`, gcc yoʻq):

```console
$ uv run --quiet homework/nuqtalar.py && go run ./homework/guru homework/nuqtalar.csv

go:    ball = 37.520865264908 + 5.338824873127 × soat
```
