## Nimani oʻrganasiz

Oʻtgan darsda bozor buyurtma summasini tiyingacha aniq hisobladi. Lekin chekni `fmt.Println` bilan chiqaradi:
raqamlar har qatorda har xil joyda, soʻm va tiyin alohida soʻz bilan. Mijozga bunday chek berib boʻlmaydi. Summani
`13993.00` koʻrinishida, hamma summani bitta ustunda qanday chiqarasiz?

**Bitta gʻoya:** `fmt.Printf` shablonni chapdan oʻngga oʻqiydi. Oddiy matnni oʻzicha chiqaradi, har bir `%` feʼl
oʻrniga esa navbatdagi argumentni shu feʼl aytgan koʻrinishda va kenglikda qoʻyadi. `fmt.Sprintf` xuddi shu matnni
ekranga chiqarmaydi, `string` qiymat qilib qaytaradi.

Dars oxirida siz:

- ikki `string`'ni `+` bilan qoʻshasiz va `string + int64` nega kompilyatsiya boʻlmasligini xabardan oʻqiysiz;
- `fmt.Printf` shablonini `%s`, `%d`, `%v`, `%q` feʼllari va `\n` bilan yozasiz;
- kenglik (`%9d`, `%-14s`) va `0` bilan (`%02d`) summani soʻm, nuqta va ikki raqamli tiyin qilib, ustunda chiqarasiz;
- ikki keng tarqalgan xatoni (`string(total)` va notoʻgʻri feʼl) natijasidan va `go vet` xabaridan taniysiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| matnni yopishtirish | ikki `string` orasidagi `+`: yonma-yon qoʻyib, yangi `string` yasaydi; ikki tomon bir xil turda boʻlishi shart | string concatenation |
| shablon va feʼl | `Printf`'ning birinchi argumenti — shablon; undagi `%` va harf juftligi (`%s`, `%d`) — feʼl, navbatdagi argument qanday yozilishini aytadi | format string, verb |
| kenglik | `%` va harf orasidagi son: qiymat kamida shuncha belgi joy oladi (`%9d`); `-` chapga tekislaydi, `0` boʻsh joyni nol bilan toʻldiradi | width (flags `-`, `0`) |

Ikkita yordamchi soʻz: **`fmt.Sprintf`** — `Printf`'ning shablonini oladi, natijani ekranga emas, `string` qilib
qaytaradi; va **`\n`** — shablondagi yangi qator belgisi.

## Boshlangʻich holat: chek `Println` bilan

Bu oʻtgan darsning yechimi, vazifasi bilan. Bugun faqat oxirgi uch qator, yaʼni chek oʻzgaradi:

```go filename="_video/01-println/main.go" showLineNumbers
package main

import "fmt"

const tiyinPerSom = 100    // 1 soʻm = 100 tiyin
const vatPercent = 12      // QQS, foizda
const deliverySom = 15_000 // yetkazib berish, soʻmda (QQS qoʻshilmaydi)

func main() {
	fmt.Println("bozor ishga tushdi")
	fmt.Println("versiya: 0.1.0")

	var name string
	var price int64
	var active bool
	fmt.Println(name, price, active)

	name = "choy"
	price = 1_999 * tiyinPerSom // tiyinda
	active = true
	stock := 40
	weight := 1.5
	fmt.Println(name, price, active, stock, weight)

	sold := 7
	stock = stock - sold
	fmt.Println(name, stock)

	subtotal := price * int64(sold)
	vat := subtotal * vatPercent / 100
	total := subtotal + vat + deliverySom*tiyinPerSom
	fmt.Println(name, sold, "dona")
	fmt.Println("QQS:", vat/tiyinPerSom, "soʻm", vat%tiyinPerSom, "tiyin")
	fmt.Println("jami:", total/tiyinPerSom, "soʻm", total%tiyinPerSom, "tiyin")
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 5–7 | `const …` | `tiyinPerSom` (1 soʻm = 100 tiyin), `vatPercent` (QQS 12 %), `deliverySom` (yetkazib berish, 15 000 soʻm) |
| 10–27 | `fmt.Println(…)`, `var …`, `:=` | GB-1.01–1.03 dagi qatorlar: ishga tushish, versiya, zero value, mahsulot, ombor. Bugun ularga tegmaymiz |
| 29 | `subtotal := price * int64(sold)` | mahsulot summasi tiyinda: 199 900 × 7 = 1 399 300 |

## Matnni qoʻshish: `string` va `+`

`string` — Go'dagi matn turi, qoʻshtirnoq ichida yoziladi. Ikki `string` orasidagi `+` ularni yonma-yon
yopishtiradi va **yangi** `string` yasaydi. Buning nomi **concatenation** (matnni yopishtirish).

```go
name := "choy"
label := "mahsulot: " + name
fmt.Println(label)
```

`label` degan yangi oʻzgaruvchi `"mahsulot: "` va `"choy"` matnlarini oladi. Ikki nuqtadan keyingi probel ham
matnning bir qismi: usiz `mahsulot:choy` chiqardi. Xotirada qator-baqator:

| Qator | Kod | `name` | `label` | Ekranda |
|---|---|---|---|---|
| 1 | `name := "choy"` | `"choy"` | — | |
| 2 | `label := "mahsulot: " + name` | `"choy"` | `"mahsulot: choy"` | |
| 3 | `fmt.Println(label)` | `"choy"` | `"mahsulot: choy"` | `mahsulot: choy` |

`+` `name`'ni oʻzgartirmaydi: u oʻsha-oʻsha `"choy"`. Natija alohida qiymat boʻlib, `label`'ga yoziladi.

Endi matnga summani qoʻshib koʻramiz. `total` — `int64`, tiyinda; `label` — `"jami: "`:

```go filename="_video/03-xato/main.go" showLineNumbers
package main

import "fmt"

func main() {
	var total int64 = 3_067_216 // tiyinda
	label := "jami: "
	fmt.Println(label + total)
}
```

Xabarni oʻqiymiz:

- `# github.com/abdurahmon27/bozor` — GB-1.01 dagi modul yoʻli: xato shu moduldagi kodda.
- `./main.go:8:14` — `main.go`, 8-qator, 14-ustun (Tab bitta ustun, `label` 14-ustunda boshlanadi).
- `invalid operation: label + total` — «notoʻgʻri amal: `label + total`».
- `(mismatched types string and int64)` — «turlar mos emas: `string` va `int64`».

Qoida: `+`'ning ikki tomoni bir xil turda boʻlishi kerak. Go sonni oʻzi matnga aylantirmaydi. GB-1.03 dagi
`int64` va `int` xatosi ham shu qoidadan edi. Turi yozilmagan son konstantasi boshqa son turiga moslashadi, lekin
matnga aylanmaydi. Sonni matn ichiga qoʻyish — formatlash ishi, uni keyingi boʻlimdagi `fmt.Printf` qiladi.

## `fmt.Printf`: shablon va feʼllar

`fmt` paketidagi `Printf` birinchi argument sifatida **shablon** (format string) oladi. Shablondagi `%` va harf
juftligi **feʼl** deyiladi (inglizcha **verb**). Qolgan argumentlar feʼllar oʻrniga tartib bilan qoʻyiladi.

```go filename="_video/04-printf/main.go" showLineNumbers
package main

import "fmt"

func main() {
	name := "choy"
	var price int64 = 199_900 // tiyinda
	fmt.Printf("%s: %d tiyin\n", name, price)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 6 | `name := "choy"` | mahsulot nomi, `string` |
| 7 | `var price int64 = 199_900` | narx tiyinda (1 999 soʻm) |
| 8 | `fmt.Printf("%s: %d tiyin\n", name, price)` | shablon `"%s: %d tiyin\n"`, keyin ikki argument |

Shablon ichida:

- `%s` — navbatdagi `string` argumentni oʻzicha qoʻyadi;
- `%d` — butun sonni oʻnlik raqamlar bilan yozadi (inglizcha *decimal*);
- `\n` — teskari slesh va `n`: yangi qator belgisi. Go uni qoʻshtirnoq ichida ikki belgi emas, **bitta** belgi deb
  saqlaydi.

`Printf` shablonni chapdan oʻngga oʻqiydi. Oddiy matnni oʻzicha chiqaradi. Birinchi feʼlga kelganda birinchi
argumentni oladi, ikkinchi feʼlga — ikkinchisini:

| Shablondagi qism | Nima boʻladi | Ekranga |
|---|---|---|
| `%s` | 1-argument `name` qoʻyiladi | `choy` |
| `: ` | oddiy matn | `: ` |
| `%d` | 2-argument `price` qoʻyiladi | `199900` |
| ` tiyin` | oddiy matn | ` tiyin` |
| `\n` | yangi qator belgisi | qator tugaydi |

```console
$ ./_video/run.sh 04-printf
choy: 199900 tiyin
```

`%d` raqamlarni pastki chiziqsiz yozadi: `199_900` faqat kodni oʻqish uchun edi (GB-1.03).

### `\n` boʻlmasa

Endi `\n`'ni olib tashlaymiz va `Printf`'ni ikki marta chaqiramiz, ikkinchisida `"non"` va 400 000 tiyin:

```go filename="_video/05-qator/main.go" showLineNumbers
import "fmt"

func main() {
```

### Yana ikki feʼl: `%v` va `%q`

`%v` istalgan qiymatni oʻzining standart koʻrinishida chiqaradi: son, `string`, `true` yoki `false`. Tur muhim
boʻlmaganda qulay (inglizcha *value*). `%q` matnni qoʻshtirnoq ichida chiqaradi (inglizcha *quoted*).

```go filename="_video/06-feyllar/main.go" showLineNumbers
package main

import "fmt"

func main() {
	input := " choy "
	sold := 7
	active := true
	fmt.Printf("%v dona, sotuvda: %v\n", sold, active)
	fmt.Printf("%s\n", input)
	fmt.Printf("%q\n", input)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 6 | `input := " choy "` | foydalanuvchi kiritgan matn: `choy`, oldida va ortida bittadan probel |
| 7 | `sold := 7` | sotilgan dona soni |
| 8 | `active := true` | `bool`: mahsulot sotuvdami |
| 9 | `fmt.Printf("%v dona, sotuvda: %v\n", sold, active)` | ikkala qiymat `%v` bilan |
| 10 | `fmt.Printf("%s\n", input)` | `input` `%s` bilan |
| 11 | `fmt.Printf("%q\n", input)` | `input` `%q` bilan |

Oʻylab koʻring: `%s` bilan chiqqan qatorda probellar koʻrinadimi?

<details>
<summary>Javob</summary>

Oldingi probel koʻrinadi (qator bitta boʻsh joy bilan boshlanadi), oxiridagisi esa koʻrinmaydi: ekranda probel va
hech narsa farq qilmaydi. `%q` qoʻshtirnoq qoʻyadi, shuning uchun ikkala probel ham ochiladi.

</details>

```console
$ ./_video/run.sh 06-feyllar

```

1-qatorda son ham, `true` ham `%v` bilan chiqdi. 2-qatorning oxirida probel bor, lekin koʻrinmaydi. 3-qatorda
qoʻshtirnoq ikkala probelni ochib beradi. Server oʻz ishi haqida yozib boradigan qatorlar **log** deyiladi.
Foydalanuvchi matnini log'ga `%q` bilan yozsangiz, ortiqcha probel darhol koʻrinadi.

Qisqasi:

| Feʼl | Nimaga | Misol | Natija |
|---|---|---|---|
| `%s` | `string` | `"choy"` | `choy` |
| `%d` | butun son, oʻnlik | `199_900` | `199900` |
| `%v` | istalgan qiymat, standart koʻrinish | `7`, `true` | `7`, `true` |
| `%q` | matn qoʻshtirnoq ichida | `" choy "` | `" choy "` |

## Tiyin: `%d.%d` xatosi va `%02d`

Endi QQS'ni soʻmda, nuqta va tiyin bilan chiqaramiz. Choy 8 dona boʻlganda QQS tiyinda `191_904`:
1 999 × 100 × 8 = 1 599 200 tiyin, uning 12 % i 191 904.

```go filename="_video/07-pul/main.go" showLineNumbers
package main

import "fmt"

const tiyinPerSom = 100

func main() {
	var vat int64 = 191_904 // choy, 8 dona: QQS tiyinda
	fmt.Printf("QQS: %d.%d soʻm\n", vat/tiyinPerSom, vat%tiyinPerSom)
}
```

`vat/tiyinPerSom` — soʻm qismi (butun sonli boʻlish kasrni tashlaydi: `1919`). `vat%tiyinPerSom` — tiyin qismi,
qoldiq: `4`. Ehtiyot boʻling: **kod ichidagi** `%` — qoldiq amali (GB-1.03), **shablon ichidagi** `%` esa feʼl
boshi. Ular bir-biriga aloqasi yoʻq.

`vat` 191 904 tiyin. Ekranda nima chiqadi?

**A)** `QQS: 1919.04 soʻm` · **B)** `QQS: 1919.4 soʻm` · **C)** `QQS: 1919.40 soʻm`

<details>
<summary>Javob</summary>

**B: `QQS: 1919.4 soʻm`.** Qoldiq `4`, `%d` uni bitta raqam qilib yozadi. **A** ni tanlagan boʻlsangiz, `%d`
ikki raqam joy ajratadi deb oʻylagansiz: ajratmaydi, son oʻz uzunligida yoziladi. **C** uchun Go nuqtadan keyingi
raqamni pul deb bilishi kerak edi; u faqat ikki alohida butun sonni nuqta bilan yonma-yon qoʻyadi.

</details>

```console
$ ./_video/run.sh 07-pul

```

Mijoz buni 40 tiyin deb oʻqiydi, aslida esa 4 tiyin. Bu chekdagi haqiqiy xato, kompilyator va dastur esa jim.

**Tuzatish:** ikkinchi feʼl `%02d`. `%` bilan `d` orasidagi `2` — **kenglik** (width): natija kamida 2 belgi joy
oladi. Uning oldidagi `0` — bayroq (flag): boʻsh joyni probel emas, nol bilan toʻldiradi.

```go filename="_video/08-pul-tuzat/main.go" showLineNumbers

import "fmt"

const tiyinPerSom = 100

func main() {
	var vat int64 = 191_904 // choy, 8 dona: QQS tiyinda

}
```

```console
$ ./_video/run.sh 08-pul-tuzat

```

Nuqtadan keyin `04`, yaʼni 4 tiyin. Qoldiq `0` dan `99` gacha boʻladi; `%02d` har birini roppa-rosa ikki raqam
qilib yozadi: `00`, `04`, `16`, `99`.

## Kenglik: `%9d` va `%-14s` bilan ustun

Kenglik har qanday feʼlga ishlaydi. `%` va harf orasidagi son — kenglik, natija kamida shuncha belgi joy oladi:

- `%9d` — sonni 9 belgilik ustunning **oʻng** chetiga suradi, chapini probel bilan toʻldiradi;
- `%-14s` — `-` bayrogʻi chapga tekislaydi: nomni 14 belgilik joyning chap chetiga qoʻyadi, oʻngini toʻldiradi.

Hozircha faqat soʻm qismi:

```go filename="_video/09-jadval/main.go" showLineNumbers
package main

import "fmt"

func main() {
	fmt.Printf("%-14s %9d\n", "QQS", 1679)
	fmt.Printf("%-14s %9d\n", "yetkazish", 15000)
	fmt.Printf("%-14s %9d\n", "jami", 30672)
}
```

Ishga tushirishdan oldin tekshiramiz. Shablonda ikki juft kvadrat qavs (bu yerda ular oddiy matn), ichida `%-6s` va
`%4d`, argumentlar `"QQS"` va `7`:

```go
fmt.Printf("[%-6s][%4d]", "QQS", 7)
```

Nima chiqadi?

**A)** `[QQS   ][   7]` · **B)** `[   QQS][7   ]` · **C)** `[QQS][7]`

<details>
<summary>Javob</summary>

**A.** `QQS` 6 belgilik joyning chapida (oʻngida 3 ta probel), `7` 4 belgilik joyning oʻngida (chapida 3 ta probel).
**B** ni tanlagan boʻlsangiz, `-` ni teskari tushungansiz: `-` chapga tekislaydi, `-` siz son oʻngga suriladi.
**C** — kenglik yoʻq boʻlgandagi natija.

Bu misol papkada yoʻq; uni oʻzim ishga tushirdim (oxiriga `\n` qoʻshdim, terminalda chiroyli chiqishi uchun):

```go
package main

import "fmt"

func main() {
	fmt.Printf("[%-6s][%4d]\n", "QQS", 7)
}
```

```console
$ go run .
[QQS   ][   7]
```

</details>

Har bir katak bitta belgi:

```text
%-6s  "QQS"  ->  [Q][Q][S][ ][ ][ ]   chapga, oʻngi probel
%4d   7      ->  [ ][ ][ ][7]         oʻngga, chapi probel
%02d  4      ->  [0][4]               kenglik 2, boʻsh joy 0 bilan
```

Endi papkadagi uch qator:

```console
$ ./_video/run.sh 09-jadval

yetkazish          15000
jami               30672
```

Nomlar uzunligi har xil (`QQS` 3, `yetkazish` 9 belgi), lekin sonlarning oʻng chetlari bir chiziqda.

Kenglik — eng kam joy, chegara emas. Matn kenglikdan uzun boʻlsa, kesilmaydi, ustun suriladi. Bu misol ham papkada
yoʻq: `"yetkazib berish"` 15 belgi, `%-14s`'dan bittaga uzun.

```go
package main

import "fmt"

func main() {
	fmt.Printf("%-14s %9d\n", "QQS", 1679)
	fmt.Printf("%-14s %9d\n", "yetkazib berish", 15000)
	fmt.Printf("%-14s %9d\n", "jami", 30672)
}
```

```console
$ go run .
QQS                 1679
yetkazib berish     15000
jami               30672
```

2-qatordagi son bitta belgiga oʻngga surildi. Shuning uchun kenglikni eng uzun nomga qarab tanlaysiz.

Qisqasi: son — kenglik, `-` chapga tekislaydi, `0` boʻsh joyni nol bilan toʻldiradi.

## `fmt.Sprintf`: natija `string` boʻlib qaytadi

Mahsulot qatorida chap ustunga ikki qiymat kerak: nom va soni (`choy, 7 dona`). Kenglik bitta argumentga
qoʻllanadi, shuning uchun avval ularni bitta matnga yigʻamiz. Buni **`fmt.Sprintf`** qiladi: shablon xuddi
`Printf`'niki, lekin natijani ekranga chiqarmaydi, `string` qilib **qaytaradi**.

```go filename="_video/10-sprintf/main.go" showLineNumbers
package main

import "fmt"

func main() {
	name := "choy"
	sold := 7
	item := fmt.Sprintf("%s, %d dona", name, sold)
	fmt.Println(item)
}
```

`fmt.Sprintf(…)` yozilgan joyda shu matn hosil boʻladi, `:=` esa uni `item` degan yangi oʻzgaruvchiga beradi:

| Qator | Kod | `name` | `sold` | `item` | Ekranda |
|---|---|---|---|---|---|
| 6 | `name := "choy"` | `"choy"` | | | |
| 7 | `sold := 7` | `"choy"` | `7` | | |
| 8 | `item := fmt.Sprintf("%s, %d dona", name, sold)` | `"choy"` | `7` | `"choy, 7 dona"` | hali hech narsa |
| 9 | `fmt.Println(item)` | `"choy"` | `7` | `"choy, 7 dona"` | `choy, 7 dona` |

```console
$ ./_video/run.sh 10-sprintf
choy, 7 dona
```

8-qatordan keyin ekranda hali hech narsa yoʻq. Matnni 9-qatordagi `Println` chiqaradi.

## Yakuniy chek

Hammasini bozorga yigʻamiz. Yuqori qism va hisob (1–31-qatorlar) oʻzgarmadi, oxiridagi uchta `Println` almashdi:

```go filename="main.go" showLineNumbers
package main

import "fmt"

const tiyinPerSom = 100    // 1 soʻm = 100 tiyin
const vatPercent = 12      // QQS, foizda
const deliverySom = 15_000 // yetkazib berish, soʻmda (QQS qoʻshilmaydi)

func main() {
	fmt.Println("bozor ishga tushdi")
	fmt.Println("versiya: 0.1.0")

	var name string
	var price int64
	var active bool
	fmt.Println(name, price, active)

	name = "choy"
	price = 1_999 * tiyinPerSom // tiyinda
	active = true
	stock := 40
	weight := 1.5
	fmt.Println(name, price, active, stock, weight)

	sold := 7
	stock = stock - sold
	fmt.Println(name, stock)

	subtotal := price * int64(sold)
	vat := subtotal * vatPercent / 100
	total := subtotal + vat + deliverySom*tiyinPerSom

	item := fmt.Sprintf("%s, %d dona", name, sold)
	fmt.Printf("%-14s %9d.%02d\n", item, subtotal/tiyinPerSom, subtotal%tiyinPerSom)
	fmt.Printf("%-14s %9d.%02d\n", "QQS", vat/tiyinPerSom, vat%tiyinPerSom)
	fmt.Printf("%-14s %9d.%02d\n", "jami", total/tiyinPerSom, total%tiyinPerSom)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 33 | `item := fmt.Sprintf("%s, %d dona", name, sold)` | chap ustun uchun bitta matn: `"choy, 7 dona"` |
| 34 | `fmt.Printf("%-14s %9d.%02d\n", item, subtotal/tiyinPerSom, subtotal%tiyinPerSom)` | mahsulot qatori: 1 399 300 tiyin → `13993` va `00` |
| 35 | `… "QQS", vat/tiyinPerSom, vat%tiyinPerSom)` | QQS qatori: 167 916 tiyin → `1679` va `16` |
| 36 | `… "jami", total/tiyinPerSom, total%tiyinPerSom)` | jami qatori: 3 067 216 tiyin → `30672` va `16` |

Uch qator bitta shablonda: `"%-14s %9d.%02d\n"`. Nom 14 kenglikda chapga, probel, soʻm qismi `%9d` bilan oʻngga,
nuqta, tiyin `%02d` bilan. Summa qismi: 9 + 1 + 2 = 12 belgi, butun qator 14 + 1 + 12 = 27 belgi.

```console
$ go run .
bozor ishga tushdi
versiya: 0.1.0
 0 false
choy 199900 true 40 1.5
choy 33
choy, 7 dona       13993.00
QQS                 1679.16
jami               30672.16
```

Darsning boshida vaʼda qilingan chek: uch qator, summalar bitta ustunda, tiyin har doim ikki raqam. Belgilarni
sanab koʻring:

```text
         1         2
123456789012345678901234567
choy, 7 dona       13993.00
QQS                 1679.16
jami               30672.16
```

| Belgilar | Shablon qismi | 1-qatorda |
|---|---|---|
| 1–14 | `%-14s` ← `item` | `choy, 7 dona` va 2 probel |
| 15 | probel | |
| 16–24 | `%9d` ← soʻm | 4 probel va `13993` |
| 25 | `.` | `.` |
| 26–27 | `%02d` ← tiyin | `00` |

Bitta cheklov (kurs papkasidagi README'dan): `%d.%02d` faqat manfiy boʻlmagan summa uchun toʻgʻri. Manfiy summada
butun sonli boʻlish ham, qoldiq ham manfiy boʻladi. Bu misol papkada yoʻq:

```go
package main

import "fmt"

const tiyinPerSom = 100

func main() {
	var refund int64 = -5 // tiyinda
	fmt.Printf("%d.%02d\n", refund/tiyinPerSom, refund%tiyinPerSom)
}
```

```console
$ go run .
0.-5
```

Bozorda summa manfiy boʻlmaydi: notoʻgʻri narx va miqdorni [GB-1.05](/lab/youtube/gb/gb-1-05) da `if` bilan rad etamiz.

## Koʻp uchraydigan xatolar

### 1. `string(total)` raqam emas, bitta belgi beradi

Oʻtgan darsda aylantirishni (conversion) koʻrdik: `int64(sold)`. Kimdir xuddi shu usul bilan summani matnga
aylantiradi va `+` bilan `"jami: "` ga qoʻshadi:

```go filename="_video/11-string-xato/main.go" showLineNumbers
package main

import "fmt"

func main() {
	var total int64 = 3_067_216 // tiyinda
	fmt.Println("jami: " + string(total))
}
```

Kompilyatsiya qilib ishga tushirsak, nima boʻladi?

**A)** `jami: 3067216` chiqadi · **B)** kompilyatsiya xatosi · **C)** raqam oʻrniga bitta belgi

<details>
<summary>Javob</summary>

**C.** Kod kompilyatsiya boʻladi va raqam oʻrniga bitta belgi chiqadi. `string(son)` yozilsa, Go sonni belgining
kodi deb oladi. **A** — kutilgan natija, lekin `string(…)` raqamlarni yozmaydi. **B** emas: ikki tomon ham
`string`, shuning uchun `+` ishlaydi.

</details>

```console
$ ./_video/run.sh 11-string-xato
jami: �
```

Unicode'dagi eng katta belgi kodi 1 114 111 (U+10FFFF), 3 067 216 esa undan katta. Bunday kodli belgi yoʻq,
shuning uchun Go almashtirish belgisini qoʻydi: ichida soʻroq belgisi bor romb (U+FFFD). Dastur xatosiz ishladi,
chekdagi summa esa buzildi.

Bunday joyni **`go vet`** topadi. `go vet` — Go bilan birga keladigan tekshiruvchi: kodni ishga tushirmasdan
shubhali joylarni topadi (toʻliq [GB-3.03](/lab/youtube/gb/gb-3-03) da).

```console
$ ./_video/run.sh 11-string-xato vet
main.go:7:25: conversion from int64 to string yields a string of one rune, not a string of digits
```

Xabar 7-qator, 25-ustun haqida: «`int64`'dan `string`'ga aylantirish raqamlar matnini emas, bitta rune'dan iborat
matnni beradi». **rune** — bitta belgining kodi; uni [GB-2.10](/lab/youtube/gb/gb-2-10) da ochamiz. `go vet` xabarida
`./` yoʻq, faqat `main.go`.

**Tuzatish:** `fmt.Sprintf("%d", total)` yoki toʻgʻridan-toʻgʻri `fmt.Printf("jami: %d\n", total)`.

### 2. Feʼl argumentga mos emas: `%!d(string=choy)`

Shablonda `%d`, yaʼni butun son kutiladi, argument esa `name`, yaʼni `string`:

```go filename="_video/12-feyl-xato/main.go" showLineNumbers
package main

import "fmt"

func main() {
	name := "choy"
	fmt.Printf("%d\n", name)
}
```

`+` bilan tur xatosini kompilyator toʻxtatgan edi. Bu safar-chi?

**A)** kompilyatsiya xatosi · **B)** ishlaydi va `choy` chiqadi · **C)** ishlaydi, lekin xato belgisi chiqadi

<details>
<summary>Javob</summary>

**C.** Dastur ishlaydi, lekin natija oʻrniga xato belgisi chiqadi. `Printf` istalgan turdagi argumentni qabul
qiladi, shablonni esa dastur ishlayotganda oʻqiydi. Kompilyator argument turlarini shablon bilan solishtirmaydi,
shuning uchun **A** emas. `%d` `string`'ni yozolmaydi, shuning uchun **B** ham emas.

</details>

```console
$ ./_video/run.sh 12-feyl-xato
%!d(string=choy)
```

Oʻqilishi: `%`, undov, feʼl `d`, qavs ichida argumentning asl turi va qiymati. Log'da `%!` ni koʻrsangiz, feʼl va
argument mos emas.

`go vet` buni ham topadi:


«7-qatordagi `fmt.Printf`: `%d` feʼliga `name` degan argument berilgan, uning turi notoʻgʻri — `string`».

`go test` vet'ning shu ikki tekshiruvini (printf va stringintconv) testlardan oldin oʻzi ishga tushiradi. Vet biror
narsa topsa, testlar ishga tushmaydi. Buni papkaning nusxasida tekshirdim (papkada yoʻq): `main.go`'ning 35-qatorida
QQS summasi oʻrniga `"1679"` matnini berdim:



### 3. Videoda koʻrgan boshqa xatolar

- **`"jami: " + total`** — `mismatched types string and int64`. Sonni matnga `fmt.Sprintf`/`fmt.Printf` aylantiradi
  («Matnni qoʻshish» boʻlimi).
- **`\n` unutilgan** — ikki `Printf` bitta qatorga yopishadi, xato chiqmaydi. Shablon oxiriga `\n` qoʻying
  («`\n` boʻlmasa» boʻlimi).
- **`%d.%d` tiyin uchun** — 4 tiyin `.4` boʻlib chiqadi va 40 tiyin deb oʻqiladi, xato chiqmaydi. Tiyin uchun
  `%02d` («Tiyin» boʻlimi).

## Oʻzingizni tekshiring

**1.** Nega `label + total` (`string` va `int64`) kompilyatsiya boʻlmaydi va toʻgʻri yoʻli qanday?

<details>
<summary>Javob</summary>

`+`'ning ikki tomoni bir xil turda boʻlishi kerak, Go sonni oʻzi matnga aylantirmaydi:
`invalid operation: label + total (mismatched types string and int64)`. Toʻgʻri yoʻli: sonni formatlash, masalan
`fmt.Sprintf("%d", total)` yoki darhol `fmt.Printf("jami: %d\n", total)`. `string(total)` emas (xato 1).

</details>

**2.** Summada 4 tiyin. `%d.%d` bilan tiyin qismi qanday chiqadi va nima tuzatadi?

<details>
<summary>Javob</summary>

Nuqtadan keyin bitta `4` chiqadi: `1919.4`. Tuzatish — `%02d`: kenglik 2, boʻsh joy nol bilan, natija `1919.04`.

</details>

**3.** Natijani oldindan ayting (`|` bu yerda oddiy matn):

```go
package main

import "fmt"

func main() {
	fmt.Printf("%-5s|%3d|%03d\n", "non", 4, 4)
	fmt.Printf("%q\n", "choy")
}
```

<details>
<summary>Javob</summary>

`%-5s` — `non` va 2 probel; `%3d` — 2 probel va `4`; `%03d` — `004`. `%q` matnni qoʻshtirnoq bilan chiqaradi.

```console
$ go run .
non  |  4|004
"choy"
```

</details>

**4.** `item := fmt.Sprintf("%s, %d dona", name, sold)` qatoridan keyin ekranda nima bor?

<details>
<summary>Javob</summary>

Hech narsa. `Sprintf` natijani ekranga chiqarmaydi, `string` qilib qaytaradi; u `item`'ga yoziladi. Ekranga uni
keyingi `Println` yoki `Printf` chiqaradi.

</details>

**5.** GB-1.01 dan: `go run .` va `go build` farqi nima?

<details>
<summary>Javob</summary>

`go run .` vaqtinchalik bajariladigan fayl yasab, darhol ishga tushiradi, papkada hech narsa qolmaydi. `go build`
papkada `bozor` degan bajariladigan faylni qoldiradi, uni `./bozor` bilan ishga tushirasiz.

</details>
