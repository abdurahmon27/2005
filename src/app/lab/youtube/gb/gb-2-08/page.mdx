**Bitta gʻoya:** `error` — bitta `Error() string` metodli interface. `errors.New` yasagan sentinel xato — bitta aniq qiymat, `==` uni
faqat oʻzi bilan teng deydi. `%w` xatoni oʻrab, asl xatoni yangi qavat ichida saqlaydi, shuning uchun `==` yolgʻon boʻladi;
`errors.Is` (qiymat boʻyicha) va `errors.As` (tur boʻyicha) esa qavatlarni `Unwrap` bilan oxirigacha tekshiradi.

Dars oxirida siz:

- `ErrNotFound` sentinel xatosini eʼlon qilib, `fmt.Errorf("mahsulot %d: %w", …)` bilan kontekst qoʻshasiz va `errors.Is` bilan topasiz;
- `%w` oʻrniga `%v` yozilganda zanjir nega uzilishini va `==` hamda `err.(*T)` nega oʻralgan xatoda ishlamasligini tushuntirasiz;
- maydonli oʻz xato turingizni (`*StockError`) yozib, `errors.As` va `errors.AsType` bilan undan qoldiq sonini olasiz;
- `errors.Join` bilan bir nechta xatoni bittaga yigʻasiz (ixtiyoriy boʻlim).

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| sentinel xato | paket darajasida bir marta yaratilgan xato qiymati; chaqiruvchi shu aniq qiymat bilan solishtiradi | sentinel error |
| oʻrash va zanjir | `%w` xatoga kontekst qoʻshadi, asl xatoni ichida saqlaydi; oʻralgan xatolar zanjir hosil qiladi | wrapping, error chain |
| typed error | maydonlari bor, `Error()` metodli oʻz tur; chaqiruvchi turi boʻyicha topadi va maydonlarini oʻqiydi | typed error |

Ikkita yordamchi: `%T` (qiymatning aniq turini chiqaradi) va `errors.Join` (bir nechta xatoni bittaga yigʻadi, «Chuqurroq» boʻlimida).

## error — bitta metodli interface

Avval `error`ning oʻzi. `go doc builtin.error` — `builtin` paketining hujjati: bu paket Go'da oldindan eʼlon qilingan nomlarni
(`error`, `int`, `string`) tasvirlaydi. Ular kichik harf bilan boshlansa ham har bir paketda koʻrinadi.

```console
$ go doc builtin.error
package builtin // import "builtin"

type error interface {
	Error() string
}
    The error built-in interface type is the conventional interface for
    representing an error condition, with the nil value representing no error.
```

`error` — interface, unda bitta metod: `Error`, parametrsiz, `string` qaytaradi. `Error() string` metodi bor **har qanday** tur
`error`ni bajaradi (GB-2.07: `implements` yozilmaydi). `fmt.Println` xatoni chiqarayotganda shu metodni chaqiradi
([fmt hujjati](https://pkg.go.dev/fmt): «If an operand implements the error interface, the Error method will be invoked»).

Eng oddiy xatoni `errors.New` yasaydi. Mana Go'ning oʻz manbasi (`errors` paketi, qator 64–75):

```console
$ sed -n 64,75p $(go env GOROOT)/src/errors/errors.go
func New(text string) error {
	return &errorString{text}
}

// errorString is a trivial implementation of error.
type errorString struct {
	s string
}

func (e *errorString) Error() string {
	return e.s
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1 | `func New(text string) error {` | `text` matnini oladi, `error` interface qaytaradi |
| 2 | `return &errorString{text}` | `&` va `{…}` yangi `errorString` struct yasaydi va **manzilini** qaytaradi (GB-2.04). Struct'da bitta maydon, shuning uchun qiymat maydon nomisiz, tartib bilan yozilgan |
| 6–8 | `type errorString struct { s string }` | tur nomi kichik harf bilan: `errors` paketidan tashqarida koʻrinmaydi (GB-2.06). Matn `s` maydonida |
| 10–12 | `func (e *errorString) Error() string { return e.s }` | `*errorString`da `Error` metodi bor, u `s`dagi matnni qaytaradi: shuning uchun `*errorString` — `error` |

Demak, `errors.New("…")` qaytargan qiymatning ichida **tur** `*errors.errorString` va **qiymat** — yangi structning manzili turadi.
Oldingi savoldagi `w io.Writer` bilan bir xil tuzilish.

## Sentinel xato va ==

Chaqiruvchi solishtirishi uchun bitta aniq xato qiymati kerak. `store.go`ga `errors` import'ini qoʻshamiz va funksiyalardan
**tashqarida**, paket darajasida, `ErrNotFound` oʻzgaruvchisini eʼlon qilamiz; `Sell` mahsulotni topmasa, aynan shuni qaytaradi:

```go
// ErrNotFound — katalogda bunday ID'li mahsulot yoʻq.
var ErrNotFound = errors.New("mahsulot topilmadi")

func (s *Store) Sell(id int64, quantity int) error {
	// … mahsulotni qidiradi, topsa sotadi va nil qaytaradi
	return ErrNotFound
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 2 | `var ErrNotFound = errors.New(…)` | paket darajasidagi oʻzgaruvchi: funksiyadan tashqarida. U dastur ishga tushganda, `main`dan oldin, **bir marta** yaratiladi ([Go spec: Package initialization](https://go.dev/ref/spec#Package_initialization)) |
| 2 | `ErrNotFound` | katta harf: `main` ham koʻradi (GB-2.06). `Err` bilan boshlash — Go odati |
| 4 | `func (s *Store) Sell(id int64, quantity int) error {` | GB-2.06dagidek: `id` — mahsulot raqami, `quantity` — dona soni |
| 6 | `return ErrNotFound` | mahsulot topilmasa, aynan shu qiymat qaytadi |

Bunday xato **sentinel error** (sentinel xato) deyiladi: kutubxonada `io.EOF` ham shunday. `main`da `err`ni `store.ErrNotFound` bilan
`==` orqali solishtiramiz:

```go
	err := st.Sell(9, 1)
	if err == store.ErrNotFound {
		fmt.Println("bunday mahsulot yoʻq")
	} else if err != nil {
		fmt.Println("xato:", err)
	}
```

Ikki interface qiymati teng, agar ichidagi **turlari** ham, **qiymatlari** ham bir xil boʻlsa ([Go spec: Comparison operators](https://go.dev/ref/spec#Comparison_operators)).
Teng boʻlsa — foydalanuvchiga tushunarli xabar. Aks holda, xato bor boʻlsa (`err != nil`), xatoning oʻzi chiqadi, shunda boshqa xato
yoʻqolib ketmaydi.

```console
$ ./_video/run.sh 01-sentinel go run ./cmd/bozor
bunday mahsulot yoʻq
```

Endi `main`ga `errors` import'ini va ikki qator qoʻshamiz: `other` — `errors.New` bilan yasalgan yangi xato, matni `ErrNotFound`niki
bilan aynan bir xil. Keyin `other == store.ErrNotFound` natijasini chiqaramiz:

```go
	other := errors.New("mahsulot topilmadi")
	fmt.Println(other == store.ErrNotFound)
```

Ikkinchi qatorda nima chiqadi?

**A)** `true`: matn bir xil · **B)** `false` · **C)** kompilyatsiya xatosi: interface'larni solishtirib boʻlmaydi

<details>
<summary>Javob</summary>

**B: `false`.** Interface'larni solishtirish mumkin: kompilyatsiya xatosi yoʻq (**C** notoʻgʻri). Solishtirish matnga emas, tur va qiymatga qaraydi.
`errors.New` har chaqirilganda **yangi** struct yasaydi va uning manzilini qaytaradi. Ikkala qiymatning turi bir xil (`*errors.errorString`),
lekin manzillar har xil. **A** ni tanlagan boʻlsangiz, solishtirish matnga qaraydi deb oʻylagansiz. `errors.New`ning
hujjat izohi ham shuni aytadi: «Each call to New returns a distinct error value even if the text is identical».

</details>

```console
$ ./_video/run.sh 02-yangi go run ./cmd/bozor
bunday mahsulot yoʻq
false
```

Birinchi qator — `Sell` qaytargan xato sentinel'ga teng. Ikkinchi qator — `false`. Xotirada:

| qiymat | ichidagi tur | ichidagi qiymat (manzil) | `== store.ErrNotFound` |
|---|---|---|---|
| `store.ErrNotFound` | `*errors.errorString` | A | — |
| `Sell` qaytargan `err` | `*errors.errorString` | A | `true` (bitta qiymat) |
| `other` | `*errors.errorString` | B | `false` (turi bir xil, manzil boshqa) |

Shuning uchun sentinel **bir marta** eʼlon qilinadi va hamma oʻsha bitta oʻzgaruvchidan foydalanadi.

## %w bilan oʻrash

Muammo: xabar «mahsulot topilmadi» deydi, lekin **qaysi** ID? ID'ni qoʻshamiz. `fmt.Errorf` (GB-1.07) `Sprintf` kabi shablonni
toʻldiradi, natijani `error` qilib qaytaradi. Yangi narsa — `%w`:

```go
func (s *Store) Sell(id int64, quantity int) error {
	// … mahsulotni qidiradi, topsa sotadi va nil qaytaradi
	return fmt.Errorf("mahsulot %d: %w", id, ErrNotFound)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 3 | `fmt.Errorf("mahsulot %d: %w", id, ErrNotFound)` | `%d` — `id`ni son qilib qoʻyadi. `%w` matnda `%v` kabi xatoning matnini qoʻyadi, lekin natija asl xatoni **ichida saqlab qoladi** |

Buni **oʻrash** (inglizcha **wrapping**) deyishadi: asl xato yangi xatoning ichida, matnga tafsilot qoʻshilgan. `main` oʻzgarmadi, hali
ham `==` bilan solishtiradi. `Sell(9, 1)` chaqirilganda nima chiqadi?

**A)** `bunday mahsulot yoʻq` · **B)** `xato: mahsulot 9: mahsulot topilmadi` · **C)** kompilyatsiya xatosi

<details>
<summary>Javob</summary>

**B.** `else` tarmogʻi ishladi: matnda endi ID bor, lekin `==` yolgʻon boʻldi. Nega — keyingi qadamda xato ichidagi turdan koʻramiz.
**A** ni tanlagan boʻlsangiz, matn oʻzgargan, xato esa oʻsha deb oʻylagansiz. **C** — kod toʻgʻri, kompilyator xato topmaydi.

</details>

```console
$ ./_video/run.sh 03-wrap go run ./cmd/bozor
xato: mahsulot 9: mahsulot topilmadi
```

Sababini koʻrish uchun `main`ning oxiriga ikki qator qoʻshamiz. `fmt.Printf`dagi `%T` qiymatning aniq turini yozadi; interface boʻlsa —
ichidagi turni. Birinchi qator `err` uchun, ikkinchisi `ErrNotFound` uchun:

```go
	fmt.Printf("%T\n", err)
	fmt.Printf("%T\n", store.ErrNotFound)
```

```console
$ ./_video/run.sh 04-tur go run ./cmd/bozor
xato: mahsulot 9: mahsulot topilmadi
*fmt.wrapError
*errors.errorString
```

`err`ning turi — `*fmt.wrapError`, `ErrNotFound`niki — `*errors.errorString`. Interface ichidagi turlar har xil boʻlsa, `==` doim
`false`. `wrapError` — `fmt` paketining oʻz turi; manbasi:

```console
$ sed -n 70,81p $(go env GOROOT)/src/fmt/errors.go
type wrapError struct {
	msg string
	err error
}

func (e *wrapError) Error() string {
	return e.msg
}

func (e *wrapError) Unwrap() error {
	return e.err
}
```

`wrapError` ikki narsani saqlaydi: tayyor matn (`msg`) va ichidagi asl xato (`err`). `Unwrap` metodi shu ichidagi xatoni qaytaradi.
Har bir `%w` yangi qavat qoʻshadi, qavatlar **zanjir** (error chain) hosil qiladi:

```text
err ──► *fmt.wrapError            msg: "mahsulot 9: mahsulot topilmadi"
            │ Unwrap()            err: ─────────────┐
            ▼                                       │
        *errors.errorString  ◄──────────────────────┘
        (store.ErrNotFound)
```

`errors.Is(err, target)` xatoni `target` bilan solishtiradi; teng boʻlmasa `Unwrap` bilan bir qavat pastga tushadi va zanjir
tugaguncha davom etadi. Bizning zanjirda:

| Qadam | Tekshirilayotgan qavat | Tur | `== store.ErrNotFound`? |
|---|---|---|---|
| 1 | `err` | `*fmt.wrapError` | yoʻq (tur boshqa) → `Unwrap` |
| 2 | ichidagi xato | `*errors.errorString` | ha, manzil A → `true` |

`main`da `==` oʻrniga `errors.Is`: birinchi argument — tekshiriladigan xato, ikkinchisi — qidirilayotgan sentinel. `main`da `errors`
import'i boʻlishi kerak:

```go
	err := st.Sell(9, 1)
	if errors.Is(err, store.ErrNotFound) {
		fmt.Println("bunday mahsulot yoʻq")
	} else if err != nil {
		fmt.Println("xato:", err)
	}
```

```console
$ ./_video/run.sh 05-is go run ./cmd/bozor
bunday mahsulot yoʻq
```

Xato oʻralgan, lekin topildi. Savol: `main`ga bitta qator qoʻshamiz — `errors.Is`ga sentinel oʻrniga xuddi shu matnli **yangi** xato beramiz:

```go
	fmt.Println(errors.Is(err, errors.New("mahsulot topilmadi")))
```

`Sell`da `%w` toʻgʻri turibdi. Nima chiqadi?

**A)** `true`: matn bir xil · **B)** `false` · **C)** `true`: xato `%w` bilan oʻralgan

<details>
<summary>Javob</summary>

**B: `false`.** `errors.Is` zanjirning har bir qavatini `==` bilan solishtiradi, matnni emas. `errors.New` yangi qiymat yasadi, uning manzili
`ErrNotFound`nikiga teng emas. **A** — matn bir xil, lekin `Is` matnga qaramaydi. **C** — oʻrash zanjirni yasaydi, lekin topish uchun baribir
**shu** qiymatning oʻzi kerak. Shuning uchun `Is`ga doim eʼlon qilingan sentinel'ning oʻzi beriladi.

</details>

```console
$ ./_video/run.sh 07-quiz go run ./cmd/bozor

```

## Oʻz xato turimiz: StockError

Endi qoldiq. Foydalanuvchiga «faqat 40 dona qoldi» demoqchimiz, lekin 40 soni faqat matnda yashaydi, matndan son qidirish esa moʻrt.
Yechim: son **maydonda** turadigan oʻz xato turimiz. `store.go`da `StockError` struct'i: mahsulot nomi `Name`, ombordagi qoldiq `Stock`
va soʻralgan son `Want`. Unga `Error` metodi: `Sprintf` birinchi ekrandagi matnni yigʻadi.

```go
// StockError — omborda soʻralgancha mahsulot yoʻq.
type StockError struct {
	Name  string
	Stock int // omborda bor
	Want  int // soʻralgan
}

func (e *StockError) Error() string {
	return fmt.Sprintf("%s: qoldiq %d, soʻralgan %d", e.Name, e.Stock, e.Want)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 2–6 | `type StockError struct { … }` | uch maydon: `Name` (mahsulot nomi), `Stock` (omborda nechta bor), `Want` (nechta soʻralgan) |
| 8 | `func (e *StockError) Error() string {` | `Error` metodi, receiver `e`. Receiver **pointer**: shunda faqat `*StockError` `error` boʻladi (GB-2.07: pointer receiver metodlari `*T`da), va chaqiruvchi qidiradigan tur bitta |
| 9 | `return fmt.Sprintf(…)` | maydonlardan matn yigʻadi: «olma: qoldiq 40, soʻralgan 41» |

Bunday xato — **typed error**: oʻz turi va maydonlari bor. Endi `Sell`dagi `%w` joyiga qaytdi (`ErrNotFound` yana `%w` bilan oʻraladi).
Qoldiq yetmasa, `Sell` hozirgacha xatoni `fmt.Errorf` bilan yasardi; oʻrniga `&StockError{…}` qaytaramiz. Bu yerda `p` — topilgan
mahsulotga pointer (qidiruv qismi qisqartirildi):

```go
	// … p — topilgan mahsulot (*Product)
	if p.Stock < quantity {
		return &StockError{Name: p.Name, Stock: p.Stock, Want: quantity}
	}
```

`&StockError{…}` — maydonlari toʻldirilgan yangi struct va uning **manzili**. Matn oʻsha, sonlar esa endi maydonlarda.

## errors.As: tur boʻyicha izlash

`main`da olma uchun 41 dona soʻraymiz. Xato boʻlsa, uni «buyurtma 7» qavati bilan oʻraymiz (buyurtma ichida chaqirilgandek).
Avval `err`ni chiqaramiz, keyin GB-2.07dagi type assertion — faqat `T` bu safar aniq tur: `err` ichida `*store.StockError` bormi?
Natija `ok`ga tushadi, qiymat `_` bilan tashlanadi:

```go
	err = st.Sell(1, 41)
	if err != nil {
		err = fmt.Errorf("buyurtma 7: %w", err)
	}
	fmt.Println(err)
	_, ok := err.(*store.StockError)
	fmt.Println(ok)
```

`ok` nima boʻladi?

**A)** `true`: ichida `*StockError` bor · **B)** `false` · **C)** `panic`

<details>
<summary>Javob</summary>

**B: `false`.** Matn qavatma-qavat yigʻildi: «buyurtma 7: » va `Sell`ning matni. Type assertion esa faqat **eng tashqi** qavatga qaraydi, u yerda
`*fmt.wrapError`. `==` kabi, oʻralgan xatoda u ishlamaydi. **A** — xato ichida bor, lekin assertion ichiga qaramaydi. **C** — comma-ok shakli
(`_, ok :=`) hech qachon panic qilmaydi.

</details>

```console
$ ./_video/run.sh 08-assert go run ./cmd/bozor
bunday mahsulot yoʻq

```

Uchinchi qator — `false`. Assertion qatorlari oʻrniga `errors.As`:

```go
	var se *store.StockError
	if errors.As(err, &se) {
		fmt.Printf("%s: faqat %d dona qoldi\n", se.Name, se.Stock)
	} else if err != nil {
		fmt.Println("xato:", err)
	}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1 | `var se *store.StockError` | `*store.StockError` turidagi oʻzgaruvchi; hozircha `nil` |
| 2 | `errors.As(err, &se)` | zanjirni `Is` kabi aylanadi, lekin **qiymat** emas, **tur** qidiradi. Qaysi turni — `se`ning turidan biladi. Topsa, topilgan xatoni `se`ga yozadi va `true` qaytaradi |
| 2 | `&se` | `se` oʻzi pointer, `&se` esa shu **oʻzgaruvchining manzili**: `As` unga faqat manzil orqali yoza oladi (GB-2.04) |
| 3 | `se.Name`, `se.Stock` | topilgan xatoning maydonlari |

`As` zanjirda:

| Qadam | Qavat | Tur `*store.StockError`ga mosmi? |
|---|---|---|
| 1 | `err` | `*fmt.wrapError`: yoʻq → `Unwrap` |
| 2 | ichidagi xato | `*store.StockError`: ha → `se` = shu xato, natija `true` |

## Koʻp uchraydigan xatolar

**1. «Matn bir xil, demak xato ham bir xil».** Bu eng keng tarqalgan notoʻgʻri tushuncha. Sentinel — matn emas, **bitta qiymat**:
`errors.New("mahsulot topilmadi")` ikkinchi marta yozilsa, yangi, boshqa xato yasaladi. Yuqoridagi «Sentinel xato va ==» boʻlimida `other == store.ErrNotFound`
`false` chiqdi, «%w bilan oʻrash» boʻlimidagi savolda `errors.Is` yangi xatoni topmadi. Tuzatish: sentinel'ni paket darajasida **bir marta** eʼlon qiling va hamma joyda oʻshani ishlating.

**2. `%w` oʻrniga `%v`.** Jim xato: dastur ishlaydi, natija notoʻgʻri. `Sell`da bitta harf almashtirildi (`_video/06-v`):

```go
	return fmt.Errorf("mahsulot %d: %v", id, ErrNotFound)
```

`main` — oʻsha, `errors.Is` bilan:

```console
$ ./_video/run.sh 06-v go run ./cmd/bozor
xato: mahsulot 9: mahsulot topilmadi
```

Yana `else` tarmogʻi, matn esa harfma-harf avvalgidek. `%v` faqat xatoning **matnini** oladi, natijada asl xato yoʻq — zanjir uziladi, `errors.Is` hech
narsa topmaydi. `go vet` ham buni koʻrmaydi:

```console
$ ./_video/run.sh 06-v go vet ./...
```

`go vet` hech narsa chiqarmadi (skript faqat oʻzining `(chiqish kodi: 0)` qatorini qoʻshadi, u yuqorida aytilganidek keltirilmadi). Qoida: chaqiruvchi tekshirishi kerak
boʻlgan xatoni `%w` bilan oʻrang. Ichki tafsilotni ataylab yashirmoqchi boʻlsangiz — `%v`: oʻralgan xato sizning API'ngizning bir qismiga aylanadi
([Go blog: Whether to Wrap](https://go.dev/blog/go1.13-errors#whether-to-wrap)).

**3. `errors.As(err, se)`: `&` yoʻq.** Bu dastur kurs papkasida yoʻq: men uni alohida papkada, xuddi shu `go.mod` va `internal/store` bilan ishga tushirdim.

## Oʻzingizni tekshiring

**1.** `Errorf`da `%v` va `%w` bir xil matn beradi. Farqi nimada?

<details>
<summary>Javob</summary>

`%w` asl xatoni natija ichida saqlaydi (`*fmt.wrapError` + `Unwrap`), shuning uchun `errors.Is` va `errors.As` uni zanjirda topadi. `%v` esa faqat matnni oladi:
zanjir uziladi, `errors.Is` va `errors.As` hech narsa topmaydi.

</details>

**2.** `errors.As(err, &se)`ga nega `se` emas, `&se` beriladi?

<details>
<summary>Javob</summary>

`As` topgan xatoni `se`ga **yozadi**. Funksiya chaqiruvchining oʻzgaruvchisiga faqat uning manzili orqali yoza oladi (GB-2.04), shuning uchun `&se`. `se` oʻzi ham
pointer (`*store.StockError`), `&se` esa shu oʻzgaruvchining manzili. `se` berilsa, `As` panic qiladi.

</details>

**3.** GB-2.05dan: `Order` struct'ida `Status` maydoni bor, `Pay` metodi **value receiver**'li:

```go
func (o Order) Pay() {
	o.Status = Paid
}
```

`order.Pay()`dan keyin `order`ning `Status`i oʻzgaradimi?

<details>
<summary>Javob</summary>

Yoʻq. Value receiver `order`ning **nusxasini** oladi, `Status` nusxada oʻzgaradi va nusxa bilan yoʻqoladi. Oʻzgartirish uchun receiver pointer boʻlishi kerak: `(o *Order) Pay()`.

</details>

**4.** Oldindan bashorat qiling. Dastur kurs papkasida yoʻq (xuddi shu `go.mod` va `internal/store` bilan alohida papkada ishga tushirildi):

```go

	"errors"
	"fmt"

	"github.com/abdurahmon27/bozor/internal/store"

	e2 := fmt.Errorf("buyurtma 7: %w", e1)
	fmt.Println(e2)
	fmt.Println(errors.Is(e2, store.ErrNotFound))
	fmt.Println(e2 == e1)
	fmt.Println(errors.Is(e2, e1))

```

Nima chiqadi?

<details>
<summary>Javob</summary>

true
false
true
```

Matn qavatma-qavat yigʻiladi (1-qator). Zanjir uch qavatli: `e2` → `e1` → `ErrNotFound`; `errors.Is` ikki marta `Unwrap` qilib sentinel'ni topadi (2-qator).
`e2 == e1` — turlari bir xil (`*fmt.wrapError`), lekin manzillari har xil: `false` (3-qator). `errors.Is(e2, e1)` — `e1` zanjirning oʻzida, ikkinchi qavatda: `true` (4-qator).

</details>

// Package store bozor katalogini xotirada saqlaydi.
// U internal/ ichida: uni faqat bozor modulining oʻz kodi import qila oladi.
package store

import (
	"errors"
	"fmt"
	"slices"
)

// ErrNotFound — katalogda bunday ID'li mahsulot yoʻq.
var ErrNotFound = errors.New("mahsulot topilmadi")

// ErrBadQuantity — soʻralgan dona soni musbat emas.
var ErrBadQuantity = errors.New("dona soni musbat boʻlishi kerak")

// StockError — omborda soʻralgancha mahsulot yoʻq.
type StockError struct {
	Name  string
	Stock int // omborda bor
	Want  int // soʻralgan
}

func (e *StockError) Error() string {
	return fmt.Sprintf("%s: qoldiq %d, soʻralgan %d", e.Name, e.Stock, e.Want)
}

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

// Store — xotiradagi katalog. Nol qiymati tayyor: var st store.Store.
type Store struct {
	products []Product
}

// Add katalogga mahsulot qoʻshadi va unga ID beradi (1, 2, 3 …).
func (s *Store) Add(name string, price int64, stock int) Product {
	p := Product{ID: int64(len(s.products)) + 1, Name: name, Price: price, Stock: stock}
	s.products = append(s.products, p)
	return p
}

// List katalogdagi mahsulotlarning nusxasini qaytaradi.
func (s *Store) List() []Product {
	return slices.Clone(s.products)
}

// Sell id'li mahsulotdan quantity dona sotadi va qoldiqni kamaytiradi.
// Xato boʻlsa qoldiq oʻzgarmaydi. Chaqiruvchi xatoni tekshira oladi:
// errors.Is(err, ErrNotFound) — mahsulot yoʻq,
// errors.As(err, &se) (se *StockError) — qoldiq yetmaydi,
// errors.Is(err, ErrBadQuantity) — dona soni musbat emas.
func (s *Store) Sell(id int64, quantity int) error {
	if quantity <= 0 {
		return fmt.Errorf("%w, hozir %d", ErrBadQuantity, quantity)
	}
	for i := range s.products {
		p := &s.products[i]
		if p.ID == id {
			if p.Stock < quantity {
				return &StockError{Name: p.Name, Stock: p.Stock, Want: quantity}
			}
			p.Stock -= quantity
			return nil
		}
	}
	return fmt.Errorf("mahsulot %d: %w", id, ErrNotFound)
}
```

```go filename="solution/cmd/bozor/main.go" showLineNumbers
// bozor dasturi: mahsulot sotadi va xatoni turiga qarab tushuntiradi.
package main

import (
	"errors"
	"fmt"

	"github.com/abdurahmon27/bozor/internal/store"
)

func main() {
	var st store.Store
	st.Add("olma", 1_200_000, 40)
	st.Add("non", 400_000, 100)

	err := st.Sell(9, 1)
	if errors.Is(err, store.ErrNotFound) {
		fmt.Println("bunday mahsulot yoʻq")
	} else if err != nil {
		fmt.Println("xato:", err)
	}

	err = st.Sell(1, 41)
	if err != nil {
		err = fmt.Errorf("buyurtma 7: %w", err)
	}
	var se *store.StockError
	if errors.As(err, &se) {
		fmt.Printf("%s: faqat %d dona qoldi\n", se.Name, se.Stock)
	} else if err != nil {
		fmt.Println("xato:", err)
	}
}

// message xatoni (err nil emas) foydalanuvchiga koʻrsatiladigan matnga aylantiradi.
// Xatoni matnga aylantirish bitta joyda: keyinroq server ham shunday funksiyadan foydalanadi.
// errors.Is va errors.As butun zanjirni tekshiradi, shuning uchun qoʻshimcha
// oʻralgan xatolar («buyurtma 7: …») ham taniladi.
func message(err error) string {
	if errors.Is(err, store.ErrNotFound) {
		return "bunday mahsulot yoʻq"
	}
	if errors.Is(err, store.ErrBadQuantity) {
		return "dona soni notoʻgʻri"
	}
	var se *store.StockError
	if errors.As(err, &se) {
		return fmt.Sprintf("%s: faqat %d dona qoldi", se.Name, se.Stock)
	}
	return "xato: " + err.Error()
}
```

- `Sell`, 1-qadam: `fmt.Errorf("%w, hozir %d", ErrBadQuantity, quantity)` — `%w` sentinel'ni oʻrab saqlaydi, `%d` soʻralgan sonni matnga qoʻyadi.
  Endi `errors.Is(err, ErrBadQuantity)` — `true`, matn esa avvalgidek: `dona soni musbat boʻlishi kerak, hozir 0`.
- `message`, 2-qadam: tartib muhim emas, lekin hammasi `errors.Is`/`errors.As` bilan, `==` bilan emas. Test xatolarni yana bir qavat («buyurtma 7: …») bilan oʻraydi;
  `Is` va `As` butun zanjirni tekshiradi, shuning uchun ular ham taniladi. Oxirgi `return` — oldingi `xato: …` xulqi.
