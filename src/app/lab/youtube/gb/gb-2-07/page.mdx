## Nimani oʻrganasiz

bozor katalogining hisobotini `printReport` funksiyasi `Printf` bilan ekranga chiqaradi. Endi xuddi shu hisobot faylga ham kerak,
testda esa xotiradagi matnga. Ekran, fayl va test uchun uchta funksiya yozmasdan buni qanday qilasiz?

**Bitta gʻoya:** interface — metodlar roʻyxatidan iborat tur. Roʻyxatdagi hamma metodga ega har qanday tur interface'ni **eʼlonsiz**
bajaradi: kompilyator metodlarni oʻzi solishtiradi. Interface qiymati ichida aniq tur va oʻsha turning qiymati turadi, `w.Write(p)`
chaqiruvi esa shu aniq turning `Write` metodiga boradi. Shuning uchun bitta `writeReport(w io.Writer, …)` ekranga, faylga va xotiradagi
buferga yoza oladi.

Dars oxirida siz:

- `go doc` bilan standart kutubxonadagi `io.Writer` va `fmt.Stringer` imzosini oʻqiysiz;
- bitta `writeReport(w io.Writer, …)` funksiyasi bilan hisobotni `os.Stdout`'ga, `os.Create` ochgan faylga va oʻzingiz yozgan
  `*byteCounter`'ga yozasiz;
- «method Write has pointer receiver» xatosini oʻqiysiz va `&c` bilan tuzatasiz;
- `Product`ga `String()` yozasiz, `fmt` uni qanday topishini koʻrasiz va `writeReport`'ni `strings.Builder` bilan faylsiz tekshirasiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| interface | metodlar roʻyxatidan iborat tur: nomi, parametrlari va natijalari yoziladi, tanasi yoʻq; maydon yoʻq | interface |
| interface'ni bajarish | turning metodlari roʻyxatdagi hamma metodni oʻz ichiga olsa, tur interface'ni bajaradi; buni hech qayerda eʼlon qilmaysiz | implementing an interface (implicitly) |
| kichik interface | bitta yoki ikkita metodli interface (`io.Writer`, `fmt.Stringer`); u qancha kichik boʻlsa, uni shuncha tur bajaradi | small interface |

Ikkita yordamchi tushuncha: `go doc` (standart kutubxona hujjatini terminalda koʻrsatuvchi buyruq) va `any` bilan type assertion
(oxirgi qismda `fmt`ning ichida). `os.Create`, `Close`, `fmt.Fprintf` va `strings.Builder` yangi tushuncha emas: har biri bir jumlada
aytiladi.

```go
func printReport(products []Product) {
```

## go doc bilan imzoni oʻqish

Yettinchi darsda xatoni `fmt.Fprintln(os.Stderr, …)` bilan standart xato oqimiga yozgan edik: birinchi argument qayerga yozishni aytadi.
Bu argumentning turi nima? Javob standart kutubxona hujjatida. `go doc` buyrugʻi shu hujjatni terminalda koʻrsatadi: `go doc fmt.Fprintln`
`fmt` paketidagi `Fprintln` haqida:

```console
$ go doc fmt.Fprintln
package fmt // import "fmt"

func Fprintln(w io.Writer, a ...any) (n int, err error)
    Fprintln formats using the default formats for its operands and writes to w.
    Spaces are always added between operands and a newline is appended.
    It returns the number of bytes written and any write error encountered.
```

Videoda hujjatdan faqat imzo qatori qoldirilgan; bu yerda `go doc`ning toʻliq natijasi. Birinchi qator — paket nomi va uning import yoʻli
(`//` dan keyin izoh). Imzo qatori:

| Qism | Maʼnosi |
|---|---|
| `w io.Writer` | birinchi parametr: nomi `w`, turi `io` paketidagi `Writer`. `Writer`ni keyingi buyruq ochadi |
| `a ...any` | ikkinchi parametr `a`: istalgan sondagi, istalgan turdagi qiymatlar (`any`ni bu darsda ochamiz) |
| `(n int, err error)` | ikkita natija, ularga nom ham berilgan: `n` — yozilgan baytlar soni, `err` — xato. Nomlar hujjat uchun |

Hujjat matnining oxirgi gapi ham shuni aytadi: u yozilgan baytlar sonini va yozishdagi xatoni qaytaradi.

## Interface: metodlar roʻyxatidan iborat tur

Endi `io.Writer`ning oʻzi:

```console
$ go doc io.Writer
package io // import "io"

type Writer interface {
	Write(p []byte) (n int, err error)
}
    Writer is the interface that wraps the basic Write method.

    Write writes len(p) bytes from p to the underlying data stream. It returns
    the number of bytes written from p (0 <= n <= len(p)) and any error
    encountered that caused the write to stop early. Write must return a non-nil
    error if it returns n < len(p). Write must not modify the slice data,
    even temporarily.

    Implementations must not retain p.

var Discard Writer = discard{}
func MultiWriter(writers ...Writer) Writer
```

Birinchi qator: `type Writer interface`. **Interface** (*interface*) ham tur, lekin unda maydon yoʻq — faqat **metodlar roʻyxati**:
har bir metodning nomi, parametrlari va natijalari, **tanasiz**. `Writer`da bitta metod bor — `Write`. U `p` degan bayt slice'ini
oladi (`[]byte`, GB-2.01). `byte` — 0 dan 255 gacha son; matn xotirada shunday baytlar ketma-ketligi. Natijalar `Fprintln`dagidek:
yozilgan baytlar soni `n` va xato `err`.

Hujjat matni bu metodning shartnomasini beradi: `Write` `p`ning hamma `len(p)` baytini yozishi kerak; hammasini yozolmasa, `n < len(p)`
va `nil` boʻlmagan xato qaytaradi; `p`ni oʻzgartirmaydi va eslab qolmaydi. Oʻz `Write`imizni yozganda shu shartni bajaramiz. Oxirgi
ikki qator (`Discard`, `MultiWriter`) `io` paketining boshqa nomlari: bugun kerak emas.

## Tur interface'ni eʼlonsiz bajaradi

Kimda shunday metod bor? `os` paketidagi `File` turi ochiq faylni ifodalaydi:

```console
$ go doc os.File.Write
package os // import "os"

func (f *File) Write(b []byte) (n int, err error)
    Write writes len(b) bytes from b to the File. It returns the number of
    bytes written and an error, if any. Write returns a non-nil error when n !=
    len(b).
```

Receiver — `(f *File)`: yulduzcha bor, demak pointer receiver (GB-2.05). Parametr nomi boshqa — `b`, `p` emas — lekin nom ahamiyatsiz:
turlar bir xil.

| `io.Writer` talab qiladi | `*os.File` da bor | Mos? |
|---|---|---|
| `Write(p []byte) (n int, err error)` | `Write(b []byte) (n int, err error)` | ha: nomlar boshqa, turlar bir xil |

**Qoida:** turning metodlari interface roʻyxatidagi hamma metodni oʻz ichiga olsa, bu tur interface'ni **bajaradi**
(*implements*). Buni hech qayerda eʼlon qilmaysiz: `implements` soʻzi yoʻq, kompilyator metodlarni oʻzi solishtiradi
([Go spec: Implementing an interface](https://go.dev/ref/spec#Implementing_an_interface)).

`os.Stdout` va `os.Stderr` — `*os.File` turidagi oʻzgaruvchilar. Shuning uchun GB-1.07'dagi `fmt.Fprintln(os.Stderr, …)` ishlagan edi:
birinchi parametr `io.Writer`, `*os.File`da esa shunday `Write` bor.

## writeReport: ekranga yozamiz

Hisobot funksiyasi — `writeReport`. Dasturning toʻliq matni (`_video/01-stdout/main.go`):

```go filename="_video/01-stdout/main.go" showLineNumbers
package main

import (
	"fmt"
	"io"
	"os"
)

const tiyinPerSom = 100 // 1 soʻm = 100 tiyin

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

// writeReport katalog hisobotini w'ga yozadi.
func writeReport(w io.Writer, products []Product) error {
	for _, p := range products {
		_, err := fmt.Fprintf(w, "%-6s %6d soʻm %4d dona\n", p.Name, p.Price/tiyinPerSom, p.Stock)
		if err != nil {
			return err
		}
	}
	return nil
}

func main() {
	products := []Product{
		{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40},
		{ID: 2, Name: "non", Price: 400_000, Stock: 100},
		{ID: 3, Name: "oʻrik", Price: 3_500_000, Stock: 5},
	}

	err := writeReport(os.Stdout, products)
	if err != nil {
		fmt.Fprintln(os.Stderr, "xato:", err)
		os.Exit(1)
	}
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 3–7 | `import ( … )` | `fmt`, `io` (u yerda `io.Writer`) va `os` (u yerda `os.Stdout`) paketlari |
| 9–17 | `tiyinPerSom`, `Product` | GB-1.03 va GB-2.03'dagidek |
| 20 | `func writeReport(w io.Writer, products []Product) error` | parametrlar: `w` — turi `io.Writer`, ya'ni «qayerga yozish»; `products` — mahsulotlar slice'i. Natija — `error` |
| 21 | `for _, p := range products {` | oldingi `printReport`dagi sikl: `p` — navbatdagi mahsulot (`_` — indeks, kerak emas) |
| 22 | `_, err := fmt.Fprintf(w, …)` | `Printf` bilan bir xil shablon, faqat birinchi argument — qayerga yozish. `Fprintf` ham ikki natija qaytaradi: bayt soni kerak emas, uni `_` bilan tashlaymiz; `err`ni saqlaymiz |
| 23–25 | `if err != nil { return err }` | yozish xato bersa (masalan, disk toʻlsa), xatoni chaqiruvchiga qaytaramiz |
| 27 | `return nil` | hammasi yozilsa — xato yoʻq |
| 31–35 | `products := []Product{ … }` | `main`da uchta mahsulot: `olma`, `non` va `oʻrik` (narx tiyinda, `1_200_000` — GB-1.03) |
| 37 | `err := writeReport(os.Stdout, products)` | `w` oʻrniga `os.Stdout`: yozish joyini chaqiruvchi tanlaydi |
| 38–41 | `if err != nil { … }` | xato boʻlsa, GB-1.07'dagidek stderr'ga yozib, kod 1 bilan chiqamiz |

`writeReport` ichida qayerga yozilayotgani koʻrinmaydi:

```text
main ──► writeReport(w, products) ──► Fprintf(w, …) ──► w.Write(bayt-lar) ──► terminal
                  w = os.Stdout
```

## Oʻz Writer'imiz: byteCounter

Endi `io.Writer`ni oʻzimiz yozamiz: `byteCounter` yozilgan baytlarni sanaydi (`_video/03-counter/main.go`dan):

```go
// byteCounter oʻziga yozilgan baytlarni sanaydi.
type byteCounter struct {
	n int
}

// Write p'dagi baytlar sonini n'ga qoʻshadi.
func (c *byteCounter) Write(p []byte) (int, error) {
	c.n += len(p)
	return len(p), nil
}
```

| Kod | Nima qiladi |
|---|---|
| `type byteCounter struct { n int }` | bitta maydonli struct: `n` — shu paytgacha yozilgan baytlar soni |
| `func (c *byteCounter) Write(p []byte) (int, error)` | `Write` metodi. Receiver `c` — pointer receiver, chunki `n` oʻzgaradi (GB-2.05). Imzo `io.Writer`dagidek: parametr `p` — bayt slice'i, natijalar — `int` va `error` |
| `c.n += len(p)` | `len(p)` — kelgan baytlar soni (GB-2.01): `n`ga qoʻshamiz |
| `return len(p), nil` | hammasi yozildi deb qaytaramiz: `n == len(p)` va xato yoʻq — `io.Writer` shartnomasi |

Diqqat: bu kodda `io.Writer` degan soʻz yoʻq. `main`da, fayl yopilgandan keyin:

```go
	var c byteCounter
	err = writeReport(&c, products)
	if err != nil {
		fmt.Fprintln(os.Stderr, "xato:", err)
		os.Exit(1)
	}
	fmt.Println("hisobot:", c.n, "bayt")
```

`var c byteCounter` — boʻsh hisoblagich, `c.n` nol (zero value, GB-1.02). `writeReport`'ga `&c` beramiz (`&` — GB-2.04: `c`ning manzili),
chunki `Write` `*byteCounter`da. Keyin `n`ni chiqaramiz. Kompilyatsiya boʻladimi?

**A)** ha, baytlar soni chiqadi · **B)** yoʻq: `byteCounter` `io.Writer`ni bajarishini eʼlon qilmagan · **C)** ha, lekin `0`: `Write` nusxaga yozadi

## Interface qiymati ichida nima bor

`writeReport`dagi `w io.Writer` — **interface qiymati** (*interface value*). U ikki qismdan iborat: ichidagi **aniq tur** va oʻsha turning
**qiymati**. `Fprintf` `w.Write(…)`ni chaqiradi, Go esa `w` ichidagi turning `Write` metodini ishga tushiradi
([Go blog: The Laws of Reflection](https://go.dev/blog/laws-of-reflection) — interface oʻzgaruvchisi qiymat va uning turi juftligini saqlaydi).

| Chaqiruv | `w` ichidagi tur | `w` ichidagi qiymat | `w.Write(p)` nima qiladi |
|---|---|---|---|
| `writeReport(os.Stdout, …)` | `*os.File` | `os.Stdout` | baytlarni terminalga yozadi |
| `writeReport(f, …)` | `*os.File` | `f` (`hisobot.txt`) | baytlarni faylga yozadi |
| `writeReport(&c, …)` | `*byteCounter` | `&c` (`c`ning manzili) | `c.n += len(p)` |

`writeReport` qaysi tur kelganini bilishi shart emas: u faqat `Write` borligiga tayanadi.

## Pointer receiver va interface: &c nega kerak

Eng koʻp uchraydigan xato: `&` unutildi, `writeReport`'ga `c`ning oʻzi berildi (`_video/04-xato/main.go`, 65-qator):

```go
	var c byteCounter
	err = writeReport(c, products)
```

`c.Write(…)` deb metodni chaqirsak, Go `&`ni oʻzi qoʻyardi (GB-2.05). Bu yerda-chi?

```console
$ ./_video/run.sh 04-xato go run .
# github.com/abdurahmon27/bozor
./main.go:65:20: cannot use c (variable of struct type byteCounter) as io.Writer value in argument to writeReport: byteCounter does not implement io.Writer (method Write has pointer receiver)
```

Xatoni oʻqish:

| Qism | Maʼnosi |
|---|---|
| `./main.go:65:20` | fayl, qator, ustun: `c` yozilgan joy |
| `cannot use c (variable of struct type byteCounter)` | `c` — `byteCounter` struct turidagi oʻzgaruvchi — ishlatib boʻlmaydi |
| `as io.Writer value in argument to writeReport` | `writeReport`'ga `io.Writer` qiymati sifatida |
| `byteCounter does not implement io.Writer` | `byteCounter` `io.Writer`ni bajarmaydi |
| `(method Write has pointer receiver)` | sababi: `Write` pointer receiver'li, ya'ni `*byteCounter`ga tegishli; `byteCounter` qiymatining oʻzida `Write` yoʻq |

Metod chaqiruvida Go `&`ni oʻzi qoʻyadi, interface'ga berishda qoʻymaydi. Tuzatish: `writeReport(&c, products)`.

Savol. `logWriter` degan boshqa tur bor, uning `Write` metodi **value** receiver'li. Qaysi chaqiruv kompilyatsiya boʻladi: `l` bilanmi,
`&l` bilanmi?

**A)** faqat `l` · **B)** faqat `&l` · **C)** ikkalasi ham

<details>
<summary>Javob</summary>

**C: ikkalasi ham.** Value receiver'li metod qiymatda ham, pointer'da ham bor: Go pointer orqali nusxani oladi. Teskarisi yoʻq:
pointer receiver'li metod faqat pointer'da. **A** ni tanlagan boʻlsangiz, pointer'ga berish mumkin emas deb oʻylagansiz; **B** — oldingi
xatoni umumlashtirgansiz: u faqat pointer receiver'ga tegishli. Toʻliq dastur (kurs papkasida yoʻq):

```go
package main

import (
	"fmt"
	"io"
)

// logWriter — Write metodi value receiver'li tur.
type logWriter struct{}

func (l logWriter) Write(p []byte) (int, error) {
	fmt.Println("yozildi:", len(p), "bayt")
	return len(p), nil
}

func hello(w io.Writer) {
	fmt.Fprintln(w, "salom")
}

func main() {
	var l logWriter
	hello(l)
	hello(&l)
}
```

```console
$ go run .
yozildi: 6 bayt
yozildi: 6 bayt
```

Ikkala chaqiruv ishladi (`salom\n` — 6 bayt). Qoida jadvalda ([Go spec: Method sets](https://go.dev/ref/spec#Method_sets)):

| Metodning receiver'i | `T` qiymatida bor | `*T` da bor |
|---|---|---|
| `(l T)` — value | ha | ha |
| `(l *T)` — pointer | yoʻq | ha |

Shuning uchun `byteCounter`ga `&` kerak edi.

</details>

## fmt.Stringer: kichik interface

`writeReport`dan tashqari yana bir kichik interface bor. `main` oxiriga mahsulotlarni toʻgʻridan-toʻgʻri chiqarishni qoʻshamiz:
`fmt.Println(products)`. `fmt` har bir struct'ni maydonlar ketma-ketligi sifatida jingalak qavsda yozadi; narx tiyinda, oʻqish noqulay:

```console
$ ./_video/run.sh 05-oldin go run .

[{1 olma 1200000 40} {2 non 400000 100} {3 oʻrik 3500000 5}]
```

`fmt` paketida bitta metodli interface bor:

```console
$ go doc fmt.Stringer
package fmt // import "fmt"

type Stringer interface {
	String() string
}
    Stringer is implemented by any value that has a String method, which defines
    the “native” format for that value. The String method is used to print
    values passed as an operand to any format that accepts a string or to an
    unformatted printer such as Print.
```

Metodi — `String`, parametrsiz, `string` qaytaradi. GB-2.05'da `OrderStatus`ga aynan shunday metod yozgan edik va `fmt` holatni nomi
bilan chiqargan edi: `OrderStatus` `Stringer`'ni eʼlonsiz bajargan edi. Endi `Product`ga `String` yozamiz (`main.go`dan):

```go
// String mahsulotni «olma (12000 soʻm)» koʻrinishida qaytaradi.
func (p Product) String() string {
	return fmt.Sprintf("%s (%d soʻm)", p.Name, p.Price/tiyinPerSom)
```

Receiver — value receiver `(p Product)`: metod faqat oʻqiydi va `Product` kichik. `Sprintf` — GB-1.04'dagi: `Printf` kabi shablon, lekin
ekranga chiqarmaydi, matnni qaytaradi; bu yerda nom va qavs ichida soʻmdagi narx. `main` oʻzgarmaydi: oʻsha `fmt.Println(products)`.
Endi nima chiqadi?

**A)** oʻzgarmaydi: `String` slice ichidagi elementlarga ishlamaydi · **B)** har bir mahsulotning nomi va narxi · **C)** kompilyatsiya xatosi

<summary>Javob</summary>

**B.** `fmt` slice'ni aylanib chiqdi, har bir elementda `String`ni topdi va chaqirdi. **A** ni tanlagan boʻlsangiz, `fmt` faqat

## fmt String'ni qanday topadi

`Println`ning parametrlari `any` turida. `any` — **metodlari yoʻq interface**: roʻyxat boʻsh, shuning uchun unga istalgan qiymat mos
keladi. Ichkarida `fmt` har bir qiymatga, bu yerda `arg`ga, savol beradi: «sen `fmt.Stringer`'misan?». Bu savol — **type assertion**.
Soddalashtirilgan koʻrinishi (haqiqiy kod emas):

```go
// arg — Println'ga berilgan qiymat, turi any
s, ok := arg.(fmt.Stringer)
if ok {
	// … s.String() natijasini yozadi
}
```

| Kod | Nima qiladi |
|---|---|
| `arg.(fmt.Stringer)` | type assertion `x.(T)`: `arg` ichidagi tur `fmt.Stringer`ni bajaradimi? |
| `s, ok := …` | GB-2.02'dagi comma-ok shakli: `ok` — `true` yoki `false`; `true` boʻlsa, `s` — `fmt.Stringer` sifatida qiymat |
| `if ok { … }` | `ok` `true` boʻlsa, `s.String()` chaqiriladi va natijasi yoziladi |

Haqiqiy `fmt` bir nechta interface'ni (`error`, `Stringer`, …) bitta `switch`da tekshiradi: Go 1.27.4 manbasida `src/fmt/print.go` faylidagi
`handleMethods` funksiyasida `case error`dan keyin `case Stringer` turadi. Mexanizm ekrandagi kodnikidek: ichidagi tur metodni
bajaradimi, shu soʻraladi. Uni oʻzimiz ishga tushiramiz (kurs papkasida yoʻq dastur):

```go
package main

import "fmt"

const tiyinPerSom = 100 // 1 soʻm = 100 tiyin

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

// String mahsulotni «olma (12000 soʻm)» koʻrinishida qaytaradi.
func (p Product) String() string {
	return fmt.Sprintf("%s (%d soʻm)", p.Name, p.Price/tiyinPerSom)
}

// describe arg fmt.Stringer'ni bajaradimi, shuni soʻraydi.
func describe(arg any) {
	s, ok := arg.(fmt.Stringer)
	if ok {
		fmt.Println("Stringer:", s.String())
	} else {
		fmt.Println("Stringer emas")
	}
}

func main() {
	olma := Product{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40}
	describe(olma)
	describe(42)
	describe("non")
}
```

```console
$ go run .
Stringer: olma (12000 soʻm)
Stringer emas
Stringer emas
```

`describe(olma)` — `Product`da `String` bor, `ok` `true`. `42` (`int`) va `"non"` (`string`)da `String` yoʻq, `ok` `false`. Shu soʻrov `fmt`ning
ichida ham ishlaydi.

## Kichik interface va faylsiz test

`io.Writer`da ham, `fmt.Stringer`da ham bitta metod. Interface qancha kichik boʻlsa, uni shuncha tur bajaradi:

| Interface | Uni bajaradigan turlar |
|---|---|
| `io.Writer` | `*os.File` (ochiq fayl va `os.Stdout`), `*byteCounter`, `*strings.Builder` (xotiradagi matn buferi) |
| `fmt.Stringer` | `Product`, `OrderStatus` |

HTTP javobini yozadigan tur ham `io.Writer`'ni bajaradi: buni [GB-4.03 · Handler — oddiy funksiya: httptest bilan tekshiramiz](/lab/youtube/gb#gb-4-03)da
koʻramiz. Shuning uchun qoida: **funksiya parametrida faqat oʻziga kerak metodlarni soʻrang**. `writeReport`'ga fayl emas, `Write` kerak
(Go maqoli: «interface qancha katta boʻlsa, abstraksiya shuncha zaif», [Go Proverbs](https://go-proverbs.github.io/)).

Ishda bu qoidaning foydasi testda koʻrinadi. Papkadagi `tekshiruv_test.go` ichidagi `TestHisobot` `writeReport`'ni faylsiz tekshiradi
(funksiya fayldan aynan shunday, `testProducts` — shu faylning oʻzida uch mahsulot qaytaradigan yordamchi):

```go
func TestHisobot(t *testing.T) {
	products := testProducts()
	want := "olma    12000 soʻm   40 dona\n" +
		"non      4000 soʻm  100 dona\n" +
		"oʻrik   35000 soʻm    5 dona\n"

	var sb strings.Builder
	err := writeReport(&sb, products)
	if err != nil {
		t.Fatalf("writeReport xato qaytardi: %v", err)
	}
	got := sb.String()
	if got != want {
		t.Errorf("hisobot:\n%s\nkutilgan:\n%s", got, want)
	}
	if got := fmt.Sprint(testProducts()[0]); got != "olma (12000 soʻm)" {
		t.Errorf("fmt.Sprint(olma) = %q; kutilgan %q", got, "olma (12000 soʻm)")
	}
}
```

| Kod | Nima qiladi |
|---|---|
| `want := "…" + "…" + "…"` | kutilgan matn: uch qator `+` bilan ulangan |
| `var sb strings.Builder` | `sb` — boʻsh matn buferi; uning `*strings.Builder` turida `Write` bor |
| `writeReport(&sb, products)` | hisobot shu buferga yoziladi (`&sb`: `Write` pointer receiver'li) |
| `got := sb.String()` | `String` yigʻilgan matnni qaytaradi |
| `if got != want { … }` | matn kutilgan matn bilan solishtiriladi; farq boʻlsa, `t.Errorf` (GB-1.08) |
| `fmt.Sprint(testProducts()[0])` | `Sprint` — `Println` kabi qiymatni matnga aylantiradi, lekin matnni qaytaradi; `Product.String` ishlayotganini tekshiradi |

Fayl yoʻq, disk yoʻq. `-run` testni nomi bilan tanlaydi, `-v` har bir testni koʻrsatadi:

## Koʻp uchraydigan xatolar

**1. Pointer receiver'li tur, `&`siz.** Eng koʻp uchraydigani yuqorida koʻrsatildi: `writeReport(c, products)`
(yuqoridagi «Pointer receiver va interface: &c nega kerak» boʻlimi). Xuddi shu xato standart kutubxona turlarida ham chiqadi.
`strings.Builder`ning `Write` metodi ham pointer receiver'li (toʻliq dastur, kurs papkasida yoʻq):

```go
package main

import (
	"fmt"
	"io"
	"strings"
)

func hello(w io.Writer) {
	fmt.Fprintln(w, "salom")
}

func main() {
	var sb strings.Builder
	hello(sb)
	fmt.Print(sb.String())
}
```

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:15:8: cannot use sb (variable of struct type strings.Builder) as io.Writer value in argument to hello: strings.Builder does not implement io.Writer (method Write has pointer receiver)
```

Oʻqilishi oldingidek: `cannot use sb … as io.Writer`, sababi qavs ichida — `method Write has pointer receiver`. Tuzatish: `hello(&sb)`.

**2. `String` pointer receiver'li — `fmt` uni chaqirmaydi (jim xato).** `String`ni `func (p *Product) String() string` deb yozsak, kod kompilyatsiya
boʻladi, xato yoʻq, lekin `fmt` mahsulotni maydonlar bilan chiqaradi. Toʻliq dastur (kurs papkasida yoʻq; `String` tanasi darsdagidek):

```go
package main

import "fmt"

const tiyinPerSom = 100 // 1 soʻm = 100 tiyin

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

// String bu yerda pointer receiver'li: bu xato.
func (p *Product) String() string {
	return fmt.Sprintf("%s (%d soʻm)", p.Name, p.Price/tiyinPerSom)
}

func main() {
	products := []Product{
		{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40},
		{ID: 2, Name: "non", Price: 400_000, Stock: 100},
	}
	fmt.Println(products)
	fmt.Println(products[0])
	fmt.Println(&products[0])
}
```

```console
$ go run .
[{1 olma 1200000 40} {2 non 400000 100}]
{1 olma 1200000 40}
olma (12000 soʻm)
```

Sababi — method set: slice'dagi elementlar `Product` qiymatlari, `Product` turida esa `String` yoʻq (u faqat `*Product`da). `fmt` interface
ichidagi turga qaraydi: `Product` — `Stringer` emas, `*Product` — `Stringer`. Kompilyator ham, `go vet` ham jim. Tuzatish: kichik, oʻzgarmaydigan
tur uchun `String`ni value receiver bilan yozing (`func (p Product) String() string`): u `Product`da ham, `*Product`da ham bor.

**3. Parametr turi keraksiz aniq.** `writeReport(f *os.File, …)` deb yozsangiz, funksiya faqat faylga yoza oladi. Toʻliq dastur (kurs papkasida yoʻq):

```go

	"fmt"
	"os"
	"strings"

	fmt.Fprintln(f, "salom")
```


`hello(os.Stdout)` ishlaydi, `hello(&sb)` — yoʻq: `*strings.Builder` `*os.File` emas. Funksiyaga faqat `Write` kerak edi: parametrni `io.Writer` qiling,
test ham, `byteCounter` ham, fayl ham kiradi.

**1-qadam.** `fmt.Printf(…)` doim ekranga yozadi; `w`'ga yozish uchun `fmt.Fprintf(w, …)`. `Fprintf` ikki natija qaytaradi: baytlar soni kerak emas
(`_`), xatoni tekshirib qaytaramiz. Shablondagi `%v` `Product`ni `String` metodi orqali yozadi (shu darsning `Stringer`i):

```go
func writeLowStock(w io.Writer, products []Product, limit int) error {
	for _, p := range products {
		if p.Stock < limit {
			_, err := fmt.Fprintf(w, "%v — %d dona qoldi\n", p, p.Stock)
			if err != nil {
				return err
			}
		}
	}
	return nil
}
```

**2-qadam.** `bytes.Count(p, []byte("\n"))` — `p`da `'\n'` bayti necha marta borligini qaytaradi (`[]byte("\n")` matnni bayt slice'iga oʻgiradi;
`import`ga `"bytes"` qoʻshing). `Write` `lines`'ni oʻzgartiradi, shuning uchun receiver pointer (GB-2.05); `n == len(p)` va `nil` — `io.Writer` shartnomasi:

```go
// lineCounter oʻziga yozilgan qatorlarni sanaydi.
type lineCounter struct {
	lines int
}

// Write p'dagi qator oxirlarini ('\n') sanab, lines'ga qoʻshadi.
func (c *lineCounter) Write(p []byte) (int, error) {
	c.lines += bytes.Count(p, []byte("\n"))
	return len(p), nil
}
```
