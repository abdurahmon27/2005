## Nimani oʻrganasiz

`Store` (GB-2.06) katalogni faqat xotirada ushlaydi: dastur tugashi bilan mahsulotlar yoʻqoladi. `bozor.json` bilan ishlash (GB-3.02) esa alohida dasturda qolgan. Bu boʻlaklarni bitta buyruq qatori dasturiga, **CLI**'ga (command-line interface) qanday yigʻamiz? Uni qanday ishonchli qilamiz: elektr oʻchsa ham fayl yarim boʻlib qolmasin, jim buzilgan qoldiqni esa test ushlasin?

**Bitta gʻoya:** bozor CLI bitta jarayonda bitta buyruqni bajaradi. `main` faqat `os.Args`'ni `run(path, args, w)`'ga beradi va xatoni chiqish kodiga aylantiradi: 1 — xato, 2 — notoʻgʻri chaqiruv. `run` katalogni `bozor.json`'dan yuklaydi, `switch` bilan buyruqni tanlaydi, `internal/store`'dagi qoidalarni chaqiradi va oʻzgargan katalogni **atomar** saqlaydi: yangi JSON avval vaqtinchalik faylga yoziladi, keyin `os.Rename` uni bir qadamda `bozor.json` oʻrniga qoʻyadi. Yoʻl va `io.Writer` parametr boʻlgani uchun test butun CLI'ni oʻz papkasida chaqirib, chiqishni emas, katalog holatini tekshiradi.

Dars oxirida siz:

- `cmd/bozor` + `internal/store` tuzilishidagi CLI'ni oʻqiysiz va `run(path, args, w)` nega butun CLI'ni testga ochishini tushuntirasiz;
- chiqish kodi 1 (xato) va 2 (notoʻgʻri chaqiruv) farqini qoʻyasiz;
- `os.WriteFile` nega yarim fayl qoldirishi mumkinligini koʻrasiz va `os.CreateTemp` + `Sync` + `os.Rename` bilan atomar saqlashni oʻqiysiz;
- `go vet` va `staticcheck` jim qolgan haqiqiy bug'ni jadvalli test ushlashini koʻrasiz, `bozor restock ID DONA` buyrugʻini esa testi bilan oʻzingiz yozasiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| CLI tuzilishi | `main` faqat argumentlarni beradi va xatoni chiqish kodiga aylantiradi; butun ish `run(path, args, w) error` funksiyasida | CLI structure (thin `main` + `run`) |
| atomar saqlash | yangi fayl avval alohida yoziladi, keyin nom bir qadamda almashadi: oʻquvchi yo eski, yo yangi faylni koʻradi | atomic save |
| holatni tekshiradigan test | test funksiyaning qaytargan qiymatini emas, katalogning (yoki faylning) holatini tekshiradi | state-checking test |

Yordamchi soʻzlar bor joyida bir jumlada tushuntiriladi: `t.TempDir()`, `fmt` kengligining rune bilan sanalishi, vaqtinchalik fayl.

## Ishga tushiramiz: add, list, order

`go build ./cmd/bozor` `cmd/bozor` paketini yigʻadi. Natija — bitta binary (GB-1.01), nomi papkadan olinadi: `bozor`. Birinchi buyruq `list`. `bozor.json` hali yoʻq, `Load` buni xato emas, boʻsh katalog deb oladi.

```console
$ go build ./cmd/bozor
$ ./bozor list
katalog boʻsh: bozor add NOM NARX QOLDIQ
```

`go build` hech narsa chiqarmadi: muvaffaqiyat. `add` nom, soʻmdagi narx va qoldiqni oladi. Dastur yangi ID beradi (eng katta ID + 1) va katalogni `bozor.json`'ga yozadi:

```console
$ ./bozor add olma 12000 40
qoʻshildi: 1. olma, 12000 soʻm, 40 dona
$ ./bozor add non 4000 3
qoʻshildi: 2. non, 4000 soʻm, 3 dona
$ ./bozor add choy 25000 8
qoʻshildi: 3. choy, 25000 soʻm, 8 dona
$ ./bozor add oʻrik 35000 2
qoʻshildi: 4. oʻrik, 35000 soʻm, 2 dona
```

`oʻrik`ning ID'si toʻrt: bu toʻrtinchi `add`. Endi `list`'ning kodi. U katalogni GB-3.05'dagi `All` iteratori bilan aylanadi va har mahsulotni `w`'ga yozadi:

```go showLineNumbers
func list(st *store.Store, w io.Writer) error {
	n := 0
	for p := range st.All() {
		n++
		_, err := fmt.Fprintf(w, "%2d. %-20s %8d soʻm %4d dona\n",
			p.ID, p.Name, p.Price/tiyinPerSom, p.Stock)
		if err != nil {
			return err
		}
	}
	if n == 0 {
		_, err := fmt.Fprintln(w, "katalog boʻsh: bozor add NOM NARX QOLDIQ")
		return err
	}
	return nil
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1 | `func list(st *store.Store, w io.Writer) error` | katalog va chiqish joyi (`w`, GB-2.07) parametr; faqat `error` qaytaradi |
| 2, 4 | `n := 0`, `n++` | chiqarilgan qatorlar soni; `++` — GB-1.06 |
| 3 | `for p := range st.All()` | katalogni birma-bir aylanadi (GB-3.05) |
| 5–6 | `fmt.Fprintf(w, "…", p.ID, p.Name, …)` | bir qatorni `w`'ga yozadi; `_` — qaytgan baytlar soni kerak emas |
| 6 | `p.Price/tiyinPerSom` | narx tiyinda saqlanadi, chiqarishda soʻmga aylanadi (GB-1.03) |
| 7–9 | `if err != nil { return err }` | yozib boʻlmasa, xatoni qaytaradi |
| 11–14 | `if n == 0 { … }` | birorta qator chiqmagan boʻlsa: «katalog boʻsh» |

Shablon `"%2d. %-20s %8d soʻm %4d dona\n"` toʻrtta qiymat uchun toʻrtta kenglik beradi (GB-1.04):

| Shablon | Qiymat | Kenglik |
|---|---|---|
| `%2d` | `p.ID` | 2 belgi, oʻngdan |
| `%-20s` | `p.Name` | 20 belgilik ustun, chapdan (minus — chapga tekislash) |
| `%8d` | narx soʻmda | 8 belgi, oʻngdan |
| `%4d` | `p.Stock` | 4 belgi, oʻngdan |

`oʻrik` 5 belgi, lekin 6 bayt (GB-2.10). `list` `oʻrik` qatorida narx ustuni `olma` qatoriga nisbatan qayerda turadi?

**A)** bir xil chiziqda · **B)** bir belgi chapda · **C)** bir belgi oʻngda

<details>
<summary>Javob</summary>

**A.** `fmt` kenglikni baytlar bilan emas, rune'lar bilan sanaydi: pkg.go.dev/fmt'da «Width and precision are measured in units of Unicode code points, that is, runes» deyilgan. `oʻrik` 5 rune, shuning uchun 15 ta boʻsh joy qoʻshiladi va ustun siljimaydi. **B** ni tanlagan boʻlsangiz, bayt sanaladi deb oʻylagansiz: unda `oʻrik` 6 ta joy olib, qatorning qolgan qismi bir belgi oʻngga surilardi. **C** da qator, aksincha, chapga surilardi. Nom 20 belgidan oshmasligini esa store tekshiradi (`validate`, quyida).

</details>

## Xato va chiqish kodi: 1 yoki 2

Endi xatolar. `oʻrik`dan besh dona soʻraymiz, omborda ikkita bor. Xabar stderr'ga chiqadi (GB-1.07). `echo $?` oxirgi buyruqning chiqish kodini koʻrsatadi:

```console
$ ./bozor order 4 5
xato: oʻrik: faqat 2 dona qoldi
$ echo $?
1
```

Chiqish kodi 1: xato. Endi nomaʼlum buyruq, masalan `sell`. Bu dastur ichidagi xato emas, chaqiruv notoʻgʻri. `./bozor sell 1 1` dan keyin `echo $?` nima koʻrsatadi?

**A)** 0 · **B)** 1 · **C)** 2

<details>
<summary>Javob</summary>

**C.** GB-1.07'da har qanday xato 1 edi. Endi CLI notoʻgʻri chaqiruvni (nomaʼlum buyruq, argumentlar soni notoʻgʻri) alohida kod bilan ajratadi: 2. **A** ni tanlagan boʻlsangiz, xabar chiqdi, demak muvaffaqiyat deb oʻylagansiz: 0 faqat xatosiz tugagan dasturga beriladi. **B** ni tanlagan boʻlsangiz, GB-1.07'dagi qoidani eslagansiz: u endi faqat dastur ichidagi xatolarga tegishli.

</details>

```console
$ ./bozor sell 1 1
foydalanish: bozor add NOM NARX QOLDIQ | list | order ID DONA
$ echo $?
```

Bu ixtiyoriy emas, qoida: Go'ning `go` buyrugʻi ham notoʻgʻri chaqiruvda 2 qaytaradi. Bu savol uchun biz uni oʻzimiz ishga tushirdik (kurs papkasida yoʻq):

Ajratishning foydasi: skript yoki boshqa dastur chiqish kodiga qarab «chaqiruvni toʻgʻrilash kerak» (2) va «amal bajarilmadi» (1) holatlarini farqlay oladi.

## Kod: main, run, order va Sell

Endi shu xatti-harakatni beradigan kod. Avval `main`:

```go showLineNumbers
func main() {
	err := run(dataFile, os.Args[1:], os.Stdout)
	if err == nil {
		return
	}
	fmt.Fprintln(os.Stderr, message(err))
	if errors.Is(err, errUsage) {
		os.Exit(2)
	}
	os.Exit(1)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 2 | `err := run(dataFile, os.Args[1:], os.Stdout)` | `dataFile` — `"bozor.json"` konstantasi; `os.Args[1:]` — dastur nomisiz argumentlar (GB-2.02); `os.Stdout` — `io.Writer` (GB-2.07) |
| 3–5 | `if err == nil { return }` | xato yoʻq: `main` oddiy tugaydi, chiqish kodi 0 |
| 6 | `fmt.Fprintln(os.Stderr, message(err))` | xatoni `message` matnga aylantiradi va stderr'ga yozadi (GB-2.08) |
| 7–9 | `if errors.Is(err, errUsage) { os.Exit(2) }` | `errUsage` — `errors.New("foydalanish: …")`: foydalanish xatosi boʻlsa, chiqish kodi 2 |
| 10 | `os.Exit(1)` | boshqa har qanday xato — 1 |

`run` — butun CLI:

```go showLineNumbers
func run(path string, args []string, w io.Writer) error {
	if len(args) == 0 {
		return errUsage
	}
	st, err := store.Load(path)
	if err != nil {
		return err
	}
	var msg string // oʻzgartiruvchi buyruqning natija qatori
	switch args[0] {
	case "list":
		return list(st, w)
	case "add":
		msg, err = add(st, args[1:])
	case "order":
		msg, err = order(st, args[1:])
	default:
		return errUsage
	}
	if err != nil {
		return err
	}
	if err := st.Save(path); err != nil {
		return err
	}
	_, err = fmt.Fprintln(w, msg)
	return err
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1 | `func run(path string, args []string, w io.Writer) error` | fayl yoʻli, argumentlar va natija yoziladigan `w` parametr; `main`'da `w` — `os.Stdout`, testda — `strings.Builder` |
| 2–4 | `if len(args) == 0 { return errUsage }` | buyruq berilmagan: foydalanish xatosi (shuning uchun keyin `args[0]` xavfsiz) |
| 5–8 | `st, err := store.Load(path)` | katalogni yuklaydi, buzuq boʻlsa xato bilan chiqadi |
| 9 | `var msg string` | oʻzgartiruvchi buyruqning natija qatori |
| 10–12 | `switch args[0] { case "list": return list(st, w) }` | `list` faqat oʻqiydi: saqlamasdan darhol qaytadi (GB-1.05) |

### Load oʻqilgan mahsulotni ham tekshiradi

```go showLineNumbers
func Load(path string) (*Store, error) {
	data, err := os.ReadFile(path)
	if errors.Is(err, os.ErrNotExist) {
		return &Store{}, nil
	}
	if err != nil {
		return nil, err
	}
	var products []Product
	if err := json.Unmarshal(data, &products); err != nil {
		return nil, fmt.Errorf("%s: %w", path, err)
	}
	seen := make(map[int64]bool)
	for i, p := range products {
		if err := validate(p); err != nil {
			return nil, fmt.Errorf("%s: %d-mahsulot: %w", path, i+1, err)
		}
		if seen[p.ID] {
			return nil, fmt.Errorf("%s: %d-mahsulot: %w: ID %d takrorlangan", path, i+1, ErrBadProduct, p.ID)
		}
		seen[p.ID] = true
	}
	return &Store{products: products}, nil
}
```

```go showLineNumbers
	case p.ID <= 0:

	case p.Name == "":
		return fmt.Errorf("%w: nom boʻsh", ErrBadProduct)
```

## Atomar saqlash: vaqtinchalik fayl va os.Rename

Yechim: avval **boshqa** faylga yozamiz, tayyor boʻlgach nomini almashtiramiz. Mana `Save`ning toʻliq kodi:

```go showLineNumbers
func (s *Store) Save(path string) (err error) {
	products := s.products
	if products == nil {
		products = []Product{} // nil slice JSON'da null boʻladi, boʻsh slice esa []
	}
	data, err := json.MarshalIndent(products, "", "  ")
	if err != nil {
		return err
	}
	data = append(data, '\n')

	f, err := os.CreateTemp(filepath.Dir(path), ".bozor-*.json")
	if err != nil {
		return err
	}
	defer func() {
		if err != nil {
			f.Close()
			os.Remove(f.Name()) // xato boʻlsa vaqtinchalik fayl qolmasin
		}
	}()
	if err = f.Chmod(0o644); err != nil { // CreateTemp 0600 bilan ochadi; bozor.json GB-3.02'dagidek 0644
		return err
	}
	if _, err = f.Write(data); err != nil {
		return err
	}
	if err = f.Sync(); err != nil {
		return err
	}
	if err = f.Close(); err != nil {
		return err
	}
	return os.Rename(f.Name(), path)
}
```

|---|---|---|
| 1 | `func (s *Store) Save(path string) (err error)` | `(err error)` — nomli natija (GB-2.09): `defer` uni koʻradi |
| 2–5 | `if products == nil { products = []Product{} }` | boʻsh katalog `null` emas, `[]` boʻlib yozilsin (pastda) |

| 12–15 | `os.CreateTemp(filepath.Dir(path), ".bozor-*.json")` | `path`dagi papkada yangi fayl ochadi; nomdagi `*` oʻrniga tasodifiy son qoʻyadi (`.bozor-2476821519.json`). `filepath.Dir("bozor.json")` — `"."`, joriy papka |
| 16–21 | `defer func() { if err != nil { … } }()` | xato boʻlsa, faylni yopadi va `os.Remove` bilan oʻchiradi: vaqtinchalik fayl qolmasin. `f.Name()` — shu faylning yoʻli |

Yozish davomida `bozor.json`'ga hech kim tegmaydi:

| Qadam | `bozor.json` | `.bozor-*.json` |
|---|---|---|
| boshida | eski katalog | yoʻq |
| `CreateTemp`, `Write`, `Sync`, `Close` | eski katalog, tegilmagan | yangi katalog yoziladi va diskka tushadi |
| `os.Rename` | yangi katalog (nom bir qadamda oʻtdi) | yoʻq (u endi `bozor.json`) |

`os.Rename` — Linux yadrosining bitta amali (`rename(2)` tizim chaqiruvi): nom yangi faylga **atomar**, yaʼni bir qadamda oʻtadi. Atomar degani: oʻquvchi yo eski, yo yangi katalogni koʻradi, yarimini hech qachon. Man sahifasi: «newpath will be atomically replaced». Tartib muhim: `Sync` rename'dan oldin keladi. `Sync`siz rename'dan keyin elektr oʻchsa, yangi nom hali diskka yozilmagan faylni koʻrsatishi mumkin (`fsync(2)` va `os.File.Sync` hujjati).

Oraliq savol. `Save` `Sync`'dan keyin, `Rename`'dan oldin elektr oʻchdi. Kompyuter qayta yoqilgach, `bozor.json`'da nima bor?

**A)** yarim yozilgan katalog · **B)** eski katalog, butun · **C)** yangi katalog

<details>
<summary>Javob</summary>

**B.** `Rename` boʻlmagan, shuning uchun `bozor.json`'ga tegilmagan: eski katalog butun. Faqat nuqtali vaqtinchalik fayl (`.bozor-*.json`) qolishi mumkin: uni qoʻlda oʻchirsangiz boʻladi. **A** ni tanlagan boʻlsangiz, yozish `bozor.json`'ning oʻzida boʻlyapti deb oʻylagansiz: yoʻq, u boshqa faylda. **C** ni tanlagan boʻlsangiz, `Sync` yangi katalogni qoʻyadi deb oʻylagansiz: `Sync` faqat vaqtinchalik faylni diskka tushiradi, nomni almashtiradigan — `Rename`. Ishda ham holat va konfiguratsiya fayllari shunday yoziladi: `github.com/google/renameio` aynan shu usulni paketga oʻragan.

</details>

### Kafolat qayerda tugaydi

- **Bitta fayl tizimi.** Rename faqat bitta fayl tizimi ichida bir qadamda ishlaydi; boshqasiga `EXDEV` («invalid cross-device link») xatosini qaytaradi. Shuning uchun vaqtinchalik fayl `bozor.json`ning **yonida** ochiladi (`filepath.Dir(path)`). Xatoni «Koʻp uchraydigan xatolar»da koʻrasiz.
- **Linux va macOS.** `go doc os.Rename`: «Even within the same directory, on non-Unix platforms Rename is not an atomic operation». Kafolat Unix tizimlari uchun.
- **Papka yozuvi.** Toʻliq «elektr oʻchsa ham» kafolati uchun rename'dan keyin papkaning oʻzini ham `Sync` qilish kerak. CLI v0 buni qilmaydi: eng yomon holda eski katalog qoladi, yarim fayl emas (kurs README'si).
- **Bitta jarayon.** Ikki `bozor` bir vaqtda ishlasa, oxirgi `rename` yutadi: fayl qulfi yoʻq. README'ga koʻra bu 4-moduldagi mutex va 5-moduldagi Postgres tranzaksiyasigacha ataylab qoldirilgan.

Fayl yoʻq boʻlsa, `s.products` — nil slice (GB-2.01): orqasida massiv yoʻq. JSON'da qiymat yoʻqligini `null` bildiradi, boʻsh roʻyxatni esa `[]`. `json.MarshalIndent` nil slice'ni qanday yozadi?

```go showLineNumbers
	c, _ := jsonv2.Marshal(nilSlice)
	fmt.Println("v1, nil slice: ", string(a), nilSlice == nil)

	fmt.Println("v2, nil slice: ", string(c))
```

```go showLineNumbers
// maxRestock — bitta Restock'da qoʻshiladigan eng koʻp dona (xato yozilgan sondan himoya).
const maxRestock = 10_000

// Restock id'li mahsulotning qoldigʻiga quantity dona qoʻshadi va yangilangan mahsulotni qaytaradi.
// Xato boʻlsa katalog oʻzgarmaydi: ErrBadQuantity (quantity 1..maxRestock emas), ErrNotFound.
func (s *Store) Restock(id int64, quantity int) (Product, error) {
	if quantity <= 0 {
		return Product{}, fmt.Errorf("%w, hozir %d", ErrBadQuantity, quantity)
	}
	if quantity > maxRestock {
		return Product{}, fmt.Errorf("%w: bir martada koʻpi bilan %d, hozir %d", ErrBadQuantity, maxRestock, quantity)
	}
	p := s.find(id)
	if p == nil {
		return Product{}, fmt.Errorf("mahsulot %d: %w", id, ErrNotFound)
	}
	p.Stock += quantity
	return *p, nil
}
```

```go filename="solution/internal/store/restock_test.go" showLineNumbers
			_, err := st.Restock(tc.id, tc.quantity)
			if !errors.Is(err, tc.wantErr) {
				t.Fatalf("Restock(%d, %d) xatosi %v, kutilgan %v", tc.id, tc.quantity, err, tc.wantErr)
			}
			if p := st.find(tc.id); p != nil && p.Stock != tc.wantStock {
				t.Fatalf("qoldiq %d, kutilgan %d", p.Stock, tc.wantStock)
			}
		})
	}
}
```

`restock` buyrugʻi `order`ning nusxasi, faqat `st.Restock` va natija qatori boshqa:

```go showLineNumbers
// restock: bozor restock ID DONA.
func restock(st *store.Store, args []string) (string, error) {
	if len(args) != 2 {
		return "", errUsage
	}
	id, err := strconv.ParseInt(args[0], 10, 64)
	if err != nil {
		return "", fmt.Errorf("ID: %w", err)
	}
	quantity, err := strconv.Atoi(args[1])
	if err != nil {
		return "", fmt.Errorf("dona: %w", err)
	}
	p, err := st.Restock(id, quantity)
	if err != nil {
		return "", err
	}
	return fmt.Sprintf("toʻldirildi: %s, qoldiq %d", p.Name, p.Stock), nil
}
```
