- slice'ning xotiradagi tuzilishini chizasiz: sarlavha va uning massivi;
- `before := stock` va funksiya parametri nimani nusxalashini va nimani nusxalamasligini aytasiz;
- `append` qachon oʻsha massivga yozishini, qachon yangi massiv ochishini va nega natijani albatta yozish kerakligini
  bilasiz;
- chaqiruvchining maʼlumotini buzadigan funksiyani `make` bilan tuzatasiz va xuddi shu xatoni oʻzingiz topasiz
  (`discounted`, vazifa).

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| slice | bir xil turdagi elementlar roʻyxati. Xotirada u ikki qismdan iborat: sarlavha (`ptr`, `len`, `cap`) va elementlar turgan massiv | slice, slice header, array |
| `append` | slice'ga element qoʻshadi va **yangi sarlavha qaytaradi**. Massivda joy boʻlsa oʻsha massivga yozadi, boʻlmasa yangi massiv ochadi | `append` |
| umumiy massiv (aliasing) | ikki slice (yoki parametr va argument) bitta massivga qaraydi: biri yozsa, ikkinchisi oʻzgarishni koʻradi | aliasing |

Ikkita yordamchi narsa: **`make([]int, n)`** — yangi massiv ochib, unga qaraydigan slice qaytaradi (`tuzatish`
boʻlimida); **`%p`** — `Printf` shabloni, slice qaraydigan massivning manzilini chiqaradi.

## Slice nimadan iborat: sarlavha va massiv

Bozor omborida har mahsulotning qoldigʻi bor: olma, non, choy. Bitta oʻzgaruvchida shu uch sonni saqlash uchun
Go'da **slice** bor. Eng kichik dastur:

```go filename="_video/01-slice/main.go" showLineNumbers
package main

import "fmt"

func main() {
	stock := []int{40, 12, 7} // olma, non, choy
	fmt.Println(stock, len(stock), cap(stock))
	fmt.Println(stock[0], stock[2])
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1 | `package main` | bu fayl `main` paketida: `go run .` shu paketni ishga tushiradi (GB-1.01) |
| 3 | `import "fmt"` | `fmt` paketini ulaydi, `Println` va `Printf` shundan (GB-1.01) |
| 5 | `func main() {` | dastur shu funksiyadan boshlanadi (GB-1.01) |
| 6 | `stock := []int{40, 12, 7}` | `stock` degan oʻzgaruvchi. `[]int` — turi: «`int`lar slice'i». Jingalak qavs ichidagi `40, 12, 7` — boshlangʻich elementlar, vergul bilan. Bunday yozuv **slice literal** deyiladi. `//` dan keyingi izoh: olma, non, choy |
| 7 | `fmt.Println(stock, len(stock), cap(stock))` | `stock`ni, `len(stock)` ni (elementlar soni) va `cap(stock)` ni (**sigʻim**: orqadagi massivda nechta joy borligi) chiqaradi |
| 8 | `fmt.Println(stock[0], stock[2])` | indeks 0 dan boshlanadi: `stock[0]` — olma, `stock[2]` — choy |

Natija:

```console
$ ./_video/run.sh 01-slice go run .
[40 12 7] 3 3
40 7
```

`Println` slice'ni kvadrat qavsda, elementlarni boʻsh joy bilan ajratib yozadi. Keyin `len` — 3 va `cap` — 3. Ikkinchi
qatordagi `40` va `7` — nolinchi va ikkinchi elementlar.

`len` va `cap` nima uchun ikkita son? Buni xotira rasmi koʻrsatadi. `stock` oʻzgaruvchisi slice'ning oʻzini emas,
uning **sarlavhasini** (slice header) ushlaydi. Sarlavhada uchta maydon bor:

- `ptr` — nolinchi element turgan xotira manzili (address). `ptr` — pointer'ning qisqartmasi; pointer'larni
  [GB-2.04](/lab/youtube/gb/gb-2-04) da ochamiz, hozir «manzil» deb bilsangiz yetadi;
- `len` — uzunlik: slice'da hozir nechta element bor;
- `cap` — sigʻim: slice boshidan massiv oxirigacha nechta joy bor.

Elementlarning oʻzi sarlavhada emas, uning orqasidagi **massivda** turadi. Massiv — xotirada ketma-ket turgan, soni
qatʼiy joylar. Uning turi `[3]int`: uzunlik turning bir qismi va oʻzgarmaydi ([Go spec: Array types](https://go.dev/ref/spec#Array_types)).

```text
stock ─► ┌─────┬─────┬─────┐
         │ ptr │ len │ cap │     sarlavha (slice header)
         │  ●  │  3  │  3  │
         └──┬──┴─────┴─────┘
            │
            ▼
         ┌─────┬─────┬─────┐
         │ 40  │ 12  │  7  │     massiv [3]int
         └─────┴─────┴─────┘
 indeks     0     1     2
```

Literal `[]int{40, 12, 7}` massivni oʻzi yaratadi, shuning uchun `len` ham, `cap` ham 3: massivda aynan uchta joy bor
([Go spec: Composite literals](https://go.dev/ref/spec#Composite_literals)). `cap` `len`dan katta boʻlishi mumkin:
massivda boʻsh joy qolgan boʻlsa. Buni `append` boʻlimida koʻramiz.

## `before := stock`: nusxa faqat sarlavhani oladi

Dasturga oʻzgarishdan oldingi holatni eslab qolish kerak boʻlsin: `before` oʻzgaruvchisiga `stock`ni beramiz,
keyin `stock[0]`ga 38 yozamiz.

```go filename="_video/02-nusxa/main.go" showLineNumbers
package main

import "fmt"

func main() {
	stock := []int{40, 12, 7}
	before := stock
	stock[0] = 38
	fmt.Println(before[0])
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 6 | `stock := []int{40, 12, 7}` | sarlavha va massiv (oldingi boʻlimdagidek) |
| 7 | `before := stock` | `before` degan yangi oʻzgaruvchi; unga `stock`ning qiymati beriladi |
| 8 | `stock[0] = 38` | `stock`ning nolinchi elementiga 38 yozadi (`=` — borini almashtirish, GB-1.02) |
| 9 | `fmt.Println(before[0])` | `before`ning nolinchi elementini chiqaradi |

`before[0]` nechchi chiqadi?

**A)** `40` · **B)** `38` · **C)** kompilyatsiya xatosi

<details>
<summary>Javob</summary>

**B: 38.** `before := stock` **faqat sarlavhani** nusxalaydi: uchta maydon (`ptr`, `len`, `cap`) koʻchadi, `ptr`ning
nusxasi esa oʻsha massivga boradi. `stock[0] = 38` massivga yozadi va `before` ham shu massivni koʻradi. **A** ni
tanlagan boʻlsangiz, `before` slice'ning butun nusxasini oldi deb oʻylagansiz: massiv nusxalanmadi. **C** — kod toʻgʻri,
kompilyator bu yerda hech narsani rad etmaydi.

</details>

```console
$ ./_video/run.sh 02-nusxa go run .
38
```

Holat qatorma-qator (massiv A — ikkala sarlavha qaraydigan bitta massiv):

| Qator | `stock` sarlavhasi | `before` sarlavhasi | massiv A | Ekranda |
|---|---|---|---|---|
| 6 | (ptr→A, 3, 3) | — | `40 12 7` | |
| 7 | (ptr→A, 3, 3) | (ptr→A, 3, 3) nusxa | `40 12 7` | |
| 8 | (ptr→A, 3, 3) | (ptr→A, 3, 3) | `38 12 7` | |
| 9 | (ptr→A, 3, 3) | (ptr→A, 3, 3) | `38 12 7` | `38` |

Natija: `before` eski holatni saqlamadi. Boshqa tomondan, slice'ni boshqa oʻzgaruvchiga berish arzon: massiv qancha
katta boʻlmasin, faqat uch maydon koʻchadi.

## `append`: joy boʻlsa oʻsha massiv, boʻlmasa yangi massiv

Omborga yangi mahsulot qoʻshamiz: oʻrik, qoldigʻi 25. Slice'ga element qoʻshadigan funksiya — **`append`**.

```go filename="_video/03-append/main.go" showLineNumbers
package main

import "fmt"

func main() {
	stock := []int{40, 12, 7}
	fmt.Printf("%d %d %p\n", len(stock), cap(stock), stock)
	stock = append(stock, 25) // oʻrik
	fmt.Printf("%d %d %p\n", len(stock), cap(stock), stock)
	stock = append(stock, 3) // anor
	fmt.Printf("%d %d %p\n", len(stock), cap(stock), stock)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 7 | `fmt.Printf("%d %d %p\n", len(stock), cap(stock), stock)` | `len`, `cap` va manzilni chiqaradi. `%d` — butun son (GB-1.04); `%p` — slice qaraydigan **massivning** manzili, 16lik sonda `0x` bilan; `\n` — yangi qator |
| 8 | `stock = append(stock, 25) // oʻrik` | `append` slice va yangi elementni oladi va **yangi sarlavha qaytaradi**. Biz uni yana `stock`ga yozamiz |
| 9 | `fmt.Printf(…)` | `append`dan keyingi holatni chiqaradi |
| 10 | `stock = append(stock, 3) // anor` | yana bitta element: anor, qoldigʻi 3 |
| 11 | `fmt.Printf(…)` | yana chiqaradi |

`append` qanday ishlaydi ([Go spec: Appending to and copying slices](https://go.dev/ref/spec#Appending_and_copying_slices)):

1. Massivda yangi element uchun joy bor boʻlsa, yaʼni `len < cap` boʻlsa, element **oʻsha massivga** yoziladi.
2. Joy yetmasa, `append` xotiradan zaxirasi bor **yangi massiv** ajratadi, eski elementlarni koʻchiradi va unga
   qaraydigan sarlavhani qaytaradi.
3. Kichik slice'larda runtime yangi massivni odatda ikki baravar katta qiladi. Bu kafolat emas: spetsifikatsiya faqat
   «yetarlicha katta» deydi.

Uchta qator chiqadi; boshida `len` ham, `cap` ham 3. Qaysi qatorlarda `%p` bir xil boʻladi?

**A)** 1 va 2 · **B)** 2 va 3 · **C)** uchalasida

<details>
<summary>Javob</summary>

**B: ikkinchi va uchinchi.** Birinchi `append`da joy yoʻq edi (`len` 3 = `cap` 3): yangi massiv ochildi, manzil
oʻzgardi, sigʻim 6 boʻldi. Ikkinchi `append`da joy bor: element oʻsha massivga yozildi, faqat `len` 5 boʻldi. **A** ni
tanlagan boʻlsangiz, `append` har doim oldingi massivni saqlaydi deb oʻylagansiz: joy yetmasa saqlamaydi. **C** — bu
`append` hech qachon massiv almashtirmaydi degani.

</details>

```console
$ ./_video/run.sh 03-append go run .
3 3 0x6f8787a8000
4 6 0x6f878800000
5 6 0x6f878800000
```

Manzil — `0x` bilan boshlangan 16lik son, har ishga tushirishda boshqacha chiqadi. Uni oʻqish shart emas: qatorlarni
bir-biri bilan solishtiramiz. Xuddi shu dastur ikkinchi marta:

```console
$ ./_video/run.sh 03-append go run .
3 3 0xb2fe8d20120
4 6 0xb2fe8e00000
5 6 0xb2fe8e00000
```

Manzillar boshqa, lekin tuzilishi bir xil: 1-qator ≠ 2-qator, 2-qator = 3-qator. (Videoda `0x103325296000`,
`0x10332529e000`, `0x10332529e000` chiqqan edi; bu uchta son videodan keltirilgan, men ularni qayta ishga tushirmadim.)

| Qator | `len` | `cap` | Slice qaraydigan massiv |
|---|---|---|---|
| 7 | 3 | 3 | massiv A: `40 12 7` |
| 9 (`append(…, 25)`) | 4 | 6 | **yangi** massiv B: `40 12 7 25 _ _` (oxirgi ikki joy boʻsh) |
| 11 (`append(…, 3)`) | 5 | 6 | oʻsha massiv B: `40 12 7 25 3 _` |

Endi ikkalasini birlashtiramiz: `before` yana `stock`ning nusxasi, lekin oʻrtada `append` bor.

```go filename="_video/04-append-nusxa/main.go" showLineNumbers
package main

import "fmt"

func main() {
	stock := []int{40, 12, 7}
	before := stock
	stock = append(stock, 25)
	stock[0] = 38
	fmt.Println(before[0], stock[0])
}
```

Avvalgi misolda `before` 38 ni koʻrgan edi. Bu safar `fmt.Println(before[0], stock[0])` nima chiqaradi?

**A)** `40 38` · **B)** `38 38` · **C)** `40 40`

<details>
<summary>Javob</summary>

**A: `40 38`.** `append` paytida `cap` 3 edi va joy yoʻq edi. Olti joyli yangi massiv ochildi, eski uch element koʻchdi,
25 toʻrtinchi boʻlib yozildi. `stock` endi yangi massivga qaraydi, `before` esa eskisida qoldi. `stock[0] = 38` yangi
massivga tushadi, `before` uni koʻrmaydi. **B** ni tanlagan boʻlsangiz, oldingi misoldagidek massiv umumiy deb
oʻylagansiz: bu safar `append` uni ajratib yubordi. **C** da `stock[0]` ning 38 ga oʻzgarishi hisobga olinmagan.

</details>

```console
$ ./_video/run.sh 04-append-nusxa go run .
40 38
```

| Qator | `stock` | `before` | Massivlar | Ekranda |
|---|---|---|---|---|
| 6 | (ptr→A, 3, 3) | — | A: `40 12 7` | |
| 7 | (ptr→A, 3, 3) | (ptr→A, 3, 3) | A: `40 12 7` | |
| 8 (`append`) | (ptr→**B**, 4, 6) | (ptr→A, 3, 3) | A: `40 12 7`; B: `40 12 7 25 _ _` | |
| 9 (`stock[0] = 38`) | (ptr→B, 4, 6) | (ptr→A, 3, 3) | A: `40 12 7`; B: `38 12 7 25 _ _` | |
| 10 | | | | `40 38` |

Kod bir xil koʻrinadi, lekin `cap`ga qarab massiv goh umumiy, goh alohida. Shu sababli `append`dan keyin eski slice'ga
tayanib boʻlmaydi.

## `append` natijasini yozmaslik

`append` yangi sarlavha qaytaradi, eskisini oʻzgartirmaydi. Shuning uchun eng koʻp uchraydigan xato: `append`ni
chaqirib, natijasini hech qayerga yozmaslik. 7-qatorda `append` yolgʻiz turibdi, `stock =` yoʻq:

```go filename="_video/05-xato/main.go" showLineNumbers
package main

import "fmt"

func main() {
	stock := []int{40, 12, 7}
	append(stock, 25)
	fmt.Println(stock)
}
```

```console
$ ./_video/run.sh 05-xato go build
# github.com/abdurahmon27/bozor
./main.go:7:2: append(stock, 25) (value of type []int) is not used
```

Xabarni oʻqiymiz:

| Qism | Maʼnosi |
|---|---|
| `# github.com/abdurahmon27/bozor` | qaysi paket kompilyatsiya qilinayotgani (modul nomi, GB-1.01). Videoda bu qator yashirilgan |
| `./main.go:7:2` | `main.go` fayli, 7-qator, 2-ustun (GB-1.01): `append` boshlanadigan joy |
| `append(stock, 25)` | xato aynan shu ifodada |
| `(value of type []int) is not used` | «`[]int` turidagi qiymat ishlatilmadi»: `append` slice qaytardi, lekin hech kim uni olmadi |

Sababi endi aniq: `append` yangi sarlavha qaytaradi, `stock`ning oʻzidagi `len` esa oʻzgarmaydi. Hatto element massivga
yozilgan boʻlsa ham, `stock` uni koʻrmaydi: `len` 3 boʻlib qoladi. Go spetsifikatsiyasi `append`ning natijasini ishlatmay,
yolgʻiz qator qilib yozishni taqiqlaydi ([Expression statements](https://go.dev/ref/spec#Expression_statements)).

Tuzatish: `stock = append(stock, 25)`.

## Bozor xatosi: funksiya parametri ham sarlavha nusxasi

Endi darsning boshidagi xatoga qaytamiz. Funksiyaga slice berilganda ham xuddi `before := stock` dagidek sarlavha
nusxalanadi.

```go filename="_video/00-bug/main.go" showLineNumbers
package main

import "fmt"

// afterOrder buyurtmadan keyingi qoldiqni hisoblaydi.
func afterOrder(stock []int, sold []int) []int {
	for i := range stock {
		stock[i] = stock[i] - sold[i]
	}
	return stock
}

func main() {
	stock := []int{40, 12, 7} // olma, non, choy
	sold := []int{2, 1, 0}    // savatda
	fmt.Println("ombor oldin:", stock)
	left := afterOrder(stock, sold)
	fmt.Println("koʻrish:    ", left)
	fmt.Println("ombor keyin:", stock)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 5 | `// afterOrder …` | izoh: funksiya buyurtmadan keyingi qoldiqni hisoblaydi |
| 6 | `func afterOrder(stock []int, sold []int) []int {` | ikki parametr, ikkalasi slice: `stock` (ombor) va `sold` (savatdagi miqdor har mahsulot uchun). Natijasi ham slice |
| 7 | `for i := range stock {` | slice ustidagi `range` bitta oʻzgaruvchi bilan faqat indeksni beradi: 0, 1, 2 |

| 10 | `return stock` | oxirida `stock` qaytadi |
| 14–15 | `stock := …`, `sold := []int{2, 1, 0}` | `main`da ombor va savat: 2 olma, 1 non, 0 choy |

Chiqish darsning boshidagi bilan bir xil: `[40 12 7]`, `[38 11 7]`, `[38 11 7]`. Nega:

| Moment | `main`dagi `stock` | `afterOrder`dagi `stock` | massiv A | `left` |
|---|---|---|---|---|
| 17: chaqiruv | (ptr→A, 3, 3) | (ptr→A, 3, 3) — nusxa | `40 12 7` | |
| 7–9: sikl | (ptr→A, 3, 3) | (ptr→A, 3, 3) | `38 11 7` | |
| 10: `return stock` | (ptr→A, 3, 3) | | `38 11 7` | (ptr→A, 3, 3) — qaytgan sarlavha |
| 19 | (ptr→A, 3, 3) | | `38 11 7` | (ptr→A, 3, 3) |

Chaqiruvda parametr ham `before := stock` kabi sarlavha nusxasi. Funksiya ichida `stock[i]`ga yozish asl massivga
tushadi. Qaytgan sarlavha ham oʻsha massivga qaraydi: `left` va `stock` bitta maʼlumot. Bitta xotiraga ikki nom — shu
holat **aliasing** deyiladi. `sold` jadvalda yoʻq: u faqat oʻqiladi. Funksiya «faqat hisoblayman» desa ham, uni
chaqirgan `main`ning omborini oʻzgartirdi.

## Tuzatish: natija uchun `make` bilan alohida massiv

Natija uchun alohida massiv kerak. Uni **`make`** beradi:

```go filename="_video/06-tuzat/main.go" showLineNumbers
package main

import "fmt"

// afterOrder buyurtmadan keyingi qoldiqni hisoblaydi; stock oʻzgarmaydi.
func afterOrder(stock []int, sold []int) []int {
	left := make([]int, len(stock))
	for i := range stock {
		left[i] = stock[i] - sold[i]
	}
	return left
}

func main() {
	stock := []int{40, 12, 7} // olma, non, choy
	sold := []int{2, 1, 0}    // savatda
	fmt.Println("ombor oldin:", stock)
	left := afterOrder(stock, sold)
	fmt.Println("koʻrish:    ", left)
	fmt.Println("ombor keyin:", stock)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 5 | `// afterOrder …; stock oʻzgarmaydi.` | izohda ham shu vaʼda |
| 7 | `left := make([]int, len(stock))` | `make` yangi massiv ajratadi, uni nollar bilan toʻldiradi va unga qaraydigan slice qaytaradi. Uzunligi — `len(stock)`, yaʼni 3 |
| 9 | `left[i] = stock[i] - sold[i]` | sikl endi faqat `left`ga yozadi, `stock`ni faqat oʻqiydi |
| 11 | `return left` | oxirida `left` qaytadi |

## Chuqurroq (ixtiyoriy): bitta sarlavhadan ikki `append`

Joy bor paytdagi `append` ham tuzoq boʻlishi mumkin. Bu yerda `stock`da `len` 4, `cap` 6. Undan ikkita `append`

## Koʻp uchraydigan xatolar

**1. «`before := stock` eski holatni saqlaydi».** Xato yoʻq, lekin natija notoʻgʻri: `before` massivni nusxalamaydi
(`38`, yuqoridagi «`before := stock`» boʻlimiga qarang). Tuzatish: nusxa uchun `make` bilan alohida massiv yasab,
elementlarni sikl bilan koʻchirish, `afterOrder` kabi.

**2. `append` natijasini yozmaslik.** Funksiyaning oʻzida kompilyator ushlaydi (yuqoridagi `is not used` xatosi). Lekin
jim variant ham bor: funksiya parametrga `append` qilib, yangi sarlavhani qaytarmasa. Bu kod papkada yoʻq, men uni
alohida ishga tushirdim (toʻliq kodi shu yerda):

```go showLineNumbers
package main

import "fmt"

// addPlumLost parametr orqali qoʻshmoqchi: yangi sarlavha faqat s ichida qoladi.
func addPlumLost(s []int) {
	s = append(s, 25)
}

// addPlum yangi sarlavhani qaytaradi.
func addPlum(s []int) []int {
	return append(s, 25)
}

func main() {
	stock := []int{40, 12, 7}
	addPlumLost(stock)
	fmt.Println(stock, len(stock))
	stock = addPlum(stock)
	fmt.Println(stock, len(stock))
}
```

```console
$ go run .
[40 12 7] 3
[40 12 7 25] 4
```

`addPlumLost(stock)` ichidagi `s = append(s, 25)` yangi sarlavhani faqat `s` parametriga yozdi. `s` — `stock`
sarlavhasining nusxasi, shuning uchun `main`dagi `stock` oʻzgarmadi: `[40 12 7]`, `len` 3. Xato ham, ogohlantirish ham
yoʻq. Tuzatish: funksiya yangi sarlavhani qaytaradi va chaqiruvchi uni yozadi: `stock = addPlum(stock)`.

**3. Funksiya kirgan slice'ga yozadi.** Darsning asosiy xatosi (bozor'ning `afterOrder` funksiyasi,
yuqoridagi «Bozor xatosi» boʻlimiga qarang): xato yoʻq, ombor jimgina oʻzgaradi. Tuzatish:
natija uchun `make` bilan alohida massiv.

**4. Indeks `len`dan oshadi, `cap`dan emas.** `cap` — massivdagi joy, element emas: indeks faqat `len`gacha. Bu kod ham
papkada yoʻq, men uni alohida ishga tushirdim:

```go showLineNumbers
package main

import "fmt"

func main() {
	s := make([]int, 0, 4)
	fmt.Println(len(s), cap(s))
	s[0] = 1
	fmt.Println(s)
}
```

```console
$ go run .
0 4
panic: runtime error: index out of range [0] with length 0

goroutine 1 [running]:
main.main()
	…/bozor/main.go:8 +0x8a
exit status 2
```

Birinchi qator `0 4`: `make([]int, 0, 4)`da massivda 4 joy bor, lekin `len` 0. Shuning uchun `s[0] = 1` 8-qatorda
panic beradi (GB-1.07 dagi `index out of range`): `index out of range [0] with length 0` — «0-indeks chegaradan
tashqarida, uzunlik 0». `…/bozor/main.go:8` dagi `…` — vaqtinchalik papka, nomi har safar boshqa; `exit status 2` —
panic bilan yiqilgan dasturning chiqish kodi, uni `go run` yozadi. Tuzatish: boʻsh joyga `append` bilan yozing
(`s = append(s, 1)`) yoki `make([]int, 4)` bilan uzunlikni 4 qiling.

## Oʻzingizni tekshiring

**1.** Slice sarlavhasida qaysi uch maydon bor va har biri nimani bildiradi?

<details>
<summary>Javob</summary>

`ptr` — nolinchi element turgan massivning manzili, `len` — slice'da nechta element bor, `cap` — slice boshidan massiv
oxirigacha nechta joy bor. Elementlarning oʻzi sarlavhada emas, orqadagi massivda turadi.

</details>

**2.** `append` qachon yangi massiv ajratadi?

<details>
<summary>Javob</summary>

Massivda joy yetmaganda: bitta element uchun `len` `cap`ga teng boʻlsa. Joy yetsa, element oʻsha massivga yoziladi,
faqat `len` oshadi. Har holda natijani yozish kerak: `stock = append(stock, 25)`.

</details>

**3.** GB-1.06 dan: `for i := range 3` siklida `i` qaysi qiymatlarni oladi?

<details>
<summary>Javob</summary>

0, 1 va 2: `range` butun son bilan 0 dan son−1 gacha sanaydi, son oʻzi kirmaydi.

</details>

**4.** Bu dastur nima chiqaradi? (Kod papkada yoʻq, men uni alohida ishga tushirdim.)

```go showLineNumbers
package main

import "fmt"

func main() {
	s := make([]int, 2, 5)
	t := append(s, 7)
	u := append(s, 8)
	fmt.Println(t[2], u[2], len(s))
}
```

**A)** `7 8 2` · **B)** `8 8 2` · **C)** `8 8 4`

<details>
<summary>Javob</summary>

**B: `8 8 2`.** `s`da `len` 2, `cap` 5: ikkala `append`da joy bor, ikkalasi ham massivning ikkinchi indeksiga yozdi,
8 7 ning ustidan yozildi. `s`ning oʻzi oʻzgarmadi: `len(s)` 2. **A** da ikkala `append` alohida massivga yozadi deb
oʻylangan. **C** da `append` `s`ning `len`ini oshiradi deb oʻylangan: u yangi sarlavha qaytaradi, `s` oʻz joyida.

```console
$ go run .
8 8 2
```

</details>

**5.** `afterOrder(stock, sold)` ombordagi `stock`ni oʻzgartirishi mumkin edi. Nega `int` parametri bilan bunday boʻlmaydi?

<details>
<summary>Javob</summary>

Parametrga har doim nusxa beriladi. `int`da nusxa — qiymatning oʻzi, funksiya uni oʻzgartirsa, chaqiruvchining
oʻzgaruvchisi oʻzgarmaydi. Slice'da nusxa — sarlavha; uning `ptr` maydoni chaqiruvchining massiviga qaraydi, shuning
uchun massivga yozish chaqiruvchida ham koʻrinadi.

</details>
