## What you will learn

Bozor asks three suppliers for the price of apples concurrently. The fastest reply wins and the test passes, but each call leaves two goroutines. How do you catch this?

**The one idea:** checking the result is not enough; check how the goroutines you start will exit. `testing/synctest` controls waiting and fake time in an isolated test environment.

After this lesson you will:

- count a goroutine leak and find the waiting line in a profile;
- catch a bug missed by an ordinary test using `synctest.Test`;
- cancel slow work through context;
- check a 50 ms deadline precisely and find a missing `Close`.

| Word | Plain meaning | English term |
|---|---|---|
| goroutine leak | a goroutine waiting forever when it should have exited | goroutine leak |
| bubble | an isolated environment for a test and the goroutines it starts | bubble |
| fake clock | a clock that advances to the end of a wait without waiting in real time | fake clock |

## One reply, two remaining goroutines

Start with the broken snapshot. `prices` maps IDs to prices in tiyin; `supplierDelays` holds three suppliers' response times.
`quote` simulates a wait instead of using a real network.

```go filename="_video/01-leak/price.go" showLineNumbers
package main

import "time"

// prices: yetkazib beruvchilar aytadigan narx, tiyinda (ID → tiyin): olma 1, non 2, oʻrik 3.
var prices = map[int64]int64{1: 1_200_000, 2: 500_000, 3: 3_000_000}

// supplierDelays: uch yetkazib beruvchining (chorsu, oloy, siyob) javob vaqti.
var supplierDelays = []time.Duration{
	100 * time.Millisecond,
	200 * time.Millisecond,
	300 * time.Millisecond,
}

func quote(delay time.Duration, id int64) int64 {
	time.Sleep(delay)
	return prices[id]
}

func fastestPrice(id int64) int64 {
	ch := make(chan int64)
	for _, d := range supplierDelays {
		go func() {
			ch <- quote(d, id)
		}()
	}
	return <-ch
}
```

| Line | Code | What it does |
|---|---|---|
| 1, 3 | `package main`, `import "time"` | executable package and time package |
| 5–6 | `prices` | comment and `map[int64]int64`; ID 1 costs 1,200,000 tiyin, or 12,000 soʻm |
| 8–13 | `supplierDelays` | comment and `[]time.Duration` slice; `*` multiplies, the trailing comma is required in a multiline literal |
| 15–18 | `quote` | takes `delay` and `id`, sleeps, returns the map value |
| 20–21 | `fastestPrice`, `make(chan int64)` | function and unbuffered result channel |
| 22 | `for _, d := range` | discards the index with `_`; creates a new `d` each iteration |
| 23 | `go func() {` | starts an anonymous function in another goroutine |
| 24 | `ch <- quote(d, id)` | computes the price first, then tries to send it |
| 25–26 | `}()`, `}` | invokes the anonymous function and closes the loop |
| 27–28 | `return <-ch`, `}` | receives one price and returns from the function |

Blank lines separate code; `//` lines are comments. `{}` marks block boundaries; `:=` declares a new variable.

```go filename="_video/01-leak/main.go" showLineNumbers
package main

import (
	"fmt"
	"runtime"
	"time"
)

func main() {
	for range 3 {
		for range 100 {
			fastestPrice(1)
		}
		time.Sleep(time.Second)
		fmt.Println("goroutine'lar:", runtime.NumGoroutine())
	}
}
```

`main.go`: line 1 is the package; 3–7 imports; 9 the function; 10 the outer loop; 11–13 one hundred calls; 14 a one-second wait.
Line 15 prints all live goroutines with `fmt.Println`; 16–17 close the blocks.
`for range 3` is three iterations without a counter variable.

**Predict:** how many goroutines remain after 300 calls? **A)** 1 · **B)** 301 · **C)** 601.

<details>
<summary>Answer</summary>

**C: 1 + 300 × 2 = 601.** The 1 is `main`. Each call starts three goroutines but receives only one reply.
A assumes all work finishes; B counts only one remaining goroutine per call.

</details>


| Time | First supplier | Second | Third | Receiver |
|---|---|---|---|---|
| 0 ms | waiting | waiting | waiting | `<-ch` |
| 100 ms | sends, exits | waiting | waiting | receives price and returns |
| 200 ms | exited | stuck sending | waiting | gone |
| 300 ms | exited | stuck sending | stuck sending | gone |

This is a **goroutine leak**: nobody will receive from the two remaining senders.
A waiting goroutine's resources are not released automatically; it must exit.

## synctest: the test returned, but work remains

`testing/synctest` has been available without an experiment flag since Go 1.25. It runs the test in a **bubble**.
This is an isolated test environment: goroutines started inside also belong to it. `synctest.Test` waits for all of them to exit.

**Durable blocking** (*durably blocked*) means a goroutine can only be unblocked by work within its bubble.
Waiting on a channel created in the bubble and `time.Sleep` qualify.
When all goroutines wait this way, the clock advances to the next wakeup. Its initial time is `2000-01-01 00:00:00 UTC`.
The clock stops advancing when the bubble's root function exits. If no work can wake and waiting remains, there is a deadlock.

```go filename="_video/04-synctest/price_test.go" showLineNumbers
package main

import (
	"testing"
	"testing/synctest"
)

func TestFastestPrice(t *testing.T) {
	synctest.Test(t, func(t *testing.T) {
		got := fastestPrice(1)
		if got != 1_200_000 {
			t.Errorf("fastestPrice(1) = %d; kutilgan 1200000", got)
		}
	})
}
```

New line 5 imports the package; line 9 passes the outer `t` and an anonymous function with its own `t` parameter.
Lines 10–13 keep the same assertion; 14–15 close the bubble and test.

**Predict:** **A)** PASS · **B)** FAIL: deadlock · **C)** waits 300 ms and passes.

<details>
<summary>Answer</summary>

**B.** The price arrives at 100 ms of fake time. The test function returns and the clock stops; two goroutines are still sleeping.
A considers only the price. C assumes the clock keeps advancing after the test function exits.

</details>

## A buffer does not cancel waiting

First attempt: only channel creation changes in `_video/05-buffer/price.go`:

```go
ch := make(chan int64, len(supplierDelays))
```

`len(supplierDelays)` gives three slots. Each goroutine sends one reply, so its later send will not get stuck.

**Predict:** **A)** PASS · **B)** the same deadlock · **C)** wrong price.

<details>
<summary>Answer</summary>

**B.** The buffer provides space for sends; it does not cancel `Sleep`. When the test returns, the remaining work still waits for 200 and 300 ms.

## Stop the remaining work with context

The final `price.go` in the lesson folder:

```go filename="price.go" showLineNumbers
// bozor: bitta mahsulot narxini uch yetkazib beruvchidan birdan soʻrab, eng tez javobni olish (GB-7.06).
// Videoning oxiridagi holat: goroutine'lar fastestPrice bilan birga tugaydi (ctx + cancel), leak yoʻq.
package main

import (
	"context"
	"time"
)

// prices: yetkazib beruvchilar aytadigan narx, tiyinda (ID → tiyin): olma 1, non 2, oʻrik 3.
var prices = map[int64]int64{1: 1_200_000, 2: 500_000, 3: 3_000_000}

// supplierDelays: uch yetkazib beruvchining (chorsu, oloy, siyob) javob vaqti.
var supplierDelays = []time.Duration{
	100 * time.Millisecond,
	200 * time.Millisecond,
	300 * time.Millisecond,
}

// quote bitta yetkazib beruvchidan narx soʻrashni taqlid qiladi: delay oʻtguncha yoki ctx bekor qilinguncha kutadi.
func quote(ctx context.Context, delay time.Duration, id int64) (int64, error) {
	select {
	case <-time.After(delay):
		return prices[id], nil
	case <-ctx.Done():
		return 0, ctx.Err()
	}
}

// fastestPrice hamma yetkazib beruvchidan birdan soʻraydi va birinchi kelgan javobni qaytaradi.
// Qaytishdan oldin cancel() qolgan soʻrovlarni toʻxtatadi: oʻzi boshlagan goroutine'lar uning bilan tugaydi.
func fastestPrice(ctx context.Context, id int64) (int64, error) {
	ctx, cancel := context.WithCancel(ctx)
	defer cancel()
	ch := make(chan int64, len(supplierDelays))
	for _, d := range supplierDelays {
		go func() {
			p, err := quote(ctx, d, id)
			if err == nil {
				ch <- p
			}
		}()
	}
	select {
	case p := <-ch:
		return p, nil
	case <-ctx.Done():
		return 0, ctx.Err()
	}
}
```

Changed lines:

| Line | What it does |
|---|---|
| 5–8 | imports `context` and `time` |
| 21 | `quote` takes a context and returns `(int64, error)` |
| 22–28 | `select`: price and `nil` when time passes; 0 and `ctx.Err()` when `Done` closes |
| 32–34 | `WithCancel` creates a child context; `ctx` reassigns the parameter in this block, `cancel` is new; `defer` signals on return |
| 35 | keeps the three-slot buffer |
| 36–43 | each goroutine queries with the child context; `p` is price, `err` is error; sends only when `err == nil` |
| 44–50 | waits for the first price or caller cancellation |

Lines 1–2, 10, 13, 20 and 30–31 are comments. Do not read «birga tugaydi» ("finish together") as a guarantee of joining.
[`CancelFunc`](https://pkg.go.dev/context#CancelFunc) only signals; it does not wait for work to exit.
Here the remaining goroutines observe the signal and exit; `synctest.Test` waits for their exit.
If the caller must strictly wait before returning, use a wait group as in [GB-7.01](/lab/youtube/gb/gb-7-01/en).
The buffer remains useful: if time and cancellation become ready together, a successful price send cannot get stuck.

| Stage | Result |
|---|---|

| `defer cancel()` | closes the child context's `Done` channel |
| remaining `quote` calls | observe cancellation, return errors, do not send |
| `synctest.Test` | waits for all goroutines to exit |

## Exactly 50 ms and a one-hour test

The deadline is 50 ms; the fastest offer takes 100 ms. Inside a bubble you can check exact equality instead of an approximate bound:

```go filename="_video/07-timeout/price_test.go" showLineNumbers
package main

import (
	"context"
	"errors"
	"testing"
	"testing/synctest"
	"time"
)

// Videodagi testlar. synctest.Test funksiyani "pufak" ichida ishga tushiradi: soxta soat, va funksiya
// tugaganda pufakda kutib qolgan goroutine boʻlsa, test yiqiladi.

func TestFastestPrice(t *testing.T) {
	synctest.Test(t, func(t *testing.T) {
		got, err := fastestPrice(t.Context(), 1)
		if err != nil || got != 1_200_000 {
			t.Errorf("fastestPrice(1) = %d, %v; kutilgan 1200000", got, err)
		}
	})
}

func TestFastestPriceTimeout(t *testing.T) {
	synctest.Test(t, func(t *testing.T) {
		ctx, cancel := context.WithTimeout(t.Context(), 50*time.Millisecond)
		defer cancel()
		start := time.Now()
		_, err := fastestPrice(ctx, 1)
		took := time.Since(start) // pufakda soat soxta: aniq tenglik mumkin (haqiqiy soatda emas)

			t.Errorf("xato %v, %v oʻtdi; kutilgan deadline, 50ms", err, took)
		}
	})
}
```

New imports are `context`, `errors`, `time`. Lines 16–18 check the result and error together.

The remaining lines are the familiar test structure and block boundaries.

## A missing Close: another wait, the same bug

`store.go` is a shortened `OwnedStore` from the previous lesson. Only the owner goroutine accesses the map.

```go filename="store.go" showLineNumbers
package main

// OwnedStore — GB-7.05'dagi qoldiq doʻkoni (qisqartirilgan): stock map'iga faqat loop goroutine'i tegadi,
// Sell unga channel orqali soʻrov yuboradi. loop sells yopilganda (Close) tugaydi.
type OwnedStore struct {
	sells chan sellReq
}

// sellReq — egasiga yuboriladigan sotish soʻrovi: qaysi mahsulot, necha dona va javob qaytadigan channel.
type sellReq struct {
	id    int64
	n     int
	reply chan bool
}

// NewOwnedStore loop'ni yangi goroutine'da boshlaydi va stock map'ini unga topshiradi.
func NewOwnedStore(stock map[int64]int) *OwnedStore {
	s := &OwnedStore{sells: make(chan sellReq)}
	go s.loop(stock)
	return s
}

func (s *OwnedStore) loop(stock map[int64]int) {
	for r := range s.sells {
		ok := stock[r.id] >= r.n
		if ok {
			stock[r.id] -= r.n
		}
		r.reply <- ok
	}
}

// Sell id'li mahsulotdan n dona sotadi; qoldiq yetmasa false.
func (s *OwnedStore) Sell(id int64, n int) bool {
	reply := make(chan bool)
	s.sells <- sellReq{id, n, reply}
	return <-reply
}

// Close loop goroutine'ini toʻxtatadi. Close'dan keyin Sell chaqirilmaydi.
func (s *OwnedStore) Close() { close(s.sells) }
```

Lines 5–7 hold the request channel; 10–14 hold the request's `id`, quantity `n` and response channel `reply`.
17–21 create the store and pass the map to `loop`. 23–31 receive requests sequentially, reduce stock if sufficient, and send a reply.
34–38 make `Sell` send a request and receive a reply. Line 41 makes `Close` close the request channel.
`>=` compares availability; `-=` subtracts; `&` takes an address; `*OwnedStore` is a pointer receiver.
The package, comments and braces follow earlier patterns.

## Going deeper (optional): goroutineleak and synctest limits

In Go 1.27 the `goroutineleak` profile graduated from experiment; `GOEXPERIMENT=goroutineleakprofile` is unnecessary and the old setting was removed.
GC means garbage collection: reclaiming unused memory.
The profile is normally available, but that does not mean automatic leak detection is enabled for every GC.
In the Go 1.27.4 source, `writeGoroutineLeak` first calls `runtime_goroutineLeakGC()`, then writes the profile.
Requesting the profile therefore triggers a GC cycle with leak detection.

```go filename="_video/10-leakprofil/main.go" showLineNumbers

		fmt.Println("goroutine'lar:", runtime.NumGoroutine())
```

Detection uses reachability: if no potentially runnable goroutine can reach a waiting primitive, it cannot wake that wait.
Leaks through primitives reachable from globals or running goroutines can be missed.
`WriteTo(..., 2)` prints all stacks, marking leaks with `(leaked)`; do not treat it as a list containing only leaks.

The fake clock in `synctest` does not completely determine execution order. If multiple `select` cases are ready, do not rely on their order.
Waiting on a mutex, file I/O or network I/O is not durable blocking.
If the outside event that would unblock it never arrives, the test may hang until its overall timeout instead of quickly reporting deadlock.

## Common mistakes

1. **“PASS means no leak.”** The ordinary test checked only the price. Compare the two snapshots in the ordinary test and synctest sections; add the bubble test.
2. **“A buffer finishes all work.”** The real deadlock above showed the remaining sleeps. Make `quote` observe cancellation and have the caller call `cancel`.
3. **“cancel waits.”** It signals. Add waiting for strict completion; `synctest.Test` waits for all internal goroutines in the test.
4. **Forgetting `Close`.** The broken test above failed with a receive at `store.go:24`. Fix: `defer s.Close()`.
5. **`took == 50*time.Millisecond` with a real clock.** Execution can be delayed by system load. Keep exact equality for fake time inside a bubble.
6. **Thinking `synctest.Wait()` means all work finished.** It waits until the others have exited or become durably blocked. A blocked leak can still remain.
7. **Running `-race` without cgo.** Use an environment with a C compiler or the Docker script above. Race checking does not replace leak checking.

```go filename="solution/offer.go" showLineNumbers
package main

import (
	"context"
	"errors"
	"time"
)

// priceOffer — bitta yetkazib beruvchining olma uchun taklifi: qancha vaqtda javob beradi va qancha narx aytadi (tiyin).
type priceOffer struct {
	delay time.Duration
	price int64
}

// priceOffers: uch yetkazib beruvchi. Uchinchisi eng arzon, lekin juda sekin.
var priceOffers = []priceOffer{
	{100 * time.Millisecond, 1_250_000},
	{200 * time.Millisecond, 1_150_000},
	{3 * time.Second, 1_100_000},
}

// quoteTimeout: cheapestPrice takliflarni shuncha vaqtdan koʻp kutmaydi.
const quoteTimeout = time.Second

// errNoOffer: quoteTimeout ichida hech bir yetkazib beruvchi javob bermadi.
var errNoOffer = errors.New("hech bir yetkazib beruvchi vaqtida javob bermadi")

// askOffer bitta yetkazib beruvchidan taklif soʻraydi: o.delay oʻtguncha yoki ctx bekor qilinguncha kutadi.
func askOffer(ctx context.Context, o priceOffer) (int64, error) {
	select {
	case <-time.After(o.delay):
		return o.price, nil
	case <-ctx.Done():
		return 0, ctx.Err()
	}
}

// cheapestPrice hamma yetkazib beruvchidan birdan soʻraydi, quoteTimeout ichida kelgan takliflarning eng arzonini
// qaytaradi va qaytganda oʻzi boshlagan birorta goroutine'ni ham ortda qoldirmaydi.
func cheapestPrice(ctx context.Context) (int64, error) {
	tctx, cancel := context.WithTimeout(ctx, quoteTimeout)
	defer cancel()
	ch := make(chan int64, len(priceOffers))
	for _, o := range priceOffers {
		go func() {
			p, err := askOffer(tctx, o)
			if err == nil {
				ch <- p
			}
		}()
	}
	var best int64
	found := false
	take := func(p int64) {
		if !found || p < best {
			best, found = p, true
		}
	}
	for range priceOffers {
		select {
		case p := <-ch:
			take(p)
		case <-tctx.Done():
			if err := ctx.Err(); err != nil {
				return 0, err // chaqiruvchi bekor qildi yoki uning muddati tugadi
			}
			for len(ch) > 0 { // muddat bilan bir paytda kelib, buffer'da turgan javoblar
				take(<-ch)
			}
			if !found {
				return 0, errNoOffer
			}
			return best, nil
		}
	}
	return best, nil
}
```

New parts: 41–42 create a timed `tctx` from the caller's context and arrange cancellation.
43–51 provide a goroutine per offer and enough buffer space; 52–53 hold the `best` price and `found` flag.
54–58 define `take`, an anonymous function that keeps the lowest price. `!found` allows zero to be a valid offer too.
59–62 collect each expected reply. 63–66 distinguish the parent context's error from the operation's own deadline.
67–69 also take replies already in the buffer. This does not add an ordering guarantee for all simultaneous events.
70–76 return the no-offer error or the lowest price. Other lines are familiar blocks and the supplied helpers.
