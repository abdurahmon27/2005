## Nimani oʻrganasiz

Bozor uch yetkazib beruvchidan olma narxini birdan soʻraydi. Eng tez javob olinadi, test oʻtadi, lekin har chaqiruv ikkita goroutine qoldiradi. Buni qanday ushlaysiz?

**Bitta gʻoya:** natijani tekshirish yetmaydi; boshlangan goroutine qanday tugashini ham tekshiring. `testing/synctest` ajratilgan test muhitida kutishni va soxta vaqtni boshqaradi.

Darsdan keyin siz:

- goroutine leak'ni sanab, profil orqali kutayotgan qatorni topasiz;
- oddiy test koʻrmagan xatoni `synctest.Test` bilan ushlaysiz;
- sekin ishlarni context orqali bekor qilasiz;
- 50 ms muddatni taxminsiz tekshirasiz va unutilgan `Close`ni topasiz.

| Soʻz | Oddiy maʼnosi | English term |
|---|---|---|
| goroutine leak | tugashi kerak boʻlsa ham abadiy kutayotgan goroutine | goroutine leak |
| pufak | test va uning ichida boshlangan goroutine'lar uchun ajratilgan muhit | bubble |
| soxta soat | kutish tugaydigan paytga haqiqiy kutishsiz suriladigan soat | fake clock |

## Bitta javob, ikkita qolgan goroutine

Avval xatoli nusxa. `prices` — ID boʻyicha tiyin narxi; `supplierDelays` — uch yetkazib beruvchining javob vaqti.
`quote` haqiqiy tarmoq oʻrniga kutishni taqlid qiladi.

```go filename="_video/01-leak/price.go" showLineNumbers
package main

import "time"

// prices: yetkazib beruvchilar aytadigan narx, tiyinda (ID → tiyin): olma 1, non 2, oʻrik 3.
var prices = map[int64]int64{1: 1_200_000, 2: 500_000, 3: 3_000_000}

// supplierDelays: uch yetkazib beruvchining (chorsu, oloy, siyob) javob vaqti.
var supplierDelays = []time.Duration{
	100 * time.Millisecond,
	200 * time.Millisecond,
	300 * time.Millisecond,
}

func quote(delay time.Duration, id int64) int64 {
	time.Sleep(delay)
	return prices[id]
}

func fastestPrice(id int64) int64 {
	ch := make(chan int64)
	for _, d := range supplierDelays {
		go func() {
			ch <- quote(d, id)
		}()
	}
	return <-ch
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1, 3 | `package main`, `import "time"` | bajariladigan paket va vaqt paketi |
| 5–6 | `prices` | izoh va `map[int64]int64`; ID 1 narxi 1 200 000 tiyin, yaʼni 12 000 soʻm |
| 8–13 | `supplierDelays` | izoh va `[]time.Duration` slice'i; `*` koʻpaytirish, oxirgi vergul koʻp qatorli literal uchun |
| 15–18 | `quote` | `delay` va `id` parametrlarini oladi, uxlaydi, map qiymatini qaytaradi |
| 20–21 | `fastestPrice`, `make(chan int64)` | funksiya va buffer'siz natija channel'i |
| 22 | `for _, d := range` | indeksni `_` bilan tashlaydi; har aylanishda yangi `d` |
| 23 | `go func() {` | nomsiz funksiyani alohida goroutine'da boshlaydi |
| 24 | `ch <- quote(d, id)` | oldin narxni hisoblaydi, keyin yuborishga urinadi |
| 25–26 | `}()`, `}` | nomsiz funksiyani chaqiradi va siklni yopadi |
| 27–28 | `return <-ch`, `}` | bitta narxni qabul qilib, funksiyadan qaytadi |

Boʻsh qatorlar kodni ajratadi; `//` qatorlari izoh. `{}` blok chegaralari, `:=` yangi oʻzgaruvchi yaratish.

```go filename="_video/01-leak/main.go" showLineNumbers
package main

import (
	"fmt"
	"runtime"
	"time"
)

func main() {
	for range 3 {
		for range 100 {
			fastestPrice(1)
		}
		time.Sleep(time.Second)
		fmt.Println("goroutine'lar:", runtime.NumGoroutine())
	}
}
```

`main.go`: 1-qator paket; 3–7 paketlar; 9 funksiya; 10 tashqi sikl; 11–13 yuz chaqiruv; 14 bir soniya kutish.
15-qator `fmt.Println` bilan barcha tirik goroutine'lar sonini chiqaradi; 16–17 bloklarni yopadi.
`for range 3` hisoblagich kerak boʻlmagan uch aylanishdir.

**Bashorat:** 300 chaqiruvdan keyin nechta goroutine? **A)** 1 · **B)** 301 · **C)** 601.

A barcha ish tugaydi deb taxmin qiladi; B har chaqiruvda faqat bitta goroutine qoladi deb sanaydi.

</details>

|---|---|---|---|---|
| 0 ms | kutadi | kutadi | kutadi | `<-ch` |

## Profil: qaysi qatorda kutyapti?

Sanoq oʻsishni koʻrsatadi. **Profil** goroutine'larning steklarini, yaʼni funksiya chaqiruvlari izini koʻrsatadi.
Keyingi nusxada `main` oxiriga bitta chaqiruv qoʻshilgan:

```go filename="_video/02-profil/main.go" showLineNumbers
package main

import (
	"fmt"
	"os"
	"runtime"
	"runtime/pprof"
	"time"
)

func main() {
	for range 3 {
		for range 100 {
			fastestPrice(1)
		}
		time.Sleep(time.Second)
		fmt.Println("goroutine'lar:", runtime.NumGoroutine())

	pprof.Lookup("goroutine").WriteTo(os.Stdout, 1)
```

## Oddiy test leak'ni tekshirmaydi

```go filename="_video/03-test/price_test.go" showLineNumbers
package main

import "testing"

func TestFastestPrice(t *testing.T) {
	got := fastestPrice(1)
	if got != 1_200_000 {
		t.Errorf("fastestPrice(1) = %d; kutilgan 1200000", got)
```

## synctest: test tugadi, lekin ish qoldi

`testing/synctest` Go 1.25'dan beri eksperiment bayrogʻisiz mavjud. U testni **pufak** ichida bajaradi.
Bu ajratilgan test muhiti: ichida boshlangan goroutine'lar ham unga tegishli. `synctest.Test` ularning hammasi chiqishini kutadi.

**Barqaror bloklanish** (*durably blocked*) — goroutine'ni faqat shu pufakdagi ish uygʻota oladigan kutish.
Pufakda yaratilgan channel'dagi kutish va `time.Sleep` bunga kiradi.
Barcha goroutine'lar shunday kutsa, soat keyingi uygʻonish paytiga suriladi. Boshlangʻich vaqt: `2000-01-01 00:00:00 UTC`.
Pufakning asosiy funksiyasi chiqqach, soat surilmaydi. Uygʻonadigan ish boʻlmasa va kutish qolsa, deadlock yuz beradi.

```go filename="_video/04-synctest/price_test.go" showLineNumbers
package main

import (
	"testing"
	"testing/synctest"
)

func TestFastestPrice(t *testing.T) {
	synctest.Test(t, func(t *testing.T) {
		got := fastestPrice(1)
		if got != 1_200_000 {
			t.Errorf("fastestPrice(1) = %d; kutilgan 1200000", got)
		}
	})
}
```

Yangi 5-qator paketni oladi; 9-qator tashqi `t` va oʻz `t` parametrini oladigan nomsiz funksiyani beradi.
10–13 tekshiruv oʻsha; 14–15 pufak va testni yopadi.

**Bashorat:** **A)** PASS · **B)** FAIL: deadlock · **C)** 300 ms kutib PASS.

<details>
<summary>Javob</summary>

**B.** 100 ms soxta vaqtda narx keladi. Test funksiyasi qaytadi, soat toʻxtaydi; ikki goroutine hali uxlayapti.
A faqat narxni hisobga oladi. C soat test funksiyasi chiqqach ham yuradi deb oʻylaydi.

</details>

## Buffer kutishni bekor qilmaydi

Birinchi urinish: `_video/05-buffer/price.go`da faqat channel yaratilishi oʻzgaradi:

```go
ch := make(chan int64, len(supplierDelays))
```

`len(supplierDelays)` uchta oʻrin beradi. Har goroutine bittadan javob yuboradi, shuning uchun keyinchalik yuborishda tiqilmaydi.

**Bashorat:** **A)** PASS · **B)** oʻsha deadlock · **C)** narx notoʻgʻri.

## Context bilan qolgan ishni toʻxtatish

Dars papkasidagi yakuniy `price.go`:

```go filename="price.go" showLineNumbers
// bozor: bitta mahsulot narxini uch yetkazib beruvchidan birdan soʻrab, eng tez javobni olish (GB-7.06).
// Videoning oxiridagi holat: goroutine'lar fastestPrice bilan birga tugaydi (ctx + cancel), leak yoʻq.
package main

import (
	"context"
	"time"
)

// prices: yetkazib beruvchilar aytadigan narx, tiyinda (ID → tiyin): olma 1, non 2, oʻrik 3.
var prices = map[int64]int64{1: 1_200_000, 2: 500_000, 3: 3_000_000}

// supplierDelays: uch yetkazib beruvchining (chorsu, oloy, siyob) javob vaqti.
var supplierDelays = []time.Duration{
	100 * time.Millisecond,
	200 * time.Millisecond,
	300 * time.Millisecond,
}

// quote bitta yetkazib beruvchidan narx soʻrashni taqlid qiladi: delay oʻtguncha yoki ctx bekor qilinguncha kutadi.
func quote(ctx context.Context, delay time.Duration, id int64) (int64, error) {
	select {
	case <-time.After(delay):
		return prices[id], nil
	case <-ctx.Done():
		return 0, ctx.Err()
	}
}

// fastestPrice hamma yetkazib beruvchidan birdan soʻraydi va birinchi kelgan javobni qaytaradi.
// Qaytishdan oldin cancel() qolgan soʻrovlarni toʻxtatadi: oʻzi boshlagan goroutine'lar uning bilan tugaydi.
func fastestPrice(ctx context.Context, id int64) (int64, error) {
	ctx, cancel := context.WithCancel(ctx)
	defer cancel()
	ch := make(chan int64, len(supplierDelays))
	for _, d := range supplierDelays {
		go func() {
			p, err := quote(ctx, d, id)
			if err == nil {
				ch <- p
			}
		}()
	}
	select {
	case p := <-ch:
		return p, nil
	case <-ctx.Done():
		return 0, ctx.Err()
	}
}
```

Oʻzgargan qatorlar:

| Qator | Nima qiladi |
|---|---|
| 5–8 | `context` va `time` paketlarini oladi |
| 21 | `quote` context oladi va `(int64, error)` qaytaradi |
| 22–28 | `select`: vaqt oʻtsa narx va `nil`; `Done` yopilsa 0 va `ctx.Err()` |
| 32–34 | `WithCancel` bola context yaratadi; `ctx` shu blokdagi parametrga qayta yoziladi, `cancel` yangi; `defer` qaytishda signal beradi |
| 35 | uch oʻrinli buffer saqlanadi |
| 36–43 | har goroutine bola context bilan soʻraydi; `p` narx, `err` xato; faqat `err == nil` boʻlsa yuboradi |
| 44–50 | birinchi narxni yoki chaqiruvchi bekor qilishini kutadi |

1–2, 10, 13, 20 va 30–31 — izohlar. Izohdagi «birga tugaydi» ni kutib qoʻshilish kafolati deb oʻqimang.
[`CancelFunc`](https://pkg.go.dev/context#CancelFunc) faqat signal beradi, ishning chiqishini kutmaydi.
Bu misolda qolgan goroutine'lar signalni koʻrib chiqadi; `synctest.Test` ularning chiqishini kutadi.
Chaqiruvchi qaytishidan oldin qatʼiy kutish kerak boʻlsa, [GB-7.01](/lab/youtube/gb/gb-7-01) kabi kutish guruhi kerak.
Buffer ham qoladi: vaqt va bekor qilish bir paytda tayyor boʻlsa, muvaffaqiyatli narx yuborilishi tiqilib qolmaydi.

| Bosqich | Natija |
|---|---|
| birinchi narx | `fastestPrice` qaytishni boshlaydi |
| `defer cancel()` | bola context'ning `Done` channel'i yopiladi |
| qolgan `quote` | bekor qilishni koʻradi, xato qaytaradi, yubormaydi |
| `synctest.Test` | barcha goroutine'lar chiqishini kutadi |

## Unutilgan Close: boshqa kutish, oʻsha xato

`store.go` — oldingi darsdagi qisqa `OwnedStore`. Mapʼga faqat egasi goroutine tegadi.

```go filename="store.go" showLineNumbers
package main

// OwnedStore — GB-7.05'dagi qoldiq doʻkoni (qisqartirilgan): stock map'iga faqat loop goroutine'i tegadi,
// Sell unga channel orqali soʻrov yuboradi. loop sells yopilganda (Close) tugaydi.
type OwnedStore struct {
	sells chan sellReq
}

// sellReq — egasiga yuboriladigan sotish soʻrovi: qaysi mahsulot, necha dona va javob qaytadigan channel.
type sellReq struct {
	id    int64
	n     int
	reply chan bool
}

// NewOwnedStore loop'ni yangi goroutine'da boshlaydi va stock map'ini unga topshiradi.
func NewOwnedStore(stock map[int64]int) *OwnedStore {
	s := &OwnedStore{sells: make(chan sellReq)}
	go s.loop(stock)
	return s
}

func (s *OwnedStore) loop(stock map[int64]int) {
	for r := range s.sells {
		ok := stock[r.id] >= r.n
		if ok {
			stock[r.id] -= r.n
		}
		r.reply <- ok
	}
}

// Sell id'li mahsulotdan n dona sotadi; qoldiq yetmasa false.
func (s *OwnedStore) Sell(id int64, n int) bool {
	reply := make(chan bool)
	s.sells <- sellReq{id, n, reply}
	return <-reply
}

// Close loop goroutine'ini toʻxtatadi. Close'dan keyin Sell chaqirilmaydi.
func (s *OwnedStore) Close() { close(s.sells) }
```

5–7 soʻrov channel'ini saqlaydi; 10–14 soʻrovning `id`, miqdor `n` va javob channel'i `reply`.
17–21 doʻkonni yaratib, map'ni `loop`ga beradi. 23–31 soʻrovlarni ketma-ket oladi, qoldiq yetsa kamaytiradi, javob yuboradi.
34–38 `Sell` soʻrov yuborib, javob oladi. 41-qator `Close` soʻrov channel'ini yopadi.
`>=` yetarlilikni solishtiradi; `-=` kamaytiradi; `&` manzil oladi; `*OwnedStore` pointer qabul qiluvchidir.

## Koʻp uchraydigan xatolar

1. **«PASS — leak yoʻq».** Oddiy test narxnigina tekshirdi. «Oddiy test» va «synctest» boʻlimlaridagi ikki nusxani solishtiring; pufakdagi testni qoʻshing.
2. **«Buffer hamma ishni tugatadi».** Yuqoridagi haqiqiy deadlock qolgan uyqularni koʻrsatdi. `quote` bekor qilishni kuzatsin, chaqiruvchi `cancel` qilsin.
3. **«cancel kutadi».** U signal beradi. Qatʼiy yakunlanish uchun kutish qoʻshing; testda `synctest.Test` barcha ichki goroutine'larni kutadi.
4. **`Close`ni unutish.** Yuqoridagi xatoli test `store.go:24`da receive bilan yiqildi. Tuzatish: `defer s.Close()`.
5. **Haqiqiy soatda `took == 50*time.Millisecond`.** Muhit yukiga qarab kechikadi. Aniq tenglikni pufakdagi soxta vaqt uchun saqlang.
6. **`synctest.Wait()` barcha ish tugadi degani.** U boshqalar chiqqan yoki barqaror bloklangan holatga yetishini kutadi. Bloklangan leak hali qolishi mumkin.
7. **`-race`ni cgoʼsiz ishlatish.** C kompilyatori mavjud muhit yoki yuqoridagi Docker skriptidan foydalaning. Race tekshiruvi leak tekshiruvini almashtirmaydi.

```go filename="solution/offer.go" showLineNumbers
package main

import (
	"context"
	"errors"
	"time"
)

// priceOffer — bitta yetkazib beruvchining olma uchun taklifi: qancha vaqtda javob beradi va qancha narx aytadi (tiyin).
type priceOffer struct {
	delay time.Duration
	price int64
}

// priceOffers: uch yetkazib beruvchi. Uchinchisi eng arzon, lekin juda sekin.
var priceOffers = []priceOffer{
	{100 * time.Millisecond, 1_250_000},
	{200 * time.Millisecond, 1_150_000},
	{3 * time.Second, 1_100_000},
}

// quoteTimeout: cheapestPrice takliflarni shuncha vaqtdan koʻp kutmaydi.
const quoteTimeout = time.Second

// errNoOffer: quoteTimeout ichida hech bir yetkazib beruvchi javob bermadi.
var errNoOffer = errors.New("hech bir yetkazib beruvchi vaqtida javob bermadi")

// askOffer bitta yetkazib beruvchidan taklif soʻraydi: o.delay oʻtguncha yoki ctx bekor qilinguncha kutadi.
func askOffer(ctx context.Context, o priceOffer) (int64, error) {
	select {
	case <-time.After(o.delay):
		return o.price, nil
	case <-ctx.Done():
		return 0, ctx.Err()
	}
}

// cheapestPrice hamma yetkazib beruvchidan birdan soʻraydi, quoteTimeout ichida kelgan takliflarning eng arzonini
// qaytaradi va qaytganda oʻzi boshlagan birorta goroutine'ni ham ortda qoldirmaydi.
func cheapestPrice(ctx context.Context) (int64, error) {
	tctx, cancel := context.WithTimeout(ctx, quoteTimeout)
	defer cancel()
	ch := make(chan int64, len(priceOffers))
	for _, o := range priceOffers {
		go func() {
			p, err := askOffer(tctx, o)
			if err == nil {
				ch <- p
			}
		}()
	}
	var best int64
	found := false
	take := func(p int64) {
		if !found || p < best {
			best, found = p, true
		}
	}
	for range priceOffers {
		select {
		case p := <-ch:
			take(p)
		case <-tctx.Done():
			if err := ctx.Err(); err != nil {
				return 0, err // chaqiruvchi bekor qildi yoki uning muddati tugadi
			}
			for len(ch) > 0 { // muddat bilan bir paytda kelib, buffer'da turgan javoblar
				take(<-ch)
			}
			if !found {
				return 0, errNoOffer
			}
			return best, nil
		}
	}
	return best, nil
}
```

Yangi qismlar: 41–42 chaqiruvchi context'idan muddatli `tctx` yaratadi va bekor qilishni rejalaydi.
43–51 har taklif uchun goroutine va yetarli buffer; 52–53 `best` narx va `found` belgisi.
54–58 `take` nomsiz funksiya eng kichik narxni saqlaydi. `!found` nol narxni ham haqiqiy taklif sifatida saqlashga imkon beradi.
59–62 har kutilgan javobni yigʻadi. 63–66 ota context xatosini oʻz muddatidan ajratadi.
67–69 buffer'da allaqachon turgan javoblarni ham oladi. Bu barcha bir vaqtdagi hodisalarga yangi tartib kafolati bermaydi.
70–76 javob yoʻq xatosi yoki eng arzon narxni qaytaradi. Qolgan qatorlar tanish bloklar va oldingi tayyor yordamchilardir.
