## Nimani oʻrganasiz

GB-2.03'da buyurtma summasini `orderTotal` funksiyasi hisoblardi. Endi buyurtmaga qator qoʻshish va uni toʻlangan deb belgilash
kerak. Bu amallar buyurtmani **oʻzgartiradi**, oʻzgarish esa yoʻqolmasligi shart. Bu amallarni qayerga yozasiz, va nega xuddi
shunday yozilgan bitta metod buyurtmani oʻzgartiradi, boshqasi esa oʻzgartirmaydi, kompilyator esa ikkalasiga ham jim?

**Bitta gʻoya:** metod — nomidan oldin receiver yozilgan funksiya. Receiver oddiy parametr kabi nusxalanadi: value receiver
(`o Order`) qiymatning nusxasini oladi va unga yozilgan oʻzgarish metod bilan birga yoʻqoladi; pointer receiver (`o *Order`)
manzilni oladi va asl qiymatga yozadi. Oddiy oʻzgaruvchida `order.Pay()` deb yozsangiz, Go `&order`ni oʻzi qoʻyadi.

Dars oxirida siz:

- `Order` turiga `Total`, `Pay` va `AddItem` metodlarini yozasiz va `order.Total()` deb chaqirasiz;
- value receiver nusxani, pointer receiver manzilni olishini xotira rasmida koʻrasiz;
- value receiver'dagi yoʻqolgan oʻzgarishni natijadan topasiz (kompilyator ham, `go vet` ham jim) va bitta belgi bilan tuzatasiz;
- receiver turini qoida boʻyicha tanlaysiz;
- int asosidagi `OrderStatus` turiga `String()` metodini yozasiz va `fmt` holatni nomi bilan chiqarishini koʻrasiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| metod | turga bogʻlangan funksiya; `func (o Order) Total() int64 { … }` deb eʼlon qilinadi, `order.Total()` deb chaqiriladi | method |
| receiver | metod ishlaydigan qiymat; `func` bilan metod nomi orasida qavsda yoziladi. `o Order` — nusxa (**value receiver**), `o *Order` — manzil (**pointer receiver**) | receiver |
| receiver tanlash qoidasi | qiymatni oʻzgartirsa yoki struct katta boʻlsa — pointer; bitta tur — bitta xil receiver; kichik, oʻzgarmas qiymat — value | choosing a receiver |

Ikkita yordamchi tushuncha: `String()` metodi (`fmt` sonning oʻrniga holat nomini chiqaradi) va «kompilyator ham, `go vet` ham jim»
turidagi xato (`go vet` — Go'ning standart tekshiruvchisi, u joriy papkadagi kodda shubhali joylarni qidiradi).

## Metod: turga bogʻlangan funksiya

GB-2.03'da summani funksiya hisoblardi: `func orderTotal(o Order) int64`. Buyurtma amallari — summa, toʻlash, qator qoʻshish —
`Order`ga tegishli. Ularni `Order` turiga bogʻlash mumkin: bunday funksiya **metod** (*method*) deyiladi. Birinchi metod — `Total`
(`orderTotal`ning oʻzi, faqat boshqacha eʼlon qilingan). Dasturning toʻliq matni (`_video/01-total/main.go`):

```go filename="_video/01-total/main.go" showLineNumbers
package main

import "fmt"

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

// OrderItem — buyurtmadagi bitta qator.
type OrderItem struct {
	ProductID int64
	Price     int64 // tiyin, buyurtma paytidagi narx
	Quantity  int
}

// Order — bitta buyurtma.
type Order struct {
	ID     int64
	Items  []OrderItem
	Status OrderStatus
}

// OrderStatus — buyurtma holati.
type OrderStatus int

const (
	StatusNew OrderStatus = iota
	StatusPaid
	StatusShipped
	StatusCancelled
)

// Total buyurtma summasini tiyinda qaytaradi.
func (o Order) Total() int64 {
	var total int64
	for _, it := range o.Items {
		total += it.Price * int64(it.Quantity)
	}
	return total
}

func main() {
	olma := Product{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40}
	order := Order{
		ID: 1,
		Items: []OrderItem{
			{ProductID: olma.ID, Price: olma.Price, Quantity: 3},
		},
	}
	fmt.Println(order.Total())
}
```

1–35-qatorlar GB-2.03'dagi turlar (`Product`, `OrderItem`, `Order`, `OrderStatus` va holatlar), ular oʻzgarmagan. Yangi qatorlar:

| Qator | Kod | Nima qiladi |
|---|---|---|
| 38 | `func (o Order) Total() int64 {` | `func`dan keyin qavs ichida `o Order` — **receiver** (*receiver*): metod ishlaydigan qiymat. Keyin metod nomi `Total`, boʻsh qavs (parametr yoʻq) va natija turi `int64`. Metod nomi ham katta harf bilan: sababini [GB-2.06](/lab/youtube/gb/gb-2-06)'da ochamiz |
| 39 | `var total int64` | `total` noldan boshlanadi (zero value) |
| 40 | `for _, it := range o.Items {` | receiver tana ichida oddiy parametr kabi ishlatiladi: `o.Items` — buyurtmaning qatorlari; `it` — bitta qator |
| 41 | `total += it.Price * int64(it.Quantity)` | har qatorda narx dona soniga koʻpaytirilib `total`ga qoʻshiladi. Bu yerdagi `*` — koʻpaytirish |
| 43 | `return total` | yigʻilgan summani qaytaradi |
| 54 | `fmt.Println(order.Total())` | metod `order.Total()` deb, boʻsh qavslar bilan chaqiriladi |

Chaqiruvda nuqtadan oldingi `order` receiver `o`ga tushadi. Funksiyada qiymat qavs ichida turardi (`orderTotal(order)`),
metodda u nuqtadan oldin turadi (`order.Total()`). Nima chiqadi?

**A)** `3600000` · **B)** `1200000` · **C)** kompilyatsiya xatosi

<details>
<summary>Javob</summary>

**A: `3600000`.** Buyurtmada bitta qator: narx 1 200 000 tiyin, 3 dona. Sikl bir marta aylanadi: `0 + 1 200 000 × 3 = 3 600 000`.
**B** ni tanlagan boʻlsangiz, dona sonini hisobga olmagansiz. **C** — `Total` shu turga eʼlon qilingan, `order.Total()` toʻgʻri chaqiruv.

```console
$ ./_video/run.sh 01-total go run .

```

3 600 000 tiyin — 36 000 soʻm.

</details>

## Value receiver: Pay nusxani oʻzgartiradi

Endi buyurtmani oʻzgartiradigan metod — `Pay`, toʻlash. `_video/02-pay-value/main.go` shu tur va holatlar bilan, yangi qismi:

```go
// Pay buyurtmani toʻlangan deb belgilaydi.
func (o Order) Pay() {
	o.Status = StatusPaid
}

func main() {
	var order Order
	order.Pay()
	fmt.Println(order.Status)
}
```

| Kod | Nima qiladi |
|---|---|
| `func (o Order) Pay() {` | receiver yana `o Order`. Natija turi yoʻq, shuning uchun qavsdan keyin darhol `{` |
| `o.Status = StatusPaid` | holatga `StatusPaid` yoziladi; uning qiymati 1 (`iota`, GB-2.03) |
| `var order Order` | boʻsh buyurtma: `ID` 0, `Items` `nil`, `Status` 0 (zero value) |
| `order.Pay()` | buyurtmani toʻlaymiz |
| `fmt.Println(order.Status)` | holatning **sonini** yozadi (nomini emas: `String` metodi hali yoʻq) |

Nima chiqadi?

**A)** `1` · **B)** `0` · **C)** kompilyatsiya xatosi

<details>
<summary>Javob</summary>

**B: `0`.** Kompilyator xato bermadi, dastur ishladi, lekin holat oʻzgarmadi. Sababi quyidagi xotira rasmida. **A** ni tanlagan
boʻlsangiz, `order.Pay()` `order`ni oʻzgartiradi deb oʻylagansiz: bu pointer receiver'da toʻgʻri, bu yerda emas. **C** — kod toʻgʻri
tuzilgan, kompilyator ikkala yozuvni ham qabul qiladi.

```console
$ ./_video/run.sh 02-pay-value go run .
0
```

</details>

Xotirada, qadamma-qadam:

| Qadam | Kod | `order` | `o` | Ekran |
|---|---|---|---|---|
| 1 | `var order Order` | `ID 0 · Items nil · Status 0` | — | |
| 2 | `order.Pay()` chaqirildi: receiver `o` yangi oʻzgaruvchi boʻlib yaratiladi | `ID 0 · Items nil · Status 0` | `order`ning **toʻliq nusxasi**: `ID 0 · Items nil · Status 0` | |
| 3 | `o.Status = StatusPaid` | `Status 0` | `Status 1` | |
| 4 | `Pay` tugadi: `o` yoʻqoladi | `Status 0` | — | |
| 5 | `fmt.Println(order.Status)` | `Status 0` | — | `0` |

Receiver oddiy parametr kabi ishlaydi: `sell`dagi `p` kabi, `o`ga `order`ning nusxasi tushadi. `Pay` nusxaga `1` yozdi, metod
tugagach nusxa yoʻqoldi, `order`da esa `0` qoldi. **Value receiver** (*value receiver*) — `o Order` shaklidagi receiver: u qiymatning
nusxasini oladi, nusxaga yozilgan oʻzgarish metod bilan birga yoʻqoladi.

## Pointer receiver: Pay asl qiymatni oʻzgartiradi

Tuzatish bitta belgi: receiver turi `*Order`. `_video/03-pay-pointer/main.go`:

```go
// Pay buyurtmani toʻlangan deb belgilaydi.
func (o *Order) Pay() {
	o.Status = StatusPaid
}

func main() {
	var order Order
	order.Pay()
	fmt.Println(order.Status)
}
```

Faqat `func (o *Order) Pay()` qatori oʻzgardi. `*Order` — `Order` manzilining turi (GB-2.04). Bunday receiver **pointer receiver**
(*pointer receiver*): metod `order`ning nusxasini emas, **manzilini** oladi. `main` oʻzgarmadi: `order` hamon oddiy oʻzgaruvchi,
pointer emas, chaqiruv ham `order.Pay()`, `&` yoʻq. Bu kod kompilyatsiya boʻladimi, boʻlsa nima chiqadi?

**A)** `1` · **B)** `0` · **C)** kompilyatsiya xatosi: `&order` kerak

<details>
<summary>Javob</summary>

**A: `1`.** Kod kompilyatsiya boʻladi va holat oʻzgardi: Go `order.Pay()`ni oʻzi `(&order).Pay()` ga aylantiradi. **B** — bu oldingi
variant (value receiver) natijasi: pointer receiver nusxa emas, manzil oladi. **C** — GB-2.04'da funksiyaga manzilni oʻzingiz
berardingiz (`sell(&olma, 3)`), metodda esa oʻzgaruvchi boʻlsa, Go buni oʻzi qiladi.

```console
$ ./_video/run.sh 03-pay-pointer go run .
1
```

</details>

Xotirada:

| Qadam | Kod | `order` | `o` | Ekran |
|---|---|---|---|---|
| 1 | `var order Order` | `ID 0 · Items nil · Status 0` | — | |
| 2 | `order.Pay()`: Go uni `(&order).Pay()` deb chaqiradi | `ID 0 · Items nil · Status 0` | — | |
| 3 | receiver `o` — `order`ning **manzili** (nusxa yoʻq) | `ID 0 · Items nil · Status 0` | `&order` ↦ `order` | |
| 4 | `o.Status = StatusPaid`: manzil boʻylab `order`ning oʻziga yoziladi (GB-2.04'dagidek) | `Status 1` | `&order` ↦ `order` | |
| 5 | `fmt.Println(order.Status)` | `Status 1` | — | `1` |

```text
order ──► ┌───────────────────────────────┐
          │ ID 0 · Items nil · Status 1   │
          └───────────────────────────────┘
               ▲
   o ──────────┘   (o — manzil; o.Status = … shu qiymatga yozadi)
```

`order.Pay()` qisqa yozuv, Go uni `(&order).Pay()` qiladi. Bu qoida `order` oddiy oʻzgaruvchi boʻlgani uchun ishlaydi, uning manzilini
olish mumkin ([Go spec: Calls](https://go.dev/ref/spec#Calls): `x` shunday oʻzgaruvchi boʻlsa, `x.m()` — `(&x).m()` qisqartmasi).
Xuddi shu chaqiruvni toʻliq yozsangiz ham natija bir xil:

```go
var order Order
(&order).Pay()
fmt.Println(order.Status)
```

```console
$ go run .
1
```

(Bu dastur kurs papkasida yoʻq: u `_video/03-pay-pointer/main.go` ning toʻliq nusxasi, faqat `order.Pay()` qatori `(&order).Pay()` ga
almashtirilgan.)

## AddItem: append natijasini pointer orqali saqlash

Asosiy metod — `AddItem`, buyurtmaga qator qoʻshish. U `Items`ni oʻzgartiradi, demak receiver pointer. `_video/04-additem/main.go`
(1–35-qatorlar — oldingi turlar, ular koʻrsatilmadi):

```go filename="_video/04-additem/main.go" showLineNumbers
package main

import "fmt"

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

// OrderItem — buyurtmadagi bitta qator.
type OrderItem struct {
	ProductID int64
	Price     int64 // tiyin, buyurtma paytidagi narx
	Quantity  int
}

// Order — bitta buyurtma.
type Order struct {
	ID     int64
	Items  []OrderItem
	Status OrderStatus
}

// OrderStatus — buyurtma holati.
type OrderStatus int

const (
	StatusNew OrderStatus = iota
	StatusPaid
	StatusShipped
	StatusCancelled
)

// AddItem buyurtmaga qator qoʻshadi; narx mahsulotdan nusxalanadi.
func (o *Order) AddItem(p Product, quantity int) {
	item := OrderItem{ProductID: p.ID, Price: p.Price, Quantity: quantity}
	o.Items = append(o.Items, item)
}

// Total buyurtma summasini tiyinda qaytaradi.
func (o Order) Total() int64 {
	var total int64
	for _, it := range o.Items {
		total += it.Price * int64(it.Quantity)
	}
	return total
}

func main() {
	olma := Product{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40}
	non := Product{ID: 2, Name: "non", Price: 400_000, Stock: 100}
	var order Order
	order.AddItem(olma, 3)
	order.AddItem(non, 2)
	fmt.Println(len(order.Items), order.Total())
}
```

`Total` oʻzgarmadi. Yangi qatorlar:

| Qator | Kod | Nima qiladi |
|---|---|---|
| 38 | `func (o *Order) AddItem(p Product, quantity int) {` | pointer receiver: `Items` oʻzgaradi. Receiver'dan keyin oddiy parametrlar: mahsulot `p` (turi `Product`) va dona soni `quantity` |
| 39 | `item := OrderItem{…}` | `p`dan ID va narx olinadi: narx buyurtma paytidagidek qatorda saqlanadi (GB-2.03) |
| 40 | `o.Items = append(o.Items, item)` | `append` yangi slice sarlavhasini qaytaradi ([GB-2.01](/lab/youtube/gb/gb-2-01)); natija `o.Items`ga saqlanadi. Receiver pointer, shuning uchun bu `order`ning oʻzi |
| 54 | `non := Product{…}` | ikkinchi mahsulot: non, narxi 400 000 tiyin |
| 56–57 | `order.AddItem(olma, 3)`, `order.AddItem(non, 2)` | olma 3 dona va non 2 dona qoʻshiladi |
| 58 | `fmt.Println(len(order.Items), order.Total())` | qatorlar soni va summa |

Taxmin qiling: qatorlar soni va summa nima boʻladi?

**A)** `2 4400000` · **B)** `0 0` · **C)** `2 3600000`

<details>
<summary>Javob</summary>

**A: `2 4400000`.** Ikki qator: olma `1 200 000 × 3 = 3 600 000` va non `400 000 × 2 = 800 000`; yigʻindisi `4 400 000` tiyin (44 000 soʻm).
**B** — pointer receiver boʻlmasa shunday chiqardi, pastdagi «Koʻp uchraydigan xatolar»da koʻramiz. **C** — nonni hisobga olmagansiz.

```console
$ ./_video/run.sh 04-additem go run .
2 4400000
```

</details>

`Total`ning receiver'i hali value: u faqat oʻqiydi, shuning uchun nusxa unga xalal bermadi.

## Receiver tanlash qoidasi

Ikki xil receiver bor. Qaysi birini yozasiz? Toʻrtta qoida ([Go FAQ](https://go.dev/doc/faq#methods_on_values_or_pointers) va
[Go Code Review Comments: Receiver Type](https://go.dev/wiki/CodeReviewComments#receiver-type)):

| # | Qoida | Misol |
|---|---|---|
| 1 | Metod qiymatni oʻzgartirsa — **pointer receiver** | `Pay`, `AddItem` |
| 2 | Struct katta boʻlsa (masalan, oʻnlab maydon) — ham pointer: har chaqiruvda butun struct nusxalansa, qimmat | — |
| 3 | Bitta turning hamma metodlari bir xil receiver oladi | `Order`: `Pay`, `AddItem` pointer, demak `Total` ham pointer |
| 4 | Kichik va oʻzgarmaydigan qiymat — **value receiver** | `OrderStatus` |

`Order`da `Pay` va `AddItem` pointer receiver oladi, uchinchi qoida boʻyicha `Total` ham. Uning tanasi oʻzgarmaydi: pointer orqali ham
`o.Items` oʻqiladi. Uchala metodning sarlavhasi:

```go
func (o *Order) Total() int64 { … }
func (o *Order) Pay() { … }
func (o *Order) AddItem(p Product, quantity int) { … }
```

(`{ … }` — sahifada tana qisqartirilgan; toʻliq matn `main.go`'da.) Savol. `Product`ga uchta metod yozmoqchimiz: `InStock` — qoldiq
bormi deydi, `Sell` — sotilgan sonni `Stock`dan ayiradi, `PriceSom` — narxni soʻmda qaytaradi. Qaysilari pointer receiver oladi?

**A)** faqat `Sell` · **B)** `Sell` va `InStock` · **C)** uchalasi ham

<details>
<summary>Javob</summary>

**C: uchalasi ham.** `Sell` `Stock`ni oʻzgartiradi, shuning uchun unga pointer receiver kerak (birinchi qoida). `InStock` va
`PriceSom` faqat oʻqiydi, lekin uchinchi qoida boʻyicha bitta turning hamma metodlari bir xil receiver oladi. **A** ni tanlagan boʻlsangiz,
faqat birinchi qoidani qoʻllagansiz; **B** — oʻqiydigan metodlarning bir qismini ajratgansiz, qoida esa hammasini birga qoldiradi.

</details>

`OrderStatus` esa kichik (bitta `int`) va oʻzgarmaydi, shuning uchun unga value receiver yetadi: keyingi boʻlimda.

## String: holatni nomi bilan chiqarish

Metod faqat struct'ga emas, oʻzingiz eʼlon qilgan istalgan turga yoziladi ([Go spec: Method declarations](https://go.dev/ref/spec#Method_declarations)).
`OrderStatus` GB-2.03'da `int` asosida eʼlon qilingan. Unga `String` metodi:

```go
// String holatning nomini qaytaradi; fmt uni oʻzi chaqiradi.
func (s OrderStatus) String() string {
	switch s {
	case StatusNew:
		return "yangi"
	case StatusPaid:
		return "toʻlangan"
	case StatusShipped:
		return "joʻnatilgan"
	case StatusCancelled:
		return "bekor qilingan"
	}
	return "nomaʼlum"
}
```

| Kod | Nima qiladi |
|---|---|
| `func (s OrderStatus) String() string {` | receiver `s`, turi `OrderStatus` — value receiver (kichik, oʻzgarmas qiymat). Natija turi `string` |
| `switch s {` | `s`ning qiymatiga qarab tarmoq tanlanadi (GB-1.05) |
| `case StatusNew:` + `return "yangi"` | holat `StatusNew` boʻlsa, nomini qaytaradi. Qolgan uch holat xuddi shunday yoziladi |
| `return "nomaʼlum"` | roʻyxatda yoʻq son kelsa (masalan, `OrderStatus(9)`) |

`fmt` qiymatda aynan `String` nomli, `string` qaytaradigan metod bor-yoʻqligini tekshiradi va boʻlsa, sonning oʻrniga uni chaqiradi
([pkg.go.dev/fmt](https://pkg.go.dev/fmt)). Buni `fmt` qanday tekshirishini [GB-2.07](/lab/youtube/gb#gb-2-07)'da, interface darsida ochamiz.
Yakuniy `main`:

```go
var order Order
order.AddItem(olma, 3)
order.AddItem(non, 2)
order.Pay()
fmt.Println(len(order.Items), order.Total(), order.Status)
```

Yangi qator bitta — `order.Pay()`. Oxirgi qiymat, holat, qanday chiqadi?

**A)** `2 4400000 1` · **B)** `2 4400000 toʻlangan` · **C)** `2 4400000 StatusPaid`

<details>
<summary>Javob</summary>

**B: `2 4400000 toʻlangan`.** `Println` `Status`da `String` metodini topdi va sonning oʻrniga nomini yozdi. **A** — `String` boʻlmaganda
shunday chiqardi (oldingi boʻlimlarda `0` va `1` ni shunday koʻrdingiz). **C** — `fmt` konstantaning kodda yozilgan nomini bilmaydi,
faqat `String` qaytargan matnni yozadi.

Papkadagi `main.go` — shu yakuniy kod:

```console
$ go run .
2 4400000 toʻlangan
```

</details>

Endi buyurtma amallari `Order`ning metodlari: `AddItem` va `Pay` oʻzgartiradi, `Total` oʻqiydi, holat esa nomi bilan chiqadi.

## Koʻp uchraydigan xatolar

**1. «Metod oʻzgaruvchini oʻzgartiradi» deb oʻylash.** Metod `order.` dan keyin chaqirilgani uchun `order`ni oʻzgartirgandek tuyuladi.
Aslida oʻzgartirish receiver turiga bogʻliq: `func (o Order) Pay()` nusxaga yozadi. Buni yuqorida koʻrdingiz (yuqoridagi «Value receiver: Pay nusxani oʻzgartiradi» boʻlimida
`0` chiqdi); tuzatish — `*Order`.

**2. `AddItem`da yulduzcha unutilgan.** Eng koʻp uchraydigan variant: `Pay` kabi ochiq-oydin emas, qator qoʻshish `append` bilan
yoziladi. `_video/05-xato/main.go`da `AddItem`ning receiver'i `o Order`, qolgan kod oʻsha. Faqat sarlavha qatori farq qiladi:

```go
func (o Order) AddItem(p Product, quantity int) {
	item := OrderItem{ProductID: p.ID, Price: p.Price, Quantity: quantity}
	o.Items = append(o.Items, item)
}
```

`main` oldingidek: olma 3, non 2, keyin `fmt.Println(len(order.Items), order.Total())`. Kompilyator buni ushlaydimi? Nima chiqadi?

```console
$ ./_video/run.sh 05-xato go run .
0 0
```

Qanday oʻqiladi: xato xabari yoʻq, dastur ishladi, lekin `len(order.Items)` ham, `Total()` ham nol. Har bir chaqiruv oʻz nusxasiga qator
qoʻshdi va nusxa bilan birga yoʻqotdi: nusxada `Items` sarlavhasi ham nusxa, `append` yangi sarlavhani faqat unga yozdi. `go vet` ham jim:

```console
$ ./_video/run.sh 05-xato go vet .
```

`go vet` hech narsa chiqarmadi (u shubhali joy topmasa jim turadi): kod Go qoidalariga toʻgʻri, mantiqiy xatoni u koʻrmaydi. Bu xatoni
kompilyator ham, `go vet` ham koʻrmaydi; uni natija yoki test ushlaydi. Tuzatish — receiver'ga yulduzcha: `func (o *Order) AddItem(…)`.
Ishda kod review'da shu savol beriladi: metod qiymatni oʻzgartiradimi, receiver'i pointermi?

**3. Siklda `it` nusxa ekanini unutish.** Xuddi shu qoida `for _, it := range` ichida ham ishlaydi: `it` — qatorning nusxasi, unga yozish
`Items`ga tegmaydi (bu xato vazifada ham uchraydi). Toʻliq dastur (kurs papkasida yoʻq):

```go
package main

import "fmt"

// OrderItem — buyurtmadagi bitta qator.
type OrderItem struct {
	ProductID int64
	Quantity  int
}

func main() {
	items := []OrderItem{{ProductID: 1, Quantity: 3}, {ProductID: 2, Quantity: 2}}
	for _, it := range items {
		it.Quantity += 1
	}
	fmt.Println(items[0].Quantity)
}
```

```console
$ go run .
3
```

Natija `4` emas, `3`. Bu yerda ham kompilyator va `go vet` jim. Tuzatish — qatorga indeks orqali yozish: `items[i].Quantity += 1` (`for i := range items`).

## Oʻzingizni tekshiring

**1.** Value receiver'li metod maydonga yozsa, uni chaqirgan oʻzgaruvchi oʻzgaradimi?

<details>
<summary>Javob</summary>

Yoʻq. Value receiver qiymatning nusxasini oladi, metod nusxaga yozadi va nusxa metod bilan birga yoʻqoladi (`Pay`ning `0` chiqargan varianti).

</details>

**2.** `Pay` pointer receiver'li, `order` esa oddiy oʻzgaruvchi (`var order Order`). `order.Pay()` deyish uchun `&order` yozish shartmi?

<details>
<summary>Javob</summary>

Yoʻq. `order` oʻzgaruvchi boʻlgani uchun Go `order.Pay()`ni oʻzi `(&order).Pay()` qiladi.

</details>

**3.** (GB-2.02) `map`ni `range` bilan aylanganda kalitlar tartibi kafolatlanadimi?

<details>
<summary>Javob</summary>

Yoʻq. Tartib kafolatlanmaydi, hatto bir dasturning ikki aylanishida ham har xil boʻlishi mumkin
([Go spec: For statements with range clause](https://go.dev/ref/spec#For_range)).

</details>

**4.** Quyidagi dastur nima chiqaradi? (`OrderStatus` GB-2.03'dagi kabi, unga yuqoridagi `String` metodi yozilgan.)

```go
fmt.Println(StatusShipped, OrderStatus(9), int(StatusPaid))
```

<details>
<summary>Javob</summary>

`joʻnatilgan nomaʼlum 1`. `StatusShipped`da `String` ishlaydi → `joʻnatilgan`; `OrderStatus(9)` — roʻyxatda yoʻq son, `String` `nomaʼlum`
qaytaradi; `int(StatusPaid)` — oddiy `int`ga aylantirilgan, unda `String` yoʻq, shuning uchun son: `1`. Toʻliq dastur (kurs papkasida yoʻq) turlar
va `String`dan iborat:

```go
package main

import "fmt"

// OrderStatus — buyurtma holati.
type OrderStatus int

const (
	StatusNew OrderStatus = iota
	StatusPaid
	StatusShipped
	StatusCancelled
)

// String holatning nomini qaytaradi; fmt uni oʻzi chaqiradi.
func (s OrderStatus) String() string {
	switch s {
	case StatusNew:
		return "yangi"
	case StatusPaid:
		return "toʻlangan"
	case StatusShipped:
		return "joʻnatilgan"
	case StatusCancelled:
		return "bekor qilingan"
	}
	return "nomaʼlum"
}

func main() {
	fmt.Println(StatusShipped, OrderStatus(9), int(StatusPaid))
}
```

```console
$ go run .
joʻnatilgan nomaʼlum 1
```

</details>

**1-qadam.** `for _, it := range o.Items { it.Quantity += quantity }` ishlamaydi: `it` — qatorning nusxasi (yuqoridagi 3-xato). Indeks bilan yoziladi.
`for i := range o.Items` faqat indeksni beradi: `i` = 0, 1, 2 …. Topilgach, qoʻshib `return` yoziladi: natija turi yoʻq metodda yolgʻiz `return`
metoddan shu yerda chiqadi, pastdagi `append`gacha yetmaydi:

```go
func (o *Order) AddItem(p Product, quantity int) {
	for i := range o.Items {
		if o.Items[i].ProductID == p.ID {
			o.Items[i].Quantity += quantity
			return
		}
	}
	item := OrderItem{ProductID: p.ID, Price: p.Price, Quantity: quantity}
	o.Items = append(o.Items, item)
}
```

func (o *Order) Cancel() error {
	if o.Status != StatusNew && o.Status != StatusPaid {
		return fmt.Errorf("buyurtma %d: holati «%v», bekor qilib boʻlmaydi", o.ID, o.Status)
	}
	o.Status = StatusCancelled
	return nil
}
