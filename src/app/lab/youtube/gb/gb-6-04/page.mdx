## Nimani oʻrganasiz

bozor parolni tekshiradi. Keyingi `GET /me`ni kim yuborganini qanday biladi? Logout eski cookie nusxasini qanday bekor qiladi?

**Bitta gʻoya:** session — serverdagi «shu token egasi shu foydalanuvchi, shu vaqtgacha» degan yozuv. Cookie tokenni olib yuradi; bazada faqat hash saqlanadi. Har himoyalangan soʻrov yozuvni tekshiradi.

Dars oxirida siz:

- tasodifiy token yaratib, faqat SHA-256 hashini saqlaysiz;
- middleware orqali foydalanuvchini soʻrov contextiga qoʻyasiz;
- muddat, qayta ishga tushirish va logoutni Postgres bilan tekshirasiz;
- hamma qurilmadan chiqish endpointini testlar oʻtguncha yozasiz.

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| session | foydalanuvchi, token va muddatni bogʻlovchi yozuv | session |
| session tokeni | kimlikni tasdiqlovchi tasodifiy sir | session token |
| sessionni bekor qilish | keyingi tekshiruv tokenni rad etishi uchun yozuvni oʻchirish | session revocation |

Ikki yordamchi: **cookie** — server `Set-Cookie` bilan beradigan, mijoz `Cookie` bilan qaytaradigan qiymat. **Soʻrov contexti** soʻrovga tegishli qiymatlarni handlerlar orasida olib yuradi.

## Tasodifiy token, bazada faqat hash

```go
func newToken() string {
	b := make([]byte, 32)
	rand.Read(b) // Go 1.24+: xato qaytarmaydi
	return base64.RawURLEncoding.EncodeToString(b)
}

// hashToken — bazaga yoziladigan va bazadan qidiriladigan qiymat: tokenning SHA-256 hash'i.
func hashToken(token string) []byte {
	sum := sha256.Sum256([]byte(token))
	return sum[:]
}
```

Bu `cmd/api/auth.go` parchasi; toʻliq fayl pastda. Parchani alohida ishga tushirmang.

| Qator | Nima qiladi |
|---|---|
| 1 | `newToken` matn qaytaradi |
| 2 | `make([]byte, 32)` 32 baytli slice yaratadi |
| 3 | `crypto/rand.Read` kriptografik tasodif bilan toʻldiradi |
| 4 | `RawURLEncoding` baytlarni URLga mos matnga aylantiradi; `=` toʻldiruvchisi yoʻq |
| 5 | funksiya tugaydi |
| 7–8 | izoh va `hashToken`: matn oladi, bayt qaytaradi |
| 9 | `Sum256([]byte(token))` aynan token matnini hashlaydi: `[32]byte` |
| 10–11 | `sum[:]` butun massivni slice qilib qaytaradi; funksiya tugaydi |

32 tasodifiy bayt — 256 bit; base64url koʻrinishi 43 belgi. Alifbo: harf, raqam, `-`, `_`. Kodlash shifrlash emas. SHA-256 natijasi 32 bayt, hex koʻrinishi 64 belgi. Go 1.24 dan `rand.Read` toʻliq toʻldiradi va xato qaytarmaydi; tasodif manbasi ishlamasa dastur qaytmasdan toʻxtaydi.

Inson paroli uchun argon2id kerak. Tasodifiy 256 bitli tokenga tez SHA-256 yetadi. Bazaning faqat oʻqish nusxasi sizsa, hashni cookie sifatida ishlatib boʻlmaydi. Bu oʻgʻirlangan cookie yoki bazaga yozish huquqidan himoya bermaydi. [OWASP saqlash tavsiyasi](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html#server-side-session-token-storage) kamida 128 bit, yaxshisi 160 yoki koʻproq tasodifni soʻraydi.

Foydalanuvchilar `00004_users.sql`da yaratiladi. `users_email_lower_idx` — `lower(email)` boʻyicha takrorni taqiqlovchi indeks. Login ham shu ifoda bilan qidiradi. Session jadvali:

```sql filename="migrations/00005_sessions.sql"
-- +goose Up
CREATE TABLE sessions (
    token_hash bytea       PRIMARY KEY,
    user_id    bigint      NOT NULL REFERENCES users (id) ON DELETE CASCADE,
    expires_at timestamptz NOT NULL
);
-- "Hamma qurilmadan chiqish" (DELETE … WHERE user_id = $1) jadvalni oxirigacha oʻqimasin.
CREATE INDEX sessions_user_id_idx ON sessions (user_id);

-- +goose Down
DROP TABLE sessions;
```

`Up` yaratadi, `Down` oʻchiradi. `bytea` baytlarni saqlaydi; primary key avtomatik unikal indeks yaratadi. `user_id` tashqi kalit; `ON DELETE CASCADE` foydalanuvchi bilan sessionlarini ham oʻchiradi. `timestamptz` UTC lahzasini saqlaydi, dastlabki vaqt mintaqasini emas. `sessions_user_id_idx` foydalanuvchi boʻyicha oʻchirishga yordam beradi.

## Login: parol tekshiruvi va cookie

```go
type loginInput struct {
	Email    string `json:"email"`
	Password string `json:"password"`
}

// login — POST /login: parol toʻgʻri boʻlsa yangi session ochadi va tokenni cookie'da qaytaradi.
// Har login yangi token oladi, so'rovda eski session cookie'si bo'lsa, uning qatori o'chiriladi: OWASP
// "Renew the Session ID After Any Privilege Level Change" — yangi ID, eskisi yo'q qilinsin (session fixation).
func (a *api) login(w http.ResponseWriter, r *http.Request) {
	var in loginInput
	if !decodeJSON(w, r, &in) {
		return
	}
	u, err := a.checkPassword(r.Context(), in.Email, in.Password)
	if err != nil {
		writeError(w, err)
		return
	}
	if err := a.endCurrentSession(r); err != nil {
		writeError(w, err)
		return
	}
	token := newToken()
	expires := time.Now().Add(sessionTTL)
	err = a.st.CreateSession(r.Context(), hashToken(token), u.ID, expires)
	if err != nil {
		writeError(w, err)
		return
	}
	setSessionCookie(w, token, expires)
	writeJSON(w, http.StatusOK, u)
}
```

`loginInput` JSON teglari `Email` va `Password`ni bodyga bogʻlaydi. `a *api` storeʼga kirish beradi. `in` kirish qiymati; `&in` uning manzili. `!decodeJSON` — oʻqish muvaffaqiyatsiz: javob yozilgan, `return` kerak.

`u, err :=` foydalanuvchi va xatoni oladi. `checkPassword` yangi metod: ichida GB-6.03 dagi `password.Verify`. Har `err != nil` tarmogʻi `writeError` va `return` bilan tugaydi.

`endCurrentSession` soʻrovdagi eski cookiening yozuvini oʻchiradi. Keyin yangi token. `time.Now().Add(sessionTTL)` hozirga `24 * time.Hour` qoʻshadi. `err =` mavjud oʻzgaruvchiga qiymat beradi. `CreateSession` hash, user ID va muddatni `INSERT` qiladi. Faqat yozuv saqlangach cookie va `200` JSON yuboriladi. `User.PasswordHash`dagi `json:"-"` hashni javobdan chiqaradi.

**Bashorat:** email bazada yoʻq. **A)** `404` · **B)** `401`, «email yoʻq» · **C)** notoʻgʻri paroldagi kabi umumiy `401`.

```go
func setSessionCookie(w http.ResponseWriter, token string, expires time.Time) {
	http.SetCookie(w, &http.Cookie{
		Name:     sessionCookie,
		Value:    token,
		Path:     "/",
		Expires:  expires,
		HttpOnly: true,
		Secure:   true,
		SameSite: http.SameSiteLaxMode,
	})
	w.Header().Set("Cache-Control", "no-store")
}
```

`http.SetCookie` `&http.Cookie{...}`dan sarlavha yaratadi. `Name` — `session`; `Value` — token; `Path: "/"` shu hostning yoʻllari; `Expires` — mijozdagi saqlash muddati. `HttpOnly` sahifa skriptiga oʻqishni taqiqlaydi. `Secure` HTTPS talab qiladi; curl `http://localhost`ni istisno qiladi. `SameSite=Lax` cross-site POSTga cookie qoʻshmaydi. Toʻliq chegaralar [GB-6.07 · cookie va CSRF](/lab/youtube/gb/gb-6-07) da. `no-store` javobni keshda saqlamaslikni buyuradi.

## Har soʻrov: cookie → baza → context

```go
type userKey struct{}

// requireUser — himoyalangan route'lar uchun middleware (GB-6.01 shakli): cookie'dagi token hash'i
// boʻyicha session egasini topadi va uni soʻrov context'iga qoʻyadi. Topilmasa — 401, handler ishlamaydi.
func (a *api) requireUser(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		c, err := r.Cookie(sessionCookie)
		if err != nil {
			writeError(w, err) // http.ErrNoCookie → 401
			return
		}
		u, err := a.st.UserBySession(r.Context(), hashToken(c.Value))
		if err != nil {
			writeError(w, err) // store.ErrNoSession → 401
			return
		}
		w.Header().Set("Cache-Control", "no-store") // shaxsiy javob: keshda qolmasin (OWASP)
		ctx := context.WithValue(r.Context(), userKey{}, u)
		next.ServeHTTP(w, r.WithContext(ctx))
	})
}
```

`userKey struct{}` — maydonsiz oʻz kalit turi. Kalit taqqoslanadigan boʻlishi kerak. Go hujjati paketlar toʻqnashmasligi uchun ichki `string` oʻrniga oʻz turni tavsiya qiladi.

`requireUser` handler olib, `http.HandlerFunc`ga aylantirilgan closure qaytaradi. `r.Cookie` nom boʻyicha oʻqiydi; yoʻq boʻlsa `http.ErrNoCookie` → `401` → `return`.

`UserBySession` `hashToken(c.Value)` bilan qidiradi. Session yoʻq yoki eskirgan boʻlsa `ErrNoSession` → `401`. Baza nosozligi `500`. Muvaffaqiyatda `no-store` qoʻyiladi. `WithValue` eski contextdan yangi `ctx` yaratadi: `userKey{}` → `u`. `r.WithContext(ctx)` soʻrovning shu contextli sayoz nusxasini beradi. `next.ServeHTTP` handlerni bajaradi. Store:

```go
func (s *Store) UserBySession(ctx context.Context, tokenHash []byte) (User, error) {
	var u User
	err := s.pool.QueryRow(ctx, `
		SELECT u.id, u.email
		FROM sessions s JOIN users u ON u.id = s.user_id
		WHERE s.token_hash = $1 AND s.expires_at > now()`,
		tokenHash).Scan(&u.ID, &u.Email)
	if errors.Is(err, pgx.ErrNoRows) {
		return User{}, ErrNoSession
	}
	if err != nil {
		return User{}, fmt.Errorf("session oʻqilmadi: %w", err)
	}
	return u, nil
}
```

`var u User` oluvchi qiymat. `QueryRow` bitta qator uchun; backtick SQLni oʻraydi. `s`, `u` jadval qisqa nomlari; `JOIN` foydalanuvchini ulaydi. `$1` hash parametri. `Scan(&u.ID, &u.Email)` maydonlarni yozadi. `pgx.ErrNoRows` session topilmaganiga aylantiriladi, boshqa xatolar `%w` bilan oʻraladi. `return u, nil` — muvaffaqiyat.

`now()` — **joriy transaction boshlanish vaqti**. Bu alohida soʻrovda u tekshiruvga yaqin. Uzoq transactionda har SELECT bilan yangilanmaydi.

```go
func currentUser(r *http.Request) store.User {
	u, ok := r.Context().Value(userKey{}).(store.User)
	if !ok {
		panic("currentUser: route requireUser bilan oʻralmagan")
	}
	return u
}
```

`Value` qaytargan `any`ga `.(store.User)` type assertion qoʻllanadi. `u, ok :=` yoʻq qiymat yoki xato turni aniqlaydi. `!ok` dasturchi xatosi: route oʻralmagan. Ataylab `panic`, `recoverPanic`dan `500`. Oddiy holatda `return u`. Routeʼlar toʻliq:

```go filename="cmd/api/handlers.go" showLineNumbers
package main

// Route'lar (GB-4.05). Ochiq: /health, POST /users (GB-6.03), POST /login, POST /logout. Himoyalangan
// route'lar requireUser bilan oʻralgan (auth.go): cookie'dagi session tirik boʻlmasa, handler'gacha
// yetib bormaydi — 401. POST body'li route'lar requireJSON bilan (GB-6.01, 415).

import (
	"fmt"
	"net/http"

	"github.com/abdurahmon27/bozor/internal/store"
)

// api — handler'lar bazani shu struct orqali koʻradi (GB-5.10).
type api struct {
	st *store.Store
}

// newMux — hamma route'lar shu yerda: main ham, testlar ham bir xil mux'ni ishlatadi.
func newMux(st *store.Store) *http.ServeMux {
	a := &api{st: st}
	mux := http.NewServeMux()
	mux.HandleFunc("GET /health", healthHandler)
	mux.Handle("POST /users", requireJSON(http.HandlerFunc(a.register))) // GB-6.03
	mux.Handle("POST /login", requireJSON(http.HandlerFunc(a.login)))
	mux.Handle("GET /me", a.requireUser(http.HandlerFunc(a.me)))
	mux.HandleFunc("POST /logout", a.logout) // requireUser'siz: eskirgan cookie ham tozalansin
	// VAZIFA (TASK.md, 2-qadam): POST /logout-all → a.logoutAll, requireUser bilan oʻralgan
	return mux
}

// healthHandler — server tirikligini tekshirish: har soʻrovga «ok» (GB-4.03).
func healthHandler(w http.ResponseWriter, r *http.Request) {
	fmt.Fprintln(w, "ok")
}

// me — GET /me: session egasi. requireUser uni context'ga qoʻygan.
func (a *api) me(w http.ResponseWriter, r *http.Request) {
	writeJSON(w, http.StatusOK, currentUser(r))
}
```

## Logout: cookie va qator alohida

```go
func (a *api) endCurrentSession(r *http.Request) error {
	c, err := r.Cookie(sessionCookie)
	if err != nil {
		return nil // cookie yoʻq: oʻchiradigan session ham yoʻq
	}
	return a.st.DeleteSession(r.Context(), hashToken(c.Value))
}

// logout — POST /logout: cookie'dagi session qatorini o'chiradi va brauzerga cookie'ni o'chirishni aytadi.
// requireUser'siz: session allaqachon eskirgan yoki o'chirilgan bo'lsa ham javob 204 va cookie tozalanadi.
func (a *api) logout(w http.ResponseWriter, r *http.Request) {
	if err := a.endCurrentSession(r); err != nil {
		writeError(w, err)
		return
	}
	clearSessionCookie(w)
	w.WriteHeader(http.StatusNoContent)
}
```

```go
func clearSessionCookie(w http.ResponseWriter) {
	http.SetCookie(w, &http.Cookie{
		Name:     sessionCookie,
		Value:    "",
		Path:     "/",
		MaxAge:   -1,
		HttpOnly: true,
		Secure:   true,
		SameSite: http.SameSiteLaxMode,
	})
}
```

`endCurrentSession`da cookie yoʻq boʻlsa, oʻchiradigan narsa yoʻq: `nil`. Aks holda `DeleteSession` hash boʻyicha `DELETE FROM sessions WHERE token_hash = $1` qiladi. Qator yoʻq boʻlsa ham muvaffaqiyat.

`if err := ...; err != nil` xatoni eʼlon qilib tekshiradi. Oʻchirish ishlamasa `writeError` va `return`. Aks holda `clearSessionCookie`, `204 No Content`, bodysiz javob.

Tozalash oʻsha nom va `Path` bilan boʻsh qiymat beradi. Goʼda `MaxAge: -1` sarlavhada `Max-Age=0`. Qolgan atributlar login bilan bir xil. Sessionni bekor qiladigan amal — DELETE.

Oldingi ikki yozuv eskirgan: qayta login kerak. **Bashorat:** login → nusxa → logout → eski nusxa bilan `/me`? **A)** `401` · **B)** `200`, Expires ertaga · **C)** `404`.

## Chuqurroq (ixtiyoriy): vaqt va himoya chegaralari

`checkPassword` yoʻq emailga ham `dummyHash` bilan argon2id ishlatadi. Aks holda erta qaytish hisob mavjudligini vaqt orqali bildirishi mumkin. `dummyHash` dastur boshlanganda bir marta hisoblanadi. Saqlangan hash buzuq boʻlsa `500`. Muvaffaqiyatda `u.PasswordHash = ""`: keyingi kodga u kerak emas.

`password.Verify` ichidagi solishtirish doimiy vaqtda. `WHERE token_hash = $1` esa **doimiy vaqt kafolatiga ega emas**. Yuqori entropiyali tokenni hashdan amaliy tiklab boʻlmaydi. Bu barcha vaqt kanallari xavfsiz degani emas. Split-token usulida ochiq identifikator va sir ajratiladi; sir hashi alohida doimiy vaqtda solishtiriladi.

Har holatni besh marta oʻlchaymiz. `time_total` soniyada; `for` takrorlaydi, `-w` vaqtni chiqaradi:

24 soatlik TTL — laboratoriya tanlovi. Bu eng uzun umr — absolute timeout. Harakatsizlik muddati — idle timeout — hali yozilmagan. Uzaytiriladigan muddat va mutlaq chegara alohida saqlanishi kerak. Ilova `time.Now()` bilan yozadi, Postgres tekshiradi: soatlar mos boʻlsin.

Har login yangi token oladi va taqdim etilgan eski sessionni oʻchiradi. Maʼlum eski tokenning login orqali saqlanishi — session fixation — cheklanadi. `SameSite` yakka CSRF himoyasi emas. Login urinishlarini cheklash GB-6.07 da; haqiqiy joylashtirishda HTTPS kerak.

RFC 9110 `401`da `WWW-Authenticate` talab qiladi. Lab `Cookie realm="bozor"` yuboradi. Bu maxsus challenge; avtomatik kirishni belgilaydigan standart cookie auth-scheme emas.

<summary>Toʻliq auth.go</summary>

```go filename="cmd/api/auth.go" showLineNumbers
package main

// Login va bekor qilinadigan session'lar (GB-6.04).
//
//	POST /login        parol toʻgʻri → yangi session: tokenning hash'i bazaga, tokenning oʻzi cookie'ga
//	requireUser        cookie → hash → sessions qatori → foydalanuvchi context'ga; yoʻq yoki eski → 401
//	POST /logout       cookie'dagi session qatorini oʻchiradi: shu token bilan keyingi soʻrov 401
//	POST /logout-all   foydalanuvchining hamma session'larini oʻchiradi (VAZIFA, TASK.md)

import (
	"context"
	"crypto/rand"
	"crypto/sha256"
	"encoding/base64"
	"errors"
	"fmt"
	"net/http"
	"time"

	"github.com/abdurahmon27/bozor/internal/password"
	"github.com/abdurahmon27/bozor/internal/store"
)

// sessionCookie — cookie nomi. sessionTTL — session'ning eng uzun umri: login'dan 24 soat keyin u
// baribir tugaydi (absolute timeout). 24 soat — bizning tanlov; OWASP Session Management Cheat Sheet'ning
// misoli ish kuni ilovasi uchun 4–8 soat, harakatsizlik (idle) muddati esa alohida (README).
const (
	sessionCookie = "session"
	sessionTTL    = 24 * time.Hour
)

// newToken — session tokeni: 32 tasodifiy bayt (256 bit), cookie'ga sigʻadigan matn qilib (43 belgi).
func newToken() string {
	b := make([]byte, 32)
	rand.Read(b) // Go 1.24+: xato qaytarmaydi
	return base64.RawURLEncoding.EncodeToString(b)
}

// hashToken — bazaga yoziladigan va bazadan qidiriladigan qiymat: tokenning SHA-256 hash'i.
func hashToken(token string) []byte {
	sum := sha256.Sum256([]byte(token))
	return sum[:]
}

// loginInput — POST /login body'si.
type loginInput struct {
	Email    string `json:"email"`
	Password string `json:"password"`
}

// login — POST /login: parol toʻgʻri boʻlsa yangi session ochadi va tokenni cookie'da qaytaradi.
// Har login yangi token oladi, so'rovda eski session cookie'si bo'lsa, uning qatori o'chiriladi: OWASP
// "Renew the Session ID After Any Privilege Level Change" — yangi ID, eskisi yo'q qilinsin (session fixation).
func (a *api) login(w http.ResponseWriter, r *http.Request) {
	var in loginInput
	if !decodeJSON(w, r, &in) {
		return
	}
	u, err := a.checkPassword(r.Context(), in.Email, in.Password)
	if err != nil {
		writeError(w, err)
		return
	}
	if err := a.endCurrentSession(r); err != nil {
		writeError(w, err)
		return
	}
	token := newToken()
	expires := time.Now().Add(sessionTTL)
	err = a.st.CreateSession(r.Context(), hashToken(token), u.ID, expires)
	if err != nil {
		writeError(w, err)
		return
	}
	setSessionCookie(w, token, expires)
	writeJSON(w, http.StatusOK, u)
}

// setSessionCookie — tokenni cookie qilib yuboradi. Atributlar GB-6.07'da batafsil:
// HttpOnly — sahifadagi skript cookie'ni oʻqiy olmaydi; Secure — brauzer uni faqat HTTPS orqali
// yuboradi (brauzerlar va curl http://localhost'ni istisno qiladi, MDN: Set-Cookie); SameSite=Lax — boshqa
// saytdan kelgan POST'ga qoʻshilmaydi. Cache-Control: no-store — session ID bor javob keshda qolmasin (OWASP).
func setSessionCookie(w http.ResponseWriter, token string, expires time.Time) {
	http.SetCookie(w, &http.Cookie{
		Name:     sessionCookie,
		Value:    token,
		Path:     "/",
		Expires:  expires,
		HttpOnly: true,
		Secure:   true,
		SameSite: http.SameSiteLaxMode,
	})
	w.Header().Set("Cache-Control", "no-store")
}

// clearSessionCookie — brauzerga cookie'ni oʻchirishni aytadi (MaxAge: -1 → "Max-Age=0").
// Bu faqat mijoz tomoni: session'ni bekor qiladigan narsa — bazadagi qatorni oʻchirish.
func clearSessionCookie(w http.ResponseWriter) {
	http.SetCookie(w, &http.Cookie{
		Name:     sessionCookie,
		Value:    "",
		Path:     "/",
		MaxAge:   -1,
		HttpOnly: true,
		Secure:   true,
		SameSite: http.SameSiteLaxMode,
	})
}

// errBadLogin — email yoki parol notoʻgʻri (problemFor → 401, ikkalasiga bir xil matn).
var errBadLogin = errors.New("email yoki parol notoʻgʻri")

// dummyHash — yoʻq email uchun ham argon2id bir marta ishlaydi: javob vaqti email bazada bor-yoʻqligini
// bildirmasin (OWASP Authentication Cheat Sheet, "Authentication Responses").
var dummyHash = password.Hash("bozor: email topilmadi")

// checkPassword — Verify (GB-6.03) ustidagi login tekshiruvi: email boʻyicha foydalanuvchi, keyin argon2id Verify.
func (a *api) checkPassword(ctx context.Context, email, pw string) (store.User, error) {
	u, err := a.st.UserByEmail(ctx, email)
	if errors.Is(err, store.ErrUserNotFound) {
		password.Verify(pw, dummyHash)
		return store.User{}, fmt.Errorf("%w: %w", errBadLogin, err)
	}
	if err != nil {
		return store.User{}, err
	}
	ok, err := password.Verify(pw, u.PasswordHash)
	if err != nil {
		return store.User{}, fmt.Errorf("foydalanuvchi %d: %w", u.ID, err)
	}
	if !ok {
		return store.User{}, fmt.Errorf("%w: foydalanuvchi %d", errBadLogin, u.ID)
	}
	u.PasswordHash = "" // hash bundan keyin kerak emas: javobga yoki log'ga tasodifan chiqmasin
	return u, nil
}

// userKey — context'dagi kalit turi. Oʻz turimiz: boshqa paketning kaliti bilan toʻqnashmaydi
// (go doc context.WithValue: kalit string yoki boshqa ichki tur boʻlmasin).
type userKey struct{}

// requireUser — himoyalangan route'lar uchun middleware (GB-6.01 shakli): cookie'dagi token hash'i
// boʻyicha session egasini topadi va uni soʻrov context'iga qoʻyadi. Topilmasa — 401, handler ishlamaydi.
func (a *api) requireUser(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		c, err := r.Cookie(sessionCookie)
		if err != nil {
			writeError(w, err) // http.ErrNoCookie → 401
			return
		}
		u, err := a.st.UserBySession(r.Context(), hashToken(c.Value))
		if err != nil {
			writeError(w, err) // store.ErrNoSession → 401
			return
		}
		w.Header().Set("Cache-Control", "no-store") // shaxsiy javob: keshda qolmasin (OWASP)
		ctx := context.WithValue(r.Context(), userKey{}, u)
		next.ServeHTTP(w, r.WithContext(ctx))
	})
}

// currentUser — requireUser context'ga qoʻygan foydalanuvchi. Route requireUser bilan oʻralmagan
// boʻlsa — bu dasturchi xatosi: panic, recoverPanic uni 500 qiladi (jim User{} qaytarishdan xavfsizroq).
func currentUser(r *http.Request) store.User {
	u, ok := r.Context().Value(userKey{}).(store.User)
	if !ok {
		panic("currentUser: route requireUser bilan oʻralmagan")
	}
	return u
}

// endCurrentSession — so'rovdagi session cookie'sining qatorini o'chiradi; cookie yo'q bo'lsa hech narsa
// qilmaydi. logout va login (eski session'ni yo'q qilish) ishlatadi.
func (a *api) endCurrentSession(r *http.Request) error {
	c, err := r.Cookie(sessionCookie)
	if err != nil {
		return nil // cookie yoʻq: oʻchiradigan session ham yoʻq
	}
	return a.st.DeleteSession(r.Context(), hashToken(c.Value))
}

// logout — POST /logout: cookie'dagi session qatorini o'chiradi va brauzerga cookie'ni o'chirishni aytadi.
// requireUser'siz: session allaqachon eskirgan yoki o'chirilgan bo'lsa ham javob 204 va cookie tozalanadi.
func (a *api) logout(w http.ResponseWriter, r *http.Request) {
	if err := a.endCurrentSession(r); err != nil {
		writeError(w, err)
		return
	}
	clearSessionCookie(w)
	w.WriteHeader(http.StatusNoContent)
}
```

Izohlar va boʻsh qatorlar bajarilmaydi. `errBadLogin` umumiy xato; ikkita `%w` asl sabablarni saqlaydi. `checkPassword`dagi `ok` parol mosligini, `err` hisoblash xatosini bildiradi.

## Koʻp uchraydigan xatolar

1. **Faqat hashni tekshirish.** «Muddat shartini olib tashlasak» boʻlimida eskirgan qator `200` berdi. `AND s.expires_at > now()`ni qaytarish va serverni qayta boshlash uni `401`ga oʻzgartirdi.
2. **Faqat cookieni oʻchirish.** Eski nusxa qator borligida ishlaydi. Logoutni `DeleteSession` muvaffaqiyatidan keyin yakunlang.
3. **`currentUser`ni ochiq routeʼda chaqirish.** `panic("currentUser: route requireUser bilan oʻralmagan")` — dasturchi xatosi: route oʻralmagan. `recoverPanic` uni `500` qiladi. Tuzatish: `a.requireUser(http.HandlerFunc(a.me))`.
4. **Oddiy logoutni `requireUser` bilan oʻrash.** Eskirgan session cookie tozalashgacha yetmaydi. Oddiy logout ochiq; logout-all joriy foydalanuvchi uchun himoyalangan.
5. **`Expires`ni server muddati deb bilish.** Mijozdagi saqlash serverdagi qabul qilishdan alohida. Tozalash ham muddat tekshiruvini almashtirmaydi.

<summary>Javob va sababi</summary>

```go
func (s *Store) DeleteUserSessions(ctx context.Context, userID int64) (int64, error) {
	tag, err := s.pool.Exec(ctx, "DELETE FROM sessions WHERE user_id = $1", userID)
	if err != nil {
		return 0, fmt.Errorf("foydalanuvchi %d session'lari oʻchirilmadi: %w", userID, err)
	}
	return tag.RowsAffected(), nil
}
```

```go
func (a *api) logoutAll(w http.ResponseWriter, r *http.Request) {
	_, err := a.st.DeleteUserSessions(r.Context(), currentUser(r).ID)
	if err != nil {
		writeError(w, err)
		return
	}
	clearSessionCookie(w)
	w.WriteHeader(http.StatusNoContent)
}
```

```go
mux.Handle("POST /logout-all", a.requireUser(http.HandlerFunc(a.logoutAll)))
```

Birinchi parcha storeʼga, ikkinchisi auth.goʼga, oxirgisi `newMux`ga. `RowsAffected()` oʻchgan qatorlar soni. Handler sonni `_` bilan tashlaydi. `WHERE user_id` boshqa foydalanuvchini saqlaydi; uni olib tashlasangiz test yiqiladi. Ixtiyoriy tozalash ham shu `Exec` shaklida, sharti `WHERE expires_at <= now()`.

</details>
