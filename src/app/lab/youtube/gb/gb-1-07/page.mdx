## Nimani oʻrganasiz

Hozir bozor nom, narx va miqdorni `main.go` ichidan oladi: `name = "choy"`, `price = 1_999 * tiyinPerSom`. Yangi mahsulot
uchun kodni oʻzgartirib, qayta build qilish kerak. Bugun bozor ularni terminaldan oladi: `./bozor add olma 12000`.
Kimdir narx oʻrniga `12k` yozsa-chi? Dastur buni sezishi va aniq xabar bilan rad etishi kerak.

**Bitta gʻoya:** Go'da muvaffaqiyatsizlik ham oddiy qaytgan qiymat. Funksiya `(qiymat, error)` juftini qaytaradi, xato
boʻlmasa `err` — `nil`. Chaqirgan kod qiymatga tegishdan oldin `if err != nil` bilan tekshiradi: xato boʻlganda qiymat
maʼnosiz boʻlishi mumkin (`Atoi` chegaradan chiqsa `9223372036854775807` qaytaradi).

Dars oxirida siz:

- `os.Args` bilan buyruq qatoridagi soʻzlarni oʻqiysiz va uning uzunligini indeksdan *oldin* tekshirasiz;
- `strconv.Atoi` bilan matnni songa aylantirasiz va qaytgan `error`'ni oʻqiysiz;
- `func parsePrice(s string) (int64, error)` yozasiz: parametr, ikki natija, `return`, `fmt.Errorf` bilan oʻz xatongiz;
- notoʻgʻri kirishni standart xato oqimiga xabar va chiqish kodi 1 bilan rad etasiz, kodni `echo $?` bilan koʻrasiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| `os.Args` | dastur ishga tushganda terminalda yozilgan soʻzlar roʻyxati; `os.Args[0]` — dasturning oʻzi, indeks 0 dan; `len(os.Args)` — nechta soʻz | command-line arguments |
| `(qiymat, error)` va `if err != nil` | funksiya natija bilan birga xatoni ham qaytaradi; `nil` — «xato yoʻq»; qiymatdan oldin `err` tekshiriladi | error value, `nil` |
| `func`: parametr, natijalar, `return` | `func nom(parametr tur) (natijalar) { … }`; `return` funksiyani tugatib, qiymatlarni chaqirgan kodga qaytaradi | function, parameter, result, `return` |

Ikkita yordamchi soʻz: **chiqish kodi** (*exit code*) — dastur tugaganda operatsion tizimga qoldiradigan son, `0` —
muvaffaqiyat, boshqasi — xato; `os.Exit(1)` dasturni shu zahoti 1 kodi bilan toʻxtatadi. **Standart xato oqimi**
(*standard error*, `os.Stderr`) — xabarlar uchun alohida chiqish; `fmt.Fprintln(os.Stderr, …)` shu yerga yozadi.

## `os.Args`: terminaldagi soʻzlar dasturga keladi

Avval `main.go` oʻrnida vaqtincha kichik sinov dasturini yozamiz; bozorning chek kodi keyin qaytadi. Endi bizga ikki paket
kerak, shuning uchun `import`'dan keyin qavs ochamiz va har bir paketni alohida qatorga yozamiz. Bu bir nechta paketni
ulashning odatiy yoʻli ([Go spec: Import declarations](https://go.dev/ref/spec#Import_declarations)).

```go filename="_video/01-args/main.go" showLineNumbers
package main

import (
	"fmt"
	"os"
)

func main() {
	fmt.Println(len(os.Args), os.Args)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 3–6 | `import (` … `)` | guruhli import: qavs ichida bir nechta paket, har biri alohida qatorda |
| 4 | `"fmt"` | ekranga yozish paketi (GB-1.01) |
| 5 | `"os"` | operatsion tizim bilan ishlaydigan standart paket (GB-1.01) |
| 9 | `os.Args` | **buyruq qatori argumentlari** (*command-line arguments*): dastur ishga tushganda terminalda yozilgan soʻzlar roʻyxati, dastur nomidan boshlab |
| 9 | `len(os.Args)` | `len(…)` roʻyxatdagi elementlar sonini qaytaradi |
| 9 | `fmt.Println(len(os.Args), os.Args)` | avval sonni, keyin roʻyxatning oʻzini chiqaradi |

Dasturni uch soʻz bilan ishga tushiramiz: `add`, `olma` va `12000`.

```console
$ ./_video/run.sh 01-args add olma 12000
4 [./bozor add olma 12000]
(chiqish kodi: 0)
```

Avval `4` chiqdi: roʻyxatda toʻrtta element. Keyin `Println` roʻyxatni kvadrat qavs ichida, elementlarni probel bilan
ajratib chiqardi. Birinchi element — dasturning oʻzi, terminalda qanday yozilgan boʻlsa shunday: `./bozor`.
pkg.go.dev ham shunday deydi: «Args hold the command-line arguments, starting with the program name»
([os.Args](https://pkg.go.dev/os#pkg-variables)).

Bu soʻzlar qayerdan keladi? Terminaldagi **shell** — buyruqni oʻqiydigan dastur — qatorni probellar boʻyicha soʻzlarga
boʻladi, qoʻshtirnoq ichidagisi bundan mustasno. Operatsion tizim bu soʻzlarni dasturga beradi va ular `os.Args`'ga
tushadi. Har bir elementga oʻrni bilan murojaat qilinadi: `os.Args[3]`. Kvadrat qavs ichidagi son — **indeks** (*index*),
sanash noldan boshlanadi:

| Element | Qiymati | Nima |
|---|---|---|
| `os.Args[0]` | `"./bozor"` | dastur nomi |
| `os.Args[1]` | `"add"` | buyruq |
| `os.Args[2]` | `"olma"` | mahsulot nomi |
| `os.Args[3]` | `"12000"` | narx — lekin **matn**, son emas |

`len(os.Args)` = 4, demak toʻgʻri indekslar 0, 1, 2 va 3. Spetsifikatsiya qoidasi: indeks `x` toʻgʻri, agar
`0 <= x < len(a)` boʻlsa ([Go spec: Index expressions](https://go.dev/ref/spec#Index_expressions)). Eng muhimi: toʻrttala
element ham matn (`string`), `12000` ham. `os.Args`'ning turi `[]string`, yaʼni satrlar roʻyxati (**slice**); slice'ning
ichini [GB-2.01](/lab/youtube/gb/gb-2-01) da ochamiz, bugun indeks va `len` yetarli.

`+` faqat bir xil turdagi qiymatlarni qoʻshadi (GB-1.04). **A** ni tanlagan boʻlsangiz, Go matnni oʻzi songa aylantiradi
deb oʻylagansiz: aylantirmaydi. **B** da `+` matnlarni yopishtiradi deb olingan: bu faqat ikkala tomon `string` boʻlganda
ishlaydi, `1` esa matn emas.

</details>


Birinchi qator — xato qaysi modulda (GB-1.04). Ikkinchisi: `main.go`, **10-qator, 14-ustun** (`price` shu ustundan

qatorigacha yetmadi. Qisqasi: terminaldan kelgan narxni hisoblashdan oldin songa aylantirish kerak.

## `strconv.Atoi`: matndan son va `error`

Buning uchun standart kutubxonada `strconv` paketi bor. Nomi *string conversion*dan, yaʼni «matnni oʻgirish».
`strconv.Atoi` undagi funksiya: matndan butun son (`int`) yasaydi. Uning toʻliq eʼloni pkg.go.dev'da:
`func Atoi(s string) (int, error)` ([strconv.Atoi](https://pkg.go.dev/strconv#Atoi)). Oxirgi qavsdagi ikki tur —
`Atoi` **ikki qiymat qaytaradi**: son va xato.

```go filename="_video/03-atoi/main.go" showLineNumbers
package main

import (
	"fmt"
	"os"
	"strconv"
)

func main() {
	price, err := strconv.Atoi(os.Args[3])
	fmt.Println(price, err)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 6 | `"strconv"` | matnni son va boshqa turlarga oʻgiradigan standart paket |
| 10 | `strconv.Atoi(os.Args[3])` | `"12000"` matnini `int`'ga aylantirishga urinadi |
| 10 | `price, err :=` | ikki natija uchun chapda vergul bilan ikki nom: `price` — son, `err` — xato. `:=` ikkalasini birga eʼlon qiladi (GB-1.02) |
| 11 | `fmt.Println(price, err)` | ikkala qiymatni probel bilan chiqaradi |

`12000` bilan xotirada ikki yorliq paydo boʻladi:

| Yorliq | Turi | Qiymati |
|---|---|---|
| `price` | `int` | `12000` |
| `err` | `error` | `nil` — xato yoʻq |

**`error`** — Go'dagi xato turi, oldindan eʼlon qilingan tur ([Go spec: Errors](https://go.dev/ref/spec#Errors)).
**`nil`** — uning boʻsh qiymati, yaʼni «xato yoʻq». `Println` `nil` xatoni burchak qavs ichida `<nil>` deb chiqaradi.
Endi ikkita kirishni sinaymiz — `12000` va `12k`:

```console
$ ./_video/run.sh 03-atoi add olma 12000
12000 <nil>
(chiqish kodi: 0)
$ ./_video/run.sh 03-atoi add olma 12k
0 strconv.Atoi: parsing "12k": invalid syntax
(chiqish kodi: 0)
```

`12k` bilan `price` — `0`, `err` esa xato matni. Uni qismlab oʻqiymiz: `strconv.Atoi` — qaysi funksiya; `parsing "12k"` —
qaysi matnni oʻqiyotgan edi (qoʻshtirnoq ichida); `invalid syntax` — sabab: «yozuv notoʻgʻri», bu son yozuvi emas
([strconv.NumError](https://pkg.go.dev/strconv#NumError)). Eʼtibor bering: dastur toʻxtamadi, chiqish kodi `0`.
Xato ham `price` kabi oddiy qiymat boʻlib qaytdi. Uni tekshirish — chaqirgan kodning ishi.

## `Atoi` faqat yozuvni tekshiradi

Endi narx oʻrniga `-5` beramiz. Nima chiqadi?

**A)** `-5 <nil>` · **B)** `0` va `invalid syntax` · **C)** `0` va «narx manfiy» degan xato

<details>
<summary>Javob</summary>

**A: `-5 <nil>`.** `Atoi` faqat yozuvni tekshiradi, `-5` esa toʻgʻri son yozuvi: «The string may begin with a leading
sign» ([strconv.ParseInt](https://pkg.go.dev/strconv#ParseInt); `Atoi` — `ParseInt(s, 10, 0)` ning qisqasi). **B** ni
tanlagan boʻlsangiz, minus belgisi ruxsat emas deb oʻylagansiz. **C** da `Atoi` narx haqida biladi deb olingan: narx
musbat boʻlishi kerakligi — bizning qoidamiz, uni oʻzimiz yozamiz.

</details>

```console
$ ./_video/run.sh 03-atoi add olma -5
-5 <nil>
(chiqish kodi: 0)
```

Yana bir holat: yigirmata `9`. Bu kompyuterda `int` 64 bitli, bunday son unga sigʻmaydi.

```console
$ ./_video/run.sh 03-atoi add olma 99999999999999999999
9223372036854775807 strconv.Atoi: parsing "99999999999999999999": value out of range
(chiqish kodi: 0)
```

`price` `0` emas! `9223372036854775807` — taxminan 9,2 kvintillion, 64 bitli `int`'ning eng katta qiymati. `err` esa
`value out of range`: «qiymat chegaradan tashqarida». Hujjatda shunday yozilgan: chegaradan chiqsa,
`err.Err = ErrRange` va qaytgan qiymat — shu turdagi eng katta son ([strconv.ParseInt](https://pkg.go.dev/strconv#ParseInt)).
Qoida shundan kelib chiqadi:

> `err` `nil` boʻlmasa, birinchi qiymatga ishonmang: avval `err`'ni tekshiring.

| Kirish | `price` | `err` | `price`'ga ishonsa boʻladimi |
|---|---|---|---|
| `12000` | `12000` | `<nil>` | ha |
| `12k` | `0` | `invalid syntax` | yoʻq: `0` haqiqiy narx emas |
| `-5` | `-5` | `<nil>` | yozuv toʻgʻri, lekin narx qoidasini oʻzimiz tekshiramiz |
| yigirmata `9` | `9223372036854775807` | `value out of range` | yoʻq: bu chegaradagi son, foydalanuvchi yozgani emas |

## `if err != nil`, xato oqimi va chiqish kodi

Tekshiruv shunday yoziladi:

```go filename="_video/04-iferr/main.go" showLineNumbers
package main

import (
	"fmt"
	"os"
	"strconv"
)

func main() {
	price, err := strconv.Atoi(os.Args[3])
	if err != nil {
		fmt.Fprintln(os.Stderr, "xato:", err)
		os.Exit(1)
	}
	fmt.Println("narx:", price)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 11 | `if err != nil {` | `!=` — «teng emas» (GB-1.05): xato bor boʻlsa, `{ }` ichidagi qatorlar bajariladi |
| 12 | `fmt.Fprintln(os.Stderr, "xato:", err)` | `Fprintln` — `Println` kabi, faqat birinchi argumentda **qayerga** yozishni oladi; `os.Stderr` — standart xato oqimi |
| 13 | `os.Exit(1)` | dasturni shu zahoti toʻxtatadi va operatsion tizimga chiqish kodi `1` ni qaytaradi |
| 15 | `fmt.Println("narx:", price)` | faqat `err == nil` boʻlganda yetib keladi: unda `if` tanasi oʻtkazib yuborilgan |

Ikki yangi tushuncha:

- **Standart xato oqimi** (*standard error*, `stderr`). Dasturda ikki alohida chiqish bor: oddiy natija uchun **standart
  chiqish** (*standard output*, `os.Stdout`; `fmt.Println` shu yerga yozadi) va xabarlar uchun standart xato oqimi.
  Terminal ikkalasini ham koʻrsatadi. Lekin skript natijani faylga yozdirsa, xato xabari faylga aralashmaydi, ekranda
  qoladi. Buni pastda bozor bilan koʻramiz.
- **Chiqish kodi** (*exit code*). Dastur tugaganda operatsion tizimga qoldiradigan son. «Conventionally, code zero
  indicates success, non-zero an error» ([os.Exit](https://pkg.go.dev/os#Exit)). Terminalda `echo $?` oxirgi buyruqning
  chiqish kodini chiqaradi ([bash: Special Parameters](https://www.gnu.org/software/bash/manual/bash.html#Special-Parameters)).
  Skriptlar va CI — kodni avtomatik tekshiradigan server — aynan shu songa qaraydi.

`12k` va `12000` bilan:

```console
$ ./_video/run.sh 04-iferr add olma 12k
xato: strconv.Atoi: parsing "12k": invalid syntax
(chiqish kodi: 1)
$ ./_video/run.sh 04-iferr add olma 12000
narx: 12000
(chiqish kodi: 0)
```

`12k` bilan endi faqat xato qatori chiqdi va chiqish kodi `1`. Videoda shu joyda `echo $?` yozilgan va u ham `1` chiqargan;
skriptning `(chiqish kodi: 1)` qatori aynan shu sonni koʻrsatadi. `12000` bilan `if` tanasi oʻtkazib yuborildi, oxirgi
qator narxni chiqardi, kod `0`. Qisqasi: qiymat va `error` birga qaytadi, qiymatga tegishdan oldin `err` tekshiriladi.

## `func parsePrice`: narx qoidasi bitta joyda

Narx qoidasi oʻsadi: son boʻlsin, musbat boʻlsin, tiyinga oʻgirilsin. Uni alohida **funksiya**ga (*function*) olamiz:
`main` qisqa qoladi, keyingi darsda esa funksiyani alohida test qilamiz. Birinchi qatori — funksiyaning eʼloni, yoki
**funksiya imzosi** (*signature*):

```go
func parsePrice(s string) (int64, error) {
```

| Qism | Nima |
|---|---|
| `func` | funksiya eʼlon qilinmoqda (GB-1.01 dagi `func main` ham shunday) |
| `parsePrice` | funksiyaning nomi: «narxni oʻqi» |
| `(s string)` | **parametr** (*parameter*): avval nomi `s`, keyin turi `string`. Chaqirganda berilgan qiymat — **argument** — shu nomga tushadi |
| `(int64, error)` | **natijalar** (*results*): ikkita qaytgan qiymat — narx tiyinda (`int64`, GB-1.03) va xato |
| `{` | funksiya tanasi boshlanadi |

Go'da odat: `error` doim oxirgi natija. `strconv.Atoi` ham shunday: `(int, error)`. Tanasi:

```go
func parsePrice(s string) (int64, error) {
	som, err := strconv.Atoi(s)
	if err != nil {
		return 0, err
	}
	return int64(som) * tiyinPerSom, nil
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 2 | `som, err := strconv.Atoi(s)` | `s` ni songa oʻgiradi; natija `som`'ga («soʻm»), xato `err`'ga |
| 3–5 | `if err != nil { return 0, err }` | xato boʻlsa: `0` va oʻsha `err` qaytadi |
| 6 | `return int64(som) * tiyinPerSom, nil` | xato boʻlmasa: `som`'ni `int64`'ga oʻgirib, `tiyinPerSom` (100) ga koʻpaytiramiz; xato oʻrnida `nil` |

**`return`** GB-1.05 da `main`'ni toʻxtatgan edi. Bu yerda u funksiyani tugatadi va qiymatlarni **chaqiruvchi**ga
(*caller*), yaʼni funksiyani chaqirgan kodga qaytaradi ([Go spec: Return statements](https://go.dev/ref/spec#Return_statements)).
`return` dan keyin natijalar soni va tartibi imzodagidek boʻlishi shart: avval `int64`, keyin `error`.

Xotirada `parsePrice("12000")` chaqiruvini kuzatamiz:

| Qadam | Qator | `s` (`string`) | `som` (`int`) | `err` (`error`) | Nima boʻladi |
|---|---|---|---|---|---|
| chaqiruv | 1 | `"12000"` | | | `s` argumentning **nusxasini** oladi |
| `Atoi` | 2 | `"12000"` | `12000` | `nil` | matn songa aylandi |
| `if` | 3 | | | | `err != nil` — `false`: `if` tanasi oʻtkazib yuboriladi |
| `return` | 6 | | | | `1200000, nil` qaytadi: 12 000 soʻm = 1 200 000 tiyin |

`s`, `som` va `err` faqat shu chaqiruv ichida mavjud: funksiya tugashi bilan ular yoʻqoladi. Spetsifikatsiya:
chaqiruvning argumentlari funksiyaga beriladi va mos parametrlarga oʻzlashtiriladi
([Go spec: Calls](https://go.dev/ref/spec#Calls)).

**Ikkinchi qoida: narx musbat.** `Atoi` `-5` ni xatosiz qabul qilishini koʻrdik, `0` ham xuddi shunday oʻtadi. Lekin narx
musbat boʻlishi kerak. `som` noldan kichik yoki teng boʻlsa, xatoni oʻzimiz yasaymiz:

```go
	if som <= 0 {
		return 0, fmt.Errorf("narx musbat boʻlishi kerak, keldi %d", som)
	}
```

**`fmt.Errorf`** GB-1.04 dagi `fmt.Sprintf` kabi shablonni toʻldiradi (`%d` oʻrniga `som` qoʻyiladi), faqat natijani
`string` emas, `error` qilib qaytaradi ([fmt.Errorf](https://pkg.go.dev/fmt#Errorf)). Bu uchta funksiya bitta shablon
bilan ishlaydi, farqi natijada:

| Funksiya | Natija nima qiladi |
|---|---|
| `fmt.Printf` | ekranga yozadi |
| `fmt.Sprintf` | `string` qaytaradi |
| `fmt.Errorf` | `error` qaytaradi |

Toʻliq `parsePrice` quyidagi faylning 14–24-qatorlarida turibdi.

## Hammasini bozorga yigʻamiz

Endi chek kodini qaytaramiz. Boshlanishi GB-1.06 oxiridagi bozor: ishga tushish qatorlari, `var` bilan eʼlon qilingan
`name`, `price` va `active`, zero value qatori. Oʻzgarganlar: `name = "choy"` oʻrniga `name = os.Args[2]`, narx matni
esa `parsePrice`'ga beriladi. Bu holat — uzunlik tekshiruvi qoʻshilishidan oldingi bozor — `_video/05-panic/main.go`
faylida (nega shunday nomlanganini keyingi boʻlimda koʻrasiz):

```go filename="_video/05-panic/main.go" showLineNumbers
package main

import (
	"fmt"
	"os"
	"strconv"
)

const tiyinPerSom = 100    // 1 soʻm = 100 tiyin
const vatPercent = 12      // QQS, foizda
const deliverySom = 15_000 // yetkazib berish, soʻmda (QQS qoʻshilmaydi)
const maxFree = 2          // bitta buyurtmada koʻpi bilan shuncha dona bepul

// parsePrice soʻmdagi narx matnini tiyinga oʻgiradi.
func parsePrice(s string) (int64, error) {
	som, err := strconv.Atoi(s)
	if err != nil {
		return 0, err
	}
	if som <= 0 {
		return 0, fmt.Errorf("narx musbat boʻlishi kerak, keldi %d", som)
	}
	return int64(som) * tiyinPerSom, nil
}

func main() {
	fmt.Println("bozor ishga tushdi")
	fmt.Println("versiya: 0.1.0")

	var name string
	var price int64
	var active bool
	fmt.Println(name, price, active)

	name = os.Args[2]
	price, err := parsePrice(os.Args[3]) // tiyinda
	if err != nil {
		fmt.Fprintln(os.Stderr, "xato:", err)
		os.Exit(1)
	}
	active = true
	stock := 40
	weight := 1.5
	fmt.Println(name, price, active, stock, weight)

	sold := 7
	if name == "" {
		fmt.Println("xato: mahsulot nomi boʻsh")
		return
	}
	if !active {
		fmt.Printf("xato: %s sotuvda emas\n", name)
		return
	}
	if price > 10_000_000*tiyinPerSom { // price <= 0 endi parsePrice ichida
		fmt.Printf("xato: narx notoʻgʻri: %d tiyin\n", price)
		return
	}
	if sold <= 0 {
		fmt.Println("xato: miqdor kamida 1 dona boʻlishi kerak")
		return
	}
	if left := stock - sold; left < 0 {
		fmt.Printf("xato: omborda %d dona yetmaydi\n", -left)
		return
	}
	stock = stock - sold
	fmt.Println(name, stock)

	var subtotal int64
	free := 0
	for i := 1; i <= sold; i++ {
		if i%3 == 0 && free < maxFree {
			free++
			continue // aksiya: har uchinchi dona bepul
		}
		subtotal += price
	}
	vat := subtotal * vatPercent / 100

	var delivery int64 // tiyinda
	switch {
	case subtotal >= 500_000*tiyinPerSom:
		delivery = 0
	case subtotal >= 100_000*tiyinPerSom:
		delivery = 10_000 * tiyinPerSom
	default:
		delivery = deliverySom * tiyinPerSom
	}
	total := subtotal + vat + delivery

	item := fmt.Sprintf("%s, %d dona", name, sold)
	fmt.Printf("%-14s %9d.%02d\n", item, subtotal/tiyinPerSom, subtotal%tiyinPerSom)
	fmt.Printf("%-14s %9d.%02d\n", "QQS", vat/tiyinPerSom, vat%tiyinPerSom)
	fmt.Printf("%-14s %9d.%02d\n", "yetkazish", delivery/tiyinPerSom, delivery%tiyinPerSom)
	fmt.Printf("%-14s %9d.%02d\n", "jami", total/tiyinPerSom, total%tiyinPerSom)
	if free > 0 {
		fmt.Printf("aksiya: %d dona bepul\n", free)
	}
}
```

Ishga tushish qatorlaridan keyin dastur **panic** bilan yiqildi. Panic — Go dasturini darhol toʻxtatadigan favqulodda holat;
uni [GB-2.09](/lab/youtube/gb#gb-2-09) da ochamiz. Xabarni oʻqiymiz:

| Qator | Maʼnosi |
|---|---|
| `panic: runtime error:` | dastur ishlab turganda (*runtime*) xato yuz berdi |
| `index out of range [3] with length 3` | «3-indeks chegaradan tashqarida, uzunlik 3»: `os.Args`'da uchta element (`./bozor`, `add`, `olma`), oʻrinlar 0, 1 va 2; 3-oʻrin yoʻq |
| `goroutine 1 [running]:` va `main.main()` | qayerda toʻxtagani: `main` paketidagi `main` funksiyasi (*goroutine* soʻzini GB-7.01 da ochamiz) |
| `…/bozor/main.go:36 +0x953` | `main.go`, **36-qator** — `os.Args[3]` turgan `price` qatori. Boshidagi `/tmp/tmp.…` — skriptning vaqtinchalik papkasi, nomi har safar boshqa |
| `(chiqish kodi: 2)` | panic bilan yiqilgan Go dasturi 2 kodi bilan chiqadi |

35-qatordagi `os.Args[2]` muammosiz ishladi: `olma` bor. 36-qatordagi `os.Args[3]` esa yoʻq oʻringa murojaat:
spetsifikatsiyaga koʻra indeks ishlash vaqtida chegaradan chiqsa, *run-time panic* boʻladi
([Go spec: Run-time panics](https://go.dev/ref/spec#Run_time_panics)). Kompilyator buni oldindan bilolmaydi: soʻzlar soni
faqat ishga tushganda maʼlum.

## Koʻp uchraydigan xatolar

**1. Xato boʻlganda ham qiymatga ishonish (xato chiqmaydi).** Eng koʻp uchraydigan notoʻgʻri tasavvur: «`Atoi`
muvaffaqiyatsiz boʻlsa, qiymat `0` boʻladi, uni ishlataversa boʻladi». Yuqorida koʻrdik: chegaradan chiqqanda `Atoi`
`9223372036854775807` qaytaradi, `12k` uchun esa `0` — haqiqiy narx emas. Ikkala holatda ham dastur toʻxtamaydi, chek esa
notoʻgʻri narx bilan chiqardi. Tuzatish: qiymatdan oldin har doim `if err != nil` («`Atoi` faqat yozuvni tekshiradi»
boʻlimidagi jadvalga qarang).

**2. `err`'ni olib, tekshirmaslik.** Papkada yoʻq misol: `err` olinadi, lekin hech qayerda ishlatilmaydi.

```go
package main

import (
	"fmt"
	"os"
	"strconv"
)

func main() {
	price, err := strconv.Atoi(os.Args[3])
	fmt.Println("narx:", price)
}
```

```console
$ go build

./main.go:10:9: declared and not used: err
```

`main.go`, 10-qator, 9-ustun — `err`. `declared and not used: err` — «`err` eʼlon qilingan, lekin ishlatilmagan». Go funksiya
ichidagi ishlatilmagan oʻzgaruvchini rad etadi ([Go spec: Variable declarations](https://go.dev/ref/spec#Variable_declarations)),
shuning uchun xatoni «unutib qoʻyish» kompilyatsiyadan oʻtmaydi. Tuzatish: `price`'dan oldin `if err != nil { … }`.

**3. `:=` chapda yangi nom qolmaganda.** Vazifada `sold := 7` qatorini qoldirib, ostiga `sold, err := …` qoʻshsangiz shunday
boʻladi. Papkada yoʻq misol:

```go
package main

import (
	"fmt"
	"os"
	"strconv"
)

func main() {
	price, err := strconv.Atoi(os.Args[3])
	if err != nil {
		fmt.Fprintln(os.Stderr, "xato:", err)
		os.Exit(1)
	}
	sold := 7
	sold, err := strconv.Atoi(os.Args[4])
	if err != nil {
		fmt.Fprintln(os.Stderr, "xato:", err)
		os.Exit(1)
	}
	fmt.Println(price, sold)
}
```

```console
./main.go:16:12: no new variables on left side of :=
```

16-qator, 12-ustun — `:=`. `no new variables on left side of :=` — «`:=` ning chap tomonida yangi oʻzgaruvchi yoʻq»: `sold`
15-qatorda, `err` 10-qatorda eʼlon qilingan. `:=` uchun chapda kamida bitta yangi nom kerak. Tuzatish: `sold := 7`
qatorini olib tashlang; shunda `sold` yangi nom boʻladi va `sold, err := …` ishlaydi (`err`'ga shunchaki yangi qiymat beriladi).

**4. Uzunlikni tekshirmasdan `os.Args[3]`.** `panic: runtime error: index out of range [3] with length 3` va chiqish kodi 2.
Yuqoridagi tuzoq boʻlimiga qarang. Tuzatish: indeksdan oldin `if len(os.Args) != 4 || … { … os.Exit(1) }`.

**5. Terminaldan kelgan matn bilan hisoblash.** `os.Args[3] + 1` — `mismatched types string and untyped int` («Terminaldan
kelgan hamma narsa matn» boʻlimi). Tuzatish: avval `strconv.Atoi`, keyin `err` tekshiruvi, keyin hisob.

## Oʻzingizni tekshiring

**1.** `Atoi` xato qaytarsa, birinchi qiymatga ishonsa boʻladimi?

<details>
<summary>Javob</summary>

Yoʻq. Avval `err`: masalan chegaradan chiqqanda `Atoi` `0` emas, chegaradagi sonni (`9223372036854775807`) qaytaradi.
`err != nil` boʻlsa, qiymat maʼnosiz.

</details>

**2.** `./bozor add olma` buyrugʻida `os.Args`'da nechta element bor va nega uzunlik tekshiruvisiz panic chiqdi?

<details>
<summary>Javob</summary>

Uchta: `./bozor`, `add`, `olma` (indekslar 0, 1, 2). `os.Args[3]` yoʻq oʻrin, shuning uchun
`index out of range [3] with length 3`. Tuzatish: indeksdan oldin `len(os.Args)`'ni tekshirish.

</details>

**3.** GB-1.04 dan: `fmt.Sprintf` va `fmt.Printf` farqi nima, `fmt.Errorf` qaysi biriga oʻxshaydi?

</details>
