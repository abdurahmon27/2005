## Nimani oʻrganasiz

bozor'ning `Store`'i mahsulotlarni kichik harfli `products` slice'ida yashiradi, shuning uchun tashqi kod unga tegolmaydi. `List()` esa har chaqiruvda `slices.Clone` bilan butun katalogning nusxasini beradi. Katalogda 10 000 mahsulot boʻlsa va kerakli mahsulot ikkinchi oʻrinda turgan boʻlsa ham, har qidiruv hammasini koʻchiradi. Slice'ni tashqariga ochmasdan va nusxalamasdan katalogni aylanib chiqish mumkinmi?

**Bitta gʻoya:** **iterator** — `yield` funksiyasini oladigan oddiy funksiya: u qiymatlarni birma-bir `yield(v)` bilan beradi. `for p := range st.All()` yozilganda kompilyator sikl tanasini funksiyaga aylantirib, uni iteratorga `yield` sifatida beradi. Iterator va tana bitta chaqiruvlar zanjirida **navbatma-navbat** ishlaydi, oraliq slice yoʻq. `break` boʻlsa `yield` `false` qaytaradi, va toʻxtash iteratorning ishi.

Dars oxirida siz:

- `Store`'ga `All() iter.Seq[Product]` metodini yozib, ichki slice'ni ochmasdan va nusxalamasdan `for p := range st.All()` bilan aylanasiz;
- iterator va sikl tanasi navbatma-navbat ishlashini chiqishda koʻrasiz va `break` iteratorni qanday toʻxtatishini tushuntirasiz;
- `yield` natijasi tekshirilmasa nima boʻlishini (`range function continued iteration …` panic'i) bilasiz va uni tuzatasiz;
- `go doc iter.Seq`'ni oʻqiysiz va map kalitlarini `slices.Sorted(maps.Keys(m))` bilan bir qatorda tartiblaysiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| iterator | `yield` funksiyasini oladigan va qiymatlarni birma-bir shu funksiyaga beradigan funksiya | iterator |
| yield funksiyasi | iterator qiymatni uzatadigan funksiya; `range` siklida uni sikl tanasi bajaradi | yield function |
| `iter.Seq[V]` | shu funksiya turining standart nomi: `func(yield func(V) bool)` | iter.Seq |

Yordamchi soʻzlar bor joyida bir jumlada tushuntiriladi: `slices.Collect`, `iter` paketi, jonli koʻrinish (live view).

## Iterator: yield oladigan funksiya

`Store`'ga `All` metodini qoʻshamiz (`_video/01-range`). U slice emas, **funksiya** qaytaradi:

```go
func (s *Store) All() func(yield func(Product) bool) {
	return func(yield func(Product) bool) {
		for _, p := range s.products {
			if !yield(p) {
				return
			}
		}
	}
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1 | `func (s *Store) All() func(yield func(Product) bool)` | `All` — `*Store` metodi (GB-2.05). Natijasi — funksiya. Shu funksiyaning bitta parametri bor, `yield`; `yield`ning oʻzi ham funksiya: `Product` oladi, `bool` qaytaradi (GB-3.04'dagi `keep` kabi). `yield` — parametr nomi, kalit soʻz emas: Go hujjatlari uni shunday ataydi |
| 2 | `return func(yield func(Product) bool) {` | oʻsha funksiyani nomsiz funksiya qilib qaytaramiz |
| 3 | `for _, p := range s.products {` | nomsiz funksiya tashqaridagi `s`'ni koʻradi (GB-2.09) va `s.products`'ni aylanadi |
| 4–6 | `if !yield(p) { return }` | har `p` `yield`'ga beriladi. `yield` `false` qaytarsa, `return`: iterator shu yerda tugaydi |
| 7–9 | `}` `}` `}` | `if`, `for` va nomsiz funksiya yopiladi (qator 9 — `All` metodi) |

`All` nomi odatiy: butun toʻplam ustidagi iterator shunday ataladi (`go doc iter`, «Naming Conventions»). Slice tashqariga chiqmaydi. `yield`ga har mahsulotning **nusxasi** beriladi: `for _, p := range` ham shunday qiladi (GB-2.01). Faqat bitta `Product` koʻchadi, butun katalog emas.

**Iterator** — shu funksiyaning oʻzi: `yield` funksiyasini oladi va qiymatlarni birma-bir shunga beradi. Endi `main`'da `All()` natijasini `range` bilan aylanamiz:

```go filename="_video/01-range/cmd/bozor/main.go" showLineNumbers
package main

import (
	"fmt"

	"github.com/abdurahmon27/bozor/internal/store"
)

func main() {
	var st store.Store
	st.Add("olma", 1_200_000, 40)
	st.Add("non", 400_000, 3)
	st.Add("choy", 2_500_000, 8)
	st.Add("oʻrik", 3_500_000, 2)

	for p := range st.All() {
		fmt.Println(p.Name, p.Stock)
	}
}
```

`for p := range st.All()` — Go 1.23'dan beri `range` shunday funksiya ustida ham ishlaydi. Kompilyator sikl tanasini (`fmt.Println(p.Name, p.Stock)`) funksiyaga aylantiradi va uni iteratorga `yield` sifatida beradi. Tana oxiriga yetsa, bu funksiya `true` qaytaradi: iterator davom etadi.

```console
$ ./_video/run.sh 01-range go run ./cmd/bozor
olma 40
non 3
choy 8
oʻrik 2
```

Toʻrt mahsulot, katalog tartibida. Natija `List` bilan bir xil, lekin hech qanday slice nusxalanmadi.

«Kompilyator tanani funksiyaga aylantiradi» degani aynan nima? Buni qoʻlda yozib koʻrsak boʻladi. Bu misol kurs papkasida yoʻq: `_video/03-break` papkasini nusxalab, faqat `cmd/bozor/main.go`'ni almashtiring (u yerdagi `All` har qadamda matn chiqaradi, shuning uchun natija keyingi boʻlimdagi bilan solishtiriladi):

```go
package main

import (
	"fmt"

	"github.com/abdurahmon27/bozor/internal/store"
)

func main() {
	var st store.Store
	st.Add("olma", 1_200_000, 40)
	st.Add("non", 400_000, 3)
	st.Add("choy", 2_500_000, 8)
	st.Add("oʻrik", 3_500_000, 2)

	// for p := range st.All() { … } oʻrniga: iteratorni oddiy funksiya kabi chaqiramiz
	// va sikl tanasini oʻzimiz yield funksiyasi qilib beramiz.
	st.All()(func(p store.Product) bool {
		fmt.Println("sikl:", p.Name)
		if p.Stock < 5 {
			return false // break
		}
		return true // tana oxiriga yetdi
	})
	fmt.Println("sikldan keyin")
}
```

Bu yerda `st.All()` natijasi oddiy funksiya sifatida chaqirilmoqda: `st.All()(…)`. Unga oʻzimiz yozgan funksiyani — sikl tanasini — `yield` qilib beryapmiz. `return true` — «tana oxiriga yetdi», `return false` — `break`.

```console
$ go run ./cmd/bozor
iterator: olma beraman
sikl: olma
iterator: non beraman
sikl: non
iterator: yield false → toʻxtayman
sikldan keyin
```

Bu natija `03-break` qadamidagi `for … range` va `break` bilan yozilgan dasturning natijasi bilan bir xil (keyingi boʻlimda koʻrasiz). Demak `range` — shu chaqiruvning qulay yozuvi. Manbasi: Go wiki «Rangefunc Experiment» va kompilyatorning `rewrite.go` fayli, u `break` → `return false`, `continue` → `return true` deb yozadi.

## Iterator va sikl tanasi navbatma-navbat ishlaydi

Har qadamni koʻrish uchun `All`'ga vaqtincha ikki `Println` qoʻshamiz, `main`'dagi sikl tanasi esa «sikl:» bilan nomni chiqaradi (`_video/02-iz`):

```go
func (s *Store) All() func(yield func(Product) bool) {
	return func(yield func(Product) bool) {
		for _, p := range s.products {
			fmt.Println("iterator:", p.Name, "beraman")
			if !yield(p) {
				fmt.Println("iterator: yield false → toʻxtayman")
				return
			}
		}
	}
}
```

```go filename="_video/02-iz/cmd/bozor/main.go" showLineNumbers
package main

import (
	"fmt"

	"github.com/abdurahmon27/bozor/internal/store"
)

func main() {
	var st store.Store
	st.Add("olma", 1_200_000, 40)
	st.Add("non", 400_000, 3)
	st.Add("choy", 2_500_000, 8)
	st.Add("oʻrik", 3_500_000, 2)

	for p := range st.All() {
		fmt.Println("sikl:", p.Name)
	}
}
```

Birinchi `Println` — iterator `yield`'dan oldin «beraman» deydi. Ikkinchisi faqat `yield` `false` qaytarsa chiqadi: «toʻxtayman» (hozir `false` boʻlmaydi). Sikl tanasi «sikl:» soʻzi bilan mahsulot nomini chiqaradi.

Toʻrt mahsulot uchun chiqish qaysi tartibda boʻladi?

**A)** avval iteratorning toʻrt qatori, keyin siklning toʻrt qatori · **B)** iterator, sikl, iterator, sikl, … · **C)** avval siklning toʻrt qatori, keyin iteratorniki

<details>
<summary>Javob</summary>

**B: navbatma-navbat.** Iterator `olma`'ni beradi va `yield`'ni chaqiradi; tana shu zahoti «sikl: olma» chiqaradi; `yield` qaytgach, iterator `non`'ga oʻtadi, va hokazo. **A** ni tanlagan boʻlsangiz, iterator avval hamma mahsulotni yigʻib, keyin siklga beradi deb oʻylagansiz: yoʻq, hech narsa yigʻilmaydi. **C** da tana iteratordan oldin ishlagan boʻlardi, lekin tanaga qiymatni iteratorning oʻzi beradi.

</details>

```console
$ ./_video/run.sh 02-iz go run ./cmd/bozor
iterator: olma beraman
sikl: olma
iterator: non beraman
sikl: non
iterator: choy beraman
sikl: choy
iterator: oʻrik beraman
sikl: oʻrik
```

Mashinada bu oddiy funksiya chaqiruvlari. `main` iteratorni chaqiradi; iterator har `p` uchun `yield`'ni chaqiradi; `yield` — kompilyator yasagan sikl tanasi. Tana oxirigacha bajarilsa, `yield` `true` bilan qaytadi va iterator keyingi `p`'ga oʻtadi.

| Qadam | Kim ishlayapti | Ekranga |
|---|---|---|
| 1 | `main` `range st.All()`'ni boshlaydi: iteratorni chaqiradi | — |
| 2 | iterator: `p = olma`, `yield`'dan oldin matn | `iterator: olma beraman` |
| 3 | iterator `yield(p)`'ni chaqiradi — sikl tanasi ishlaydi | `sikl: olma` |
| 4 | tana oxiriga yetdi, `yield` `true` qaytaradi | — |
| 5 | iterator keyingi `p = non`'ga oʻtadi, 2-qadam takrorlanadi | `iterator: non beraman` … |

Tana ishlayotgan paytda chaqiruvlar zanjiri (`p = non`):

```text
main
 └─ iterator (All ichidagi funksiya)    p = non
     └─ yield(p)  = sikl tanasi          «sikl: non»
```

Hammasi bitta chaqiruvlar zanjirida: navbat ham, oraliq slice ham yoʻq.

## break: kim toʻxtaydi

Endi birinchi kam qolgan mahsulotni qidiramiz: qoldiq 5 dan kam boʻlsa, `break` (`_video/03-break`). Katalogda ikkinchi mahsulot `non`, qoldigʻi 3. Sikldan keyin bitta qator chiqaramiz.

```go filename="_video/03-break/cmd/bozor/main.go" showLineNumbers
package main

import (
	"fmt"

	"github.com/abdurahmon27/bozor/internal/store"
)

func main() {
	var st store.Store
	st.Add("olma", 1_200_000, 40)
	st.Add("non", 400_000, 3)
	st.Add("choy", 2_500_000, 8)
	st.Add("oʻrik", 3_500_000, 2)

	for p := range st.All() {
		fmt.Println("sikl:", p.Name)
		if p.Stock < 5 {
			break
		}
	}
	fmt.Println("sikldan keyin")
}
```

`All` oldingidek (ikki `Println` bilan). `«sikl: non»`dan keyin ekranda nima boʻladi?

**A)** `iterator: choy beraman` · **B)** `iterator: yield false → toʻxtayman` · **C)** faqat `sikldan keyin`

<details>
<summary>Javob</summary>

**B.** `break` tanani muddatidan oldin toʻxtatadi va `yield` `false` qaytaradi. Iterator buni `if !yield(p)` da koʻradi, «toʻxtayman» deb `return` qiladi. Faqat iterator qaytgandan keyin `main`'da sikldan keyingi qator ishlaydi. **A** ni tanlagan boʻlsangiz, `break` iteratorga eshittirmaydi deb oʻylagansiz: eshittiradi, `false` orqali. **C** — iterator hech narsa demay oʻchiriladi degani; lekin «toʻxtayman» qatorini iteratorning oʻzi chiqaradi.

</details>

```console
$ ./_video/run.sh 03-break go run ./cmd/bozor
iterator: olma beraman
sikl: olma
iterator: non beraman
sikl: non
iterator: yield false → toʻxtayman
sikldan keyin
```

`choy` va `oʻrik` umuman oʻqilmadi. Ketma-ketlik:

```text
break                    sikl tanasida
 └─ yield → false        tana qaytadi
     └─ if !yield(p)     iterator: return
         └─ range tugadi sikldan keyingi qator
```

Demak `break` iteratorni oʻzi toʻxtatmaydi: u faqat `false` orqali **soʻraydi**. Toʻxtash — iteratorning ishi. Buni iterator bajarmasa nima boʻlishini «Koʻp uchraydigan xatolar» boʻlimida koʻrasiz.

## Oʻlchov: List va All

Boshdagi holatni oʻlchaymiz: 10 000 mahsulotli katalogda birinchi kam qolgan mahsulot ikkinchi oʻrinda, uni `List` bilan va `All` bilan qidiramiz (`_video/09-olchov`). Benchmark'lar GB-11.01'da ochiladi; hozir faqat nima oʻlchanishi muhim.

```go filename="_video/09-olchov/internal/store/olchov_test.go" showLineNumbers
package store

import "testing"

// 10 000 mahsulotli katalogda birinchi kam qolgan mahsulotni (2-oʻrinda) topish:
// List bilan va All bilan. go test -bench . -benchmem ./internal/store
func katta() *Store {
	var st Store
	for i := range 10_000 {
		stock := 40
		if i == 1 {
			stock = 3
		}
		st.Add("olma", 1_200_000, stock)
	}
	return &st
}

func BenchmarkList(b *testing.B) {
	st := katta()
	for b.Loop() {
		for _, p := range st.List() {
			if p.Stock < 5 {
				break
			}
		}
	}
}

func BenchmarkAll(b *testing.B) {
	st := katta()
	for b.Loop() {
		for p := range st.All() {
			if p.Stock < 5 {
				break
			}
		}
	}
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|

## iter.Seq: funksiya turining nomi

Bizning funksiya turi standart kutubxonada nomlangan:

```console
$ go doc iter.Seq
package iter // import "iter"

type Seq[V any] func(yield func(V) bool)
    Seq is an iterator over sequences of individual values. When called as
    seq(yield), seq calls yield(v) for each value v in the sequence, stopping
    early if yield returns false. See the iter package documentation for more
    details.
```

Hujjat: `Seq` — qiymatlar ketma-ketligi ustidagi iterator; `seq(yield)` chaqirilganda u har `v` uchun `yield(v)`'ni chaqiradi va `yield` `false` qaytarsa, erta toʻxtaydi. (`package iter …` qatori va oxirgi «See the iter package documentation» jumlasi ham chiqadi; ular ham `go doc` natijasi.)

Birinchi qatorni oʻqiymiz:

```go
type Seq[V any] func(yield func(V) bool)
```

- `type Seq` — yangi tur nomi. Kvadrat qavsdagi `[V any]` — **tur parametri** `V`: `Seq` tur parametri boʻlgan tur. GB-3.04'da kvadrat qavs funksiyada edi, bu yerda turda.
- Asosi `func(yield func(V) bool)` — xuddi bizniki. Bu GB-2.03'dagi `type OrderStatus int`ga oʻxshaydi: nomli tur, asosi boshqa tur.
- `Seq[Product]` — `V` oʻrnida `Product`: aynan `All` qaytargan tur.

Endi `All`'ning natija turini `iter.Seq[Product]` qilamiz (`_video/05-seq`; `iter` ham import qilinadi):

```go
import (
	"iter"
	"slices"
)
```

```go
func (s *Store) All() iter.Seq[Product] {
	return func(yield func(Product) bool) {
		for _, p := range s.products {
			if !yield(p) {
				return
			}
		}
	}
}
```

Tana oʻzgarmaydi. `iter.Seq[Product]` — nomli tur, asosi oʻsha `func`. Nomsiz funksiyaning turi nomsiz, asosi bir xil: Go spec boʻyicha u nomli turga toʻgʻridan-toʻgʻri mos keladi (assignability). Imzo oʻquvchiga bu iterator ekanini aytadi. Natija `01-range` bilan bir xil:

```console

```

Standart kutubxonada aynan shu tana bor: `slices.Values(s)` slice'ni iterator qiladi (`src/slices/iter.go`, go1.27.4 GOROOT'dan):

```go
func Values[Slice ~[]E, E any](s Slice) iter.Seq[E] {
	return func(yield func(E) bool) {
		for _, v := range s {
			if !yield(v) {
				return
			}
		}
	}
}
```

Shuning uchun `All`'ni bitta qator bilan yozish mumkin. Bu variant kurs papkasida yoʻq, lekin ishga tushirilgan (`_video/05-seq` nusxasida faqat `All` almashtirilgan; `go vet` jim):

```go
	return slices.Values(s.products)
}
```

## Koʻp uchraydigan xatolar

**Xato: `yield` natijasini tekshirmaslik.** Eng tez-tez uchraydigan xato. `All`'da `if` yoʻq, `for` har doim hamma mahsulotni beradi (`_video/04-buzuq`; `main` — oldingi boʻlimdagi `break`'li sikl):

```go
func (s *Store) All() func(yield func(Product) bool) {
	return func(yield func(Product) bool) {
		for _, p := range s.products {
			fmt.Println("iterator:", p.Name, "beraman")
			yield(p)
		}
	}
}
```

Kod build boʻladi. `non`'da `break`'dan keyin nima boʻladi?

**A)** `break` eʼtiborsiz qoladi, `choy` va `oʻrik` ham tanadan oʻtadi · **B)** iterator jim aylanib tugaydi · **C)** dastur yiqiladi (panic)

<details>
<summary>Javob</summary>

**C.** `break`dan keyin `yield` `false` qaytardi, iterator esa uni tashlab yuborib, `choy` bilan `yield`'ni yana chaqirdi. Bu qoidaga zid, runtime panic qiladi. **A** — `break` iteratorga bogʻliq emas deb oʻylash; **B** — bunday jimjitlik yoʻq: Go buni panic bilan bildiradi.

</details>

Oʻqish tartibi:

1. `iterator: choy beraman` — `non`'da `break` boʻldi, lekin iterator `choy`'ga oʻtib `yield`'ni yana chaqirdi (`sikl: choy` chiqmadi).
2. `panic: runtime error: range function continued iteration after function for loop body returned false` — «sikl tanasi `false` qaytargandan keyin `range` funksiyasi aylanishni davom ettirdi». Kompilyator yasagan `yield` oʻzi `false` qaytarganini eslab turadi va qayta chaqirilsa, panic qiladi.
3. Stack: `main.main-range1` — kompilyator `main` ichidagi birinchi `range` siklining tanasidan yasagan funksiya; `store.go:39` — `yield(p)` chaqirilgan qator; `main.go:16` — `for p := range st.All()` qatori.
4. `exit status 2` — GB-2.09'dagi panic kabi.

**Tuzatish:** har `yield`'dan keyin natijani tekshiring va `false` boʻlsa, darhol `return` qiling — bu bizning `All` (yuqorida) va `slices.Values` tanasi. Go spec qoidasi: sikl tanasi `break` bilan erta toʻxtasa, `yield` `false` qaytaradi va uni qayta chaqirib boʻlmaydi. Muharrir yordam bermaydi: `gopls`'da shunday tahlilchi bor (`yield may be called again after returning false`), lekin u faqat `iter`'ni import qilgan paketni tekshiradi, va bu yerdagi `gopls` v0.22.0 `go 1.27` modulini tahlil qilmadi, `gopls check` jim qoldi. Shuning uchun xatoga muharrirga emas, `if !yield(p) { return }` qoidasiga tayaning.

**`return`'dan keyin `defer` ishlaydi.** Iterator ichida fayl ochilgan boʻlsa, uni `defer` bilan yopsangiz, sikl `break` qilganda ham yopiladi: `yield` `false` qaytaradi, iterator `return` qiladi, uning `defer`'i ishlaydi, shundan keyingina `range` tugaydi (`_video/10-defer`; `katalog.txt` shu papkada; demoda fayl ochish xatosi tashlab yuborilgan):

```go filename="_video/10-defer/cmd/bozor/main.go" showLineNumbers
// Iterator ichidagi defer: sikl break qilsa ham, iterator return qilganda fayl yopiladi.
// (Demo: ochish xatosi tashlab yuborilgan; ishda xatoni ham qaytaring.)
package main

import (
	"bufio"
	"fmt"
	"iter"
	"os"
)

// lines faylni qatorma-qator beradi (GB-3.01'dagi bufio.Scanner).
func lines(name string) iter.Seq[string] {
	return func(yield func(string) bool) {
		f, err := os.Open(name)
		if err != nil {
			return
		}
		defer func() {
			f.Close()
			fmt.Println("iterator: fayl yopildi")
		}()
		sc := bufio.NewScanner(f)
		for sc.Scan() {
			if !yield(sc.Text()) {
				return
			}
		}
	}
}

func main() {
	for line := range lines("katalog.txt") {
		fmt.Println("sikl:", line)
		break
	}
	fmt.Println("sikldan keyin")
}
```

```go
func (s *Store) LowStock(limit int) iter.Seq[Product] {
	return func(yield func(Product) bool) {
		for _, p := range s.products {
			if p.Stock >= limit {
				continue
			}
			if !yield(p) {
				return
			}
		}
	}
}
```

`SortedNames` — papkadagi tayyor `Names()` iteratoridan bitta qator:

```go
func (s *Store) SortedNames() []string {
	return slices.Sorted(s.Names())
}
```

`slices.Sorted` yangi slice yasaydi, shuning uchun unga yozish katalogni oʻzgartirmaydi. Eslatma (`TASK.md`): `slices.Sorted(st.All())` kompilyatsiya boʻlmaydi — `Product`'ni `<` bilan solishtirib boʻlmaydi; `Names()` esa `iter.Seq[string]`. Javob bilan tekshirish:
