## Nimani oʻrganasiz

Oʻtgan darsdagi bozor yuz kvadrillion soʻmlik olmani qabul qildi va chekka manfiy narx yozdi:

```console
$ ./_video/run.sh 00-gb107 bash -c 'go build && ./bozor add olma 100000000000000000 1'
bozor ishga tushdi
versiya: 0.1.0

olma -8446744073709551616 true 40 1.5
olma 39
olma, 1 dona   -84467440737095516.-16
QQS            -912720851596686.-13
yetkazish          15000.00
jami           -85380161588677202.-29
```

Narx, QQS va jami manfiy, nuqtadan keyin ham minus bor. Kod har bir buyruqni tekshirgan edi, lekin bunday kirishni hech
kim sinab koʻrmagan. Bu xatoni qoʻlda emas, dastur bilan qanday topasiz va u qaytib kelmasligiga qanday ishonch hosil
qilasiz?

**Bitta gʻoya:** `go test` paketingizni `_test.go` fayllari bilan birga alohida **test dasturiga** kompilyatsiya qiladi va
har bir `TestXxx(t)` funksiyasini chaqiradi. `t.Errorf` faqat `t`ga «yiqildi» belgisini qoʻyadi, funksiya davom etadi;
`t.Fatalf` shu test funksiyasini toʻxtatadi. Dastur oxirida belgi boʻlsa, `FAIL` yozadi va 1 kodi bilan chiqadi.

Dars oxirida siz:

- Go funksiyasiga test yozasiz va uni `go test`, `go test -v` bilan ishga tushirasiz;
- yiqilgan testning xabarini qatorma-qator oʻqiysiz: qaysi test, qaysi fayl va qator, nima qaytdi, nima kutilgan edi;
- jadvalli test yozasiz: holatlar maʼlumot boʻlib yoziladi, tekshiruv kodi bitta, har qator `t.Run` bilan alohida subtest;
- bozor'dagi ikki haqiqiy xatoni test bilan topib, tuzatasiz va bitta subtest'ni `-run` bilan alohida ishga tushirasiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| test fayli va `go test` | nomi `_test.go` bilan tugaydigan fayl; undagi `func TestXxx(t *testing.T)` funksiyalarini `go test` alohida test dasturida chaqiradi, `go build` esa bu faylni binary'ga qoʻshmaydi | test file, `go test` |
| `t.Errorf` | xabar yozadi va testni «yiqildi» deb belgilaydi, lekin funksiya davom etadi | `t.Errorf` |
| jadvalli test | holatlar roʻyxati (`name`, `in`, `want`, `wantErr`) va ularni bitta sikl bilan tekshiradigan kod; har qator — alohida **subtest** | table-driven test, subtest |

Ikkita yordamchi soʻz: **`t.Fatalf`** — `t.Errorf` kabi xabar yozadi, lekin shu test funksiyasini (yoki subtest'ni) darhol
toʻxtatadi; **`-v` va `-run`** — `go test` bayroqlari: `-v` har bir test nomini chiqaradi, `-run` faqat nomi shablonga mos
testlarni ishga tushiradi.

## Xato qayerda: Atoi'da emas, koʻpaytirishda

Darsning boshidagi `100000000000000000` (10¹⁷) `Atoi` uchun toʻgʻri son: bu kompyuterda `int` 8 bayt, ya'ni eng kattasi
9 223 372 036 854 775 807 (qariyb toʻqqiz kvintillion), 10¹⁷ unga sigʻadi. Muammo `parsePrice`ning oxirgi qatorida:
`int64(som) * tiyinPerSom`. Natija 10¹⁹ boʻlishi kerak edi, bu `int64` chegarasidan oshadi va GB-1.03 dagidek ortigʻi
aylanib, manfiy son chiqadi ([Go spec: Integer overflow](https://go.dev/ref/spec#Integer_overflow)):

| Qadam | Qiymat |
|---|---|
| `s` (kirish matni) | `"100000000000000000"` |
| `som, err := strconv.Atoi(s)` | `som` = 100 000 000 000 000 000, `err` = `nil`: son `int`ga sigʻdi |
| `int64(som) * tiyinPerSom` — kerakli natija | 10 000 000 000 000 000 000 = 10¹⁹ > 9 223 372 036 854 775 807 |
| `int64(som) * tiyinPerSom` — haqiqiy natija | 10¹⁹ − 2⁶⁴ = **−8 446 744 073 709 551 616**: overflow |

Chekdagi birinchi qator — shu manfiy tiyinning soʻmga boʻlingani: `-84467440737095516.-16`.

Bugun shu xatoni test bilan topasiz va tuzatasiz. Uch narsa kerak:

1. test fayli va `go test` buyrugʻi;
2. `t.Errorf`, ya'ni test yiqilganini bildirish: nima va nega;
3. jadvalli test: koʻp holatni bitta tekshiruv bilan sinash.

## Test fayli va test funksiyasi

**Test** — oddiy Go kodi, alohida faylda. Fayl nomining boshini oʻzingiz tanlaysiz, bu yerda `price`, lekin oxiri
`_test.go` boʻlishi shart. `go build` bunday faylni bozor binary'siga qoʻshmaydi, `go test` esa uni topadi
([pkg.go.dev/testing](https://pkg.go.dev/testing): «excluded from regular package builds but will be included when the
"go test" command is run»). Birinchi test ikki holatni tekshiradi (`_video/01-test/price_test.go`):

```go filename="_video/01-test/price_test.go" showLineNumbers
package main

import "testing"

func TestParsePrice(t *testing.T) {
	got, err := parsePrice("12000")
	if err != nil || got != 1_200_000 {
		t.Errorf("parsePrice(%q) = %d, %v; kutilgan %d, xatosiz", "12000", got, err, 1_200_000)
	}
	got, err = parsePrice("500")
	if err != nil || got != 50_000 {
		t.Errorf("parsePrice(%q) = %d, %v; kutilgan %d, xatosiz", "500", got, err, 50_000)
	}
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1 | `package main` | paket `main.go` bilan bir xil: shuning uchun test `parsePrice`ni toʻgʻridan-toʻgʻri chaqira oladi |
| 3 | `import "testing"` | standart kutubxonadagi test paketi |
| 5 | `func TestParsePrice(t *testing.T) {` | test funksiyasi: nomi `Test` bilan boshlanadi, undan keyingi harf kichik boʻlmasin. Parametr `t`, turi `testing.T`: natijani shu `t` orqali bildirasiz. Turdagi yulduzcha `*` — **pointer**, uni [GB-2.04](/lab/youtube/gb/gb-2-04) da ochamiz |
| 6 | `got, err := parsePrice("12000")` | oddiy chaqiruv: 12 000 soʻm, natija `got` va `err` (*got* — «olingan») |
| 7 | `if err != nil \|\| got != 1_200_000 {` | shart: xato bor, **yoki** natija 1 200 000 tiyin emas. `\|\|` — «yoki» (GB-1.05) |
| 8 | `t.Errorf(…)` | Printf shabloni bilan xabar yozadi va testni yiqilgan deb belgilaydi. `%q` matnni qoʻshtirnoq bilan chiqaradi (GB-1.04) |
| 9 | `}` | `if` tugadi. Eʼtibor bering: `Errorf`'dan keyin `return` yoʻq |
| 10 | `got, err = parsePrice("500")` | ikkinchi holat: 500 soʻm = 50 000 tiyin. `got` va `err` allaqachon bor, shuning uchun ikki nuqtasiz `=` (GB-1.02) |
| 11–13 | `if …` / `t.Errorf(…)` / `}` | tekshiruv birinchisi bilan bir xil |
| 14 | `}` | test funksiyasi tugadi |

Xabar tartibi Go'da odatiy: **nima chaqirildi, nima qaytdi, nima kutilgan edi** — `parsePrice("12000") = …; kutilgan …`
([Go Code Review Comments: Useful Test Failures](https://go.dev/wiki/CodeReviewComments#useful-test-failures)). Yiqilgan
test xabarini oʻqigan odam kodni ochmasdan ham nima boʻlganini tushunadi.

## `go test` va `go test -v`

Ishga tushiramiz. **`go test`** paketni test fayllari bilan birga kompilyatsiya qiladi va har bir `Test` funksiyasini
chaqiradi ([go help test](https://pkg.go.dev/cmd/go#hdr-Test_packages)):

```console
$ ./_video/run.sh 01-test go test
PASS
ok  	github.com/abdurahmon27/bozor	0.006s
```

`PASS` — hamma test oʻtdi. `ok` qatorida paket yoʻli (`go.mod`dagi modul nomi, GB-1.01) va testga ketgan vaqt. `-v`
(*verbose*) bayrogʻi bilan har bir test nomi ham chiqadi ([go help testflag](https://pkg.go.dev/cmd/go#hdr-Testing_flags)):

```console
$ ./_video/run.sh 01-test go test -v
=== RUN   TestParsePrice
--- PASS: TestParsePrice (0.00s)
PASS
ok  	github.com/abdurahmon27/bozor	0.002s
```

`=== RUN` — test boshlandi, `--- PASS` — oʻtdi, qavs ichida shu testning oʻz vaqti.

## Testni bir marta yiqilgan holda koʻring

Testga ishonish uchun uni bir marta yiqilgan holda koʻring: hech qachon yiqilmagan test hech narsani tekshirmayotgan
boʻlishi mumkin. `parsePrice`ning oxirgi qatoridan yuzga koʻpaytirishni olib tashlaymiz, goʻyo kimdir narx allaqachon
tiyinda deb oʻylagan (`_video/02-buzuq/main.go`, 23-qator; `price_test.go` oʻsha-oʻsha):

```go
// parsePrice soʻmdagi narx matnini tiyinga oʻgiradi.
func parsePrice(s string) (int64, error) {
	som, err := strconv.Atoi(s)
	if err != nil {
		return 0, err
	}
	if som <= 0 {
		return 0, fmt.Errorf("narx musbat boʻlishi kerak, keldi %d", som)
	}
	return int64(som), nil
}
```

Ikkala holat ham notoʻgʻri natija beradi. `go test` nechta xato qatorini chiqaradi?

**A)** 1: birinchi xatoda toʻxtaydi · **B)** 2: ikkala holat · **C)** kompilyatsiya xatosi

<details>
<summary>Javob</summary>

**B: ikkita qator.** `t.Errorf` testni toʻxtatmaydi, keyingi qatorlar bajarilaveradi: 10-qatordagi ikkinchi chaqiruv ham
ishlaydi va oʻz xabarini yozadi. **A** ni tanlagan boʻlsangiz, `t.Errorf` testni toʻxtatadi deb oʻylagansiz: toʻxtatadigani
`t.Fatalf`, uni jadvalda koʻramiz. **C** — kod kompilyatsiya boʻladi: `int64(som)` ham `int64`, funksiya turi oʻzgarmadi.

</details>

## `go test` ichida nima boʻladi

`exit status 1` qayerdan chiqdi? `go test` `main.go` va `price_test.go` fayllaridan vaqtinchalik **test dasturini** yasaydi.
U `TestParsePrice`ni chaqirib, unga `t`ni beradi. `t.Errorf` faqat `t`ga «yiqildi» degan belgi qoʻyadi. Funksiya tugagach,
dastur belgini koʻradi, `FAIL` yozadi va 1 kodi bilan chiqadi ([go help test](https://pkg.go.dev/cmd/go#hdr-Test_packages):
«compiles the package sources and tests found in the current directory and then runs the resulting test binary»):

```text
 main.go + price_test.go        (bitta package main)
            │  go test kompilyatsiya qiladi
            ▼
 test dasturi ──► TestParsePrice(t)
                     │ 8-qator:  t.Errorf → t: «yiqildi» ✗, funksiya davom etadi
                     │ 12-qator: t.Errorf → t: «yiqildi» ✗ (yana xabar)
                     ▼
            funksiya tugadi: t'da belgi bor
                     ▼
 FAIL  →  exit status 1  →  go test: FAIL github.com/abdurahmon27/bozor
```

`t.Errorf` hujjatda shunday yozilgan: «Errorf is equivalent to Logf followed by Fail» — xabar yozish va belgi qoʻyish,
boshqa hech narsa ([pkg.go.dev/testing](https://pkg.go.dev/testing)). Koʻpaytirishni joyiga qaytaramiz va jadvalga oʻtamiz.

## Jadvalli test

Endi boshidagi ulkan kirishni, harfli matnni, nolni va chegaralarni qoʻshmoqchimiz. Har holat uchun uch qatorni nusxalash
xato manbai: bitta joyda raqamni almashtirib, ikkinchisida unutasiz. Go'da odatiy yoʻl — **jadvalli test** (*table-driven
test*): holatlar maʼlumot boʻlib yoziladi, tekshiruv kodi bitta ([Go wiki: TableDrivenTests](https://go.dev/wiki/TableDrivenTests)).
Bu papkadagi `price_test.go`:

```go filename="price_test.go" showLineNumbers
package main

import "testing"

func TestParsePrice(t *testing.T) {
	tests := []struct {
		name    string
		in      string
		want    int64
		wantErr bool
	}{
		{"oddiy", "12000", 1_200_000, false},
		{"chegara", "10000000", 1_000_000_000, false},
		{"harf", "12k", 0, true},
		{"nol", "0", 0, true},
		{"ortiq", "10000001", 0, true},
		{"ulkan", "100000000000000000", 0, true},
	}
	for _, tc := range tests {
		t.Run(tc.name, func(t *testing.T) {
			got, err := parsePrice(tc.in)
			if (err != nil) != tc.wantErr {
				t.Fatalf("parsePrice(%q) = %d, %v; xato kutilgan: %v", tc.in, got, err, tc.wantErr)
			}
			if got != tc.want {
				t.Errorf("parsePrice(%q) = %d; kutilgan %d", tc.in, got, tc.want)
			}
		})
	}
}
```

**Jadval (6–18-qatorlar):**

| Qator | Kod | Nima qiladi |
|---|---|---|
| 6 | `tests := []struct {` | `tests` degan oʻzgaruvchi. **`struct`** bir nechta nomlangan maydonni bitta qiymatga yigʻadi (batafsil [GB-2.03](/lab/youtube/gb/gb-2-03)). Oldidagi `[]` — shunday qiymatlar roʻyxati, **slice** (keyingi dars, [GB-2.01](/lab/youtube/gb/gb-2-01)) |
| 7 | `name    string` | holat nomi (subtest nomi boʻladi) |
| 8 | `in      string` | kirish matni |
| 9 | `want    int64` | kutilgan natija, tiyinda |
| 10 | `wantErr bool` | xato kutilyaptimi: `true` yoki `false` |
| 11 | `}{` | `}` struct turini yopadi, `{` qatorlar roʻyxatini ochadi |
| 12 | `{"oddiy", "12000", 1_200_000, false},` | har qator — jingalak qavs ichida maydonlar tartibida (`name`, `in`, `want`, `wantErr`), oxirida vergul |
| 13 | `{"chegara", "10000000", 1_000_000_000, false},` | 10 mln soʻm: GB-1.05 dagi qoidaga koʻra u **oʻtishi** kerak |
| 14–17 | `harf`, `nol`, `ortiq`, `ulkan` | xato berishi kerak (`true`): `12k`, `0`, chegaradan bir soʻm ortiq (10 000 001) va boshidagi ulkan son |
| 18 | `}` | roʻyxat tugadi |

Oxirgi vergul (17-qatordagi ham) shart: qator oxirida `}` boʻlsa, Go oʻsha yerga yashirin nuqtali vergul qoʻyadi, vergul
esa bunga yoʻl qoʻymaydi ([Go spec: Semicolons](https://go.dev/ref/spec#Semicolons)). Xatolar koʻpincha aynan chegarada
boʻladi, shuning uchun 10 000 000 va 10 000 001 ikkalasi ham jadvalda. Chegaraning ikki tomonidagi bunday qiymat —
**chegara qiymati** (*boundary value*).

**Sikl (19–29-qatorlar):**

| Qator | Kod | Nima qiladi |
|---|---|---|
| 19 | `for _, tc := range tests {` | GB-1.06 da `range` songacha sanagan edi. Roʻyxat ustida u ikki qiymat beradi: tartib raqami va qatorning oʻzi. Raqam kerak emas, pastki chiziq `_` uni tashlaydi. Qator `tc` degan oʻzgaruvchiga tushadi (*test case*) |
| 20 | `t.Run(tc.name, func(t *testing.T) {` | **`t.Run`** har qatorni alohida **subtest** qilib ishga tushiradi. Birinchi argument — nomi: `tc.name`, nuqta qatorning maydonini oʻqiydi. Ikkinchisi — **nomsiz funksiya**: `func`, parametr va tana nomsiz yozilib, toʻgʻridan-toʻgʻri argument boʻladi. Uning `t`si boshqa `t`, subtest'niki |
| 21 | `got, err := parsePrice(tc.in)` | shu qatorning kirishi bilan chaqiruv |
| 22 | `if (err != nil) != tc.wantErr {` | qavsdagi `err != nil` — «xato bormi» degan `bool`. U `wantErr`'ga teng boʻlmasa, xato kutilgandek emas |
| 23 | `t.Fatalf(…)` | **`t.Fatalf`**: xuddi `Errorf` kabi xabar yozadi, lekin shu subtest'ni darhol toʻxtatadi. Xato kutilmaganda kelgan (yoki kutilganda kelmagan) boʻlsa, `got`'ni tekshirishning maʼnosi yoʻq |
| 25–26 | `if got != tc.want {` / `t.Errorf(…)` | `got`'ni `want` bilan solishtiradi; bu yerda oddiy `Errorf` |
| 28 | `})` | `}` nomsiz funksiyani, `)` `t.Run` chaqiruvini yopadi |
| 29–30 | `}` / `}` | sikl va `TestParsePrice` tugadi |

`t.Fatalf` hujjatda: «Fatalf is equivalent to Logf followed by FailNow» — `FailNow` shu test funksiyasining ishini
toʻxtatadi, boshqa subtest'lar esa ishlayveradi ([pkg.go.dev/testing#T.Fatalf](https://pkg.go.dev/testing#T.Fatalf),
[T.Run](https://pkg.go.dev/testing#T.Run), [Go blog: Using Subtests](https://go.dev/blog/subtests)).

```go filename="main.go" showLineNumbers
package main

import (
	"fmt"
	"os"
	"strconv"
)

const tiyinPerSom = 100        // 1 soʻm = 100 tiyin
const vatPercent = 12          // QQS, foizda
const deliverySom = 15_000     // yetkazib berish, soʻmda (QQS qoʻshilmaydi)
const maxFree = 2              // bitta buyurtmada koʻpi bilan shuncha dona bepul
const maxPriceSom = 10_000_000 // bitta mahsulot narxining yuqori chegarasi, soʻmda

// parsePrice soʻmdagi narx matnini tiyinga oʻgiradi.
func parsePrice(s string) (int64, error) {
	som, err := strconv.Atoi(s)
	if err != nil {
		return 0, err
	}
	if som <= 0 {
		return 0, fmt.Errorf("narx musbat boʻlishi kerak, keldi %d", som)
	}
	if som > maxPriceSom {
		return 0, fmt.Errorf("narx %d soʻmdan oshmasin, keldi %d", maxPriceSom, som)
	}
	return int64(som) * tiyinPerSom, nil
}

// parseSold sotilgan dona sonini matndan oʻgiradi: kamida 1 dona.
func parseSold(s string) (int, error) {
	n, err := strconv.Atoi(s)
	if err != nil {
		return 0, err
	}
	if n < 1 {
		return 0, fmt.Errorf("miqdor kamida 1 boʻlishi kerak, keldi %d", n)
	}
	return n, nil
}

func main() {
	fmt.Println("bozor ishga tushdi")
	fmt.Println("versiya: 0.1.0")

	var name string
	var price int64
	var active bool
	fmt.Println(name, price, active)

	if len(os.Args) != 5 || os.Args[1] != "add" {
		fmt.Fprintln(os.Stderr, "foydalanish: bozor add NOM NARX MIQDOR")
		os.Exit(1)
	}
	name = os.Args[2]
	price, err := parsePrice(os.Args[3]) // tiyinda
	if err != nil {
		fmt.Fprintln(os.Stderr, "xato:", err)
		os.Exit(1)
	}
	active = true
	stock := 40
	weight := 1.5
	fmt.Println(name, price, active, stock, weight)

	sold, err := parseSold(os.Args[4])
	if err != nil {
		fmt.Fprintln(os.Stderr, "xato:", err)
		os.Exit(1)
	}
	if name == "" {
		fmt.Println("xato: mahsulot nomi boʻsh")
		return
	}
	if !active {
		fmt.Printf("xato: %s sotuvda emas\n", name)
		return
	}
	if left := stock - sold; left < 0 {
		fmt.Printf("xato: omborda %d dona yetmaydi\n", -left)
		return
	}
	stock = stock - sold
	fmt.Println(name, stock)

	var subtotal int64
	free := 0
	for i := 1; i <= sold; i++ {
		if i%3 == 0 && free < maxFree {
			free++
			continue // aksiya: har uchinchi dona bepul
		}
		subtotal += price
	}
	vat := subtotal * vatPercent / 100

	var delivery int64 // tiyinda
	switch {
	case subtotal >= 500_000*tiyinPerSom:
		delivery = 0
	case subtotal >= 100_000*tiyinPerSom:
		delivery = 10_000 * tiyinPerSom
	default:
		delivery = deliverySom * tiyinPerSom
	}
	total := subtotal + vat + delivery

	item := fmt.Sprintf("%s, %d dona", name, sold)
	fmt.Printf("%-14s %9d.%02d\n", item, subtotal/tiyinPerSom, subtotal%tiyinPerSom)
	fmt.Printf("%-14s %9d.%02d\n", "QQS", vat/tiyinPerSom, vat%tiyinPerSom)
	fmt.Printf("%-14s %9d.%02d\n", "yetkazish", delivery/tiyinPerSom, delivery%tiyinPerSom)
	fmt.Printf("%-14s %9d.%02d\n", "jami", total/tiyinPerSom, total%tiyinPerSom)
	if free > 0 {
		fmt.Printf("aksiya: %d dona bepul\n", free)
	}
}
```

## Oʻzingizni tekshiring

**1.** `t.Errorf` va `t.Fatalf` farqi nima?

<details>
<summary>Javob</summary>

Ikkalasi ham xabar yozadi va testni yiqilgan deb belgilaydi. `Errorf` shundan keyin davom etadi, `Fatalf` shu test
funksiyasini (subtest'ni) darhol toʻxtatadi. Keyingi tekshiruvning maʼnosi qolmasa `Fatalf`, qolsa `Errorf`.

</details>

**2.** Jadvalli testga yangi holat — manfiy narx `-5` — qoʻshish uchun nima qilasiz?

<details>

</details>

**5.** Darsning boshidan: `strconv.Atoi("100000000000000000")` nega xatosiz oʻtdi, `parsePrice` esa manfiy son qaytardi?

<details>
<summary>Javob</summary>

Bu kompyuterda `int` 8 bayt: 10¹⁷ unga sigʻadi, `Atoi` uchun bu toʻgʻri son. Muammo keyingi qadamda: `× 100` dan keyin
