## Что вы узнаете

Чек магазина bozor печатает название товара в колонку из 10 символов, а длинное название обрезает. Но у `oʻrik qoqi` («курага») пропала последняя
буква, а `paxta yogʻi` («хлопковое масло») вышло с битым символом в конце. Почему так, и как сократить узбекское название, ничего не сломав?

**Одна идея:** `string` в Go — неизменяемая последовательность байтов, а текст в коде записан в UTF-8: каждый символ занимает 1–4 байта
(`oʻrik` («абрикос») = 5 символов, 6 байт). `len`, индекс `s[i]` и срез `s[a:b]` работают с **байтами**. А `for i, r := range s` читает UTF-8 и на каждом
шаге отдаёт одну **руну** и индекс байта, с которого она начинается. Поэтому строку безопасно обрезать только по индексу, который дал `range`.

К концу урока вы:

- увидите, почему `len("oʻrik")` равно 6, и выведете сами байты через `% x`;
- обойдёте строку по символам (рунам) через `for i, r := range name` и посчитаете руны пакетом `unicode/utf8`;
- увидите в настоящей ошибке, как `name[:n]` режет символ посередине, и исправите функцию `short`, чтобы она резала по границе руны;
- напишете в задании `shortLabel` (с `…`) и `checkName` (пустое название, не UTF-8, длиннее 20 рун) — пока не пройдёт `go test`.

Три главных новых слова урока:

| Слово | Простой смысл | По-английски |
|---|---|---|
| UTF-8 | правило записи Unicode-номера символа в 1–4 байта; строка Go состоит из этих байтов | UTF-8 |
| руна | Unicode-номер одного символа (code point), тип `int32`; это не то же самое, что буква: `oʻ` — одна буква, но две руны | rune |
| граница руны | байт, на котором одна руна закончилась и началась следующая; строку безопасно резать только здесь | rune boundary |

Вспомогательные понятия объясняются одной фразой там, где встречаются впервые: **Unicode**, **code point**, **шестнадцатеричная запись** (hex),
пакет `unicode/utf8` и глаголы `Printf` `%x`, `%c`, `%U`.

## Проблема: две ошибки в чеке

Чек печатает каждое название товара в колонку из 10 символов в квадратных скобках. С тремя названиями программа выдаёт вот что
(`_video/00-chek` — первое состояние из видео; его код мы разберём в последнем основном разделе страницы):

```console
$ ./_video/run.sh 00-chek go run .
[olma      ]
[oʻrik qoq ]
[paxta yog�]
```

Здесь две ошибки:

- `oʻrik qoqi` — 10 символов, в колонку из 10 символов он должен помещаться. Но последняя `i` пропала.
- `paxta yogʻi` — в конце вместо `ʻ` вышел `�` (ромб с вопросительным знаком). Так терминал рисует недопустимый байт.

Обе ошибки из одной причины: программа измеряет текст **байтами**, а вы видите символы. Сначала посмотрим, что лежит внутри строки,
потом исправим ошибку.

## Что считает `len`

В переменной `name` лежит `oʻrik`. `len` для слайса возвращал число элементов (GB-2.01); для строки он тоже работает. Программа
(`_video/01-len/main.go`):

```go filename="_video/01-len/main.go" showLineNumbers
package main

import "fmt"

func main() {
	name := "oʻrik"
	fmt.Println(len(name))
}
```

| Строка | Код | Что делает |
|---|---|---|
| 1 | `package main` | этот файл — исполняемая программа (GB-1.01) |
| 3 | `import "fmt"` | подключает пакет `fmt` ради `Println` |
| 5 | `func main() {` | программа начинается с этой функции |
| 6 | `name := "oʻrik"` | создаёт переменную `name`, внутри текст `oʻrik` (GB-1.02) |
| 7 | `fmt.Println(len(name))` | печатает результат `len(name)` |

На экране в `oʻrik` видно 5 символов: `o`, `ʻ`, `r`, `i`, `k`. А `oʻ` в узбекском алфавите — одна буква. Что выведется?

**A)** `4`, потому что `oʻ` — одна буква · **B)** `5`, потому что на экране пять символов · **C)** `6`

<details>
<summary>Ответ</summary>

**C: `6`.** `len` считает **байты** строки: не буквы и не символы на экране
([Go spec: String types](https://go.dev/ref/spec#String_types): «The number of bytes is called the length of the string»).
Если вы выбрали **A**, вы посчитали `oʻ` за одну. Если выбрали **B**, вы решили, что `len` считает символы на экране.

</details>

```console
$ ./_video/run.sh 01-len go run .
6
```

Чтобы увидеть, какой байт откуда взялся, выведем сами байты.

## Смотрим на сами байты

У `fmt.Printf` появляется новый глагол `%x`: он выводит значение в **hex**, то есть в **шестнадцатеричной записи** (цифры 0–9 и a–f; `a` = 10, `f` = 15).
Для строки `%x` записывает каждый байт двумя hex-цифрами. Пробел между `%` и `x` ставит пробелы и между байтами: `% x`.
Программа (`_video/02-bayt/main.go`):

```go filename="_video/02-bayt/main.go" showLineNumbers
package main

import "fmt"

func main() {
	name := "oʻrik"
	fmt.Println(len(name))
	fmt.Printf("% x\n", name)
}
```

Новая строка — 8-я: `fmt.Printf("% x\n", name)`. `"% x\n"` — шаблон (GB-1.04), `% x` — вывести байты в hex через пробел, `\n` — конец строки. Сколько
hex-пар выведется на экран?

<details>
<summary>Ответ</summary>

Шесть: `len(name)` = 6 байт, каждый байт — одна пара. Разница между 6 и 5 — ответ на предыдущий вопрос: один символ может занимать несколько байтов.

</details>

```console
$ ./_video/run.sh 02-bayt go run .
6
6f ca bb 72 69 6b
```

Шесть байтов. Какой байт к какому символу относится:

```text
индекс байта:   0    1  2    3    4    5
байт (hex):     6f   ca bb   72   69   6b
символ:         o    ʻ       r    i    k
```

Первый байт `6f` — буква `o`. Следующие два байта `ca bb` **вместе** — один символ: перевёрнутая запятая `ʻ` из `oʻ`. Потом `r`, `i`
и `k`, по одному байту.

Вот почему. **Unicode** — пронумерованный список символов всего мира. Номер символа называется **code point** и записывается как
`U+02BB` (после `U+` идёт hex-число): `ʻ` — это U+02BB (MODIFIER LETTER TURNED COMMA, [таблица Unicode](https://www.unicode.org/charts/PDF/U02B0.pdf)).
**UTF-8** — правило записи этого номера в байты: каждый code point занимает от 1 до 4 байтов. Латинские буквы a–z, цифры и обычные знаки
препинания (**ASCII**) — один байт. `ʻ` — два байта. Исходный файл Go записан в UTF-8
([Go spec: Source code representation](https://go.dev/ref/spec#Source_code_representation)), поэтому и текст в кавычках лежит в памяти в виде этих байтов.
Строка неизменяема: её байты нельзя заменить на месте (эту ошибку вы увидите ниже, в разделе «Частые ошибки»).

Сколько байтов занимают другие символы, тоже можно посмотреть. Следующей программы нет в папке курса: я запустил её в отдельной папке с тем же `go.mod`.
`[]rune(s)[0]` — первый символ `s` (эту запись объясняет ниже раздел «Глубже»), `%U` — его code point:

```go
package main

import "fmt"

func main() {
	for _, s := range []string{"a", "ʻ", "…", "😀"} {
		fmt.Printf("%q: %d bayt, %U\n", s, len(s), []rune(s)[0])
	}
}
```

```console
$ go run .
"a": 1 bayt, U+0061
"ʻ": 2 bayt, U+02BB
"…": 3 bayt, U+2026
"😀": 4 bayt, U+1F600
```

(В шаблоне слово `bayt` — «байт»: вывод общий для всех языков страницы.) Правило ([RFC 3629](https://www.rfc-editor.org/rfc/rfc3629#section-3), раздел 3):

| Диапазон code point | Байтов | Пример |
|---|---|---|
| `U+0000`–`U+007F` (ASCII) | 1 | `a` |
| `U+0080`–`U+07FF` | 2 | `ʻ` (U+02BB) |
| `U+0800`–`U+FFFF` | 3 | `…` (U+2026) |
| `U+10000`–`U+10FFFF` | 4 | `😀` (U+1F600) |

## Индекс тоже отдаёт байт

Индекс в квадратных скобках тоже работает с байтами: `name[0]` — первый байт, `name[1]` — второй (индексы идут с 0, GB-2.01).
Программа (`_video/03-indeks/main.go`):

```go filename="_video/03-indeks/main.go" showLineNumbers
package main

import "fmt"

func main() {
	name := "oʻrik"
	fmt.Println(name[0], name[1])
}
```

Строка 7 печатает `name[0]` и `name[1]` в одной строке (`Println` ставит пробел между аргументами). Что выведется: буквы или числа?

<details>
<summary>Ответ</summary>

**Числа.** Индекс возвращает значение типа `byte` ([Go spec: Index expressions](https://go.dev/ref/spec#Index_expressions)); `byte` — тип из GB-2.07,
число от 0 до 255. `Println` выводит число как число.

</details>

```console
$ ./_video/run.sh 03-indeks go run .
111 202
```

Это те же байты из предыдущего шага, только в десятичной записи: `6f` = 6 × 16 + 15 = 111 (байт буквы `o`), `ca` = 12 × 16 + 10 = 202
(первый байт символа `ʻ`). `name[1]` — не символ, а **половина** символа.

Итог: `len`, `name[i]` и (ниже увидим) `name[a:b]` работают с байтами. Чтобы получить символы, нужен другой способ.

## `for range`: один шаг — один символ

`range` по слайсу отдавал индекс и элемент (GB-2.01). `range` по **строке** читает UTF-8: на каждом шаге один символ, то есть
один code point. `i` — индекс байта, с которого начинается этот символ, `r` — сам символ. Программа (`_video/04-range/main.go`):

```go filename="_video/04-range/main.go" showLineNumbers
package main

import "fmt"

func main() {
	name := "oʻrik"
	for i, r := range name {
		fmt.Printf("%d %c\n", i, r)
	}
}
```

| Строка | Код | Что делает |
|---|---|---|
| 7 | `for i, r := range name {` | обходит `name` символ за символом: на каждом шаге `i` — индекс байта, `r` — символ (руна) |
| 8 | `fmt.Printf("%d %c\n", i, r)` | `%d` выводит `i` как число, `%c` выводит `r` как **символ** (`%c`: число → символ с этим номером) |

Какие числа примет `i`? В `oʻrik` 6 байтов.

**A)** `0 1 2 3 4` · **B)** `0 1 3 4 5` · **C)** `0 1 2 3 4 5`

<details>
<summary>Ответ</summary>

**B: `0 1 3 4 5`.** `ʻ` занимает два байта (байты 1 и 2), поэтому следующий символ `r` начинается с байта 3: `i` перескакивает с 1 на 3. Если вы выбрали **A**,
вы решили, что `i` считает символы подряд с нуля. Если выбрали **C**, вы решили, что `range` делает шаг на каждый байт: но он делает шаг на каждый **символ**,
а их пять.
([Go spec: For statements with range clause](https://go.dev/ref/spec#For_range): индекс — это индекс первого байта символа.)

</details>

```console
$ ./_video/run.sh 04-range go run .
0 o
1 ʻ
3 r
4 i
5 k
```

Шаги в таблице (`r` — число: code point символа, `%c` превращает его обратно в символ):

| Шаг | `i` | `r` | Сколько байтов у символа | На экран |
|---|---|---|---|---|
| 1 | 0 | 111 | 1 (байт 0) | `0 o` |
| 2 | 1 | 699 | 2 (байты 1 и 2) | `1 ʻ` |
| 3 | 3 | 114 | 1 (байт 3) | `3 r` |
| 4 | 4 | 105 | 1 (байт 4) | `4 i` |
| 5 | 5 | 107 | 1 (байт 5) | `5 k` |

Значение `r` — всегда номер символа: у `o` это 111, у `ʻ` — 699 (это U+02BB в hex).

## `rune`: номер символа

Тип `r` — **rune** (руна). Это другое имя `int32` ([Go spec: Numeric types](https://go.dev/ref/spec#Numeric_types)), и хранит она один code point.
Символ в одинарных кавычках — **литерал руны** (rune literal): его значение — номер символа. Двойные кавычки (`"…"`) — строка,
одинарные (`'…'`) — руна. Программа (`_video/05-rune/main.go`):

```go filename="_video/05-rune/main.go" showLineNumbers
package main

import "fmt"

func main() {
	var r rune
	r = 'ʻ'
	fmt.Printf("%d %c %U\n", r, r, r)
}
```

| Строка | Код | Что делает |
|---|---|---|
| 6 | `var r rune` | `r` — переменная типа rune, начальное значение 0 (GB-1.02) |
| 7 | `r = 'ʻ'` | кладёт в `r` номер символа `ʻ` |
| 8 | `fmt.Printf("%d %c %U\n", r, r, r)` | выводит одну `r` тремя способами: `%d` — номер, `%c` — символ, `%U` — запись Unicode (`U+` и hex) |

Что выведут три глагола из одной `r`?

```console
$ ./_video/run.sh 05-rune go run .
699 ʻ U+02BB
```

Одно число, три вида. `02BB` после `U+` — это те же 699, только в hex: место символа в Unicode.

Количество рун возвращает функция `RuneCountInString` из пакета `unicode/utf8`. В `import` теперь два пакета. Последняя часть пути импорта
(`utf8`) — имя пакета: в коде мы вызываем его по этому имени. Программа (`_video/06-count/main.go`):

```go filename="_video/06-count/main.go" showLineNumbers
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	name := "oʻrik"
	fmt.Println(utf8.RuneCountInString(name))
}
```

| Строка | Код | Что делает |
|---|---|---|
| 3–6 | `import ( "fmt"  "unicode/utf8" )` | два пакета, каждый на своей строке; второй вызываем как `utf8.` |
| 10 | `fmt.Println(utf8.RuneCountInString(name))` | печатает количество рун в `name` |

Сколько рун в `oʻrik`?


Пять рун, но шесть байтов.

### Руна — не буква

Руна — это code point, а не буква. Узбекская `oʻ` — одна буква, но **две** руны: `o` и `ʻ`. Если разрез попадёт между ними, оставшийся текст
останется корректным UTF-8, но `oʻ` превратится в обычную `o`. Предупреждение `go vet` из GB-1.04 («string of one rune») — об этом же: один code point.

Промежуточный вопрос. Знак многоточия `…` — один символ; в чеке он ставится в конец сокращённого названия (в задании нужен именно он). Чему равны его

Если вы выбрали **A**, вы решили, что `len` тоже считает символы. Если выбрали **C**, вы решили, что число рун равно числу байтов.

## Исправляем ошибку в чеке: срез по границе руны

Теперь код первого состояния (`_video/00-chek/main.go`):

```go filename="_video/00-chek/main.go" showLineNumbers
package main

import "fmt"

// short nomni chek ustuniga sigʻdiradi: limit'dan uzun boʻlsa kesadi.
func short(name string, limit int) string {
	if len(name) <= limit {
		return name
	}
	return name[:limit]
}

func main() {
	names := []string{"olma", "oʻrik qoqi", "paxta yogʻi"}
	for _, name := range names {
		fmt.Printf("[%-10s]\n", short(name, 10))
	}
}
```

| Строка | Код | Что делает |
|---|---|---|
| 6 | `func short(name string, limit int) string {` | функция, обрезающая название до `limit`; `limit` — ширина колонки (GB-1.07) |
| 7–9 | `if len(name) <= limit { return name }` | если название помещается, возвращает его как есть. Условие записано через `len`, то есть в **байтах** |
| 10 | `return name[:limit]` | `name[:limit]` — первые `limit` **байтов** строки. Перед `:` числа нет, значит с начала (GB-2.02: `os.Args[1:]` — до конца) |
| 14 | `names := []string{…}` | слайс из трёх названий (GB-2.01) |
| 15 | `for _, name := range names {` | цикл по каждому названию; `_` — индекс не нужен |
| 16 | `fmt.Printf("[%-10s]\n", short(name, 10))` | `%-10s` пишет текст в колонку из 10 символов слева (GB-1.04); `[` и `]` — обычные символы шаблона |

Теперь в `main` обрежем `oʻrik` до двух байтов, результат запишем в `cut` и выведем через `%q` (текст в кавычках, GB-1.04).
`utf8.ValidString` проверяет, что байты — корректный UTF-8: `true` или `false`. Программа (`_video/08-kesish/main.go`):

```go filename="_video/08-kesish/main.go" showLineNumbers
package main

import (
	"fmt"
	"unicode/utf8"
)

// short nomni chek ustuniga sigʻdiradi: limit'dan uzun boʻlsa kesadi.
func short(name string, limit int) string {
	if len(name) <= limit {
		return name
	}
	return name[:limit]
}

func main() {
	cut := short("oʻrik", 2)
	fmt.Printf("%q\n", cut)
	fmt.Println(utf8.ValidString(cut))
}
```

Что вернёт `short("oʻrik", 2)`?

**A)** `"oʻ"` и `true` · **B)** `"o"` и `true` · **C)** битый текст и `false`

<details>
<summary>Ответ</summary>

**C: битый текст и `false`.** `name[:2]` — это два **байта**: `o` (`6f`) и только первый байт `ʻ` (`ca`). Если вы выбрали **A**, вы решили, что берутся два
**символа**. Если выбрали **B**, вы решили, что половина символа отбрасывается: Go ничего не отбрасывает, он оставляет байт как есть.

</details>

```console
$ ./_video/run.sh 08-kesish go run .
"o\xca"
false
```

Строка может хранить любой байт, даже не-UTF-8. `%q` показывает такой байт как `\x` и две hex-цифры: `\xca`.
`ValidString` — `false`. В чеке терминал нарисовал этот байт `ca` как `�`.

**Исправление:** считаем не байты, а руны. Сначала часть, которая только считает (это не отдельный файл, а промежуточное состояние функции):

```go
func short(name string, limit int) string {
	n := 0
	for i := range name {
		// … i — shu rune boshlangan bayt
		n++
	}
	return name
}
```

`n` — сколько рун уже пройдено. Если в `range` одна переменная, приходит только индекс: байт, с которого начинается каждая руна.
На каждом шаге `n++` увеличивает счётчик на единицу. Если цикл закончился, название уместилось в `limit`: оно возвращается целиком. Пока цикл только
считает, срез — на следующем шаге.

Теперь срез. Когда `n` достигло `limit`, `i` — это ровно начало **следующей** руны. Режем здесь: `name[:i]`. Например, для `oʻrik` и `limit` 2
`i` будет 3, и `name[:3]` берёт `o` и `ʻ` целиком. Полная программа (`_video/09-tuzat/main.go`):

```go filename="_video/09-tuzat/main.go" showLineNumbers
package main

import "fmt"

// short nomni limit ta rune'gacha qisqartiradi va rune'ni hech qachon oʻrtasidan kesmaydi.
func short(name string, limit int) string {
	n := 0
	for i := range name {
		if n == limit {
			return name[:i]
		}
		n++
	}
	return name
}

func main() {
	names := []string{"olma", "oʻrik qoqi", "paxta yogʻi"}
	for _, name := range names {
		fmt.Printf("[%-10s]\n", short(name, 10))
	}
}
```

| Строка | Код | Что делает |
|---|---|---|
| 7 | `n := 0` | сколько рун пройдено |
| 8 | `for i := range name {` | один шаг на каждую руну; `i` — байт, с которого руна начинается |
| 9–11 | `if n == limit { return name[:i] }` | пройдено `limit` рун: `i` — начало следующей руны, здесь режем |
| 12 | `n++` | увеличивает счётчик для следующей руны |
| 14 | `return name` | цикл закончился, название уместилось в `limit` рун: возвращается целиком |

Как в чеке выйдут `oʻrik qoqi` и `paxta yogʻi`?

**A)** оба целиком · **B)** `oʻrik qoqi` целиком, `paxta yogʻ` (10 рун) · **C)** `oʻrik qoq` и `paxta yog`: оба теряют по букве

<details>
<summary>Ответ</summary>

**B.** `oʻrik qoqi` — 10 рун (11 байтов), теперь помещается целиком. `paxta yogʻi` — 11 рун: аккуратно обрезается после 10-й руны, `ʻ` остаётся целым.
Если вы выбрали **A**, вы решили, что `paxta yogʻi` тоже поместится: в нём 11 рун, а колонка — 10. **C** — это ошибка старой `short`, резавшей по байтам.

</details>

```console
$ ./_video/run.sh 09-tuzat go run .
[olma      ]
[oʻrik qoqi]
[paxta yogʻ]
```

`oʻrik qoqi` выведено полностью, `paxta yogʻi` аккуратно обрезано после 10-й руны. Колонка ровная, потому что ширина в `Printf` тоже измеряется в рунах
([документация fmt](https://pkg.go.dev/fmt#hdr-Printing): «Width and precision are measured in units of Unicode code points, that is, runes»).
В работе ограничение длины названия товара или имени пользователя тоже проверяют в рунах, а не в байтах.

## Глубже (необязательно): `[]rune`, `string(число)` и два апострофа

Этот раздел — необязательная часть в конце видео. Всё, что выше, работает и без него.

**`[]rune` и `string(...)`.** Руны можно резать и другим способом: `[]rune(s)` превращает текст в слайс рун, а `string(runes)` собирает
из него снова текст в UTF-8. Программа (`_video/10-runes/main.go`):

```go filename="_video/10-runes/main.go" showLineNumbers
package main

import "fmt"

func main() {
	runes := []rune("paxta yogʻi")
	fmt.Println(len(runes), string(runes[:10]))
}
```

В строке 6 текст записывается в `runes`: каждая руна — `int32`, то есть занимает 4 байта. Теперь `len(runes)` считает руны, а `runes[:10]` — первые 10
рун (индекс не должен выходить за `len`). Сколько выведет `len`?

```console
$ ./_video/run.sh 10-runes go run .
11 paxta yogʻ
```

Это простой способ, но весь текст **копируется в новую память**; `range` не копирует. Поэтому `short` написана через `range`.

**`string(число)` и ромб.** В GB-1.04 `string(total)` (`total = 3_067_216`) вывела `jami: �`. `string(целое число)` принимает число за **один code point**.
Наибольший code point — U+10FFFF = 1_114_111; `total` больше, поэтому Go заменил его символом замены `�`
([Go spec: Conversions to a string type](https://go.dev/ref/spec#Conversions_to_and_from_a_string_type)). Поэтому `go vet` и предупреждал: «conversion from int64 to
string yields a string of one rune».

**`ʻ` и обычный апостроф.** Два названия почти одинаковы: в первом `ʻ` (перевёрнутая запятая, 2 байта), во втором обычный апостроф с клавиатуры (`'`, 1 байт).
Программа (`_video/11-apostrof/main.go`):

```go filename="_video/11-apostrof/main.go" showLineNumbers
package main

import "fmt"

func main() {
	fmt.Println("oʻrik" == "o'rik")
	fmt.Println(len("oʻrik"), len("o'rik"))
}
```

Будут ли они равны?

```console
$ ./_video/run.sh 11-apostrof go run .
false
6 5
```

`==` сравнивает байты ([Go spec: Comparison operators](https://go.dev/ref/spec#Comparison_operators)), поэтому `false`.
Если покупатель ищет `oʻrik` с обычным апострофом, магазин его не найдёт. Поэтому названия приводят к одной форме сразу на входе (эти программы — в следующих уроках).

## Частые ошибки

**1. «`len` возвращает число символов».** Самая распространённая ошибка. Если проверять предел длины названия через `len`, лимит в 20 символов
на узбекских названиях превращается в меньшее число символов. Следующей программы нет в папке курса: я запустил её в отдельной папке.

```go
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	name := "oʻgʻil bola koʻylagi"
	fmt.Println(len(name), utf8.RuneCountInString(name))
	if len(name) > 20 {
		fmt.Println("rad etildi: nom uzun")
	}
}
```

```console
$ go run .
23 20
rad etildi: nom uzun
```

(`oʻgʻil bola koʻylagi` — «рубашка для мальчика»; `rad etildi: nom uzun` — «отклонено: название длинное».) В названии 20 символов, но 23 байта (`oʻ`, `gʻ`, `oʻ` — три `ʻ`, в каждом
+1 байт). Условие `len(name) > 20` его отклонило. Исправление: `utf8.RuneCountInString(name) > 20` (именно это делает `checkName` из задания).

**2. Обход символов по индексу.** `for i := 0; i < len(name); i++` идёт по байтам. Эта программа тоже не из папки курса:

```go
package main

import "fmt"

func main() {
	name := "oʻrik"
	for i := 0; i < len(name); i++ {
		fmt.Printf("%d %c\n", i, name[i])
	}
}
```

```console
$ go run .
0 o
1 Ê
2 »
3 r
4 i
5 k
```

Ошибки нет, но в строках 1 и 2 вместо `ʻ` стоят `Ê` и `»`: `name[1]` и `name[2]` — байты `ca` и `bb`, а `%c` выводит каждый как отдельный code point (202 и
187). Исправление: `for i, r := range name`.

**3. Изменение строки по индексу.** Строка неизменяема, поэтому байт на месте не заменить. Программа (не из папки курса):

```go
package main

import "fmt"

func main() {
	name := "oʻrik"
	name[0] = 'O'
	fmt.Println(name)
}
```

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:7:2: cannot assign to name[0] (neither addressable nor a map index expression)
```

Как читать: файл `main.go`, строка 7, столбец 2; «cannot assign to name[0]» — в `name[0]` нельзя записать значение. Исправление: соберите новую строку
(например `"O" + name[1:]`: здесь первая буква занимает 1 байт, поэтому это работает; в общем случае собирайте текст из рун).

**4. Срез `name[:n]`.** Это молчаливая ошибка: ни компилятор, ни `go vet` ничего не говорят, а результат — битый текст. Мы увидели её выше, в разделе
«Исправляем ошибку в чеке: срез по границе руны» (`"o\xca"`, `ValidString` — `false`). Исправление: режьте по индексу, который дал `range`, как в `short`.
