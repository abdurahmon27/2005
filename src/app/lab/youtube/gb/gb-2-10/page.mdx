## Nimani oʻrganasiz

Bozor cheki mahsulot nomini 10 belgilik ustunga sigʻdiradi, uzun nomni esa kesadi. Lekin `oʻrik qoqi` oxirgi harfini yoʻqotdi,
`paxta yogʻi` esa oxirida singan belgi bilan chiqdi. Nega shunday boʻladi va oʻzbekcha nomni qanday qilib buzmasdan qisqartirasiz?

**Bitta gʻoya:** Go'da `string` — oʻzgarmas baytlar ketma-ketligi, kod ichidagi matn esa UTF-8'da: har bir belgi 1–4 baytga yoziladi
(`oʻrik` = 5 belgi, 6 bayt). `len`, indeks `s[i]` va kesish `s[a:b]` **baytlar** bilan ishlaydi. `for i, r := range s` esa UTF-8'ni oʻqib,
har qadamda bitta **rune** va u boshlangan baytning indeksini beradi. Shuning uchun matnni faqat `range` bergan indeksda kesish xavfsiz.

Dars oxirida siz:

- `len("oʻrik")` nega 6 ekanini koʻrasiz va baytlarning oʻzini `% x` bilan chiqarasiz;
- `for i, r := range name` bilan matnni belgilar (rune'lar) boʻyicha aylanasiz, `unicode/utf8` paketi bilan rune'larni sanaysiz;
- `name[:n]` belgini oʻrtasidan kesishini real xatoda koʻrasiz va `short` funksiyasini rune chegarasida kesadigan qilib tuzatasiz;
- vazifada `shortLabel` (`…` bilan) va `checkName` (boʻsh, UTF-8 emas, 20 rune'dan uzun nom) yozasiz, `go test` oʻtguncha.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| UTF-8 | belgining Unicode raqamini 1–4 baytga yozish qoidasi; Go matni shu baytlardan iborat | UTF-8 |
| rune | bitta belgining Unicode raqami (code point), `int32` turi; harf bilan bir xil emas: `oʻ` bitta harf, lekin ikki rune | rune |
| rune chegarasi | bitta rune tugab, keyingisi boshlanadigan bayt; matnni faqat shu yerda kesish xavfsiz | rune boundary |

Yordamchi tushunchalar har biri birinchi uchraganda bir jumlada aytiladi: **Unicode**, **code point**, **oʻn oltilik sanoq** (hex),
`unicode/utf8` paketi va `Printf`ning `%x`, `%c`, `%U` feʼllari.

## `len` nimani sanaydi

`name` oʻzgaruvchisida `oʻrik` turibdi. `len` slice'da elementlar sonini berar edi (GB-2.01); string'da ham ishlaydi. Dastur
(`_video/01-len/main.go`):

```go filename="_video/01-len/main.go" showLineNumbers

import "fmt"

func main() {
	name := "oʻrik"
	fmt.Println(len(name))
}
```

## Baytlarning oʻzini koʻramiz

`fmt.Printf`ning yangi feʼli `%x`: qiymatni **hex**, yaʼni **oʻn oltilik sanoqda** chiqaradi (0–9 va a–f raqamlari; `a` = 10, `f` = 15).
String uchun `%x` har bir baytni ikki hex raqam bilan yozadi. `%` va `x` orasidagi probel baytlar orasiga ham probel qoʻyadi: `% x`.
Dastur (`_video/02-bayt/main.go`):

```go filename="_video/02-bayt/main.go" showLineNumbers
package main

import "fmt"

func main() {
	name := "oʻrik"
	fmt.Println(len(name))
	fmt.Printf("% x\n", name)
}
```

Yangi qator — 8-qator: `fmt.Printf("% x\n", name)`. `"% x\n"` — shablon (GB-1.04), `% x` — baytlarni hex'da, probel bilan ajratib
chiqar, `\n` — qator oxiri. Ekranda nechta hex juftlik chiqadi?

<details>
<summary>Javob</summary>

Oltita: `len(name)` = 6 bayt, har bir bayt — bitta juftlik. 6 va 5 farqi yuqoridagi savolning javobi: bitta belgi bir nechta bayt boʻlishi mumkin.

</details>

```console
$ ./_video/run.sh 02-bayt go run .
6
6f ca bb 72 69 6b
```

Oltita bayt. Qaysi baytlar qaysi belgiga tegishli:

```text
bayt indeksi:   0    1  2    3    4    5
bayt (hex):     6f   ca bb   72   69   6b
belgi:          o    ʻ       r    i    k
```

Birinchi bayt `6f` — `o` harfi. Keyingi ikki bayt `ca bb` **birgalikda** bitta belgi: `oʻ`dagi teskari vergul `ʻ`. Keyin `r`, `i`
va `k`, har biri bittadan bayt.

Buning sababi shu. **Unicode** — butun dunyo belgilarining raqamlangan roʻyxati. Har bir belgining raqami **code point** deyiladi va
`U+02BB` koʻrinishida yoziladi (`U+` dan keyin hex raqam): `ʻ` — U+02BB (MODIFIER LETTER TURNED COMMA, [Unicode jadvali](https://www.unicode.org/charts/PDF/U02B0.pdf)).
**UTF-8** shu raqamni baytlarga yozish qoidasi: har bir code point 1 dan 4 baytgacha oladi. a–z lotin harflari, raqamlar va oddiy tinish
belgilari (**ASCII**) — bitta bayt. `ʻ` — ikki bayt. Go manba fayli UTF-8'da yoziladi
([Go spec: Source code representation](https://go.dev/ref/spec#Source_code_representation)), shuning uchun qoʻshtirnoq ichidagi matn ham
xotirada shu baytlar boʻlib turadi. String oʻzgarmas: uning baytlarini joyida almashtirib boʻlmaydi (pastda «Koʻp uchraydigan xatolar»da
bu xatoni koʻrasiz).

Boshqa belgilar necha bayt olishini ham koʻrish mumkin. Quyidagi dastur kurs papkasida yoʻq: uni alohida papkada, shu `go.mod` bilan
ishga tushirdim. `[]rune(s)[0]` — `s` ning birinchi belgisi (bu yozuv pastda «Chuqurroq» boʻlimida tushuntiriladi), `%U` — uning code point'i:

```go
package main

import "fmt"

func main() {
	for _, s := range []string{"a", "ʻ", "…", "😀"} {
		fmt.Printf("%q: %d bayt, %U\n", s, len(s), []rune(s)[0])
	}
}
```

```console
$ go run .
"a": 1 bayt, U+0061
"ʻ": 2 bayt, U+02BB
"…": 3 bayt, U+2026
"😀": 4 bayt, U+1F600
```

Qoida ([RFC 3629](https://www.rfc-editor.org/rfc/rfc3629#section-3), 3-boʻlim):

| Code point oraligʻi | Bayt soni | Misol |
|---|---|---|
| `U+0000`–`U+007F` (ASCII) | 1 | `a` |
| `U+0080`–`U+07FF` | 2 | `ʻ` (U+02BB) |
| `U+0800`–`U+FFFF` | 3 | `…` (U+2026) |
| `U+10000`–`U+10FFFF` | 4 | `😀` (U+1F600) |

## Indeks ham bayt beradi

Kvadrat qavsdagi indeks ham baytlar bilan ishlaydi: `name[0]` — birinchi bayt, `name[1]` — ikkinchi bayt (indeks 0 dan boshlanadi, GB-2.01).
Dastur (`_video/03-indeks/main.go`):

```go filename="_video/03-indeks/main.go" showLineNumbers
package main

import "fmt"

func main() {
	name := "oʻrik"
	fmt.Println(name[0], name[1])
}
```

7-qator `name[0]` va `name[1]`ni bir qatorda chiqaradi (`Println` argumentlar orasiga probel qoʻyadi). Ekranda harflar chiqadimi yoki sonlar?

<details>
<summary>Javob</summary>

**Sonlar.** Indeks `byte` turidagi qiymat qaytaradi ([Go spec: Index expressions](https://go.dev/ref/spec#Index_expressions)); `byte` — GB-2.07'da
koʻrgan tur, 0 dan 255 gacha son. `Println` sonni son qilib chiqaradi.

</details>

```console
$ ./_video/run.sh 03-indeks go run .
111 202
```

Bular oldingi qadamdagi oʻsha baytlar, faqat oʻnlik sanoqda: `6f` = 6 × 16 + 15 = 111 (`o` harfining bayti), `ca` = 12 × 16 + 10 = 202
(`ʻ` belgisining birinchi bayti). `name[1]` belgi emas, belgining **yarmi**.

Xulosa: `len`, `name[i]` va (pastda koʻramiz) `name[a:b]` baytlar bilan ishlaydi. Belgilarni olish uchun boshqa yoʻl kerak.

## `for range`: bitta qadam — bitta belgi

Slice ustida `range` indeks va elementni berar edi (GB-2.01). **String** ustida `range` UTF-8'ni oʻqiydi: har qadamda bitta belgi, yaʼni
bitta code point. `i` — shu belgi boshlangan baytning indeksi, `r` — belgining oʻzi. Dastur (`_video/04-range/main.go`):

```go filename="_video/04-range/main.go" showLineNumbers
package main

import "fmt"

func main() {
	name := "oʻrik"
	for i, r := range name {
		fmt.Printf("%d %c\n", i, r)
	}
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 7 | `for i, r := range name {` | `name`ni belgi-belgi aylanadi: har qadamda `i` — bayt indeksi, `r` — belgi (rune) |
| 8 | `fmt.Printf("%d %c\n", i, r)` | `%d` — `i`ni son qilib, `%c` — `r`ni **belgi** qilib chiqaradi (`%c`: son → shu raqamli belgi) |

`i` qaysi sonlarni oladi? `oʻrik` — 6 bayt.

**A)** `0 1 2 3 4` · **B)** `0 1 3 4 5` · **C)** `0 1 2 3 4 5`

<details>
<summary>Javob</summary>

**B: `0 1 3 4 5`.** `ʻ` ikki bayt oladi (1 va 2-baytlar), shuning uchun keyingi belgi `r` 3-baytda boshlanadi: `i` 1 dan 3 ga sakraydi. **A** ni
tanlagan boʻlsangiz, `i` belgilarni 0 dan ketma-ket sanaydi deb oʻylagansiz. **C** ni tanlagan boʻlsangiz, `range` har bir baytda bir marta
aylanadi deb oʻylagansiz: lekin u har bir **belgida** bir marta aylanadi, belgilar esa beshta.
([Go spec: For statements with range clause](https://go.dev/ref/spec#For_range): indeks — belgining birinchi baytidagi indeks.)

</details>

```console
$ ./_video/run.sh 04-range go run .
0 o
1 ʻ
3 r
4 i
5 k
```

Qadamlarni jadvalda koʻramiz (`r` — son: belgining code point'i, `%c` uni yana belgiga aylantiradi):

| Qadam | `i` | `r` | Bu belgi nechta bayt | Ekranga |
|---|---|---|---|---|
| 1 | 0 | 111 | 1 (bayt 0) | `0 o` |
| 2 | 1 | 699 | 2 (bayt 1 va 2) | `1 ʻ` |
| 3 | 3 | 114 | 1 (bayt 3) | `3 r` |
| 4 | 4 | 105 | 1 (bayt 4) | `4 i` |
| 5 | 5 | 107 | 1 (bayt 5) | `5 k` |

`r` ning qiymati doim belgining raqami: `o` — 111, `ʻ` — 699 (= U+02BB hex'da).

## `rune`: belgining raqami

`r` ning turi **rune**. Bu `int32` ning boshqa nomi ([Go spec: Numeric types](https://go.dev/ref/spec#Numeric_types)) va u bitta code point'ni
saqlaydi. Bittalik qoʻshtirnoq ichidagi belgi — **rune literal**: uning qiymati belgining raqami. Ikkilik qoʻshtirnoq (`"…"`) — string,
bittalik (`'…'`) — rune. Dastur (`_video/05-rune/main.go`):

```go filename="_video/05-rune/main.go" showLineNumbers
package main

import "fmt"

func main() {
	var r rune
	r = 'ʻ'
	fmt.Printf("%d %c %U\n", r, r, r)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 6 | `var r rune` | `r` — rune turidagi oʻzgaruvchi, boshlangʻich qiymati 0 (GB-1.02) |
| 7 | `r = 'ʻ'` | `r`ga `ʻ` belgisining raqamini beradi |
| 8 | `fmt.Printf("%d %c %U\n", r, r, r)` | bitta `r`ni uch xil chiqaradi: `%d` — raqam, `%c` — belgi, `%U` — Unicode yozuvi (`U+` va hex) |

Uchala feʼl bitta `r`dan nima chiqaradi?

```console
$ ./_video/run.sh 05-rune go run .
699 ʻ U+02BB
```

Bitta raqam, uch koʻrinish. `U+` dan keyingi `02BB` — oʻsha 699, faqat hex'da: belgining Unicode'dagi oʻrni.

Rune'lar sonini `unicode/utf8` paketidagi `RuneCountInString` funksiyasi beradi. `import`da endi ikkita paket bor. Import yoʻlining
oxirgi qismi (`utf8`) — paket nomi: kodda shu nom bilan chaqiramiz. Dastur (`_video/06-count/main.go`):

```go filename="_video/06-count/main.go" showLineNumbers
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	name := "oʻrik"
	fmt.Println(utf8.RuneCountInString(name))
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 3–6 | `import ( "fmt"  "unicode/utf8" )` | ikkita paket: har biri alohida qatorda; ikkinchisini `utf8.` deb chaqiramiz |
| 10 | `fmt.Println(utf8.RuneCountInString(name))` | `name`dagi rune'lar sonini chiqaradi |

`oʻrik`da nechta rune?

```console
$ ./_video/run.sh 06-count go run .
5
```

Beshta rune, lekin olti bayt.

### Rune harf emas

Rune — code point, harf emas. Oʻzbekcha `oʻ` bitta harf, lekin **ikki** rune: `o` va `ʻ`. Kesish ular orasiga tushsa, qolgan matn
toʻgʻri UTF-8 boʻladi, lekin `oʻ` oddiy `o` ga aylanadi. GB-1.04'da `go vet` aytgan «string of one rune» ham shu: bitta code point.

Oraliq savol. Uch nuqta belgisi `…` — bitta belgi; chekda qisqartirilgan nomning oxiriga qoʻyiladi (vazifada aynan shu kerak). Uning
`len`'i va rune soni qancha? Dastur (`_video/07-quiz/main.go`):

```go filename="_video/07-quiz/main.go" showLineNumbers
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	fmt.Println(len("…"), utf8.RuneCountInString("…"))
}
```

**A)** `1 1` · **B)** `3 1` · **C)** `3 3`

<details>
<summary>Javob</summary>

**B: `3 1`.** ASCII'dan tashqaridagi belgi kamida ikki bayt oladi, `…` ning raqami (U+2026) esa undan ham katta: u uch bayt. Belgi esa bitta.
**A** ni tanlagan boʻlsangiz, `len` ham belgilarni sanaydi deb oʻylagansiz. **C** ni tanlagan boʻlsangiz, rune soni baytlar soniga teng deb
oʻylagansiz.

</details>

```console
$ ./_video/run.sh 07-quiz go run .
3 1
```

## Chekdagi xatoni tuzatamiz: rune chegarasida kesish

Endi birinchi holatning kodi (`_video/00-chek/main.go`):

```go filename="_video/00-chek/main.go" showLineNumbers
package main

import "fmt"

// short nomni chek ustuniga sigʻdiradi: limit'dan uzun boʻlsa kesadi.
func short(name string, limit int) string {
	if len(name) <= limit {
		return name
	}
	return name[:limit]
}

func main() {
	names := []string{"olma", "oʻrik qoqi", "paxta yogʻi"}
	for _, name := range names {
		fmt.Printf("[%-10s]\n", short(name, 10))
	}
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 6 | `func short(name string, limit int) string {` | nomni `limit` gacha kesadigan funksiya; `limit` — ustun kengligi (GB-1.07) |
| 7–9 | `if len(name) <= limit { return name }` | nom sigʻsa, oʻzini qaytaradi. Sharti `len` bilan, yaʼni **baytlar** bilan yozilgan |
| 10 | `return name[:limit]` | `name[:limit]` — string'ning boshidan `limit` ta **bayt**. `:` oldida son yoʻq, demak boshidan (GB-2.02: `os.Args[1:]` — oxirigacha) |
| 14 | `names := []string{…}` | uchta nomli slice (GB-2.01) |
| 15 | `for _, name := range names {` | har bir nom uchun sikl; `_` — indeks kerak emas |
| 16 | `fmt.Printf("[%-10s]\n", short(name, 10))` | `%-10s` — matnni 10 belgilik ustunga chapdan yozadi (GB-1.04); `[` va `]` shablondagi oddiy belgilar |

Endi `main`da `oʻrik`ni ikki baytgacha kesamiz, natijani `cut`ga yozamiz, `%q` (qoʻshtirnoqli matn, GB-1.04) bilan chiqaramiz.
`utf8.ValidString` baytlar toʻgʻri UTF-8 ekanini tekshiradi: `true` yoki `false`. Dastur (`_video/08-kesish/main.go`):

```go filename="_video/08-kesish/main.go" showLineNumbers
package main

import (
	"fmt"
	"unicode/utf8"
)

// short nomni chek ustuniga sigʻdiradi: limit'dan uzun boʻlsa kesadi.
func short(name string, limit int) string {
	if len(name) <= limit {
		return name
	}
	return name[:limit]
}

func main() {
	cut := short("oʻrik", 2)
	fmt.Printf("%q\n", cut)
	fmt.Println(utf8.ValidString(cut))
}
```

`short("oʻrik", 2)` nima beradi?

**A)** `"oʻ"` va `true` · **B)** `"o"` va `true` · **C)** buzilgan matn va `false`

<details>
<summary>Javob</summary>

**C: buzilgan matn va `false`.** `name[:2]` — ikki **bayt**: `o` (`6f`) va `ʻ` ning faqat birinchi baytlari (`ca`). **A** ni tanlagan boʻlsangiz, ikki
**belgi** olinadi deb oʻylagansiz. **B** ni tanlagan boʻlsangiz, yarim belgi tashlab yuboriladi deb oʻylagansiz: Go hech narsani tashlamaydi,
baytni oʻzi qoldiradi.

</details>

```console
$ ./_video/run.sh 08-kesish go run .
"o\xca"
false
```

String istalgan baytni saqlaydi, hatto UTF-8 boʻlmaganini ham. `%q` bunday baytni `\x` va ikki hex raqam bilan koʻrsatadi: `\xca`.
`ValidString` — `false`. Chekda terminal shu `ca` baytini `�` bilan chizgan edi.

**Tuzatish:** baytlarni emas, rune'larni sanaymiz. Avval faqat sanaydigan qism (bu qadam alohida fayl emas, funksiyaning yarim tayyor holati):

```go
func short(name string, limit int) string {
	n := 0
	for i := range name {
		// … i — shu rune boshlangan bayt
		n++
	}
	return name
}
```

`n` — shu paytgacha oʻtilgan rune'lar soni. `range`da bitta oʻzgaruvchi boʻlsa, faqat indeks keladi: har bir rune boshlangan bayt.
Har qadamda `n++` sanoqni bittaga oshiradi. Sikl tugasa, nom `limit` ga sigʻgan: u butunligicha qaytadi. Hozircha sikl faqat sanaydi,
kesish keyingi qadamda.

Endi kesish. `n` `limit`ga yetganda `i` aynan **keyingi** rune'ning boshi. Shu joydan kesamiz: `name[:i]`. Masalan, `oʻrik` va `limit` 2
boʻlsa, `i` 3 boʻladi va `name[:3]` — `o` bilan `ʻ` ni toʻliq oladi. Toʻliq dastur (`_video/09-tuzat/main.go`):

```go filename="_video/09-tuzat/main.go" showLineNumbers
package main

import "fmt"

// short nomni limit ta rune'gacha qisqartiradi va rune'ni hech qachon oʻrtasidan kesmaydi.
func short(name string, limit int) string {
	n := 0
	for i := range name {
		if n == limit {
			return name[:i]
		}
		n++
	}
	return name
}

func main() {
	names := []string{"olma", "oʻrik qoqi", "paxta yogʻi"}
	for _, name := range names {
		fmt.Printf("[%-10s]\n", short(name, 10))
	}
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 7 | `n := 0` | oʻtilgan rune'lar soni |
| 8 | `for i := range name {` | har bir rune uchun bir marta aylanadi; `i` — rune boshlangan bayt |
| 9–11 | `if n == limit { return name[:i] }` | `limit` ta rune oʻtgan: `i` — keyingi rune'ning boshi, shu yerda kesamiz |
| 12 | `n++` | keyingi rune uchun sanoqni oshiradi |
| 14 | `return name` | sikl tugadi, nom `limit` rune'ga sigʻdi: butunligicha qaytadi |

Chekda `oʻrik qoqi` va `paxta yogʻi` qanday chiqadi?

**A)** ikkalasi toʻliq · **B)** `oʻrik qoqi` toʻliq, `paxta yogʻ` (10 rune) · **C)** `oʻrik qoq` va `paxta yog`: ikkalasi bittadan harf yoʻqotadi

<details>
<summary>Javob</summary>

**B.** `oʻrik qoqi` — 10 rune (11 bayt), endi toʻliq sigʻadi. `paxta yogʻi` — 11 rune: 10-rune'dan keyin toza kesiladi, `ʻ` butun qoladi.
**A** ni tanlagan boʻlsangiz, `paxta yogʻi` ham sigʻadi deb oʻylagansiz: u 11 rune, ustun 10. **C** — bu eski, bayt bilan kesadigan
`short`ning xatosi.

</details>

```console
$ ./_video/run.sh 09-tuzat go run .

[oʻrik qoqi]
[paxta yogʻ]
```

`oʻrik qoqi` oxirigacha chiqdi, `paxta yogʻi` 10-rune'dan keyin toza kesildi. Ustun tekis, chunki `Printf` kengligi ham rune'larda
oʻlchanadi ([fmt hujjati](https://pkg.go.dev/fmt#hdr-Printing): «Width and precision are measured in units of Unicode code points, that is, runes»).
Ishda mahsulot nomi yoki foydalanuvchi ismining uzunlik chegarasi ham baytlarda emas, rune'larda tekshiriladi.

## Chuqurroq (ixtiyoriy): `[]rune`, `string(son)` va ikki apostrof

Bu boʻlim video oxiridagi ixtiyoriy qism. Yuqoridagi hamma narsa shularsiz ishlaydi.

**`[]rune` va `string(...)`.** Rune'larni boshqa yoʻl bilan ham kesish mumkin: `[]rune(s)` matnni rune'lar slice'iga aylantiradi, `string(runes)` esa
qaytadan UTF-8 matn yasaydi. Dastur (`_video/10-runes/main.go`):

```go filename="_video/10-runes/main.go" showLineNumbers
package main

import "fmt"

func main() {
	runes := []rune("paxta yogʻi")
	fmt.Println(len(runes), string(runes[:10]))
}
```

6-qatorda matn `runes`ga yoziladi: har bir rune `int32`, yaʼni 4 bayt joy oladi. Endi `len(runes)` rune'larni sanaydi, `runes[:10]` — birinchi 10
rune (indeks `len`dan oshmasin). `len` nechta chiqadi?

```console
$ ./_video/run.sh 10-runes go run .
11 paxta yogʻ
```

Bu oddiy yoʻl, lekin butun matn **yangi xotiraga nusxalanadi**; `range` esa nusxa olmaydi. Shuning uchun `short` `range` bilan yozilgan.

**`string(son)` va romb.** GB-1.04'da `string(total)` (`total = 3_067_216`) `jami: �` chiqargan edi. `string(butun son)` sonni **bitta code point** deb oladi.
Eng katta code point — U+10FFFF = 1_114_111; `total` undan katta, shuning uchun Go uni almashtirish belgisi `�` bilan almashtirdi
([Go spec: Conversions to a string type](https://go.dev/ref/spec#Conversions_to_and_from_a_string_type)). `go vet` shuning uchun «conversion from int64 to
string yields a string of one rune» deb ogohlantirgan edi.

**`ʻ` va oddiy apostrof.** Ikki nom deyarli bir xil: birinchisida `ʻ` (teskari vergul, 2 bayt), ikkinchisida klaviaturadagi oddiy apostrof (`'`, 1 bayt).
Dastur (`_video/11-apostrof/main.go`):

```go filename="_video/11-apostrof/main.go" showLineNumbers
package main

import "fmt"

func main() {
	fmt.Println("oʻrik" == "o'rik")
	fmt.Println(len("oʻrik"), len("o'rik"))
}
```

Teng chiqadimi?

```console
$ ./_video/run.sh 11-apostrof go run .
false
6 5
```

`==` baytlarni solishtiradi ([Go spec: Comparison operators](https://go.dev/ref/spec#Comparison_operators)), shuning uchun `false`.
Xaridor `oʻrik`ni oddiy apostrof bilan qidirsa, bozor uni topmaydi. Shuning uchun nomlar kirishdayoq bitta shaklga keltiriladi (bu dasturlar
keyingi darslarda).

## Koʻp uchraydigan xatolar

**1. «`len` belgilar sonini beradi.»** Eng keng tarqalgan xato. Nom uzunligi chegarasini `len` bilan tekshirsangiz, 20 belgilik chegara
oʻzbekcha nomlarda 20 dan kam belgiga tushib qoladi. Quyidagi dastur kurs papkasida yoʻq: uni alohida papkada ishga tushirdim.

```go
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	name := "oʻgʻil bola koʻylagi"
	fmt.Println(len(name), utf8.RuneCountInString(name))
	if len(name) > 20 {
		fmt.Println("rad etildi: nom uzun")
	}
}
```

```console
$ go run .
23 20
rad etildi: nom uzun
```

Nom 20 belgi, lekin 23 bayt (`oʻ`, `gʻ`, `oʻ` — uchta `ʻ`, har biri +1 bayt). `len(name) > 20` shartli uni rad etdi. Tuzatish: `utf8.RuneCountInString(name) > 20`
(vazifadagi `checkName` aynan shuni qiladi).

**2. Belgilarni indeks bilan aylanish.** `for i := 0; i < len(name); i++` baytlar boʻyicha yuradi. Quyidagi dastur ham kurs papkasida yoʻq:

```go
package main

import "fmt"

func main() {
	name := "oʻrik"
	for i := 0; i < len(name); i++ {
		fmt.Printf("%d %c\n", i, name[i])
	}
}
```

```console
$ go run .
0 o
1 Ê
2 »
3 r
4 i
5 k
```

Xato bermaydi, lekin 1- va 2-qatorda `ʻ` oʻrniga `Ê` va `»`: `name[1]` va `name[2]` — `ca` va `bb` baytlari, `%c` ularni alohida code point (202 va
187) deb chiqaradi. Tuzatish: `for i, r := range name`.

**3. Indeks bilan string'ni oʻzgartirish.** String oʻzgarmas, shuning uchun baytni joyida almashtirib boʻlmaydi. Dastur (kurs papkasida yoʻq):

```go
package main

import "fmt"

func main() {
	name := "oʻrik"
	name[0] = 'O'
	fmt.Println(name)
}
```

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:7:2: cannot assign to name[0] (neither addressable nor a map index expression)
```

Oʻqish: `main.go` faylining 7-qatori, 2-ustuni; «cannot assign to name[0]» — `name[0]`ga qiymat berib boʻlmaydi. Tuzatish: yangi string yasang
(masalan `"O" + name[1:]`: bu yerda birinchi harf 1 bayt, shuning uchun ishlaydi; umumiy holda matnni rune'lar bilan yigʻing).

**4. `name[:n]` bilan kesish.** Bu jim xato: kompilyator ham, `go vet` ham jim, natija esa buzilgan matn. Yuqorida
«Chekdagi xatoni tuzatamiz: rune chegarasida kesish» boʻlimida koʻrdik (`"o\xca"`, `ValidString` — `false`). Tuzatish:
`short` kabi `range` bergan indeksda kesing.

const maxNameRunes = 20

	return nil
}
