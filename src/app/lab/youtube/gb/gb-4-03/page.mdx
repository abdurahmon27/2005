## Nimani oʻrganasiz

bozor katalogi HTTP orqali beriladi. Kodni har oʻzgartirgandan keyin serverni ishga tushirib, `curl` bilan qoʻlda tekshirsak, tekshiruv sekin boʻladi va takrorlanmaydi.
Savol: javob yasaydigan kodni server ishga tushirmasdan, bitta `go test` ichida qanday tekshirish mumkin?

**Bitta gʻoya:** handler — `func(w http.ResponseWriter, r *http.Request)` imzosidagi oddiy funksiya. Server soʻrov matnini `*http.Request` struct'iga oʻqiydi, shu funksiyani chaqiradi
va `w`ga yozilganni javob matni qiladi. Shuning uchun handler'ni serversiz ham chaqirish mumkin: `httptest.NewRequest` soʻrovni, `httptest.NewRecorder` esa yozilganni saqlaydigan `w`ni yasaydi.
Javob tartibi: header'lar → status → body. `WriteHeader` chaqirilmasa, birinchi `Write` statusni `200` qiladi; `Write`dan keyingi `Header().Set` va `WriteHeader` taʼsir qilmaydi.

Dars oxirida siz:

- `func(w http.ResponseWriter, r *http.Request)` imzosini oʻqiysiz va `w` bilan `r` nima ekanini aytasiz;
- handler'ni server, port va `curl` siz, `httptest.NewRequest` va `httptest.NewRecorder` bilan chaqirib, statusni, header'ni va JSON body'ni tekshirasiz;
- javob tartibini (header'lar → status → body) va `WriteHeader` chaqirilmasa status nega `200` ekanini tushuntirasiz;
- `catalogHandler` handler'ini yozib, `go test .` ni oʻtkazasiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| handler | server har soʻrovda chaqiradigan funksiya: soʻrovni oladi, javobni `w`ga yozadi | handler |
| `httptest.NewRequest` va `httptest.NewRecorder` | handler'ga kiradigan soʻrovni va javob yoziladigan joyni oʻzimiz yasash: serversiz chaqirish | httptest request, recorder |
| javob tartibi | header'lar, keyin status, keyin body; birinchi `Write`dan keyin oldingilar oʻzgarmaydi | response order |

Yordamchi soʻzlar: `json.NewEncoder(w).Encode(v)` (qiymatni JSON qilib `w`ga yozadi) va `http.HandlerFunc` bilan `httptest.NewServer` (oxirgi, ixtiyoriy boʻlim).
Boshqa yangi nomlarning hammasiga yoʻlda bitta jumla beraman.

## Server bitta soʻrovda nima qiladi

Soʻrov matni [GB-4.01](/lab/youtube/gb/gb-4-01)dagidek: birinchi qator `GET /products/1 HTTP/1.1`, keyin header'lar va body. Server har soʻrovda uch ish qiladi:

| Qadam | Nima boʻladi |
|---|---|
| 1 | server tarmoqdan kelgan soʻrov matnini Go struct'iga — `http.Request` ga — oʻqiydi |
| 2 | server **bizning funksiyamizni** chaqiradi: unga soʻrovni va javob yoziladigan joyni beradi |
| 3 | funksiya yozgan narsa javob matni boʻlib ketadi |

```text
soʻrov matni                    server                         bizning kod
GET /products/1 HTTP/1.1  ──►   1. matnni http.Request ga
Host: …                            oʻqiydi
                                2. handler(w, r) ni chaqiradi ──►  func(w, r) { … w ga yozadi }
javob matni               ◄──   3. w ga yozilganlarni
HTTP/1.1 200 OK …                  javob matni qilib yuboradi
```

Bugun faqat oʻrtadagi funksiya bilan shugʻullanamiz. Shu funksiya **handler** (handler) deyiladi.

## Handler imzosi: w va r

Mana eng kichik handler. Hozircha uni oʻqiymiz, ishga tushirmaymiz:

```go
func healthHandler(w http.ResponseWriter, r *http.Request) {
	fmt.Fprintln(w, "ok")
}
```

Funksiyaning birinchi qatori — uning **imzosi** (signature): nomi, parametrlari va natija turi.

| Qism | Maʼnosi |
|---|---|
| `func` | funksiya eʼloni ([GB-1.07](/lab/youtube/gb/gb-1-07)) |
| `healthHandler` | funksiya nomi. Nomni biz tanladik: server tirikligini tekshiradigan handler |
| `w http.ResponseWriter` | birinchi parametr: nomi `w`, turi `http.ResponseWriter`. Javob shunga yoziladi |
| `r *http.Request` | ikkinchi parametr: nomi `r`, turi `*http.Request`. Kelgan soʻrov. Yulduzcha — struct'ga koʻrsatkich ([GB-2.04](/lab/youtube/gb/gb-2-04)): soʻrov nusxalanmaydi |
| (natija turi yoʻq) | funksiya hech narsa qaytarmaydi. Javob qaytarilmaydi: u `w`ga yoziladi |

`http` — `net/http` paketining nomi; `ResponseWriter` va `Request` shu paketdagi turlar. Server handler'ni aynan shu imzoda kutadi: `w` va `r` nomlari odat, tur va tartib — qoida.

## ResponseWriter: javob yoziladigan joy

`w` ning turi `http.ResponseWriter` — **interface** ([GB-2.07](/lab/youtube/gb/gb-2-07)dagidek). `net/http` paketida u shunday eʼlon qilingan (izohlar tushirilgan):

```go
type ResponseWriter interface {
	Header() Header
	Write([]byte) (int, error)
	WriteHeader(statusCode int)
}
```

Uchta metod:

| Metod | Nima qiladi |
|---|---|
| `Header()` | javob header'lari jadvalini qaytaradi; uning turi ham `Header`. Header'ni shu jadvalga qoʻyamiz |
| `Write([]byte)` | baytlarni javob body'siga yozadi |
| `WriteHeader(statusCode int)` | status kodni belgilaydi |

`Write` metodi bor, demak `ResponseWriter` — `io.Writer` ham. Shuning uchun `fmt.Fprintln(w, "ok")` ishlaydi: u `w`ga `ok` va yangi qator yozadi.
Bu `healthHandler`ning butun tanasi.

Muhim qoida: **`WriteHeader` chaqirilmasa, birinchi `Write` statusni `200` qiladi** ([ResponseWriter hujjati](https://pkg.go.dev/net/http#ResponseWriter)).
`healthHandler` statusni hech belgilamaydi, demak javobi `200` boʻladi. Buni hozir koʻramiz.

## httptest.NewRequest: soʻrovni oʻzimiz yasaymiz

Funksiya tayyor. Lekin `w` va `r` ni kim beradi? Odatda server: uni [GB-4.04 · Birinchi server, qatorma-qator](/lab/youtube/gb/gb-4-04) darsida yozamiz.
Lekin handler — oddiy funksiya, uni biz ham chaqira olamiz. Buning uchun faqat `w` va `r` kerak. Ularni `net/http/httptest` paketi yasab beradi.

Avval soʻrov. Quyidagi dastur `r`ni yasaydi va ichiga qaraydi:

```go filename="_video/01-request/main.go" showLineNumbers
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

func main() {
	req := httptest.NewRequest(http.MethodGet, "/products/1", nil)
	fmt.Println(req.Method, req.URL.Path, req.Proto)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 10 | `req := httptest.NewRequest(http.MethodGet, "/products/1", nil)` | soʻrov yasaydi va `*http.Request` qaytaradi; natija `req`da. Birinchi argument — method: `http.MethodGet` — `"GET"` matni. Ikkinchisi — yoʻl, [GB-4.01](/lab/youtube/gb/gb-4-01)dagi soʻrov qatoridan. Uchinchisi — body: `nil`, ya'ni yoʻq |
| 11 | `fmt.Println(req.Method, req.URL.Path, req.Proto)` | soʻrov ichiga qaraydi: `Method` — method, `URL.Path` — yoʻl, `Proto` — protokol versiyasi |

Bashorat: `go run .` nima chiqaradi?

**A)** `GET /products/1 HTTP/1.1` · **B)** `GET /products/1` · **C)** `/products/1 GET`

<details>
<summary>Javob</summary>

**A.** `Println` argumentlarni bitta boʻshliq bilan ajratib chiqaradi: method, yoʻl, versiya. **B** da versiyani (`Proto`) unutdingiz — uchinchi argument ham bor.
**C** da tartibni almashtirdingiz: `Println` argumentlarni berilgan tartibda yozadi, bu yerda `Method` birinchi.

## httptest.NewRecorder: handler'ni funksiya kabi chaqiramiz

Endi javob yoziladigan joy. `httptest.NewRecorder()` ham `ResponseWriter`: u hech qayerga yubormaydi, yozilganni saqlaydi. Saqlanganini `rec.Code` (status) va `rec.Body` (body) orqali oʻqiymiz.
Butun dastur:

```go filename="_video/02-recorder/main.go" showLineNumbers
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

func healthHandler(w http.ResponseWriter, r *http.Request) {
	fmt.Fprintln(w, "ok")
}

func main() {
	req := httptest.NewRequest(http.MethodGet, "/health", nil)
	rec := httptest.NewRecorder()
	healthHandler(rec, req)
	fmt.Printf("%d %q\n", rec.Code, rec.Body.String())
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 9–11 | `func healthHandler(…) { fmt.Fprintln(w, "ok") }` | oldingi bobdagi handler |
| 14 | `req := httptest.NewRequest(http.MethodGet, "/health", nil)` | soʻrov; yoʻl endi `/health` |
| 15 | `rec := httptest.NewRecorder()` | yozilganni saqlaydigan `ResponseWriter` |
| 16 | `healthHandler(rec, req)` | butun fokus shu: handler'ni oddiy funksiya kabi chaqiramiz. `w` oʻrniga `rec`, `r` oʻrniga `req` beramiz |
| 17 | `fmt.Printf("%d %q\n", rec.Code, rec.Body.String())` | `rec.Code` — status, `rec.Body.String()` — yozilgan body matn sifatida. `%d` — son, `%q` — matnni qoʻshtirnoq ichida, yashirin belgilari bilan chiqaradi |

Handler statusni hech belgilamadi. `rec.Code` nima boʻladi?

**A)** `0` · **B)** `200` · **C)** `500`

<details>
<summary>Javob</summary>

**B: `200`.** Yuqoridagi qoida: `WriteHeader` chaqirilmasa, birinchi `Write` statusni `200` qiladi. **A** ni tanlagan boʻlsangiz, "belgilanmagan status = nol" deb oʻyladingiz;
**C** — xato boʻlmagan joyda `500` boʻlmaydi.

</details>

```console
$ ./_video/run.sh 02-recorder go run .
200 "ok\n"
(chiqish kodi: 0)
```

`200` — status. Body — `ok` va yangi qator: buni `Fprintln` qoʻshgan; `%q` uni `\n` deb koʻrsatdi.

Haqiqiy serverda birinchi `Write` `200`ni joʻnatadi; recorder esa `200` bilan boshlanadi — natija bir xil. Server ham, port ham, `curl` ham kerak boʻlmadi: bu oddiy funksiya chaqiruvi.

## Maʼlumot qaytaradigan handler: productHandler

`healthHandler` faqat `ok` deydi. Endi mahsulot beradigan handler. Butun fayl (`Product` — [GB-3.02](/lab/youtube/gb/gb-3-02)dagi struct, narx tiyinda):

```go filename="_video/04-product/main.go" showLineNumbers
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/http/httptest"
)

// Product — katalogdagi bitta mahsulot (GB-3.02).
type Product struct {
	ID    int64  `json:"id"`
	Name  string `json:"name"`
	Price int64  `json:"price"` // tiyin
	Stock int    `json:"stock"`
}

var olma = Product{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40}

// healthHandler — server tirikligini tekshirish: har soʻrovga «ok».
func healthHandler(w http.ResponseWriter, r *http.Request) {
	fmt.Fprintln(w, "ok")
}

// productHandler — GET'ga olma mahsulotini JSON qilib beradi, boshqa metodga 405.
func productHandler(w http.ResponseWriter, r *http.Request) {
	if r.Method != http.MethodGet {
		w.Header().Set("Allow", http.MethodGet)
		w.WriteHeader(http.StatusMethodNotAllowed)
		return
	}
	w.Header().Set("Content-Type", "application/json")
	json.NewEncoder(w).Encode(olma) // Encode xatosi: log'ga yozish GB-8.02'da
}

// main serverni ishga tushirmaydi (u GB-4.04'da): handler'ni oddiy funksiya kabi chaqirib, javobni chiqaradi.
func main() {
	req := httptest.NewRequest(http.MethodGet, "/products/1", nil)
	rec := httptest.NewRecorder()
	productHandler(rec, req)
	fmt.Printf("%d %s", rec.Code, rec.Body.String())
}
```

**Mahsulot (18-qator).** `var olma = Product{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40}` — handler beradigan `Product` qiymati. Narx tiyinda: `1_200_000` tiyin ([GB-1.03](/lab/youtube/gb/gb-1-03)).

**Header (32-qator).** `w.Header().Set("Content-Type", "application/json")`: `w.Header()` header'lar jadvalini qaytaradi, `Set` unga qiymat qoʻyadi. `application/json` — body JSON ekanini aytadi
([GB-4.01](/lab/youtube/gb/gb-4-01)). Header'ni body'dan **oldin** qoʻyamiz; sababi — "Javob tartibi" boʻlimida.

**Body (33-qator).** `json.NewEncoder(w).Encode(olma)`: `NewEncoder`ga `w`ni beramiz — bu `Decode`ning teskarisi, JSON'ni istalgan `io.Writer`ga yozadi. `Encode` `olma`ni (shu faylda eʼlon qilingan `Product`ni) `w`ga yozadi.
`Encode`ning xatosini hozircha tekshirmaymiz: log'ga yozish — [GB-8.02](/lab/youtube/gb#gb-8-02)da.

**Metod (27–31-qatorlar).** Handler `r`dan ham oʻqiy oladi: `r.Method` — soʻrov qatorining birinchi soʻzi. `GET` boʻlmasa, javob `405` (Method Not Allowed): `Allow` header'i qaysi metod mumkinligini aytadi
(`http.MethodGet`); [RFC 9110](https://www.rfc-editor.org/rfc/rfc9110#name-405-method-not-allowed) — HTTP standarti — `405` javobida uni majburiy qiladi. `WriteHeader(http.StatusMethodNotAllowed)` statusni belgilaydi: `405`.
`return` funksiyani shu yerda tugatadi, shuning uchun body yozilmaydi. [GB-4.05](/lab/youtube/gb/gb-4-05)da `ServeMux` metodni oʻzi tekshiradi; bu yerda `r`dan oʻqishni koʻrsatish uchun qoʻlda yozdik.

**main (37–42-qatorlar).** Handler'ni `/products/1` manziliga `GET` bilan chaqiradi va statusni, body'ni chiqaradi. `%s` — matn; `Encode` oxiriga yangi qator qoʻshadi, shuning uchun `Printf`da `\n` kerak emas.

Bashorat: `go run .` nima chiqaradi?

**A)** `200 {"ID":1,"Name":"olma","Price":12000,"Stock":40}` · **B)** `200 {"id":1,"name":"olma","price":1200000,"stock":40}` · **C)** `200 {"name":"olma"}`

<details>
<summary>Javob</summary>

**B.** Kalitlar `Product`dagi `json` tag'laridan olinadi, kichik harfda ([GB-3.02](/lab/youtube/gb/gb-3-02)); narx tiyinda saqlanadi: `1200000`. **A** da tag'larni unutdingiz (kalitlar katta harfda boʻlardi) va narxni
soʻmga aylantirdingiz — `Encode` hech narsani aylantirmaydi. **C** — `Encode` butun struct'ni yozadi, faqat `Name`ni emas.

</details>

Status `200`: `WriteHeader`ni chaqirmadik, birinchi `Write` uni belgiladi. Endi test. `TestProduct` body'ni qatorma-qator solishtirmaydi: u body'ni `Product`ga oʻqiydi.

```go
func TestProduct(t *testing.T) {
	rec := httptest.NewRecorder()
	productHandler(rec, httptest.NewRequest(http.MethodGet, "/products/1", nil))
	var got Product
	if err := json.NewDecoder(rec.Body).Decode(&got); err != nil {
		t.Fatalf("body JSON emas: %v", err)
	}
	if got != olma {
		t.Errorf("mahsulot %v, kutilgan %v", got, olma)
	}
}
```

|---|---|---|
| 1–2 | `rec := …; productHandler(rec, httptest.NewRequest(…))` | recorder va chaqiruv; soʻrov `NewRequest` bilan toʻgʻridan-toʻgʻri argumentga yozilgan |
| 3 | `var got Product` | oʻqilgan mahsulot uchun boʻsh oʻzgaruvchi |

| 7–9 | `if got != olma { t.Errorf(…) }` | `got` va `olma` struct'larini bitta taqqoslaymiz: Go struct'larni maydonma-maydon solishtiradi |

## Javob tartibi: header'lar, status, body

Handler'da tartib muhim. Uch qadam, shu ketma-ketlikda:

| Qadam | Chaqiruv | Nima boʻladi |
|---|---|---|
| 1 | `w.Header().Set(…)` | header'lar jadvalga yigʻiladi; hali hech narsa ketmagan |
| 2 | `w.WriteHeader(…)` | status belgilanadi (chaqirilmasa — `200`) |
| 3 | `w.Write(…)` yoki `Encode` | body yoziladi |

Birinchi `Write` chaqirilganda header'lar va status **joʻnatiladi**. Shundan keyingi `Header().Set` va `WriteHeader` hech narsani oʻzgartirmaydi:
joʻnatilgan narsani qaytarib boʻlmaydi ([ResponseWriter hujjati](https://pkg.go.dev/net/http#ResponseWriter)).

```text
Header().Set(…)  ─►  WriteHeader(…)  ─►  Write(…) / Encode(…)  ─►  joʻnatildi
  header'lar          status               body                      birinchi Write'da

                                                   keyingi Set / WriteHeader: oʻzgarmaydi
```

Shu sababli `productHandler`da `Content-Type` `Encode`dan oldin, `Allow` esa `WriteHeader`dan oldin qoʻyiladi. Tartib buzilsa nima boʻlishi — "Koʻp uchraydigan xatolar" boʻlimida.

## Chuqurroq (ixtiyoriy): http.Handler, HandlerFunc va NewServer

[GB-4.02](/lab/youtube/gb/gb-4-02)dagi test fayli `http.HandlerFunc` va `httptest.NewServer`dan foydalangan. Endi uni oʻqiy olasiz.

Server handler'ni `http.Handler` turida kutadi. Bu **bitta metodli interface**: `ServeHTTP(ResponseWriter, *Request)`. Bizning funksiyada bunday metod yoʻq.
`http.HandlerFunc` — **funksiya turi**: `type HandlerFunc func(ResponseWriter, *Request)`. Uning `ServeHTTP` metodi bor va u ichidagi funksiyani chaqiradi. Demak `http.HandlerFunc(f)` — oddiy
funksiyani `Handler`ga aylantirish ([HandlerFunc hujjati](https://pkg.go.dev/net/http#HandlerFunc)).

`httptest.NewServer` shu kompyuterda boʻsh portda **haqiqiy** server ochadi. Butun dastur:

```go filename="_video/07-server/main.go" showLineNumbers
package main

import (
	"fmt"
	"net/http"
	"net/http/httptest"
)

func main() {
	srv := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprintln(w, "ok")
	}))
	defer srv.Close()
	resp, err := http.Get(srv.URL)
	if err != nil {
		fmt.Println("xato:", err)
		return
	}
	defer resp.Body.Close()
	fmt.Println(resp.Status)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 10–12 | `srv := httptest.NewServer(http.HandlerFunc(func(w …, r …) { … }))` | funksiya literal'i — `w` va `r` bilan, bizning handler shakli; `HandlerFunc` uni `Handler` qiladi; `NewServer` server ochadi. Qavslar ketma-ket yopiladi: funksiya, `HandlerFunc`, `NewServer` |
| 13 | `defer srv.Close()` | [GB-2.09](/lab/youtube/gb/gb-2-09)dagidek: `srv.Close()` funksiya tugaganda chaqiriladi |
| 14–19 | `resp, err := http.Get(srv.URL)` va xato tekshiruvi | `srv.URL` — serverning manzili; client unga haqiqiy soʻrov yuboradi ([GB-4.02](/lab/youtube/gb/gb-4-02)) |
| 20 | `fmt.Println(resp.Status)` | javobning status qatorini chiqaradi |

Nima chiqadi? `A)` `200 OK` · `B)` `ok` · `C)` xato.

<details>
<summary>Javob</summary>

**A.** `resp.Status` — status kodi va sabab matni: `200 OK`. Body (`ok`) bu qatorda chiqarilmaydi. `ok` (B) handler yozgan body edi, xato (C) yoʻq: server ochildi va javob berdi.

</details>

```console
$ ./_video/run.sh 07-server go run .
200 OK
(chiqish kodi: 0)
```

Client haqiqiy soʻrov yubordi, bizning handler javob berdi. Qachon nimani ishlatamiz:

| Nimani tekshiramiz | Nima kerak | Nega |
|---|---|---|
| handler'ning oʻzi | `httptest.NewRecorder` | tez, port kerak emas |
| client kodi (masalan, [GB-4.02](/lab/youtube/gb/gb-4-02)dagi) | `httptest.NewServer` | client haqiqiy server bilan gaplashadi |

Test serveri shu kompyuterda, shuning uchun oddiy `http.Get` yetadi; tashqi serverga qoʻngʻiroq qilganda `Timeout` kerak ([GB-4.02](/lab/youtube/gb/gb-4-02)).

## Koʻp uchraydigan xatolar

**1. Avval body, keyin status.** Eng koʻp uchraydigan xato. Mana `notFoundHandler`: `Fprintln` body'ni yozadi, keyin `WriteHeader` bilan `404`ni belgilaymiz.

func catalogHandler(w http.ResponseWriter, r *http.Request) {
