## Nimani oʻrganasiz

bozor katalogi shu paytgacha `main.go` ichida yozilgan edi: narx oʻzgarsa, dasturni qayta qurish kerak. Endi katalog faylda keladi.
Har qatorda ID, nom, soʻmdagi narx va qoldiq, nuqtali vergul bilan ajratilgan:

```console
$ cat katalog.txt
1;olma;12000;40
2;oʻrik;35000;5
3;non;4000;100
4;choy;25000;8
```

Dastur bu faylni qanday oʻqiydi? Nega bitta `loadCatalog` funksiyasi katalogni fayldan ham, terminalga yozilgan matndan ham, testdagi
matndan ham bir xil oʻqiy olishi kerak?

**Bitta gʻoya:** `io.Reader` — bitta metodli interface. Chaqiruvchi `Read`'ga bufer boʻladigan bayt slice'i `p`'ni beradi, Reader unga koʻpi
bilan `len(p)` bayt yozadi va nechta yozganini `n`'da qaytaradi; maʼlumot tugaganda — `io.EOF`. Ochiq fayl baytlarni **boʻlak-boʻlak** beradi
va qatorni ham, belgi chegarasini ham bilmaydi. `bufio.Scanner` esa istalgan `io.Reader` ustida baytlarni oʻz buferiga yigʻib, ulardan
qatorlar yasaydi va nega toʻxtaganini `Err()` bilan aytadi. Shuning uchun fayl nomini emas, `io.Reader`'ni qabul qiladigan bitta funksiya
fayl, standart kirish va test matni bilan ishlaydi.

Dars oxirida siz:

- katalogni `os.Open` va `defer f.Close()` bilan fayldan ochasiz va `go doc io.Reader` dagi `Read` shartnomasini oʻqiysiz;
- `f.Read`'ni oʻzingiz chaqirib, fayl baytlarni qanday boʻlaklarda berishini koʻrasiz va `bufio.Scanner` bilan qatorma-qator oʻqiysiz;
- bitta `loadCatalog(r io.Reader)` funksiyasini fayl bilan, `cat katalog.txt | go run .` bilan va `strings.NewReader` bilan ishlatasiz;
- `sc.Err()` tekshirilmasa maʼlumot **jim** yoʻqolishini oʻz koʻzingiz bilan koʻrib, tuzatasiz; vazifada `loadCatalog`'ga izohlarni
  oʻtkazib yuborishni va xato qatorini aytishni oʻrgatasiz, `go test` oʻtguncha.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| `io.Reader` | bitta metodli interface: `Read(p)` sizning buferingizni baytlar bilan toʻldiradi, oxirida `io.EOF` | io.Reader |
| `bufio.Scanner` | Reader'dan boʻlak-boʻlak kelgan baytlardan qatorlar yasaydigan oʻqigich | bufio.Scanner |
| Reader qabul qilish | funksiya fayl nomini emas, `io.Reader`'ni oladi: bitta kod fayl, stdin va test uchun | accept an io.Reader |

Yordamchi tushunchalar birinchi uchraganda bir jumlada aytiladi: **standart kirish** (stdin) va **tik chiziq** (pipe), `strings.Split`,
**offset** va **bufer**.

## `io.Reader`: bitta metod

Faylni oʻqish uchun `f` ning metodlari kerak. Qaysi metod va u nimani kafolatlaydi? Buni `go doc` ([GB-2.07](/lab/youtube/gb/gb-2-07)) aytadi. Hujjatning
boshini koʻramiz (butun hujjat uzun, `head -n 5` faqat birinchi besh qatorni oladi):

```console
$ go doc io.Reader | head -n 5
package io // import "io"

type Reader interface {
	Read(p []byte) (n int, err error)
}
```

Bu [GB-2.07](/lab/youtube/gb/gb-2-07) dagi `Writer` kabi bitta metodli interface. Qismlari:

| Qism | Nima |
|---|---|
| `Read` | metod nomi |
| `p []byte` | chaqiruvchi beradigan **bufer**: baytlar uchun joy (`[]byte` — baytlar slice'i) |
| `n int` | `Read` nechta bayt yozgani |
| `err error` | xato yoki maʼlumot tugagani |

Hujjat qoidasi: `Read` `p` ga **koʻpi bilan `len(p)` bayt** yozadi va `n`'da nechtaligini qaytaradi. `n` har doim `0 <= n <= len(p)`.

Ochiq fayl bu interface'ni eʼlonsiz bajaradi ([GB-2.07](/lab/youtube/gb/gb-2-07)). `*os.File`'ning `Read`'i:

```console
$ go doc os.File.Read
package os // import "os"

func (f *File) Read(b []byte) (n int, err error)
    Read reads up to len(b) bytes from the File and stores them in b. It
    returns the number of bytes read and any error encountered. At end of file,
    Read returns 0, io.EOF.
```

Imzo aynan bir xil: `Read(b []byte) (n int, err error)` (parametr nomi `b`, bu muhim emas). Hujjati: «`len(b)` gacha bayt oʻqiydi, sonini va xatoni
qaytaradi. **Fayl oxirida** `0, io.EOF` qaytaradi.» **EOF** — *end of file*, yaʼni fayl oxiri. `io.EOF` — **sentinel xato**
([GB-2.08](/lab/youtube/gb/gb-2-08) dagi `ErrNotFound` kabi): paketda bir marta yaratilgan, chaqiruvchi uni solishtiradi. Uning oʻz hujjati:

```console
$ go doc io.EOF
package io // import "io"

var EOF = errors.New("EOF")
    EOF is the error returned by Read when no more input is available. (Read
    must return EOF itself, not an error wrapping EOF, because callers will test
    for EOF using ==.) Functions should return EOF only to signal a graceful
    end of input. If the EOF occurs unexpectedly in a structured data stream,
    the appropriate error is either ErrUnexpectedEOF or some other error giving
    more detail.
```

Eʼtibor bering: «Read EOF'ni **oʻramay** qaytarishi shart, chunki chaqiruvchilar uni `==` bilan tekshiradi». Shuning uchun keyingi kodda
`errors.Is` emas, `==` yoziladi.

## `Read`'ni oʻzimiz chaqiramiz

Shartnomani tekshiramiz: bufer ataylab kichik — 20 bayt. Dastur (`_video/02-read/main.go`):

```go filename="_video/02-read/main.go" showLineNumbers
// Video, 02-read: f.Read'ni oʻzimiz chaqiramiz — 20 baytlik buferga boʻlak-boʻlak.
package main

import (
	"fmt"
	"io"
	"os"
)

func run() error {
	f, err := os.Open("katalog.txt")
	if err != nil {
		return err
	}
	defer f.Close()
	buf := make([]byte, 20)
	for {
		n, err := f.Read(buf)
		fmt.Printf("%d %q\n", n, buf[:n])
		if err == io.EOF {
			break // fayl tugadi
		}
		if err != nil {
			return err
		}
	}
	return nil
}

func main() {
	if err := run(); err != nil {
		fmt.Fprintln(os.Stderr, "xato:", err)
		os.Exit(1)
	}
}
```

## `bufio.Scanner`: boʻlaklardan qatorlar

Bu ishni standart kutubxonadagi `bufio` paketi qiladi (*buffered I/O*, yaʼni buferli oʻqish-yozish). `bufio.NewScanner` istalgan `io.Reader`'ni oladi,
oʻz buferiga `Read` bilan baytlarni yigʻadi va ulardan qatorlar yasaydi. Dastur (`_video/03-scan/main.go`):

```go filename="_video/03-scan/main.go" showLineNumbers
// Video, 03-scan: bufio.Scanner fayldan qatorlarni beradi.
package main

import (
	"bufio"
	"fmt"
	"os"
)

func run() error {
	f, err := os.Open("katalog.txt")
	if err != nil {
		return err
	}
	defer f.Close()
	sc := bufio.NewScanner(f)
	for sc.Scan() {
		fmt.Printf("%q\n", sc.Text())
	}
	if err := sc.Err(); err != nil {
		return err
	}
	return nil
}

func main() {
	if err := run(); err != nil {
		fmt.Fprintln(os.Stderr, "xato:", err)
		os.Exit(1)
	}
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 5 | `"bufio"` | `bufio` paketi |
| 16 | `sc := bufio.NewScanner(f)` | `f`'dan oʻqiydigan Scanner yasaydi; `f` — `io.Reader`. Scanner `f.Read`'ni oʻzi chaqiradi |
| 17 | `for sc.Scan() {` | `Scan` keyingi qatorni topsa `true`, maʼlumot tugasa yoki xato boʻlsa `false` qaytaradi. U `for`'ning sharti ([GB-1.06](/lab/youtube/gb/gb-1-06)) |
| 18 | `fmt.Printf("%q\n", sc.Text())` | `sc.Text()` topilgan qatorni `string` qilib beradi |
| 20–22 | `if err := sc.Err(); err != nil { return err }` | sikldan keyin: `Scan` nega toʻxtagan? `sc.Err()` xato boʻlsa — uni qaytaramiz. Qisqa `if` — [GB-1.05](/lab/youtube/gb/gb-1-05) dagi shakl |

Endi oldingi natijaga qarab oʻylang: fayldagi ikkinchi qator, `oʻrik`, `sc.Text()` da qanday chiqadi?

## `parseLine`: qatordan `Product`

Qator — hali oddiy `string`. Uni `Product`'ga `parseLine` aylantiradi. Videoda uning ichi qisqa koʻrsatilgan, toʻliq kodi `main.go`da:

```go
func parseLine(line string) (Product, error) {
	parts := strings.Split(line, ";")
	if len(parts) != 4 {
		return Product{}, fmt.Errorf("4 ta maydon kerak, bor %d", len(parts))
	}
	id, err := strconv.ParseInt(parts[0], 10, 64)
	if err != nil {
		return Product{}, fmt.Errorf("ID: %w", err)
	}
	name := parts[1]
	if name == "" {
		return Product{}, errors.New("nom boʻsh")
	}
	if !utf8.ValidString(name) {
		return Product{}, errors.New("nom UTF-8 emas") // GB-2.10
	}
	price, err := parsePrice(parts[2])
	if err != nil {
		return Product{}, fmt.Errorf("narx: %w", err)
	}
	stock, err := strconv.Atoi(parts[3])
	if err != nil {
		return Product{}, fmt.Errorf("qoldiq: %w", err)
	}
	if stock < 0 {
		return Product{}, fmt.Errorf("qoldiq manfiy boʻlmasin, keldi %d", stock)
	}
	return Product{ID: id, Name: name, Price: price, Stock: stock}, nil
}
```

| Qator | Nima qiladi |
|---|---|
| `parts := strings.Split(line, ";")` | `strings.Split` qatorni `;` boʻyicha boʻlaklaydi va `[]string` beradi: `"1;olma;12000;40"` → `["1" "olma" "12000" "40"]` |
| `if len(parts) != 4 {…}` | toʻrtta maydon boʻlmasa — xato: `4 ta maydon kerak, bor 1` kabi |
| `id, err := strconv.ParseInt(parts[0], 10, 64)` | ID matnini `int64` songa aylantiradi (`10` — oʻnlik sanoq, `64` — 64 bit); xato boʻlsa `ID: …` bilan qaytadi (`%w`, GB-2.08) |
| `name := parts[1]` va ikki tekshiruv | nom boʻsh emas va toʻgʻri UTF-8 (`utf8.ValidString`, GB-2.10) |
| `price, err := parsePrice(parts[2])` | narx soʻmdan tiyinga: `12000` → `1200000` ([GB-1.07](/lab/youtube/gb/gb-1-07)) |
| `stock, err := strconv.Atoi(parts[3])` | qoldiq `int` songa; manfiy boʻlmasin |
| `return Product{ID: id, …}, nil` | tayyor `Product` (GB-2.03) |

`strings.Split` ning haqiqiy natijasini koʻramiz (bu dastur kurs papkasida yoʻq; saqlab `go run main.go` bilan ishga tushiring):

## Oʻzingizni tekshiring

1. `f.Read(buf)` `n` va `err` qaytardi. Avval qaysi biri ishlatiladi?

<details>
<summary>Javob</summary>

</details>

2. `for sc.Scan() { … }` tugagach nimani tekshirasiz va nega?

<details>
<summary>Javob</summary>

</details>

([errors.Is](https://pkg.go.dev/errors#Is)).

</details>

<details>
<summary>Javobning izohi (avval oʻzingiz urinib koʻring)</summary>

`solution/main.go`dagi `loadCatalog`:

```go
func loadCatalog(r io.Reader) ([]Product, error) {
	var products []Product
	sc := bufio.NewScanner(r)
	n := 0 // oʻqilgan qatorlar soni, izoh va boʻsh qatorlar ham
	for sc.Scan() {
		n++
		line := strings.TrimSpace(sc.Text())
		if line == "" || strings.HasPrefix(line, "#") {
			continue
		}
		p, err := parseLine(line)
		if err != nil {
			return nil, fmt.Errorf("%d-qator: %w", n, err)
		}
		products = append(products, p)
	}
	if err := sc.Err(); err != nil {
		// Scanner n-qatordan keyingisini oʻqiy olmadi.
		return nil, fmt.Errorf("%d-qator: %w", n+1, err)
	}
	return products, nil
}
```

- `n++` har qatorda, `continue`dan **oldin**: izoh va boʻsh qatorlar ham sanaladi, shuning uchun xato qatori fayldagi raqamga mos keladi.
- `strings.TrimSpace` boshidagi va oxiridagi probellarni olib tashlaydi; `line == ""` — boʻsh qator, `strings.HasPrefix(line, "#")` — izoh. Ikkalasida `continue`.
- `fmt.Errorf("%d-qator: %w", n, err)`: `%w` asl xatoni ichida saqlaydi, `errors.As` va `errors.Is` uni topadi. `%v` bilan matn bir xil chiqardi, lekin zanjir uzilardi: test buni tekshiradi.
- `sc.Err()` endi alohida tekshiriladi va `n+1` bilan oʻraladi: Scanner oxirgi oʻqilgan qatordan **keyingisini** oʻqiy olmadi. `katta.txt`da ikki qator oʻqildi, uchinchisi uzun: `3-qator`.
