## `var`: объявление с именем и типом

Программа должна запомнить название товара. Для этого объявляется **переменная**: в памяти выделяется место с
именем, и в него записывается значение только одного типа. Спецификация Go определяет так же: переменная — место
для хранения значения, а какие значения допустимы, задаёт её тип.

В 9-ю строку `main.go` пишем:

```go
	var name string
```

Читайте строку слева направо: *переменная с именем `name`, тип `string`.*

| Часть | Что это |
|---|---|
| `var` | ключевое слово: «объявляю переменную». Оно происходит от слова *variable* |
| `name` | имя, которое выбрали мы. По нему мы потом читаем и меняем значение |
| `string` | тип: текст |

Имена выбираем английские, в коде bozor на следующих уроках будут те же имена. Ещё два объявления:

```go
	var name string
	var price int
	var active bool
```

- `price` — цена за килограмм, тип `int`: **целое число**. Пока храним цену в целых сумах. Правильный выбор для
  денег — тема следующего урока ([GB-1.03](/lab/youtube/gb/gb-1-03/ru)).
- `active` — товар в продаже. Его тип `bool`, значение только `true` (да) или `false` (нет).

Теперь выведем все три на экран. В `fmt.Println` можно передать в скобках несколько значений через запятую. Он
пишет их в одну строку, ставит между ними один пробел и в конце переходит на новую строку. В документации так и
сказано: «между операндами всегда добавляются пробелы, а в конце добавляется перевод строки».

```go
	fmt.Println(name, price, active)
```

Обратите внимание: мы ещё не присвоили значение ни одной переменной. Файл сейчас выглядит так (первые 12 строк
`main.go` из папки курса и закрывающая `}`; отдельного файла с этим состоянием в папке нет, мы запустили его
отдельно):

```go
package main

import "fmt"

func main() {
	fmt.Println("bozor ishga tushdi")
	fmt.Println("versiya: 0.1.0")

	var name string
	var price int
	var active bool
	fmt.Println(name, price, active)
}
```

Что окажется в третьей строке вывода, если запустить программу?

**A)** ошибка компиляции · **B)** `0 0 false` · **C)** `(пусто) 0 false`

<details>
<summary>Ответ</summary>

**C: пустой текст, `0` и `false`.** Компилятор не выдаёт ошибку: переменные объявлены и использованы. Переменная
без присвоенного значения всё равно не пустая.

- Если вы выбрали **A**, вы думали, что читать переменную без значения запрещено. В Go такого правила нет.
- Если вы выбрали **B**, вы думали, что и для `string` выведется `0`. Начальное значение `string` — пустой текст,
  на экране он ничего не показывает.

```console
$ go run .
bozor ishga tushdi
versiya: 0.1.0
 0 false
```

Первые две строки — с прошлого урока. Третья начинается с пробела: сначала вывелся пустой текст из `name`
(ничего), потом пробел, который ставит `Println`, потом `0` и `false`.

</details>

## Zero value: если значение не задано

Это правило Go, оно называется **zero value**. Если переменную объявить без значения, Go заполняет её память
нулевым значением этого типа. Поэтому в Go у каждой переменной всегда есть определённое начальное значение.

| Тип | Zero value | Что покажет `fmt.Println` |
|---|---|---|
| `string` | `""` (пустой текст) | ничего |
| `int` | `0` | `0` |
| `float64` | `0` | `0` |
| `bool` | `false` | `false` |

Память после трёх строк:

| Строка | Код | `name` (`string`) | `price` (`int`) | `active` (`bool`) |
|---|---|---|---|---|
| 9 | `var name string` | `""` | — | — |
| 10 | `var price int` | `""` | `0` | — |
| 11 | `var active bool` | `""` | `0` | `false` |

«—» — переменная ещё не объявлена.

**В бэкенде это встречается часто.** Позже bozor будет читать товары из JSON-файла. Если в файле нет цены, ошибки
не будет: `price` останется в zero value, то есть `0`. Для компилятора ноль не ошибка, но как цена он не годится.
Поэтому такое значение проверяют отдельно: это будет в [GB-1.05](/lab/youtube/gb/gb-1-05/ru), через `if`.

## Присваивание: один `=`

Теперь заполним запись. Один знак равенства — **присваивание** (assignment). Go записывает значение справа в
память переменной слева, старое значение стирается. Строки 14–16 файла `main.go`:

```go
	name = "olma"
	price = 12000
	active = true
```

| Строка | Код | `name` | `price` | `active` |
|---|---|---|---|---|
| после 11 | (zero value) | `""` | `0` | `false` |
| 14 | `name = "olma"` | `"olma"` | `0` | `false` |
| 15 | `price = 12000` | `"olma"` | `12000` | `false` |
| 16 | `active = true` | `"olma"` | `12000` | `true` |

В `name` записан `olma` в кавычках, в `price` — целое число 12 000, в `active` — `true`. Один `=` не создаёт новую
переменную, он только записывает в существующую. Это правило понадобится в разделе «Промежуточный вопрос».

## `:=`: короткое объявление

Если значение известно уже при объявлении, его задают сразу. `stock` хранит, сколько упаковок на складе. Записать
это можно тремя способами:

```go
var stock int = 40
var stock = 40
stock := 40
```

| Форма | Что написано | Откуда тип |
|---|---|---|
| `var stock int = 40` | `var`, имя, тип, значение | указан явно: `int` |
| `var stock = 40` | тип не указан | из значения: `40` — целое число, Go сам определяет тип `int` |
| `stock := 40` | самая короткая форма, «двоеточие-равно» | из значения: `int` |

Третья — **short variable declaration** (краткое объявление переменной): объявление и присваивание в одном
действии, тип берётся из значения. Все три строки дают одно и то же: `stock` типа `int` со значением `40`. Если
написано целое число, тип будет `int`, если число с точкой (`1.5`) — `float64`: в спецификации это называется
*default type* числа без кавычек.

Правила `:=`:

- **Одно имя — одно объявление.** Одно и то же имя нельзя объявить в одном месте дважды, поэтому в коде пишется
  только одна из трёх форм.
- **`:=` работает только внутри функции.** `main` — тоже функция. Вне функции переменную объявляют только через
  `var`.
- **Обычный выбор:** есть значение — `:=`, переменная должна начинаться с zero value — `var`. То же советует
  руководство по стилю Go от Google.

Добавляем в `main.go` два коротких объявления (строки 17–18):

```go
	stock := 40
	weight := 1.5
```

`stock` — 40, тип `int`. `weight` — вес одной упаковки, 1,5 килограмма. Число с точкой — **дробное число**, Go
берёт для него тип `float64`. `64` в конце: значение занимает 64 бита, о размерах — на следующем уроке.

| Строка | Код | `stock` (`int`) | `weight` (`float64`) |
|---|---|---|---|
| 17 | `stock := 40` | `40` | — |
| 18 | `weight := 1.5` | `40` | `1.5` |

Все четыре основных типа урока теперь есть в файле: `string`, `int`, `bool`, `float64`.

## Полный файл

`main.go` из папки курса (исходное состояние задания):

```go filename="main.go" showLineNumbers
package main

import "fmt"

func main() {
	fmt.Println("bozor ishga tushdi")
	fmt.Println("versiya: 0.1.0")

	var name string
	var price int
	var active bool
	fmt.Println(name, price, active)

	name = "olma"
	price = 12000
	active = true
	stock := 40
	weight := 1.5
	fmt.Println(name, price, active, stock, weight)
}
```

| Строка | Код | Что делает |
|---|---|---|
| 1–7 | `package main` … `fmt.Println("versiya: 0.1.0")` | из GB-1.01: пакет, импорт `fmt`, функция `main` и две строки вывода |
| 9–11 | `var name string` … | три объявления без значения: начинают с zero value |
| 12 | `fmt.Println(name, price, active)` | выводит zero value: ` 0 false` |
| 14–16 | `name = "olma"` … | присваивание существующим переменным |
| 17–18 | `stock := 40`, `weight := 1.5` | два коротких объявления: `int` и `float64` |
| 19 | `fmt.Println(name, price, active, stock, weight)` | все пять значений в одной строке |

Почему все пять стоят в 19-й строке? Если объявленная переменная нигде не используется, Go не собирает программу и
пишет `declared and not used` («объявлена, но не используется»). Эта ошибка — в разделе «Частые ошибки».

```console
$ go run .
bozor ishga tushdi
versiya: 0.1.0

olma 12000 true 40 1.5
```

В четвёртой строке — запись о товаре: `olma`, `12000`, `true`, `40` и `1.5`, в том же порядке, в каком мы передали
их в `Println`.

## Ошибка типов: `int` и `float64`

Теперь посчитаем цену одной упаковки: 12 000 за кило, упаковка 1,5 кило. Добавим это в 20-ю строку (после 19-й,
перед закрывающей `}`). `*` — умножение:

```go
	fmt.Println(name, price, active, stock, weight)
	fmt.Println(price * weight)
}
```

`price` — `int`, `weight` — `float64`. Что будет?

**A)** `18000` · **B)** `12000` · **C)** ошибка компиляции

<details>
<summary>Ответ</summary>

**C: ошибка компиляции.**

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:20:14: invalid operation: price * weight (mismatched types int and float64)
```

Читаем сообщение, как на прошлом уроке: `main.go`, строка 20, столбец 14 — место, где начинается `price` (Tab —
1-й столбец, `fmt.Println(` — столбцы 2–13). *invalid operation* — «недопустимая операция». В скобках причина:
*mismatched types int and float64* — «типы не совпадают: int и float64».

- Если вы выбрали **A**, вы думали, что Go сам превратит `price` в дробное число.
- Если вы выбрали **B**, вы думали, что `1.5` обрежется до целого (`1`).

Go не делает ни того, ни другого.

</details>

**Почему ошибка.** В Go в операции над двумя переменными их типы должны совпадать. Числа, написанные без кавычек
(например, `price * 2`), — исключение, их разберём на следующем уроке. Компилятор не превращает `int` во `float64`
сам. На официальной странице FAQ Go сказано почему: удобство автоматического преобразования между числовыми типами
не стоит той путаницы, которую оно вызывает. Явное изменение типа называется **conversion** (преобразование), его
напишем в [GB-1.03](/lab/youtube/gb/gb-1-03/ru). Коротко: Go не смешивает типы молча. Поэтому эту строку пока удаляем.

## Промежуточный вопрос: `stock := stock - 1`

Продали одну упаковку, и кто-то написал в 20-й строке (`-` — вычитание):

```go
	fmt.Println(name, price, active, stock, weight)
	stock := stock - 1
}
```

А `stock` уже объявлен в 17-й строке как `stock := 40`. Что сделает эта строка?

**A)** `stock` теперь 39 · **B)** ошибка компиляции · **C)** второй `stock`: 39, первый 40

<details>
<summary>Ответ</summary>

**B: ошибка компиляции.**

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:20:8: no new variables on left side of :=
```

Сообщение указывает на строку 20, столбец 8, то есть на место, где стоит `:=` (Tab — 1-й столбец, `stock` — 2–6,
пробел — 7). *no new variables on left side of :=* — «слева от `:=` нет новых переменных». `:=` объявляет, а
`stock` уже объявлен.

- Если вы выбрали **A**, вы думали, что `:=` записывает в существующую переменную: это работа `=`.
- Если вы выбрали **C**, вы думали, что одно имя можно объявить в одном месте дважды. Так тоже нельзя.

Если слева несколько имён, достаточно, чтобы хотя бы одно было новым. Это правило понадобится в
[GB-1.07](/lab/youtube/gb/gb-1-07/ru).

</details>

**Исправление.** В существующую переменную пишут одним `=`:

```go
	stock = stock - 1
```

Go сначала вычисляет правую часть, потом записывает результат в переменную слева:

| Шаг | Что происходит | `stock` |
|---|---|---|
| после строки 17 | `stock := 40` | `40` |
| строка 20, шаг 1 | вычисляется правая часть: `stock - 1` = 40 − 1 = 39 | `40` |
| строка 20, шаг 2 | 39 записывается в память `stock` | `39` |

Исправленная строка собирается. Вывод не меняется, потому что после 20-й строки `stock` не выводится:

```console
$ go run .
bozor ishga tushdi
versiya: 0.1.0
 0 false
olma 12000 true 40 1.5
```

Эту строку оставим для задания, а пока удалим.

## Текст вместо числа: `price = "12000"`

Теперь ситуация из начала урока: вместо цены текст. Значение скопировали откуда-то вместе с кавычками, и 15-я
строка стала такой:

```go
	price = "12000"
```

На вид это число, но кавычки делают его текстом. А `price` объявлен в 10-й строке как `int`. Кто поймает эту
ошибку?

**A)** при работе программы, клиент · **B)** при сборке, компилятор · **C)** никто: Go сам превратит текст в число

<details>
<summary>Ответ</summary>

**B: компилятор, во время сборки.**

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:15:10: cannot use "12000" (untyped string constant) as int value in assignment
```

Сообщение указывает на строку 15, столбец 10, то есть на открывающую кавычку. *cannot use "12000"* — «нельзя
использовать `"12000"`», *as int value in assignment* — «как значение `int` при присваивании». *untyped string
constant* в скобках — так компилятор называет текст в кавычках, константы разберём в [GB-1.03](/lab/youtube/gb/gb-1-03/ru).
Главное: тип `price` при объявлении был `int`, и он не меняется.

- Если вы выбрали **A**, вы думали, что тип проверяется во время работы программы. В Go тип проверяет компилятор,
  ещё до запуска.
- Если вы выбрали **C**, вы думали, что Go сам превратит текст в число. Go этого не делает, как и в случае
  `int * float64`.

</details>

**Исправление:** убираем кавычки, 15-я строка снова `price = 12000`. Эта ошибка ни до кого не дошла, потому что
компилятор остановился и исполняемый файл вообще не был собран. А текст, который пользователь вводит в работающую
программу, компилятор не видит, его проверим в [GB-1.07](/lab/youtube/gb/gb-1-07/ru).

Коротко: тип переменной задаётся один раз при объявлении, и компилятор сверяет с ним каждое значение.

## Частые ошибки

**1. Запись в существующую переменную через `:=`.** Самая частая ошибка, и в задании есть именно эта ловушка. Если
начать задание так (после 20-й строки):

```go
	sold := 3
	stock := stock - sold
	fmt.Println(name, stock)
```

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:22:8: no new variables on left side of :=
```

Строка 22, столбец 8: `stock` объявлен в 17-й строке, а `:=` требует нового имени (раздел «Промежуточный вопрос»).
**Исправление:** `stock = stock - sold`.

**2. Объявить и не использовать.** Если написать `sold := 3` и нигде его не использовать:

```go
	fmt.Println(name, price, active, stock, weight)

	sold := 3
}
```

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:21:2: declared and not used: sold
```

*declared and not used: sold* — «`sold` объявлена, но не используется». Это не предупреждение, а ошибка: программа
не собирается. **Исправление:** используйте переменную или удалите объявление.

**3. `:=` вне функции.** Если написать `stock := 40` до `func main()`, на уровне файла:

```go
package main

import "fmt"

stock := 40

func main() {
```

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:5:1: syntax error: non-declaration statement outside function body
```

*syntax error: non-declaration statement outside function body* — «синтаксическая ошибка: инструкция, не
являющаяся объявлением, вне тела функции». Вне функции `:=` не работает. **Исправление:** `var stock = 40` или
перенесите объявление внутрь `main`. (Этого примера нет в видео, мы запустили его отдельно.)

**4. Смешивание типов и число в кавычках.** `price * weight` (`int` и `float64`) и `price = "12000"` — обе
ошибки компиляции. Полный разбор — в разделах «Ошибка типов» и «Текст вместо числа».

**5. Тихая ошибка: остаток уменьшен слишком рано.** Если написать новые строки задания *до* 19-й строки, программа
соберётся и не выдаст ошибку, но изменится 4-я строка: `olma 12000 true 37 1.5`. `go test` это ловит:

```console
$ go test
--- FAIL: TestQatorlar (0.00s)
    main_test.go:64: 4-qator «olma 12000 true 40 1.5» boʻlishi kerak, hozir «olma 12000 true 37 1.5»
FAIL
exit status 1
FAIL	github.com/abdurahmon27/bozor	0.002s
```

(Сообщение теста на узбекском: «4-я строка должна быть «…», сейчас «…»».) **Исправление:** пишите новые строки
**после** существующей строки `fmt.Println(name, price, active, stock, weight)`. (Время в последнем столбце при
каждом запуске немного другое.)

## Проверьте себя

Сначала ответьте сами, потом откройте.

**1.** Чем `var stock int` отличается от `stock := 40`?

<details>
<summary>Ответ</summary>

`var stock int` — объявление без значения: `stock` начинается с zero value, то есть с `0`. `stock := 40`
объявляет со значением `40`, тип берётся из значения (`int`), и работает только внутри функции.

</details>

**2.** Чему равна `active` после `var active bool`?

<details>
<summary>Ответ</summary>

`false`: это zero value типа `bool`.

</details>

**3.** Что выведет эта программа? (Её нет в папке курса, запущена отдельно. `+` — сложение.)

```go
package main

import "fmt"

func main() {
	var stock int
	stock = stock + 10
	weight := 2.5
	var ok bool
	fmt.Println(stock, weight, ok)
}
```

**A)** ошибка компиляции · **B)** `10 2.5 false` · **C)** `0 2.5 false`

<details>
<summary>Ответ</summary>

**B.** `stock` начинается с zero value `0`, потом вычисляется `0 + 10` и записывается `10`. `weight` — `float64`,
`ok` — `false`.

```console
$ go run .
10 2.5 false
```

Если вы выбрали **A**, вы думали, что переменную без значения нельзя читать. Если **C** — вы не учли строку с `=`.

</details>

**4.** `price` объявлена с целым числом, потом в неё записывают `1.5`. Что будет? (Нет в папке курса, запущено
отдельно.)

```go
package main

import "fmt"

func main() {
	price := 12000
	price = 1.5
	fmt.Println(price)
}
```

<details>
<summary>Ответ</summary>

Ошибка компиляции: тип `price` взят в `:=` из `12000`, то есть `int`, и он не меняется.

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:7:10: cannot use 1.5 (untyped float constant) as int value in assignment (truncated)
```

*truncated* — «усечено»: чтобы поместиться в `int`, `1.5` пришлось бы потерять дробную часть, и Go этого не
допускает.

</details>

**5.** С прошлого урока: что создаёт `go build`?

<details>
<summary>Ответ</summary>

Один исполняемый файл. Он работает и на компьютере без установленного Go, если там та же операционная система и
тот же тип процессора.

</details>

    main_test.go:108: stock'ning yangi qiymati sold'dan hisoblanib, bor oʻzgaruvchiga yozilishi kerak (:= emas: stock allaqachon bor)
FAIL

Тест проверяет три вещи: пять строк вывода, объявление `sold := …` и то, что новое значение `stock` вычислено из
`sold` через `=`. Ещё проверяется, что файл отформатирован `go fmt`.

<details>
<summary>Ответ</summary>

```go filename="solution/main.go" showLineNumbers
package main

import "fmt"

func main() {
	fmt.Println("bozor ishga tushdi")
	fmt.Println("versiya: 0.1.0")

	var name string
	var price int
	var active bool
	fmt.Println(name, price, active)

	name = "olma"
	price = 12000
	active = true
	stock := 40
	weight := 1.5
	fmt.Println(name, price, active, stock, weight)

	sold := 3
	stock = stock - sold
	fmt.Println(name, stock)
}
```

| Строка | Код | Что делает |
|---|---|---|
| 21 | `sold := 3` | новая переменная, короткое объявление, тип `int` |
| 22 | `stock = stock - sold` | запись в существующий `stock`: сначала `40 - 3` = `37`, потом записывается `37`. Не `:=` |
| 23 | `fmt.Println(name, stock)` | `olma 37`; `sold` при этом тоже использована (в 22-й строке) |

Все три строки стоят после 19-й, поэтому 4-я строка остаётся с `40`. Есть и запись `stock -= sold`: это короткая
форма `stock = stock - sold`, тест принимает и её.

</details>
