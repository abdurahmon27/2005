## Nimani oʻrganasiz

bozorga birinchi mahsulotni kiritamiz: olma, kilosi 12 000 soʻm, omborda 40 qadoq. Kodda narx oʻrniga tasodifan
matn yozilsa, bu xatoni dastur ishga tushmasdan oldin kim ushlaydi?

**Bitta gʻoya:** oʻzgaruvchi — xotirada nomi va bitta turi bor joy. Qiymatsiz eʼlon qilinsa, unda shu turning
zero value'si turadi. `=` unga yangi qiymat yozadi, turi esa eʼlondan keyin oʻzgarmaydi, va buni kompilyator qurish
paytida tekshiradi.

Dars oxirida siz:

- oʻzgaruvchini `var` bilan va qisqa shakl `:=` bilan eʼlon qilasiz va qaysi birini qachon tanlashni bilasiz;
- toʻrt asosiy turdan birini tanlaysiz: `int`, `float64`, `string`, `bool`;
- qiymat berilmagan oʻzgaruvchida nima turishini (zero value) oldindan aytasiz;
- uchta haqiqiy kompilyator xabarini `fayl:qator:ustun` boʻyicha oʻqib, xatoni tuzatasiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| oʻzgaruvchi eʼloni | xotirada nomi va turi bor joy ochish: `var name string` yoki `stock := 40` | variable declaration |
| tur | qiymat qaysi xilda: butun son, kasrli son, matn yoki `true`/`false` | type (`int`, `float64`, `string`, `bool`) |
| nol qiymat (zero value) | qiymat berilmagan oʻzgaruvchidagi boshlangʻich qiymat: `""`, `0`, `false` | zero value |

Ikkita yordamchi soʻz ham bor: **qiymat berish** (assignment) — bitta `=` bilan bor oʻzgaruvchiga yangi qiymat
yozish; va kompilyatorning tur haqidagi uchta xabari: `invalid operation … mismatched types`, `no new variables on
left side of :=` va `cannot use … as int value in assignment`. Ularning har biri quyida alohida boʻlimda.

```go
package main
```

## `var`: nom va tur bilan eʼlon

Dastur mahsulot nomini eslab qolishi kerak. Buning uchun **oʻzgaruvchi** eʼlon qilinadi: xotirada nomi bor joy
ajratiladi va unga faqat bitta turdagi qiymat yoziladi. Go spetsifikatsiyasi ham shunday taʼriflaydi: oʻzgaruvchi —
qiymatni saqlaydigan joy, qanday qiymatlar mumkinligini uning turi belgilaydi.

`main.go`'ning 9-qatoriga shuni yozamiz:

```go
	var name string
```

Qatorni chapdan oʻngga shunday oʻqing: *`name` degan oʻzgaruvchi, turi `string`.*

| Qism | Nima |
|---|---|
| `var` | kalit soʻz: «oʻzgaruvchi eʼlon qilaman». U *variable* soʻzidan olingan |
| `name` | biz tanlagan nom. Shu nom bilan qiymatni keyin oʻqiymiz va oʻzgartiramiz |
| `string` | tur: matn |

Nomlarni inglizcha tanlaymiz, bozor kodida keyingi darslarda ham shu nomlar ishlatiladi. Yana ikkita eʼlon:

```go
	var name string
	var price int
	var active bool
```

- `price` — bir kilogramm narxi, turi `int`: **butun son**. Hozircha narxni butun soʻmda saqlaymiz. Pul uchun toʻgʻri
  tanlov keyingi darsning mavzusi ([GB-1.03](/lab/youtube/gb/gb-1-03)).
- `active` — mahsulot sotuvda ekanini bildiradi. Uning turi `bool`, qiymati faqat `true` (ha) yoki `false` (yoʻq).

Endi uchalasini ekranga chiqaramiz. `fmt.Println`'ga qavs ichida vergul bilan bir nechta qiymat berish mumkin. U
hammasini bitta qatorga yozadi, orasiga bitta boʻsh joy qoʻyadi va oxirida yangi qatorga oʻtadi. Hujjatda ham shunday:
«operandlar orasiga doim boʻsh joy qoʻshiladi va oxiriga yangi qator qoʻshiladi».

```go
	fmt.Println(name, price, active)
```

Eʼtibor bering: hali hech bir oʻzgaruvchiga qiymat bermadik. Fayl shu paytda mana bunday (kurs papkasidagi
`main.go`'ning birinchi 12 qatori va yopuvchi `}`; bu holat papkada alohida fayl emas, biz uni alohida ishga
tushirdik):

```go
package main

import "fmt"

func main() {
	fmt.Println("bozor ishga tushdi")
	fmt.Println("versiya: 0.1.0")

	var name string
	var price int
	var active bool
	fmt.Println(name, price, active)
}
```

Dasturni ishga tushirsak, chiqishning uchinchi qatorida nima boʻladi?

**A)** kompilyator xatosi · **B)** `0 0 false` · **C)** `(boʻsh) 0 false`

<details>
<summary>Javob</summary>

**C: boʻsh matn, `0` va `false`.** Kompilyator xato bermaydi: oʻzgaruvchilar eʼlon qilingan va ishlatilgan.
Qiymat berilmagan oʻzgaruvchi ham qiymatsiz emas.

- **A** ni tanlagan boʻlsangiz, qiymat berilmagan oʻzgaruvchini oʻqish taqiqlangan deb oʻylagansiz. Go'da bunday
  qoida yoʻq.
- **B** ni tanlagan boʻlsangiz, `string` uchun ham `0` chiqadi deb oʻylagansiz. `string`'ning boshlangʻich qiymati
  boʻsh matn, u ekranda koʻrinmaydi.

```console
$ go run .
bozor ishga tushdi
versiya: 0.1.0
 0 false
```

Birinchi ikki qator oldingi darsdan. Uchinchisi boʻsh joy bilan boshlanadi: avval `name`'dagi boʻsh matn chiqdi
(hech narsa), keyin `Println` qoʻygan boʻsh joy, keyin `0` va `false`.

</details>

## Zero value: qiymat berilmasa

Bu Go'ning qoidasi, uning nomi **zero value**. Oʻzgaruvchi qiymatsiz eʼlon qilinsa, Go uning xotirasini shu turning
nol qiymati bilan toʻldiradi. Shuning uchun Go'da har bir oʻzgaruvchining doim aniq boshlangʻich qiymati bor.

| Tur | Zero value | `fmt.Println` koʻrsatadi |
|---|---|---|
| `string` | `""` (boʻsh matn) | hech narsa |
| `int` | `0` | `0` |
| `float64` | `0` | `0` |
| `bool` | `false` | `false` |

Uch qatordan keyin xotira:

| Qator | Kod | `name` (`string`) | `price` (`int`) | `active` (`bool`) |
|---|---|---|---|---|
| 9 | `var name string` | `""` | — | — |
| 10 | `var price int` | `""` | `0` | — |
| 11 | `var active bool` | `""` | `0` | `false` |

«—» — oʻzgaruvchi hali eʼlon qilinmagan.

**Backend'da bu koʻp uchraydi.** Keyinroq bozor mahsulotlarni JSON faylidan oʻqiydi. Faylda narx yozilmagan
boʻlsa, xato chiqmaydi: `price` zero value boʻlib qoladi, yaʼni `0`. Nol kompilyator uchun xato emas, lekin narx
sifatida yaroqsiz. Shuning uchun bunday qiymatni alohida tekshiramiz: bu [GB-1.05](/lab/youtube/gb/gb-1-05) da, `if` bilan
boʻladi.

## Qiymat berish: bitta `=`

Endi yozuvni toʻldiramiz. Bitta teng belgisi — **qiymat berish** (assignment). Go oʻng tomondagi qiymatni chap
tomondagi oʻzgaruvchining xotirasiga yozadi, eski qiymat oʻchadi. `main.go`'ning 14–16-qatorlari:

```go
	name = "olma"
	price = 12000
	active = true
```

| Qator | Kod | `name` | `price` | `active` |
|---|---|---|---|---|
| 11 dan keyin | (zero value) | `""` | `0` | `false` |
| 14 | `name = "olma"` | `"olma"` | `0` | `false` |
| 15 | `price = 12000` | `"olma"` | `12000` | `false` |
| 16 | `active = true` | `"olma"` | `12000` | `true` |

`name`'ga qoʻshtirnoq ichidagi `olma` yozildi, `price`'ga butun son 12 000, `active`'ga `true`. Bitta `=` yangi
oʻzgaruvchi yaratmaydi, faqat bor oʻzgaruvchiga yozadi. Bu qoida «Oraliq savol» boʻlimida kerak boʻladi.

## `:=`: qisqa eʼlon

Qiymat eʼlon paytidayoq maʼlum boʻlsa, uni darhol beramiz. `stock` omborda nechta qadoq borligini saqlaydi. Uni uch
xil yozish mumkin:

```go
var stock int = 40
var stock = 40
stock := 40
```

| Shakl | Nima yozilgan | Tur qayerdan |
|---|---|---|
| `var stock int = 40` | `var`, nom, tur, qiymat | yozilgan: `int` |
| `var stock = 40` | tur yozilmagan | qiymatdan: `40` butun son, Go turni oʻzi `int` deb aniqlaydi |
| `stock := 40` | eng qisqa shakl, «ikki nuqta teng» | qiymatdan: `int` |

Uchinchisi — **short variable declaration** (qisqa eʼlon): eʼlon va qiymat berish bitta amalda, tur qiymatdan
olinadi. Uchala qator bir xil natija beradi: `int` turidagi `stock`, qiymati `40`. Butun son yozilsa tur `int`,
nuqtali son (`1.5`) yozilsa `float64` boʻladi: spetsifikatsiyada bu qoʻshtirnoqsiz sonning *default type*'i deb
ataladi.

`:=` qoidalari:

- **Bitta nom — bitta eʼlon.** Bitta nomni bir joyda ikki marta eʼlon qilib boʻlmaydi, shuning uchun kodda uch
  shakldan bittasi yoziladi.
- **`:=` faqat funksiya ichida ishlaydi.** `main` ham funksiya. Funksiyadan tashqarida oʻzgaruvchi faqat `var` bilan
  eʼlon qilinadi.
- **Odatiy tanlov:** qiymat bor boʻlsa `:=`, oʻzgaruvchi zero value bilan boshlanishi kerak boʻlsa `var`. Google'ning
  Go uslub qoʻllanmasi ham shuni tavsiya qiladi.

`main.go`'ga ikkita qisqa eʼlon qoʻshamiz (17–18-qatorlar):

```go
	stock := 40
	weight := 1.5
```

`stock` — 40, turi `int`. `weight` — bitta qadoqning ogʻirligi, 1.5 kilogramm. Nuqtali son — **kasrli son**, Go
uning turini `float64` deb oladi. Oxiridagi `64`: bu qiymat 64 bit joy egallaydi, oʻlchamlar keyingi darsda.

| Qator | Kod | `stock` (`int`) | `weight` (`float64`) |
|---|---|---|---|
| 17 | `stock := 40` | `40` | — |
| 18 | `weight := 1.5` | `40` | `1.5` |

Bugungi toʻrtta asosiy turning hammasi endi faylda bor: `string`, `int`, `bool`, `float64`.

## Toʻliq fayl

Kurs papkasidagi `main.go` (vazifaning boshlangʻich holati):

```go filename="main.go" showLineNumbers
package main

import "fmt"

func main() {
	fmt.Println("bozor ishga tushdi")
	fmt.Println("versiya: 0.1.0")

	var name string
	var price int
	var active bool
	fmt.Println(name, price, active)

	name = "olma"
	price = 12000
	active = true
	stock := 40
	weight := 1.5
	fmt.Println(name, price, active, stock, weight)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1–7 | `package main` … `fmt.Println("versiya: 0.1.0")` | GB-1.01 dan: paket, `fmt` importi, `main` funksiyasi va ikki qator chiqish |
| 9–11 | `var name string` … | uchta qiymatsiz eʼlon: zero value bilan boshlanadi |
| 12 | `fmt.Println(name, price, active)` | zero value'larni chiqaradi: ` 0 false` |
| 14–16 | `name = "olma"` … | bor oʻzgaruvchilarga qiymat berish |
| 17–18 | `stock := 40`, `weight := 1.5` | ikkita qisqa eʼlon: `int` va `float64` |
| 19 | `fmt.Println(name, price, active, stock, weight)` | beshala qiymat bitta qatorda |

Nega beshalasi ham 19-qatorda? Eʼlon qilingan oʻzgaruvchi hech qayerda ishlatilmasa, Go dasturni qurmaydi va
`declared and not used` (eʼlon qilingan, lekin ishlatilmagan) deydi. Bu xato «Koʻp uchraydigan xatolar» boʻlimida.

```console
$ go run .
bozor ishga tushdi
versiya: 0.1.0
 0 false
olma 12000 true 40 1.5
```

Toʻrtinchi qatorda mahsulot yozuvi: `olma`, `12000`, `true`, `40` va `1.5`, xuddi `Println`'ga bergan tartibda.

## Tur xatosi: `int` bilan `float64`

Endi bitta qadoq narxini hisoblaymiz: kilosi 12 000, qadoq 1.5 kilo. 20-qatorga (19-qatordan keyin, yopuvchi `}`
dan oldin) shuni qoʻshamiz. `*` — koʻpaytirish:

```go
	fmt.Println(name, price, active, stock, weight)
	fmt.Println(price * weight)
}
```

`price` — `int`, `weight` — `float64`. Nima boʻladi?

**A)** `18000` · **B)** `12000` · **C)** kompilyator xatosi

<details>
<summary>Javob</summary>

**C: kompilyator xatosi.**

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:20:14: invalid operation: price * weight (mismatched types int and float64)
```

Xabarni oldingi darsdagidek oʻqiymiz: `main.go`, 20-qator, 14-ustun — `price` boshlanadigan joy (Tab 1-ustun,
`fmt.Println(` 2–13-ustunlar). *invalid operation* — «amal notoʻgʻri». Qavs ichida sababi: *mismatched types int and
float64* — «turlar mos emas: int va float64».

- **A** ni tanlagan boʻlsangiz, Go `price`'ni oʻzi kasrli songa aylantiradi deb oʻylagansiz.
- **B** ni tanlagan boʻlsangiz, `1.5` butun songa (`1`) qisqaradi deb oʻylagansiz.

Go ikkalasini ham qilmaydi.

</details>

**Nega xato.** Go'da ikki oʻzgaruvchi ustidagi amalda ikkalasining turi bir xil boʻlishi shart. Qoʻshtirnoqsiz
yozilgan sonlar (masalan `price * 2`) bundan istisno, ularni keyingi darsda koʻramiz. Kompilyator `int`'ni
`float64`'ga oʻzi aylantirmaydi. Go'ning rasmiy FAQ sahifasida sababi yozilgan: sonli turlar orasidagi avtomatik
aylantirishning qulayligi u keltiradigan chalkashlikka arzimaydi. Turni aniq oʻzgartirish **conversion**
(aylantirish) deyiladi, uni [GB-1.03](/lab/youtube/gb/gb-1-03) da yozamiz. Qisqasi, Go turlarni jimgina aralashtirmaydi.
Shuning uchun bu qatorni hozircha oʻchiramiz.

## Oraliq savol: `stock := stock - 1`

Bitta qadoq sotildi va kimdir 20-qatorga shuni yozdi (`-` — ayirish):

```go
	fmt.Println(name, price, active, stock, weight)
	stock := stock - 1
}
```

`stock` esa 17-qatorda `stock := 40` bilan eʼlon qilingan. Bu qator nima qiladi?

**A)** `stock` endi 39 · **B)** kompilyator xatosi · **C)** ikkinchi `stock`: 39, birinchisi 40

<details>
<summary>Javob</summary>

**B: kompilyator xatosi.**

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:20:8: no new variables on left side of :=
```

Xabar 20-qator, 8-ustunni, yaʼni `:=` turgan joyni koʻrsatadi (Tab 1-ustun, `stock` 2–6, boʻsh joy 7). *no new
variables on left side of :=* — «`:=` ning chap tomonida yangi oʻzgaruvchi yoʻq». `:=` eʼlon qiladi, `stock` esa
allaqachon eʼlon qilingan.

- **A** ni tanlagan boʻlsangiz, `:=` ni bor oʻzgaruvchiga yozish deb oʻylagansiz: bu `=` ning ishi.
- **C** ni tanlagan boʻlsangiz, bitta nom bir joyda ikki marta eʼlon qilinadi deb oʻylagansiz. Bu ham mumkin emas.

Chapda bir nechta nom boʻlsa, kamida bittasi yangi boʻlishi yetarli. Bu qoida [GB-1.07](/lab/youtube/gb/gb-1-07) da kerak
boʻladi.

</details>

**Tuzatish.** Bor oʻzgaruvchiga bitta `=` bilan yoziladi:

```go
	stock = stock - 1
```

Go avval oʻng tomonni hisoblaydi, keyin natijani chap tomondagi oʻzgaruvchiga yozadi:

| Qadam | Nima boʻladi | `stock` |
|---|---|---|
| 17-qatordan keyin | `stock := 40` | `40` |
| 20-qator, 1-qadam | oʻng tomon hisoblanadi: `stock - 1` = 40 − 1 = 39 | `40` |
| 20-qator, 2-qadam | 39 `stock`'ning xotirasiga yoziladi | `39` |

Bu tuzatilgan qator quriladi. Chiqish oʻzgarmaydi, chunki 20-qatordan keyin `stock` chiqarilmaydi:

```console
$ go run .
bozor ishga tushdi
versiya: 0.1.0
 0 false
olma 12000 true 40 1.5
```

Bu qatorni vazifaga qoldiramiz va hozircha oʻchiramiz.

## Son oʻrniga matn: `price = "12000"`

Endi dars boshidagi holat: narx oʻrniga matn. Qiymat boshqa joydan qoʻshtirnoq bilan koʻchirildi, 15-qator endi
shunday:

```go
	price = "12000"
```

Koʻzga son boʻlib koʻrinadi, lekin qoʻshtirnoq uni matnga aylantiradi. `price` esa 10-qatorda `int` deb eʼlon
qilingan. Bu xatoni kim ushlaydi?

**A)** dastur ishlaganda, mijoz · **B)** qurishda, kompilyator · **C)** hech kim: Go matnni songa aylantiradi

<details>
<summary>Javob</summary>

**B: kompilyator, qurish paytida.**

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:15:10: cannot use "12000" (untyped string constant) as int value in assignment
```

Xabar 15-qator, 10-ustunni, yaʼni qoʻshtirnoq boshlangan joyni koʻrsatadi. *cannot use "12000"* — «`"12000"` ni
ishlatib boʻlmaydi», *as int value in assignment* — «qiymat berishda `int` qiymat sifatida». Qavsdagi *untyped
string constant* — qoʻshtirnoqdagi matnning kompilyatordagi nomi, konstantalarni [GB-1.03](/lab/youtube/gb/gb-1-03) da
ochamiz. Asosiysi: `price`'ning turi eʼlonda `int` boʻlgan va u oʻzgarmaydi.

- **A** ni tanlagan boʻlsangiz, tur dastur ishlaganda tekshiriladi deb oʻylagansiz. Go'da turni kompilyator
  tekshiradi, dastur ishga tushishidan oldin.
- **C** ni tanlagan boʻlsangiz, Go matnni songa oʻzi aylantiradi deb oʻylagansiz. Go buni qilmaydi, `int * float64`
  dagidek.

</details>

**Tuzatish:** qoʻshtirnoqni olib tashlaymiz, 15-qator yana `price = 12000`. Bu xato hech kimga yetib bormadi, chunki
kompilyator toʻxtadi va bajariladigan fayl umuman qurilmadi. Foydalanuvchi ishlayotgan dasturga kiritgan matnni esa
kompilyator koʻrmaydi, uni [GB-1.07](/lab/youtube/gb/gb-1-07) da tekshiramiz.

Qisqasi, oʻzgaruvchining turi eʼlonda bir marta belgilanadi va kompilyator har bir qiymatni shu turga solishtiradi.

## Koʻp uchraydigan xatolar

**1. Bor oʻzgaruvchiga `:=` bilan yozish.** Eng koʻp uchraydigani, vazifada ham shu tuzoq bor. Vazifani shunday
boshlasangiz (20-qatordan keyin):

```go
	sold := 3
	stock := stock - sold
	fmt.Println(name, stock)
```

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:22:8: no new variables on left side of :=
```

22-qator, 8-ustun: `stock` 17-qatorda eʼlon qilingan, `:=` esa yangi nom talab qiladi («Oraliq savol» boʻlimi).
**Tuzatish:** `stock = stock - sold`.

**2. Eʼlon qilib, ishlatmaslik.** `sold := 3` yozib, uni hech qayerda ishlatmasangiz:

```go
	fmt.Println(name, price, active, stock, weight)

	sold := 3
}
```

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:21:2: declared and not used: sold
```

*declared and not used: sold* — «`sold` eʼlon qilingan, lekin ishlatilmagan». Bu ogohlantirish emas, xato: dastur
qurilmaydi. **Tuzatish:** oʻzgaruvchini ishlating yoki eʼlonni oʻchiring.

**3. Funksiyadan tashqarida `:=`.** `stock := 40` ni `func main()` dan oldin, fayl darajasida yozsangiz:

```go
package main

import "fmt"

stock := 40

func main() {
```

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:5:1: syntax error: non-declaration statement outside function body
```

*syntax error: non-declaration statement outside function body* — «yozuv xatosi: funksiya tanasidan tashqarida eʼlon
boʻlmagan amal». Funksiyadan tashqarida `:=` ishlamaydi. **Tuzatish:** `var stock = 40`, yoki eʼlonni `main` ichiga
oʻtkazing. (Bu misol videoda yoʻq, biz uni alohida ishga tushirdik.)

**4. Turlarni aralashtirish va qoʻshtirnoqdagi son.** `price * weight` (`int` va `float64`) va `price = "12000"` —
ikkalasi ham kompilyator xatosi. Toʻliq tahlil «Tur xatosi» va «Son oʻrniga matn» boʻlimlarida.

**5. Jim xato: qoldiqni juda erta kamaytirish.** Vazifadagi yangi qatorlarni 19-qatordan *oldin* yozsangiz, dastur
quriladi va xato bermaydi, lekin 4-qator oʻzgaradi: `olma 12000 true 37 1.5`. `go test` buni ushlaydi:

```console
$ go test
--- FAIL: TestQatorlar (0.00s)
    main_test.go:64: 4-qator «olma 12000 true 40 1.5» boʻlishi kerak, hozir «olma 12000 true 37 1.5»
FAIL
exit status 1
FAIL	github.com/abdurahmon27/bozor	0.002s
```

**Tuzatish:** yangi qatorlarni mavjud `fmt.Println(name, price, active, stock, weight)` qatoridan **keyin** yozing.
(Oxirgi ustundagi vaqt har ishga tushirishda biroz boshqacha.)

## Oʻzingizni tekshiring

Avval oʻzingiz javob bering, keyin oching.

**1.** `var stock int` bilan `stock := 40` ning farqi nima?

<details>
<summary>Javob</summary>

`var stock int` — qiymatsiz eʼlon: `stock` zero value bilan, yaʼni `0` bilan boshlanadi. `stock := 40` — `40`
qiymati bilan eʼlon qiladi, tur qiymatdan olinadi (`int`), va u faqat funksiya ichida ishlaydi.

</details>

**2.** `var active bool` dan keyin `active` nimaga teng?

<details>
<summary>Javob</summary>

`false`: bu `bool`'ning zero value'si.

</details>

**3.** Bu dastur nima chiqaradi? (Kurs papkasida yoʻq, alohida ishga tushirilgan. `+` — qoʻshish.)

```go
package main

import "fmt"

func main() {
	var stock int
	stock = stock + 10
	weight := 2.5
	var ok bool
	fmt.Println(stock, weight, ok)
}
```

**A)** kompilyator xatosi · **B)** `10 2.5 false` · **C)** `0 2.5 false`

<details>
<summary>Javob</summary>

**B.** `stock` zero value `0` bilan boshlanadi, keyin `0 + 10` hisoblanib, `10` yoziladi. `weight` — `float64`,
`ok` — `false`.

```console
$ go run .
10 2.5 false
```

**A** ni tanlagan boʻlsangiz, qiymatsiz oʻzgaruvchini oʻqib boʻlmaydi deb oʻylagansiz. **C** ni tanlagan boʻlsangiz,
`=` qatorini hisobga olmagansiz.

</details>

**4.** `price` butun son bilan eʼlon qilingan, keyin unga `1.5` yozilyapti. Nima boʻladi? (Kurs papkasida yoʻq,
alohida ishga tushirilgan.)

```go
package main

import "fmt"

func main() {
	price := 12000
	price = 1.5
	fmt.Println(price)
}
```

<details>
<summary>Javob</summary>

Kompilyator xatosi: `price`'ning turi `:=` da `12000` dan olingan, yaʼni `int`, va u oʻzgarmaydi.

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:7:10: cannot use 1.5 (untyped float constant) as int value in assignment (truncated)
```

*truncated* — «kesib tashlangan»: `1.5` `int`'ga sigʻishi uchun kasr qismini yoʻqotishi kerak edi, Go bunga yoʻl
qoʻymaydi.

</details>

**5.** Oldingi darsdan: `go build` nima yaratadi?

<details>
<summary>Javob</summary>

Bitta bajariladigan fayl. U xuddi shu operatsion tizim va protsessor turidagi, Go oʻrnatilmagan kompyuterda ham
ishlaydi.

</details>

- 🟢 **Oson · sotuvdan keyin qoldiq.** Bugun bozorda 3 qadoq olma sotildi. `main.go`'ning oxiriga (19-qatordan keyin,
  yopuvchi `}` dan oldin): `sold` degan oʻzgaruvchini qisqa shakl bilan `3` qiymati bilan eʼlon qiling; `stock`'ni
  `sold` qadar kamaytiring (`stock` allaqachon bor); mahsulot nomi va yangi qoldiqni bitta `fmt.Println` bilan
  chiqaring. Dastur aynan shu besh qatorni chiqarishi kerak:

```text

 0 false
olma 12000 true 40 1.5
```

Tekshiruv — papkadagi `go test` buyrugʻi. U `main_test.go` faylini ishga tushiradi. Bu faylni oʻzgartirmang, uning
ichini [GB-1.08](/lab/youtube/gb/gb-1-08) da ochamiz. Boshlangʻich holatda test yiqiladi va nima kutilayotganini aytadi:

```console
$ go test
--- FAIL: TestQatorlar (0.00s)
    main_test.go:59: 5-qator «olma 37» boʻlishi kerak, hozir dastur faqat 4 qator chiqaryapti (TASK.md)
--- FAIL: TestSold (0.00s)
    main_test.go:105: main.go'da «sold := 3» kabi eʼlon yoʻq: sotilgan qadoqlar soni uchun sold degan oʻzgaruvchi kerak
    main_test.go:108: stock'ning yangi qiymati sold'dan hisoblanib, bor oʻzgaruvchiga yozilishi kerak (:= emas: stock allaqachon bor)
FAIL
exit status 1
FAIL	github.com/abdurahmon27/bozor	0.003s
```

Test uchta narsani tekshiradi: chiqishdagi besh qator, `sold := …` eʼloni va `stock`'ning yangi qiymati `sold`'dan
`=` bilan hisoblangani. Fayl `go fmt` formatida boʻlishi ham tekshiriladi.

<details>
<summary>Javob</summary>

```go filename="solution/main.go" showLineNumbers
package main

import "fmt"

func main() {
	fmt.Println("bozor ishga tushdi")
	fmt.Println("versiya: 0.1.0")

	var name string
	var price int
	var active bool
	fmt.Println(name, price, active)

	name = "olma"
	price = 12000
	active = true
	stock := 40
	weight := 1.5
	fmt.Println(name, price, active, stock, weight)

	sold := 3
	stock = stock - sold
	fmt.Println(name, stock)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 21 | `sold := 3` | yangi oʻzgaruvchi, qisqa eʼlon, turi `int` |
| 22 | `stock = stock - sold` | bor `stock`'ga yozish: avval `40 - 3` = `37`, keyin `37` yoziladi. `:=` emas |
| 23 | `fmt.Println(name, stock)` | `olma 37`; `sold` ham shu bilan ishlatilgan boʻladi (22-qatorda) |

Uchala qator 19-qatordan keyin turgani uchun 4-qator `40` bilan qoladi. `stock -= sold` yozuvi ham bor: bu
`stock = stock - sold` ning qisqa shakli, test uni ham qabul qiladi.

Javobni tekshirish: `go test ./solution` (papkaning oʻzidan), yoki `solution/main.go`'ni papkadagi `main.go` oʻrniga
qoʻyib, `go test`:

```console
$ go test
PASS
ok  	github.com/abdurahmon27/bozor	0.002s
```

</details>
