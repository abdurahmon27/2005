## Nimani oʻrganasiz

bozorga yangi mahsulot qoʻshadigan `POST /products` soʻrovining body'sini mijoz yozadi. U juda katta body yuborishi, ortiqcha kalit qoʻshishi yoki narxga minus besh yozishi mumkin.
Savol: server bu uch holatning har biriga qanday aniq va bir xil shakldagi javob beradi?

**Bitta gʻoya:** `POST` body'ni mijoz yozadi, shuning uchun u ishonib boʻlmaydigan kirish. Handler uni **qatʼiy** oʻqiydi: `http.MaxBytesReader` hajmni cheklaydi (`413`), `DisallowUnknownFields` ortiqcha kalitni rad etadi (`400`).
Oʻqilgandan keyin **qiymatlarni** tekshiradi (`422` va `fields`), va har xato bitta JSON shaklida qaytadi: `{"error": {"code", "message", "fields"}}`.
`400` — body bizning shaklga mos emas; `422` — shakl toʻgʻri, qiymat qoidaga zid.

Dars oxirida siz:

- hamma xatoni bitta JSON shaklida qaytaradigan `writeError` yozasiz;
- body hajmini `http.MaxBytesReader` bilan cheklaysiz va limit oshganini `errors.As` bilan ajratib, `413` qaytarasiz;
- ortiqcha kalitni `DisallowUnknownFields` bilan rad etasiz va `400` bilan `422` oʻrtasidagi chegarani tushuntirasiz;
- `POST /orders` uchun `validateOrder` va `createOrder`ni yozib, `go test .` ni oʻtkazasiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| xato shakli | hamma xato javobi bitta tuzilmada: `error` ichida `code`, `message`, `fields` | error response shape |
| qatʼiy oʻqish | body'ni hajm limiti va ortiqcha kalit taqiqi bilan oʻqish: `http.MaxBytesReader`, `DisallowUnknownFields` | strict decoding |
| validatsiya | body oʻqilgandan keyin qiymatlarni qoidaga solishtirish: `400` — shakl, `422` — qiymat | validation |

Yordamchi: `201 Created` (yangi resurs yaratildi) va `return` unutilishi (xatolar boʻlimida). Boshqa yangi nomlarning hammasiga yoʻlda bitta jumla beraman.

## Xato javobi uchun bitta shakl

Mijoz kodi avval statusga qaraydi, keyin xato nimaligini JSON'dan oʻqiydi. Har endpoint xatoni oʻz shaklida qaytarsa, mijoz har endpoint uchun alohida kod yozadi. Shuning uchun hamma xato bitta shaklda:

```text
{"error": {
  "code": "validation_failed",
  "message": "qiymatlar notoʻgʻri",
  "fields": {"price": "0 dan katta boʻlsin"}
}}
```

| Kalit | Kim oʻqiydi | Nima |
|---|---|---|
| `error` | mijoz kodi | tashqi kalit: bu javob xato ekanini koʻrsatadi |
| `code` | mashina | qisqa, oʻzgarmas nom: `bad_json`, `too_large`, `validation_failed` |
| `message` | odam | oʻqiladigan matn |
| `fields` | mijoz formasi | qaysi maydon nega notoʻgʻri: kalit — maydon nomi, qiymat — sabab. Faqat validatsiya xatosida bor |

Go'da bu shakl — **struct**. Nomi `apiError`, nomni biz tanladik:

```go
type apiError struct {
	Code    string            `json:"code"`
	Message string            `json:"message"`
	Fields  map[string]string `json:"fields,omitempty"`
}
```

Bu bir nechta qator, raqamlar bu boʻlakning oʻzidagi qator raqami:

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1 | `type apiError struct {` | yangi tur eʼloni: `struct` — nomli maydonlar toʻplami ([GB-2.03](/lab/youtube/gb/gb-2-03)) |
| 2–3 | `Code string`, `Message string` | ikki matn maydoni. Backtick ichidagi `json:"code"` — tag: JSON'dagi kalit nomi `code` ([GB-3.02](/lab/youtube/gb/gb-3-02)) |
| 4 | `Fields map[string]string` | `map`: kalit — maydon nomi, qiymat — sabab ([GB-2.02](/lab/youtube/gb/gb-2-02)). Tagdagi `omitempty`: map boʻsh boʻlsa, `fields` kaliti umuman yozilmaydi |

Javobni yozish bir joyda — `writeJSON`. Tartib [GB-4.03](/lab/youtube/gb/gb-4-03)dagidek: header, keyin status, keyin body:

```go
func writeJSON(w http.ResponseWriter, status int, v any) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status)
	json.NewEncoder(w).Encode(v)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1 | `func writeJSON(w http.ResponseWriter, status int, v any) {` | status endi parametr: har chaqiruvchi oʻzi tanlaydi. `v any` — istalgan qiymat ([GB-2.07](/lab/youtube/gb/gb-2-07)) |
| 2 | `w.Header().Set("Content-Type", "application/json")` | 1: header — body JSON ekanini aytadi |
| 3 | `w.WriteHeader(status)` | 2: status |
| 4 | `json.NewEncoder(w).Encode(v)` | 3: `v`ni JSON qilib `w`ga yozadi. `Encode` qaytaradigan xatoni bu darsda tekshirmaymiz: log'ga yozishni [GB-8.02](/lab/youtube/gb#gb-8-02)da koʻramiz |

Xatoni shu shaklga `writeError` oʻraydi:

```go
func writeError(w http.ResponseWriter, status int, e apiError) {
	writeJSON(w, status, map[string]apiError{"error": e})
}
```

`map[string]apiError{"error": e}` — bitta kalitli map: kalit `error`, qiymat `e`. `Encode` uni `{"error": {...}}` qiladi. Endi hamma xato shu funksiyadan chiqadi.

## POST /products: birinchi handler

Mijoz beradigan maydonlar alohida structda: `productInput`. `Product`dan farqi — `ID` yoʻq: uni server beradi, mijoz emas.

```go
type productInput struct {
	Name  string `json:"name"`
	Price int64  `json:"price"`
	Stock int    `json:"stock"`
}
```

Handler:

```go
func createProduct(w http.ResponseWriter, r *http.Request) {
	var in productInput
	if err := json.NewDecoder(r.Body).Decode(&in); err != nil {
		writeError(w, http.StatusBadRequest, apiError{Code: "bad_json", Message: err.Error()})
		return
	}
	writeJSON(w, http.StatusCreated, addProduct(in))
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1 | `func createProduct(w http.ResponseWriter, r *http.Request) {` | handler ([GB-4.03](/lab/youtube/gb/gb-4-03)) |
| 2 | `var in productInput` | boʻsh `productInput`; oʻzgaruvchi nomi `in` |
| 3 | `if err := json.NewDecoder(r.Body).Decode(&in); err != nil {` | body'ni oʻqib, `in`ga joylaydi ([GB-4.02](/lab/youtube/gb/gb-4-02)). Xato boʻlsa — blok ishlaydi |
| 4 | `writeError(w, http.StatusBadRequest, apiError{...})` | `400` (`http.StatusBadRequest`), `code` — `bad_json` (bu nomni biz tanladik), `message` — `err.Error()`, ya'ni xatoning matni |
| 5 | `return` | javob yozib boʻlindi: funksiyadan chiqamiz |
| 7 | `writeJSON(w, http.StatusCreated, addProduct(in))` | hammasi joyida boʻlsa: `201` va yaratilgan mahsulot |

`201 Created` ([RFC 9110 §15.3.2](https://www.rfc-editor.org/rfc/rfc9110#name-201-created)) — yangi resurs, ya'ni yangi mahsulot, yaratildi; body'da u, serverning bergan `ID`si bilan. `addProduct` mahsulotni katalogga qoʻshadi; ichini bugun koʻrsatmayman. U bir vaqtda ikki soʻrov kelsa xavfsiz emas: buni [GB-4.07](/lab/youtube/gb#gb-4-07)da `-race` bilan koʻramiz.

Soʻrovlarni serversiz yuboradigan `send` ([GB-4.03](/lab/youtube/gb/gb-4-03)dagi qadamlar bitta funksiyada):

```go
func send(h http.Handler, method, path, body string) {
	req := httptest.NewRequest(method, path, strings.NewReader(body))
	rec := httptest.NewRecorder()
	h.ServeHTTP(rec, req)
	fmt.Printf("%d %s", rec.Code, rec.Body.String())
}
```

`h http.Handler` — mux ham handler ([GB-2.07](/lab/youtube/gb/gb-2-07)). `strings.NewReader(body)` body matnini soʻrovga ulaydi. Qolgan uch qator — [GB-4.03](/lab/youtube/gb/gb-4-03)dagidek: recorder, `ServeHTTP`, status va body'ni chiqarish.
Mana butun dastur; ikki soʻrov `main`da:

```go filename="_video/01-oddiy/main.go" showLineNumbers
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/http/httptest"
	"strings"
)

// Product — katalogdagi bitta mahsulot (GB-3.02).
type Product struct {
	ID    int64  `json:"id"`
	Name  string `json:"name"`
	Price int64  `json:"price"` // tiyin
	Stock int    `json:"stock"`
}

var catalog = []Product{
	{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40},
	{ID: 2, Name: "non", Price: 400_000, Stock: 120},
	{ID: 3, Name: "oʻrik", Price: 3_500_000, Stock: 5},
}

type productInput struct {
	Name  string `json:"name"`
	Price int64  `json:"price"`
	Stock int    `json:"stock"`
}

type apiError struct {
	Code    string            `json:"code"`
	Message string            `json:"message"`
	Fields  map[string]string `json:"fields,omitempty"`
}

func writeJSON(w http.ResponseWriter, status int, v any) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status)
	json.NewEncoder(w).Encode(v)
}

func writeError(w http.ResponseWriter, status int, e apiError) {
	writeJSON(w, status, map[string]apiError{"error": e})
}

func addProduct(in productInput) Product {
	var last int64
	for _, p := range catalog {
		last = max(last, p.ID)
	}
	p := Product{ID: last + 1, Name: in.Name, Price: in.Price, Stock: in.Stock}
	catalog = append(catalog, p)
	return p
}

func createProduct(w http.ResponseWriter, r *http.Request) {
	var in productInput
	if err := json.NewDecoder(r.Body).Decode(&in); err != nil {
		writeError(w, http.StatusBadRequest, apiError{Code: "bad_json", Message: err.Error()})
		return
	}
	writeJSON(w, http.StatusCreated, addProduct(in))
}

func newMux() *http.ServeMux {
	mux := http.NewServeMux()
	mux.HandleFunc("POST /products", createProduct)
	return mux
}

func send(h http.Handler, method, path, body string) {
	req := httptest.NewRequest(method, path, strings.NewReader(body))
	rec := httptest.NewRecorder()
	h.ServeHTTP(rec, req)
	fmt.Printf("%d %s", rec.Code, rec.Body.String())
}

func main() {
	mux := newMux()
	send(mux, http.MethodPost, "/products", `{"name":"choy","price":2500000,"stock":30}`)
	send(mux, http.MethodPost, "/products", `{"name":`)
}
```

| Qator | Nima |
|---|---|
| 3–9 | importlar: yangi paketlar yoʻq, hammasi oldingi darslardan |
| 11–23 | `Product` va `catalog` ([GB-3.02](/lab/youtube/gb/gb-3-02)): katalogda 3 mahsulot, shuning uchun yangisining `ID`si 4 boʻladi |
| 25–45 | `productInput`, `apiError`, `writeJSON`, `writeError`: yuqorida tushuntirilgan |
| 47–55 | `addProduct`: katalogga qoʻshadi, `ID` = eng katta `ID` + 1 (bugun ichi kerak emas) |
| 57–64 | `createProduct`: yuqorida |
| 66–70 | `newMux`: route'larni yigʻadi; `POST /products` `createProduct`ga ulangan ([GB-4.04](/lab/youtube/gb/gb-4-04), [GB-4.05](/lab/youtube/gb#gb-4-05)) |
| 72–77 | `send`: yuqorida |
| 79–83 | `main`: birinchi soʻrov — toʻgʻri body, ikkinchisi — buzuq JSON: oxiri yoʻq (`{"name":`) |

Bashorat: `go run .` nima chiqaradi?

**A)** `201`, `201` · **B)** `201`, `400` · **C)** `400`, `400`

<details>
<summary>Javob</summary>

**B.** Birinchi body toʻliq va toʻgʻri: `201`, yangi mahsulot. Ikkinchi body `"name":` dan keyin tugaydi — JSON kutilmaganda uzildi, `Decode` xato qaytaradi, handler `400` yozadi. **A** da buzuq JSON ham qabul qilinadi deb oʻyladingiz; **C** da toʻgʻri body ham xato deb hisobladingiz.

</details>

```console
$ ./_video/run.sh 01-oddiy go run .

400 {"error":{"code":"bad_json","message":"unexpected EOF"}}
(chiqish kodi: 0)
```

Birinchi qator: `201`, katalogdagi toʻrtinchi mahsulot, `"id":4` — uni server berdi. Ikkinchi qator: `400` va `unexpected EOF` (EOF — end of file, "kirish tugadi"): JSON kutilmaganda tugadi. `fields` kaliti yoʻq: `omitempty` ishladi.

| Soʻrov | Body | `Decode` | Javob |
|---|---|---|---|
| 1 | `{"name":"choy","price":2500000,"stock":30}` | muvaffaqiyatli | `201` + mahsulot |
| 2 | `{"name":` | `unexpected EOF` | `400` + `bad_json` |

## Ortiqcha kalit jimgina tashlanadi

Endi body toʻgʻri, lekin unda `productInput`da yoʻq kalit bor: `rang` kaliti, qiymati `qora`:

```text
{"name":"choy","price":2500000,"rang":"qora"}
```

Bashorat: hozirgi kod bilan status nima boʻladi?

**A)** `201` · **B)** `400` · **C)** `422`

<details>
<summary>Javob</summary>

**A.** Standart `Decode` struct'da yoʻq kalitni jimgina tashlaydi ([`json.Unmarshal` hujjati](https://pkg.go.dev/encoding/json#Unmarshal)). Xato yoʻq, demak `201`. **B** va **C** xato boʻladi deb oʻyladi, lekin xato aynan shu yerda yoʻq: shu muammo.

</details>

```console
$ ./_video/run.sh 01b-rang go run .
201 {"id":4,"name":"choy","price":2500000,"stock":0}
(chiqish kodi: 0)
```

`201`, lekin `"stock":0`: soʻrovda `stock` yoʻq edi, `rang` esa yoʻqoldi. Mijoz `rang` saqlandi deb oʻylaydi, server esa uni hech qachon koʻrmadi. Kalit nomini xato yozgan mijoz buni hech qachon bilmay qoladi.

Tuzatish: `Decoder`ni alohida oʻzgaruvchiga olamiz (`dec`) va `DisallowUnknownFields()` chaqiramiz. Shundan keyin struct'da yoʻq kalit uchun `Decode` xato qaytaradi. `Decode` endi `dec`dan chaqiriladi:

```go
func createProduct(w http.ResponseWriter, r *http.Request) {
	var in productInput
	dec := json.NewDecoder(r.Body)
	dec.DisallowUnknownFields()
	if err := dec.Decode(&in); err != nil {
		writeError(w, http.StatusBadRequest, apiError{Code: "bad_json", Message: err.Error()})
		return
	}
	writeJSON(w, http.StatusCreated, addProduct(in))
}
```

| Qator | Nima oʻzgardi |
|---|---|
| 3 | `dec := json.NewDecoder(r.Body)`: decoder endi oʻzgaruvchida |
| 4 | `dec.DisallowUnknownFields()`: ortiqcha kalit — xato ([hujjat](https://pkg.go.dev/encoding/json#Decoder.DisallowUnknownFields)) |
| 5 | `dec.Decode(&in)`: avvalgidek, faqat `dec`dan |

```console

(chiqish kodi: 0)
```

`400`, `message` ichida kalit nomi bor: `json: unknown field "rang"`. Mijoz nimani tuzatishni biladi. Ichkaridagi `\"` — JSON'ning oʻzidagi qoʻshtirnoq belgisi: `message` matni ichida `"` shunday yoziladi.

Shu yerda `400`ning kursdagi maʼnosi aniq: **body bizning shaklga mos kelmaydi**. Uch holat:

| Holat | Misol | Javob |
|---|---|---|
| JSON buzuq | `{"name":` | `400`, `unexpected EOF` |
| kalit ortiqcha | `"rang":"qora"` | `400`, `unknown field "rang"` |
| tur boshqa | `name` oʻrniga son | `400` (xabar matni: Chuqurroq boʻlimda) |

`ID`ni mijoz yuborsa ham `400`: `productInput`da `id` yoʻq, demak u ham ortiqcha kalit (bu holat `handler_test.go`da tekshiriladi, quyida). Bu kursning kelishuvi, RFC buyrugʻi emas: bir xil qoidani hamma endpoint'da qoʻllaymiz.

## Hajm limiti: http.MaxBytesReader

Endi hajm. `Decode` bitta JSON qiymatni toʻliq xotiraga oʻqiydi. Mijoz juda katta qiymat yuborsa, server hammasini saqlaydi. Limit yoʻq boʻlsa, bitta soʻrov serverning xotirasini egallashi mumkin.
Go buning uchun `http.MaxBytesReader` beradi: u body'ni oʻraydi va belgilangan baytdan keyin xato qaytaradi ([hujjat](https://pkg.go.dev/net/http#MaxBytesReader)).

```text
limit yoʻq:        body ──► Decode ──► qiymat toʻliq xotirada (hajm cheklanmagan)

MaxBytesReader:    body ──► MaxBytesReader(1024) ──► Decode
                            1024 baytdan keyin o'qish xatosi ──► Decode xato qaytaradi
```

Handler'ga bir qator qoʻshamiz: `r.Body`ni oʻralgan body bilan almashtiramiz.

```go
r.Body = http.MaxBytesReader(w, r.Body, 1024)
```

## decodeJSON: uch qadam bitta funksiyada

Limit, qatʼiy oʻqish va xato javobi — har `POST` handler'ga kerak. Ularni `decodeJSON` funksiyasiga ajratamiz:

```go
func decodeJSON(w http.ResponseWriter, r *http.Request, dst any) bool {
	r.Body = http.MaxBytesReader(w, r.Body, 1024)
	dec := json.NewDecoder(r.Body)
	dec.DisallowUnknownFields()
	if err := dec.Decode(dst); err != nil {
		writeDecodeError(w, err)
		return false
	}
	return true
}

func writeDecodeError(w http.ResponseWriter, err error) {
	var tooBig *http.MaxBytesError
	if errors.As(err, &tooBig) {
		writeError(w, http.StatusRequestEntityTooLarge, apiError{Code: "too_large", Message: fmt.Sprintf("body %d baytdan oshmasin", tooBig.Limit)})
		return
	}
	writeError(w, http.StatusBadRequest, apiError{Code: "bad_json", Message: err.Error()})
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1 | `func decodeJSON(w http.ResponseWriter, r *http.Request, dst any) bool {` | `dst any` — qaysi struct'ga oʻqishni chaqiruvchi beradi (`&in`). Natija `bool`: `true` — body oʻqildi, `false` — xato, javob allaqachon yozilgan |
| 2–4 | `MaxBytesReader`, `NewDecoder`, `DisallowUnknownFields` | limit va qatʼiy oʻqish: yuqoridagi uch qator |
| 5–8 | `if err := dec.Decode(dst); err != nil { writeDecodeError(w, err); return false }` | xato boʻlsa javobni `writeDecodeError` yozadi, `false` qaytadi |
| 9 | `return true` | xato yoʻq: body `dst`ga oʻqildi |
| 12–19 | `writeDecodeError` | oldingi `MaxBytesError` tekshiruvi: `413` yoki `400` |

Chaqiruvchi `false` koʻrsa, hech narsa yozmay `return` qiladi — javob tayyor:

```go
func createProduct(w http.ResponseWriter, r *http.Request) {
	var in productInput
	if !decodeJSON(w, r, &in) {
		return
	}
	writeJSON(w, http.StatusCreated, addProduct(in))
}
```

**Bitta tuzoq.** `Decode` faqat **birinchi** JSON qiymatni oʻqiydi; undan keyingi baytlarni oʻqimaydi, demak limitga ham tegmaydi. `{"name":"non","price":400000}{"x":1}` body'ida ikkinchi qiymat jimgina tashlanardi (bu holat Chuqurroq boʻlimda).
Shuning uchun `decodeJSON`ga yana bir `Decode` qoʻshamiz — boʻsh struct'ga. Papkadagi `main.go`da `decodeJSON` shunday:

```go
func decodeJSON(w http.ResponseWriter, r *http.Request, dst any) bool {
	r.Body = http.MaxBytesReader(w, r.Body, 1024)
	dec := json.NewDecoder(r.Body)
	dec.DisallowUnknownFields()
	if err := dec.Decode(dst); err != nil {
		writeDecodeError(w, err)
		return false
	}
	// Decode faqat birinchi JSON qiymatni oʻqiydi: undan keyin hech narsa boʻlmasligi kerak (limit ham shunga tegadi).
	if err := dec.Decode(&struct{}{}); err != io.EOF {
		if err == nil {
			err = errors.New("body'da bitta JSON boʻlishi kerak")
		}
		writeDecodeError(w, err)
		return false
	}
	return true
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 10 | `if err := dec.Decode(&struct{}{}); err != io.EOF {` | yana bir `Decode`, boʻsh struct'ga. `io.EOF` — "kirish tugadi": body'da ortiqcha narsa yoʻq degani. `io.EOF` **boʻlmasa**, body'da yana nimadir bor |
| 11–13 | `if err == nil { err = errors.New(...) }` | `nil` boʻlsa, ikkinchi qiymat bor edi: xabarni oʻzimiz yozamiz |
| 14 | `writeDecodeError(w, err)` | boshqa xato boʻlsa — oʻqish xatosi, masalan limit: `413` yoki `400` |

## Qiymatlarni tekshirish: 400 va 422

Body oʻqildi, shakl toʻgʻri. Lekin qiymat notoʻgʻri boʻlishi mumkin: `name` boʻsh, narx minus besh. Bunday body JSON sifatida mukammal, `400` esa oʻqib boʻlmagan body uchun. Bunga `422`: soʻrov tushunarli, lekin mazmunini qayta ishlab boʻlmaydi ([RFC 9110 §15.5.21](https://www.rfc-editor.org/rfc/rfc9110#name-422-unprocessable-content)).
Qaysi maydonlar notoʻgʻri ekanini `fields`da qaytaramiz.

| | `400` | `422` |
|---|---|---|
| Savol | body shaklga mosmi? | qiymat qoidaga mosmi? |
| Misol | buzuq JSON, ortiqcha kalit, tur boshqa | `{"name":"","price":-5}` |
| `fields` | yoʻq | bor: maydon → sabab |

RFC "shakl yoki qiymat" boʻlinishini oʻzi belgilamaydi: bu kursning kelishuvi (baʼzi API'lar hamma holatda `400` beradi). Muhimi — butun API'da bir xil.

`validate` `productInput`ni oladi va jadval qaytaradi: kalit — maydon nomi, qiymat — sabab. Papkadagi toʻliq shakli:

```go
func validate(in productInput) map[string]string {
	f := map[string]string{}
	if in.Name == "" {
		f["name"] = "boʻsh boʻlmasin"
	}
	if in.Price <= 0 {
		f["price"] = "0 dan katta boʻlsin"
	}
	if in.Stock < 0 {
		f["stock"] = "manfiy boʻlmasin"
	}
	return f
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 2 | `f := map[string]string{}` | boʻsh jadval ([GB-2.02](/lab/youtube/gb/gb-2-02)) |
| 3–5 | `if in.Name == "" { f["name"] = "..." }` | nom boʻsh boʻlsa, `name` kalitiga sabab yoziladi |
| 6–8 | `if in.Price <= 0 { f["price"] = "..." }` | narx noldan katta boʻlishi kerak; aks holda `price` |
| 9–11 | `if in.Stock < 0 { f["stock"] = "..." }` | uchinchi qoida: qoldiq manfiy boʻlmasin |
| 12 | `return f` | boʻsh jadval — hammasi joyida |

Funksiya birinchi xatoda toʻxtamaydi: hamma notoʻgʻri maydon bir javobda qaytadi. Handler'da `decodeJSON`dan keyin:

```go
	if f := validate(in); len(f) > 0 {
		writeError(w, http.StatusUnprocessableEntity, apiError{Code: "validation_failed", Message: "qiymatlar notoʻgʻri", Fields: f})
		return
	}
```

`validate(in)` chaqiriladi, `len(f) > 0` jadval boʻsh emasligini tekshiradi ([GB-2.02](/lab/youtube/gb/gb-2-02)). Boʻsh boʻlmasa: `422` (Go'dagi nomi `http.StatusUnprocessableEntity`), `code` — `validation_failed`, `Fields` — oʻsha jadval; keyin `return`.

Bashorat: body `{"name":"","price":-5}` — `name` boʻsh, `price` minus besh, `stock` umuman yoʻq. `fields`da nechta kalit boʻladi?

**A)** bitta: `name` · **B)** ikkita: `name` va `price` · **C)** uchta: `stock` ham

<details>
<summary>Javob</summary>

**B.** `validate` birinchi xatoda toʻxtamaydi: `name` ham, `price` ham jadvalga tushadi (**A** da birinchi xatoda toʻxtaydi deb oʻyladingiz). `stock` berilmagan, ya'ni **nol qiymat** (`0`) ([Go spec](https://go.dev/ref/spec#The_zero_value)), nol esa toʻgʻri qoldiq: `stock < 0` emas (**C** da berilmagan maydonni xato deb hisobladingiz).

</details>

## Koʻp uchraydigan xatolar

### 1. `writeError`dan keyin `return` yozilmagan

`writeError` javobni yozadi, lekin funksiyani **toʻxtatmaydi**. Kod pastga davom etadi. Mana `return`siz handler:

```go
func createProduct(w http.ResponseWriter, r *http.Request) {
	var in productInput
	if !decodeJSON(w, r, &in) {
		return
	}
	if f := validate(in); len(f) > 0 {
		writeError(w, http.StatusUnprocessableEntity, apiError{Code: "validation_failed", Message: "qiymatlar notoʻgʻri", Fields: f})
	}
	writeJSON(w, http.StatusCreated, addProduct(in))
}
```

Bashorat: body `{"name":"","price":-5}`. Status nima boʻladi va katalogga yangi mahsulot qoʻshiladimi?

**A)** `422`, katalog oʻzgarmaydi · **B)** `422`, mahsulot qoʻshildi · **C)** `201`

<details>
<summary>Javob</summary>

**B.** Status `422`: birinchi `WriteHeader` hisobga olinadi ([GB-4.03](/lab/youtube/gb/gb-4-03)). Lekin `return` yoʻq, shuning uchun keyingi `writeJSON(w, http.StatusCreated, addProduct(in))` ham ishlaydi: mahsulot qoʻshiladi, body'ga ikkinchi JSON yoziladi. **A** da xato `return` qiladi deb oʻyladingiz; **C** da ikkinchi `WriteHeader(201)` statusni oʻzgartiradi deb oʻyladingiz, lekin u eʼtiborga olinmaydi.

</details>

Qadam `main`ning oxirida `fmt.Println(len(catalog), "mahsulot")` ni ham chiqaradi:

```console
$ ./_video/run.sh 08-return go run .
422 {"error":{"code":"validation_failed","message":"qiymatlar notoʻgʻri","fields":{"name":"boʻsh boʻlmasin","price":"0 dan katta boʻlsin"}}}
{"id":4,"name":"","price":-5,"stock":0}
4 mahsulot
(chiqish kodi: 0)
```

Birinchi qator — `422` va xato JSON. Ikkinchi qator — **ikkinchi** JSON: `{"id":4,"name":"","price":-5,"stock":0}`, boʻsh nomli mahsulot. Oxirgi qator: katalog 3 dan 4 ga oʻsdi. Xato yoʻq, kompilyator ham jim, ammo notoʻgʻri mahsulot saqlandi.
Haqiqiy serverda log'da yana bir qator chiqadi: `http: superfluous response.WriteHeader call` (README; `httptest.NewRecorder` log yozmaydi, shuning uchun bu yerda koʻrinmaydi). Tuzatish: `writeError`dan keyin `return`. `decodeJSON` bu xatodan himoya qilmaydi: u faqat oʻz ichidagi `return false` ni kafolatlaydi.

### 2. `errors.As`ga nishonning oʻzini berish, manzilini emas

[GB-2.08](/lab/youtube/gb/gb-2-08)da: `errors.As`ning ikkinchi argumenti — nishonning **manzili** (`&tooBig`). `tooBig`ning oʻzini bersangiz, kompilyator jim, lekin `go vet` ushlaydi. Bu dastur kurs papkasida yoʻq: bu mustaqil sinov (boʻsh papkada `go mod init scratch` qiling va quyidagini `main.go`ga yozing):

```go
package main

import (
	"errors"
	"fmt"
	"net/http"
)

func main() {
	var err error = &http.MaxBytesError{Limit: 1024}
	var tooBig *http.MaxBytesError
	fmt.Println(errors.As(err, tooBig))
}
```

```console
$ go vet .
main.go:12:14: second argument to errors.As must be a non-nil pointer to either a type that implements error, or to any interface type
```

`go vet` fayl, qator va ustunni koʻrsatadi (`main.go:12:14`) va aytadi: ikkinchi argument `error`ni bajaradigan turga **koʻrsatkich** boʻlishi kerak. `go run .` esa ishga tushganda `panic: errors: target must be a non-nil pointer` bilan toʻxtaydi. Tuzatish: `errors.As(err, &tooBig)`.

### 3. Jimgina qabul qilinadigan ortiqcha kalit

`DisallowUnknownFields`siz `rang` kabi kalit xatosiz tashlanadi va javob `201`. Boʻlim: «Ortiqcha kalit jimgina tashlanadi». Tuzatish: `dec.DisallowUnknownFields()`.

### 4. Faqat birinchi qiymat oʻqiladi

Bitta `Decode` body'dagi ikkinchi qiymatni oʻqimaydi va uning hajmini ham tekshirmaydi. Boʻlim: «decodeJSON: uch qadam bitta funksiyada». Tuzatish: ikkinchi `Decode` va `io.EOF` tekshiruvi.

## Oʻzingizni tekshiring

**1.** `400` va `422` oʻrtasidagi farq nima?

<details>
<summary>Javob</summary>

`400` — body bizning shaklga mos emas: JSON buzuq, kalit ortiqcha yoki tur boshqa; body oʻqib boʻlmadi. `422` — shakl toʻgʻri, JSON oʻqildi, lekin qiymat qoidaga zid (narx minus besh); javobda `fields`. Bu kursning kelishuvi.

</details>

**2.** `http.MaxBytesReader` nega kerak va limit oshsa qaysi status qaytadi?

<details>
<summary>Javob</summary>

`Decode` bitta qiymatni toʻliq xotiraga oʻqiydi; limit boʻlmasa, mijoz cheksiz katta body yuborishi mumkin. `MaxBytesReader` body'ni oʻraydi va limitdan keyin `*http.MaxBytesError` qaytaradi; `errors.As` bilan uni ajratib, `413` yozamiz.

</details>

**3.** ([GB-4.03](/lab/youtube/gb/gb-4-03)dan.) Handler body yozgandan **keyin** `w.WriteHeader(http.StatusNotFound)` chaqirsa, mijoz qaysi statusni koʻradi?

<details>
<summary>Javob</summary>

`200`. Birinchi `Write` statusni (hali belgilanmagan boʻlsa, `200`) va header'larni joʻnatib boʻladi; keyingi `WriteHeader` eʼtiborga olinmaydi. Xuddi shu qoida `return`siz handler'da `422`ni saqlab qoldi.

</details>

**4.** Bashorat: body `{"name":"choy","price":2500000,"stock":-1}`. Javob qanday?

<details>
<summary>Javob</summary>

Shakl toʻgʻri, `name` va `price` joyida, faqat `stock` manfiy: `422`, `fields`da bitta kalit — `stock`. Qadam `07-stock`:

```go
func validateOrder(in orderInput) map[string]string {
	f := map[string]string{}
	if in.ProductID <= 0 {
		f["product_id"] = "0 dan katta boʻlsin"
	}
	if in.Quantity < 1 || in.Quantity > 100 {
		f["quantity"] = "1 dan 100 gacha boʻlsin"
	}
	return f
}
```

```go
func createOrder(w http.ResponseWriter, r *http.Request) {
	var in orderInput
	if !decodeJSON(w, r, &in) {
		return
	}
	if f := validateOrder(in); len(f) > 0 {
		writeError(w, http.StatusUnprocessableEntity, apiError{Code: "validation_failed", Message: "qiymatlar notoʻgʻri", Fields: f})
		return
	}
	for _, p := range catalog {
		if p.ID == in.ProductID {
			writeJSON(w, http.StatusCreated, Order{ProductID: p.ID, Quantity: in.Quantity, Total: p.Price * int64(in.Quantity)})
			return
		}
	}
	writeError(w, http.StatusNotFound, apiError{Code: "not_found", Message: "mahsulot topilmadi"})
}
```
