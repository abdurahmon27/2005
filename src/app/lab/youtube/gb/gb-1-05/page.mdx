## Nimani oʻrganasiz

Bozorga miqdor oʻrniga −3 kelsa, dastur indamay ishlaydi: ombordagi choy 40 dan 43 ga koʻpayadi, chekdagi QQS esa
`-719.-64` boʻlib chiqadi. Kompilyator hech narsa demaydi, chunki −3 ham toʻgʻri `int`. Qaysi qiymat maʼnoli ekanini
u bilmaydi. Notoʻgʻri buyurtmani chek chiqmasdan va ombordan ayirilmasdan oldin qanday toʻxtatasiz?

**Bitta gʻoya:** taqqoslash `true` yoki `false` qiymat beradi. `if` va `switch` shu qiymatga qarab bitta blokni
tanlaydi, blokdan keyin esa dastur davom etadi: notoʻgʻri buyurtmani toʻxtatish uchun `return` kerak.

Dars oxirida siz:

- ikki qiymatni `==`, `!=`, `<`, `<=`, `>`, `>=` bilan solishtirasiz va shartlarni `&&`, `||`, `!` bilan ulaysiz;
- `if`, `else if`, `else` yozasiz va notoʻgʻri holatda `return` bilan `main`'dan chiqasiz;
- qisqa eʼlonli `if` (`if left := …; left < 0`) yozasiz va `undefined: left` xatosini oʻqiysiz;
- `switch` bilan bir nechta shartdan bittasini tanlaysiz: yetkazish narxini summaga qarab.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| taqqoslash va mantiqiy amal | ikki qiymatni solishtirish (`sold > 0`), natijasi `bool`: `true` yoki `false`; `&&` (va), `\|\|` (yoki), `!` (inkor) bir nechta shartni ulaydi | comparison, logical operators |
| `if` / `else` | shart `true` boʻlsa `{ }` ichidagi blok bajariladi, `false` boʻlsa oʻtkazib yuboriladi; `else` — shart `false` boʻlganda | if statement |
| `switch` | bir nechta `case`'dan birinchi mos kelganini bajaradi va shu yerda tugaydi; hech biri mos kelmasa `default` | switch statement |

Ikkita yordamchi soʻz: **`return`** — funksiyani shu joyda tugatadi (bu darsda `main`'ni, demak dasturni); va
**koʻrinish doirasi** (inglizcha **scope**) — kodning nom koʻrinadigan qismi.

## Boshlangʻich holat: miqdor manfiy

Bu oʻtgan darsdagi bozor, vazifasi bilan. Faqat 25-qatorda `sold` −3 ga oʻzgartirilgan:

```go filename="_video/01-manfiy/main.go" showLineNumbers
package main

import "fmt"

const tiyinPerSom = 100    // 1 soʻm = 100 tiyin
const vatPercent = 12      // QQS, foizda
const deliverySom = 15_000 // yetkazib berish, soʻmda (QQS qoʻshilmaydi)

func main() {
	fmt.Println("bozor ishga tushdi")
	fmt.Println("versiya: 0.1.0")

	var name string
	var price int64
	var active bool
	fmt.Println(name, price, active)

	name = "choy"
	price = 1_999 * tiyinPerSom // tiyinda
	active = true
	stock := 40
	weight := 1.5
	fmt.Println(name, price, active, stock, weight)

	sold := -3
	stock = stock - sold
	fmt.Println(name, stock)

	subtotal := price * int64(sold)
	vat := subtotal * vatPercent / 100
	total := subtotal + vat + deliverySom*tiyinPerSom

	item := fmt.Sprintf("%s, %d dona", name, sold)
	fmt.Printf("%-14s %9d.%02d\n", item, subtotal/tiyinPerSom, subtotal%tiyinPerSom)
	fmt.Printf("%-14s %9d.%02d\n", "QQS", vat/tiyinPerSom, vat%tiyinPerSom)
	fmt.Printf("%-14s %9d.%02d\n", "yetkazish", deliverySom, 0)
	fmt.Printf("%-14s %9d.%02d\n", "jami", total/tiyinPerSom, total%tiyinPerSom)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 5–7 | `const …` | GB-1.03: 1 soʻm = 100 tiyin, QQS 12 %, yetkazish 15 000 soʻm |
| 10–23 | `fmt.Println(…)`, `var …`, `:=` | GB-1.01–1.02: ishga tushish va versiya qatori, zero value, mahsulot va ombor. Bugun ularga tegmaymiz |
| 25 | `sold := -3` | sotilgan dona: **−3**. Yagona oʻzgarish |
| 26 | `stock = stock - sold` | omborni kamaytirish kerak edi: 40 − (−3) = 43, ombor oʻsdi |
| 29–31 | `subtotal`, `vat`, `total` | GB-1.03 dagi hisob, tiyinda: 199 900 × (−3) = −599 700; QQS −71 964 |
| 33–37 | `fmt.Sprintf`, `fmt.Printf` | GB-1.04 dagi chek: `%9d` soʻm, `.`, `%02d` tiyin |

## Taqqoslash: natija — `bool`

Qaror solishtirishdan boshlanadi:

```go filename="_video/02-bool/main.go" showLineNumbers
package main

import "fmt"

func main() {
	sold := -3
	ok := sold > 0
	fmt.Println(ok)
}
```

7-qatorda `>` — «katta» belgisi: `sold` noldan kattami? Natija son emas, GB-1.02 dagi **`bool`** turi: `true` yoki
`false`. −3 noldan katta emas, shuning uchun `ok` degan yangi oʻzgaruvchiga `false` yoziladi. `:=` turni qiymatdan
oladi, demak `ok` — `bool`. Xotirada qator-baqator:

| Qator | Kod | `sold` (`int`) | `ok` (`bool`) | Ekranda |
|---|---|---|---|---|
| 6 | `sold := -3` | −3 | — | |
| 7 | `ok := sold > 0` | −3 | `false` (−3 > 0 ?) | |
| 8 | `fmt.Println(ok)` | −3 | `false` | `false` |

```console
$ ./_video/run.sh 02-bool
false
```

Go'da oltita **taqqoslash** operatori (comparison operators) bor. Har birining natijasi `bool`:

| Operator | Maʼnosi | Misol, `sold` = 7 | Natija |
|---|---|---|---|
| `==` | teng | `sold == 7` | `true` |
| `!=` | teng emas | `sold != 7` | `false` |
| `<` | kichik | `sold < 7` | `false` |
| `<=` | kichik yoki teng | `sold <= 7` | `true` |
| `>` | katta | `sold > 0` | `true` |
| `>=` | katta yoki teng | `sold >= 10` | `false` |

Ehtiyot boʻling: **bitta** `=` taqqoslash emas, qiymat berish (GB-1.02). Tenglikni **ikki** teng, `==` tekshiradi.
`string`'larni ham `==` bilan solishtirish mumkin: `name == "choy"` `name` aynan `"choy"` boʻlsa `true`.

**Ikki tomonning turi mos boʻlishi kerak.** `sold` — `int`, `price` — `int64`. `sold > price` yozsangiz,
kompilyator GB-1.03 dagi `mismatched types` xatosini beradi (toʻliq misol «Koʻp uchraydigan xatolar» boʻlimida).
`sold > 0` esa ishlaydi: `0` — turi yozilmagan konstanta, u `sold`'ning turiga, `int`'ga oʻzi moslashadi.

### Mantiqiy amallar: `&&`, `||`, `!`

Koʻpincha bitta shart yetmaydi: miqdor musbat **va** ombordagidan oshmasligi kerak. Buning uchun **mantiqiy
amallar** (logical operators) bor:

```go filename="_video/03-mantiq/main.go" showLineNumbers
package main

import "fmt"

func main() {
	sold := 7
	stock := 40
	ok := sold > 0 && sold <= stock
	bad := sold <= 0 || sold > stock
	fmt.Println(ok, bad, !ok)
}
```

- `&&` (ikki ampersand) — mantiqiy **va**: ikkala tomon `true` boʻlsagina natija `true`.
- `||` (ikki vertikal chiziq) — mantiqiy **yoki**: kamida bittasi `true` boʻlsa yetadi.
- `!` (undov) — **inkor**: `true` ni `false` ga, `false` ni `true` ga aylantiradi.

| `a` | `b` | `a && b` | `a \|\| b` |
|---|---|---|---|
| `true` | `true` | `true` | `true` |
| `true` | `false` | `false` | `true` |
| `false` | `true` | `false` | `true` |
| `false` | `false` | `false` | `false` |

8-qatorda qavs yoʻq. Kerak ham emas: taqqoslash (`>`, `<=`) `&&` va `||` dan oldin hisoblanadi (Go
spetsifikatsiyasi, Operator precedence). Shuning uchun `sold > 0 && sold <= stock` = `(sold > 0) && (sold <= stock)`.

`sold` 7, `stock` 40. Ekranda nima chiqadi?

**A)** `true false false` · **B)** `true true false` · **C)** `true false true`

<details>
<summary>Javob</summary>

**A: `true false false`.** `ok`: 7 > 0 → `true`, 7 &lt;= 40 → `true`, `true && true` → `true`. `bad` ikkala shartning
teskarisini soʻraydi: 7 &lt;= 0 → `false`, 7 > 40 → `false`, `false || false` → `false`. `!ok` → `false`. **B** ni
tanlagan boʻlsangiz, `||` ni «kamida bittasi» emas, boshqa narsa deb oʻqigansiz: bu yerda ikkala tomon ham `false`.
**C** da `!` unutilgan: `!ok` — `ok` ning teskarisi.

</details>

| Qator | Kod | Hisob | Natija |
|---|---|---|---|
| 8 | `ok := sold > 0 && sold <= stock` | `true && true` | `ok` = `true` |
| 9 | `bad := sold <= 0 \|\| sold > stock` | `false \|\| false` | `bad` = `false` |
| 10 | `fmt.Println(ok, bad, !ok)` | `!true` | ekranda `true false false` |

## `if`: shart `true` boʻlsa, blok bajariladi

Birinchi qoida: miqdor kamida 1 dona. U `sold` eʼlon qilingan qatordan keyin, ombordan ayirishdan oldin turadi:

```go filename="_video/04-if/main.go" showLineNumbers
package main

import "fmt"

const tiyinPerSom = 100    // 1 soʻm = 100 tiyin
const vatPercent = 12      // QQS, foizda
const deliverySom = 15_000 // yetkazib berish, soʻmda (QQS qoʻshilmaydi)

func main() {
	fmt.Println("bozor ishga tushdi")
	fmt.Println("versiya: 0.1.0")

	var name string
	var price int64
	var active bool
	fmt.Println(name, price, active)

	name = "choy"
	price = 1_999 * tiyinPerSom // tiyinda
	active = true
	stock := 40
	weight := 1.5
	fmt.Println(name, price, active, stock, weight)

	sold := -3
	if sold <= 0 {
		fmt.Println("xato: miqdor kamida 1 dona boʻlishi kerak")
	}
	stock = stock - sold
	fmt.Println(name, stock)

	subtotal := price * int64(sold)
	vat := subtotal * vatPercent / 100
	total := subtotal + vat + deliverySom*tiyinPerSom

	item := fmt.Sprintf("%s, %d dona", name, sold)
	fmt.Printf("%-14s %9d.%02d\n", item, subtotal/tiyinPerSom, subtotal%tiyinPerSom)
	fmt.Printf("%-14s %9d.%02d\n", "QQS", vat/tiyinPerSom, vat%tiyinPerSom)
	fmt.Printf("%-14s %9d.%02d\n", "yetkazish", deliverySom, 0)
	fmt.Printf("%-14s %9d.%02d\n", "jami", total/tiyinPerSom, total%tiyinPerSom)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 26 | `if sold <= 0 {` | `if` kalit soʻzi, keyin shart `sold <= 0`, qavssiz; oxirida ochuvchi jingalak qavs |
| 27 | `fmt.Println("xato: …")` | blok ichidagi qator: faqat shart `true` boʻlsa bajariladi |
| 28 | `}` | blok tugadi |

**`if`** qoidalari (Go spetsifikatsiyasi, If statements):

- shart faqat `bool` boʻladi. `if sold {` deb yozsangiz, kompilyator rad etadi: `sold` son, `bool` emas;
- shart `true` boʻlsa, `{ }` ichidagi **blok** bajariladi; `false` boʻlsa, Go uni oʻtkazib yuboradi;
- jingalak qavslar doim kerak, blokda bitta qator boʻlsa ham. Ochuvchi `{` `func main() {` dagidek shu qatorda turadi;
- shart atrofidagi oddiy qavs shart emas. `if (sold > 0) {` ham kompilyatsiya boʻladi, lekin `gofmt` qavsni olib
  tashlaydi, shuning uchun Go kodida qavssiz yoziladi.

`sold` −3, shart `true`, blok bajariladi. `go run .` ekranga nima chiqaradi?

**A)** faqat xato qatori · **B)** xato qatori, keyin chek · **C)** kompilyatsiya xatosi

<details>
<summary>Javob</summary>

**B.** Xato qatori chiqadi, keyin baribir ombor 43 va manfiy chek. `if` faqat oʻz blokini boshqaradi: yopuvchi `}` dan
keyin dastur keyingi qatordan davom etadi. **A** ni tanlagan boʻlsangiz, xatoni ekranga yozish dasturni toʻxtatadi deb
oʻylagansiz: toʻxtatmaydi. Kod toʻgʻri yozilgan, shuning uchun **C** ham emas.

</details>

## `return`: shu joyda toʻxtash

Toʻxtatish uchun blok ichiga **`return`** qoʻshamiz. Fayl `04-if` bilan bir xil, faqat 28-qator qoʻshilgan. Uning
25–31-qatorlari:

```go
	sold := -3
	if sold <= 0 {
		fmt.Println("xato: miqdor kamida 1 dona boʻlishi kerak")
		return
	}
	stock = stock - sold
	fmt.Println(name, stock)
```

`return` funksiyani shu joyda tugatadi: undan keyingi qatorlar bajarilmaydi. Bu `main`, `main` tugasa dastur ham
tugaydi (GB-1.01). Qiymat qaytaradigan `return`'ni [GB-1.07](/lab/youtube/gb/gb-1-07) da koʻramiz. Toʻliq fayl:
`_video/05-return/main.go`.

```console
$ ./_video/run.sh 05-return
bozor ishga tushdi
versiya: 0.1.0
 0 false
choy 199900 true 40 1.5
xato: miqdor kamida 1 dona boʻlishi kerak
```

Endi xato qatoridan keyin na ombor qatori, na chek bor. Bu shakl Go kodida juda koʻp uchraydi: notoʻgʻri holatni
boshida tekshirib, darhol chiqib ketish (inglizcha *guard clause*, *early return*). Asosiy hisob qoʻshimcha qavslarga
surilmaydi, chap chetda qoladi. Go Code Review Comments buni «Indent Error Flow» deb ataydi. Effective Go ham shunday
yozadi: xato holati `return` bilan tugasa, ortiqcha `else` yozilmaydi. Shunday yozilmaydi:

```go
	if sold <= 0 {
		fmt.Println("xato: miqdor kamida 1 dona boʻlishi kerak")
	} else {
		stock = stock - sold
		// … butun hisob va chek shu qavslar ichida, bir pogʻona oʻngda
	}
```

Hozircha bir soddalashtirish bor. Xato xabari chek bilan bir joyga, standart chiqishga (stdout) yoziladi. Dastur esa
0 chiqish kodi bilan, yaʼni «muvaffaqiyatli» tugaydi: operatsion tizim xato boʻlganini bilmaydi. Xatoni alohida
oqimga (stderr) yozish va muvaffaqiyatsizlikni bildirish (`os.Exit(1)`) — [GB-1.07](/lab/youtube/gb/gb-1-07) da.

## Shartda bitta `=`

Endi shartda tez-tez uchraydigan xato. Nol miqdorni tekshirmoqchi boʻlib, `==` oʻrniga bitta `=` yozildi. Fayl
`05-return` bilan bir xil, faqat 25–26-qator boshqa:

```go
	sold := 0
	if sold = 0 {
		fmt.Println("xato: miqdor kamida 1 dona boʻlishi kerak")
		return
	}
```

Koʻzga tekshiruvdek koʻrinadi, lekin bitta `=` — qiymat berish. Bu faylda ataylab yozilish xatosi bor, shuning uchun
u papkada `_video/06-teng-xato/main.go.txt` nomida turadi: `.go` boʻlsa, `gofmt` va `go vet` butun papkani oʻqiy
olmay qolardi. `run.sh` uni `main.go` qilib koʻchiradi:

```console
$ ./_video/run.sh 06-teng-xato

./main.go:26:10: syntax error: cannot use assignment sold = 0 as value
```

Xabarni oʻqiymiz:

- `./main.go:26:10` — 26-qator, 10-ustun: `=` belgisi (Tab bitta ustun, `if` 2–3, `sold` 5–8, `=` 10-ustunda);
- `syntax error` — yozilish xatosi: kompilyator kodni oʻqiy olmadi;
- `cannot use assignment sold = 0 as value` — «`sold = 0` qiymat berishni qiymat sifatida ishlatib boʻlmaydi».

Go'da qiymat berish natija bermaydi, u alohida buyruq (Go spetsifikatsiyasi, Assignment statements). Shart esa
`bool` qiymat kutadi. Shuning uchun xato dastur ishga tushishidan oldin ushlanadi. Tuzatish: `==`, bizning qoidada
esa `<=` (nol ham, manfiy ham rad etiladi).

## Qisqa eʼlonli `if`: ombor qoidasi

Ikkinchi qoida: ombordagidan koʻp sotib boʻlmaydi. Bu safar buyurtma 50 dona (25-qator), omborda esa 40:

```go filename="_video/07-ombor/main.go" showLineNumbers
package main

import "fmt"

const tiyinPerSom = 100    // 1 soʻm = 100 tiyin
const vatPercent = 12      // QQS, foizda
const deliverySom = 15_000 // yetkazib berish, soʻmda (QQS qoʻshilmaydi)

func main() {
	fmt.Println("bozor ishga tushdi")
	fmt.Println("versiya: 0.1.0")

	var name string
	var price int64
	var active bool
	fmt.Println(name, price, active)

	name = "choy"
	price = 1_999 * tiyinPerSom // tiyinda
	active = true
	stock := 40
	weight := 1.5
	fmt.Println(name, price, active, stock, weight)

	sold := 50
	if sold <= 0 {
		fmt.Println("xato: miqdor kamida 1 dona boʻlishi kerak")
		return
	}
	if left := stock - sold; left < 0 {
		fmt.Printf("xato: omborda %d dona yetmaydi\n", -left)
		return
	}
	stock = stock - sold
	fmt.Println(name, stock)

	subtotal := price * int64(sold)
	vat := subtotal * vatPercent / 100
	total := subtotal + vat + deliverySom*tiyinPerSom

	item := fmt.Sprintf("%s, %d dona", name, sold)
	fmt.Printf("%-14s %9d.%02d\n", item, subtotal/tiyinPerSom, subtotal%tiyinPerSom)
	fmt.Printf("%-14s %9d.%02d\n", "QQS", vat/tiyinPerSom, vat%tiyinPerSom)
	fmt.Printf("%-14s %9d.%02d\n", "yetkazish", deliverySom, 0)
	fmt.Printf("%-14s %9d.%02d\n", "jami", total/tiyinPerSom, total%tiyinPerSom)
}
```

30-qatordagi `if` boshqacha: shartdan oldin **qisqa eʼlon** turadi.

| Qism | Kod | Nima qiladi |
|---|---|---|
| eʼlon | `left := stock - sold` | sotuvdan keyin omborda qoladigan dona; `left` («qolgan») — yangi oʻzgaruvchi |
| ajratuvchi | `;` | nuqtali vergul eʼlonni shartdan ajratadi |
| shart | `left < 0` | qoldiq manfiy boʻlsa, omborda yetmaydi |
| 31-qator | `fmt.Printf("xato: omborda %d dona yetmaydi\n", -left)` | `-left` — minus `left`: yetmagan dona sonini musbat qiladi |
| 32-qator | `return` | chek ham, ombordan ayirish ham boʻlmaydi |

Go avval eʼlonni bajaradi, keyin shartni tekshiradi (Go spetsifikatsiyasi: «The expression may be preceded by a simple
statement, which executes before the expression is evaluated»):

| Qadam | Nima boʻladi | `left` | Natija |
|---|---|---|---|
| 1 | `left := stock - sold` → 40 − 50 | −10 | |
| 2 | `left < 0` → −10 &lt; 0 | −10 | `true`: blok bajariladi |
| 3 | `-left` → −(−10) | −10 | ekranda `xato: omborda 10 dona yetmaydi` |
| 4 | `return` | | `main` tugaydi |

`stock` 40 va `sold` 40 boʻlsa, `left` 0 boʻladi: 0 &lt; 0 — `false`, buyurtma oʻtadi. Ombordagi hamma choyni sotish
mumkin.

```console
$ ./_video/run.sh 07-ombor
bozor ishga tushdi
versiya: 0.1.0
 0 false
choy 199900 true 40 1.5
xato: omborda 10 dona yetmaydi
```

### `left` qayerda koʻrinadi

Endi `if`'ning yopuvchi `}` idan keyingi qatorda `left`'ni chiqaramiz (`08-scope`, 34-qator qoʻshilgan):

```go
	if left := stock - sold; left < 0 {
		fmt.Printf("xato: omborda %d dona yetmaydi\n", -left)
		return
	}
	fmt.Println(left)
```

`stock` 40, `sold` 50. Nima boʻladi?

**A)** `-10` chiqadi · **B)** `0` chiqadi · **C)** kompilyatsiya xatosi

<details>
<summary>Javob</summary>

**C.** Kompilyatsiya xatosi: `undefined: left`, yaʼni «`left` aniqlanmagan». Qisqa eʼlondagi oʻzgaruvchi faqat shu
`if` ichida koʻrinadi, yopuvchi `}` dan keyin bu nom yoʻq. **A** ni tanlagan boʻlsangiz, `left` `main`'ga tegishli deb
oʻylagansiz. **B** — `left` zero value bilan qoladi degan taxmin: nom umuman yoʻq, qiymati haqida gap ham boʻlmaydi.

</details>

```console
$ ./_video/run.sh 08-scope
# github.com/abdurahmon27/bozor
./main.go:34:14: undefined: left
```

`./main.go:34:14` — 34-qator, 14-ustun: `fmt.Println(` ichidagi `left`. Nom koʻrinadigan joy **koʻrinish doirasi**
deyiladi, inglizcha **scope**. Go spetsifikatsiyasi (Blocks): «Each if, for, and switch statement is considered to be
in its own implicit block» — har bir `if`, `for` va `switch` oʻzining yashirin blokida turadi:

```text
func main() {                          ← main bloki: name, price, stock, sold …
    if left := stock - sold; left < 0 {   ← if bloki boshlanadi: left shu yerda paydo boʻladi
        … -left …                      ← left koʻrinadi
    }                                  ← if bloki tugadi: left yoʻq
    fmt.Println(left)                  ← undefined: left
}
```

`left` `if`'ning sharti va blokida koʻrinadi (`if`'ga ulangan `else` bloklarida ham). Yordamchi nom shunday qilib faqat
kerakli joyda turadi va keyingi kodda adashib ishlatilmaydi.

## `else if` va `else`: yetkazish narxi

Endi yetkazish narxi. Buyurtma: oʻrik, 25 000 soʻmdan, 24 dona. Qoida:

| Mahsulot summasi | Yetkazish |
|---|---|
| 500 000 soʻm va undan koʻp | 0 (bepul) |
| 100 000 soʻm va undan koʻp | 10 000 soʻm |
| qolgani | 15 000 soʻm (`deliverySom`) |

```go filename="_video/09-elseif/main.go" showLineNumbers
package main

import "fmt"

const tiyinPerSom = 100    // 1 soʻm = 100 tiyin
const vatPercent = 12      // QQS, foizda
const deliverySom = 15_000 // yetkazib berish, soʻmda (QQS qoʻshilmaydi)

func main() {
	fmt.Println("bozor ishga tushdi")
	fmt.Println("versiya: 0.1.0")

	var name string
	var price int64
	var active bool
	fmt.Println(name, price, active)

	name = "oʻrik"
	price = 25_000 * tiyinPerSom // tiyinda
	active = true
	stock := 40
	weight := 1.5
	fmt.Println(name, price, active, stock, weight)

	sold := 24
	if sold <= 0 {
		fmt.Println("xato: miqdor kamida 1 dona boʻlishi kerak")
		return
	}
	if left := stock - sold; left < 0 {
		fmt.Printf("xato: omborda %d dona yetmaydi\n", -left)
		return
	}
	stock = stock - sold
	fmt.Println(name, stock)

	subtotal := price * int64(sold)
	vat := subtotal * vatPercent / 100

	var delivery int64 // tiyinda
	if subtotal >= 500_000*tiyinPerSom {
		delivery = 0
	} else if subtotal >= 100_000*tiyinPerSom {
		delivery = 10_000 * tiyinPerSom
	} else {
		delivery = deliverySom * tiyinPerSom
	}
	total := subtotal + vat + delivery

	item := fmt.Sprintf("%s, %d dona", name, sold)
	fmt.Printf("%-14s %9d.%02d\n", item, subtotal/tiyinPerSom, subtotal%tiyinPerSom)
	fmt.Printf("%-14s %9d.%02d\n", "QQS", vat/tiyinPerSom, vat%tiyinPerSom)
	fmt.Printf("%-14s %9d.%02d\n", "yetkazish", delivery/tiyinPerSom, delivery%tiyinPerSom)
	fmt.Printf("%-14s %9d.%02d\n", "jami", total/tiyinPerSom, total%tiyinPerSom)

```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 18–19, 25 | `name = "oʻrik"`, `price = 25_000 * tiyinPerSom`, `sold := 24` | yangi buyurtma: 25 000 × 24 = 600 000 soʻm |
| 40 | `var delivery int64 // tiyinda` | qiymatsiz eʼlon: hozircha zero value 0 (GB-1.02). Unga quyidagi uch yoʻldan biri qiymat beradi |
| 41–42 | `if subtotal >= 500_000*tiyinPerSom {` | summa tiyinda, shuning uchun soʻmdagi chegara `tiyinPerSom`'ga koʻpaytirilgan; 500 000 soʻmdan boshlab bepul |
| 43–44 | `} else if subtotal >= 100_000*tiyinPerSom {` | **`else if`**: oldingi shart `false` boʻlsa, yana bitta shart; 100 000 soʻmdan boshlab 10 000 soʻm |
| 45–47 | `} else {` | **`else`**: yuqoridagi hamma shart `false` boʻlsa; 15 000 soʻm |
| 48 | `total := subtotal + vat + delivery` | jami endi `delivery`'dan olinadi |
| 53 | `"yetkazish", delivery/tiyinPerSom, delivery%tiyinPerSom` | chekdagi yetkazish qatori ham |

Shartlar tepadan pastga tekshiriladi. Birinchi `true` boʻlgan shartning bloki bajariladi, qolganlari tekshirilmaydi.
`else` va `else if` yopuvchi `}` bilan bir qatorda turadi: `}` dan keyin yangi qator boshlasangiz, kompilyatsiya xatosi
(«Koʻp uchraydigan xatolar», 4-band).

Bu buyurtmada mahsulot summasi 600 000 soʻm (60 000 000 tiyin):

|---|---|---|
| `subtotal >= 500_000*tiyinPerSom` | `true` | `delivery = 0` |
| `subtotal >= 100_000*tiyinPerSom` | tekshirilmaydi | — |
| `else` | — | — |

## `switch`: birinchi `true` case

Xuddi shu `if`, `else if`, `else` zanjirini **`switch`** bilan yozish oʻqishga qulayroq. Effective Go ham shuni aytadi:
«it's idiomatic to write an if-else-if-else chain as a switch». Fayl `09-elseif` bilan bir xil, faqat 41–48-qator
boshqa. Uning 40–49-qatorlari:

```go
	var delivery int64 // tiyinda
	switch {
	case subtotal >= 500_000*tiyinPerSom:
		delivery = 0
	case subtotal >= 100_000*tiyinPerSom:
		delivery = 10_000 * tiyinPerSom
	default:
		delivery = deliverySom * tiyinPerSom
	}
	total := subtotal + vat + delivery
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 41 | `switch {` | `switch`'dan keyin hech narsa yoʻq: bu **ifodasiz switch**, har bir `case` `bool` shart oladi |
| 42–43 | `case subtotal >= 500_000*tiyinPerSom:` | `case` soʻzi, shart, ikki nuqta; pastida shu `case`'ning qatorlari |
| 44–45 | `case subtotal >= 100_000*tiyinPerSom:` | keyingi `case` oʻsha qolipda |
| 46–47 | `default:` | hech bir `case` `true` boʻlmaganda bajariladi |
| 48 | `}` | `switch` tugadi |

Go spetsifikatsiyasi: ifodasiz `switch` — `switch true` bilan bir xil. Yaʼni Go `true` boʻlgan birinchi `case`'ni
qidiradi. Toʻliq fayl: `_video/10-switch/main.go`.

Summa 600 000 soʻm, demak birinchi `case` ham, ikkinchisi ham `true`. Yetkazish qancha boʻladi?

**A)** 0 soʻm · **B)** 10 000 soʻm · **C)** kompilyatsiya xatosi

<details>
<summary>Javob</summary>

**A: 0 soʻm.** Go tepadan pastga birinchi `true` `case`'ni bajardi va `switch` shu yerda tugadi. Keyingi `case`'lar
tekshirilmaydi ham. **B** ni tanlagan boʻlsangiz, hamma `true` case bajariladi va oxirgisi yutadi deb oʻylagansiz.
**C** emas: ikkita `case` bir vaqtda `true` boʻlishi mumkin, Go buni taqiqlamaydi.

</details>

### Qiymatli `switch`

```go filename="_video/11-qiymat/main.go" showLineNumbers
	}

```

| 10–11 | `case "non":` | `name` `"non"` boʻlsa |

## Koʻp uchraydigan xatolar

### 1. `if` blokidan keyin dastur toʻxtaydi deb oʻylash

Eng koʻp uchraydigan xato. Xabarni ekranga yozish dasturni toʻxtatmaydi: `if` blokidan keyin dastur davom etadi.
Kompilyator jim, natija esa notoʻgʻri: xato qatoridan keyin baribir ombor oʻzgaradi va manfiy chek chiqadi («`if`: shart
`true` boʻlsa, blok bajariladi» boʻlimidagi `04-if` natijasi). **Tuzatish:** blok oxiriga `return`.

### 2. Shartda bitta `=`

`if sold = 0 {` — qiymat berish, taqqoslash emas. Natija: `syntax error: cannot use assignment sold = 0 as value`
(«Shartda bitta `=`» boʻlimi). **Tuzatish:** `==`, yoki qoidaga qarab `<=`.

### 3. Shart `bool` emas

Shart sifatida sonning oʻzini yozish. Papkada yoʻq misol:

```go
package main

import "fmt"

func main() {
	sold := 7
	if sold {
		fmt.Println("sotildi")
	}
}
```

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:7:5: non-boolean condition in if statement
```

«7-qator, 5-ustun: `if` buyrugʻida `bool` boʻlmagan shart». `sold` — `int`, `if` esa faqat `true`/`false` oladi. Go
sonni oʻzi `bool`'ga aylantirmaydi. **Tuzatish:** savolni aniq yozing: `if sold > 0 {`.

### 4. `else` yangi qatorda

Papkada yoʻq misol:

```go
package main

import "fmt"

func main() {
	sold := 7
	if sold <= 0 {
		fmt.Println("xato")
	}
	else {
		fmt.Println("ok")
	}
}
```

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:10:2: syntax error: unexpected keyword else, expected }
```

«10-qator: kutilmagan `else` kalit soʻzi, `}` kutilgan edi». Go qator oxirida `}` dan keyin nuqtali vergulni oʻzi
qoʻyadi (Go spetsifikatsiyasi, Semicolons). Shunda `if` 9-qatorda tugaydi, 10-qatordagi `else` esa hech narsaga ulanmay
qoladi. **Tuzatish:** `} else {` bitta qatorda.

### 5. Turli turdagi qiymatlarni solishtirish

Papkada yoʻq misol: `sold` — `int`, `price` — `int64`:

```go
package main

import "fmt"

func main() {
	var price int64 = 199_900
	sold := 7
	if sold > price {
		fmt.Println("?")
	}
	fmt.Println(sold > 0)
}
```

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:8:12: invalid operation: sold > price (mismatched types int and int64)
```

«Notoʻgʻri amal: `sold > price`, turlar mos emas: `int` va `int64`» — GB-1.03 dagi xabarning oʻzi. 11-qatordagi
`sold > 0` esa xato bermaydi: `0` — turi yozilmagan konstanta. **Tuzatish:** bir turga keltiring, masalan
`int64(sold) > price`.

### 6. `switch`'da kichik chegara tepada

Kompilyator jim, natija notoʻgʻri. Papkada yoʻq misol, `case`'lar teskari tartibda:

```go
package main

import "fmt"

const tiyinPerSom = 100

func main() {
	var subtotal int64 = 600_000 * tiyinPerSom
	var delivery int64
	switch {
	case subtotal >= 100_000*tiyinPerSom:
		delivery = 10_000 * tiyinPerSom
	case subtotal >= 500_000*tiyinPerSom:
		delivery = 0
	}
	fmt.Println(delivery / tiyinPerSom)
}
```

```console
$ go run .
10000
```

600 000 soʻmlik buyurtma bepul boʻlishi kerak edi, lekin 10 000 soʻm chiqdi. Birinchi `case` allaqachon `true`, shuning
uchun ikkinchisi hech qachon tekshirilmaydi. **Tuzatish:** eng qattiq (eng katta) chegara tepada, `10-switch`'dagidek.

- 🟢 **Oson · nom, sotuv va narx qoidasi.** Hozir mahsulotning oʻzi tekshirilmaydi: `name` boʻsh boʻlsa, chek `, 7 dona`
  bilan boshlanadi; `active` `false` boʻlsa ham mahsulot sotiladi; `price` berilmasa (zero value, `0`) yoki manfiy
  boʻlsa, tekinga yoki «minus» pulga sotiladi. `main()` da `sold := 7` qatoridan keyin, **miqdor tekshiruvidan
  (`if sold <= 0`) oldin**, uchta qoida qoʻshing, aynan shu tartibda. Har biri videodagidek: shart, xabar, `return`.

  1. `name` boʻsh matn (`""`) boʻlsa: `xato: mahsulot nomi boʻsh`.
  2. `active` `false` boʻlsa (`!` bilan yozing), xabarda mahsulot nomi: `xato: choy sotuvda emas`.
  3. `price` nol yoki manfiy, **yoki** 10 000 000 soʻmdan katta boʻlsa, narx tiyinda: `xato: narx notoʻgʻri: 0 tiyin`.
     Aynan 10 000 000 soʻm (1 000 000 000 tiyin) va 1 tiyin hali toʻgʻri narx.

  Bir nechta xato boʻlsa, birinchi qoidaning xabari chiqadi: nom ham boʻsh, narx ham 0 boʻlsa, faqat
  `xato: mahsulot nomi boʻsh`. Xabardan oldingi toʻrt qator joyida qoladi.

- 🟡 **Ixtiyoriy · uchala qoida bitta `switch`'da.** Qoidalarni ifodasiz `switch`'ga yigʻing: har bir `case` — bitta
  qoida. `switch` birinchi `true` `case`'ni bajaradi, shuning uchun tartib oʻz-oʻzidan saqlanadi. Test xuddi shu.

Maslahatlar (`TASK.md`'dan):

1. Matn ham `==` bilan solishtiriladi: `name == ""`.
2. `!active` — «`active` emas»: `active` `false` boʻlganda `true`.
3. Narx qoidasi bitta `if` bilan yoziladi: ikki shartni `||` bilan ulang. Chegara tiyinda: `10_000_000*tiyinPerSom`.
   Aynan 10 000 000 soʻm rad etilmasligi uchun `>` va `>=` farqiga qarang.

```go filename="solution/main.go" showLineNumbers
package main

import "fmt"

const tiyinPerSom = 100    // 1 soʻm = 100 tiyin
const vatPercent = 12      // QQS, foizda
const deliverySom = 15_000 // yetkazib berish, soʻmda (QQS qoʻshilmaydi)

func main() {
	fmt.Println("bozor ishga tushdi")
	fmt.Println("versiya: 0.1.0")

	var name string
	var price int64
	var active bool
	fmt.Println(name, price, active)

	name = "choy"
	price = 1_999 * tiyinPerSom // tiyinda
	active = true
	stock := 40
	weight := 1.5
	fmt.Println(name, price, active, stock, weight)

	sold := 7
	if name == "" {
		fmt.Println("xato: mahsulot nomi boʻsh")
		return
	}
	if !active {
		fmt.Printf("xato: %s sotuvda emas\n", name)
		return
	}
	if price <= 0 || price > 10_000_000*tiyinPerSom {
		fmt.Printf("xato: narx notoʻgʻri: %d tiyin\n", price)
		return
	}
	if sold <= 0 {
		fmt.Println("xato: miqdor kamida 1 dona boʻlishi kerak")
		return
	}
	if left := stock - sold; left < 0 {
		fmt.Printf("xato: omborda %d dona yetmaydi\n", -left)
		return
	}
	stock = stock - sold
	fmt.Println(name, stock)

	subtotal := price * int64(sold)
	vat := subtotal * vatPercent / 100

	var delivery int64 // tiyinda
	switch {
	case subtotal >= 500_000*tiyinPerSom:
		delivery = 0
	case subtotal >= 100_000*tiyinPerSom:
		delivery = 10_000 * tiyinPerSom
	default:
		delivery = deliverySom * tiyinPerSom
	}
	total := subtotal + vat + delivery

	item := fmt.Sprintf("%s, %d dona", name, sold)
	fmt.Printf("%-14s %9d.%02d\n", item, subtotal/tiyinPerSom, subtotal%tiyinPerSom)
	fmt.Printf("%-14s %9d.%02d\n", "QQS", vat/tiyinPerSom, vat%tiyinPerSom)
	fmt.Printf("%-14s %9d.%02d\n", "yetkazish", delivery/tiyinPerSom, delivery%tiyinPerSom)
	fmt.Printf("%-14s %9d.%02d\n", "jami", total/tiyinPerSom, total%tiyinPerSom)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 26–29 | `if name == "" {` | nom boʻsh matnga tengmi: `""` — `string`'ning zero value'si |
| 30–33 | `if !active {` | `active` `false` boʻlsa `!active` `true`; `%s` oʻrniga nom |
| 34–37 | `if price <= 0 \|\| price > 10_000_000*tiyinPerSom {` | ikki shartdan biri yetadi; `>` (`>=` emas), shuning uchun aynan 10 000 000 soʻm oʻtadi; 1 tiyin `<= 0` emas, u ham oʻtadi |
| 38–45 | `if sold <= 0`, `if left := …` | videodagi ikki qoida, joyida |

Qoidalar ketma-ket, har biri `return` bilan tugaydi. Shuning uchun birinchi buzilgan qoidaning xabari chiqadi va
keyingilari tekshirilmaydi: tartib kodda yozilgan tartibning oʻzi.

Ixtiyoriy `switch` yoʻli (shu `go test` bilan tekshirdim, `solution/`'da yoʻq), 26–37-qator oʻrniga:

```go
	switch {
	case name == "":
		fmt.Println("xato: mahsulot nomi boʻsh")
		return
	case !active:
		fmt.Printf("xato: %s sotuvda emas\n", name)
		return
	case price <= 0 || price > 10_000_000*tiyinPerSom:
		fmt.Printf("xato: narx notoʻgʻri: %d tiyin\n", price)
		return
	}
```

Bu yerda `default` yoʻq: hamma qoida bajarilsa, `switch` hech narsa qilmaydi va dastur keyingi qatordan davom etadi.
