## Nimani oʻrganasiz

Birinchi modulda bozor'dagi mahsulot uchta alohida oʻzgaruvchi edi:

```go
name := "olma"
price := int64(1_200_000) // tiyin
stock := 40
```

Ikkinchi mahsulot qoʻshilsa, yana uchta paydo boʻladi:

```go
name2 := "non"
price2 := int64(400_000)
stock2 := 100
```

`name2` bilan `price2` bitta mahsulotga tegishli ekanini faqat nomdagi `2` raqami aytadi. Kompilyator bu bogʻlanishni bilmaydi. Bitta
mahsulotni bitta qiymat qilib qanday yigʻasiz?

**Bitta gʻoya:** **struct** — maydonlari bitta qiymat ichida yonma-yon turadigan tur. Literal'da yozilmagan maydon oʻz turining
zero value'sini oladi, `q := p` esa hamma maydonni nusxalaydi: `q` alohida qiymat.

Dars oxirida siz:

- `type Product struct { … }` bilan struct turini eʼlon qilasiz va maydonni `p.Name` bilan oʻqib, `p.Stock = 40` bilan yozasiz;
- struct qiymatini maydon nomlari bilan toʻldirasiz (struct literal) va `%+v` bilan maydon nomlari bilan chiqarasiz;
- yozilmagan maydon nima boʻlishini va `q := p` dan keyin `q`ni oʻzgartirish `p`ga tegmasligini oldindan aytasiz;
- buyurtma holatini `type OrderStatus int` va `iota` bilan yozasiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| struct | bir nechta nomli maydonni bitta qiymatga yigʻadigan tur: `type Product struct { … }` | struct |
| struct literal | struct qiymatini kodda maydon nomlari bilan yozish: `Product{Name: "non"}`; yozilmagan maydon zero value oladi | struct literal |
| iota | `const ( … )` blokidagi qator raqami: 0 dan boshlanadi, har qatorda 1 ga oshadi | iota |

Ikkita yordamchi tushuncha: `%+v` (struct'ni maydon nomlari bilan chiqaradi) va `type OrderStatus int` (`int` asosidagi yangi tur).

Bu darsda yangi turlar paydo boʻladi: `Product`, `OrderItem`, `Order` va `OrderStatus`. Ular bozor'ning **domen turlari**, ya'ni
doʻkon tushunchalari. Keyingi darslar shu turlar ustiga quriladi.

## Muammo: uchta oʻzgaruvchi bitta mahsulot emas

Yuqoridagi oltita oʻzgaruvchi bir-biriga bogʻlanmagan. Mahsulot soni oʻnta boʻlsa, oʻttizta oʻzgaruvchi, oʻttizta nom va
nom oxiridagi raqamlarni oʻzingiz kuzatib borasiz. Mahsulotni funksiyaga bermoqchi boʻlsangiz, uchta qiymatni uchta parametr qilib
yozasiz. Kerak narsa: nom, narx va qoldiqni **bitta** qiymatga yigʻish.

Bugun uch narsa qilamiz:

1. **struct** — bir nechta nomli maydonni bitta qiymatga yigʻadigan tur;
2. **struct literal va zero value** — qiymatni maydon nomlari bilan toʻldirish;
3. **iota** — buyurtma holatlari uchun ketma-ket raqamlangan konstantalar.

## Struct: nomli maydonlar, bitta qiymat

Yangi tur eʼlon qilish uchun `type` kalit soʻzi bor. `type Product struct { … }` — «`Product` degan yangi tur, uning koʻrinishi —
maydonlar roʻyxati». Har bir **maydon** (field) — nom va uning turi. Birinchi dastur (`_video/01-product/main.go`):

```go filename="_video/01-product/main.go" showLineNumbers
package main

import "fmt"

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

func main() {
	p := Product{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40}
	fmt.Println(p.Name, p.Price)
	fmt.Printf("%+v\n", p)
}
```

1–3-qatorlar GB-1.01'dan tanish (`package main`, `import "fmt"`), 13-qator — `func main()`. Yangi qatorlar:

| Qator | Kod | Nima qiladi |
|---|---|---|
| 5 | `// Product — katalogdagi bitta mahsulot.` | izoh (GB-1.03): tur nimaligini aytadi |
| 6 | `type Product struct {` | `type` — yangi tur eʼlon qiladi, nomi `Product`. `struct` — turning koʻrinishi: jingalak qavs ichida maydonlar roʻyxati. Oxiri 11-qatordagi `}` |
| 7 | `ID    int64` | maydon: avval **nom** (`ID`, mahsulot raqami), keyin **tur** (`int64`, GB-1.03) |
| 8 | `Name  string` | `Name` — mahsulot nomi, matn |
| 9 | `Price int64 // tiyin` | `Price` — narxi, GB-1.03'dagidek tiyinda |
| 10 | `Stock int` | `Stock` — ombordagi qoldiq |
| 14 | `p := Product{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40}` | **struct literal**: `Product`, keyin jingalak qavs ichida `Maydon: qiymat` juftlari, vergul bilan ajratilgan. Natija `p` oʻzgaruvchisiga tushadi (`:=`, GB-1.02) |
| 15 | `fmt.Println(p.Name, p.Price)` | `p.Name` — `p`ning `Name` maydonini oʻqiydi: nuqta maydonni tanlaydi. GB-1.08'dagi `tc.name` ham shunday edi. `Println` ikki qiymatni probel bilan chiqaradi |
| 16 | `fmt.Printf("%+v\n", p)` | `%+v` butun struct'ni chiqaradi; `+` belgisi har qiymat oldiga maydon nomini qoʻshadi |

Ikki eslatma. Birinchisi: ustunlar (`ID    int64`, `Name  string`) `go fmt` tomonidan tekislangan (GB-1.01), tekislash Go uchun
maʼnoga ega emas. Ikkinchisi: tur va maydon nomlari bosh harf bilan boshlangan. Buning sababini
[GB-2.06 · Paketlar: katta harf, internal/ va loyiha tuzilishi](/lab/youtube/gb/gb-2-06) ochadi, hozircha shunday yozing.

Oxirgi ikki qator nima chiqaradi? Ikkalasini oʻzingiz taxmin qiling.

```console
$ ./_video/run.sh 01-product go run .
olma 1200000
{ID:1 Name:olma Price:1200000 Stock:40}
```

Birinchi qatorda ikki maydon, `Println` ularni probel bilan ajratdi. Ikkinchi qatorda jingalak qavs ichida har bir maydonning nomi,
ikki nuqta va qiymati, tartibi eʼlondagidek. Matn qoʻshtirnoqsiz chiqdi: `%v` shunday yozadi.

`+` belgisi nimaga kerakligini oʻzimiz tekshiramiz. Quyidagi dastur kurs papkasida **yoʻq**; uni alohida papkada, shu `go.mod`
bilan ishga tushirdik. Hamma uch qatorda bir xil `p`:

```go
package main

import "fmt"

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

func main() {
	p := Product{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40}
	fmt.Printf("%v\n", p)
	fmt.Printf("%+v\n", p)
	fmt.Println(p)
}
```

```console
$ go run .
{1 olma 1200000 40}
{ID:1 Name:olma Price:1200000 Stock:40}
{1 olma 1200000 40}
```

`%v` va `Println` faqat qiymatlarni beradi, nomlarsiz. `%+v` nomlarni qoʻshadi, shuning uchun maydonlarni tekshirishda aynan u qulay.

## Yozilmagan maydon: zero value

Endi `n` degan oʻzgaruvchida ikkita maydonni yozmaymiz: non, narxi 400 000 tiyin. `ID` va `Stock` yoʻq
(`_video/02-nol/main.go`, `main` ichidagi ikki qator):

```go
n := Product{Name: "non", Price: 400_000}
fmt.Printf("%+v\n", n)
```

Bu qator kompilyatsiya boʻladimi? Boʻlsa, nima chiqadi?

**A)** `{ID:0 Name:non Price:400000 Stock:0}` · **B)** `{Name:non Price:400000}` · **C)** kompilyatsiya xatosi

<details>
<summary>Javob</summary>

**A.** Kompilyatsiya boʻladi va toʻrtala maydon chiqadi. Literal'da yozilmagan maydon oʻz turining **zero value**'sini oladi:
`int64` uchun `0`, `string` uchun `""`, `int` uchun `0`. **B** ni tanlagan boʻlsangiz, struct faqat yozilgan maydonlardan iborat
deb oʻylagansiz: struct'ning maydonlari tur eʼlonida belgilangan, literal ularning faqat qiymatini beradi. **C** ni tanlagan
boʻlsangiz, hamma maydonni yozish shart deb oʻylagansiz: maydon nomlari bor literal'da shart emas, tartib ham erkin
([Go spec: Composite literals](https://go.dev/ref/spec#Composite_literals)).

</details>

```console
$ ./_video/run.sh 02-nol go run .
{ID:0 Name:non Price:400000 Stock:0}
```

`ID:0` va `Stock:0` yozilmagan maydonlar. Yangi mahsulotning qoldigʻi nol: bu maʼnoli boshlanish, `Stock` ni keyin yozasiz.

## Xotirada: struct bitta qiymat, `q := p` nusxa

Kodni xotirada kuzatamiz (`_video/03-nusxa/main.go`, `main` ichi):

```go
p := Product{ID: 1, Name: "olma", Price: 1_200_000}
p.Stock = 40
q := p
q.Stock = 0
fmt.Println(p.Stock, q.Stock)
```

Literal bajarilganda `p` yorligʻi toʻrt maydonli **bitta** qiymatga yopishadi. Maydonlar shu qiymat ichida yonma-yon turadi,
alohida oʻzgaruvchilar emas. `Stock` yozilmagan, shuning uchun `0`.

```text
p ──▶ ┌───────────────────┐
      │ ID     1          │
      │ Name   "olma"     │
      │ Price  1200000    │
      │ Stock  0          │
      └───────────────────┘   ← bitta qiymat, toʻrt maydon
```

Ikkinchi qator nuqta orqali bitta maydonga **yozadi**: `p.Stock = 40`, qolgan uch maydon oʻzgarmaydi. Keyin `q := p`: `:=` yangi
oʻzgaruvchi eʼlon qiladi (GB-1.02). Soʻng `q`ning `Stock`i `0` ga oʻzgaradi. Ekranga qaysi ikki son chiqadi?

**A)** `0 0` · **B)** `40 0` · **C)** `40 40`

<details>
<summary>Javob</summary>

**B: `40 0`.** `q := p` struct'ni **butunligicha nusxalaydi**: `q` oʻzining toʻrt maydonli, alohida qiymatini oladi. `q.Stock = 0`
faqat `q`ni oʻzgartiradi, `p`da `40` qoladi. **A** ni tanlagan boʻlsangiz, `q` va `p` bitta qiymatning ikki nomi deb oʻylagansiz:
yoʻq, nusxadan keyin ikkita qiymat bor. **C** ni tanlagan boʻlsangiz, `q.Stock = 0` yozuvi umuman ishlamadi deb oʻylagansiz: u `q`da ishladi.

</details>

Har qatordan keyin xotira:

| Qator | Kod | `p` | `q` | Ekran |
|---|---|---|---|---|
| 1 | `p := Product{ID: 1, Name: "olma", Price: 1_200_000}` | `{ID:1 Name:olma Price:1200000 Stock:0}` | — | |
| 2 | `p.Stock = 40` | `{ID:1 Name:olma Price:1200000 Stock:40}` | — | |
| 3 | `q := p` | `{… Stock:40}` | `{ID:1 Name:olma Price:1200000 Stock:40}` — **yangi** qiymat, 4 maydon nusxasi | |
| 4 | `q.Stock = 0` | `{… Stock:40}` | `{… Stock:0}` | |
| 5 | `fmt.Println(p.Stock, q.Stock)` | | | `40 0` |

```console
$ ./_video/run.sh 03-nusxa go run .
40 0
```

Funksiyaga struct argument qilib berilganda ham xuddi shunday nusxa ketadi: funksiya oʻz nusxasi bilan ishlaydi
([Go spec: Calls](https://go.dev/ref/spec#Calls), [Go FAQ: pass by value](https://go.dev/doc/faq#pass_by_value)). Bitta
mahsulotni bir nechta joydan oʻzgartirish kerak boʻlsa, pointer kerak: uni
[GB-2.04 · Pointer: nusxa yoki umumiy qiymat](/lab/youtube/gb/gb-2-04) ochadi.

**Bitta ehtiyot.** Maydon slice boʻlsa, `=` slice'ning faqat **sarlavhasini** (uzunlik, sigʻim va massivga ishora) nusxalaydi;
elementlar GB-2.01'dagidek umumiy massivda qoladi. Buni tekshiramiz: quyidagi dastur kurs papkasida **yoʻq**, alohida papkada
ishga tushirildi (`Order` bu yerda qisqartirilgan, keyingi boʻlimda toʻliq yoziladi):

```go
package main

import "fmt"

// OrderItem — buyurtmadagi bitta qator.
type OrderItem struct {
	ProductID int64
	Price     int64 // tiyin, buyurtma paytidagi narx
	Quantity  int
}

// Order — bitta buyurtma.
type Order struct {
	ID    int64
	Items []OrderItem
}

func main() {
	a := Order{ID: 1, Items: []OrderItem{{ProductID: 1, Price: 1_200_000, Quantity: 3}}}
	b := a
	b.ID = 2
	b.Items[0].Quantity = 99
	fmt.Println(a.ID, b.ID)
	fmt.Println(a.Items[0].Quantity, b.Items[0].Quantity)
}
```

```console
$ go run .
1 2
99 99
```

`ID` maydoni nusxalandi: `1 2`. Lekin `b.Items[0].Quantity = 99` `a` ni ham oʻzgartirdi, chunki `a.Items` bilan `b.Items`
bitta massivga qaraydi: `99 99`. Qoida: struct nusxalanadi, lekin uning ichidagi slice'ning elementlari nusxalanmaydi.

## Buyurtma turlari: `OrderItem` va `Order`

Buyurtmadagi har bir qator — `OrderItem`: qaysi mahsulot, qanchadan, qancha narxda.

```go
// OrderItem — buyurtmadagi bitta qator.
type OrderItem struct {
	ProductID int64
	Price     int64 // tiyin, buyurtma paytidagi narx
	Quantity  int
}
```

- `ProductID` — mahsulotning **ID**'si, mahsulotning oʻzi emas. Qatorda `Product` qiymati yoʻq, faqat unga ishora qiluvchi raqam.
- `Price` — shu **qatorning** narxi. Bu bozor'ning qarori: narx buyurtma paytida mahsulotdan nusxalanadi. Keyin mahsulot narxi
  oʻzgarsa ham, eski buyurtmaning summasi oʻzgarmaydi.
- `Quantity` — shu qatordagi dona soni.

`Order` uchta maydondan iborat:

```go
// Order — bitta buyurtma.
type Order struct {
	ID     int64
	Items  []OrderItem
	Status OrderStatus
}
```

- `ID` — buyurtmaning raqami;
- `Items` turi `[]OrderItem`: `OrderItem`lardan iborat slice (GB-2.01). Maydonning turi slice ham, boshqa struct ham boʻlishi mumkin;
- `Status` turi `OrderStatus`: uni hozir yozamiz.

`Order` `OrderStatus`dan **oldin** turibdi, lekin kod kompilyatsiya boʻladi: fayl darajasidagi eʼlonlar tartibi Go uchun muhim emas
([Go spec: Declarations and scope](https://go.dev/ref/spec#Declarations_and_scope)). Papkadagi `main.go` aynan shunday tartibda.

## Holat: `type OrderStatus int` va `iota`

Buyurtmaning toʻrt holati bor: yangi, toʻlangan, joʻnatilgan va bekor qilingan. Ularni son bilan saqlaymiz, kodda esa nom bilan
yozamiz:

```go
// OrderStatus — buyurtma holati.
type OrderStatus int

const (
	StatusNew OrderStatus = iota
	StatusPaid
	StatusShipped
	StatusCancelled
)
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1 | `// OrderStatus — buyurtma holati.` | izoh |
| 2 | `type OrderStatus int` | `int` asosidagi **yangi tur**: ichida oddiy son turadi, nomi esa bu son holat ekanini aytadi |
| 4 | `const (` | `const` va qavs (GB-1.03) bir nechta konstantani bitta blokda eʼlon qiladi |
| 5 | `StatusNew OrderStatus = iota` | `iota` — shu blok ichidagi qator raqami, **noldan** boshlanadi. `StatusNew` turi `OrderStatus`, qiymati `0` |
| 6–8 | `StatusPaid` va keyingilar | ifodasiz qatorda tur ham, `= iota` ham **takrorlanadi**, faqat `iota` 1 ga oshadi |

Natija:

| Konstanta | `iota` | Qiymat |
|---|---|---|
| `StatusNew` | 0 | `0` |
| `StatusPaid` | 1 | `1` |
| `StatusShipped` | 2 | `2` |
| `StatusCancelled` | 3 | `3` |

Bu Go qoidasi: [Go spec: Iota](https://go.dev/ref/spec#Iota) va [Constant declarations](https://go.dev/ref/spec#Constant_declarations)
(ifodasiz qator oldingisini takrorlaydi).

**`OrderStatus` — alohida tur.** `int` turidagi **oʻzgaruvchi** `OrderStatus` oʻrniga berilmaydi. Buni tekshirdik: quyidagi
dastur kurs papkasida **yoʻq**, alohida papkada ishga tushirildi.

```go
package main

import "fmt"

// OrderStatus — buyurtma holati.
type OrderStatus int

const (
	StatusNew OrderStatus = iota
	StatusPaid
	StatusShipped
	StatusCancelled
)

func main() {
	n := 1
	var s OrderStatus = n
	fmt.Println(s)
}
```

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:17:22: cannot use n (variable of type int) as OrderStatus value in variable declaration
```

Xato: 17-qator, 22-ustun, `n` (`int` turidagi oʻzgaruvchi) `OrderStatus` qiymati sifatida ishlatib boʻlmaydi. Lekin **konstanta**
berilsa, kompilyator qabul qiladi, hatto roʻyxatda yoʻq `99` ni ham. Yuqoridagi dasturning `main` funksiyasini quyidagiga almashtiring (biz shunday ishga tushirdik):

```go
func main() {
	var s OrderStatus = 99
	fmt.Println(s, s == StatusCancelled)
}
```

```console
$ go run .
99 false
```

Demak, bu tur noqonuniy holatni rad etmaydi: tur — nom va tekshirilgan oʻzgaruvchi, qiymatlar roʻyxati emas
([Go spec: Assignability](https://go.dev/ref/spec#Assignability)). Qiymatni tekshirishni keyingi darslarda oʻzimiz yozamiz.

## Hammasi birga: buyurtma yigʻamiz

Endi `main`da buyurtmani uch qadamda yigʻamiz. Bu papkadagi `main.go`: uning 1–49-qatorlari `_video/04-order/main.go` bilan bir xil. Pastdagi
ikki funksiya (`orderTotal`, `canCancel`) vazifa uchun, ularga «Uy vazifasi» boʻlimida qaytamiz:

```go filename="main.go" showLineNumbers
package main

import "fmt"

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

// OrderItem — buyurtmadagi bitta qator.
type OrderItem struct {
	ProductID int64
	Price     int64 // tiyin, buyurtma paytidagi narx
	Quantity  int
}

// Order — bitta buyurtma.
type Order struct {
	ID     int64
	Items  []OrderItem
	Status OrderStatus
}

// OrderStatus — buyurtma holati.
type OrderStatus int

const (
	StatusNew OrderStatus = iota
	StatusPaid
	StatusShipped
	StatusCancelled
)

func main() {
	p := Product{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40}
	o := Order{
		ID: 1,
		Items: []OrderItem{
			{ProductID: p.ID, Price: p.Price, Quantity: 3},
		},
	}
	fmt.Printf("%+v\n", o)

	var empty Order
	fmt.Println(empty.Status == StatusNew, len(empty.Items))
}

// orderTotal buyurtmaning jami summasini tiyinda qaytaradi: har qatorda narx × dona.
// TASK.md, 1-qadam: hozir doim 0 qaytaradi.
func orderTotal(o Order) int64 {
	return 0
}

// canCancel buyurtmani bekor qilish mumkinmi: yangi va toʻlangan — ha,
// joʻnatilgan va bekor qilingan — yoʻq. TASK.md, 2-qadam: hozir doim false.
func canCancel(o Order) bool {
	return false
}
```

Yangi qatorlar `main` ichida:

| Qator | Kod | Nima qiladi |
|---|---|---|
| 38 | `p := Product{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40}` | **birinchi qadam**: oʻsha olma, `p` oʻzgaruvchisida |
| 39–44 | `o := Order{ … }` | **ikkinchi qadam** (birinchisi — 38-qator): `Order` literal'i. `ID: 1` va `Items:` — `OrderItem` slice'ining literal'i (41–43-qatorlar). Qator yopilishidagi vergullar GB-1.08'dagidek |
| 42 | `{ProductID: p.ID, Price: p.Price, Quantity: 3},` | slice elementi. Element literal'ida tur nomi yozilmaydi: u `[]OrderItem`dan maʼlum, GB-1.08'dagi jadval qatorlari kabi. `ID` va narx `p`dan olinadi, dona soni 3 |
| — | `Status` yozilmagan | **uchinchi qadam**: zero value, ya'ni `StatusNew` (`0`) |
| 45 | `fmt.Printf("%+v\n", o)` | butun buyurtmani maydon nomlari bilan chiqaradi |
| 47 | `var empty Order` | boʻsh buyurtma, GB-1.02'dagidek `var` bilan: hamma maydon zero value'da |
| 48 | `fmt.Println(empty.Status == StatusNew, len(empty.Items))` | holati `StatusNew`ga tengmi (`==`, GB-1.05) va `Items` uzunligi nechta |

Oxirgi qator nimani chiqaradi? Boʻsh buyurtmaning holati `StatusNew`ga tengmi va `Items` uzunligi nechta? `Printf` qatorini ham
oʻzingiz taxmin qiling.

**A)** `true 0` · **B)** `false 0` · **C)** `panic` (`Items` nil boʻlgani uchun)

<details>
<summary>Javob</summary>

**A: `true 0`.** Zero value'li `Order` — yangi buyurtma, chunki `StatusNew` nolga teng. `Items` — nil slice: uzunligi `0`, panic yoʻq
([Go spec: The zero value](https://go.dev/ref/spec#The_zero_value), [Length and capacity](https://go.dev/ref/spec#Length_and_capacity)).
**B** ni tanlagan boʻlsangiz, `Status`ni «tanlanmagan» holat deb oʻylagansiz: Go'da u `0`, ya'ni roʻyxatdagi birinchi konstanta.
**C** — nil slice'ning uzunligini olish panic bermaydi; panic indeks boʻyicha oʻqishda boʻlardi (`Items[0]`).

</details>

```console
$ go run .
{ID:1 Items:[{ProductID:1 Price:1200000 Quantity:3}] Status:0}
true 0
```

Birinchi qatorda `Items` — kvadrat qavs ichida slice'ning yagona elementi, oʻz jingalak qavslari bilan. `Status:0`: `%+v` holatning
sonini yozadi; nomini chiqarish (`String()` metodi) [GB-2.05 · Metodlar: value receiver yoki pointer receiver](/lab/youtube/gb/gb-2-05)'da.
Ikkinchi qator — `true 0`. Roʻyxat ataylab shunday tartiblangan: zero value maʼnoli holat, ya'ni yangi buyurtma.

Xotira: `empty` — `Order` qiymati, uning maydonlari:

| Maydon | `empty`dagi qiymat | Sababi |
|---|---|---|
| `ID` | `0` | `int64`ning zero value'si |
| `Items` | `nil`, `len` 0 | slice'ning zero value'si |
| `Status` | `0` = `StatusNew` | `OrderStatus`ning asosi `int`, zero value `0` |

## Chuqurroq (ixtiyoriy): `iota` roʻyxatining oʻrtasiga qiymat qoʻshish

Holatlar son boʻlib saqlanadi: faylga yoki bazaga yoziladi (buni 3- va 5-modullarda qilamiz). Faraz qiling, kimdir `StatusNew`dan keyin
yangi holat qoʻshdi: `StatusReserved`, band qilingan (`_video/06-iota/main.go`):

```go
const (
	StatusNew OrderStatus = iota
	StatusReserved
	StatusPaid
	StatusShipped
	StatusCancelled
)

func main() {
	fmt.Println(StatusPaid, StatusShipped)
}
```

`StatusPaid` bilan `StatusShipped` endi nechaga teng?

**A)** `1 2`, avvalgidek · **B)** `2 3` · **C)** kompilyatsiya xatosi

<details>
<summary>Javob</summary>

**B: `2 3`.** `iota` qator raqami, shuning uchun `StatusReserved` 1 ni oldi, undan keyingi hamma konstantalar bittaga siljidi.
**A** ni tanlagan boʻlsangiz, konstanta oʻz sonini nomi bilan birga saqlaydi deb oʻylagansiz: son roʻyxatdagi oʻrnidan hisoblanadi.
**C** — kod toʻgʻri, kompilyator bu oʻzgarishni xato deb hisoblamaydi.

</details>

```console
$ ./_video/run.sh 06-iota go run .
2 3
```

Oqibat: bazada `1` deb saqlangan «toʻlangan» buyurtma endi «band qilingan» boʻlib oʻqiladi. Kompilyator ham, `go vet` ham jim.
Qoida: **saqlanadigan `iota` roʻyxatiga yangi qiymat faqat oxiriga qoʻshiladi.** Boshqa yoʻllar: har bir konstantaga sonni aniq yozish
(`StatusPaid OrderStatus = 1`) yoki bazada holatning nomini saqlash. Kurs papkasidagi `tekshiruv_test.go`da `TestHolatRaqamlari`
shu sababli `0, 1, 2, 3` raqamlarini qotirib qoʻygan: roʻyxatning oʻrtasiga qiymat qoʻshsangiz, test yiqiladi.

## Koʻp uchraydigan xatolar

**1. Maydon nomlarisiz literal.** Literal'ni nomlarsiz ham yozish mumkin: qiymatlar eʼlondagi tartibda maydonlarga tushadi. Bu
yerda uchta qiymat bor, `Stock` esa tushib qolgan (`_video/05-xato/main.go`, 14-qator):

```go
p := Product{1, "olma", 1_200_000}
```

```console
$ ./_video/run.sh 05-xato go run .
# github.com/abdurahmon27/bozor
./main.go:14:35: too few values in struct literal of type Product
```

Qanday oʻqiladi: `./main.go:14:35` — fayl, qator, ustun. 14-qator, 35-ustun — literal'ning yopuvchi `}`si. Xabar: `too few values in
struct literal of type Product`, ya'ni «`Product` turidagi struct literal'da qiymatlar juda kam». Nomsiz literal'da **hamma** maydon
tartib bilan yozilishi shart ([Go spec: Composite literals](https://go.dev/ref/spec#Composite_literals)).

Toʻrttasini yozsangiz kompilyatsiya boʻladi: `_video/05-xato/main.go`dagi 14-qatorni quyidagiga almashtiring (biz shunday ishga tushirdik):

```go
p := Product{1, "olma", 1_200_000, 40}
```

```console
$ go run .
{ID:1 Name:olma Price:1200000 Stock:40}
```

Lekin `Product`ga beshinchi maydon qoʻshilgan kuni (`Category string`) har bir shunday qator buziladi. Maydon nomli literal esa
oʻzgarmaydi: yangi maydon zero value oladi. Quyidagi dastur ikkalasini yonma-yon koʻrsatadi (kurs papkasida yoʻq):

```go
package main

import "fmt"

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID       int64
	Name     string
	Price    int64 // tiyin
	Stock    int
	Category string
}

func main() {
	p := Product{1, "olma", 1_200_000, 40}
	fmt.Printf("%+v\n", p)
	q := Product{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40}
	fmt.Printf("%+v\n", q)
}
```

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:15:39: too few values in struct literal of type Product
```

15-qator (`p := …`) buzildi, 17-qator (`q := …`) esa yaxshi. Shuning uchun maydon nomlari bilan yozing.

**2. `q := p` ikki nom emas, ikki qiymat.** Eng koʻp uchraydigan notoʻgʻri tasavvur: `q := p` dan keyin `q`ni oʻzgartirsangiz `p`
ham oʻzgaradi. Yoʻq: «Xotirada: struct bitta qiymat, `q := p` nusxa» boʻlimidagi jadvalga qarang, `40 0`. Xato bu yerda
dastur yiqilmaydi, natija shunchaki kutilganidan boshqacha. Bitta qiymatni ikki joydan oʻzgartirish kerak boʻlsa, pointer
([GB-2.04](/lab/youtube/gb/gb-2-04)) kerak. Maydon slice boʻlsa, uning elementlari nusxalanmasligini ham eslang (`99 99`).

**3. Zero value'ni «qiymat berilmagan» deb oʻqish.** Zero value'li `Stock` — `0`, «noma'lum» emas. `Stock: 0` yozilgan mahsulot bilan
`Stock` yozilmagan mahsulotni struct ajratmaydi: ikkalasida `0`. Yangi mahsulot uchun bu maʼnoli, lekin har maydon uchun shunday
emas: maydonning zero value'si sizning domeningizda maʼnoli boʻlishini oʻzingiz tekshiring. `OrderStatus`da shu uchun `StatusNew`
`0` ga qoʻyilgan.

<details>
<summary>Maslahat va javobning izohi</summary>

Maslahatlar (TASK.md'dan):

- `o.Items` — slice: `for _, it := range o.Items { … }` har bir qatorni `it`ga beradi (GB-1.08'dagi `for _, tc := range tests` kabi).
- `it.Price` — `int64`, `it.Quantity` — `int`: koʻpaytirishdan oldin `int64(it.Quantity)` deb oʻgiring (GB-1.07). Yigʻindi uchun
  `var total int64` va `+=` (GB-1.06).
- `canCancel` bitta `return` bilan yoziladi: ikkita `==` taqqoslash va `||` (GB-1.05).

Javob (`solution/main.go`, ikki funksiya):

```go
func orderTotal(o Order) int64 {
	var total int64
	for _, it := range o.Items {
		total += it.Price * int64(it.Quantity)
	}
	return total
}

func canCancel(o Order) bool {
	return o.Status == StatusNew || o.Status == StatusPaid
}
```

Izoh: `orderTotal` har qatorda narxni dona soniga koʻpaytirib `total`ga qoʻshadi. `Quantity` — `int`, `Price` — `int64`; Go turlarni
oʻzi aralashtirmaydi, shuning uchun `int64(it.Quantity)`. Qatorsiz buyurtmada sikl bajarilmaydi va `total` zero value'da, ya'ni `0` qoladi.
`canCancel` — `Status`ni ikki konstanta bilan `==` orqali solishtiradi; `||` «yoki». Zero value'li buyurtmaning `Status`i `StatusNew`, shuning
uchun `true`. Javobni papkaning oʻzidan tekshirish:

</details>
