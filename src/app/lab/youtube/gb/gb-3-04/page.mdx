## Nimani oʻrganasiz

bozor'da `go run` ikki roʻyxat chiqaradi: kam qolgan mahsulotlar va toʻlangan buyurtmalar. Ularni ajratadigan ikki funksiyaning tanasi harfma-harf bir xil, farqi faqat turda.
Uchinchi tur kelsa, uchinchi nusxa yoziladi. Tanani bir marta yozib, turni chaqiruvda tanlasak boʻladimi?

**Bitta gʻoya:** **tur parametri** — funksiyaning *tur* uchun parametri. U kvadrat qavsda, funksiya nomidan keyin va oddiy parametrlardan oldin eʼlon qilinadi: `[T any]`.
Funksiya tanasi **bir marta**, constraint boʻyicha tekshiriladi: constraint `T` qaysi tur boʻla olishini va shuning uchun tanada `T` bilan qaysi amallar mumkinligini belgilaydi.
Har chaqiruvda kompilyator `T`'ni argumentlardan chiqaradi va faqat chaqiruvni tekshiradi: tur constraint'ga mosmi, argumentlar mosmi.

Dars oxirida siz:

- ikki nusxa `filterProducts` va `filterOrders`ni bitta `Filter[T any]` bilan almashtirasiz;
- `int` va `int64` yigʻindisini bitta `Sum[N Number]` bilan yozasiz, `==` kerak boʻlsa `comparable`ni tanlaysiz;
- kompilyatorning generic xatolarini oʻqiysiz: `cannot use … as []any`, `does not match inferred type`, `operator + not defined … constrained by any`, `cannot infer E`;
- faqat metod chaqiriladigan joyda (`writeTotal`) tur parametrini olib tashlaysiz va `errors.AsType[*StockError](err)`dagi kvadrat qavsni oʻqiy olasiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| tur parametri | funksiya nomidan keyingi kvadrat qavsdagi nom (`T`): funksiya qaysi tur bilan ishlashini chaqiruv tanlaydi | type parameter |
| constraint | `T` qaysi tur boʻla olishini va unda qaysi amallar borligini belgilaydigan interface | constraint |
| type inference | kompilyator `T`'ni chaqiruvning argumentlaridan oʻzi topadi | type inference |

Yordamchi soʻzlar bor joyida bir jumlada tushuntiriladi: **generic funksiya**, **tur argumenti**, **instantiation**, **type set**, tilde `~`.

## Muammo: tanasi bir xil ikki funksiya

Bu darsning boshlangʻich dasturi — `_video/00-takror/main.go`. U toʻliq dastur; `Product`, `OrderItem`, `OrderStatus` va `Order` GB-2.03'dagi turlar.

```go filename="_video/00-takror/main.go" showLineNumbers
package main

import (
	"fmt"
)

// Product — katalogdagi bitta mahsulot (GB-2.03).
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

// OrderItem — buyurtmadagi bitta qator (GB-2.03).
type OrderItem struct {
	ProductID int64
	Price     int64 // tiyin
	Quantity  int
}

// OrderStatus — buyurtma holati (GB-2.03).
type OrderStatus int

const (
	StatusNew OrderStatus = iota
	StatusPaid
)

// Order — bitta buyurtma (GB-2.03).
type Order struct {
	ID     int64
	Items  []OrderItem
	Status OrderStatus
}

func filterProducts(ps []Product, keep func(Product) bool) []Product {
	var out []Product
	for _, p := range ps {
		if keep(p) {
			out = append(out, p)
		}
	}
	return out
}

func filterOrders(orders []Order, keep func(Order) bool) []Order {
	var out []Order
	for _, o := range orders {
		if keep(o) {
			out = append(out, o)
		}
	}
	return out
}

func main() {
	products := []Product{
		{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40},
		{ID: 2, Name: "non", Price: 400_000, Stock: 3},
		{ID: 3, Name: "choy", Price: 2_500_000, Stock: 0},
	}
	orders := []Order{
		{ID: 7, Status: StatusPaid, Items: []OrderItem{{ProductID: 1, Price: 1_200_000, Quantity: 3}}},
		{ID: 8, Status: StatusNew, Items: []OrderItem{{ProductID: 2, Price: 400_000, Quantity: 5}}},
		{ID: 9, Status: StatusPaid, Items: []OrderItem{{ProductID: 2, Price: 400_000, Quantity: 2}}},
	}

	low := filterProducts(products, func(p Product) bool { return p.Stock < 5 })
	paid := filterOrders(orders, func(o Order) bool { return o.Status == StatusPaid })
	for _, p := range low {
		fmt.Println("kam qolgan:", p.Name, p.Stock)
	}
	for _, o := range paid {
		fmt.Println("toʻlangan buyurtma:", o.ID)
	}
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1–35 | `package main`, `import`, `Product`, `OrderItem`, `OrderStatus`, `Order` | GB-2.03'dagi turlar: mahsulot, buyurtma qatori, buyurtma holati va buyurtma |
| 37 | `func filterProducts(ps []Product, keep func(Product) bool) []Product {` | birinchi parametr `ps` — mahsulotlar slice'i; ikkinchi `keep` — **funksiya** turidagi parametr: `Product` oladi, `bool` qaytaradi; natija — `[]Product` |
| 38 | `var out []Product` | `out` — nil slice (GB-2.01): hozircha hech narsa yoʻq |
| 39–41 | `for _, p := range ps { if keep(p) { out = append(out, p) } }` | har bir `p` uchun `keep(p)` chaqiriladi; `true` qaytsa, `p` `out`ga qoʻshiladi |
| 44 | `return out` | tanlangan mahsulotlar qaytadi |
| 47–55 | `func filterOrders(orders []Order, keep func(Order) bool) []Order { … }` | ikkinchi funksiya: tana yana oʻsha yetti qator, `p` oʻrnida `o` |
| 58–67 | `products := …`, `orders := …` | maʼlumot: mahsulotlar olma (40), non (3), choy (0); buyurtmalar 7 (toʻlangan), 8 (yangi), 9 (toʻlangan) |
| 69 | `low := filterProducts(products, func(p Product) bool { return p.Stock < 5 })` | `keep` oʻrniga nomsiz funksiya (GB-1.08): `p` oladi, qoldigʻi 5 dan kam boʻlsa `true` qaytaradi. Natija `low`ga yoziladi |
| 70 | `paid := filterOrders(orders, func(o Order) bool { return o.Status == StatusPaid })` | `Status` `StatusPaid` (toʻlangan) boʻlsa `true`; natija `paid`ga yoziladi |
| 71–76 | ikkita `for` sikli | `low` va `paid` elementlarini chiqaradi |

`keep func(Product) bool` GB-2.09'dagi `fn func()`dan farq qiladi: bu funksiyaning parametri ham, natijasi ham bor. Shuning uchun `keep` bilan shart chaqiruvda beriladi, tanada emas.

Dasturni ishga tushiramiz:

```console
$ ./_video/run.sh 00-takror go run .
kam qolgan: non 3
kam qolgan: choy 0
toʻlangan buyurtma: 7
toʻlangan buyurtma: 9
```

Kam qolgan mahsulotlar — `non` (3) va `choy` (0), toʻlangan buyurtmalar — 7 va 9. Endi ikki funksiyaning farqi:

| | `filterProducts` | `filterOrders` |
|---|---|---|
| 1-parametr | `ps []Product` | `orders []Order` |
| `keep` turi | `func(Product) bool` | `func(Order) bool` |
| `out` turi | `[]Product` | `[]Order` |
| sikl oʻzgaruvchisi | `p` | `o` |
| natija turi | `[]Product` | `[]Order` |
| qolgan hammasi | `var out`, `for`, `if keep`, `append`, `return` | xuddi shunday |

Farq faqat tur nomlarida. Mantiq — "elementlarni aylan, `keep` `true` qaytarganini yigʻ" — turga umuman bogʻliq emas. Uchinchi tur (masalan `Customer`) kelsa, yana bir nusxa kerak boʻladi.

Go jamoasidan Ian Lance Taylor shu holatni sanab oʻtadi: bir xil kod koʻp marta yoziladi va nusxalar faqat ishlatadigan turi bilan farq qiladi. Bunda tur parametri haqida oʻylash kerak.
Hozir esa avval oddiy yechimni sinaymiz.

## Birinchi urinish: `any` bilan bitta funksiya

GB-2.07'dan bilasiz: `any` — metodsiz interface, unga istalgan qiymat sigʻadi. Demak `[]any` oladigan bitta funksiya yozsak boʻladimi? Uning tanasi oʻsha (`_video/01-any/main.go`):

```go
func filterAny(items []any, keep func(any) bool) []any {
	var out []any
	for _, x := range items {
		if keep(x) {
			out = append(out, x)
		}
	}
	return out
}
```

Chaqiruvda `keep` ichida qiymatni yana `Product` qilib olish kerak: `x.(Product)` — GB-2.07'dagi type assertion, u interface ichidagi `Product`ni qaytaradi.

```go
low := filterAny(products, func(x any) bool { return x.(Product).Stock < 5 })
```

`Product` `any`ga sigʻadi. `[]Product` slice'i `[]any` slice'iga sigʻadimi? `go build` nima deydi?

**A)** build boʻladi · **B)** kompilyatsiya xatosi · **C)** build boʻladi, keyin `panic`

<details>
<summary>Javob</summary>

**B: kompilyatsiya xatosi.** `products`ning turi `[]Product`, parametr esa `[]any`; Go bunday slice'ni oʻzi aylantirmaydi. **A** ni tanlagan boʻlsangiz, `Product` `any`ga sigʻgani uchun slice ham sigʻadi deb oʻylagansiz.
**C** ni tanlagan boʻlsangiz, xatoni dastur ishlayotganda kutgansiz: bu xato dastur ishga tushmasdan topiladi.

```console
$ ./_video/run.sh 01-any go build
# github.com/abdurahmon27/bozor
./main.go:59:19: cannot use products (variable of type []Product) as []any value in argument to filterAny
```

</details>

Xabarni oʻqing. `./main.go:59:19` — fayl, 59-qator, 19-ustun: `products` argumenti. `cannot use products (variable of type []Product) as []any value in argument to filterAny` —
"`products`ni (turi `[]Product`) `filterAny` argumentida `[]any` qiymati sifatida ishlatib boʻlmaydi". Birinchi qator `# github.com/abdurahmon27/bozor` — modul nomi.

Nega? Sabab xotirada. Oʻlchamni `unsafe.Sizeof` bilan oʻlchaymiz (`_video/01b-olcham/main.go`; `main`ning ichi shu qator):

```go
fmt.Println(unsafe.Sizeof(Product{}), unsafe.Sizeof(any(nil)))
```

```console
$ ./_video/run.sh 01b-olcham go run .
40 16
```

`Product` — **40 bayt**, `any` (interface qiymati, GB-2.07) — **16 bayt**: tur va qiymatga koʻrsatkich. Shu platformada (`linux/amd64`) shunday.

```text
[]Product  (3 element):  | Product: 40 bayt | Product: 40 bayt | Product: 40 bayt |   struct'ning oʻzi, yonma-yon
[]any      (3 element):  | tur + qiymat: 16 | tur + qiymat: 16 | tur + qiymat: 16 |   har biri — koʻrsatkichlar
```

Ikki slice'ning elementlari xotirada boshqacha turadi, shuning uchun bittasini ikkinchisi oʻrnida berib boʻlmaydi. Boshqa yoʻl — har elementni yangi `[]any` slice'iga nusxalash. Keyin:

| Qadam | Nima boʻladi |
|---|---|
| 1 | `[]Product` → yangi `[]any`: har element nusxalanadi |
| 2 | `filterAny` `[]any` qaytaradi |
| 3 | har safar `x.(Product)` bilan turni tiklash kerak |
| 4 | tur adashsa, assertion ishlab turgan dasturni `panic` bilan toʻxtatadi ([Go spec](https://go.dev/ref/spec#Type_assertions)) |

Natijada kod uzunroq va xavfliroq boʻladi, tur xatosi esa kompilyatsiyada emas, ishlayotganda chiqadi. Bu Go FAQ'da ham yozilgan: bu ikki tur xotirada bir xil koʻrinishga ega emas.

## Tur parametri: bitta `Filter`

Go'ning yechimi — **tur parametri** (type parameter). U funksiya nomidan keyin, oddiy parametrlardan oldin, kvadrat qavsda eʼlon qilinadi. Tur parametrli funksiya **generic funksiya** deyiladi (`_video/02-filter/main.go`):

```go
func Filter[T any](items []T, keep func(T) bool) []T {
	var out []T
	for _, x := range items {
		if keep(x) {
			out = append(out, x)
		}
	}
	return out
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1 | `[T any]` | tur parametrlari roʻyxati: `T` — tur uchun nom, uni chaqiruvchi tanlaydi. `T`'dan keyingi `any` — constraint: `T` qanday tur boʻla olishini aytadi; `any` — istalgan tur |
| 1 | `items []T`, `keep func(T) bool`, `[]T` | `T` oddiy tur kabi ishlatiladi: `items` — `T` slice'i, `keep` — `T` oladigan funksiya, natija — `T` slice'i |
| 2 | `var out []T` | `out` ham `T` slice'i, nil |
| 3–5 | `for _, x := range items { if keep(x) { out = append(out, x) } }` | `x` — har bir element (turi `T`); `true` qaytsa, `out`ga qoʻshiladi |
| 8 | `return out` | `[]T` qaytadi |

`Filter` — `filterProducts` va `filterOrders` oʻrniga bitta tana. Endi `main`dagi chaqiruvlar (`T`'ni yozmaymiz):

```go
low := Filter(products, func(p Product) bool { return p.Stock < 5 })
paid := Filter(orders, func(o Order) bool { return o.Status == StatusPaid })
```

`T`'ni yozmadik: kompilyator uni argumentlardan chiqaradi. Bu **type inference** — turni chiqarib olish.

| Chaqiruv | Birinchi argument | Kompilyator xulosasi | `keep` turi shu boʻladi |
|---|---|---|---|
| `Filter(products, …)` | `[]Product` | `T = Product` | `func(Product) bool` |
| `Filter(orders, …)` | `[]Order` | `T = Order` | `func(Order) bool` |

Ikki funksiya oʻrniga bitta. Natija hook'dagi bilan bir xil boʻlishi kerak:

```console
$ ./_video/run.sh 02-filter go run .
kam qolgan: non 3
kam qolgan: choy 0
toʻlangan buyurtma: 7
toʻlangan buyurtma: 9
```

Endi notoʻgʻri chaqiruv: `Filter`ga `orders` beriladi, `keep` esa `Product` oladigan funksiya (`_video/04-mos-emas/main.go`):

```go
low := Filter(orders, func(p Product) bool { return p.Stock < 5 })
```

Nima boʻladi?

**A)** ishlaydi: boʻsh slice qaytadi · **B)** kompilyatsiya xatosi · **C)** ishga tushganda `panic`

<details>
<summary>Javob</summary>

**B: kompilyatsiya xatosi.** Kompilyator `T`'ni birinchi argumentdan `Order` deb chiqardi. Demak `keep` `Order` oladigan funksiya boʻlishi kerak edi, keldi esa `Product` oladigani.
**A** ni tanlagan boʻlsangiz, Go turlarni "yetarlicha oʻxshash" deb qabul qiladi deb oʻylagansiz. **C** ni tanlagan boʻlsangiz, xato ishlayotganda chiqadi deb oʻylagansiz: generic tur xatosi dastur ishga tushmasdan topiladi.

```console
$ ./_video/run.sh 04-mos-emas go build
# github.com/abdurahmon27/bozor
./main.go:59:24: in call to Filter, type func(p Product) bool of func(p Product) bool {…} does not match inferred type func(Order) bool for func(T) bool
```

</details>

Xabarni oʻqing: `in call to Filter` — xato `Filter` chaqiruvida; `type func(p Product) bool of func(p Product) bool {…}` — berilgan argumentning turi (`{…}` — kompilyator funksiya tanasini shunday qisqartiradi);
`does not match inferred type func(Order) bool for func(T) bool` — "`func(T) bool` uchun chiqarilgan tur `func(Order) bool`ga mos kelmaydi". Xato dastur ishga tushmasdan topildi.

`T`'ni oʻzimiz ham yozsak boʻladi: kvadrat qavsda (`_video/03-tur/main.go`; `main`ning ichi):

```go
fmt.Printf("%T\n", Filter[Product])
fmt.Printf("%T\n", Filter[Order])
```

Bu yerda `Product` — **tur argumenti** (type argument): `T`'ning oʻrniga qoʻyiladigan aniq tur. `%T` qiymatning turini chiqaradi (GB-2.08).

```console
$ ./_video/run.sh 03-tur go run .
func([]main.Product, func(main.Product) bool) []main.Product
func([]main.Order, func(main.Order) bool) []main.Order
```

`main.Product` — `main` paketidagi `Product`. Natija oddiy funksiya turi: `[]Product` va funksiya oladi, `[]Product` qaytaradi. `T` oʻrniga tur argumentini qoʻyish **instantiation** deyiladi.
Kvadrat qavssiz `Filter`ni `Printf`ga berib boʻlmaydi: `T`'ni chiqaradigan joy yoʻq. Bu misol kurs papkasida yoʻq: `_video/03-tur/main.go`ning `main`ida birinchi `Filter[Product]`ni `Filter` qilib oʻzgartirdim, qolgan hamma narsa oʻsha.

```go
fmt.Printf("%T\n", Filter)
fmt.Printf("%T\n", Filter[Order])
```

```console
$ go build
# github.com/abdurahmon27/bozor
./main.go:48:12: in call to fmt.Printf, cannot infer T (declared at ./main.go:37:13)
```

`cannot infer T` — "`T`'ni chiqarib boʻlmadi"; qavs ichida `T` eʼlon qilingan joy koʻrsatilgan: 37-qator, 13-ustun, yaʼni `Filter`dagi `[T any]`.

## Constraint: tur bilan qaysi amallar mumkin

Ikkinchi nusxa: yigʻindi. Qoldiqlar `int`, summalar `int64`; ikkalasiga bitta `Sum` yozmoqchimiz. Tur parametri `N`, constraint yana `any` (`_video/05-sum-any/main.go`):

```go
func Sum[N any](nums []N) N {
	var total N
	for _, n := range nums {
		total += n
	}
	return total
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1 | `func Sum[N any](nums []N) N` | `N` — tur parametri; `nums` — `N` turidagi sonlar slice'i; natija ham `N` |
| 2 | `var total N` | `N` turidagi oʻzgaruvchi, boshida nol qiymat (zero value) |
| 3–5 | `for _, n := range nums { total += n }` | har bir `n` `total`ga qoʻshiladi |
| 6 | `return total` | yigʻindi qaytadi |

Hozircha `Sum` faqat `int` va `int64` bilan chaqiriladi: `Sum([]int{…})`, `Sum([]int64{…})`. Bu kod kompilyatsiya boʻladimi?

**A)** ha, ikkala tur bilan ishlaydi · **B)** yoʻq: `+` `N` uchun aniqlanmagan · **C)** faqat `string` bilan xato

<details>
<summary>Javob</summary>

**B.** Generic funksiya tanasi chaqiruvlarga qarab emas, **bir marta** tekshiriladi. Kompilyator tanada `N` haqida faqat constraint aytganini biladi — bu yerda `any`. `any`'ga `struct` ham, `bool` ham kiradi, ularda `+` yoʻq.
**A** ni tanlagan boʻlsangiz, kompilyator `Sum`ni chaqiruvdagi `int` bilan tekshiradi deb oʻylagansiz. **C** ni tanlagan boʻlsangiz, faqat chaqiruvdagi turni kutgansiz: xato chaqiruvga emas, tanaga qarshi.

```console
$ ./_video/run.sh 05-sum-any go build
# github.com/abdurahmon27/bozor
./main.go:40:3: invalid operation: operator + not defined on total (variable of type N constrained by any)
```

</details>

Xabar: `./main.go:40:3` — 40-qator (`total += n`); `operator + not defined on total` — "`+` amali `total` uchun aniqlanmagan"; `(variable of type N constrained by any)` —
"`total` — `N` turidagi oʻzgaruvchi, `N`'ning constraint'i `any`". **Qoida:** tana faqat constraint'dagi **hamma** turlarda mavjud amallarni ishlata oladi. Constraint ruxsat bergan turlar toʻplami **type set** deyiladi; `any`'ning type set'i — hamma tur.
Bu tez-tez uchraydigan xato.

Tuzatish: constraint'ni oʻzimiz yozamiz (`_video/06-sum/main.go`). `Number` ham interface, lekin metodlar oʻrnida **turlar roʻyxati**. Tik chiziq `|` "yoki" degani:

```go
type Number interface {
	int | int64
}

func Sum[N Number](nums []N) N {
```

`N` endi faqat `int` yoki `int64` boʻla oladi; ikkalasida `+` bor, kompilyator rozi. Tana oʻsha, faqat `Sum`ning birinchi qatori oʻzgardi. Bunday interface faqat constraint boʻla oladi, oʻzgaruvchining turi boʻla olmaydi ([Go spec](https://go.dev/ref/spec#General_interfaces)).
`main`da ikki chaqiruv:

```go
fmt.Println(Sum([]int{40, 3, 0}), Sum([]int64{3_600_000, 800_000}))
```

```console
$ ./_video/run.sh 06-sum go run .

```

| Chaqiruv | `N` | Hisob | Natija |
|---|---|---|---|
| `Sum([]int{40, 3, 0})` | `int` | 40 + 3 + 0 | `43` |
| `Sum([]int64{3_600_000, 800_000})` | `int64` | 3 600 000 + 800 000 | `4400000` (tiyin) |

Oraliq savol. `Contains` slice'da `x` bormi, tekshiradi: har bir `v`ni `x` bilan `==` bilan solishtiradi. Constraint `any`. `go build` nima deydi? (`_video/07-contains/main.go`)

```go
func Contains[T any](items []T, x T) bool {
	for _, v := range items {
		if v == x {
			return true
		}
	}
	return false
}
```

**A)** build boʻladi · **B)** kompilyatsiya xatosi · **C)** faqat `string` bilan ishlaydi

<details>
<summary>Javob</summary>

**B.** `==` hamma turda yoʻq: slice, map va funksiyani `==` bilan solishtirib boʻlmaydi ([Go spec](https://go.dev/ref/spec#Comparison_operators)), `any`'ning type set'ida esa ular ham bor. Xuddi `Sum`dagi qoida: tana hamma turda bor amalni ishlatishi kerak.
**A** ni tanlagan boʻlsangiz, `==` har qanday turda ishlaydi deb oʻylagansiz. **C** ni tanlagan boʻlsangiz, xato chaqiruvga emas, tanaga qaratilganini oʻtkazib yuborgansiz.

```console

./main.go:39:6: invalid operation: v == x (incomparable types in type set)
```

</details>

`incomparable types in type set` — "type set'da solishtirib boʻlmaydigan turlar bor". Tuzatish — Go'da oldindan eʼlon qilingan constraint: **`comparable`**, yaʼni `==` bilan solishtiriladigan turlar (`_video/07b-comparable/main.go`):

```go

```

```console
$ go doc slices.Contains | head -4
package slices // import "slices"
```

## Tur parametri kerak boʻlmagan joy: faqat metod chaqirilsa

Endi teskari holat. Jamoadosh `writeTotal`ni generic qilib yozgan (`_video/08-writer/main.go`):

```go
func writeTotal[W io.Writer](w W, total int64) error {
	_, err := fmt.Fprintf(w, "jami: %d tiyin\n", total)
	return err
}
```

Bu yerda `W` — tur parametri, constraint'i `io.Writer`: metodli oddiy interface ham constraint boʻla oladi, `W`'da `Write` metodi boʻlishi shart. `total` — yoziladigan summa. `main` uni shunday chaqiradi:

```go
if err := writeTotal(os.Stdout, 4_400_000); err != nil { … }
```

```console
$ ./_video/run.sh 08-writer go run .
jami: 4400000 tiyin
```

Dastur toʻgʻri ishlaydi. Lekin `W` imzoda **bir marta** uchraydi: faqat `w`'ning turi sifatida. U boshqa hech qanday turni bogʻlamaydi. Funksiya `w` bilan bitta ish qiladi — `Write` metodini chaqiradi (`Fprintf` orqali).
Buning uchun GB-2.07'dagi oddiy `io.Writer` parametri yetadi (`_video/08b-writer/main.go`):

```go
func writeTotal(w io.Writer, total int64) error {
```

Tana oʻsha, `[W io.Writer]` yoʻq, `w W` oʻrnida `w io.Writer`.

```console
$ ./_video/run.sh 08b-writer go run .
jami: 4400000 tiyin
```

Natija harfma-harf oʻsha, kod esa sodda. Taylor'ning qoidalari ([When To Use Generics](https://go.dev/blog/when-generics)):

| Holat | Nima oling |
|---|---|
| bir xil kod faqat turi boshqa holda takrorlanadi | tur parametri (`Filter`, `Sum`) |
| qiymat bilan faqat metod chaqiriladi | interface (`io.Writer`) |
| `T` kirish va chiqish turini bogʻlaydi | tur parametri: `Filter[T]`da `[]T` kiradi, `[]T` chiqadi; `T` olib tashlansa, natija turi (`[]Product`) yoʻqoladi |
| metodning bajarilishi har tur uchun boshqa | har turga oʻz metodi, chaqiruv interface orqali |

Taylor'ning oʻz misoli: `func ReadSome[T io.Reader](r T) ([]byte, error)` oʻrniga `func ReadSome(r io.Reader) ([]byte, error)` yozing. U shunday deydi: *"Omitting the type parameter makes the function easier to write, easier to read, and the execution time will likely be the same."*
Tezlik uchun interface'ni tur parametriga almashtirmang. Kod review'da shu qoidalarga tayaning.

## `errors.AsType`dagi kvadrat qavsni oʻqiymiz

GB-2.08'da `errors.AsType`dagi kvadrat qavsni shu darsga qoldirgan edik. Endi uning eʼlonini oʻqiy olamiz (`| head -4` chiqishni birinchi 4 qatorda kesadi):

```console
$ go doc errors.AsType | head -4
package errors // import "errors"

func AsType[E error](err error) (E, bool)
    AsType finds the first error in err's tree that matches the type E, and if
```

`func AsType[E error](err error) (E, bool)`: `E` — tur parametri, constraint'i `error`, yaʼni `E`'da `Error()` metodi boʻlishi shart. Oddiy parametr bitta: `err`, turi `error`. `E` esa faqat **natijada** uchraydi: topilgan xato va `bool`.

Kvadrat qavsni yozmasak-chi? `err` bor, kompilyator `Filter`dagidek turni oʻzi chiqara oladimi? Kodning ikki qatori (`_video/09-astype/main.go`; `err` ichida `*StockError`):

```go
err := fmt.Errorf("buyurtma 7: %w", &StockError{Name: "olma", Stock: 40, Want: 41})
if se, ok := errors.AsType(err); ok {
```

**A)** `E = error` boʻladi · **B)** xato: `E` aniqlanmaydi · **C)** `E = *StockError` topiladi

<details>
<summary>Javob</summary>

**B.** Chaqiruvda `E` faqat argumentlar turidan chiqadi; natija qaysi oʻzgaruvchiga yozilishi hisobga olinmaydi. `err`ning turi `error`, unda `E` yoʻq.
**A** ni tanlagan boʻlsangiz, kompilyator `error`ni `E` oʻrniga qoʻyadi deb oʻylagansiz: `error` — argumentning turi, `E` esa undan chiqarilmaydi. **C** ni tanlagan boʻlsangiz, kompilyator `err` ichidagi `*StockError`ni koʻradi deb oʻylagansiz: `err`ning turi `error`, ichidagisi esa dastur ishlayotganda maʼlum boʻladi.

```console
$ ./_video/run.sh 09-astype go build
# github.com/abdurahmon27/bozor
./main.go:51:28: in call to errors.AsType, cannot infer E (declared at $GOROOT/src/errors/wrap.go:167:13)
```

</details>

`cannot infer E` — "`E`'ni chiqarib boʻlmadi". Qavs ichida `E` eʼlon qilingan joy koʻrsatilgan; `$GOROOT` — Go oʻrnatilgan papka. Shuning uchun turni oʻzimiz yozamiz (`_video/10-astype-ok/main.go`):

```go
if se, ok := errors.AsType[*StockError](err); ok {
	fmt.Printf("%T %s %d\n", se, se.Name, se.Stock)
}
```

```console
$ ./_video/run.sh 10-astype-ok go run .
*main.StockError olma 40
```

Kvadrat qavsdagi `*StockError` — **tur argumenti**, `E` esa tur parametri. GB-2.08'da buni "tur parametri" degan edik; toʻgʻrisi — tur argumenti. Bu labda `StockError` `main` paketida, shuning uchun `%T` `*main.StockError` chiqaradi.
`se`ning turi `*StockError` boʻlgani uchun uning maydonlari (`se.Name`, `se.Stock`) toʻgʻridan-toʻgʻri oʻqiladi.

## Chuqurroq (ixtiyoriy): `~int64` va `type Tiyin int64`

Pul uchun alohida tur yozamiz: `type Tiyin int64` — `int64` **asosiy tur**i (underlying type) boʻlgan yangi tur, `OrderStatus` kabi (GB-2.03). Faqat misol: bozor'da pul oddiy `int64` qoladi.
`Sum`ga `Tiyin` slice'ini bersak (`_video/11-tilde/main.go`):

```go
type Tiyin int64
```

```go
fmt.Println(Sum([]Tiyin{1_200_000, 400_000}))
```

```console
$ ./_video/run.sh 11-tilde go build
# github.com/abdurahmon27/bozor
./main.go:53:17: Tiyin does not satisfy Number (possibly missing ~ for int64 in Number)
```

`Tiyin does not satisfy Number` — "`Tiyin` `Number`ni qanoatlantirmaydi". Maslahat: `possibly missing ~ for int64 in Number` — "`Number`da `int64` oldida `~` yetishmayotgan boʻlishi mumkin".
`int | int64` roʻyxatida aynan `int64` bor, `Tiyin` esa boshqa tur. Tuzatish — tilde (`_video/12-tilde-ok/main.go`):

```go
type Number interface {
	~int | ~int64
}
```

`~int64` — bitta tur emas, asosiy turi `int64` boʻlgan **hamma** turlar; `~int` — asosiy turi `int` boʻlganlar.

```console
$ ./_video/run.sh 12-tilde-ok go run .
1600000
```

`1 200 000 + 400 000 = 1 600 000`. `slices` paketining eʼlonlarida tilde koʻp uchraydi, masalan:

```console
$ go doc slices.Clone | head -4
package slices // import "slices"

func Clone[S ~[]E, E any](s S) S
    Clone returns a copy of the slice. The elements are copied using assignment,
```

Generics tilda Go 1.18'dan beri bor ([Go 1.18 release notes](https://go.dev/doc/go1.18#generics)).

## Koʻp uchraydigan xatolar

Hammasi bu sahifada koʻrilgan; bu yerda qisqacha, tuzatishi bilan.

**1. "`any` — istalgan tur, demak tanada istalgan amal ishlaydi."** Yoʻq: tana faqat constraint'dagi **hamma** turlarda bor amalni ishlata oladi (qarang: "Constraint" boʻlimi).
`Sum[N any]`da `total += n` → `operator + not defined on total (variable of type N constrained by any)`. Tuzatish: constraint'ni toraytiring (`Number`). `==` kerak boʻlsa — `comparable`.

**2. `[]Product`ni `[]any` parametriga berish.** Xotirada ikki slice boshqacha (40 va 16 bayt), shuning uchun `cannot use products (variable of type []Product) as []any value`. Tuzatish: `any` oʻrniga tur parametri (`Filter[T any]`).

**3. `errors.AsType(err)`ni kvadrat qavssiz yozish.** `E` faqat natijada, argumentlardan chiqarib boʻlmaydi: `cannot infer E`. Tuzatish: `errors.AsType[*StockError](err)`.

**4. Roʻyxatda yoʻq tur.** `Number` faqat `int | int64`: `float64` yoki `Tiyin` bersangiz `does not satisfy Number`. `Tiyin` uchun — `~int64` (chuqurroq boʻlim); `float64` uchun — constraint'ga `float64` qoʻshish.

**5. Argumentlar bir-biriga mos kelmaydi.** `Filter(orders, func(p Product) bool {…})` → `does not match inferred type func(Order) bool for func(T) bool`: `T` birinchi argumentdan chiqdi, `keep` shunga mos boʻlishi kerak.

**6. Hamma joyga tur parametri qoʻyish.** `writeTotal[W io.Writer](w W, …)` ishlaydi, lekin `W` hech narsani bogʻlamaydi: `w io.Writer` yetadi va kod soddaroq (qarang: "Tur parametri kerak boʻlmagan joy" boʻlimi).

```go
func SumBy[T any, N Number](items []T, value func(T) N) N {

	for _, x := range items {

	}
	return total
}
```

Tana `Sum`nikiga oʻxshash: `n` oʻrnida `value(x)`.

**2-qadam.**

```go
func paidTotal(orders []Order) int64 {

}
```

`Filter`da `T = Order` (`orders`dan). `SumBy`da `T = Order` (`paid`dan), `N = int64` — `value` funksiyasining natijasidan. Ikkalasi ham type inference.
