## Nimani oʻrganasiz

bozor'ning kodi hozir bitta `main.go` faylida: `st` degan katalog, uning `Add` metodi va ichidagi `products` slice'i. `main` shu
slice'ga toʻgʻridan-toʻgʻri yozib, olmaning qoldigʻini minus beshga tushirdi. Kompilyator jim:

```go
func main() {
	var st Store
	st.Add("olma", 1_200_000, 40)
	st.products[0].Stock = -5
	fmt.Println(st.products[0].Stock)
}
```

```console
$ ./_video/run.sh 00-birfayl go run .

```

Katalog qoidasi («qoldiq manfiy boʻlmasin») `Store`ning metodlarida yozilishi kerak. Lekin `products` hammaga ochiq, shuning uchun
istalgan qator qoidani chetlab oʻtadi. Kodni paketlarga boʻlsak, kompilyatorning oʻzi shu yoʻlni yopadi. Qanday, va yana qaysi teshik qoladi?

**Bitta gʻoya:** Go'da paket — bitta papkadagi fayllar, import yoʻli esa modul nomi plyus papka. Paket chegarasidan faqat katta
harf bilan boshlangan nomlar oʻtadi, `internal/` papkasi esa paketni import qila oladiganlar doirasini modulning oʻzi bilan
cheklaydi. Shu chegara qoidani chetlab oʻtib boʻlmaydigan qiladi.

Dars oxirida siz:

- bitta `main.go`'ni `cmd/bozor` (dastur) va `internal/store` (katalog) paketlariga boʻlib, `go run ./cmd/bozor` bilan ishga tushirasiz;
- `unexported` xatosini oʻqiysiz va boshqa paketdagi nomga katta harf bilan murojaat qilasiz;
- tashqi modulni `go mod tidy` bilan qoʻshasiz va `go.sum` nimani tekshirishini bilasiz;
- `internal/` xatosini oʻqiysiz va bu papka kimga import qilishga ruxsat berishini aytasiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| paket | bitta papkadagi Go fayllar toʻplami; har bir fayl `package` qatori bilan boshlanadi va bir papkada hamma fayl bir xil nom yozadi | package |
| export qilingan nom | katta harf bilan boshlangan nom: boshqa paketlarga koʻrinadi. Kichik harfli nom faqat oʻz paketida koʻrinadi | exported / unexported |
| `internal/` papkasi | ichidagi paketni faqat shu papkaning ota papkasi ostidagi kod import qila oladi | internal directory |

Ikkita yordamchi tushuncha: **import yoʻli** (paketning toʻliq nomi) va **tashqi modul** bilan `go.sum` fayli.

## Muammo: katalogning qoidasi bitta joyda emas

Darsning boshidagi dastur (`_video/00-birfayl/main.go`): bozor'ning katalogi va `main`, hammasi bitta faylda.

```go filename="_video/00-birfayl/main.go" showLineNumbers
package main

import "fmt"

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

// Store — xotiradagi katalog.
type Store struct {
	products []Product
}

// Add katalogga mahsulot qoʻshadi va unga ID beradi.
func (s *Store) Add(name string, price int64, stock int) Product {
	p := Product{ID: int64(len(s.products)) + 1, Name: name, Price: price, Stock: stock}
	s.products = append(s.products, p)
	return p
}

// List katalogdagi mahsulotlarni qaytaradi.
func (s *Store) List() []Product {
	return s.products
}

func main() {
	var st Store
	st.Add("olma", 1_200_000, 40)
	st.products[0].Stock = -5
	fmt.Println(st.products[0].Stock)
}
```

5–11-qatorlar GB-2.03'dagi `Product` turi. Yangi qatorlar:

| Qator | Kod | Nima qiladi |
|---|---|---|
| 14–16 | `type Store struct { products []Product }` | `Store` — katalog turi. Uning bitta maydoni bor: `products`, `Product`'lar slice'i |
| 19 | `func (s *Store) Add(name string, price int64, stock int) Product {` | `Add` — `Store`ning metodi. Receiver pointer: `*Store`, chunki metod katalogni oʻzgartiradi (GB-2.05). Natijasi — qoʻshilgan `Product` |
| 20 | `p := Product{ID: int64(len(s.products)) + 1, …}` | yangi mahsulotning `ID`'si slice uzunligi plyus bir: 1, 2, 3. Qolgan maydonlar parametrlardan |
| 21 | `s.products = append(s.products, p)` | mahsulotni slice'ga qoʻshadi; `append` natijasini qaytadan `s.products`ga yozish kerak (GB-2.01) |
| 22 | `return p` | qoʻshilgan mahsulotning **nusxasini** qaytaradi |
| 26–28 | `func (s *Store) List() []Product { return s.products }` | yangi metod: katalogdagi mahsulotlarni qaytaradi |
| 31 | `var st Store` | boʻsh katalog: `products` — nil slice. `append` nil slice'ga ham ishlaydi, shuning uchun `Add` darrov ishlaydi |
| 32 | `st.Add("olma", 1_200_000, 40)` | olma (narxi 1 200 000 tiyin, qoldigʻi 40) katalogda birinchi mahsulot, `ID` 1 |
| 33 | `st.products[0].Stock = -5` | `main` katalogning ichki slice'iga toʻgʻridan-toʻgʻri yozadi: birinchi mahsulotning qoldigʻi −5 |
| 34 | `fmt.Println(st.products[0].Stock)` | shu qoldiqni chiqaradi |

Kompilyator jim: bitta faylda `main` va `Store` bir-birining hamma nomini koʻradi. Qoldiq qoidasini `Add` va keyingi metodlarga
yozsangiz ham, 33-qator ularni aylanib oʻtadi.

| Qadam | `st.products[0].Stock` | Ekranda |
|---|---|---|
| `st.Add("olma", …, 40)` (32-qator) | 40 | |
| `st.products[0].Stock = -5` (33-qator) | **−5** | |
| `fmt.Println(…)` (34-qator) | −5 | `-5` |

## Paket: bitta papkadagi fayllar

Go'da **paket** (package) — bitta papkadagi Go fayllar. Har bir faylning birinchi kod qatori — `package` va paket nomi; bir
papkadagi hamma fayl bir xil nom yozadi. Bu qoida Go spetsifikatsiyasida: bir xil paket nomli fayllar toʻplami shu paketning
amalga oshirilishini hosil qiladi ([Go spec: Package clause](https://go.dev/ref/spec#Package_clause)).

Ikki xil paket bor:

- `package main` — ishga tushadigan dastur. Uni `go run` va `go build` ishga tushiradi (GB-1.01).
- boshqa nom (`store`, `fmt`) — boshqa kod `import` qiladigan paket. `fmt` ham shunday paket: uning fayllari Go'ning oʻz
  kutubxonasidagi `fmt` papkasida.

bozor'ni quyidagicha boʻlamiz:

```text
bozor/
├── go.mod
├── cmd/
│   └── bozor/
│       └── main.go        package main
└── internal/
    └── store/
        └── store.go       package store
```

- `cmd/bozor/main.go` — dastur (`package main`). `cmd/` ichida har bir dastur oʻz papkasida; kursning 4-modulida bozor'ning
  yonida ikkinchi dastur paydo boʻladi.
- `internal/store/store.go` — katalog, paket nomi `store`. `internal` soʻzining maʼnosini shu darsning oxirida ochamiz.
- `go.mod` ildizda, modul nomi bilan (GB-1.01).

Papkalarni yaratamiz. Hozirgi papkada `go.mod` va `main.go` bor:

```console
$ mkdir -p cmd/bozor internal/store
$ mv main.go cmd/bozor/
```

Ikkala buyruq hech narsa chiqarmaydi. `mkdir -p` ikki yoʻlni birdan yaratadi: `-p` oraliq papkalarni (`cmd`, `internal`) ham
ochadi va papka allaqachon bor boʻlsa xato bermaydi. `mv main.go cmd/bozor/` `main.go`'ni `cmd/bozor` ichiga koʻchiradi. Keyin
`Product`, `Store` va ularning metodlarini yangi `store.go` fayliga olib oʻtamiz.

`internal/store/store.go`:

```go filename="_video/01-paket/internal/store/store.go" showLineNumbers
package store

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

// Store — xotiradagi katalog.
type Store struct {
	products []Product
}

// Add katalogga mahsulot qoʻshadi va unga ID beradi.
func (s *Store) Add(name string, price int64, stock int) Product {
	p := Product{ID: int64(len(s.products)) + 1, Name: name, Price: price, Stock: stock}
	s.products = append(s.products, p)
	return p
}

// List katalogdagi mahsulotlarni qaytaradi.
func (s *Store) List() []Product {
	return s.products
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1 | `package store` | fayl `store` paketiga kiradi. Paket nomi papka nomi bilan bir xil: kompilyator buni talab qilmaydi, lekin Go'da odat shunday ([Effective Go: Package names](https://go.dev/doc/effective_go#package-names)) |
| 3–9, 12–14, 17–21 | `Product`, `Store`, `Add` | tanalari 00-birfayl'dagidek, oʻzgarmagan |
| 24–26 | `func (s *Store) List() []Product` | `List` yangi emas: u 00-birfayl'da ham bor edi. U katalogdagi mahsulotlarni qaytaradi |

Endi `cmd/bozor/main.go`. Uning `import` qismiga ikkinchi qator qoʻshiladi:

```go filename="_video/01-paket/cmd/bozor/main.go" showLineNumbers
package main

import (
	"fmt"

	"github.com/abdurahmon27/bozor/internal/store"
)

func main() {
	var st store.Store
	st.Add("olma", 1_200_000, 40)
	st.Add("non", 400_000, 100)
	for _, p := range st.List() {
		fmt.Println(p.ID, p.Name, p.Price)
	}
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 3–7 | `import ( … )` | ikki paketni import qiladi (GB-1.07). Standart paket (`fmt`) alohida guruhda, bizniki boshqa guruhda: oradagi boʻsh qator shuning uchun |
| 6 | `"github.com/abdurahmon27/bozor/internal/store"` | `store` paketining **import yoʻli** |
| 10 | `var st store.Store` | boshqa paketdagi nomga paket nomi va nuqta orqali murojaat qilinadi: `store.Store`, xuddi `fmt.Println`. `st` — boʻsh katalog |
| 11–12 | `st.Add(…)` | ikki mahsulot qoʻshadi: olma (ID 1) va non (ID 2) |
| 13–15 | `for _, p := range st.List() { … }` | `List` qaytargan mahsulotlarni aylanadi (GB-1.06) va har birining `ID`, `Name`, `Price`'ini chiqaradi |

**Import yoʻli** ikki qismdan iborat: `go.mod`'dagi modul nomi, keyin modul ichidagi papka. Modul nomini birinchi darsda `go mod init`
bilan yozgan edik:

```console

```

|---|---|---|
| modul nomi | `github.com/abdurahmon27/bozor` | `go.mod`dagi `module` qatori |
| modul ichidagi papka | `internal/store` | fayl daraxti |
| import yoʻli | `github.com/abdurahmon27/bozor/internal/store` | ikkalasi `/` bilan birlashadi ([Go Modules Reference](https://go.dev/ref/mod#modules-overview)) |

**A)** ikki mahsulot chiqadi · **B)** xato: bu papkada Go fayl yoʻq · **C)** xato: `store` paketi topilmadi

## Katta harf: paketdan tashqariga nima koʻrinadi

Endi darsning boshidagi qator. `main` olmaning qoldigʻiga toʻgʻridan-toʻgʻri minus besh yozadi. Bitta faylda bu ishlagan edi; endi
`products` boshqa paketda (`_video/02-eksport/cmd/bozor/main.go`):

```go filename="_video/02-eksport/cmd/bozor/main.go" showLineNumbers
package main

import (
	"fmt"

	"github.com/abdurahmon27/bozor/internal/store"
)

func main() {
	var st store.Store
	st.Add("olma", 1_200_000, 40)
	st.Add("non", 400_000, 100)
	st.products[0].Stock = -5
	for _, p := range st.List() {
		fmt.Println(p.ID, p.Name, p.Price)
	}
}
```

`go run ./cmd/bozor` nima qiladi?

**A)** ishlaydi va qoldiq −5 · **B)** kompilyatsiya xatosi · **C)** dastur ishlab, panic bilan yiqiladi

<details>
<summary>Javob</summary>

**B.** **A** ni tanlagan boʻlsangiz, bitta fayldagi natijaga tayangansiz: u yerda `main` va `Store` bitta paketda edi. **C** —
panic dastur **ishlayotganda** chiqadi, bu esa kompilyatsiyada topiladi: dastur umuman ishga tushmaydi.

</details>

```console
$ ./_video/run.sh 02-eksport go run ./cmd/bozor
# github.com/abdurahmon27/bozor/cmd/bozor
cmd/bozor/main.go:13:5: st.products undefined (cannot refer to unexported field products)
```

Xabarni qatorma-qator oʻqiymiz:

- `# github.com/abdurahmon27/bozor/cmd/bozor` — qaysi paketni kompilyatsiya qilishda xato chiqdi: `cmd/bozor`.
- `cmd/bozor/main.go:13:5` — fayl, qator, ustun (GB-1.01): 13-qator, 5-ustun, yaʼni `products` soʻzining boshi.
- `st.products undefined` — «`st.products` aniqlanmagan»: kompilyator `st`da `products` nomini koʻrmayapti.
- `(cannot refer to unexported field products)` — sababi: «eksport qilinmagan (**unexported**) maydonga murojaat qilib boʻlmaydi».
  `products` boshqa paketda va u unexported.

Go'ning qoidasi bitta. Nom **katta harf** bilan boshlansa, u **export qilingan** (**exported**): boshqa paketlarga koʻrinadi. Kichik
harf bilan boshlansa, u faqat oʻz paketida koʻrinadi — shu papkadagi hamma faylda. Aniqrogʻi, birinchi belgi Unicode katta harfi
boʻlishi kerak ([Go spec: Exported identifiers](https://go.dev/ref/spec#Exported_identifiers)).

Qoida paket darajasidagi turlarga, funksiyalarga, konstantalarga va oʻzgaruvchilarga, shuningdek maydon va metodlarga bir xil ishlaydi:

| Nom | Birinchi harf | Boshqa paketga |
|---|---|---|
| `Store`, `Product`, `Add`, `List` | katta | koʻrinadi |
| `Product.Stock`, `Product.Name` | katta | koʻrinadi |
| `fmt.Println` | katta `P` | koʻrinadi: birinchi darsdagi katta `P` shu sababli |
| `products` | kichik | faqat `store` paketi ichida |

Rasmda: `main` `store`ning faqat katta harfli nomlarini koʻradi.

```text
 cmd/bozor (package main)          internal/store (package store)
┌──────────────────────┐          ┌───────────────────────────────┐
│ st.Add(…)            │ ───────► │ Store, Product, Add, List     │ export qilingan
│ st.List()            │ ───────► │                               │
│ st.products     ✗    │ ─ ─ ╳    │ products                      │ faqat store ichida
└──────────────────────┘          └───────────────────────────────┘
```

Lekin bizning chegarada hali bitta teshik bor. `List` ichki slice'ni qaytaradi. `main` natijaning birinchi elementiga minus besh

## Tashqi modul: narxni soʻmda, guruhlab

Endi narxlarni soʻmda, raqamlarni guruhlab chiqaramiz: «12 000», oʻrtada boʻsh joy bilan. `fmt` sonlarni guruhlamaydi. Buni Go
jamoasining `golang.org/x/text` moduli qiladi: u standart kutubxonadan tashqarida, lekin Go loyihasining qismi
([Go wiki: X-Repositories](https://go.dev/wiki/X-Repositories), [x/text](https://pkg.go.dev/golang.org/x/text)). Undan ikki paket olamiz:
`language` til tegini beradi, `message` tilga moslangan printer yaratadi. `_video/04-modul/cmd/bozor/main.go`:

```go filename="_video/04-modul/cmd/bozor/main.go" showLineNumbers
package main

import (
	"github.com/abdurahmon27/bozor/internal/store"
	"golang.org/x/text/language"
	"golang.org/x/text/message"
)

const tiyinPerSom = 100 // 1 soʻm = 100 tiyin

func main() {
```

| 9 | `const tiyinPerSom = 100` | 1 soʻm = 100 tiyin (GB-1.03) |

| 18 | `printer.Printf("%d. %s: %d soʻm\n", …)` | `fmt.Printf` kabi format qatori (GB-1.04), lekin sonlarni til qoidasi bilan guruhlaydi |

## Uy vazifasi

Vazifa kurs papkasidagi [`TASK.md`](https://github.com/abdurahmon27/go-backend-uz/blob/main/lessons/gb-2-06-paketlar/TASK.md) faylida;
papka: [lessons/gb-2-06-paketlar](https://github.com/abdurahmon27/go-backend-uz/tree/main/lessons/gb-2-06-paketlar). Ikkita ish,
ikkalasi `internal/store/store.go`da:

- 🟡 **`Sell(id int64, quantity int) error`.** Hozir u hech narsa qilmaydi va har doim `nil` qaytaradi. Qoidani yozing: `quantity`
  musbat boʻlmasa (0 yoki manfiy), `id`'li mahsulot katalogda boʻlmasa yoki qoldiq `quantity`'dan kam boʻlsa — `error`; aks holda
  shu mahsulotning `Stock`'i `quantity`'ga kamayadi va `nil` qaytadi. Xato boʻlganda hech bir qoldiq oʻzgarmasin. Masalan, non
  (ID 2, qoldiq 100): `Sell(2, 3)` → `nil`, qoldiq 97; olma (ID 1, qoldiq 40): `Sell(1, 41)` → `error`, qoldiq 40.
- 🟢 **`List() []Product`.** Hozir u `s.products`'ning oʻzini qaytaradi: yuqorida koʻrgan teshik. `List` **nusxa** qaytarsin: natijaga
  yozish katalogga taʼsir qilmasin.

`Product`, `Store`'ning maydonlari va `Add`'ni oʻzgartirmang. Daraja belgilari (🟢🟡) kurs papkasida yoʻq: men qoʻydim. Maslahatlar
`TASK.md`da: mahsulotni indeks bilan qidiring (`for i := range s.products`): `for _, p := range s.products` ichida `p` — elementning
nusxasi, `p.Stock -= quantity` katalogni oʻzgartirmaydi. Xato uchun `fmt.Errorf` (GB-1.07). Nusxa uchun `slices.Clone(s.products)`
yoki `make` bilan `copy`.

Javob — [`solution/internal/store/store.go`](https://github.com/abdurahmon27/go-backend-uz/blob/main/lessons/gb-2-06-paketlar/solution/internal/store/store.go):

```go filename="solution/internal/store/store.go" showLineNumbers
// Package store bozor katalogini xotirada saqlaydi.
// U internal/ ichida: uni faqat bozor modulining oʻz kodi import qila oladi.
package store

import (
	"fmt"
	"slices"
)

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

// Store — xotiradagi katalog. Nol qiymati tayyor: var st store.Store.
// products kichik harf bilan: paketdan tashqaridagi kod unga yoza olmaydi.
type Store struct {
	products []Product
}

// Add katalogga mahsulot qoʻshadi va unga ID beradi (1, 2, 3 …).
func (s *Store) Add(name string, price int64, stock int) Product {
	p := Product{ID: int64(len(s.products)) + 1, Name: name, Price: price, Stock: stock}
	s.products = append(s.products, p)
	return p
}

// List katalogdagi mahsulotlarning nusxasini qaytaradi: natijaga yozish
// katalogni oʻzgartirmaydi.
func (s *Store) List() []Product {
	return slices.Clone(s.products)
}

// Sell id'li mahsulotdan quantity dona sotadi va qoldiqni kamaytiradi.
// quantity musbat boʻlishi, mahsulot katalogda boʻlishi va qoldiq yetishi kerak;
// aks holda error qaytadi va qoldiq oʻzgarmaydi.
func (s *Store) Sell(id int64, quantity int) error {
	if quantity <= 0 {
		return fmt.Errorf("dona soni musbat boʻlishi kerak, hozir %d", quantity)
	}
	for i := range s.products {
		if s.products[i].ID == id {
			if s.products[i].Stock < quantity {
				return fmt.Errorf("%s: qoldiq %d, soʻralgan %d", s.products[i].Name, s.products[i].Stock, quantity)
			}
			s.products[i].Stock -= quantity
			return nil
		}
	}
	return fmt.Errorf("mahsulot %d topilmadi", id)
}
```

- `Sell`: avval `quantity <= 0` tekshiriladi. Keyin `for i := range s.products` indeks bilan qidiradi va `s.products[i]` — katalogdagi
  elementning **oʻzi**, nusxa emas; shuning uchun `s.products[i].Stock -= quantity` katalogni oʻzgartiradi. Qoldiq yetmasa, kamaytirishdan
  **oldin** `error` qaytadi: xato boʻlganda qoldiq oʻzgarmaydi. Sikl tugagan, mahsulot topilmagan boʻlsa — oxirgi `error`.
- `List`: `slices.Clone` yangi massivli nusxa qaytaradi, `st.List()[0].Stock = -5` endi nusxaga yoziladi.
