## Nimani oʻrganasiz

`sell` funksiyasi olmaning qoldigʻini 40 dan 37 ga tushirib, ichida «37» deb yozdi. `main`ga qaytgach qoldiq yana 40. Kompilyator
hech narsa demadi:

```console
$ ./_video/run.sh 01-nusxa go run .
sell ichida: 37
main'da: 40
```

Dastur toʻgʻri yozilgan, natija esa notoʻgʻri. `sell` nimani oʻzgartirdi va qoldiq haqiqatan kamayishi uchun nima
oʻzgarishi kerak?

**Bitta gʻoya:** pointer — qiymatning xotiradagi manzili. `&olma` manzilni oladi, `*Product` turidagi `p` uni saqlaydi, `p.Stock`
esa manzil boʻylab asl qiymatga yozadi. Go har doim nusxalaydi: pointer berilsa, nusxalanadigan narsa manzil, qiymat esa
bitta qoladi. `nil` pointer hech narsani koʻrsatmaydi, u orqali oʻqish — panic.

Dars oxirida siz:

- funksiyaga struct berilganda nima nusxalanishini xotira rasmida koʻrasiz;
- `&olma` bilan manzil olib, `sell(p *Product, quantity int)` funksiyasida qoldiqni chaqiruvchining qiymatida kamaytirasiz;
- katalogdan elementning manzilini (`&products[i]`) qaytarasiz;
- nil pointer panic'ini oʻqiysiz va `if p == nil` bilan oldini olasiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| pointer | qiymatning xotiradagi manzilini saqlaydigan oʻzgaruvchi. `&olma` — `olma`ning manzili, `*Product` — shunday manzilning turi | pointer |
| funksiyaga pointer berish | funksiya qiymatning nusxasini emas, manzilning nusxasini oladi va chaqiruvchining qiymatini oʻzgartira oladi | passing a pointer |
| nil pointer | hech narsani koʻrsatmaydigan pointer, `*T` turining zero value'si. U orqali qiymatni oʻqish panic beradi | nil pointer |

Ikkita yordamchi tushuncha: `-=` amali (`x -= n` — `x = x - n`) va `&products[i]` bilan `&p` farqi (oxirgisi «Chuqurroq» boʻlimida).

## Muammo: sell nusxani kamaytirdi

Darsning boshidagi dastur (`_video/01-nusxa/main.go`):

```go filename="_video/01-nusxa/main.go" showLineNumbers
package main

import "fmt"

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

func sell(p Product, quantity int) {
	p.Stock -= quantity
	fmt.Println("sell ichida:", p.Stock)
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 13 | `func sell(p Product, quantity int) {` | `sell` ikki parametr oladi: `p` (turi `Product`, sotilayotgan mahsulot) va `quantity` (sotilgan dona soni) |
| 14 | `p.Stock -= quantity` | `-=` («minus teng») — `+=`ning teskarisi: `p.Stock` dan `quantity`ni ayirib, natijani oʻsha maydonga yozadi. `p.Stock = p.Stock - quantity` bilan bir xil |

Funksiyani chaqirganda Go argument qiymatini **nusxalab** parametrga beradi: Go FAQ'ning soʻzlari bilan, *«everything in Go is

qiymat, shuning uchun nusxa ham butun: toʻrt maydonning hammasi. Xotirada bu shunday koʻrinadi (`olma.Stock` — `main`dagi qiymat,
`p.Stock` — `sell`dagi nusxa):

| Nima boʻldi | `olma.Stock` | `p.Stock` | Ekranda |
|---|---|---|---|
| `olma := Product{…Stock: 40}` (20-qatordan oldin) | 40 | `p` hali yoʻq | |
| `sell(olma, 3)` chaqirildi: `p` — `olma`ning toʻliq nusxasi, `quantity` — 3 | 40 | 40 | |
| `p.Stock -= quantity` (14-qator) | 40 | **37** | |
| `fmt.Println("sell ichida:", …)` (15-qator) | 40 | 37 | `sell ichida: 37` |
| `sell` tugadi: `p` nusxasi bilan yoʻqoldi | 40 | yoʻq | |
| `fmt.Println("main'da:", …)` (21-qator) | 40 | yoʻq | `main'da: 40` |

Kompilyator jim, chunki xato yoʻq: `sell` oʻz nusxasini toʻgʻri kamaytirdi. Yoʻqolgani — oʻzgarishning `main`dagi `olma`ga yetib
bormagani. Buning uchun `sell`ga `olma`ning nusxasi emas, oʻzining **manzili** kerak.

## Pointer: qiymatning manzili

`olma` yorligʻi xotiradagi bitta qiymatga (katakka) yopishtirilgan. Bu katakning xotirada oʻz joyi, yaʼni **manzili** (address)
bor. Qiymat manzilini saqlaydigan oʻzgaruvchi **pointer** deyiladi. Ikki yangi belgi:

- `&olma` — «`olma`ning manzili» (ampersand);
- `*Product` — pointer'ning turi: «`Product`ga pointer». Bu turdagi oʻzgaruvchi `Product`ning oʻzini emas, uning manzilini saqlaydi.

Kichik dastur (`_video/02-pointer/main.go`):

```go filename="_video/02-pointer/main.go" showLineNumbers
package main

import "fmt"

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

func main() {
	olma := Product{Name: "olma", Stock: 40}
	p := &olma
	p.Stock = 37
	q := p
	q.Stock = 35
	fmt.Println(olma.Stock, p.Stock)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 14 | `olma := Product{Name: "olma", Stock: 40}` | `olma` qiymatini yaratadi. Rasm oddiy boʻlsin deb `ID` va `Price` yozilmadi: ular zero value, yaʼni 0 |
| 15 | `p := &olma` | `p` — `*Product` turidagi yangi oʻzgaruvchi. Uning katagida `Product` emas, `olma`ning manzili turibdi |
| 16 | `p.Stock = 37` | Go `p`dagi manzil boʻylab `olma`ning oʻziga borib, uning `Stock` maydoniga 37 yozadi |
| 17 | `q := p` | `q` — yana `*Product`. `p`ning katagidagi narsa nusxalanadi, yaʼni manzil |
| 18 | `q.Stock = 35` | `q`dagi manzil boʻylab `Stock`ka 35 yozadi |
| 19 | `fmt.Println(olma.Stock, p.Stock)` | `olma`ning qoldigʻini va `p` orqali qoldiqni chiqaradi |

16-qatordan keyin rasm:

```text
olma → [ ID 0 | Name "olma" | Price 0 | Stock 37 ] ◄──┐
                                                       │
p    → [ manzil ] ─────────────────────────────────────┘
```

`p`ning katagida yangi `Product` yoʻq, faqat `olma`ga strelka. Endi 17–18-qatorlar: `q := p` va `q.Stock = 35`. Oxirgi qator nima
chiqaradi?

**A)** `37 35` · **B)** `35 35` · **C)** `37 37`

<details>
<summary>Javob</summary>

**B: `35 35`.** `q := p` pointer'ni nusxalaydi, yaʼni manzilni: endi ikkita strelka bitta `olma`ga boradi. `q` orqali yozish ham oʻsha
`olma`ni oʻzgartiradi, shuning uchun `olma.Stock` ham, `p.Stock` ham 35. **A** ni tanlagan boʻlsangiz, `q := p` yangi `Product`
yasaydi deb oʻylagansiz (bu GB-2.03'dagi struct qoidasi, pointer'da emas). **C** — `q.Stock = 35` ni hisobga olmagansiz.

```text
olma → [ ID 0 | Name "olma" | Price 0 | Stock 35 ] ◄──┬────┐
                                                       │    │
p    → [ manzil ] ─────────────────────────────────────┘    │
q    → [ manzil ] ──────────────────────────────────────────┘
```

</details>

### `*` ifodada va `p.Stock` yozuvi

`*` belgisi ikki joyda turadi. Tur ichida (`*Product`) u «pointer turi» degani. Ifodada (`*p`) u «`p` koʻrsatgan qiymatning oʻzi»:
manzil boʻylab qiymatga borish, bu **dereference** deyiladi. Demak `p.Stock` aslida `(*p).Stock`, yaʼni «`p` koʻrsatgan
`Product`ning `Stock`i». Go qavs va yulduzchani oʻzi qoʻyadi, shuning uchun `p.Stock` deb yozasiz
([Go spec: Selectors](https://go.dev/ref/spec#Selectors), [A Tour of Go: Pointers to structs](https://go.dev/tour/moretypes/4)).

Buni tekshiradigan dastur (kurs papkasida yoʻq, men ishga tushirdim):

```go
package main

import "fmt"

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

func main() {
	olma := Product{Name: "olma", Stock: 40}
	p := &olma
	q := p
	fmt.Println(p == q, p == &olma)
	fmt.Println((*p).Stock, p.Stock)
	fmt.Println(*p)
	var z *Product
	fmt.Println(z == nil)
}
```

```console
$ go run .
true true
40 40
{0 olma 0 40}
true
```

- `p == q` va `p == &olma` — `true`: ikki pointer bir xil manzilni saqlasa teng
  ([Go spec: Comparison operators](https://go.dev/ref/spec#Comparison_operators)).
- `(*p).Stock` va `p.Stock` bir xil: `40 40`.
- `fmt.Println(*p)` butun `Product`ni chiqaradi: figurali qavs ichida maydonlar tartib bilan (`ID`, `Name`, `Price`, `Stock`)
  ([pkg.go.dev/fmt](https://pkg.go.dev/fmt)).
- `var z *Product` qiymat bermasdan eʼlon qilingan pointer: zero value'si `nil`, shuning uchun `z == nil` — `true`. Bu haqda
  «nil pointer» boʻlimida.

## Funksiyaga pointer berish

Endi `sell`ni tuzatamiz: parametr turi `*Product` boʻladi. `sell` mahsulotning nusxasini emas, manzilini oladi. Tanasi oʻzgarmaydi:
`p.Stock` manzil boʻylab boradi. `sell` ichidagi `Println`ni olib tashladik. `main`dagi chaqiruv esa eskicha qoldi
(`_video/03-xato/main.go`):

```go filename="_video/03-xato/main.go" showLineNumbers

	Price int64 // tiyin
	Stock int
}

func sell(p *Product, quantity int) {
```

Bu kod kompilyatsiya boʻladimi, boʻlsa nima chiqadi?

**A)** `main'da: 37` · **B)** `main'da: 40` · **C)** kompilyatsiya xatosi

<summary>Javob</summary>

manzilini oʻzi oladi deb oʻylagansiz. **B** ni tanlagan boʻlsangiz, eski nusxa qoidasi hamon ishlaydi deb oʻylagansiz: dastur

</details>

  turi `Product`) `sell`ga argument sifatida `*Product` qiymati oʻrnida ishlatib boʻlmaydi».

Endi `main`da 37. Xotirada:

| Nima boʻldi | `olma.Stock` | `p` | `quantity` |
|---|---|---|---|
| `olma := Product{…Stock: 40}` | 40 | yoʻq | yoʻq |
| `sell(&olma, 3)` chaqirildi: `p` — `olma` manzilining nusxasi | 40 | → `olma` | 3 |
| `p.Stock -= quantity`: manzil boʻylab `olma`ning oʻziga yozadi | **37** | → `olma` | 3 |
| `sell` tugadi: `p` yoʻqoldi | 37 | yoʻq | yoʻq |

Argument yana nusxalandi, faqat nusxalangan narsa manzil. Go FAQ'ning soʻzlari: *«passing a pointer value makes a copy of the pointer,
but not the data it points to»* ([Go FAQ](https://go.dev/doc/faq#pass_by_value)). `p` yoʻqolsa ham, oʻzgarish `olma`da qoladi.

**Qoida.** Funksiya chaqiruvchining qiymatini oʻzgartirishi kerak boʻlsa, pointer bering: bu funksiya imzosida (`p *Product`)
koʻrinib turadi. Funksiya faqat oʻqisa, `Product` kabi kichik struct'ni qiymat bilan bering: nusxa arzon va funksiya asl
qiymatni buzolmaydi. Go Code Review Comments: *«Don't pass pointers as function arguments just to save a few bytes»*
([Pass Values](https://go.dev/wiki/CodeReviewComments#pass-values)).

**`*testing.T` ham shu.** GB-1.08'da test funksiyasi `func TestXxx(t *testing.T)` edi va `*` keyinga qoldirilgan edi:

```go
func TestVazifaSellByID(t *testing.T) {
```

`go test` test funksiyasiga `testing.T` qiymatining manzilini beradi. `t.Errorf` shu manzil orqali testni «yiqilgan» deb belgilaydi
([pkg.go.dev/testing](https://pkg.go.dev/testing)). Bu — `sell(p *Product, …)` bilan bir xil mexanizm.

## Katalogdan topish: &products[i]

Haqiqiy bozor'da mahsulot ID boʻyicha katalogdan topiladi. `findProduct` mahsulotlar slice'ini va ID'ni oladi, natijasi `*Product`.
`_video/05-find/main.go`:

```go filename="_video/05-find/main.go" showLineNumbers
package main

import "fmt"

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

func sell(p *Product, quantity int) {
	p.Stock -= quantity
}

// findProduct katalogdan ID boʻyicha mahsulotni topadi: topilsa elementning manzili, topilmasa nil.
func findProduct(products []Product, id int64) *Product {
	for i := range products {
		if products[i].ID == id {
			return &products[i]
		}
	}
	return nil
}

func main() {
	catalog := []Product{
```

## nil pointer: hech narsani koʻrsatmaydigan manzil

`findProduct` hech narsa topmasa, `nil` qaytaradi. `nil` — pointer'ning zero value'si: `p`ning katagida strelka yoʻq. Katalogda
yoʻq 9-ID'ni soʻraymiz (`_video/06-nil/main.go`):

```go filename="_video/06-nil/main.go" showLineNumbers
package main

import "fmt"

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

func sell(p *Product, quantity int) {
	p.Stock -= quantity
}

// findProduct katalogdan ID boʻyicha mahsulotni topadi: topilsa elementning manzili, topilmasa nil.
func findProduct(products []Product, id int64) *Product {
	for i := range products {
		if products[i].ID == id {
			return &products[i]
		}
	}
	return nil
}

func main() {
	catalog := []Product{
		{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40},
		{ID: 2, Name: "non", Price: 400_000, Stock: 100},
	}
	p := findProduct(catalog, 9)
	fmt.Println(p == nil)
	fmt.Println(p.Stock)
}
```

33-qator `p == nil` ni tekshiradi: `p` `nil`mi? U `true` chiqaradi. 34-qator nil pointer orqali `Stock`ni oʻqimoqchi, lekin strelka
oxirida `Product` yoʻq. Nima boʻladi?

**A)** `0`, chunki zero value · **B)** panic · **C)** kompilyatsiya xatosi

<details>
<summary>Javob</summary>

**B: panic.** Kompilyator buni ushlamaydi: `p` `nil` ekani faqat dastur ishlaganda maʼlum boʻladi. **A** ni tanlagan boʻlsangiz,
zero value hamma joyda boʻladi deb oʻylagansiz: `int` uchun `0` bor, lekin `nil`ning orqasida `Product` umuman yoʻq, `Stock`
oʻqiydigan joy ham yoʻq. **C** — kod kompilyatsiya boʻladi.

</details>

(Panic'dagi vaqtinchalik papka yoʻlini `/tmp/…` bilan qisqartirdim; qolgani chiqqanidek. Videoda faqat birinchi ikki qator

`0` chiqmadi, chunki zero value qiymat bor joyda boʻladi, `nil`ning orqasida esa `Product` yoʻq.

**Tuzatish:** pointer qaytaradigan funksiyadan keyin `nil`ni tekshiring. `p == nil` boʻlsa, xabar chiqarib, `return` bilan
`main`dan chiqing (GB-1.05'dagidek). Undan keyingi qatorlarda `p` aniq `nil` emas (`_video/07-guard/main.go`):

## Chuqurroq (ixtiyoriy): range bergan oʻzgaruvchining manzili

`findProduct`ni `range`ning ikkinchi qiymati bilan yozsak ham, kod kompilyatsiya boʻladi (`_video/08-range/main.go`):

```go filename="_video/08-range/main.go" showLineNumbers
package main

import "fmt"

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

func sell(p *Product, quantity int) {
	p.Stock -= quantity
}

// findProduct — XATO variant: range bergan p elementning nusxasi.
func findProduct(products []Product, id int64) *Product {
	for _, p := range products {
		if p.ID == id {
			return &p
		}
	}
	return nil
}

func main() {
	catalog := []Product{
		{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40},
		{ID: 2, Name: "non", Price: 400_000, Stock: 100},
	}
	p := findProduct(catalog, 2)
	sell(p, 1)
	fmt.Println(p.Stock, catalog[1].Stock)
}
```

19-qatorda `p` — `range` bergan oʻzgaruvchi. Spec boʻyicha `range` har bir elementni oʻzgaruvchiga oddiy qiymat berish kabi
qoʻyadi ([Go spec: For statements with range clause](https://go.dev/ref/spec#For_range)): `p` — elementning **nusxasi**, xuddi
`q := p` (struct) kabi. `&p` esa shu nusxaning manzili, katalogdagi elementniki emas. Go 1.22 dan har aylanishda `p` yangi
oʻzgaruvchi boʻladi, lekin u baribir nusxa. `main` avvalgidek `non`ni topib sotadi va `p` orqali qoldiqni, keyin katalogdagi qoldiqni
chiqaradi. Qaysi ikki son chiqadi?

**A)** `99 99` · **B)** `99 100` · **C)** `100 100`

<details>
<summary>Javob</summary>

**B: `99 100`.** `sell` nusxani kamaytirdi (100 → 99), katalogdagi `non` esa hamon 100. **A** ni tanlagan boʻlsangiz, `&p`
katalogdagi elementga qaraydi deb oʻylagansiz. **C** — `sell` nusxaga ham tegmagan deb oʻylagansiz.

</details>

```console
$ ./_video/run.sh 08-range go run .

```

Element manzili kerak boʻlsa, indeks bilan yuring: `&products[i]`. Vazifadagi test aynan shu xatoni ushlaydi.

Yana bir ehtiyot chorasi (videoda yoʻq, kurs papkasining README'sidan): `findProduct` qaytargan pointer katalog slice'ining
massiviga ishora qiladi. Keyin `append` yangi massiv ochsa (GB-2.01), eski pointer eski massivni oʻzgartiradi, katalog esa
oʻzgarmaydi. Kurs papkasida yoʻq dastur, men ishga tushirdim:

```go
package main

import "fmt"

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

func main() {
	catalog := []Product{
		{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40},
	}
	p := &catalog[0]
	catalog = append(catalog, Product{ID: 2, Name: "non", Price: 400_000, Stock: 100})
	p.Stock = 0
	fmt.Println(p.Stock, catalog[0].Stock)
}
```

```console
$ go run .
0 40
```

`catalog`ning sigʻimi 1 edi, `append` yangi massiv yasadi, `p` esa eski massivda qoldi: `p.Stock = 0` eski elementga yozildi.
Qoida: pointer'ni saqlab qoʻymang, katalogni oʻzgartirgandan keyin qaytadan toping.

## Koʻp uchraydigan xatolar

**1. «Funksiya argumentni oʻzgartirdi, demak `main`da ham oʻzgaradi».** Eng keng tarqalgan xato: `sell(p Product, …)` oʻz nusxasini
oʻzgartiradi, `main`dagi qiymat oʻzgarmaydi, kompilyator esa jim. Dars boshidagi `sell ichida: 37` / `main'da: 40` aynan shu
(«Muammo» boʻlimi). Tuzatish: parametr turini `*Product` qiling va `sell(&olma, 3)` deb chaqiring.

**2. `Product` va `*Product`ni aralashtirish.** `sell(olma, 3)` — `*Product` kutilgan joyda `Product`:
`cannot use olma (variable of struct type Product) as *Product value in argument to sell` («Funksiyaga pointer berish» boʻlimi).
Aksincha ham xato: `*Product` kutilmagan joyga `p` (pointer) bersangiz, `*p` kerak. Tuzatish: `&olma` yoki `*p`.

**3. `nil` tekshirilmagan pointer.** `findProduct` natijasidan darhol `p.Stock` oʻqisangiz va ID topilmasa:
`panic: runtime error: invalid memory address or nil pointer dereference` («nil pointer» boʻlimi). Tuzatish: `if p == nil { … return }`.

**4. `for _, p := range` va `&p`.** `p` — elementning nusxasi, `&p` — nusxaning manzili: `sell` katalogni oʻzgartirmaydi, xato
chiqmaydi (`99 100`, «Chuqurroq» boʻlimi). Tuzatish: `&products[i]`.

**5. `nil`ni `0` bilan solishtirish.** Yangi yozuvchi pointer'ning «boʻshligʻini» `0` deb tekshiradi. Kurs papkasida yoʻq dastur, men
ishga tushirdim:

```go
package main

import "fmt"

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

func main() {
	var p *Product
	if p == 0 {
		fmt.Println("topilmadi")
	}
}
```

```console
$ go run .
# github.com/abdurahmon27/bozor
./main.go:15:10: invalid operation: p == 0 (mismatched types *Product and untyped int)
```

`./main.go:15:10` — 15-qator, 10-ustun (`0` raqami). Xabar: «`p == 0` amali notoʻgʻri: turlar mos emas — `*Product` va turi
aniqlanmagan butun son (`untyped int`)». `nil` — `0` emas: pointer'ni faqat `nil` bilan solishtiring, `if p == nil`.

**1.** `var p *Product` deb eʼlon qilingan va qiymat berilmagan `p` nimaga teng?

**2.** `f` funksiyasining parametri `p Product`, u `p.Stock`ni 0 ga tenglaydi. Chaqiruvchining `olma`si oʻzgaradimi?

<details>

Ha. `t := s` slice sarlavhasini nusxalaydi, lekin sarlavhadagi koʻrsatkich oʻsha massivga boradi: ikkala slice bitta massivni

</details>

```go filename="solution/main.go" showLineNumbers
package main

import "fmt"

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

func sell(p *Product, quantity int) {
	p.Stock -= quantity
}

// findProduct katalogdan ID boʻyicha mahsulotni topadi: topilsa elementning manzili, topilmasa nil.
func findProduct(products []Product, id int64) *Product {
	for i := range products {
		if products[i].ID == id {
			return &products[i]
		}
	}
	return nil
}

func main() {
	catalog := []Product{
		{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40},
		{ID: 2, Name: "non", Price: 400_000, Stock: 100},
	}
	p := findProduct(catalog, 9)
	if p == nil {
		fmt.Println("mahsulot topilmadi: 9")
		return
	}
	sell(p, 1)
	fmt.Println(p.Stock)
}

// sellByID katalogdagi id raqamli mahsulotdan quantity dona sotadi va xatoni qaytaradi.
func sellByID(products []Product, id int64, quantity int) error {
	p := findProduct(products, id)
	if p == nil {
		return fmt.Errorf("mahsulot topilmadi: %d", id)
	}
	if quantity <= 0 {
		return fmt.Errorf("miqdor musbat boʻlishi kerak, keldi %d", quantity)
	}
	if quantity > p.Stock {
		return fmt.Errorf("%s: qoldiq %d, soʻralgan %d", p.Name, p.Stock, quantity)
	}
	sell(p, quantity)
	return nil
}

// cheapest katalogdagi eng arzon mahsulotning manzilini qaytaradi; katalog boʻsh boʻlsa nil.
func cheapest(products []Product) *Product {
	var best *Product
	for i := range products {
		if best == nil || products[i].Price < best.Price {
			best = &products[i]
		}
	}
	return best
}
```

- `sellByID`: avval `p := findProduct(products, id)` — katalogdagi elementning manzili. `p == nil` boʻlsa, panic oʻrniga xato.
  Keyin ikki shart: `quantity <= 0` va `quantity > p.Stock`. Hammasi tekshirilgandan **keyin** `sell(p, quantity)` chaqiriladi, shuning
  uchun xato boʻlsa qoldiq oʻzgarmaydi.
- `cheapest`: `var best *Product` — zero value'si `nil`. Sikl indeks bilan yuradi (`for i := range products`). `best == nil || products[i].Price < best.Price` — `||` «yoki»: chap tomon rost boʻlsa, oʻng tomon hisoblanmaydi
  ([Go spec: Logical operators](https://go.dev/ref/spec#Logical_operators)), shuning uchun `best` hali `nil` boʻlganda `best.Price`
  panic bermaydi. Mos kelsa, `best = &products[i]`: katalogdagi elementning manzili, `range`dagi nusxaniki emas.
