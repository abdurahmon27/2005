## Muhit, flag va ustunlik

`cmd/api/config.go` ichida ikki maydon bor. Kichik harf ularni shu `main` paketida qoldiradi; log'dan yashirmaydi.
Quyidagilar shu faylning qismlari. Toʻliq fayl sirni chiqarish tuzatilganidan keyin beriladi.

```go
type config struct {
	port        int
	databaseURL string // secret: ichida parol bor
}

func envOr(key, def string) string {
	if v, ok := os.LookupEnv(key); ok {
		return v
	}
	return def
}
```

`key` — muhitdagi nom, `def` — standart qiymat. `LookupEnv` qiymat va borligini bildiruvchi `ok` qaytaradi.
`if` ichidagi `:=` ikki natijani oladi; `; ok` qaytgan belgini tekshiradi. `Getenv` bu farqni bera olmaydi.

| `PORT` holati | `v` | `ok` | `envOr("PORT", "8765")` |
|---|---|---|---|
| qoʻyilmagan | `""` | `false` | `"8765"` |
| `PORT=` | `""` | `true` | `""` |
| `PORT=9090` | `"9090"` | `true` | `"9090"` |

```go
func loadConfig(args []string) (config, error) {
	fs := flag.NewFlagSet("api", flag.ContinueOnError)
	port := fs.String("port", envOr("PORT", "8765"), "HTTP port (muhitda: PORT)")
	if err := fs.Parse(args); err != nil {
		return config{}, err
	}
```

`args []string` — dastur nomisiz argumentlar. `NewFlagSet` har chaqiruvda alohida `api` nomli toʻplam yaratadi.
`ContinueOnError` bilan `Parse` xato qaytaradi; jarayonni oʻzi tugatmaydi. Shuning uchun funksiya testdan chaqiriladi.
`fs.String` uch argument oladi: nom, standart qiymat va yordam matni. Natijasi `*string`, yaʼni matnga pointer.
Avval unda muhit yoki standart bor. `Parse` berilgan `-port` bilan shu qiymatni almashtiradi.
`config{}` — xato bilan qaytadigan boʻsh struct. Uni muvaffaqiyatli sozlama sifatida ishlatmang.

| Qadam | `PORT=9090`, argument `-port 8781` | Faqat `PORT=9090` | Ikkalasi yoʻq |
|---|---|---|---|
| `fs.String`dan keyin `*port` | `"9090"` | `"9090"` | `"8765"` |
| `fs.Parse`dan keyin `*port` | `"8781"` | `"9090"` | `"8765"` |

`DATABASE_URL` uchun flag roʻyxatdan oʻtkazilmaydi: sir buyruq qatorida boʻlmasin.

## Tekshiruv resurslardan oldin

```go
	var errs []error
	n, err := strconv.Atoi(*port)
	if err != nil || n < 1 || n > 65535 {
		errs = append(errs, fmt.Errorf("port %q: 1–65535 oraligʻidagi butun son kerak", *port))
	}
	db := os.Getenv("DATABASE_URL")
	if db == "" {
		errs = append(errs, errors.New("DATABASE_URL qoʻyilmagan: .env.example'ga qarang"))
	}
	if len(errs) > 0 {
		return config{}, errors.Join(errs...)
	}
	return config{port: n, databaseURL: db}, nil
}
```

`errs` — xatolar slice'i. `Atoi(*port)` pointer ortidagi matnni butun songa aylantiradi.
`||` shartlardan bittasi rost boʻlsa ham xato qoʻshadi. `append` natijasi yana `errs`ga yoziladi.
`%q` qoʻshtirnoq chiqaradi: boʻsh port ham `""` boʻlib koʻrinadi. Baza xatosida faqat nom bor, qiymat yoʻq.
`len(errs)` musbat boʻlsa, `errs...` elementlarni `Join`ga alohida argumentlar qilib beradi.
`Join` bitta xato qiymatini qaytaradi va xabarlarni yangi qator bilan birlashtiradi. Muammo yoʻq boʻlsa, nomlangan maydonli `config` va `nil` qaytadi.

Quyida kursdagi toʻliq `main.go`. Uning `Printf` qatori hozirgi faylda `String()` orqali ishlaydi.
Keyingi boʻlimda shu metod boʻlmagan bosqichni alohida nusxada takrorlaymiz.

```go filename="cmd/api/main.go" showLineNumbers
// api — bozor API'si (GB-6.08'dagi himoyalangan bozor), endi sozlamasi tashqaridan (GB-8.01, config.go):
// port flag yoki muhitdan, DATABASE_URL faqat muhitdan; notoʻgʻri sozlamada server aniq xato bilan toʻxtaydi.
//
//	docker compose up -d --wait
//	goose up                     (GOOSE_DRIVER, GOOSE_DBSTRING, GOOSE_MIGRATION_DIR: GB-5.06)
//	docker compose exec db psql -f /lab/seed.sql
//	cp .env.example .env         (bir marta; .env gitga tushmaydi)
//	set -a; . ./.env; set +a     (.env'dagi qatorlarni muhitga eksport qiladi)
//	go build ./cmd/api && ./api  → config: port=8765 db=localhost:5581/bozor
//	./api -h                     → flag'lar roʻyxati
package main

import (
	"context"
	"errors"
	"flag"
	"fmt"
	"net/http"
	"os"
	"time"

	"github.com/abdurahmon27/bozor/internal/store"
	"github.com/jackc/pgx/v5/pgxpool"
)

// newServer — bozor API serveri (GB-4.04). Handler — newHandler: middleware zanjiri, ichida newMux (GB-6.01).
func newServer(addr string, st *store.Store) *http.Server {
	return &http.Server{
		Addr:              addr,
		Handler:           newHandler(st),
		ReadHeaderTimeout: 5 * time.Second,
	}
}

func main() {
	err := run(os.Args[1:])
	if errors.Is(err, flag.ErrHelp) {
		return // -h: flag yordam matnini chiqardi, bu xato emas
	}
	if err != nil {
		fmt.Fprintln(os.Stderr, "xato:", err)
		os.Exit(1)
	}
}

// run — dasturning hammasi shu yerda (GB-5.10): xato qaytaradi, defer'lar ishlaydi, chiqish kodini main hal qiladi.
func run(args []string) error {
	cfg, err := loadConfig(args)
	if err != nil {
		return err
	}
	fmt.Printf("config: %+v\n", cfg) // String() chaqiriladi: parol chiqmaydi
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()
	pool, err := pgxpool.New(ctx, cfg.databaseURL)
	if err != nil {
		return err
	}
	defer pool.Close()
	if err := pool.Ping(ctx); err != nil { // baza ishlamasa server ishga tushmaydi
		return err
	}
	srv := newServer(cfg.addr(), store.New(pool))
	fmt.Printf("bozor API: http://localhost:%d\n", cfg.port)
	return srv.ListenAndServe()
}
```

| Qator | Nima qiladi |
|---|---|
| 1–10 | ishga tushirish boʻyicha izohlar; bajarilmaydi |
| 11 | bajariladigan `main` paketi |
| 13–24 | context, xato, flag, format, HTTP, muhit, vaqt, store va pgx pool paketlari |
| 26–33 | `newServer`: manzil, handler va sarlavhani oʻqish uchun 5 soniya chegara; `&` server pointer'ini qaytaradi |
| 35–39 | `os.Args[1:]` dastur nomini tashlaydi; `ErrHelp` boʻlsa muvaffaqiyatli chiqadi |
| 40–44 | boshqa xatoni stderrʼga yozadi va `os.Exit(1)` qiladi |
| 46–51 | `run` sozlamani oladi; xatoda tashqi resurslarga yetmasdan qaytadi |
| 52 | sozlamaning log koʻrinishini chiqaradi |
| 53–54 | baza uchun 5 soniyalik context; `defer cancel()` qaytishda ishlaydi |
| 55–62 | pool yaratadi, yopishni rejalaydi, `Ping` bilan ulanishni tekshiradi |
| 63–65 | HTTP serverni yaratadi, manzilni chiqaradi va tinglaydi; xatoni qaytaradi |

`loadConfig` faqat port va `DATABASE_URL`ning boʻshligini tekshiradi. URI shakli yoki baza mavjudligi bu funksiyada tekshirilmaydi.
`pgxpool.New` va `Ping` keyingi bosqich; ular ham HTTP tinglashdan oldin bajariladi.
Notoʻgʻri flag'da `Parse` darhol qaytadi: keyingi validatsiya xatolari bu holatda yigʻilmaydi.

| Holat | `loadConfig` | Postgres | HTTP port |
|---|---|---|---|
| port yaroqsiz yoki DB yoʻq | xato, `run` qaytadi | ochilmaydi | ochilmaydi |
| DB matni bor, lekin ulanish yaroqsiz | sozlama qaytadi | yaratish yoki `Ping`da xato | ochilmaydi |
| hammasi yaroqli | sozlama qaytadi | `Ping` oʻtadi | `ListenAndServe` ochadi |

## Sir gitga tushmasin

`.env.example`da faqat nomlar va namuna bor. `PAROL` — haqiqiy credential emas.
Quyidagi namuna kursdagi fayl bilan bir xil:

```text
# Nusxa oling: cp .env.example .env — haqiqiy qiymatlar faqat .env'da (u gitga tushmaydi).
PORT=8765
DATABASE_URL='postgres://bozor:PAROL@localhost:5581/bozor'
```

URI'da `bozor` — foydalanuvchi, `PAROL` — parol, `localhost:5581` — host va port, `/bozor` — baza.
Bittalik qoʻshtirnoq shell talqinidan saqlaydi; URI ichidagi maxsus belgilar kerak boʻlsa percent-encoding bilan yoziladi.
Parolning oʻzida bittalik qoʻshtirnoq boʻlsa, uni shu shaklga oʻzgartirmasdan joylab boʻlmaydi.

Bash faylni maʼlumot sifatida emas, kod sifatida bajaradi. Faqat oʻzingiz ishonadigan `.env`ni yuklang.
Git qoidalari oldindan yozilgan. Qaysi fayl eʼtiborsiz qoldirilganini tekshiring: `.env`mi yoki `.env.example`mi?

**A)** ikkalasi · **B)** faqat `.env` · **C)** hech biri

<details>
<summary>Javob</summary>

**B.** `.env` qoidasi `.env.example`ga mos kelmaydi. `/api` faqat ildizdagi binary'ni yashiradi; `api` boʻlsa `cmd/api` ham mos kelardi.

</details>

```console
$ cat .gitignore

/api
$ git check-ignore -v .env

$ git check-ignore -v .env.example ; echo "kod: $?"

```

`-v` natijasi: qoida fayli, qator, qoida, keyin Tab va tekshirilgan yoʻl. `kod: 1` bu yerda ignore qoidasi yoʻqligini bildiradi.
`cp` hech narsa chiqarmadi. Nusxadagi `PAROL`ni muharrirda `bozor-lab`ga almashtiring; qoʻshtirnoq qolsin.
**Bu ataylab ochiq laboratoriya paroli**, `compose.yaml` ham shu qiymatdan foydalanadi. Haqiqiy parolni sahifaga yoki gitga yozmang.


**A)** hamma maydon, parol ham · **B)** faqat port · **C)** `{}`

[OWASP Logging](https://cheatsheetseries.owasp.org/cheatsheets/Logging_Cheat_Sheet.html#data-to-exclude) parol va ulanish satrlarini log'ga toʻgʻridan-toʻgʻri yozmaslikni tavsiya qiladi.
Log nusxasi faylga, log xizmatiga yoki skrinshotga ketishi mumkin.
Tuzatish — foydalanuvchi va parolni oʻchirishga urinish oʻrniga, chiqarishga ruxsat berilgan maydonlarni tanlash.
`net/url`dagi `Parse` manzilni qismlarga ajratadi; `Host` host va portni, `Path` baza yoʻlini beradi.

Quyida kursdagi toʻliq, tuzatilgan `config.go`:

```go filename="cmd/api/config.go" showLineNumbers
package main

// Sozlama (GB-8.01). Kod hamma muhitda bir xil; muhitga qarab oʻzgaradigan narsa (port, baza manzili, kalitlar)
// tashqaridan keladi: muhit oʻzgaruvchilari va flag'lardan (Twelve-Factor App, III. Config).
// Ustunlik: flag > muhit oʻzgaruvchisi > standart qiymat. Hammasi ishga tushishda BIR MARTA tekshiriladi:
// biror qiymat notoʻgʻri boʻlsa server hech narsa ochmaydi, hamma xatolarni sanab, 1 kodi bilan chiqadi.
//
//	PORT          -port   HTTP port, 1–65535 (standart 8765)
//	DATABASE_URL  —       Postgres manzili. SECRET: ichida parol bor. Faqat muhitdan, flag emas:
//	                      buyruq qatori (ps, /proc/PID/cmdline) shu kompyuterdagi hamma foydalanuvchiga koʻrinadi.
//
// Qiymatlar: .env.example (gitda) → nusxasi .env (gitda emas, .gitignore).

import (
	"errors"
	"flag"
	"fmt"
	"net/url"
	"os"
	"strconv"
)

// config — serverning ishga tushish sozlamalari.
type config struct {
	port        int
	databaseURL string // secret: ichida parol bor
}

// envOr — key qoʻyilgan boʻlsa uning qiymati (boʻsh boʻlsa ham), qoʻyilmagan boʻlsa def.
// «PORT=» (boʻsh) — xato sozlama: u standart qiymatga jim almashmaydi, tekshiruvda ushlanadi.
func envOr(key, def string) string {
	if v, ok := os.LookupEnv(key); ok {
		return v
	}
	return def
}

// loadConfig — args (os.Args[1:]) va muhitdan config. Hamma xato bitta error'da (errors.Join), har biri alohida qatorda.
// flag.ContinueOnError: notoʻgʻri flag'da Parse dasturni toʻxtatmaydi, xato qaytaradi (testlar uchun ham).
func loadConfig(args []string) (config, error) {
	fs := flag.NewFlagSet("api", flag.ContinueOnError)
	port := fs.String("port", envOr("PORT", "8765"), "HTTP port (muhitda: PORT)")
	if err := fs.Parse(args); err != nil {
		return config{}, err
	}

	var errs []error
	n, err := strconv.Atoi(*port)
	if err != nil || n < 1 || n > 65535 {
		errs = append(errs, fmt.Errorf("port %q: 1–65535 oraligʻidagi butun son kerak", *port))
	}
	db := os.Getenv("DATABASE_URL")
	if db == "" {
		errs = append(errs, errors.New("DATABASE_URL qoʻyilmagan: .env.example'ga qarang"))
	}
	if len(errs) > 0 {
		return config{}, errors.Join(errs...)
	}
	return config{port: n, databaseURL: db}, nil
}

// addr — http.Server'ning Addr maydoni: ":8765" — shu portda, kompyuterning hamma tarmoq manzillarida.
func (c config) addr() string {
	return fmt.Sprintf(":%d", c.port)
}

// String — config'ning log'dagi koʻrinishi. fmt'ning %v, %+v va %s'i shu metodni chaqiradi (GB-2.07).
// Bazadan faqat host va baza nomi: foydalanuvchi, parol va ?parametrlar chiqmaydi (OWASP Logging Cheat Sheet:
// «Database connection strings» log'ga toʻgʻridan-toʻgʻri yozilmaydi). %#v String'ni chaqirmaydi: config'ni %#v bilan yozmang.
func (c config) String() string {
	db := "[yashirin]"
	if u, err := url.Parse(c.databaseURL); err == nil && u.Host != "" {
		db = u.Host + u.Path
	}
	return fmt.Sprintf("port=%d db=%s", c.port, db)
}
```

Oldin tushuntirilgan `envOr` va `loadConfig` oʻzgarmadi. Toʻliq fayldagi yangi qatorlar:

| Qator | Nima qiladi |
|---|---|
| 1–13 | paket va izohlar; izohdagi «hammasi» yuqoridagi tekshiruv doirasi bilan cheklangan |
| 14–21 | kerakli standart paketlarni import qiladi |
| 23–27 | `config`ning ikki maydoni |
| 29–36 | `envOr`, yoʻq va boʻshni ajratadi |
| 38–60 | flag'ni oʻqish, validatsiya va bitta xato qaytarish |
| 62–65 | `addr()` `%d` bilan portni `":8765"` shakliga keltiradi |
| 67–69 | `String()`ning vazifasi va `%#v` cheklovi haqidagi izoh |
| 70–71 | qiymat qabul qiluvchi metod, standart natija `[yashirin]` |
| 72 | `Parse` muvaffaqiyatli va host boʻsh emasligini `&&` bilan tekshiradi |
| 73–74 | faqat `u.Host + u.Path`ni oladi; `u.User` va query olinmaydi |
| 75–76 | `%d` portni, `%s` tanlangan DB matnini formatlab qaytaradi |

`Host` borligi toʻliq va yaroqli Postgres manzili isboti emas. Bu log koʻrinishi uchun shart.
`[yashirin]` manzil shakli bu usulga mos kelmaganini bildiradi; xom qiymatni chiqarish shart emas.

Bu natija ham qayta bajarilgan. `%v`, `%+v`, `%s` bevosita `config` qiymatida `String()`dan foydalanadi.
**Chegara:** `%#v` bu metodni chetlab oʻtadi. Notoʻgʻri `%d` yoki boshqa structʼning kichik harfli maydonidagi config ham xom chiqishi mumkin.

## Chuqurroq (ixtiyoriy): buyruq qatori ham kuzatiladi

`DATABASE_URL`ni flag qilmaganimizning sababi bor. Linuxʼda buyruq qatori odatda boshqa foydalanuvchilarga koʻrinadi.
Videoda `ps -o args= -C api` va `pid=$(pgrep -x api)` ishlatilgan.
`-o args=` sarlavhasiz argumentlarni, `-C api` shu nomli barcha jarayonlarni tanlaydi; `pgrep -x` nomni toʻliq solishtiradi.
Bizning tekshiruvda shu nomli boshqa laboratoriya ham ishlayotgandi. Shu sabab faqat oʻz jarayonimiz PIDʼini tanladik.
PID — jarayon raqami. Server yuqoridagi buyruq bilan ishlayotgan paytda ikkinchi terminaldagi haqiqiy natija:

```console
$ ps -o args= -p 1036694
./api -port 8781
$ stat -c '%A %n' /proc/1036694/cmdline /proc/1036694/environ
-r--r--r-- /proc/1036694/cmdline
-r-------- /proc/1036694/environ
```

`-p` bitta PIDʼni tanlaydi; `stat -c` shablonida `%A` huquq, `%n` fayl nomi.
Videodagi PID `990337`; bizdagi raqam yuqorida. PID har safar oʻzgaradi.
`cmdline` huquqi bu safar `-r--r--r--`, `environ`niki `-r--------` boʻldi.
Bu muhit sirlar uchun mutlaq himoya degani emas: kirish procfs mount sozlamalari, jarayon holati va ptrace tekshiruvlariga ham bogʻliq.
[Linux hujjati](https://man7.org/linux/man-pages/man5/proc_pid_environ.5.html) `environ` uchun ptrace ruxsat tekshiruvini koʻrsatadi.

[OWASP Secrets Management](https://cheatsheetseries.owasp.org/cheatsheets/Secrets_Management_Cheat_Sheet.html) muhit qiymatlari log va xotira nusxalariga chiqishi mumkinligini eslatadi.
Katta tizimlarda secret manager — sirni boshqaradigan alohida xizmat — ishlatiladi.
Jarayon muhitini toʻliq chiqarmang. Tekshiruvdan keyin serverni `Ctrl+C` bilan toʻxtating va laboratoriya bazasini volume'i bilan olib tashlang:

```console
$ docker compose down -v

 Container gb801-db-1 Stopped 
 Container gb801-db-1 Removing 
 Container gb801-db-1 Removed 
 Volume gb801_pgdata Removing 
 Network gb801_default Removing 
 Volume gb801_pgdata Removed 
 Network gb801_default Removed
```

`down -v` shu laboratoriya maʼlumotini oʻchiradi. Boshqa xizmatning Compose loyihasida bajarmang.
Videodagi timing yoki tezlik oʻlchovi yoʻq; bu darsda muhim natija — chiqish kodi, tekshiruv tartibi va sirning chiqmasligi.

## Koʻp uchraydigan xatolar

1. **«Kichik harf parolni yashiradi».** Notoʻgʻri kod — yuqoridagi `fmt.Printf("config: %+v\n", cfg)`ning `String()`siz bosqichi.
   Uning haqiqiy chiqishi parolni koʻrsatdi. Tuzatish — tanlangan qiymatlarni chiqarish; JSON'ning maydon qoidasi `fmt`ga oʻtmaydi.
2. **Boʻsh `PORT`ni standartga almashtirish.** Yuqoridagi `PORT=` natijasida `port ""` va kod 1 chiqdi.
   Tuzatish — faqat `LookupEnv`dagi `ok == false` boʻlganda standartga oʻtish. Xato qiymatni jim yashirmang.
3. **Flag notoʻgʻri yozilgan.** `-host` hali starterʼda yoʻq. Quyidagi homework testi haqiqiy `flag provided but not defined: -host` xabarini beradi.
   Bu «flag berilgan, lekin taʼriflanmagan» degani. `fs.String("host", …)`ni `Parse`dan oldin yozing.
4. **`.gitignore` bilan eski commitʼni tuzatish.** Qoida kuzatiladigan faylga taʼsir qilmaydi.
   Tuzatish — oshkor credentialʼni darhol bekor qilish yoki almashtirish; keyin repo va tarixni tegishli tartibda tozalash.
5. **`loadConfig` hamma narsani tekshiradi deb oʻylash.** Baza URI'si keyin pgxʼda tekshiriladi; pozitsion argumentlar bu kodda rad etilmaydi.
   `flag.Parse` birinchi oddiy argumentda toʻxtaydi. Qoʻshimcha argumentlarni rad etish kerak boʻlsa, `fs.NArg()`ni tekshiring.
