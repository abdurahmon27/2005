## Nimani oʻrganasiz

Mijoz bozor'dan bitta olma va bitta anor buyurtma qildi. Katalogda anor yoʻq. Dastur xato bermadi:

```console
$ ./_video/run.sh 00-hook go run . olma anor
anor  1 dona
olma  1 dona
jami: 12000 soʻm
```

Anor chekka tushdi, jami esa faqat olmaning narxi. Dastur yoʻq mahsulotni nima uchun xatosiz qabul qildi va uni qanday rad
etasiz?

**Bitta gʻoya:** map — kalit boʻyicha qiymat topadigan jadval. Yoʻq kalit xato emas: map qiymat turining zero value'sini
qaytaradi, shuning uchun «yoʻq» bilan «nol»ni faqat comma-ok ajratadi. `range` map ustida har safar tasodifiy joydan
boshlaydi: tartib kerak boʻlsa, kalitlarni oʻzingiz saralaysiz.

Dars oxirida siz:

- `map[string]int64` turini yozasiz, uni map literal bilan toʻldirasiz va qiymatni kalit boʻyicha oʻqib, yozib, oʻchirasiz;
- `price, ok := prices[name]` bilan katalogda yoʻq mahsulotni rad etasiz;
- buyurtmadagi donalarni `count[name]++` bilan sanaysiz;
- chekni kalitlarni saralab har safar bir xil tartibda chiqarasiz va `var` bilan eʼlon qilingan map'ga yozish nega panic
  berishini bilib olasiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| map | kalit (nom) boʻyicha qiymat topadigan jadval: `map[string]int64` — nom → narx | map |
| comma-ok | `price, ok := prices[name]`: ikkinchi oʻzgaruvchi `ok` kalit map'da borligini aytadi (`true` / `false`) | comma-ok |
| map ustida `range` tartibi | `range` kalitlarni qaysi tartibda berishi belgilanmagan va har ishga tushirishda oʻzgarishi mumkin | map iteration order |

Ikkita yordamchi tushuncha: **`make`** bilan boʻsh map yaratish va nil map; hamda map qiymati jadvalning oʻzi emas, uning
manzili ekani (funksiyaga berilganda jadval nusxalanmaydi).

## Muammo: roʻyxatda nom boʻyicha qidirish

Narxlar slice'da turgan boʻlsa, olmaning narxini topish uchun roʻyxatni boshidan aylanib, har bir nomni «olma» bilan
solishtirasiz. 50 000 mahsulotda bitta soʻrov 50 000 tagacha solishtirishga olib keladi. Bu hisob-kitob, oʻlchov emas: roʻyxat

## Map: kalit boʻyicha qiymat

**Map** shu muammoni boshqacha hal qiladi. U kalitni **hash funksiyadan** oʻtkazadi: funksiya matndan son yasaydi. Son
jadvaldagi joyni koʻrsatadi, map faqat oʻsha joydagi kalitlarni solishtirib, qiymatni qaytaradi. Shuning uchun qidirish vaqti
oʻrtacha mahsulotlar soniga bogʻliq emas ([Go blog: Go maps in action](https://go.dev/blog/maps)). Ichki jadval **hash
jadval** (hash table) deyiladi.

```text
kalit "olma"  →  hash (matn → son)  →  jadvaldagi joy  →  qiymat 1200000 (olma narxi, tiyinda)
```

Muhim oqibat: joyni hash tanlaydi, shuning uchun jadvaldagi kalitlar na kiritilgan tartibda, na alifbo tartibida turadi.
Bu gap «Map ustida range» boʻlimida yana kerak boʻladi.

### Tur va literal

Birinchi dastur (`_video/01-map/main.go`):

```go filename="_video/01-map/main.go" showLineNumbers
package main

import "fmt"

const tiyinPerSom = 100 // 1 soʻm = 100 tiyin

func main() {
	prices := map[string]int64{
		"olma": 12_000 * tiyinPerSom,
		"non":  4_000 * tiyinPerSom,
	}
	fmt.Println(prices["olma"])
	prices["choy"] = 25_000 * tiyinPerSom
	fmt.Println(len(prices))
	fmt.Println(prices["anor"])
}
```

1–7-qatorlar sizga tanish (`package`, `import`, `const`, `func main`). Yangi qatorlar:

| Qator | Kod | Nima qiladi |
|---|---|---|
| 8 | `prices := map[string]int64{` | `prices` oʻzgaruvchisini yaratadi. `map[string]int64` — tur: kvadrat qavs ichida **kalit turi** (`string`, mahsulot nomi), undan keyin **qiymat turi** (`int64`, narx tiyinda). Jingalak qavs map literalni ochadi: qiymatlari kodda yozilgan map |
| 9–10 | `"olma": 12_000 * tiyinPerSom,` | literalning qatori: kalit, ikki nuqta, qiymat, oxirida vergul (GB-1.08'dagi `tests` roʻyxati kabi) |
| 11 | `}` | literalni yopadi: map'da ikki kalit bor |
| 12 | `fmt.Println(prices["olma"])` | kvadrat qavs ichida kalit: kalit boʻyicha **oʻqish** |
| 13 | `prices["choy"] = 25_000 * tiyinPerSom` | **yozish**: kalit yoʻq boʻlsa qoʻshiladi, bor boʻlsa qiymati almashadi |
| 14 | `fmt.Println(len(prices))` | `len` map'dagi kalitlar sonini beradi |
| 15 | `fmt.Println(prices["anor"])` | katalogda yoʻq `anor`ni oʻqiydi |

Kalit turi `==` bilan solishtiriladigan boʻlishi shart ([Go spec: Map types](https://go.dev/ref/spec#Map_types)). `string`
shunday tur.

Oxirgi qator nima chiqaradi? `anor` map'da yoʻq.

**A)** `0` · **B)** `panic` (dastur ish paytida xato bilan toʻxtaydi) · **C)** kompilyatsiya xatosi

<details>
<summary>Javob</summary>

**A: `0`.** Yoʻq kalit uchun map xato bermaydi: qiymat turining zero value'sini qaytaradi. `int64` uchun u `0`
([Go spec: Index expressions](https://go.dev/ref/spec#Index_expressions)). **B** ni tanlagan boʻlsangiz, slice'ning
chegaradan tashqari indeksidagi panic'ni (GB-1.07) eslagansiz: map'da bunday panic yoʻq. **C** — kod toʻgʻri, kompilyator
kalit mavjudligini tekshirmaydi.

</details>

```console
$ ./_video/run.sh 01-map go run .

3
0
```

Birinchi qator — olmaning narxi tiyinda (12 000 soʻm × 100). Ikkinchisi — `choy` qoʻshilgandan keyingi kalitlar soni.
Uchinchisi — yoʻq `anor` uchun `0`. Darsning boshidagi anor aynan shunday tekin boʻldi.

## Comma-ok: yoʻq kalit va nol narx

`0` narx ham boʻlishi mumkin (tekin mahsulot), yoʻq mahsulot ham `0` beradi. Ularni ajratish uchun indekslashning ikkinchi
shakli bor. Ikkinchi dastur (`_video/02-ok/main.go`) buyruq qatoridan bitta nom oladi:

```go filename="_video/02-ok/main.go" showLineNumbers
package main

import (
	"fmt"
	"os"
)

const tiyinPerSom = 100 // 1 soʻm = 100 tiyin

func main() {
	prices := map[string]int64{
		"olma": 12_000 * tiyinPerSom,
		"non":  4_000 * tiyinPerSom,
	}
	if len(os.Args) != 2 {
		fmt.Fprintln(os.Stderr, "foydalanish: bozor NOM")
		os.Exit(1)
	}
	name := os.Args[1]
	price, ok := prices[name]
	if !ok {
		fmt.Fprintln(os.Stderr, "xato:", name, "katalogda yoʻq")
		os.Exit(1)
	}
	fmt.Println(name, price/tiyinPerSom, "soʻm")
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 15–18 | `if len(os.Args) != 2 { … }` | soʻzlar sonini tekshiradi, GB-1.07'dagidek: dastur nomi va bitta mahsulot nomi boʻlmasa, foydalanish xabarini stderr'ga yozib, 1 kodi bilan chiqadi |
| 19 | `name := os.Args[1]` | `name` — buyruq qatoridagi birinchi soʻz (`os.Args[0]` — dastur nomi) |
| 20 | `price, ok := prices[name]` | chapda ikki oʻzgaruvchi: `price` — qiymat, `ok` — `bool`: kalit map'da boʻlsa `true`, boʻlmasa `false`. `false` boʻlganda `price` — zero value, ya'ni `0` |
| 21–24 | `if !ok { … }` | `!ok`, ya'ni «ok emas»: xatoni stderr'ga yozib, 1 kodi bilan chiqadi (GB-1.07) |
| 25 | `fmt.Println(name, price/tiyinPerSom, "soʻm")` | narxni tiyindan soʻmga boʻlib chiqaradi |

`v, ok := m[k]` shakli **comma-ok** deb ataladi: Go kodida u juda koʻp uchraydi. Uch holat:

| Holat | `price` | `ok` |
|---|---|---|
| kalit bor, narx 1 200 000 | `1200000` | `true` |
| kalit bor, narx `0` | `0` | `true` |
| kalit yoʻq | `0` | `false` |

```console
$ ./_video/run.sh 02-ok go run . olma
olma 12000 soʻm
$ ./_video/run.sh 02-ok go run . anor
xato: anor katalogda yoʻq
exit status 1
$ ./_video/run.sh 02-ok go run .
foydalanish: bozor NOM
exit status 1
```

`exit status 1` qatorini dasturning oʻzi emas, `go run` yozadi: dastur 1 kodi bilan tugaganini bildiradi (GB-1.07). Endi
«nol soʻm» va «mahsulot yoʻq» ikki xil holat.

## Nol qiymat va delete

Uchinchi dastur (`_video/03-delete/main.go`) qiymati nol boʻlgan kalitni oʻchirilgan kalit bilan solishtiradi:

```go filename="_video/03-delete/main.go" showLineNumbers
package main

import "fmt"

const tiyinPerSom = 100 // 1 soʻm = 100 tiyin

func main() {
	prices := map[string]int64{
		"olma": 12_000 * tiyinPerSom,
		"non":  4_000 * tiyinPerSom,
	}
	prices["olma"] = 0
	_, ok := prices["olma"]
	fmt.Println(len(prices), ok)
	delete(prices, "non")
	_, ok = prices["non"]
	fmt.Println(len(prices), ok)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 12 | `prices["olma"] = 0` | olmaga nol yozadi: kalit joyida qoladi, faqat qiymati almashadi |
| 13 | `_, ok := prices["olma"]` | comma-ok bilan tekshiradi; qiymat kerak emas, `_` uni tashlaydi |
| 14 | `fmt.Println(len(prices), ok)` | kalitlar sonini va `ok`ni chiqaradi |
| 15 | `delete(prices, "non")` | `delete` — Go'ga oʻrnatilgan funksiya: birinchi argument map, ikkinchisi oʻchiriladigan kalit |
| 16 | `_, ok = prices["non"]` | `ok` allaqachon bor, shuning uchun `:=` emas, `=` |
| 17 | `fmt.Println(len(prices), ok)` | yana kalitlar soni va `ok` |

Dastur ikki qator chiqaradi, har birida avval `len`, keyin `ok`. Qaysi variant toʻgʻri?

**A)** `2 true`, keyin `1 false` · **B)** `2 false`, keyin `1 false` · **C)** `1 false`, keyin yana `1 false`

<details>
<summary>Javob</summary>

**A.** Nol qiymatli `olma` map'da bor: `len` 2, `ok` `true`. `delete(prices, "non")` dan keyin bitta kalit qoldi va `non` uchun
`ok` `false`. **B** ni tanlagan boʻlsangiz, nol narxni «yoʻq» deb oʻylagansiz: kalit `0` qiymat bilan ham map'da turadi. **C** —
`prices["olma"] = 0` kalitni oʻchirmaydi, faqat qiymatini almashtiradi.

</details>

```console
$ ./_video/run.sh 03-delete go run .
2 true
1 false
```

| Qator | `prices` (kalit → qiymat) | `len` | `ok` |
|---|---|---|---|
| 12 dan keyin | `olma → 0`, `non → 4000·100` | 2 | |
| 13–14 | oʻzgarmadi | 2 | `true` (`olma` bor) |
| 15 dan keyin | `olma → 0` | 1 | |
| 16–17 | oʻzgarmadi | 1 | `false` (`non` yoʻq) |

Yoʻq kalitni `delete` qilish xato emas, hech narsa qilmaydi: spec buni ochiq yozadi (*«If the map m is nil or the element
m[k] does not exist, delete is a no-op»*, [Go spec: Deletion of map elements](https://go.dev/ref/spec#Deletion_of_map_elements)).
Bu gapni men alohida ishga tushirmadim, spec'dan keltirdim.

## make bilan boʻsh map va sanash

Buyurtmadagi donalarni sanash uchun boʻsh map kerak. Uni `make` yaratadi. GB-2.01'da `make` slice uchun massiv ajratgan edi,
map uchun u boʻsh jadval ajratadi ([Go spec: Making slices, maps and channels](https://go.dev/ref/spec#Making_slices_maps_and_channels)).
Toʻliq dastur (bu fayl kurs papkasida yoʻq: men uni alohida papkada ishga tushirdim):

```go
package main

import "fmt"

func main() {
	order := []string{"olma", "non", "olma"}
	count := make(map[string]int)
	for _, name := range order {
		count[name]++
	}
	fmt.Println(count["olma"], count["anor"])
}
```

```console
$ go run .
2 0
```

`count[name]++` — «yoʻq kalit nol beradi» qoidasidan foydalanish: yoʻq kalitning qiymati `0`, unga 1 qoʻshib yozamiz. Sikl
qadamlari:

| Sikl qadami | `name` | `count` jadvali |
|---|---|---|
| `make` dan keyin | | boʻsh |
| 1 | `olma` | `olma 1` (yoʻq edi: `0 + 1`) |
| 2 | `non` | `olma 1`, `non 1` |
| 3 | `olma` | `olma 2`, `non 1` (`1 + 1`) |

Oxirida `count["olma"]` — 2, yoʻq `count["anor"]` — 0. Rasmda `count` oʻzgaruvchisida jadvalning oʻzi emas, uning xotiradagi
manzili turadi, slice sarlavhasidagi `ptr` kabi (GB-2.01). Kodda «jadval» degan nom yoʻq: bu runtime yaratgan hash jadval.

```text
count (map[string]int)          hash jadval (runtime yaratgan)
┌──────────────┐                ┌─────────┬───┐
│  manzil   ───┼──────────────► │ olma    │ 2 │
└──────────────┘                │ non     │ 1 │
                                └─────────┴───┘
```

## Map ustida range va uning tartibi

Endi nomlar buyruq qatoridan keladi. Toʻrtinchi dastur (`_video/04-tartib/main.go`):

```go filename="_video/04-tartib/main.go" showLineNumbers
package main

import (
	"fmt"
	"os"
)

func main() {
	order := os.Args[1:]
	count := make(map[string]int)
	for _, name := range order {
		count[name]++
	}
	for name, n := range count {
		fmt.Println(name, n)
	}
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 9 | `order := os.Args[1:]` | kvadrat qavsda `1:` — birinchi indeksdan oxirigacha: dastur nomidan keyingi barcha soʻzlar ([Go spec: Slice expressions](https://go.dev/ref/spec#Slice_expressions)) |
| 10–13 | `count := make(…)` va sikl | oldingi boʻlimdagi sanash |
| 14 | `for name, n := range count {` | map ustida `range` ikki oʻzgaruvchi beradi: `name` — kalit, `n` — qiymat |
| 15 | `fmt.Println(name, n)` | har juftni chiqaradi |

`go run . olma non olma choy` bir necha marta ishga tushiriladi. Qatorlar tartibi qanday boʻladi?

**A)** har safar kiritilgan tartibda: `olma`, `non`, `choy` · **B)** alifbo boʻyicha: `choy`, `non`, `olma` · **C)** ishga
tushirishlar orasida oʻzgarishi mumkin

<details>
<summary>Javob</summary>

**C: oʻzgarishi mumkin.** Hash joyni tanlaydi (yuqorida koʻrdingiz), `range` esa jadvalni tasodifiy joydan boshlab aylanadi. **A**
koʻpincha chiqadi, shuning uchun uni tanlash tabiiy, lekin kafolat yoʻq. **B** ni tanlagan boʻlsangiz, map kalitlarni saralab
saqlaydi deb oʻylagansiz: unday emas.

</details>

Sababi spec'da: *«The iteration order over maps is not specified and is not guaranteed to be the same from one iteration to
the next»* ([Go spec: For statements with range clause](https://go.dev/ref/spec#For_range)). Runtime har `range` boshida
tasodifiy boshlanish joyini tanlaydi, ataylab: dasturchilar tartibga tayanmasin deb ([Go blog](https://go.dev/blog/maps):
*«you should not rely on it»*; [Go 1 release notes](https://go.dev/doc/go1#iteration)). Xavfi: tartibga tayangan test
koʻpincha oʻtadi va bir kuni yiqiladi. Bu yerda ishga tushirishlarning taxminan toʻrtdan biri boshqa tartib beradi.

## Tartib kerak boʻlsa: kalitlarni saralash

Tartib kerak boʻlsa, uni oʻzingiz yasaysiz: kalitlarni slice'ga yigʻasiz, slice'ni saralaysiz va slice ustida yurasiz. Beshinchi
dastur (`_video/05-sort/main.go`):

```go filename="_video/05-sort/main.go" showLineNumbers
package main

import (
	"fmt"
	"os"
	"slices"
)

func main() {
	order := os.Args[1:]
	count := make(map[string]int)
	for _, name := range order {
		count[name]++
	}
	var names []string
	for name := range count {
		names = append(names, name)
	}
	slices.Sort(names)
	for _, name := range names {
		fmt.Printf("%-5s %d dona\n", name, count[name])
	}
}
```

## Map funksiyaga berilganda

`restock` funksiyasi `s` parametri orqali olmaga 10 qoʻshadi. `main`dagi `stock`da olma 40 edi. Chaqiruvdan keyin u nechta?
Toʻliq dastur (kurs papkasida yoʻq, men ishga tushirdim):

```go
package main

import "fmt"

func restock(s map[string]int) {
	s["olma"] += 10
}

func main() {
	stock := map[string]int{"olma": 40}
	restock(stock)
	fmt.Println(stock["olma"])
}
```

**A)** `40` · **B)** `50` · **C)** kompilyatsiya xatosi

<details>
<summary>Javob</summary>

**B: `50`.** Go argumentni nusxalaydi, lekin map qiymati jadvalning oʻzi emas, uning manzili. `restock(stock)` da `s` shu
manzilning nusxasi, shuning uchun `s` ham oʻsha jadvalga qaraydi. **A** ni tanlagan boʻlsangiz, funksiya butun jadvalni
nusxalaydi deb oʻylagansiz: nusxalanadigan faqat manzil. **C** — kod toʻgʻri: map parametr sifatida berilaveradi.

</details>

```console
$ go run .
50
```

| Qator | `stock` | `s` | jadval |
|---|---|---|---|
| `stock := map[string]int{"olma": 40}` | manzil → jadval | | `olma 40` |
| `restock(stock)` chaqirildi | manzil → jadval | manzilning nusxasi → **shu** jadval | `olma 40` |
| `s["olma"] += 10` | manzil → jadval | manzil → jadval | `olma 50` |
| `fmt.Println(stock["olma"])` | | | `50` chiqadi |

Map «havola turi»: Go blog'ning soʻzlari — *«Map types are reference types»* ([Go maps in action](https://go.dev/blog/maps)).
Vazifada shu muhim: `reserve`ga `stock` jadvalining manzili keladi, shuning uchun xato boʻlsa ombor oʻzgarmasligi uchun
avval hammasini tekshirish kerak.

## Chuqurroq (ixtiyoriy): nega aynan uchta tartib va nega 75 %

Bu boʻlim runtime tafsiloti: unga tayanmang, kod uchun muhim emas. Kichik map'da (sakkiztagacha kalit) Go 1.24'dan beri kalitlar
8 oʻrinli bitta guruhda, qoʻshilgan tartibda turadi (oʻchirishlar boʻlmasa; [Go 1.24 release notes](https://go.dev/doc/go1.24#runtime)).
`range` boshlanish joyini 8 oʻrindan tasodifiy tanlaydi (runtime manbasida `it.entryOffset = rand()`; men uni
`go1.27.4` manbasida topdim, `src/internal/runtime/maps/table.go`, 757-qator). Bizda 3 kalit va 5 boʻsh oʻrin:

| Boshlanish oʻrni | 0 | 1 | 2 | 3–7 (boʻsh) |
|---|---|---|---|---|
| Chiqadigan tartib | `olma non choy` | `non choy olma` | `choy olma non` | `olma non choy` |

8 oʻrindan 6 tasi `olma`dan boshlanadigan tartibni beradi: 6/8 = 75 %. Qolgan ikki oʻrin 12,5 % dan. Oʻlchovimiz (taxminan 75 %,
12,5 %, 12,5 %) bilan mos. Faqat 3 ta tartib chiqadi, 6 tasi emas: tartib tasodifiy boshlanadi, ammo aralashtirilmaydi.

## Koʻp uchraydigan xatolar

### 1. Yoʻq kalit xato beradi deb oʻylash

Eng koʻp uchraydigan xato — `price := prices[name]` yozib, `name` map'da yoʻq boʻlsa xato chiqadi deb kutish. Xato chiqmaydi:
`price` — `0`. Darsning boshidagi chek shundan: `_video/00-hook/main.go` dagi sikl qatori `price := prices[name]` edi, anor 0 soʻmga
sotildi (natija «Nimani oʻrganasiz» boʻlimida). Tuzatish — comma-ok va `if !ok` (yuqoridagi «Comma-ok: yoʻq kalit va nol narx» boʻlimi).

### 2. `var` bilan eʼlon qilingan map'ga yozish

`var stock map[string]int` — GB-1.02'dan bilasiz: qiymatsiz eʼlon qilingan oʻzgaruvchida zero value turadi. Map uchun u `nil`: jadval
umuman yoʻq. `_video/06-nil/main.go`:

**A)** `0 0`, keyin panic · **B)** `0 0` va `40` · **C)** kompilyatsiya xatosi

**A.** nil map'dan oʻqish boʻsh map kabi `0` beradi, `len` ham `0` (7-qator). Yozish uchun esa jadval kerak: 8-qatorda runtime
panic qiladi. **B** ni tanlagan boʻlsangiz, yozish jadvalni oʻzi yaratadi deb oʻylagansiz: yaratmaydi. **C** — kod

### 3. Tartibga tayanish

`range` tartibiga tayangan chek yoki test kunlarning birida yiqiladi. Nima boʻlishi va qanday tuzatilishi
«Map ustida range va uning tartibi» hamda «Tartib kerak boʻlsa: kalitlarni saralash» boʻlimlarida: kalitlarni saralab, slice
ustida yuring.

## Oʻzingizni tekshiring

1. Yoʻq kalit nima qaytaradi va uni haqiqiy noldan qanday ajratasiz?

<details>
<summary>Javob</summary>

Qiymat turining zero value'sini (`int64` uchun `0`). Ajratish uchun comma-ok: `price, ok := prices[name]`; kalit yoʻq boʻlsa `ok`
`false` boʻladi, nol narx boʻlsa `true`.

</details>

2. Chekni har safar bir xil tartibda chiqarish uchun nima qilasiz?

<details>
<summary>Javob</summary>

Kalitlarni slice'ga yigʻasiz (`names = append(names, name)`), `slices.Sort(names)` bilan saralaysiz va map emas, slice ustida
`range` qilasiz. Map ustida `range` tartibi kafolatlanmagan.

</details>

3. GB-1.07'dan: `os.Args`ning nolinchi elementida nima turadi? Shuning uchun buyurtma qaysi indeksdan boshlanadi?

<details>
<summary>Javob</summary>

Dastur nomi. Shuning uchun buyurtma birinchi indeksdan boshlanadi: `os.Args[1:]`.

</details>

```go filename="solution/main.go" showLineNumbers
package main

import (
	"fmt"
	"os"
	"slices"
)

const tiyinPerSom = 100 // 1 soʻm = 100 tiyin

// reserve buyurtmadagi mahsulotlarni ombordan ayiradi. Biror mahsulot katalogda
// yoʻq boʻlsa yoki yetmasa, xato qaytaradi va omborni oʻzgartirmaydi.
func reserve(stock map[string]int, order []string) error {
	need := make(map[string]int)
	for _, name := range order {
		need[name]++
	}
	// avval hammasini tekshiramiz: shu yerda ombor hali oʻzgarmagan
	for _, name := range order {
		have, ok := stock[name]
		if !ok {
			return fmt.Errorf("%s omborda yoʻq", name)
		}
		if have < need[name] {
			return fmt.Errorf("%s: omborda %d dona, buyurtmada %d", name, have, need[name])
		}
	}
	// keyin ayiramiz: stock chaqiruvchining jadvali, oʻzgarish unga ham koʻrinadi
	for name, n := range need {
		stock[name] -= n
	}
	return nil
}

func main() {
	prices := map[string]int64{
		"olma": 12_000 * tiyinPerSom,
		"non":  4_000 * tiyinPerSom,
		"choy": 25_000 * tiyinPerSom,
	}
	order := os.Args[1:]
	count := make(map[string]int)
	var total int64
	for _, name := range order {
		price, ok := prices[name]
		if !ok {
			fmt.Fprintln(os.Stderr, "xato:", name, "katalogda yoʻq")
			os.Exit(1)
		}
		count[name]++
		total += price
	}
	var names []string
	for name := range count {
		names = append(names, name)
	}
	slices.Sort(names)
	for _, name := range names {
		fmt.Printf("%-5s %d dona\n", name, count[name])
	}
	fmt.Printf("jami: %d soʻm\n", total/tiyinPerSom)
}
```

Fikr: `reserve` ikki bosqichda ishlaydi. Avval hammasini tekshiradi, keyin ayiradi. Sababi — oldingi boʻlim: `stock` chaqiruvchining
jadvali, `stock[name] -= n` unga darhol koʻrinadi. Agar tekshirish va ayirish aralash boʻlsa, ikkinchi mahsulotda xato chiqqanda
birinchisi allaqachon ayirilgan boʻlardi.

- 14–17-qatorlar: `need` — `make` bilan yangi map; `need[name]++` buyurtmadagi donalarni sanaydi (`olma non olma` → `olma 2`, `non 1`);
- 18–27-qatorlar: buyurtma ustida yurib har nom `have, ok := stock[name]` bilan tekshiriladi. `!ok` — `omborda yoʻq`, `have < need[name]` — yetmaydi. Hech narsa
  yozilmaydi, shuning uchun xato bilan qaytsak, ombor oʻzgarmagan;
- 28–32-qatorlar: xato yoʻq, endi `stock[name] -= n` (`x -= n` — `x = x - n`) ayiradi. Bu yerda tartib muhim emas, shuning uchun map ustida `range` yetadi.
