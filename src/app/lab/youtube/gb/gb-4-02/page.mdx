## Nimani oʻrganasiz

bozor narxlarni soʻmda saqlaydi, mijozlar esa narxni dollarda ham koʻrmoqchi. Dollar kursi har kuni oʻzgaradi, shuning uchun uni tashqi **API**'dan olamiz: API — boshqa dastur HTTP orqali beradigan maʼlumot.
Bu bitta chaqiruv, lekin unda uchta joyda xato qilish mumkin. Bugun shu uch joyni yopamiz.

**Bitta gʻoya:** `http.Get` va `client.Get` faqat soʻrov **bajarilmasa** xato qaytaradi: ulanish uzildi, muddat tugadi, protokol xatosi, yoʻnaltirish haddan ortiq koʻp.
Server javob bergan boʻlsa — `404` ham, `503` ham — `err` boʻsh (`nil`) va holat `resp.StatusCode`da yotadi: uni oʻzimiz tekshiramiz. Standart client'da `Timeout` 0, ya'ni javobni kutishga
chegara yoʻq; jim server dasturni abadiy toʻxtatib qoʻyadi, shuning uchun `&http.Client{Timeout: …}` beramiz. `resp.Body` — oqim: xato tekshiruvidan **keyin**
`defer resp.Body.Close()` yozamiz va JSON'ni `Decode` bilan oʻqiymiz.

Dars oxirida siz:

- standart `http.Get` nega jim serverni cheksiz kutishini koʻrib, `http.Client{Timeout: 2 * time.Second}` bilan kutishni cheklaysiz;
- `404` javobida `err` nega `nil` ekanini koʻrasiz va `resp.StatusCode != http.StatusOK` tekshiruvini yozasiz;
- `resp.Body`ni `defer resp.Body.Close()` bilan yopasiz, `defer`ni xato tekshiruvidan oldin yozish xatosini `go vet` topishini koʻrasiz;
- JSON'ni `rateResponse` struct'iga oʻqiydigan `fetchRate` yozasiz va uning uchinchi tuzogʻini (status `200`, lekin body'da xato) koʻrasiz;
- vazifada `fetchRate`ni shu tuzoqdan, `*StatusError` turi va `io.LimitReader` bilan himoya qilib, `go test` ni oʻtkazasiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| Timeout (kutish chegarasi) | client javobni kutadigan eng uzun vaqt; `0` — chegara yoʻq | timeout |
| status tekshiruvi | javob kelgach `resp.StatusCode`ni oʻzimiz solishtirishimiz | status check |
| `resp.Body` va `Close` | javobning asosiy qismi: oqim sifatida oʻqiladi, soʻng yopiladi | response body, close |

Yordamchi soʻzlar: `time.Second` va `&http.Client{…}` yozuvi, `float64(x)` hamda `%.2f`/`%.0f` (faqat narxni koʻrsatish uchun).

## API va birinchi chaqiruv: http.Get

Avval API'ning oʻzi. Manzil: `https://open.er-api.com/v6/latest/USD`. Uni qismlarga ajratamiz ([GB-4.01](/lab/youtube/gb/gb-4-01)dagi manzil kabi):

| Qism | Maʼnosi |
|---|---|
| `https://` | protokol: HTTP, shifrlangan ulanish (TLS) bilan |
| `open.er-api.com` | server nomi: ochiq kurs API'si |
| `/v6/latest/USD` | yoʻl: 6-versiya, eng soʻnggi kurslar, hisob bir dollardan: bir dollar boshqa valyutalarda necha turadi |

Kalit shart emas. Javob — JSON ([GB-3.02](/lab/youtube/gb/gb-3-02)). Bizga kerak qismi shunday (`…` — tushirib qoldirilgan qiymatlar):

```json
{
  "result": "success",
  "base_code": "USD",
  "rates": { "EUR": 0.911313, "UZS": 11966.840025, … }
}
```

| Kalit | Maʼnosi |
|---|---|
| `result` | `"success"` — soʻrov oʻtdi |
| `base_code` | `"USD"` — hisob bir dollardan |
| `rates` | valyuta kodi va kursi: `"UZS"` — soʻm, `1 USD = 11966.84 soʻm` |

Endi Go'dan chaqiramiz. Birinchi qadam — `_video/01-get/main.go`:

```go filename="_video/01-get/main.go" showLineNumbers
package main

import (
	"fmt"
	"net/http"
	"os"
)

func main() {
	resp, err := http.Get("https://open.er-api.com/v6/latest/USD")
	if err != nil {
		fmt.Fprintln(os.Stderr, "xato:", err)
		os.Exit(1)
	}
	fmt.Println(resp.Status, resp.StatusCode)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 3–7 | `import ( "fmt"; "net/http"; "os" )` | `net/http` — HTTP uchun standart paket, bugungi yangilik; `fmt` va `os` oldingi darslardan |
| 10 | `resp, err := http.Get("…")` | berilgan manzilga GET soʻrovi yuboradi va **ikkita** qiymat qaytaradi: `resp` — javob, `err` — xato |
| 11–14 | `if err != nil { … os.Exit(1) }` | xato boʻlsa `xato:` deb standart xato oqimiga (`os.Stderr`) chiqaradi va chiqish kodi 1 bilan tugaydi ([GB-1.07](/lab/youtube/gb/gb-1-07)) |
| 15 | `fmt.Println(resp.Status, resp.StatusCode)` | `resp.Status` — javob qatorining matni (`200 OK`), `resp.StatusCode` — shu kodning son koʻrinishi (`200`, `int`) |

Oldin oʻylab koʻring. Dastur nima chiqaradi?

**A)** `200` · **B)** `200 OK 200` · **C)** `OK 200`

**B.** `Println` ikkita qiymatni boʻshliq bilan yozadi: `resp.Status` oʻzi ikki soʻz (`200 OK`), undan keyin `resp.StatusCode` (`200`). **A** da `Status` yoʻq; **C** da kod yoʻq: `Status` kodni ham oʻz ichiga oladi.

</details>

Bir qator ishlaydi. Lekin `http.Get` **standart client**'dan foydalanadi, va uning bir sozlamasi tashqi serverga bogʻliq xavf tugʻdiradi.

## Birinchi jim xato: javob bermaydigan server

Standart client'da `Timeout` 0, nol esa **javobni kutishga chegara yoʻq** degani. Aniqrogʻi: standart transport ulanishni ochish uchun 30 soniya, TLS qoʻl siqishuvi uchun 10 soniya beradi,
lekin ulanish ochilgach javob sarlavhalarini kutishga cheklov qoʻymaydi. Server ulanishni qabul qilib, javob bermay tursa, dastur kutaveradi.

Buni koʻrish uchun javob bermaydigan server kerak. Ikkinchi terminalda `nc` buyrugʻi:

```console
$ nc -l 8089
```

`nc` hech narsa chiqarmaydi: u turib kutadi. `nc` (netcat) — oddiy tarmoq dasturi, `-l` (listen) — "tingla". `8089` — **port**: shu kompyuterdagi bitta dasturning tarmoq raqami.
`nc` shu portdagi ulanishni qabul qiladi, lekin hech narsa yozmaydi: bu — "jim server". (`nc` dasturlari har xil: bu LibreSSL/OpenBSD varianti; GNU netcat'da `nc -l -p 8089`.)

Dasturni shu serverga qaratamiz. Manzil — `http://localhost:8089`: `localhost` — shu kompyuterning oʻzi, `8089` — port. `_video/02-sukut/main.go` oldingisidan ikki joyda farq qiladi
(boshqa qatorlar xuddi shu):

```go
	fmt.Println("soʻrov yuborildi")
	resp, err := http.Get("http://localhost:8089")
```

Birinchi qator `Get`dan oldin matn chiqaradi: soʻrov ketgani koʻrinsin. Ikkinchisida manzil — jim `nc`. Natija qanday boʻladi?

**A)** darhol xato · **B)** 30 soniyadan keyin xato · **C)** xato yoʻq: dastur kutib turadi

<details>
<summary>Javob</summary>

**C.** `http.Get` standart client bilan chaqirilgan, `Timeout` 0: kutishga chegara yoʻq. Ulanish ochildi (`nc` uni qabul qildi), shuning uchun ulanish xatosi ham yoʻq; javob esa kelmaydi.
**A** boʻlardi, agar port hech kim tinglamasa ("connection refused"). **B** — 30 soniya faqat ulanishni *ochish* cheklovi; ulanish allaqachon ochilgan.

</details>

Terminal'da `nc`ni ishga tushirib, boshqa terminalda dasturni yurgizamiz. Videoda dastur Control C bilan toʻxtatildi. Takrorlanadigan boʻlishi uchun men oʻsha signalni `timeout` bilan, 6 soniyadan keyin yubordim:

```console
$ cd _video/02-sukut && timeout -s INT 6 go run .
soʻrov yuborildi
signal: interrupt
```

`soʻrov yuborildi` chiqdi, keyin 6 soniya hech narsa. `signal: interrupt` — dastur uzildi (`interrupt` — Control C yuboradigan signal). Videoda Control C ni bosganingizda terminal `^C` ni oʻzi koʻrsatadi
(`^Csignal: interrupt`); `timeout` bilan `^C` chiqmaydi, qolgani bir xil. 6 soniya tasodif emas: men oʻzim toʻxtatdim; toʻxtatmasam, dastur 30 soniyadan keyin ham kutib turadi.
Server hech qachon javob bermasa, bizning dastur ham hech qachon davom etmaydi.

## Yechim: http.Client va Timeout

Yechim — oʻz **client**'imiz. `http.Client` — struct, uning maydonlari bor; `Timeout` maydoniga kutish chegarasini beramiz. `_video/03-timeout/main.go`:

```go filename="_video/03-timeout/main.go" showLineNumbers
package main

import (
	"fmt"
	"net/http"
	"os"
	"time"
)

func main() {
	client := &http.Client{Timeout: 2 * time.Second}
	resp, err := client.Get("http://localhost:8089")
	if err != nil {
		fmt.Fprintln(os.Stderr, "xato:", err)
		os.Exit(1)
	}
	fmt.Println(resp.Status)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 7 | `"time"` | `time` — vaqt bilan ishlaydigan standart paket |
| 11 | `client := &http.Client{Timeout: 2 * time.Second}` | `http.Client{…}` — `Client` struct'i, `Timeout` maydoni bilan; `time.Second` — bir soniya, `2 * time.Second` — ikki soniya; `&` struct'ning **manzilini** oladi ([GB-2.04](/lab/youtube/gb/gb-2-04)), shunda bitta client hamma chaqiruvda ishlatiladi |
| 12 | `resp, err := client.Get("http://localhost:8089")` | endi `client.Get`: `http.Get` emas, oʻz client'imiz. Manzil — yana jim `nc` |

Server hamon jim. Nima chiqadi?

**A)** 2 soniyadan keyin xato · **B)** darhol xato · **C)** hamon kutadi

<details>
<summary>Javob</summary>

**A.** `Timeout` — kutishning chegarasi. U oshsa, client soʻrovni toʻxtatadi va `Get` xato qaytaradi. **C** — `Timeout` 0 boʻlgan (standart) client'dagi holat. **B** — `Timeout`dan oldin xato qilish uchun sabab yoʻq.

</details>

Yangi `nc` ishga tushiramiz (u bir ulanishdan keyin tugaydi) va dasturni yurgizamiz:

```console
$ cd _video/03-timeout && go run .
xato: Get "http://localhost:8089": context deadline exceeded (Client.Timeout exceeded while awaiting headers)
exit status 1
```

Xabar qismlari: `Get "http://localhost:8089"` — qaysi chaqiruv va manzil; `context deadline exceeded` — "muddat tugadi"; qavs ichida — sababi: `Client.Timeout exceeded while awaiting headers`,
ya'ni `Timeout` oshdi, javob sarlavhalari kelmadi. Xabardagi `context` soʻzini [GB-7.03 · `select` va `context`](/lab/youtube/gb/gb-7-03)da ochamiz; hozir "muddat" deb oʻqish yetadi.
`exit status 1` — `os.Exit(1)`dan ([GB-1.07](/lab/youtube/gb/gb-1-07)). Endi kutish chegaralangan, dastur qotib qolmaydi.

Chizma:

| Vaqt | Nima boʻladi |
|---|---|
| 0 s | dastur `client.Get` ni chaqiradi, soʻrov ketadi; client taymerni 2 soniyaga ishga tushiradi |
| 0–2 s | server (`nc`) jim turadi |
| 2 s | taymer tugaydi; `Get` xato qaytaradi: `deadline exceeded` |

Bu 2 soniyani oʻlchab koʻrdim. Videodagi raqam — "2 soniya" (kod shunday yozilgan). Yangi `nc` bilan binary qurib, `time` bilan oʻlchadim (bu oʻlchash videoda yoʻq):

```console
$ go build -o kurs .
```

`go build` hech narsa chiqarmadi: yangi `kurs` fayli paydo boʻldi (kerak boʻlmasa oʻchirib tashlang).

```console
$ time ./kurs
xato: Get "http://localhost:8089": context deadline exceeded (Client.Timeout exceeded while awaiting headers)

real	0m2.003s
user	0m0.000s
sys	0m0.003s
```

`real` — devor soatidagi vaqt: 2.003 soniya, `Timeout: 2 * time.Second` ga deyarli teng (ikkinchi yurishda ham 2.003). Mashina band boʻlsa, yuzdan bir soniyalar qoʻshilishi mumkin; muhimi — nisbat:
**client kutish vaqti `Timeout` qiymatiga teng, mashina tezligiga emas**. `user` va `sys` — protsessor vaqti: dastur kutayotganda deyarli hech narsa qilmaydi. (`time` chiqishi shell'ga qarab boshqacha koʻrinadi: bu bash.)

## Ikkinchi jim xato: 404 xato emas

Ikkinchi holat: server javob beradi, lekin kutganimiz emas. Mavjud boʻlmagan manzilga soʻrov yuboramiz: `/v6/nothing`. `_video/04-404/main.go`:

```go filename="_video/04-404/main.go" showLineNumbers
package main

import (
	"fmt"
	"net/http"
	"os"
	"time"
)

func main() {
	client := &http.Client{Timeout: 2 * time.Second}
	resp, err := client.Get("https://open.er-api.com/v6/nothing")
	if err != nil {
		fmt.Fprintln(os.Stderr, "xato:", err)
		os.Exit(1)
	}
	fmt.Println("err:", err)
	fmt.Println(resp.Status, resp.StatusCode)
}
```

Yangi qatorlar: 12 — manzil `/v6/nothing` ("hech narsa": bunday yoʻl yoʻq); 17 — `err`ning oʻzini chiqaradi (bu yerga faqat `err == nil` boʻlsa yetib kelamiz); 18 — status. `Get` nima qaytaradi?

**A)** `err != nil`, `resp` yoʻq · **B)** `err` nil, status `404` · **C)** panic

<details>
<summary>Javob</summary>

**B.** Server javob berdi, shuning uchun soʻrov **bajarildi**: `err` nil, `404` esa `resp` ichida. **A** — aloqa muammosi boʻlsa shunday boʻlardi (oldingi boʻlim). **C** — `Get` panic qilmaydi; panic keyinroq, `resp` boʻlmagan joyda ishlatilsa chiqadi.

</details>

```console
$ cd _video/04-404 && go run .
err: <nil>
404 Not Found 404
```

`err: <nil>` — xato yoʻq (`nil`, chiqarilganda `<nil>` koʻrinadi, [GB-1.07](/lab/youtube/gb/gb-1-07)); `404 Not Found 404` — `Status` va `StatusCode`. `Get` hujjati buni aniq aytadi:
*"A non-2xx response doesn't cause an error"* — `2xx` bilan boshlanmaydigan javob xato keltirmaydi. `Get` xato qaytaradi, agar soʻrov bajarilmasa: ulanish, muddat yoki protokol xatosi, yoʻnaltirishlar haddan koʻp.
**Statusni tekshirish — bizning ishimiz.**

Buni bozor boshqa joydan chaqiradigan funksiyaga oʻraymiz. `fetchRate`: kirishida client, manzil va valyuta kodi, chiqishida kurs va xato.

```go
func fetchRate(client *http.Client, url, code string) (float64, error) {
	resp, err := client.Get(url)
	if err != nil {
		return 0, err
	}
	// …
}
```

`url, code string` — ikkala parametr ham `string` (`url string, code string` ning qisqa yozuvi); `client *http.Client` — `Client`ga **pointer** ([GB-2.04](/lab/youtube/gb/gb-2-04)): `&http.Client{…}` shu turni beradi.
Natijalar `(float64, error)`: kurs (kasr son) va xato ([GB-1.07](/lab/youtube/gb/gb-1-07)). `Get` endi client'ning oʻzidan. Xatoda nol va `err` qaytaramiz.

Status tekshiruvi:

```go
	resp, err := client.Get(url)
	if err != nil {
		return 0, err
	}
	if resp.StatusCode != http.StatusOK {
		return 0, fmt.Errorf("kurs soʻrovi: javob %s", resp.Status)
	}
	// …
```

`http.StatusOK` — `200` sonining nomi (paketdagi konstanta). `StatusCode` unga teng boʻlmasa, oʻzimiz xato yasaymiz: `fmt.Errorf` ([GB-1.07](/lab/youtube/gb/gb-1-07)). Xabarga `resp.Status` ni qoʻshdik, nima boʻlgani koʻrinib tursin
(masalan `kurs soʻrovi: javob 404 Not Found`). Bu hozircha oddiy matn: vazifada uni oʻz turingiz bilan almashtirasiz.

Endi uchala holatni bir jadvalda yigʻamiz:

| Holat | `err` | `resp.StatusCode` | Nima qilamiz |
|---|---|---|---|
| ulanish yoʻq, muddat tugadi | `!= nil` | `resp` ham yoʻq | `err`ni qaytaramiz |
| server javob berdi, lekin `200` emas | `nil` | `404`, `503`, … | oʻzimiz tekshirib, xato yasaymiz |
| server `200` berdi | `nil` | `200` | body'ni oʻqiymiz |

## resp.Body: oqim, Close va JSON

Uchinchisi — body. Javob ikki qismdan keladi:

```text
client.Get(url)
   │
   ▼
server ──► status qatori va header'lar ──► resp.Status, resp.StatusCode   darhol keladi
       └─► body                        ──► resp.Body                      oqim: oʻqiladi, soʻng yopiladi
```

Status va header'lar `resp` ichida darhol turadi. **Body** esa **oqim**: undan maʼlumotni `Decode` bilan oʻzimiz oʻqiymiz. `resp.Body`ning turi — `io.ReadCloser`: bu `Reader`
([GB-2.07](/lab/youtube/gb/gb-2-07)dagi `io.Reader`, undan oʻqiladi) va `Close` metodi. `Close` — body'ni yopish.

Nega yopish kerak? Hujjat: body oxirigacha oʻqilib **yopilmasa**, serverga ochilgan ulanishni keyingi soʻrov qayta ishlata olmasligi mumkin (*"may not reuse"*). Shuning uchun xato tekshiruvidan keyin darhol
`defer resp.Body.Close()` yozamiz: [GB-2.09](/lab/youtube/gb/gb-2-09)dagi `defer f.Close()` kabi. Hujjat yana: `err == nil` boʻlsa, `resp.Body` hech qachon `nil` emas.

Javobdan faqat kerakli maydonlarni oladigan tur:

```go
type rateResponse struct {
	Result   string             `json:"result"`
	BaseCode string             `json:"base_code"`
	Rates    map[string]float64 `json:"rates"`
}
```

`rateResponse` — struct: `Result`, `BaseCode`, `Rates`. Teglar ([GB-3.02](/lab/youtube/gb/gb-3-02)) maydonlarni JSON kalitlariga bogʻlaydi: `base_code` kaliti `BaseCode` maydoniga tushadi.
`Rates` — map ([GB-2.02](/lab/youtube/gb/gb-2-02)): kalit — valyuta kodi (`string`), qiymat — kurs (`float64`).

Hammasini birlashtirgan dastur — `_video/05-decode/main.go`:


## bozorga ulaymiz: narx dollarda

```go filename="main.go" showLineNumbers
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"os"
	"time"
)

const tiyinPerSom = 100 // 1 soʻm = 100 tiyin (GB-1.03)

// rateURL — ochiq kurs API'si: 1 USD necha valyutaga teng (kalitsiz, bepul).
const rateURL = "https://open.er-api.com/v6/latest/USD"

// Product — katalogdagi mahsulot (GB-2.03); narx tiyinda.
type Product struct {
	ID    int64  `json:"id"`
	Name  string `json:"name"`
	Price int64  `json:"price"` // tiyin
	Stock int    `json:"stock"`
}

// rateResponse — kurs API'si javobining bizga kerak qismi.
type rateResponse struct {
	Result   string             `json:"result"`
	BaseCode string             `json:"base_code"`
	Rates    map[string]float64 `json:"rates"`
}

// StatusError — server 200 dan boshqa status bilan javob bergani.
// VAZIFA (2-qadam): fetchRate shu turdagi xato qaytarsin (TASK.md).
type StatusError struct {
	Code int
}

func (e *StatusError) Error() string {
	return fmt.Sprintf("server %d status bilan javob berdi", e.Code)
}

// fetchRate url'dan kurs javobini oladi va code valyutasining kursini qaytaradi
// (1 USD = ? code).
// VAZIFA: 1-qadam (code yoʻq / result "success" emas), 2-qadam (*StatusError), 3-qadam (javob hajmi).
func fetchRate(client *http.Client, url, code string) (float64, error) {
	resp, err := client.Get(url)
	if err != nil {
		return 0, err
	}
	defer resp.Body.Close()
	if resp.StatusCode != http.StatusOK {
		return 0, fmt.Errorf("kurs soʻrovi: javob %s", resp.Status)
	}
	var data rateResponse
	if err := json.NewDecoder(resp.Body).Decode(&data); err != nil {
		return 0, fmt.Errorf("kurs javobi: %w", err)
	}
	return data.Rates[code], nil
}

func run() error {
	client := &http.Client{Timeout: 5 * time.Second}
	rate, err := fetchRate(client, rateURL, "UZS")
	if err != nil {
		return err
	}
	p := Product{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40}
	som := float64(p.Price) / tiyinPerSom
	fmt.Printf("1 USD = %.2f soʻm\n", rate)
	fmt.Printf("%s: %.0f soʻm = %.2f USD\n", p.Name, som, som/rate)
	return nil
}

func main() {
	if err := run(); err != nil {
		fmt.Fprintln(os.Stderr, "xato:", err)
		os.Exit(1)
	}
}
```

## Chuqurroq (ixtiyoriy): client'ni qayta ishlatish, Timeout va LimitReader

Bu qism asosiy gʻoyaga kerak emas; ish kodida esa uchraydi. Uchta qoida:

1. **Client'ni har chaqiruvda yangidan yaratmang.** Bitta client'ni qayta ishlating: serverga ochilgan ulanishlar uning ichida saqlanadi va qayta ishlatiladi. Hujjat shuni aytadi
   (*"Clients should be reused instead of created as needed"*) va bir vaqtda bir nechta joydan chaqirishni ham xavfsiz deydi. Shuning uchun `run`da bitta `client` yasalib, `fetchRate`ga beriladi.
2. **`Timeout` butun soʻrovga chegara.** Hujjatga koʻra u ulanishni, yoʻnaltirishlarni va **javob body'sini oʻqishni** ham oʻz ichiga oladi. Har soʻrovga alohida muddat berish — `context` bilan, [GB-7.03](/lab/youtube/gb/gb-7-03)da.
3. **Tashqi serverning javob hajmiga ishonmang.** `io.LimitReader` body'dan koʻpi bilan berilgan miqdorda bayt oʻqiydi:

```go
	body := io.LimitReader(resp.Body, 1<<20) // 1 MB
	if err := json.NewDecoder(body).Decode(&data); err != nil {
```

`1<<20` — birni 20 bit chapga surish: `1048576` bayt, ya'ni 1 megabayt. `io.LimitReader(resp.Body, 1<<20)` — `resp.Body`ning oʻzi, faqat 1 megabaytdan keyin "tugadi" deydi.
`Decode` endi `body`dan oʻqiydi. JSON qiymatning oʻzi 1 megabaytdan uzun boʻlsa, `Decode` uni oxirigacha oʻqiy olmaydi va xato qaytaradi: kod cheksiz katta javob bilan xotirani toʻldirmaydi.
Buni vazifaning 3-qadamida qoʻllaysiz.

## Oʻzingizni tekshiring

**1.** Client'da `Timeout` nol boʻlsa nima boʻladi, qanday tuzatiladi?

</details>

</details>

```go filename="solution/main.go" showLineNumbers
package main

import (
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"os"
	"time"
)

const tiyinPerSom = 100 // 1 soʻm = 100 tiyin (GB-1.03)

// rateURL — ochiq kurs API'si: 1 USD necha valyutaga teng (kalitsiz, bepul).
const rateURL = "https://open.er-api.com/v6/latest/USD"

// Product — katalogdagi mahsulot (GB-2.03); narx tiyinda.
type Product struct {
	ID    int64  `json:"id"`
	Name  string `json:"name"`
	Price int64  `json:"price"` // tiyin
	Stock int    `json:"stock"`
}

// rateResponse — kurs API'si javobining bizga kerak qismi.
type rateResponse struct {
	Result    string             `json:"result"`
	ErrorType string             `json:"error-type"`
	BaseCode  string             `json:"base_code"`
	Rates     map[string]float64 `json:"rates"`
}

// StatusError — server 200 dan boshqa status bilan javob bergani.
// fetchRate shu turdagi xato qaytaradi: chaqiruvchi errors.As bilan kodini oladi.
type StatusError struct {
	Code int
}

func (e *StatusError) Error() string {
	return fmt.Sprintf("server %d status bilan javob berdi", e.Code)
}

// fetchRate url'dan kurs javobini oladi va code valyutasining kursini qaytaradi
// (1 USD = ? code).
func fetchRate(client *http.Client, url, code string) (float64, error) {
	resp, err := client.Get(url)
	if err != nil {
		return 0, err
	}
	defer resp.Body.Close()
	if resp.StatusCode != http.StatusOK {
		return 0, &StatusError{Code: resp.StatusCode}
	}
	var data rateResponse
	// Tashqi server javobining hajmiga ishonmaymiz: ko'pi bilan 1 MB (1<<20 bayt).
	body := io.LimitReader(resp.Body, 1<<20)
	if err := json.NewDecoder(body).Decode(&data); err != nil {
		return 0, fmt.Errorf("kurs javobi: %w", err)
	}
	if data.Result != "success" {
		return 0, fmt.Errorf("kurs API xatosi: %s", data.ErrorType)
	}
	rate, ok := data.Rates[code]
	if !ok {
		return 0, fmt.Errorf("kurs topilmadi: %s", code)
	}
	return rate, nil
}

func run() error {
	client := &http.Client{Timeout: 5 * time.Second}
	rate, err := fetchRate(client, rateURL, "UZS")
	if err != nil {
		return err
	}
	p := Product{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40}
	som := float64(p.Price) / tiyinPerSom
	fmt.Printf("1 USD = %.2f soʻm\n", rate)
	fmt.Printf("%s: %.0f soʻm = %.2f USD\n", p.Name, som, som/rate)
	return nil
}

func main() {
	if err := run(); err != nil {
		fmt.Fprintln(os.Stderr, "xato:", err)
		os.Exit(1)
	}
}
```

## Manbalar

- [pkg.go.dev: net/http, Client](https://pkg.go.dev/net/http#Client) — `Timeout` ulanishni, yoʻnaltirishlarni va body oʻqishni qamraydi; `0` — cheklov yoʻq; client'ni qayta ishlatish kerak va u bir vaqtda ishlatishga xavfsiz
- [pkg.go.dev: net/http, Get](https://pkg.go.dev/net/http#Get) — "non-2xx response doesn't cause an error"; xato: yoʻnaltirishlar koʻpligi, protokol xatosi; `err == nil` boʻlsa `resp.Body` `nil` emas va uni yopish kerak
- [pkg.go.dev: net/http, Response](https://pkg.go.dev/net/http#Response) — `Body`: oxirigacha oʻqilib yopilmasa, ulanish qayta ishlatilmasligi mumkin
- [pkg.go.dev: net/http, status konstantalari](https://pkg.go.dev/net/http#pkg-constants) — `http.StatusOK` (200)
- [RFC 9110: status kodlari](https://www.rfc-editor.org/rfc/rfc9110#name-status-codes) — `200`, `404`, `503`
- [go vet: httpresponse](https://pkg.go.dev/golang.org/x/tools/go/analysis/passes/httpresponse) — `using resp before checking for errors`
- [pkg.go.dev: io, LimitReader](https://pkg.go.dev/io#LimitReader) — Chuqurroq boʻlim
- [Go spetsifikatsiyasi: index ifodalari](https://go.dev/ref/spec#Index_expressions) — map'da yoʻq kalit nol qiymat beradi
- [ExchangeRate-API: ochiq foydalanish](https://www.exchangerate-api.com/docs/free) — kalitsiz API, `result` va `error-type`, soʻrovlar cheklovi (`429`). Kurs maʼlumoti: [Rates By Exchange Rate API](https://www.exchangerate-api.com)
