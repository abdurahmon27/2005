## Nimani oʻrganasiz

bozor katalogni `katalog.txt` fayldan oʻqiy oladi, lekin hech narsani yozmaydi. Sotilgan qoldiq ham, yangi mahsulot ham dastur tugashi bilan yoʻqoladi.
Bugun katalogni `bozor.json` fayliga yozamiz va keyingi ishga tushishda qayta oʻqiymiz. Yoʻlda esa bitta xavfli holat chiqadi: `json.Marshal`
hech qanday xatosiz `{}` qaytaradi. Katalog qayerga yoʻqoldi?

**Bitta gʻoya:** `encoding/json` struct'ni uning **export qilingan maydonlari** boʻyicha JSON matniga aylantiradi. Har maydonning kaliti — tag'dagi nom
(`` `json:"name"` ``), tag boʻlmasa maydonning oʻz nomi. Kichik harfli maydonni `json` paketi koʻrmaydi va jim tashlaydi; `omitempty` "boʻsh" qiymatni
(`""`, `0`, `false`, `nil`) tashlaydi. Qaytish yoʻli — `json.Unmarshal(data, &v)`: natijani **manzil orqali** bizning oʻzgaruvchimizga yozadi, notanish kalitni
tashlaydi, yoʻq kalitni nol qiymatda qoldiradi, buzuq matn yoki mos kelmagan turda xato qaytaradi. Fayl — shu baytlarning oʻzi.

Dars oxirida siz:

- `Product`ga json tag'larini va `omitempty`ni qoʻyib, katalogni `json.MarshalIndent` va `os.WriteFile` bilan `bozor.json`ga yozasiz;
- `os.ReadFile` va `json.Unmarshal(data, &products)` bilan katalogni qayta yuklaysiz;
- kichik harfli maydon, tag'dagi ortiqcha probel, `&`'siz `Unmarshal` va buzuq fayl xatolarini oʻqiysiz va `go vet` ulardan qaysi birini oldindan topishini bilasiz;
- `TASK.md`da `Order` va `OrderItem`ga tag'lar qoʻyib, `loadProducts`ni "fayl yoʻq — boʻsh katalog" va "buzuq fayl — yoʻl bilan oʻralgan xato" qilasiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| `json.Marshal` | struct'ni JSON baytlariga aylantiradi | marshal |
| struct tag | maydondan keyingi matn: JSON kalitining nomi va qoidalari | struct tag |
| `json.Unmarshal` | JSON matnini struct'ga yozadi (oʻzgaruvchining manzili orqali) | unmarshal |

Yordamchilar: `os.WriteFile` va `os.ReadFile` (faylni butunlay yozish va oʻqish), `json.NewEncoder` va `json.NewDecoder` (oqimga yozish va oqimdan oʻqish).

## JSON nima

Dastur tugaganda xotira tozalanadi, shuning uchun katalogni **matn** koʻrinishida faylga yozamiz. Matn formati bizga kerak: `bozor.json` ham, GB-4'dagi HTTP soʻrovlar ham
maʼlumotni asosan shu formatda tashiydi. U **JSON** deyiladi. Qoidasi qisqa ([RFC 8259](https://www.rfc-editor.org/rfc/rfc8259)):

- **obyekt** — jingalak qavs `{ … }`; ichida `kalit: qiymat` juftlari, vergul bilan ajratilgan;
- **kalit** — doim qoʻshtirnoq ichidagi matn (`"name"`);
- **qiymat** — matn (`"olma"`), son (`40`), `true` yoki `false`, ichma-ich obyekt, yoki roʻyxat;
- **roʻyxat** — kvadrat qavs `[ … ]`, ichida qiymatlar;
- `null` — qiymat yoʻqligini bildiradi.

Ikki alohida misol: birinchisi — obyekt, ikkinchisi — roʻyxat:

```text
{"name": "olma", "stock": 40, "active": true}
["olma", "oʻrik"]
```

| Misol | Nima |
|---|---|
| `{"name": "olma", …}` | obyekt: `name`, `stock`, `active` kalitlari |
| `"olma"` | matn qiymati, qoʻshtirnoqda |
| `40` | son qiymati, qoʻshtirnoqsiz |
| `true` | mantiqiy qiymat |
| `["olma", "oʻrik"]` | ikki matndan iborat roʻyxat |

Bugun uch narsa: `json.Marshal` (struct'dan JSON baytlari), struct tag'lar (kalit nomi maydon yonida), `json.Unmarshal` (JSON'dan struct va uning xatolari).

## json.Marshal: struct'dan JSON baytlariga

`encoding/json` — standart kutubxonadagi paket; kodda nomi `json` (fayl boshidagi `package json` qatoridagidek). Uning imzosini `go doc` bilan koʻramiz
(buyruq chiqishining birinchi 4 qatori; `| head -4` — chiqishni 4 qatorda kesadi):

```console
$ go doc encoding/json.Marshal | head -4
package json // import "encoding/json"

func Marshal(v any) ([]byte, error)
    Marshal returns the JSON encoding of v.
```

`Marshal` har qanday qiymatni (`any`) oladi va uning JSON koʻrinishini **bayt slice'i** (`[]byte`) qilib qaytaradi; ikkinchi natija — `error`.
Eng kichik dastur (`_video/01-marshal/main.go`):

```go filename="_video/01-marshal/main.go" showLineNumbers
package main

import (
	"encoding/json"
	"fmt"
	"os"
)

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64
	Name  string
	Price int64 // tiyin
	Stock int
}

func main() {
	p := Product{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40}
	data, err := json.Marshal(p)
	if err != nil {
		fmt.Fprintln(os.Stderr, "xato:", err)
		os.Exit(1)
	}
	fmt.Println(string(data))
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 3–7 | `import ( … )` | uchta paket: `encoding/json` (bugungi), `fmt`, `os` |
| 10–15 | `type Product struct { … }` | GB-2.03'dagi tur: `ID`, `Name`, `Price` (tiyinda), `Stock` |
| 18 | `p := Product{ID: 1, Name: "olma", …}` | `p` — bitta mahsulot (`olma`, narxi 1 200 000 tiyin, qoldigʻi 40) |
| 19 | `data, err := json.Marshal(p)` | `p`ni JSON'ga aylantiradi: `data` — baytlar (`[]byte`), `err` — xato yoki `nil` |
| 20–23 | `if err != nil { … }` | xato boʻlsa, GB-3.01'dagidek `os.Stderr`ga chiqarib, `os.Exit(1)` |
| 24 | `fmt.Println(string(data))` | `string(data)` baytlarni matnga aylantiradi, `Println` uni chiqaradi |

Ekranda nima chiqadi? Kalitlar qanday yoziladi?

**A)** kichik harf bilan: `{"id":1,"name":"olma",…}` · **B)** maydon nomlarining oʻzi: `{"ID":1,"Name":"olma",…}` · **C)** kalitsiz, faqat qiymatlar: `{1,"olma",1200000,40}`

<details>
<summary>Javob</summary>

**B.** Teg boʻlmasa, kalit — maydonning Go'dagi nomi, katta harfi bilan. **A** ni tanlagan boʻlsangiz, `json` nomlarni oʻzi kichraytiradi deb oʻylagansiz: yoʻq,
kichik harfli kalit kerak boʻlsa, uni bugun oʻrganadigan tag bilan **siz** aytasiz. **C** — JSON'da qiymat doim kalit bilan keladi (`{1,"olma",…}` JSON ham emas).

```console
$ ./_video/run.sh 01-marshal go run .
{"ID":1,"Name":"olma","Price":1200000,"Stock":40}
```

</details>

Natijani oʻqing: sonlar qoʻshtirnoqsiz (`1200000`), matn qoʻshtirnoqda (`"olma"`), narx tiyinda. Tartib — struct'dagi maydonlar tartibi.

| `Product` maydoni | Qiymati | JSON'dagi juft |
|---|---|---|
| `ID` | `1` | `"ID":1` |
| `Name` | `"olma"` | `"Name":"olma"` |
| `Price` | `1_200_000` | `"Price":1200000` |
| `Stock` | `40` | `"Stock":40` |

### Kichik harfli maydon: xatosiz `{}`

Fayllarda kalitlar koʻpincha kichik harf bilan yoziladi. Birinchi fikr: maydonlarning oʻzini kichik harf bilan nomlash (`_video/02-kichik/main.go`; qolgan hamma narsa oldingidek,
`main`dagi literal ham yangi nomlar bilan):

```go
type Product struct {
	id    int64
	name  string
	price int64 // tiyin
	stock int
}
```

Endi nima chiqadi: kichik harfli kalitlar, boʻsh obyekt yoki kompilyatsiya xatosi?

**A)** `{"id":1,"name":"olma",…}` · **B)** `{}` · **C)** kompilyatsiya xatosi

<details>
<summary>Javob</summary>

**B: `{}`, xatosiz.** `go vet` ham hech narsa demaydi. **A** ni tanlagan boʻlsangiz, `json` kichik harfli maydonni ham oʻqiydi deb oʻylagansiz.
**C** ni tanlagan boʻlsangiz, bunday kod notoʻgʻri deb oʻylagansiz; aslida u toʻgʻri Go kodi.

```console
$ ./_video/run.sh 02-kichik go run .
{}
$ ./_video/run.sh 02-kichik go vet .
```

`go vet .` hech narsa chiqarmadi: bu uning "topganim yoʻq" deyishi.

</details>

Sababi GB-2.06 qoidasi: kichik harfli nom faqat oʻz paketida koʻrinadi. `id`, `name`, `price`, `stock` — `main` paketining maydonlari; `encoding/json` esa boshqa paket.
U ularni **koʻrmaydi** va jim tashlaydi. Kompilyator rozi (kod toʻgʻri), `go vet` rozi — **maʼlumot xatosiz yoʻqoladi**. Shu sababli bu eng koʻp uchraydigan JSON xatosi.

| Maydon | Eksportmi? | `json` nima qiladi |
|---|---|---|
| `ID`, `Name`, `Price`, `Stock` | ha (katta harf) | JSON'ga yozadi |
| `id`, `name`, `price`, `stock` | yoʻq (kichik harf) | tashlaydi, xabar bermaydi |

## Struct tag: kalit nomini maydon yonida aytish

Yechim: maydon katta harfda qoladi (eksport qilinadi), JSON'dagi nomi esa **struct tag**da aytiladi. Tag — maydon turidan keyingi matn, **backtick** (`` ` ``, teskari qoʻshtirnoq) ichida
(`_video/03-tag/main.go`; faqat struct oʻzgardi):

```go
type Product struct {
	ID    int64  `json:"id"`
	Name  string `json:"name"`
	Price int64  `json:"price"` // tiyin
	Stock int    `json:"stock"`
}
```

Tag'ni qismlarga ajratamiz:

| Qism | Maʼnosi |
|---|---|
| `ID int64` | oddiy maydon: nom, keyin tur |
| `` `json:"id"` `` | tag: turdan keyin yoziladi |
| `` ` `` … `` ` `` | backtick ichidagi matn — **raw string literal**: ichidagi `"` oddiy belgi, uni qochirish (`\"`) shart emas |
| `json:"id"` | `kalit:"qiymat"` shakli: `json` kaliti, ikki nuqta, qoʻshtirnoq ichida JSON'dagi nom |

`encoding/json` tag'ni dastur **ishlayotganda** `reflect` paketi orqali oʻqiydi: `reflect` — turlarning tuzilishini (maydon nomlari, tag'lari) dastur ichidan koʻrsatadigan standart paket.
Shuning uchun kompilyator tag ichidagi matnni tekshirmaydi: u uchun bu oddiy string.

### Shakl qatʼiy: ikki nuqtadan keyin probel boʻlmaydi

`_video/03b-probel/main.go`da bitta qator boshqacha: `Name  string `` `json: "name"` `` (ikki nuqtadan keyin probel). Kompilyator buni qabul qiladi. Ishga tushiramiz,
keyin `go vet` bilan tekshiramiz:

```console
$ ./_video/run.sh 03b-probel go run .
{"id":1,"Name":"olma","price":1200000,"stock":40}
$ ./_video/run.sh 03b-probel go vet .

```

`json` bu tag'ni **tanimaydi** va jim maydon nomini ishlatadi: kalit yana `"Name"`. Xato yoʻq. `go vet` esa topadi:

| Qism | Maʼnosi |
|---|---|
| `main.go:12:2` | fayl, 12-qator, 2-ustun: bu `Name` maydoni qatori |
| `struct field tag` | struct tag |
| `` `json: "name"` `` | vet koʻrsatgan tag |
| `not compatible with reflect.StructTag.Get` | tag'ni oʻqiydigan `reflect.StructTag.Get` bu shaklga mos kelmaydi |
| `bad syntax for struct tag value` | tag qiymatining yozuvi notoʻgʻri |

Probelni olib tashlab (`03-tag`), qayta ishga tushiramiz:

```console
$ ./_video/run.sh 03-tag go run .
```

Kalitlar endi kichik harf, Go'dagi nomlar esa oʻzgarmadi: kod `p.Name` deydi, JSON esa `name`.

## omitempty: boʻsh maydonni yozmaslik

Yangi maydon: `Note` — mahsulot izohi. Koʻp mahsulotda izoh yoʻq; har birida boʻsh `"note":""` faqat shovqin. Tag'da nomdan keyin vergul va `omitempty`:
maydon **boʻsh** boʻlsa, kalit yozilmaydi. Matn uchun "boʻsh" — ichi boʻsh string `""`. Katalogda endi ikki mahsulot: olmada izoh yoʻq, oʻrikda bor
(`_video/04-omit/main.go`dan):

```go
	Note  string `json:"note,omitempty"`
}

	products := []Product{
		{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40},
		{ID: 2, Name: "oʻrik", Price: 3_500_000, Stock: 5, Note: "quritilgan"},
	}
```

Birinchi qator — `Product`ning oxirgi maydoni va yopuvchi `}`; qolgani — `main`dagi katalog: `[]Product` — `Product`lar slice'i (GB-2.01, GB-2.03).

Ikkalasini chiqarish uchun `json.NewEncoder` ishlatamiz (`main`ning qolgan qismi):

```go
	enc := json.NewEncoder(os.Stdout)
	for _, p := range products {
		if err := enc.Encode(p); err != nil {
			fmt.Fprintln(os.Stderr, "xato:", err)
			os.Exit(1)
		}
	}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1 | `enc := json.NewEncoder(os.Stdout)` | `NewEncoder` `io.Writer` oladi (GB-2.07); bu yerda `os.Stdout`. Natija `enc` — shu oqimga yozadigan **Encoder** |
| 2 | `for _, p := range products {` | har mahsulot `p` uchun sikl (GB-1.06) |
| 3 | `if err := enc.Encode(p); err != nil {` | `Encode` `p`ni JSON'ga aylantirib, **darhol** oqimga yozadi va oxiriga yangi qator qoʻshadi; xato `if`ning qisqa ifodasida (GB-1.05) |
| 4–5 | `fmt.Fprintln(os.Stderr, …)`, `os.Exit(1)` | xato boʻlsa, chiqish |

`Marshal` baytlarni **qaytaradi**, `Encode` esa oqimga **yozadi**: ikkalasi bir ish, boshqa shakl. Oʻrik soʻzi qanday chiqadi: oʻz holida yoki maxsus kod bilan?

```console
$ ./_video/run.sh 04-omit go run .
{"id":1,"name":"olma","price":1200000,"stock":40}
{"id":2,"name":"oʻrik","price":3500000,"stock":5,"note":"quritilgan"}
```

Oʻz holida: JSON matni UTF-8 ([RFC 8259 §8.1](https://www.rfc-editor.org/rfc/rfc8259#section-8.1)), tutuq belgisi `ʻ` GB-2.10'dagidek ikki bayt. Olmaning qatorida `note` yoʻq, oʻrikda bor.

### Savol: songa omitempty qoʻysak-chi?

`Stock` tag'iga ham `omitempty` qoʻshamiz (`"stock,omitempty"`) va oʻrikning qoldigʻini nolga tushiramiz (`Stock: 0`). Oʻrik qatorida `stock` qanday yoziladi?

**A)** `"stock":0` · **B)** `stock` kaliti umuman yoʻq · **C)** `"stock":null`

<details>
<summary>Javob</summary>

**B: `stock` kaliti yoʻq.** `omitempty` uchun **nol ham boʻsh**. Hujjatdagi roʻyxat: `false`, `0`, nil pointer, nil interface qiymati va uzunligi nol boʻlgan array, slice, map yoki string.
**A** ni tanlagan boʻlsangiz, `omitempty` faqat matnga tegadi deb oʻylagansiz. **C** — `null` faqat nil pointer yoki nil slice yozilganda chiqadi, nol son uchun emas.

```console
$ ./_video/run.sh 05-quiz go run .
{"id":1,"name":"olma","price":1200000,"stock":40}
{"id":2,"name":"oʻrik","price":3500000,"note":"quritilgan"}
```

</details>

Bu nega yomon: faylni keyin oʻqiydigan dastur qoldiq **nolmi yoki nomaʼlummi**, ajrata olmaydi: ikkala holda ham kalit yoʻq. **Qoida: `omitempty` matnga va roʻyxatga, songa emas.**

| Maydon turi | `omitempty` uchun "boʻsh" |
|---|---|
| `string` | `""` |
| `int`, `int64` va boshqa sonlar | `0` |
| `bool` | `false` |
| pointer, interface | `nil` |
| slice, map | uzunligi 0 (nil ham, boʻsh ham) |

### Marshal har maydon uchun qanday qaror qiladi

Hamma qoidalar bitta yoʻlda:

| Qadam | Savol | Javob boʻlsa |
|---|---|---|
| 1 | maydon eksport qilinganmi (katta harf)? | yoʻq → **tashla** |
| 2 | kalit nima? | tag'dagi nom; tag boʻlmasa — maydon nomi |
| 3 | `omitempty` bormi va maydon boʻshmi? | ha → **tashla** |
| 4 | aks holda | qiymatni (son, matn, roʻyxat, ichma-ich obyekt) kalit bilan yoz |

## Faylga yozish: saveProducts

Endi katalogni faylga yozamiz. Toʻliq dastur (`_video/06-save/main.go`); `run` — GB-3.01'dagi shakl:

```go filename="_video/06-save/main.go" showLineNumbers
package main

import (
	"encoding/json"
	"fmt"
	"os"
)

// Product — katalogdagi bitta mahsulot. Tag'lar — bozor.json'dagi kalit nomlari.
type Product struct {
	ID    int64  `json:"id"`
	Name  string `json:"name"`
	Price int64  `json:"price"` // tiyin
	Stock int    `json:"stock"`
	Note  string `json:"note,omitempty"`
}

// saveProducts katalogni path fayliga JSON qilib yozadi.
func saveProducts(path string, products []Product) error {
	data, err := json.MarshalIndent(products, "", "  ")
	if err != nil {
		return err
	}
	return os.WriteFile(path, data, 0o644)
}

// run katalogni bozor.json'ga saqlaydi (GB-3.01'dagi shakl).
func run() error {
	products := []Product{
		{ID: 1, Name: "olma", Price: 1_200_000, Stock: 40},
		{ID: 2, Name: "oʻrik", Price: 3_500_000, Stock: 5, Note: "quritilgan"},
	}
	if err := saveProducts("bozor.json", products); err != nil {
		return err
	}
	fmt.Println("saqlandi:", len(products), "ta mahsulot")
	return nil
}

func main() {
	if err := run(); err != nil {
		fmt.Fprintln(os.Stderr, "xato:", err)
		os.Exit(1)
	}
}
```

|---|---|---|
| 19 | `func saveProducts(path string, products []Product) error` | `path` — fayl yoʻli, `products` — katalog; faqat `error` qaytaradi |
| 20 | `json.MarshalIndent(products, "", "  ")` | `Marshal`ga oʻxshash, lekin JSON'ni qatorlarga boʻlib yozadi: har qator boshidagi **prefiks** boʻsh (`""`), **chekinish** — ikki probel (`"  "`) |
| 21–23 | `if err != nil { return err }` | marshal xato bersa, funksiya xatoni qaytaradi |
| 24 | `return os.WriteFile(path, data, 0o644)` | `data`ni `path` fayliga yozadi; fayl yoʻq boʻlsa yaratadi, bor boʻlsa **ichini tozalab** yozadi; natijasi — `error` |
| 28–38 | `run` | katalog tuzadi, `saveProducts("bozor.json", …)`ni chaqiradi va nechta mahsulot saqlanganini chiqaradi |

## Faylni oʻqish: loadProducts va nega &products

| Qator | Kod | Nima qiladi |
|---|---|---|
| 28 | `func loadProducts(path string) ([]Product, error)` | fayl yoʻlini oladi, katalog va `error` qaytaradi |
| 29–32 | `data, err := os.ReadFile(path)` va tekshiruv | `ReadFile` faylning **butun** ichini `[]byte` qilib oʻqiydi; xato boʻlsa, `nil` katalog va shu xato |
| 33 | `var products []Product` | boʻsh oʻzgaruvchi: hozircha `nil` slice (GB-2.01) |
| 34 | `json.Unmarshal(data, &products)` | JSON baytlarini `products`ga yozadi; imzosi `Unmarshal(data []byte, v any) error` |
| 35 | `return nil, err` | JSON buzuq boʻlsa, katalog oʻrniga xato |
| 37 | `return products, nil` | hammasi joyida: toʻldirilgan katalog |

Nega `&products`? `Unmarshal`ning ikkinchi parametri `any`: natijani **shu argumentga** yozadi. Funksiya chaqiruvchining oʻzgaruvchisiga faqat **manzili** orqali yoza oladi (GB-2.04).

| Moment | `products` oʻzgaruvchisi | `Unmarshal` nimani koʻradi |
|---|---|---|
| 33-qatordan keyin | `nil` (hech narsa yoʻq) | — |
| `&products` bilan chaqiruv | `nil` | oʻzgaruvchining **manzili**: yozadigan joyi bor |
| `Unmarshal` tugadi | `[{1 olma …} {2 oʻrik …}]` | — |

`&`ni unutsak-chi: `json.Unmarshal(data, products)`?

**A)** kompilyatsiya xatosi · **B)** dastur ishlaydi, `Unmarshal` xato qaytaradi · **C)** xatosiz, lekin katalog boʻsh

<details>
<summary>Javob</summary>

`non-pointer` — "pointer emas". Natija xato, shuning uchun **C** (jim boʻsh katalog) ham notoʻgʻri. `go vet` esa buni dastur ishga tushmasdan topadi.

</details>

Shuning uchun commit'dan oldin `go vet` ishga tushiring: u GB-3.03'da batafsil. `&` oʻz joyiga qaytgach (`07-load`), `run` `loadProducts("bozor.json")`ni chaqiradi va har mahsulotni chiqaradi

## Xato yoʻllari: buzuq fayl, yoʻq fayl va Unmarshal qoidalari

### Narx matn boʻlib qolsa

Faylni qoʻlda tahrirlaymiz (`_video/09-buzuq/bozor.json`): olmaning narxini qoʻshtirnoqqa olamiz, endi u son emas, **matn**:

```text
  {
    "id": 1,
    "name": "olma",
    "price": "1200000",
    "stock": 40
  },
```

`Unmarshal` endi nima qiladi? `Price` — `int64`, fayldagi qiymat esa matn.

```console
$ ./_video/run.sh 09-buzuq go run .
xato: json: cannot unmarshal string into Go struct field .0.price of type int64
exit status 1
```

Xabarni oʻqing: "`string`ni `int64` maydonga yozib boʻlmaydi". `.0.price` — roʻyxatning nolinchi elementidagi `price` kaliti (maydon nomi Go 1.27 xabarida shunday koʻrinadi; `.0` — element raqami).
Xabarda **fayl nomi yoʻq**: buni vazifada qoʻshasiz. Yana bir tafsilot: bunday xatoda `Unmarshal` qolgan maydonlarni baribir toʻldiradi; shuning uchun `loadProducts` xatoda `nil` qaytaradi, chala katalogni emas.

### Unmarshal qoidalari

Videoda bu qoidalar roʻyxat bilan aytilgan. Men ularni alohida kichik dasturda tekshirdim (u kurs papkasida yoʻq: `rules/main.go`, `go run main.go`). Toʻliq kodi:

```go
package main

import (
	"encoding/json"
	"fmt"
)

type Product struct {
	ID    int64  `json:"id"`
	Name  string `json:"name"`
	Price int64  `json:"price"` // tiyin
	Stock int    `json:"stock"`
	Note  string `json:"note,omitempty"`
}

func main() {
	var a Product
	err := json.Unmarshal([]byte(`{"id":1,"name":"olma","rang":"qizil"}`), &a)
	fmt.Printf("1: %+v err=%v\n", a, err)

	var b Product
	err = json.Unmarshal([]byte(`{"ID":3,"NAME":"non"}`), &b)
	fmt.Printf("2: %+v err=%v\n", b, err)

	var c Product
	err = json.Unmarshal([]byte(`{"id":1 "name":"olma"}`), &c)
	fmt.Printf("3: %+v err=%v\n", c, err)

	var d []Product
	err = json.Unmarshal([]byte(`[{"id":1,"name":"olma","price":"1200000","stock":40}]`), &d)
	fmt.Printf("4: %+v err=%v\n", d, err)

	out, err := json.Marshal(Product{ID: 2, Name: "non", Price: 400_000})
	fmt.Println("5:", string(out), err)
}
```

`[]byte(`…`)` matnni baytlarga aylantiradi (`string(data)`ning teskarisi); backtick — yana raw string. `%+v` struct'ni maydon nomlari bilan chiqaradi.

```console
$ go run main.go
1: {ID:1 Name:olma Price:0 Stock:0 Note:} err=<nil>
2: {ID:3 Name:non Price:0 Stock:0 Note:} err=<nil>
3: {ID:0 Name: Price:0 Stock:0 Note:} err=invalid character '"' after object key:value pair
4: [{ID:1 Name:olma Price:0 Stock:40 Note:}] err=json: cannot unmarshal string into Go struct field .0.price of type int64
5: {"id":2,"name":"non","price":400000,"stock":0} <nil>
```

| Qator | Nimani koʻrsatadi |
|---|---|
| 1 | **notanish kalit** (`rang`) jim tashlandi; **yoʻq kalit** (`price`, `stock`) maydonni nol qiymatida qoldirdi; xato yoʻq |
| 2 | kalit nomida katta-kichik harf **farqlanmaydi**: `"ID"` va `"NAME"` `id` va `name` maydonlariga tushdi |
| 3 | buzuq JSON (kalit-qiymatdan keyin vergul yoʻq): xato, katalog boʻsh |
| 4 | tur mos kelmadi: xato **va** `Stock: 40` baribir toʻldirildi (shuning uchun `loadProducts` xatoda `nil` qaytaradi) |
| 5 | `Note` boʻsh — kalit yoʻq (`omitempty`); `Stock` nol, lekin `omitempty` yoʻq — `"stock":0` yozildi |

Uch qoida: notanish kalit tashlanadi, yoʻq kalit maydonni nolda qoldiradi, kalit nomida harf farqlanmaydi. Xato esa ikki holatda: buzuq JSON va mos kelmagan tur.

bozor birinchi marta ishga tushganda `bozor.json` hali yoʻq. Qanday xato kutasiz? `rm` (faylni oʻchiradi) bilan oʻchirib, `go run .` qilamiz.

## Decoder: faylni oqim sifatida oʻqish

`Encoder`ning oʻqiydigan jufti — `Decoder`. Bu `loadProducts`ning boshqa varianti (`_video/11-decoder/main.go`, funksiyaning oʻzgargan qismi):

```go
	f, err := os.Open(path)
	if err != nil {
		return nil, err
	}
	defer f.Close()
	var products []Product
	if err := json.NewDecoder(f).Decode(&products); err != nil {
		return nil, err
	}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 1–4 | `f, err := os.Open(path)` va tekshiruv | GB-3.01'dagidek faylni ochadi; xato boʻlsa, qaytadi |
| 5 | `defer f.Close()` | `err` tekshiruvidan **keyin** (GB-2.09): xatoda `f` `nil`, yopadigani yoʻq |
| 7 | `json.NewDecoder(f).Decode(&products)` | `NewDecoder` `io.Reader` oladi: `f` (`*os.File`) shunday; qaytgan `Decoder`ning `Decode` metodi JSON'ni oqimdan oʻqib, `&products`ga yozadi |

`Decode` ham manzil oladi — `&` yana kerak. Natija oldingi bilan bir xil (`./_video/run.sh 11-decoder go run .` — `07-load`dagi ikki qator). `Decoder` bizga GB-4'da kerak boʻladi:
server HTTP soʻrovidagi JSON'ni `io.Reader` orqali shunday oʻqiydi. Bu dars uchun `ReadFile` + `Unmarshal` yetadi.

## Chuqurroq (ixtiyoriy): encoding/json/v2

Go 1.27'da `encoding/json/v2` qoʻshildi; `encoding/json` esa endi uning ustida ishlaydi va xulqi oʻsha ([Go 1.27 release notes](https://go.dev/doc/go1.27)).
Import'da v2'ga `jsonv2` nomini beramiz, chunki ikkalasining nomi `json`. Toʻliq dastur (`_video/12-v2/main.go`): `in` oʻzgaruvchisida `name` kaliti **ikki marta**:

```go filename="_video/12-v2/main.go" showLineNumbers
package main

import (
	"encoding/json"
	jsonv2 "encoding/json/v2"
	"fmt"
)

// Product — katalogdagi bitta mahsulot.
type Product struct {
	ID    int64  `json:"id"`
	Name  string `json:"name"`
	Price int64  `json:"price"` // tiyin
	Stock int    `json:"stock"`
}

func main() {
	in := []byte(`{"id":1,"name":"olma","name":"non"}`)
	var p Product
	err := json.Unmarshal(in, &p)
	fmt.Println("v1:", err, p.Name)
	err = jsonv2.Unmarshal(in, &p)
	fmt.Println("v2:", err)
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 5 | `jsonv2 "encoding/json/v2"` | v2 paketini `jsonv2` nomi bilan import qiladi |
| 18 | `in := []byte(`…`)` | JSON matnini baytlarga aylantiradi; `name` ikki marta |
| 20–21 | `json.Unmarshal(in, &p)` | v1: natija va `p.Name`ni chiqaradi |
| 22–23 | `jsonv2.Unmarshal(in, &p)` | v2: faqat xatoni chiqaradi |

```console
$ ./_video/run.sh 12-v2 go run .
v1: <nil> non
v2: jsontext: duplicate object member name "name"
```

v1 xatosiz **oxirgi** qiymatni oldi: `non`, xato `nil`. v2 rad etdi: `jsontext` (v2'ning matn paketi) "duplicate" — takrorlangan kalit — deydi.

v2 yana uch joyda boshqacha. Men ularni `v1` va `v2` bilan yonma-yon ishga tushirdim (kurs papkasida yoʻq dastur; kodi qisqa, shu yerda):

```go
package main

import (
	"encoding/json"
	jsonv2 "encoding/json/v2"
	"fmt"
)

type P struct {
	ID    int64 `json:"id"`
	Stock int   `json:"stock,omitempty"`
}

type L struct {
	id int64
}

func main() {
	b, err := json.Marshal(P{ID: 2})
	fmt.Println("v1:", string(b), err)
	b, err = jsonv2.Marshal(P{ID: 2})
	fmt.Println("v2:", string(b), err)

	b, err = json.Marshal(L{id: 1})
	fmt.Println("v1:", string(b), err)
	b, err = jsonv2.Marshal(L{id: 1})
	fmt.Println("v2:", string(b), err)

	var p P
	err = json.Unmarshal([]byte(`{"ID":3}`), &p)
	fmt.Println("v1:", p.ID, err)
	p = P{}
	err = jsonv2.Unmarshal([]byte(`{"ID":3}`), &p)
	fmt.Println("v2:", p.ID, err)
}
```

```console
$ go run main.go
v1: {"id":2} <nil>
v2: {"id":2,"stock":0} <nil>
v1: {} <nil>
v2:  json: cannot marshal from Go main.L: Go struct has no exported fields
v1: 3 <nil>
v2: 0 <nil>
```

| Holat | v1 (`encoding/json`) | v2 (`encoding/json/v2`) |
|---|---|---|
| `omitempty` va `Stock: 0` | `stock` yoʻq | `"stock":0` qoladi: v2 faqat boʻsh **JSON** qiymatni tashlaydi |
| eksport maydoni yoʻq struct | jim `{}` | xato: `Go struct has no exported fields` |
| `"ID"` kaliti, tag `"id"` | `ID` toʻldirildi (harf farqlanmaydi) | toʻldirilmadi (harf farqlanadi) |

`go doc encoding/json` yangi kod uchun v2'ni tavsiya qiladi; v1 API esa qoʻllab-quvvatlanadi va oʻtish majburiy emas. Kurs ishdagi kodda keng tarqalgan `encoding/json` bilan davom etadi.
Bu qismi uchun sahifadagi hamma natijani men oʻzim ishga tushirdim.

## Koʻp uchraydigan xatolar

Hammasi bu sahifada koʻrilgan; bu yerda — qisqacha, tuzatishi bilan.

**1. "Kichik harfli maydon ham yoziladi yoki kamida xato beradi."** Yoʻq: `Marshal` jim `{}` qaytaradi (qarang: yuqoridagi "Kichik harfli maydon: xatosiz `{}`" boʻlimi).
`go run` ham, `go vet` ham jim. Tuzatish: maydon katta harfda, JSON nomi tag'da: `` ID int64 `json:"id"` ``.

**2. Tag'da ikki nuqtadan keyin probel.** `` `json: "name"` `` — `json` tanimaydi va maydon nomini ishlatadi (`"Name"`); kompilyator jim, `go vet` topadi:

```console
$ ./_video/run.sh 03b-probel go vet .
main.go:12:2: struct field tag `json: "name"` not compatible with reflect.StructTag.Get: bad syntax for struct tag value
```

12-qator, 2-ustun — shu maydon; `bad syntax for struct tag value` — tag yozuvi notoʻgʻri. Tuzatish: probelsiz, `` `json:"name"` ``.

**3. `Unmarshal`ga `&`siz berish.** Kompilyator jim, dastur xato bilan toʻxtaydi:

```console
$ ./_video/run.sh 08-pointer go run .
xato: json: Unmarshal(non-pointer []main.Product)
exit status 1
```

`non-pointer` — ikkinchi argument manzil emas. Tuzatish: `json.Unmarshal(data, &products)`. Oldindan `go vet .` topadi (`call of Unmarshal passes non-pointer as second argument`).

**4. Songa `omitempty`.** `Stock: 0` boʻlganda `stock` kaliti yoʻqoladi va oʻqiydigan dastur nolni nomaʼlumdan ajrata olmaydi (qarang: yuqoridagi "Savol: songa omitempty qoʻysak-chi?" boʻlimi). Tuzatish: sonda tag'ni `` `json:"stock"` `` qoldiring.

**5. Buzuq fayl xatosini fayl nomisiz qaytarish.** `json: cannot unmarshal string into Go struct field .0.price of type int64` qaysi fayl ekanini aytmaydi. Tuzatish: xatoni yoʻl bilan `%w` yordamida oʻrang (vazifa, 2(b)-qadam).

</details>

<details>
<summary>Javob</summary>

</details>

4. Natijani oldindan ayting: `json.Marshal(Product{ID: 2, Name: "non", Price: 400_000})`, `Product` — `Note` va hamma tag'lari bilan (oxirgi variant). `Stock`da `omitempty` yoʻq.

`omitempty` uchun nol ham "boʻsh": `Stock: 0` boʻlsa, `stock` kaliti yoʻqoladi. Faylni oʻqigan dastur qoldiq nolmi yoki nomaʼlummi, ajrata olmaydi.

</details>

6. Tag `` `json: "name"` `` (ikki nuqtadan keyin probel) boʻlsa, `go run` nima chiqaradi va uni qaysi vosita topadi?

<details>
<summary>Javob</summary>

`go run` jim `"Name"` (maydon nomi) kalitini yozadi, xato yoʻq. Topadigani — `go vet` (`bad syntax for struct tag value`).

</details>

- 🟢 **1-qadam, `Order` va `OrderItem`ga json tag'lari.** Jadvaldagi kalitlar: `Order.ID` → `id`, `Order.Items` → `items`, `Order.Status` → `status`, `OrderItem.ProductID` → `product_id`,
  `OrderItem.Price` → `price`, `OrderItem.Quantity` → `quantity`. `status`da `omitempty` **boʻlmasin**: `StatusNew` = 0 ham yozilishi kerak. Kutilgan natija:
  `{"id":7,"items":[{"product_id":1,"price":1200000,"quantity":3}],"status":0}`.
- 🟡 **2(a)-qadam, fayl yoʻq — boʻsh katalog.** `loadProducts` `bozor.json` yoʻq boʻlsa, boʻsh katalog va `nil` xato qaytarsin. Boshqa `os.ReadFile` xatolari (masalan, ruxsat yoʻq) avvalgidek qaytsin.

<summary>Javoblar: 1-qadam (tag'lar) va 2-qadam (loadProducts)</summary>

**1-qadam.** Har maydonga tag, `Status`da `omitempty`siz:

```go
type OrderItem struct {
	ProductID int64 `json:"product_id"`
	Price     int64 `json:"price"` // tiyin, buyurtma paytidagi narx
	Quantity  int   `json:"quantity"`
}

type Order struct {
	ID     int64       `json:"id"`
	Items  []OrderItem `json:"items"`
	Status OrderStatus `json:"status"`
}
```

`status`ga `omitempty` qoʻyilsa, `StatusNew` (0) yozilmay qoladi: bu darsdagi `stock` savolining oʻzi.

**2-qadam.** `loadProducts`:

```go
func loadProducts(path string) ([]Product, error) {
	data, err := os.ReadFile(path)
	if errors.Is(err, os.ErrNotExist) {
		return nil, nil
	}
	if err != nil {
		return nil, err
	}
	var products []Product
	if err := json.Unmarshal(data, &products); err != nil {
		return nil, fmt.Errorf("%s: %w", path, err)
	}
	return products, nil
}
```

(a) `errors.Is(err, os.ErrNotExist)` "fayl yoʻq" xatosini taniydi; u `if err != nil`dan **oldin** turishi shart, aks holda "fayl yoʻq" ham umumiy xato boʻlib qaytadi.
Fayl yoʻq boʻlsa — `nil, nil`: boʻsh katalog va xato yoʻq. (b) `fmt.Errorf("%s: %w", path, err)` yoʻlni xato matniga qoʻshadi va `%w` asl JSON xatosini zanjirda saqlaydi (GB-2.08);
`%v` yozsangiz, zanjir uziladi va test "asl JSON xatosi yoʻq" deydi. Tekshirish (mening ishga tushirishim):

```console
$ go test -count=1 ./solution/

```

</details>
