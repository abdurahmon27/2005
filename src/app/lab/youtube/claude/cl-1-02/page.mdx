## Nimani oʻrganasiz

Serverda xato chiqdi. Siz logni Claude'ga yopishtirmoqchisiz va «nima boʻldi?» deb soʻramoqchisiz. Lekin logda baza parolingiz,
Claude API kalitingiz va mijozning telefoni turibdi. Chatga yopishtirilgan matn qayerga ketadi va u yerda qancha turadi?
Anthropic yozishicha, kalit sizishining eng koʻp sabablaridan biri — uni ochiq repository'ga yoki begona asbobga
tasodifan qoʻyib yuborish. Bugun buni hal qiladigan kichik Go skanerini yozamiz va Claude.ai'ning oʻzini toʻgʻri
sozlashni koʻramiz.

**Bitta gʻoya:** Claude.ai'da ishni vazifaga mos model va Project tezlashtiradi, lekin chatga yuborilgan har bir
narsa kompyuteringizdan chiqib, serverda saqlanadi. Shuning uchun model va Project'ni oʻylab tanlang, sir esa chatga
umuman tushmasin.

Dars oxirida siz:

- vazifaga qarab Haiku, Sonnet, Opus yoki Fable'ni va effort darajasini tanlaysiz;
- bitta mavzu uchun Project ochib, unga kurs fayllari va qisqa koʻrsatma qoʻyasiz, Claude nimani koʻrishini va
  nimani koʻrmasligini bilasiz;
- Claude.ai'ga yuborgan maʼlumotingiz qancha saqlanishini va kalit ketib qolsa nima qilishni aytasiz;
- logni yoki papkani `main.go` skaneri bilan tekshirib, sirlarni `-yashir` bilan almashtirasiz va skaner qayerda
  adashishini bilasiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| Project | Claude.ai'dagi alohida ish joyi: oʻz chatlari, bilim bazasi (fayllar) va koʻrsatmasi bor | project (knowledge, instructions) |
| effort | modelning bitta javobga qancha kuch (oʻylash va vaqt) sarflashi; menyuda Low dan Max gacha | effort |
| entropiya | matndagi belgilar qanchalik tasodifiy ekanining oʻlchovi, bit/belgi bilan | entropy (Shannon) |

Yordamchi soʻzlar matnda birinchi uchraganda bitta gap bilan tushuntiriladi: **RAG** (bilim bazasidan faqat kerakli

## Qaysi modelni tanlash va effort

Anthropic dasturchilar uchun (API ilovalarida) ikki yoʻlni koʻrsatadi (*Choosing the right model*). Bu mantiq chatda
ham ishlaydi:

| Yoʻl | Qanday | Qachon |
|---|---|---|
| efficiency-first | tez va arzon modeldan (Haiku) boshlaysiz, yetmasa kuchlisiga oʻtasiz | oddiy, koʻp takrorlanadigan ish |
| capability-first | eng kuchli modeldan (Opus) boshlaysiz, keyin arzonroqqa tushasiz; Opus `xhigh`/`max` effort'da ham yetmasa — Fable | murakkab ish |

Hujjat yana aytadi: effort'ni sozlash koʻpincha model almashtirishdan yaxshiroq richag. Bu kursdagi qoidamiz shunday.
Bu hujjat emas, bizning qoidamiz:

| Vazifa | Model |
|---|---|
| xato xabari nima degani? | Haiku |
| bitta funksiya, bitta test | Sonnet |
| koʻp faylli oʻzgarish, qiyin bug | Opus |
| Opus yuqori effort bilan ham uddalamadi | Fable |

Modelni qayerda tanlaysiz? Yordam markazi (*Change the model, effort, and thinking settings*) boʻyicha sxema:

```text
[ xabar maydoni ............ ] [Sonnet 5.5 · High ▾] [↑]
                                  ├─ Haiku 5.5 / Sonnet 5.5 / Opus 5.5 / Fable 5.2
                                  ├─ More models
                                  └─ Effort: Low · Medium · High · Extra high · Max
```

- Model menyusi yuborish tugmasi yonida. Model nomini bosasiz va kerakligini tanlaysiz, roʻyxatda yoʻqlari
  **More models** ichida.
- **Effort** — shu menyuda. Yordam markazi: Low va Medium oddiy ishlar uchun yaxshi, High sifat va tezlikning eng
  yaxshi umumiy muvozanati.
- Hozirgi toʻrtta modelda (Fable 5.2, Opus 5.5, Sonnet 5.5, Haiku 5.5) **thinking** (javobdan oldin oʻylash) doim
  yoqiq, uni oʻchirib boʻlmaydi. Kamroq oʻylashi uchun effort'ni pasaytirasiz.
- Oʻzgarish Claude'ning keyingi javobidan boshlanadi, suhbat oʻrtasida ham.

## Project: oʻz fayllari va koʻrsatmasi bor ish joyi

Bir mavzuda uzoq ishlasangiz (masalan, kursning bitta darsi), har yangi chatda bir xil fayllarni qayta yuklash va
bir xil qoidalarni qayta yozish kerak boʻladi. Buning uchun **Project** bor. Yordam markazi taʼrifi: oʻz chat tarixi
va bilim bazasi bor alohida ish joyi (*self-contained workspace*). Project bepul rejada ham bor, lekin beshtagacha.

Yangi Project ochish (yordam markazi boʻyicha sxema):

```text
claude.ai/projects → + New Project → nom + tavsif (Claude ularni KOʻRMAYDI)
                   → Set project instructions  (har bir chatga qoʻshiladi)
                   → + → fayllar               (Project bilim bazasi)
```

Qiziq tomoni: Project'ning nomi va tavsifi faqat siz uchun, Claude ularni koʻrmaydi. Yordam markazi buni ochiq
yozadi: «Claude will not have access to these details». Shuning uchun muhim gapni **Set project instructions**
boʻlimiga yozasiz (bu **project instructions**, koʻrsatma). Fayllarni esa **+** tugmasi orqali yuklaysiz, ular
Project'ning **bilim bazasi**ga (*project knowledge*) tushadi.

Anthropic Projects'ning yangi versiyasini (beta) bosqichma-bosqich chiqaryapti, avval Claude Code'da. Shuning uchun
sizning ekraningiz sxemadan biroz farq qilishi mumkin. Sxemalar yordam markazidagi hozirgi versiya boʻyicha.

## Bilim bazasi, xotira, RAG va kesh

Project ichida nima nimani koʻradi:

| Nima | Project'dagi boshqa chatlarda koʻrinadimi? |
|---|---|
| bilim bazasidagi fayllar | ha, hamma chatlarda |
| project instructions | ha, har bir chatga qoʻshiladi |
| bitta chatdagi suhbatning oʻzi | yoʻq |
| Project xotirasi (*memory*, yoqilgan boʻlsa) | qisqa xulosalar shaklida, Claude ishlatishi mumkin |

Yordam markazi: «Context is not shared across chats within a project unless the information is added into the
project knowledge base». Yaʼni bir chatda kelishgan qaroringiz boshqa chatga oʻzi oʻtmaydi. Xotira (*memory*) Free,
Pro, Max va Ultra'da standart holda yoqiq va har Project'ning oʻz xotirasi bor. Lekin u qisqa xulosa, toʻliq suhbat
emas. Muhim qarorni bilim bazasiga fayl qilib qoʻying. Project'ni hisob xotirasidan toʻliq ajratish uchun Project
sahifasida «Use account memory» ni oʻchiring.

Ikki fakt limit va context window haqida:

- **RAG** (*retrieval-augmented generation*). Pullik rejada bilim bazasi context window'ga yaqinlashsa, Claude RAG
  rejimini oʻzi yoqadi. Endi u hamma faylni oynaga yuklamaydi, faqat savolga keraklisini qidirib oladi. Sigʻim
  10 baravargacha oshadi.
- **Kesh.** Project fayllari keshlanadi (*cached*): takror ishlatilganda limitdan kamroq sarflaydi.

## Skaner ichida: maʼlum formatlar va Luhn

Endi skanerning ichiga qaraymiz. U ikki usulda ishlaydi. Birinchisi — maʼlum formatlar: kalitning oʻz prefiksi yoki

```go filename="main.go" showLineNumbers
// tekshir: matnni chatga (Claude.ai, Project fayllari) yuborishdan oldin unda kalit,
// parol yoki shaxsiy maʼlumotga oʻxshash narsa bor-yoʻqligini qidiradi.
//
//	go run . fayl.log           topilmalar roʻyxati (qiymatning faqat boshi va oxiri)
//	go run . papka/             papkadagi matn fayllari + .env fayllarining nomi
//	go run . -yashir fayl.log   matnning oʻzi, topilmalar [YASHIRIN:tur] bilan
//	cat fayl.log | go run .     stdin
//
//	go run . -qatiy papka/      topilma boʻlsa chiqish kodi 1 (skript va git hook uchun)
package main

type qoida struct {
	tur string              // topilma turi
	sir bool                // true: kalit/parol, false: shaxsiy maʼlumot

	ok  func(s string) bool // qoʻshimcha tekshiruv (nil = shart yoʻq)

// Tartib muhim: bir joyga ikki qoida tushsa, roʻyxatda oldin turgani yutadi.
var qoidalar = []qoida{

	{"github-token", true, regexp.MustCompile(`\b(?:gh[pousr]_|github_pat_)[A-Za-z0-9_]{20,}`), nil},
	{"aws-kalit", true, regexp.MustCompile(`\b(?:AKIA|ASIA)[A-Z0-9]{16}\b`), nil},

// Nomaʼlum formatdagi kalit: uzun, tasodifiy koʻrinadigan soʻz.
var soz = regexp.MustCompile(`[A-Za-z0-9]{24,}`)

type topilma struct {
	joy        string // fayl:qator
	bosh, oxir int    // qator ichidagi bayt oraligʻi
	tur        string
	sir        bool
	qiymat     string
}

// qatorTekshir bitta qatordagi topilmalarni qaytaradi (bir-birini qoplamaydi).
func qatorTekshir(joy, qator string) []topilma {
	var t []topilma
	band := func(b, o int) bool {
		for _, x := range t {
			if b < x.oxir && x.bosh < o {
				return true
			}
		}
		return false
	}
	for _, q := range qoidalar {
		for _, m := range q.re.FindAllStringIndex(qator, -1) {
			s := qator[m[0]:m[1]]
			if band(m[0], m[1]) || (q.ok != nil && !q.ok(s)) {
				continue
			}
			t = append(t, topilma{joy, m[0], m[1], q.tur, q.sir, s})
		}
	}
	for _, m := range soz.FindAllStringIndex(qator, -1) {
		s := qator[m[0]:m[1]]
		if !band(m[0], m[1]) && tasodifiy(s) {
			t = append(t, topilma{joy, m[0], m[1], "nomaʼlum-kalit", true, s})
		}
	}
	sort.Slice(t, func(i, j int) bool { return t[i].bosh < t[j].bosh })
	return t
}

// tasodifiy: kamida 24 belgi; katta harf, kichik harf va kamida 2 ta raqam aralash; Shannon
// entropiyasi 4 bit/belgidan koʻp (Go'dagi uzun nomlar, masalan http2ErrCodeEnhanceYourCalm, oʻtmaydi).
// Git hash (40 ta hex) bu sinovga kirmaydi: katta harfi yoʻq, 16 xil belgida esa maksimum 4 bit.
// Narxi: 24 belgili tasodifiy kalitlarning ~13 foizini oʻtkazib yuboradi (go test -run Olchov -v).
func tasodifiy(s string) bool {
	var katta, kichik bool
	raqam := 0
	soni := map[rune]int{}
	for _, r := range s {
		katta = katta || (r >= 'A' && r <= 'Z')
		kichik = kichik || (r >= 'a' && r <= 'z')
		if r >= '0' && r <= '9' {
			raqam++
		}
		soni[r]++
	}
	return katta && kichik && raqam >= 2 && entropiya(soni, len(s)) > 4.0
}

func entropiya(soni map[rune]int, n int) float64 {
	var c []int
	for _, x := range soni {
		c = append(c, x)
	}
	sort.Ints(c) // map tartibi tasodifiy: yigʻindi har safar bir xil boʻlsin
	h := 0.0
	for _, x := range c {
		p := float64(x) / float64(n)
		h -= p * math.Log2(p)
	}
	return h
}

// luhn: karta raqamining oxirgi raqami tekshiruv raqami (ISO/IEC 7812-1).
// 16 xonali har qanday son (buyurtma raqami, vaqt) karta emas. 0000 0000 … ham emas.
func luhn(s string) bool {
	raqamlar := strings.Map(func(r rune) rune {
		if r >= '0' && r <= '9' {
			return r
		}
		return -1
	}, s)
	if strings.Count(raqamlar, raqamlar[:1]) == len(raqamlar) {
		return false // hammasi bir xil raqam
	}
	sum, ikki := 0, false
	for i := len(s) - 1; i >= 0; i-- {
		c := s[i]
		if c < '0' || c > '9' {
			continue
		}
		d := int(c - '0')
		if ikki {
			if d *= 2; d > 9 {
				d -= 9
			}
		}
		sum += d
		ikki = !ikki
	}
	return sum%10 == 0
}

// yashir qiymatning boshi va oxirini qoldiradi: sk-a…Qx. Qisqa qiymat toʻliq yashirinadi.
func yashir(s string) string {
	r := []rune(s)
	if len(r) < 16 {
		return strings.Repeat("*", len(r))
	}
	return string(r[:4]) + "…" + string(r[len(r)-2:])
}

var xeshFayl = map[string]bool{"go.sum": true, "package-lock.json": true, "yarn.lock": true, "pnpm-lock.yaml": true}

// envFayl: .env, .env.local … (lekin namunasi .env.example emas)
func envFayl(nom string) bool {
	if nom == ".env.example" || nom == ".env.sample" {
		return false
	}
	return nom == ".env" || strings.HasPrefix(nom, ".env.")
}

func oqi(joy string, r io.Reader, yoz io.Writer) ([]topilma, error) {
	var hammasi []topilma
	sc := bufio.NewScanner(r)
	sc.Buffer(make([]byte, 1024*1024), 1024*1024)
	for n := 1; sc.Scan(); n++ {
		qator := sc.Text()
		t := qatorTekshir(fmt.Sprintf("%s:%d", joy, n), qator)
		hammasi = append(hammasi, t...)
		if yoz != nil { // -yashir: qatorni topilmalarsiz chiqaramiz
			for i := len(t) - 1; i >= 0; i-- {
				qator = qator[:t[i].bosh] + "[YASHIRIN:" + t[i].tur + "]" + qator[t[i].oxir:]
			}
			fmt.Fprintln(yoz, qator)
		}
	}
	return hammasi, sc.Err()
}

func papka(yol string) ([]topilma, error) {
	var hammasi []topilma
	err := filepath.WalkDir(yol, func(p string, d fs.DirEntry, err error) error {
		if err != nil {
			return err
		}
		if d.IsDir() {
			if d.Name() == ".git" || d.Name() == "node_modules" {
				return filepath.SkipDir
			}
			return nil
		}
		if xeshFayl[d.Name()] {
			return nil // xesh'lar roʻyxati: tasodifiy koʻrinadi, lekin sir emas
		}
		if envFayl(d.Name()) {
			hammasi = append(hammasi, topilma{joy: p, tur: "env-fayl", sir: true, qiymat: d.Name()})
		}
		if info, err := d.Info(); err != nil || info.Size() > 1<<20 {
			return nil // 1 MB dan katta fayl: oʻtkazib yuboramiz
		}
		b, err := os.ReadFile(p)
		if err != nil {
			fmt.Fprintln(os.Stderr, "oʻqib boʻlmadi:", err)
			return nil
		}
		if bytes.IndexByte(b[:min(len(b), 512)], 0) >= 0 {
			return nil // binar fayl
		}
		t, err := oqi(p, bytes.NewReader(b), nil)
		hammasi = append(hammasi, t...)
		return err
	})
	return hammasi, err
}

func main() {
	yashirMode := flag.Bool("yashir", false, "matnni chiqarish, topilmalarni [YASHIRIN:tur] bilan almashtirib")
	qatiy := flag.Bool("qatiy", false, "topilma boʻlsa chiqish kodi 1")
	flag.Parse()

	var t []topilma
	var err error
	switch {
	case flag.NArg() == 0:
		t, err = oqi("stdin", os.Stdin, chiqish(*yashirMode))
	case *yashirMode:
		var f *os.File
		if f, err = os.Open(flag.Arg(0)); err == nil {
			t, err = oqi(flag.Arg(0), f, os.Stdout)
			f.Close()
		}
	default:
		for _, yol := range flag.Args() {
			var x []topilma
			x, err = papka(yol) // fayl boʻlsa ham ishlaydi
			t = append(t, x...)
			if err != nil {
				break
			}
		}
	}
	if err != nil {
		fmt.Fprintln(os.Stderr, "xato:", err)
		os.Exit(2)
	}
	if *yashirMode {
		fmt.Fprintf(os.Stderr, "%d ta qiymat yashirildi\n", len(t))
		return
	}
	sirlar := 0
	for _, x := range t {
		turi := "shaxsiy"
		if x.sir {
			turi, sirlar = "sir", sirlar+1
		}
		q := yashir(x.qiymat)
		if x.tur == "env-fayl" {
			q = "Project'ga yuklamang"
		}
		fmt.Printf("%-22s %-7s %-15s %s\n", x.joy, turi, x.tur, q)
	}
	if len(t) == 0 {
		fmt.Println("topilma yoʻq (bu «xavfsiz» degani emas: faqat shu qoidalar tekshirildi)")
		return
	}
	fmt.Printf("jami %d: %d ta sir, %d ta shaxsiy maʼlumot. Chatga yuborishdan oldin olib tashlang.\n",
		len(t), sirlar, len(t)-sirlar)
	if *qatiy {
		os.Exit(1)
	}
}

// chiqish: -yashir boʻlsa matn stdout'ga yoziladi, aks holda hech qayerga.
func chiqish(ha bool) io.Writer {
	if ha {
		return os.Stdout
	}
	return nil
}
```

41-qatordagi `[a-z_]*` nega kerak? Go'da (JS va Python'da ham) `\b` — soʻz belgisi (`\w`: harf, raqam, `_`) bilan
boshqa belgi orasidagi chegara. `DB_PASSWORD` da `_` va `P` ikkalasi soʻz belgisi, ular orasida chegara yoʻq. Shuning
uchun `\bpassword` bu yerda topilmas edi. `[a-z_]*` `DB_` qismini ham oladi.

beradi (`regexp.Compile` esa xato qaytaradi). Python'dagi `re.compile` ga oʻxshaydi.

oxirgi raqami — tekshiruv raqami, u **Luhn** formulasi bilan hisoblanadi (ISO/IEC 7812-1). Formula: oʻngdan boshlab
har ikkinchi raqamni ikkiga koʻpaytiring (9 dan oshsa, 9 ni ayiring), hamma raqamni qoʻshing. Yigʻindi 10 ga

| `4111 1111 1111 1112` | 31 | yoʻq | karta emas |

## Nomaʼlum kalit: entropiya

Ikkinchi usul — nomaʼlum formatdagi kalit uchun. Logdagi toʻlov kaliti `Xq7Lm2Pz…` hech qanday prefikssiz. Uni qanday
ajratamiz? Tasodifiy yaratilgan kalitda belgilar xilma-xil va deyarli bir xil tez-tez uchraydi. Odam yozgan nom yoki
xesh esa unday emas. Buni **entropiya** oʻlchaydi (Shannon, 1948):

```text
H = −Σ p · log₂ p        p — har bir belgining soʻzdagi ulushi
```

`tasodifiy` funksiyasi (92–105) toʻrt shartni tekshiradi, hammasi bajarilsa — kalitga oʻxshaydi:

1. kamida 24 ta harf yoki raqam (48-qatordagi namuna);
2. katta harf bor, kichik harf bor;
3. kamida 2 ta raqam;
4. entropiya 4 bit/belgidan koʻp.

`entropiya` (107–119) har belgining sonini (`soni` map'i) oladi va formulani hisoblaydi. 112-qatordagi `sort.Ints`
nega kerak? Map tartibi tasodifiy (GO-1.09). Kasr sonlarni har xil tartibda qoʻshsangiz, oxirgi raqamlari biroz farq
qilishi mumkin. Saralangan tartib natijani har safar bir xil qiladi.

Logdagi uchta satr:

| Satr | Uzunligi | Xil belgi | Raqam | Entropiya | Natija |
|---|---|---|---|---|---|
| `Xq7Lm2Pz9Rt4Vb8Nc3Kd6Wf1Hs5Jy0Ge` (toʻlov kaliti) | 32 | 32 | 10 | 5.0 | kalit |
| `3f9a1c27e0b84d6a9e2c5b7f1d08a4c6e9b2f731` (git commit hash) | 40 | 16 | 25 | 3.95 | sinovga kirmaydi |
| `http2ErrCodeEnhanceYourCalm` (Go'dagi nom) | 27 | 17 | 1 | 3.99 | sinovga kirmaydi |

Toʻlov kalitining 32 belgisi hammasi har xil, demak har birining ulushi 1/32 va H = log₂ 32 = 5.0. Git hash'ida esa
katta harf umuman yoʻq, u 2-shartdayoq tushib qoladi. Hatto katta harf boʻlganida ham, 16 xil belgi (0–9, a–f) bilan
entropiya log₂ 16 = 4 dan oshmaydi. Go nomida esa bitta raqam bor (3-shart).

Skaner entropiya qiymatini chiqarmaydi. Jadvaldagi sonlarni biz xuddi shu formula bilan Python'da hisobladik. Bu
fayl dars papkasida yoʻq: uni `entropiya.py` nomi bilan saqlab, oʻzingiz ishga tushiring:

```python
import math
from collections import Counter

def entropiya(s):
    n = len(s)
    return -sum(k / n * math.log2(k / n) for k in Counter(s).values())

for s in ["Xq7Lm2Pz9Rt4Vb8Nc3Kd6Wf1Hs5Jy0Ge",
          "3f9a1c27e0b84d6a9e2c5b7f1d08a4c6e9b2f731",
          "http2ErrCodeEnhanceYourCalm"]:
    print(f"{s:42} {entropiya(s):.2f}")
```

```console
$ python3 entropiya.py
Xq7Lm2Pz9Rt4Vb8Nc3Kd6Wf1Hs5Jy0Ge           5.00
3f9a1c27e0b84d6a9e2c5b7f1d08a4c6e9b2f731   3.95
http2ErrCodeEnhanceYourCalm                3.99
```

`Counter(s)` har belgining sonini beradi (Go'dagi `soni` map'i), `k / n` — ulushi `p`.

Skanerni haqiqiy kodda sinaymiz: Go'ning `net/http` paketi (115 fayl), unda haqiqiy sir yoʻq. Buyruqdagi qismlar:

🔴 Git hook — commit oldidan git oʻzi ishga tushiradigan skript:

```bash filename="homework/pre-commit"
#!/usr/bin/env bash
# CL-1.02 uy vazifasi, «Guru»: sir bor commit'ni toʻxtatadigan git hook.
# Commit'ga ketayotgan (staged) fayllarning index'dagi holatini skaner bilan tekshiradi.
#
# Oʻrnatish (go-backend-uz repo ildizida):
#   cp lessons/cl-02-claude-ai/homework/pre-commit .git/hooks/pre-commit && chmod +x .git/hooks/pre-commit
# Bir martaga chetlab oʻtish (faqat yolgʻon signal boʻlsa!): git commit --no-verify
set -euo pipefail
root=$(git rev-parse --show-toplevel)
tmp=$(mktemp -d); trap 'rm -rf "$tmp"' EXIT

git diff --cached --name-only --diff-filter=ACMR -z | while IFS= read -r -d '' f; do
	mkdir -p "$tmp/$(dirname "$f")"
	git show ":$f" > "$tmp/$f"
done

if ! (cd "$root" && go run ./lessons/cl-02-claude-ai -qatiy "$tmp" | sed "s|$tmp/||"); then
	echo "commit toʻxtatildi: yuqoridagi sirlarni olib tashlang (yoki -yashir bilan almashtiring)" >&2
	exit 1
fi
```

`git diff --cached --name-only` commit'ga ketayotgan (staged) fayllar roʻyxatini beradi. `git show ":$f"` faylning
diskdagi emas, *index* dagi holatini oladi: aynan shu commit'ga tushadi. Fayllar vaqtinchalik papkaga yoziladi va
`-qatiy` bilan tekshiriladi: topilma boʻlsa, chiqish kodi 1 va git commit'ni toʻxtatadi. `trap … EXIT` vaqtinchalik
papkani oxirida oʻchiradi. Oʻrnatish (repository ildizida):

```bash
cp lessons/cl-02-claude-ai/homework/pre-commit .git/hooks/pre-commit && chmod +x .git/hooks/pre-commit
```

Biz uni vaqtinchalik repository'da sinadik (`go.mod` va shu dars papkasining nusxasi, hook oʻrnatilgan). Parolli fayl:

```console
$ git add config.txt && git commit -m "config"
exit status 1
config.txt:1 sir     url-parol       post…6@
jami 1: 1 ta sir, 0 ta shaxsiy maʼlumot. Chatga yuborishdan oldin olib tashlang.
commit toʻxtatildi: yuqoridagi sirlarni olib tashlang (yoki -yashir bilan almashtiring)
```

`config.txt` da bitta qator bor edi: `DB_URL=postgres://bozor:Qovun2026@localhost:5432/bozor`. Commit yaratilmadi. Toza
fayl bilan (`toza.txt`, ichida `salom`) hook `topilma yoʻq …` deb yozdi va commit oʻtdi. Diqqat: kurs papkasining
oʻzi soxta kalitlarga toʻla, shuning uchun hook ularni ham ushlaydi. Faqat yolgʻon signalda bir martaga
`git commit --no-verify` ishlating.
