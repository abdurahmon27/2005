## Bilim illyuziyasi: «tushunaman» hissi tushunish emas

Bitta savol: kurtkadagi molniya (zipper) qanday ishlaydi? Koʻpchilik «bilaman» deydi. Endi uni qadam-baqadam yozib
koʻring: tishlar qanday ilashadi, nega ochilib ketmaydi?

Rozenblit va Keil (Cognitive Science, 2002, 1-tadqiqot) Yel universitetidagi 16 aspirantdan shunday narsalar —
molniya, spidometr, pianino klavishi, qulf — boʻyicha bilimini 1 dan 7 gacha baholashni soʻradi. Keyin ular har biri
qanday ishlashini qadam-baqadam yozdi va qaytadan baholadi. Mualliflar: *«Nearly all participants showed drops in
estimates of what they knew when confronted with having to provide a real explanation»* — «haqiqiy tushuntirish
yozishga toʻgʻri kelganda, deyarli hammaning bahosi tushdi».

| Qadam | Nima boʻldi |
|---|---|
| 1. «Bilaman»: 1 dan 7 gacha baho | his asosida, oʻylamasdan |
| 2. Qadam-baqadam tushuntirib yozish | boʻshliqlar koʻrinib qoladi |
| 3. Qayta baho | deyarli hammada pastroq |
| Xulosa | his ≠ tushunish: tushuntira olmasangiz, tushunmagansiz |

Mualliflar buni **bilim illyuziyasi** (*illusion of explanatory depth*) deb atashdi. Dasturchi uchun bu tanish holat:
Claude'ning tushuntirishini oʻqiysiz, hammasi mantiqli tuyuladi, lekin chatni yopib oʻsha kodni yoza olmaysiz. Turk
tadqiqotidagi oʻquvchilar ham aynan shunday edi: ular imtihonni yomonroq yozdi, lekin buni sezmadi.

**Ustoz ham kafolat emas.** Turk tadqiqotida uchinchi guruh ham bor edi: **GPT Tutor**. Uning yordamchisi javobni
aytmay, ishora berardi; oʻqituvchilar unga har masalaning yechimi va koʻp uchraydigan xatolarni ham yozib qoʻygan.

| Guruh | Mashqda | Imtihonda (AI'siz) | Oʻzi qanday baholadi |
|---|---|---|---|
| AI'siz | — | asos | — |
| GPT Base (ChatGPT'ga oʻxshash) | +48 % | −17 % | yomonlashganini sezmadi |
| GPT Tutor (ishora, javob emas) | +127 % | zarar deyarli yoʻq, foyda ham yoʻq | «yaxshiroq yozdik» deb oʻyladi |

Demak, ustoz zararni olib tashlaydi, lekin illyuziyani emas. Shuning uchun ustozdan keyin ham oʻzingizni
tekshirasiz. Buni qanday qilish — bu sahifaning oxirgi qismida.

Nega avval oʻzingiz yozasiz? Bertsch va hamkasblarining meta-tahlili (Memory & Cognition, 2007) 86 ta tadqiqotni
jamladi: oʻzingiz yaratgan (*generate*) maʼlumot shunchaki oʻqiganingizdan yaxshiroq esda qoladi. Psixologlar buni
*generation effect* deyishadi. Oʻrtacha effekt 0,40 standart ogʻish, yaʼni «deyarli yarim standart ogʻish».

## Tajriba: narx −5, javob 500

Tajriba kurs loyihasidagi kichik onlayn doʻkon (`bozor`) kodida. Handler buyurtmani tekshiradi va xatoga qarab HTTP
status qaytaradi. Talab: narx manfiy boʻlsa — `400` (mijoz notoʻgʻri maʼlumot yubordi), `500` emas. Oʻquvchimiz
**xayoliy**: uning kodi va xabarlarini biz yozdik, Claude javoblari esa oʻzgarishsiz. U [CL-1.03](/lab/youtube/claude/cl-1-03)
da `errors.Is` ni endi oʻrgangan va 400 uchun ham shuni yozdi:

```go filename="bozor/main.go" showLineNumbers
package main

import (
	"errors"
	"fmt"
)

var ErrTopilmadi = errors.New("buyurtma topilmadi")

// MaydonXato: buyurtmaning bitta maydoni notoʻgʻri
type MaydonXato struct {
	Maydon string
	Sabab  string
}

func (e *MaydonXato) Error() string { return e.Maydon + ": " + e.Sabab }

func tekshir(narx int) error {
	if narx <= 0 {
		return fmt.Errorf("tekshir: %w", &MaydonXato{Maydon: "narx", Sabab: "musbat boʻlishi kerak"})
	}
	return nil
}

// holat: handler shu kodni HTTP javobga yozadi
func holat(err error) int {
	if err == nil {
		return 200
	}
	if errors.Is(err, ErrTopilmadi) {
		return 404
	}
	// mening urinishim: oʻtgan safar errors.Is yordam bergan edi
	if errors.Is(err, &MaydonXato{}) {
		return 400
	}
	return 500
}

func main() {
	for _, narx := range []int{12000, -5} {
		err := tekshir(narx)
		fmt.Printf("POST /buyurtma narx=%d → %d %v\n", narx, holat(err), err)
	}
}
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 8 | `var ErrTopilmadi = errors.New(…)` | **sentinel xato**: bitta tayyor qiymat, `errors.Is` bilan solishtiriladi ([GO-1.14](/lab/youtube/go/go-1-14)) |
| 11–14 | `type MaydonXato struct` | oʻz xato turimiz: qaysi maydon (`Maydon`, «maydon») va nega (`Sabab`, «sabab») notoʻgʻri |
| 16 | `func (e *MaydonXato) Error() string` | pointer receiver: `error` ni faqat `*MaydonXato` bajaradi |
| 18–23 | `func tekshir(narx int) error` | narx ≤ 0 boʻlsa, **yangi** `&MaydonXato{…}` yaratib, uni `%w` bilan `tekshir: ` ga oʻraydi |
| 26–38 | `func holat(err error) int` | xatoni HTTP status'ga aylantiradi: `nil` → 200, `ErrTopilmadi` → 404, `MaydonXato` → 400, qolgani → 500 |
| 33 | `// mening urinishim…` | oʻquvchining izohi: «oʻtgan safar `errors.Is` yordam bergan edi» |
| 34 | `errors.Is(err, &MaydonXato{})` | oʻquvchining niyati: «xato `MaydonXato` boʻlsa, 400». Lekin qator boshqa narsani soʻraydi (pastda) |
| 41 | `for _, narx := range []int{12000, -5}` | ikki soʻrov: toʻgʻri narx va manfiy narx |
| 43 | `fmt.Printf(…)` | soʻrov, status va xato matni; `%v` xatoni matn qilib chiqaradi, xato yoʻq boʻlsa `<nil>` |

`narx=-5` uchun nima chiqadi?

**A)** `400` · **B)** `500` · **C)** kompilyatsiya xatosi

<details>
<summary>Javob</summary>

**B.** Kod kompilyatsiya boʻladi: `&MaydonXato{}` — toʻgʻri turdagi `error`. Lekin 34-qatordagi `errors.Is` hech
qachon `true` qaytarmaydi, shuning uchun `holat` oxirgi `return 500` ga tushadi. «A» ni tanlagan boʻlsangiz, siz ham
oʻquvchi kabi `errors.Is` ni «shu turdagi xato bormi?» deb oʻqidingiz. Nega unday emasligi — keyingi boʻlimda.

</details>

```console
$ go run ./bozor
POST /buyurtma narx=12000 → 200 <nil>
POST /buyurtma narx=-5 → 500 tekshir: narx: musbat boʻlishi kerak
```

Birinchi qatorda narx toʻgʻri: `200`, `<nil>` esa «xato yoʻq». Ikkinchi qatorda xato matni toʻgʻri — «narx: musbat
boʻlishi kerak» — lekin status `500`. `go vet` ham yordam bermaydi:

```console
$ go vet ./bozor
```

U hech narsa chiqarmadi: Go nuqtai nazaridan bu kod toʻgʻri. Bu jim xato (silent bug): kompilyator ham, `vet` ham
ushlamaydi.

## Xato qayerda: `errors.Is` aniq qiymatni qidiradi

`tekshir` qaytargan xato ikki qavatli **xatolar zanjiri**: tashqarida `fmt.Errorf("tekshir: %w", …)` oʻrami,
ichida `*MaydonXato` pointer'i. Videodagi rasm: pasportingiz sumkada, sumka chamadonda. `errors.Is` ham, `errors.As`
ham chamadonni qavatma-qavat ochadi. Farq — ular nimani qidirishida:

```text
err  =  "tekshir: …"  (%w oʻrami)
          └── *MaydonXato  manzil 0xA1  {Maydon: "narx", Sabab: "musbat boʻlishi kerak"}

errors.Is(err, &MaydonXato{})       qidiradi: manzil 0xB2 dagi YANGI, boʻsh qiymat
                                    0xA1 == 0xB2 ?  yoʻq → false → 500

errors.AsType[*MaydonXato](err)     qidiradi: *MaydonXato TURIDAGI istalgan xato
                                    0xA1 ning turi *MaydonXato ?  ha → true → 400
```

(Manzillar shartli, faqat farqni koʻrsatish uchun.) `errors.Is` zanjirdagi har bir xatoni berilgan qiymatga `==`
bilan solishtiradi. Pointer'lar uchun `==` — «ikkalasi xotiradagi **aynan bir** obyektgami?». `&MaydonXato{}`
har safar yangi obyekt yaratadi, u `tekshir` yaratgan obyekt bilan hech qachon bir xil boʻlmaydi. Pasport tilida:
`errors.Is` «ichida **aynan mening** pasportim bormi?» deb soʻraydi, oʻquvchi esa yangi, boʻsh pasport yasab, «shu
bormi?» deb soʻradi. Kerakli savol boshqa: «ichida **umuman** pasport bormi?» Bu `errors.As` va `errors.AsType`.

JS va Python'da ham xuddi shunday farq bor: obyektlarni solishtirish va turni tekshirish ikki xil amal.

```console
$ node -e 'class MaydonXato {}; console.log(new MaydonXato() === new MaydonXato(), new MaydonXato() instanceof MaydonXato)'
false true
```

```console
$ python3 -c '
class MaydonXato(Exception): pass
print(MaydonXato() == MaydonXato(), isinstance(MaydonXato(), MaydonXato))'
False True
```

(Bu ikki buyruq kurs papkasida yoʻq: ular Node 24 va Python 3.13 da bir qatorda ishga tushirildi.) Ikki yangi obyekt
`===` va `==` boʻyicha teng emas, lekin ikkalasi bir turda. Go'da:

| Savol | JS | Python | Go (zanjir boʻylab) |
|---|---|---|---|
| aynan shu qiymatmi? | `a === b` | `a == b` (yoki `is`) | `errors.Is(err, ErrTopilmadi)` |
| shu turdagi xatomi? | `e instanceof MaydonXato` | `isinstance(e, MaydonXato)` / `except MaydonXato as e` | `errors.As(err, &me)` yoki `errors.AsType[*MaydonXato](err)` |

`errors.Is` sentinel xatolar (`ErrTopilmadi`) uchun. Tur boʻyicha qidirish uchun `errors.As` (Go 1.13 dan) yoki
`errors.AsType` (Go 1.26 dan) kerak ([GO-1.14](/lab/youtube/go/go-1-14)). Endi bu xatoni Claude'ga ikki xil beramiz.

## 1-yoʻl: javob mashinasi

`promptlar/1-javob.txt` ning birinchi qatori, undan keyin butun `bozor/main.go` va `go run` natijasi:

```text
Bu Go kodni tuzatib ber. Narx manfiy bo'lsa 400 qaytishi kerak, lekin 500 qaytyapti. Go 1.26.8.
```

Biz uni Claude Sonnet 5.5 ga tizim matnisiz, uch marta, har safar yangi suhbatda berdik (`takrorla.sh`, CL-1.03 dagi
kabi). Uchala javobda ham tayyor kod bor. Birinchi javobdan (`javoblar/1-javob/1-1.txt`) koʻchirma:

```text
Xato **turini** tekshirish uchun `errors.As` kerak. U zanjirdagi (`%w` orqali o'ralgan) xatolar ichidan shu turdagisini topib, o'zgaruvchiga yozadi.

`holat` funksiyasini shunday o'zgartiring:
```

Undan keyin javobda tayyor funksiya keladi, aynan shunday:

```go
func holat(err error) int {
	if err == nil {
		return 200
	}
	if errors.Is(err, ErrTopilmadi) {
		return 404
	}
	var me *MaydonXato
	if errors.As(err, &me) {
		return 400
	}
	return 500
}
```

Bu toʻgʻri tuzatish. Oʻzgargan ikki qator:

| Kod | Nima qiladi |
|---|---|
| `var me *MaydonXato` | topilgan xato uchun boʻsh «choʻntak»: `nil` pointer oʻzgaruvchi |
| `errors.As(err, &me)` | zanjirdan `*MaydonXato` turidagi xatoni qidiradi; topsa, uni `me` ga yozadi va `true` qaytaradi. Yozishi uchun `me` ning **manzili** (`&me`) beriladi |

Biz kodni `bozor/main.go` ga qoʻyib koʻrdik (buni `olchov` dasturi qiladi, pastda): uchala javobning kodi ishladi va
`narx=-5 → 400` chiqdi. Javobda tushuntirish ham bor: `errors.Is` `==` bilan solishtiradi, yangi pointer hech qachon
teng boʻlmaydi.

**Keling, xulosa qilamiz: nima boʻldi?** Kod ishladi, tushuntirish ham bor. Lekin biz hech narsa yozmadik va hech
narsani eslamadik. Tushuntirishni oʻqib oʻtib ketish oson — bu bilim illyuziyasining aynan oʻzi. Turk tadqiqotida GPT
Base guruhidagi oʻquvchilar yordamchiga eng koʻp yozgan xabar ham shu edi: *«What is the answer?»* — «javobi nima?».

## Ustoz bilan suhbat: uch xabar, bitta savoldan keyin

Endi oʻsha kodni ustoz qoidalari bilan beramiz (`promptlar/2-ustoz.txt`). Bu promptda kod va natijadan tashqari
oʻquvchining izohi ham bor: «oʻtgan safar oʻralgan xatoda `==` ishlamagan edi, `errors.Is` yordam bergan edi». Suhbat
uch xabardan iborat, uch marta takrorlandi. 2- va 3-xabarni biz bir marta yozdik va uchala suhbatga bir xil yubordik.

**1-xabar.** Claude xatoli qatorni aniq koʻrsatdi, lekin tuzatmadi. 1-suhbatdan (`javoblar/2-ustoz/1-1.txt`) koʻchirma:

```text
…

Xato `holat` funksiyasidagi `errors.Is(err, &MaydonXato{})` qatorida. `errors.Is` zanjirdagi har bir xatoni berilgan qiymatga `==` bilan solishtiradi. Ko'rsatkichlarda esa `==` ikkala ko'rsatkich xotirada aynan bir ob'ektga qaraganini tekshiradi, maydonlari bir xil bo'lishi yetmaydi.

Savol: `errors` paketida zanjirdan qiymatni emas, **turni** qidiradigan va topilganini senga qaytarib beradigan funksiya bormi? Uning nomini `go doc errors` orqali topib ko'r.
```

Qoidadagidek, funksiya nomini aytmadi. Uchala suhbatda ham `errors.As` nomi 1-xabarda yoʻq (0/3).

**2-xabar.** Oʻquvchi hujjatdan `errors.As` ni topdi va oʻzi yozdi (`promptlar/3-urinish.txt`). Bu urinish
`urinish/main.go` da, `holat` ichidagi oʻzgargan qatorlar:

```go
	// ikkinchi urinish: hujjatdan errors.As ni topdim
	var mx *MaydonXato
	if errors.As(err, mx) {
		return 400
	}
```

Javob mashinasining kodidan farqi bitta belgi: `&mx` emas, `mx`. Bu nima qiladi?

**A)** `400` chiqadi · **B)** `500` chiqadi · **C)** dastur `panic` bilan toʻxtaydi · **D)** kompilyatsiya xatosi

<details>
<summary>Javob</summary>

**C**, lekin faqat ikkinchi soʻrovda. `errors.As` ning ikkinchi argumenti `any` turida, shuning uchun kompilyator
`mx` ni ham qabul qiladi («D» emas). `mx` — `nil` pointer: unga yozib boʻlmaydi. `errors.As` buni ishlash paytida
tekshiradi va `panic` qiladi. Birinchi soʻrovda `err == nil`, `holat` `errors.As` gacha yetmaydi, shuning uchun
birinchi qator chiqadi. «A» ni tanlagan boʻlsangiz, `As` `mx` ni oʻzi toʻldiradi deb oʻyladingiz: Go'da funksiya
oʻzgaruvchingizga faqat uning manzili orqali yoza oladi ([GO-1.11](/lab/youtube/go/go-1-11)).

</details>

Toʻliq `panic` xabari stack trace bilan uzun, birinchi ikki qatori yetarli (`2>&1 | head -2` xato oqimini ham
oladi va faqat ikki qatorni koʻrsatadi):

```console
$ go run ./urinish 2>&1 | head -2
POST /buyurtma narx=12000 → 200 <nil>
panic: errors: target must be a non-nil pointer
```

`target must be a non-nil pointer` — «nishon (ikkinchi argument) nil boʻlmagan pointer boʻlishi kerak». Bu xatoni
`go vet` oldindan topadi:

```console
$ go vet ./urinish
urinish/main.go:35:5: second argument to errors.As must be a non-nil pointer to either a type that implements error, or to any interface type
```

`urinish/main.go`, 35-qator, 5-ustun: «`errors.As` ning ikkinchi argumenti `error` ni bajaradigan turga yoki
interface turiga koʻrsatadigan nil boʻlmagan pointer boʻlishi kerak».

Claude yana tuzatmadi: xato shu qatorda, hatto uning ikkinchi argumentida ekanini aytdi va bitta savol berdi
(`javoblar/2-ustoz/1-2.txt`, koʻchirma):

```text
…

Xato `errors.As(err, mx)` qatorida, ikkinchi argumentda. `mx` hozir `nil` ko'rsatkich, `As` esa unga hech narsa yoza olmaydi. Panic xabari ham shuni aytyapti: `target must be a non-nil pointer`.

`As` topilgan xatoni sening o'zgaruvchingga **yozishi** kerak. Buning uchun unga o'zgaruvchining qiymatini emas, boshqa narsani berish lozim.

Savol: `mx` o'zgaruvchisining ichidagi qiymat emas, o'zgaruvchining o'zi qaerda turishini `As`ga bildirish uchun Go'da qaysi operatordan foydalanasan?
```

Uchala suhbatda ham Claude `&mx` ni yozmadi, faqat qanday uzatishni soʻradi. Videodagi rasm bilan: `var mx` — topilgan
pasport uchun choʻntak, `&mx` — shu choʻntakni uzatish, `mx` esa boʻsh qoʻlni uzatish.

**3-xabar.** Oʻquvchi bu savolga javob bermadi: u GO-1.14 dagi boshqa yoʻlni esladi — `errors.AsType`. Bu funksiya
choʻntak soʻramaydi, topilgan xatoni oʻzi qaytaradi. `tuzatildi/main.go` dagi yangi `holat`:

```go
// holat: handler shu kod va matnni HTTP javobga yozadi
func holat(err error) (int, string) {
	if err == nil {
		return 200, "ok"
	}
	if errors.Is(err, ErrTopilmadi) {
		return 404, "topilmadi"
	}
	// zanjirdan *MaydonXato turidagi xatoni qidiradi va topilsa oʻzini qaytaradi (Go 1.26)
	if mx, ok := errors.AsType[*MaydonXato](err); ok {
		return 400, "notoʻgʻri maydon: " + mx.Maydon
	}
	return 500, "ichki xato"
}
```

| Kod | Nima qiladi |
|---|---|
| `(int, string)` | endi `holat` ikki qiymat qaytaradi: status va javob matni (oʻquvchi qaysi maydon xato ekanini ham yozmoqchi edi) |
| `errors.AsType[*MaydonXato](err)` | kvadrat qavsda qidirilayotgan tur (type argument). Zanjirda shu turdagi xato boʻlsa, uni va `true` qaytaradi |
| `mx, ok := …; ok` | `mx` — topilgan `*MaydonXato`, faqat shu `if` ichida; `ok` — topildimi |
| `"notoʻgʻri maydon: " + mx.Maydon` | qaysi maydon xato ekanini javobga yozadi |

`main` ham ikki qiymatni oladi (`kod, matn := holat(err)`). Dasturni yana ishga tushiramiz:

```console
$ go run ./tuzatildi
POST /buyurtma narx=12000 → 200 ok
POST /buyurtma narx=-5 → 400 notoʻgʻri maydon: narx
```

Endi `narx=-5` uchun `400` va qaysi maydon notoʻgʻri ekani: `narx`.

Oxirida oʻquvchi «toʻgʻri tushundimmi? Menga bitta savol ber» deb yozdi. Claude tuzatishni tasdiqladi va tekshiruv
savoli berdi (`javoblar/2-ustoz/1-3.txt`, oxirgi qism):

```text
`errors.Is(err, &MaydonXato{})` zanjirda `*MaydonXato` turidagi xato bo'lsa ham nega `false` qaytardi, `AsType[*MaydonXato]` esa nega `true`? Ikkalasi nimani solishtirishini o'z so'zlaring bilan tushuntir.
```

Bu molniya tajribasining oʻzi: tushuntira olsangiz, tushungansiz. Boshqa ikki suhbatda Claude boshqa savollar berdi —
ular uy vazifasida.

## Eslab yozish: tushunganingizni qanday tekshirasiz

Ustozdan keyin ham oʻzingizni tekshirasiz, dedik. Eng yaxshi oʻrganilgan usullardan biri — **eslab yozish**
(*retrieval practice*). Roediger va Karpicke (Psychological Science, 2006, 2-tajriba): bir guruh matnni toʻrt marta
oʻqidi. Boshqa guruh bir marta oʻqib, keyin uch marta kitobni yopib, esida qolganini yozdi.

| Guruh | 5 daqiqadan keyin | 1 haftadan keyin |
|---|---|---|
| faqat oʻqish (4 marta) | 83 % | 40 % |
| bir oʻqish + 3 marta eslab yozish | 71 % | 61 % |

Besh daqiqadan keyin oʻqiganlar yaxshiroq esladi va oʻzlariga koʻproq ishondi. Bir haftadan keyin esa ular 40 %,
eslab yozganlar 61 % esladi. Yana bilim illyuziyasi: qayta oʻqish «bilaman» hissini beradi, lekin uzoq esda
qoldirmaydi.

Dasturchilarda ham shunday natija bor. Anthropic tadqiqotchilari Shen va Tamkin (arXiv, 2026) 52 dasturchiga notanish
Python kutubxonasi (Trio) bilan vazifa berdi, koʻpi bilan 35 daqiqa. Yarmiga AI yordamchi berildi (u GPT-4o edi). Keyingi testda
AI guruhining oʻrtacha bali 50 %, AI'sizlarniki 67 % boʻldi; eng katta farq debugging savollarida. AI guruhi ichida
faqat tushuntirish soʻragan 7 kishi (*conceptual inquiry*) yuqori ball oldi. Mualliflar bu guruhlar uchun sabab-natija
bogʻlanishini daʼvo qilmaydi, test ham vazifadan darhol keyin boʻlgan.

**Kod ishladi. Uni haqiqatan tushunganingizni qanday bilasiz?** Javobni ochishdan oldin oʻylab koʻring (ishora:
molniya tajribasi).

```go filename="homework/sinov/main.go" showLineNumbers
// sinov: Claude ustoz rejimida bergan uchta tekshiruv savoliga javobni ishga tushirib koʻrsatadi.
// Avval savollarga oʻzingiz javob yozing (README → Uy vazifasi), keyin: go run ./homework/sinov
package main

import (
	"errors"
	"fmt"
)

type MaydonXato struct{ Maydon, Sabab string }

func (e *MaydonXato) Error() string { return e.Maydon + ": " + e.Sabab }

// QiymatXato: xuddi shunday, lekin Error() qiymat qabul qiluvchida va pointersiz qaytariladi
type QiymatXato struct{ Maydon, Sabab string }

func (e QiymatXato) Error() string { return e.Maydon + ": " + e.Sabab }

func main() {
	err := fmt.Errorf("tekshir: %w", &MaydonXato{Maydon: "narx", Sabab: "musbat boʻlishi kerak"})

	// 1-savol: errors.Is qiymatni (bu yerda pointer manzilini) solishtiradi, AsType esa turni qidiradi
	_, ok := errors.AsType[*MaydonXato](err)
	fmt.Println("1. errors.Is(err, &MaydonXato{}):", errors.Is(err, &MaydonXato{}), "· AsType[*MaydonXato]:", ok)

	// 2-savol: yana bir qavat %w bilan oʻrasak zanjir saqlanadi, %v bilan esa uziladi
	w := fmt.Errorf("handler: %w", err)
	v := fmt.Errorf("handler: %v", err)
	_, okW := errors.AsType[*MaydonXato](w)
	_, okV := errors.AsType[*MaydonXato](v)
	fmt.Println("2. %w bilan yana oʻralgan:", okW, "· %v bilan:", okV)

	// 3-savol: xato pointersiz qaytsa, *QiymatXato turi zanjirda yoʻq
	q := fmt.Errorf("tekshir: %w", QiymatXato{Maydon: "narx", Sabab: "musbat boʻlishi kerak"})
	_, okP := errors.AsType[*QiymatXato](q)
	_, okQ := errors.AsType[QiymatXato](q)
	fmt.Println("3. pointersiz xato: AsType[*QiymatXato]:", okP, "· AsType[QiymatXato]:", okQ)
}
```

- (2) `%w` zanjirni saqlaydi — qavatlar soni muhim emas, `holat` 400 qaytaradi. `%v` xatoni oddiy matnga aylantiradi,
  zanjir uziladi → 500.
- (3) Zanjirda `QiymatXato` (qiymat) bor, `*QiymatXato` (pointer) yoʻq, shuning uchun `false`; `AsType[QiymatXato]`
  kerak (`Error()` qiymat receiver'da boʻlishi sharti bilan). Tur aynan mos kelishi kerak. Faylda bu savol uchun
  alohida `QiymatXato` turi bor, chunki `MaydonXato` ning `Error()` i pointer receiver'da.
