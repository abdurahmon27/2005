## Nimani oʻrganasiz

Jamoangizning bir yillik standup eslatmalari bor: 12 ta matn fayli, 360 qator. Bajarilgan ish oddiy yoziladi, ochiq
ish esa `TODO` bilan boshlanadi. Savol: Aziz hali nechta ishni yopmagan? Python yoki Node'da kichik skript yozish
mumkin. Bugun esa javobni skriptsiz, terminalda uchta kichik buyruqni ulab olamiz.

**Bitta gʻoya:** har biri bitta ish qiladigan kichik buyruqlarni tik chiziq (pipe) bilan bosqichma-bosqich ulasak,
ular skriptsiz katta savolga javob beradi: `grep` filtrlaydi, `wc -l` sanaydi, xuddi JavaScript'dagi
`filter().filter().length` kabi.

Dars oxirida siz:

- `grep -r` bilan papkadagi hamma fayllardan kerakli qatorlarni topasiz va natijadagi `fayl yoʻli:qator` shaklini
  oʻqiysiz;
- `|` va `wc -l` bilan qatorlarni sanaysiz, oʻrtaga yangi filtr bosqichini qoʻshasiz;
- pipeline'ning oxirgi bosqichini olib tashlab, oraliq natijani tekshirasiz;
- tik chiziqdan keyingi `grep` ga papka yoki `-r` berish nega jimgina notoʻgʻri son berishini tushuntira olasiz.

Bugungi uchta asosiy yangi soʻz:

| Soʻz | Oddiy maʼnosi | Inglizcha |
|---|---|---|
| `grep` | qatorlarni filtrlaydi: naqsh bor qatorni butunligicha oʻtkazadi, qolganini tashlaydi | grep |
| `wc -l` | kelgan qatorlarni sanaydi va bitta son yozadi | wc (word count), `-l` = lines |
| tik chiziq `\|` | chapdagi buyruq natijasini oʻngdagi buyruqning kirishiga beradi | pipe |

Ikkita yordamchi soʻz ham bor: **standart kirish** (stdin) — fayl berilmasa, buyruq maʼlumotni shu yerdan oʻqiydi;
**stderr** — xato xabarlari uchun alohida chiqish (faqat «Chuqurroq» boʻlimida). **Naqsh** (pattern) esa `grep`
qidiradigan matn, bugun oddiy soʻz: `TODO`, `Aziz`.

## Oldin bilish kerak

Bu «Kompyuter, OS va tarmoq» trekining birinchi darsi: oldingi dars shart emas. Sizdan faqat dasturchi sifatida
bilganingiz kerak: massiv, `filter`, `length`, fayl va papka. Linux terminalini bilish shart emas, hammasi shu yerda.

**Qayerda yozamiz.**

- **Linux** va **macOS**: oddiy terminal yetadi (macOS'da *Terminal* ilovasi).
- **Windows**: `cmd` va PowerShell'da `grep` yoʻq. [Git for Windows](https://gitforwindows.org/) ni oʻrnating, u
  bilan birga **Git Bash** keladi (ichida `bash`, `grep`, `wc` bor). WSL ham boʻladi. VS Code'da terminal odatda
  PowerShell ochadi: `+` yonidagi strelka → **Git Bash**.
- **Tik chiziq `|`**: klaviatura inglizcha layoutda boʻlsin, **Shift + `\`** (teskari slesh). Ruscha layoutda bu
  tugma boshqa belgini beradi.

**Dars papkasi.** Kursni yuklab oling va dars papkasiga oʻting (`cd` — terminalning joriy papkasini oʻzgartiradi):

```bash
git clone https://github.com/abdurahmon27/go-backend-uz
cd go-backend-uz/lessons/sys-01-terminal
```

`git` boʻlmasa, GitHub'da **Code → Download ZIP** ni bosing. Windows'da papka ustida sichqonchaning oʻng tugmasi →
**Open Git Bash here** (Windows 11'da avval *Show more options*). Bu sahifadagi hamma buyruq shu papkadan ishga
tushiriladi: ichida `eslatmalar/` va `yil/` papkalari bor. `No such file or directory` chiqsa, terminal boshqa
papkada turibdi (`pwd` qayerdaligingizni aytadi).

Bu sahifadagi natijalar Linux'da GNU bash 5.3.9, GNU grep 3.12 va GNU coreutils 9.11 (`wc`) bilan olingan. macOS'da
`wc -l` sondan oldin boʻsh joy qoʻyadi (`       6`), bu normal (kurs README'sidan; macOS'da tekshirilmagan).

Boshlashdan oldin bitta savol, oʻzingiz biladigan tildan. Massivda toʻrt qator bor:

```js
const qatorlar = [
  "Aziz: saytga logo qoʻydi",
  "TODO Aziz: menyuni tuzatish",
  "Malika: narxlarni yangiladi",
  "TODO Malika: rasmlarni kichraytirish",
];
qatorlar.filter((q) => q.includes("TODO")).filter((q) => q.includes("Aziz")).length;
```

Oxirgi ifoda nimaga teng?

**A)** `1` · **B)** `2` · **C)** `4`

<details>
<summary>Javob</summary>

**A: `1`.** Birinchi `filter` `TODO` bor ikki qatorni qoldiradi, ikkinchisi ulardan `Aziz` borini, `length` esa
qolganini sanaydi. «`2`» ni tanlagan boʻlsangiz, ikkinchi filtrni unutgansiz: `Aziz` ikki qatorda bor, lekin
ulardan bittasi `TODO` emas. Bugun aynan shu zanjirni terminalda quramiz.

</details>

## JavaScript zanjiridan terminalga

JavaScript'da bu savolni shunday yozardingiz: qatorlar massividan `TODO` borini filtrlash, keyin `Aziz` borini,
oxirida `length`. Terminalda har bir qadamga bitta buyruq toʻgʻri keladi:

| JavaScript | Terminal | Nima qiladi |
|---|---|---|
| `.filter(q => q.includes("TODO"))` | `grep TODO` | naqsh bor qatorlarni qoldiradi |
| `.filter(q => q.includes("Aziz"))` | `grep Aziz` | yana filtrlaydi |
| `.length` | `wc -l` | qatorlarni sanaydi |
| `.` (zanjir) | `\|` (tik chiziq) | bir qadam natijasini keyingisiga beradi |

Solishtirish uchun, xuddi shu savol `eslatmalar/` papkasida Node'da. Bu fayl kurs papkasida yoʻq: uni dars papkasiga
`zanjir.js` nomi bilan saqlang va Node 24 bilan ishga tushiring.

```js
// zanjir.js: xuddi shu savol JavaScript'da (Node 24)
const fs = require("fs");

const qatorlar = fs.readdirSync("eslatmalar")
  .flatMap((f) => fs.readFileSync(`eslatmalar/${f}`, "utf8").trimEnd().split("\n"));

const javob = qatorlar
  .filter((q) => q.includes("TODO"))
  .filter((q) => q.includes("Aziz"))
  .length;

console.log(javob);
```

| Qator | Kod | Nima qiladi |
|---|---|---|
| 4–5 | `readdirSync` + `flatMap(…split("\n"))` | papkadagi hamma fayllarni oʻqib, bitta qatorlar massiviga yigʻadi |
| 7–10 | `.filter(…).filter(…).length` | `TODO` li, keyin `Aziz` li qatorlar, keyin ularning soni |
| 12 | `console.log(javob)` | sonni chiqaradi |

```console
$ node zanjir.js
3
```

Bu 12 qatorli dastur. Terminalda xuddi shu javobni bitta qator beradi:
`grep -r TODO eslatmalar | grep Aziz | wc -l`. Endi uni bosqichma-bosqich quramiz.

Ikkinchi papka `yil/` — bir yillik eslatmalar: 12 fayl (`01-yanvar.txt` … `12-dekabr.txt`), har birida 30 qator.
Unga dars oxirida qaytamiz.

## Ishlab chiqarish liniyasi: pipe

Pipe'ni ishlab chiqarish liniyasi deb tasavvur qiling. Har bosqich bitta ish qiladi va natijasini keyingi lentaga
qoʻyadi. Birinchi bosqich ombordan, yaʼni papkadan oʻqiydi. Keyingilari faqat oldidagi lentadan oʻqiydi.

Terminalda **bosqich** — bu buyruq, **lenta** — tik chiziq `|`. Inglizcha uni **pipe** deyishadi. Butun zanjir
**pipeline** deyiladi.

```text
 ombor (papka)          lenta (|)            lenta (|)
 ┌────────────┐      ┌──────────────┐     ┌────────────┐     ┌───────────┐
 │ eslatmalar/│ ───► │ grep -r TODO │ ──► │ grep Aziz  │ ──► │  wc -l    │ ──► ekran
 └────────────┘      │  filtrlaydi  │     │ filtrlaydi │     │  sanaydi  │
                     └──────────────┘     └────────────┘     └───────────┘
                      1-bosqich:           2-bosqich:          3-bosqich:
                      papkadan oʻqiydi     lentadan oʻqiydi    lentadan oʻqiydi
```

Massivdagi zanjirdan farqi ham bor, va u muhim:

| | JavaScript `filter().length` | Terminal pipeline |
|---|---|---|
| Bosqich nima | bitta dastur ichidagi metod chaqiruvi | alohida dastur (alohida jarayon) |
| Qachon ishlaydi | navbat bilan: avval butun yangi massiv yigʻiladi, keyin keyingi metod | hamma bosqich bir vaqtda ishlaydi |
| Nima uzatiladi | massiv (obyektlar, tiplar bilan) | matn oqimi: baytlar, qatorlarga boʻlingan |

Shell pipeline'dagi har buyruqni alohida jarayonda ishga tushiradi va ular bir vaqtda ishlaydi. Maʼlumot esa
yadrodagi kichik bufer orqali **oqim** boʻlib oʻtadi (POSIX §2.9.2, bash(1), pipe(7)). Uchinchi qator — «faqat matn» —
dars davomida ikki marta kerak boʻladi.

## 1-bosqich: `grep`

Birinchi bosqich `grep`. U qatorlarni filtrlaydi: naqsh bor qatorni butunligicha oʻtkazadi, qolganini tashlaydi.

```console
$ grep -r TODO eslatmalar
eslatmalar/seshanba.txt:TODO Bobur: zaxira nusxa olish
eslatmalar/seshanba.txt:TODO Aziz: mijozga javob yozish
eslatmalar/chorshanba.txt:TODO Malika: biz haqimizda matni
eslatmalar/chorshanba.txt:TODO Aziz: telefon raqamini tekshirish
eslatmalar/dushanba.txt:TODO Aziz: menyuni tuzatish
eslatmalar/dushanba.txt:TODO Malika: rasmlarni kichraytirish
```

Natijaga hali qaramang. Avval buyruqni qismlarga ajratamiz:

| Qism | Nima |
|---|---|
| `grep` | buyruq (dastur) nomi |
| `-r` | **flag**: papkani rekursiv oʻqi, ichidagi hamma fayllarni (npm'dagi `-g` kabi) |
| `TODO` | naqsh: qidiriladigan matn |
| `eslatmalar` | qayerdan oʻqish: papka |

`grep` katta-kichik harfni farqlaydi: naqshni `todo` deb yozsangiz, hech narsa topilmaydi (buni «Koʻp uchraydigan
xatolar» da koʻramiz).

Endi savol. `grep` bu yerda uchta faylni oʻqiydi. Natijada har bir qator qanday koʻrinadi?

**A)** faqat qatorning oʻzi · **B)** fayl yoʻli, ikki nuqta, keyin qator · **C)** faqat fayl nomlari

<details>
<summary>Javob</summary>

**B.** Yuqoridagi natijaga qarang: olti qator chiqdi, dushanbadan ikkitasi. Har qator boshida fayl yoʻli
(`eslatmalar/dushanba.txt`), ikki nuqtadan keyin qatorning oʻzi. Bir nechta fayl oʻqilsa, `grep` qaysi fayldan
ekanini shunday koʻrsatadi (GNU grep qoʻllanmasi, `-H`: «bir nechta fayl qidirilganda bu odatiy»).

«A» ni tanlagan boʻlsangiz, bitta fayldagi `grep` ni oʻylagansiz: `grep TODO eslatmalar/dushanba.txt` haqiqatan
faqat qatorlarni chiqaradi. «C» — bu boshqa flag, `grep -l`, u faqat fayl nomlarini chiqaradi.

</details>

Natija ekranga chiqdi, chunki keyingi bosqich yoʻq. Fayllar tartibi sizda boshqacha boʻlishi mumkin: `grep -r`
fayllarni fayl tizimi bergan tartibda oʻqiydi (bu yerda seshanba, chorshanba, dushanba).

## 2-bosqich: `wc -l`

Ikkinchi bosqich `wc -l`. `wc` — *word count*, `-l` flagi bilan esa faqat qatorlar soni. Uni tik chiziq bilan
ulaymiz:

```text
grep -r TODO eslatmalar  |  wc -l
└──── 1-bosqich ──────┘  │  └─ 2-bosqich: fayl berilmagan → lentadan oʻqiydi
                       lenta
```

`wc` ga fayl bermaymiz. Fayl berilmasa, u tik chiziqdan kelganini oʻqiydi. Buyruqning bu kirishi **standart kirish**
(inglizcha *standard input*, qisqasi **stdin**) deyiladi. wc(1): «FILE boʻlmasa … standart kirishni oʻqiydi».

Endi ekranda nima chiqadi?

**A)** oʻsha 6 qator · **B)** bitta son: `6` · **C)** bitta son: `13`

<details>
<summary>Javob</summary>

**B: `6`.** `grep` ning qatorlari ekranga emas, lentaga tushdi. `wc -l` ularni sanab, faqat sonni yozdi.

«A» ni tanlagan boʻlsangiz, `|` ni oʻtkazib yubordingiz: qatorlar endi ekranga emas, `wc` ga boradi. «C» — `13` —
papkadagi hamma qatorlar soni. Lekin `wc` papkani oʻqimadi, u faqat lentada kelganini sanaydi.

</details>

```console
$ grep -r TODO eslatmalar | wc -l
6
```

`13` qayerdan kelishi mumkin edi? Agar `wc` hamma fayllarni oʻqiganida. `cat` fayllarni ketma-ket chiqaradi, `*.txt`
esa papkadagi hamma `.txt` fayllar:

```console
$ cat eslatmalar/*.txt | wc -l
13
```

## Oʻrtaga yangi bosqich: `grep Aziz`

Endi asosiy savol: Azizning ishlari. JavaScript'dagi ikkinchi `filter` kabi, oʻrtaga yana bitta `grep` qoʻyamiz,
naqsh `Aziz`. Unga `-r` ham, papka ham bermaymiz: u qatorlarni lentadan oladi. Uchta bosqich, ikkita tik chiziq.

Ekranda qaysi son chiqadi? Oldingi olti qatorni eslang.

**A)** `6` · **B)** `3` · **C)** `5`

<details>
<summary>Javob</summary>

**B: `3`.** Lentada olti `TODO` qatori bor edi, ulardan uchtasida `Aziz` bor.

«A» ni tanlagan boʻlsangiz, ikkinchi `grep` hech narsani tashlamaydi deb oʻyladingiz. «C» — `5` — Azizning **hamma**
yozuvlari, yopilganlari bilan. Bu son boshqa buyruqdan chiqadi, uni «Koʻp uchraydigan xatolar» da koʻramiz.

</details>

Avval `wc -l` ni olib tashlab, lentada nima borligini koʻramiz:

```console
$ grep -r TODO eslatmalar | grep Aziz
eslatmalar/seshanba.txt:TODO Aziz: mijozga javob yozish
eslatmalar/chorshanba.txt:TODO Aziz: telefon raqamini tekshirish
eslatmalar/dushanba.txt:TODO Aziz: menyuni tuzatish
```

Uchta qator, hammasi Azizning `TODO` qatorlari. Pipeline'ni shunday tekshirish qulay: oxirgi bosqichni olib, oraliq
natijaga qaraysiz. Bu JavaScript'da zanjir oʻrtasiga `console.log` qoʻyishga oʻxshaydi. Endi `wc -l` ni qaytaramiz:

```console
$ grep -r TODO eslatmalar | grep Aziz | wc -l
3
```

Har lentada nima borligi:

| Joy | Nima bor | Qatorlar |
|---|---|---|
| ombor: `eslatmalar/` | uch faylning hamma qatorlari | 13 |
| 1-lenta: `grep -r TODO eslatmalar` dan keyin | `TODO` qatorlari (fayl yoʻli bilan) | 6 |
| 2-lenta: `grep Aziz` dan keyin | Azizning `TODO` qatorlari | 3 |
| ekran: `wc -l` dan keyin | bitta son | `3` |

Node'dagi `zanjir.js` ham `3` degan edi.

## Tartib muhim: `wc -l` oʻrtada boʻlsa

Bosqichlar tartibini almashtirsak-chi: `wc -l` oʻrtada, `grep Aziz` oxirida?

```text
grep -r TODO eslatmalar | wc -l | grep Aziz
```

Ekranda nima chiqadi?

**A)** `3` · **B)** `6` · **C)** hech narsa

<details>
<summary>Javob</summary>

**C: hech narsa.** `wc -l` lentaga faqat bitta qator qoʻyadi: `6`. Oxirgi `grep` shu qatorda `Aziz` naqshini
topmaydi va hech narsa chiqarmaydi.

«A» ni tanlagan boʻlsangiz, bosqichlar tartibi ahamiyatsiz deb oʻyladingiz. «B» ni tanlagan boʻlsangiz, oxirgi
`grep` ni hisobga olmadingiz: `6` lentada bor, lekin u `grep Aziz` filtridan oʻtmaydi.

</details>

```console
$ grep -r TODO eslatmalar | wc -l | grep Aziz
```

Buyruq hech narsa chiqarmadi: na son, na xato. Oxirgi `grep` ni olib koʻramiz:

```console
$ grep -r TODO eslatmalar | wc -l
6
```

`wc` lentaga bitta qator qoʻydi: `6`. `grep Aziz` undan hech narsa topmaydi. (`grep` hech narsa topmasa, chiqish kodi
1 boʻladi, lekin ekranga hech narsa yozmaydi.)

JavaScript'da `length` dan keyin `filter` chaqirsangiz, TypeError olasiz (Node 24 da
`TypeError: [1,2].length.filter is not a function`). Terminal esa jim turadi, chunki lentada faqat matn bor, tiplar
yoʻq: `6` ham oddiy matn qatori. Tartib muhim: avval filtrlash, keyin sanash.

## Bir yillik papka

Endi boshidagi savol: bir yillik papka. Pipeline'da nimani oʻzgartirish kerak? Davom etishdan oldin oʻylab koʻring.

Faqat papka nomini: `eslatmalar` oʻrniga `yil`.

```console
$ grep -r TODO yil | grep Aziz | wc -l
22
```

Azizda 22 ta ochiq ish bor. 12 faylni bir qator buyruq bilan koʻrib chiqdik. Ishonch uchun papkaning hajmi (`ls` —
papkadagi fayllar roʻyxati, har biri alohida qatorda, chunki natija lentaga ketyapti):

```console
$ ls yil | wc -l
12
```

```console
$ cat yil/* | wc -l
360
```

```console
$ grep -r TODO yil | wc -l
93
```

12 fayl, 360 qator, 93 ta `TODO`. `yil/` papkasini kurs papkasidagi `yasash.py` yasaydi (natija har doim bir xil).
Unda har bir `TODO` — alohida ish, va u hech qachon «bajarildi» deb yozilmaydi. Shuning uchun `22` — haqiqatan ochiq
ishlar soni.

## Chuqurroq (ixtiyoriy): xatolar lentaga tushmaydi

Yana bir nozik joy. Har dasturda ikki chiqish bor: asosiy natija (inglizcha *standard output*, **stdout**) va xato
xabarlari uchun alohida oqim — **stderr**. Bu Node'dagi `console.log` va `console.error` farqi bilan bir xil:
`console.error` ham stderr'ga yozadi. Oddiy tik chiziq esa faqat asosiy natijani uzatadi.

Yoʻq papkani (`arxiv`) qoʻshsak, `wc -l` nima deydi? Avval oʻylang.

```console
$ grep -r TODO eslatmalar arxiv | wc -l
grep: arxiv: No such file or directory
6
```

Xato ekranda qoldi: «`arxiv`: bunday fayl yoki papka yoʻq». `wc` esa baribir `6` deydi: xato qatori lentaga
tushmadi va sanalmadi. Shuning uchun pipeline xato bersa ham, soni toʻgʻri boʻlishi mumkin. Xatoni ham lentaga
qoʻshish usullari (`2>&1 |`, bash'da `|&`) kurs README'sining «Chuqurroq» qismida va keyingi darslarda.

## Koʻp uchraydigan xatolar

### 1. Tik chiziqdan keyingi `grep` ga papka berish

Bu eng koʻp uchraydigan xato. Ikkinchi `grep` ga ham odat boʻyicha `-r` va papka nomini yozsak-chi?

```text
grep -r TODO eslatmalar | grep -r Aziz eslatmalar | wc -l
```

**A)** baribir `3` · **B)** `3` dan koʻp · **C)** `0`

<details>
<summary>Javob</summary>

**B: `5`.** Fayl yoki papka berilgan `grep` lentaga qaramaydi, omborga qaytib ketadi. U papkani boshidan oʻqib,
Azizning hamma yozuvlarini, yopilganlarini ham chiqaradi. `wc` esa ularni sanaydi.

</details>

```console
$ grep -r TODO eslatmalar | grep -r Aziz eslatmalar | wc -l
5
```

Xato xabari yoʻq, son shunchaki notoʻgʻri. Ikkinchi `grep` aslida nima chiqarganini oxirgi bosqichsiz koʻrish mumkin.
U lentani emas, papkani oʻqiydi, shuning uchun natija buning bilan bir xil:

```console
$ grep -r Aziz eslatmalar
eslatmalar/seshanba.txt:Aziz: tugma rangini oʻzgartirdi
eslatmalar/seshanba.txt:TODO Aziz: mijozga javob yozish
eslatmalar/chorshanba.txt:TODO Aziz: telefon raqamini tekshirish
eslatmalar/dushanba.txt:Aziz: saytga logo qoʻydi
eslatmalar/dushanba.txt:TODO Aziz: menyuni tuzatish
```

Uchta `TODO` va ikkita yopilgan ish: 5. Birinchi `grep` ning ishi behuda ketdi. `grep --help` da qoida yozilgan:
«FILE boʻlmasa, rekursiv boʻlsa `.` ni oʻqiydi, aks holda `-` ni (standart kirishni)».

**Qoida:** tik chiziqdan keyingi bosqichga `-r` ham, papka ham bermang. Toʻgʻrisi:

```console
$ grep -r TODO eslatmalar | grep Aziz | wc -l
3
```

### 2. Faqat `-r`, papkasiz

Papkani olib, `-r` ni qoldirsak ham boʻlmaydi: faylsiz `grep -r` lentani emas, **joriy papkani** (`.`) oʻqiydi.

```console
$ grep -r TODO eslatmalar | grep -r Aziz | wc -l
112
```

`112` — dars papkasidagi hamma fayllardagi `Aziz` qatorlari (`yil/` ham, README ham). Bu son papkaning ichiga
bogʻliq, sizda boshqacha boʻlishi mumkin. Muhimi: u `3` emas, va xato yoʻq.

### 3. Faqat papka, `-r` siz

Teskari holat: papka bor, `-r` yoʻq. Bu safar `grep` xato beradi:

```console
$ grep -r TODO eslatmalar | grep Aziz eslatmalar | wc -l
grep: eslatmalar: Is a directory
0
```

Qanday oʻqiladi: `grep:` — xatoni `grep` yozdi; `eslatmalar: Is a directory` — «`eslatmalar` — bu papka»: `-r` siz
`grep` papkani oʻqimaydi. Lentaga hech narsa tushmadi, `wc` `0` dedi. Tuzatish oʻsha: papkani ham olib tashlang.

### 4. Naqsh kichik harflar bilan

```console
$ grep -r todo eslatmalar | wc -l
0
```

Xato yoʻq, faqat `0`. `grep` katta-kichik harfni farqlaydi: fayllarda `TODO` yozilgan, `todo` emas. Naqshni fayldagi
kabi yozing. (Harfni farqlamaslik uchun `grep -i` bor.)

### 5. Terminal boshqa papkada

Dars papkasidan tashqarida (masalan, uy papkangizda) ishga tushirsangiz:

```console
$ grep -r TODO eslatmalar | wc -l
grep: eslatmalar: No such file or directory
0
```

«`eslatmalar`: bunday fayl yoki papka yoʻq». Bu buyruq dars papkasidan tashqarida ishga tushirildi. Tuzatish:
`cd go-backend-uz/lessons/sys-01-terminal` (yoki `pwd` bilan qayerdaligingizni tekshiring).

### 6. `wc -l` oʻrtada

`… | wc -l | grep Aziz` hech narsa chiqarmaydi va xato ham bermaydi: lentada faqat `6` qoladi. Bu «Tartib muhim»
boʻlimida koʻrildi. Tuzatish: avval filtrlash, keyin sanash: `… | grep Aziz | wc -l`.

### 7. Terminal «qotib qoldi»

`grep Aziz` ni yolgʻiz yozsangiz (oldida tik chiziq ham, papka ham yoʻq), `grep` standart kirishni, yaʼni
klaviaturani kutadi. Terminal javob bermayotgandek koʻrinadi. **Ctrl+C** bosing: u ishlayotgan buyruqni toʻxtatadi.

## Oʻzingizni tekshiring

1. Tik chiziq `|` nima qiladi?

<details>
<summary>Javob</summary>

Chapdagi buyruq natijasini (stdout) oʻngdagi buyruqning kirishiga (stdin) beradi. Natija ekranga emas, keyingi
bosqichga boradi.

</details>

2. Tik chiziqdan keyingi `grep` ga nega papka (yoki `-r`) bermaymiz?

<details>
<summary>Javob</summary>

Papka yoki `-r` berilsa, `grep` lentaga qaramaydi: papkani (yoki joriy papkani) qaytadan oʻqiydi. Natijada
oldingi bosqichning filtri yoʻqoladi va son jimgina notoʻgʻri chiqadi (`5` yoki `112`, `3` emas).

</details>

3. `wc -l` oʻrtada boʻlsa, nega terminal xato bermaydi, JavaScript esa TypeError beradi?

<details>
<summary>Javob</summary>

Lentada faqat matn bor, tiplar yoʻq. `wc -l` lentaga oddiy matn qatori `6` ni qoʻyadi, keyingi `grep` uni boshqa
qatorlar kabi filtrlaydi va hech narsa topmaydi. JavaScript'da esa `length` son qaytaradi, sonda `filter` metodi
yoʻq.

</details>

4. Natijani taxmin qiling:

```text
grep -r TODO eslatmalar | grep Bobur | wc -l
```

<details>
<summary>Javob</summary>

`1`. Olti `TODO` qatoridan faqat bittasi Boburniki (`seshanba.txt`).

```console
$ grep -r TODO eslatmalar | grep Bobur
eslatmalar/seshanba.txt:TODO Bobur: zaxira nusxa olish
```

```console
$ grep -r TODO eslatmalar | grep Bobur | wc -l
1
```

</details>

5. Dars boshidan: `grep -r TODO eslatmalar` natijasida har qator nega `eslatmalar/seshanba.txt:` kabi yoʻl bilan
   boshlanadi?

<details>
<summary>Javob</summary>

`grep` bir nechta faylni oʻqiyapti (`-r` papkadagi uchala faylni oʻqiydi). Bunday holda u har qator oldiga qaysi
fayldan ekanini yozadi: fayl yoʻli va ikki nuqta. Bitta faylni oʻqiganda bu prefiks boʻlmaydi.

</details>

## Uy vazifasi

Kurs papkasi: [lessons/sys-01-terminal](https://github.com/abdurahmon27/go-backend-uz/tree/main/lessons/sys-01-terminal).
Hammasini shu papkadan ishga tushiring.

- 🟢 **Oson:** `eslatmalar` papkasida Malikaning ochiq ishlari nechta? Boshlangʻich fayl `uyga/oson.sh` da bitta
  soʻzni oʻzgartiring, keyin `bash uyga/oson.sh` bilan ishga tushiring.
- 🟡 **Oʻrta:** `yil` papkasida Boburning **hamma** yozuvlari (yopilganlari bilan) nechta? Ishora: birinchi bosqichni
  olib tashlang va `yil` papkasini `-r` bilan `grep Bobur` ga bering (endi u birinchi bosqich). Terminal qotib qolsa,
  Ctrl+C.
- 🔍 **Qiziqish uchun:** `yil` papkasida toʻrt kishidan (Aziz, Malika, Bobur, Dilnoza) kimda eng koʻp ochiq ish bor?

Boshlangʻich fayl (`bash` — faylni bash bilan ishga tushiradi; `#` bilan boshlangan qatorlar izoh):

```bash filename="uyga/oson.sh"
#!/usr/bin/env bash
# SYS-0.01 · Uy vazifasi 🟢 Oson (boshlangʻich fayl)
# Savol: Malika nechta ishni hali qilmagan?
# Videodagi qator Azizning ishlarini sanaydi. Bitta soʻzni oʻzgartiring, keyin ishga tushiring
# (sys-01-terminal papkasidan): bash uyga/oson.sh
grep -r TODO eslatmalar | grep Aziz | wc -l
```

```console
$ bash uyga/oson.sh
3
```

Hozircha u Azizniki — `3`. Javoblar:
[uyga/javoblar.sh](https://github.com/abdurahmon27/go-backend-uz/blob/main/lessons/sys-01-terminal/uyga/javoblar.sh)
(`bash uyga/javoblar.sh`). Avval oʻzingiz urinib koʻring.

<details>
<summary>Javob</summary>

🟢 `Aziz` → `Malika`: `grep -r TODO eslatmalar | grep Malika | wc -l` → `2`.

🟡 `grep -r Bobur yil | wc -l` → `100`. Birinchi `grep -r TODO` olib tashlandi, shuning uchun `TODO` filtri yoʻq:
Boburning hamma qatorlari sanaladi. Endi `grep` birinchi bosqich, unga papka va `-r` berish toʻgʻri.

🔍 Bobur — `25` (Dilnoza `24`, Aziz `22`, Malika `22`). Eng oddiy yoʻl — dars pipeline'ini har bir ism bilan
ishga tushirish. `javoblar.sh` buni sikl bilan qiladi, keyin yana bir yoʻlni koʻrsatadi: `cut -d' ' -f2` qatorni
boʻsh joydan boʻlib 2-boʻlakni (ismni) oladi, `tr -d :` ikki nuqtani oʻchiradi, `sort` bir xil ismlarni yonma-yon
qoʻyadi, `uniq -c` yonma-yon turganlarini sanaydi, `sort -rn` eng kattasini tepaga chiqaradi. `grep -rh` dagi `-h`
fayl yoʻlini olib tashlaydi.

```console
100

Malika 22
Bobur 25
Dilnoza 24
     25 Bobur
     24 Dilnoza
     22 Malika
     22 Aziz
```

</details>
