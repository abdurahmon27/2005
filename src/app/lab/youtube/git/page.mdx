Git'ni buyruqlar roʻyxati sifatida emas, maʼlumot modeli sifatida oʻrganamiz: commit — bu snapshot, branch — bitta hash yozilgan fayl, hamma narsa `.git` ichidagi obyektlar. Shuning uchun conflict, rebase, `reset` va `reflog` qoʻrqinchli boʻlmaydi: nima boʻlayotganini koʻrib turasiz. Pro Git, MIT Missing Semester va GitHub hujjatlari asosida, hammasi kursning haqiqiy repo'si (bozor) ustida: jamoada ishlash, code review odobi, GitHub Actions'da CI, sizib chiqqan kalitni toʻgʻri tartibda tozalash, katta repo'lar va oxirida git'ning oʻzini Go'da yozamiz. Birinchi uch dars 1-mavsumda, qolganlari har mavsumda kichik qadamlar bilan.
