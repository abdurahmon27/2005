## The one-paragraph version

I build full-stack products in **TypeScript** and increasingly in **Go**. Today
I'm **Lead Software Engineer at [dona.uz](https://dona.uz)**. Before that, at
[Numeo](https://numeo.ai), I shipped a Chrome extension, a React admin
dashboard, Node backend services and Telegram Mini Apps. I mentor; and I chair
**Gopher Uzbekistan** under [FLOSS Uzbekistan](https://floss.uz), where I run
[gopher.uz](https://gopher.uz) and the Go community around it. My daily driver
is **NixOS + Hyprland**, which is its own hobby — see [NixOS & Linux](/lab/skills/nixos).

## How I learn

1. Build the smallest real thing that could work.
2. Break it on purpose, then read the docs I skipped.
3. Write the note — [Skills](/lab/skills) is that step made public.
4. Teach it to someone; the gaps show up immediately.
