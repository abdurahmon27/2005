Every idea I keep coming back to gets a note here. The rule: one note per idea, a
**status** at the top, and the reason it should exist before any talk of the stack.

| Status | Meaning |
|---|---|
| **Shipping** | It exists, people can use it, I maintain it. |
| **Building** | Code exists and runs; not finished. |
| **Designing** | I know the shape of it; nothing runs yet. |
| **Seed** | One paragraph. Might be a bad idea. |

## The filter I try to apply

1. Would I use it this week? If not, it's a portfolio piece, not an idea.
2. What's the smallest version that's still useful on its own?
3. What do I learn by building it that I can't learn by reading? See [Skills](/lab/skills).

> **Stub.** Seeds go here as one-liners before they earn their own note.
